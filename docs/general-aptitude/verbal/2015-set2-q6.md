# 2015 CS2 Q6: Most grammatical sentence

## Question

Out of the following four sentences, select the most suitable sentence with respect to grammar and usage:

- (A) Since the report lacked needed information, it was of no use to them.
- (B) The report was useless to them because there were no needed information in it.
- (C) Since the report did not contain the needed information, it was not real useful to them.
- (D) Since the report lacked needed information, it would not had been useful to them.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) is correct in grammar and usage.
- (B) "there were no needed information": *information* is uncountable, so it needs the singular verb *was*.
- (C) "not real useful": an adverb is needed, *really useful*.
- (D) "would not had been": the correct form is *would not have been*.

**Key idea:** check agreement (uncountable *information* takes a singular verb), adverb form and verb tense.

</details>
