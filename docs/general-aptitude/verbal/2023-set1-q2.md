# 2023 CS Q2: Analogy by word meaning: Kind : ___ :: Often : Frequently

## Question

Kind : _______ : : Often : Frequently

(By word meaning)

- (A) Mean
- (B) Type
- (C) Cruel
- (D) Kindly

<details class="success" markdown="1">
<summary>Answer</summary>

**MTA (marks awarded to all; the key gives no single option)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Official key:** *MTA*, i.e. marks to all. The question was treated as faulty, so there is no single option to check against.

**The intended pattern.** *Often : Frequently* is a pair of synonyms, so the blank should be a synonym of *Kind*.

- *Type* is a synonym of the noun *kind* ("a kind of fruit" = "a type of fruit"). This is the closest fit.
- *Mean*, *Cruel*: opposites of the adjective *kind*.
- *Kindly*: the adverb form of *kind*, so a related word, not a synonym.

**Why it was withdrawn.** *Kind* can be a noun (type) or an adjective (gentle). Under the adjective reading, no option is a clean synonym, so the question is ambiguous.

**Status note:** marked `unverified` because the key supplies no answer to compare with. *Type* is my reading of the intended answer.

**Key idea:** in a word-meaning analogy, first decide which part of speech and which sense the words use.

</details>
