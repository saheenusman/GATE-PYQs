# 2016 CS2 Q56: Choosing the correct articles in a sentence about a Municipal Commissioner

## Question

(GA Set-6, Q1) The man who is now Municipal Commissioner worked as ____________________.

- (A) the security guard at a university
- (B) a security guard at the university
- (C) a security guard at university
- (D) the security guard at the university

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- *worked as* **a** security guard: a job title or role takes the indefinite article, since he was one of many security guards.
- *at **the** university*: a particular, understood university (the one in the story), so the definite article.

So "a security guard at the university" is **(B)**.

- (A) "a university" makes the place unspecified, and "the security guard" suggests a unique guard.
- (C) "at university" drops the article, which is wrong here.
- (D) "the security guard" implies the only guard.

**Key idea:** role takes *a*; a known specific place takes *the*.

</details>
