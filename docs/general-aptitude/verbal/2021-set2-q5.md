# 2021 CS2 Q5: Analogy: Pen is to Write as Knife is to ____

## Question

Pen : Write :: Knife : ______

Which one of the following options maintains a similar logical relation in the above?

- (A) Vegetables
- (B) Sharp
- (C) Cut
- (D) Blunt

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A **pen** is a tool used to **write**. The relation is "tool : its function". A **knife** is a tool used to **cut**.

- (A) Vegetables is what a knife may cut, not its function.
- (B) Sharp and (D) Blunt describe a property of a knife.
- (C) **Cut.** Same relation as pen to write.

**Key idea:** keep the same relation: tool to the action it performs.

</details>
