# 2017 CS2 Q57: Word order with enough: Saturn is ___ to be seen

## Question

Saturn is __________ to be seen on a clear night with the naked eye.

- (A) enough bright
- (B) bright enough
- (C) as enough bright
- (D) bright as enough

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rule.** When *enough* modifies an adjective, it comes **after** the adjective: *bright enough to be seen*. It is followed by an infinitive ("to be seen").

- (A) *enough bright* puts *enough* before the adjective, the order used for nouns (*enough light*), not adjectives.
- (B) *bright enough* is correct.
- (C), (D) *as enough bright* and *bright as enough* are not valid English constructions (*as ... as* is a comparison and needs a second *as*).

Answer: **(B)**.

**Status note:** grammar question (no program applies); the answer matches the official key.

**Key idea:** adjective + *enough* + *to*-infinitive.

</details>
