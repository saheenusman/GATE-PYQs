# 2012 CS Q60: That, which or who for a dog

## Question

Choose the most appropriate alternative from the options given below to complete the following sentence:

**Suresh's dog is the one ––––––––– was hurt in the stampede.**

- (A) that
- (B) which
- (C) who
- (D) whom

<details class="success" markdown="1">
<summary>Answer</summary>

**MTA (marks awarded to all; the key names no single option)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Official key:** MTA, i.e. marks to all. The question has more than one acceptable option, so there is no single answer to check.

**My reading.** The blank starts a relative clause about an animal, as the subject of "was hurt".

- **that** is the usual choice after "the one" for a restrictive clause: acceptable.
- **which** is also used for animals and for things, and many writers accept it here: also acceptable.
- **who** is for people (though some speakers use it for pets).
- **whom** is the object form and cannot be a subject.

With both (A) and (B) defensible, the question is ambiguous, which fits the MTA.

**Status note:** marked `unverified`. This is a judgement about usage, so there is no code check, and the key gives no answer to compare with.

**Key idea:** "whom" is for objects; for animals the subject forms are "that" or "which".

</details>
