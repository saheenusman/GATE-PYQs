# 2025 CS2 Q2: Analogy: Bird : Nest :: Bee : ___

## Question

Bird : Nest :: Bee : _______

Select the correct option to complete the analogy.

- (A) Kennel
- (B) Hammock
- (C) Hive
- (D) Lair

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A nest is the home a bird builds and lives in. The matching home of a bee is a **hive**.

| Option | Whose home |
|---|---|
| A, kennel | a dog |
| B, hammock | a hanging bed, not an animal home |
| **C, hive** | bees |
| D, lair | a wild animal such as a lion or fox |

**Key idea:** in "A : B :: C : D" analogies, name the relation first (here *animal : its home*), then apply it.

</details>
