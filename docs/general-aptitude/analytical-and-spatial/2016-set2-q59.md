# 2016 CS2 Q59: Odd one out among four five-letter sequences

## Question

(GA Set-6, Q4) Pick the odd one from the following options.

- (A) CADBE
- (B) JHKIL
- (C) XVYWZ
- (D) ONPMQ

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write each string as alphabet positions and subtract the smallest value:

| Option | Positions | Relative to the smallest |
|---|---|---|
| CADBE | 3, 1, 4, 2, 5 | 3, 1, 4, 2, 5 |
| JHKIL | 10, 8, 11, 9, 12 | 3, 1, 4, 2, 5 |
| XVYWZ | 24, 22, 25, 23, 26 | 3, 1, 4, 2, 5 |
| ONPMQ | 15, 14, 16, 13, 17 | **3, 2, 4, 1, 5** |

A, B and C follow the pattern $3, 1, 4, 2, 5$. ONPMQ follows $3, 2, 4, 1, 5$, so it is the odd one: **(D)**.

**Key idea:** three strings follow the position pattern 3-1-4-2-5; ONPMQ follows 3-2-4-1-5.

</details>
