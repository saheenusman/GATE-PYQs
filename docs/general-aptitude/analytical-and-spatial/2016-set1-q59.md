# 2016 CS1 Q59: Decoding a word code to find the word for aftercare

## Question

(GA Set-5, Q4) If 'relftaga' means carefree, 'otaga' means careful and 'fertaga' means careless, which of the following could mean 'aftercare'?

- (A) zentaga
- (B) tagafer
- (C) tagazen
- (D) relffer

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find the pieces.** All three codes end in `taga`, and all three English words begin with *care*. So `taga` = *care*.

| Code | Left over | English left over |
|---|---|---|
| relf-taga | `relf` | *free* |
| o-taga | `o` | *ful* |
| fer-taga | `fer` | *less* |

**Order.** In the code, `taga` (care) comes **last**, while in English *care* comes first. So the code writes the parts in the **reverse** order of the English word.

**Apply it.** *aftercare* = *after* + *care*, so the code is `taga` followed by the code for *after*. Only (C) `tagazen` fits (`zen` = *after*).

- (A) `zentaga` has the parts in the English order (*after* then *care*), not reversed.
- (B) `tagafer` means *care* + *less*, i.e. careless.
- (D) `relffer` contains no `taga` (*care*).

**Key idea:** `taga` = care, and the code lists the parts in reverse order, so aftercare = `taga` + `zen`.

</details>
