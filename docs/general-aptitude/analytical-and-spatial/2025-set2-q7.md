# 2025 CS2 Q7: Letter coding of IMAGE and FIELD

## Question

If IMAGE and FIELD are coded as FHBNJ and EMFJG respectively then, which one among the given options is the most appropriate code for BEACH ?

- (A) CEADP
- (B) IDBFC
- (C) JGIBC
- (D) IBCEC

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find the rule on IMAGE.** Reverse it: E G A M I. Then move each letter one step forward in the alphabet: F H B N J, which is the given code.

**Check on FIELD.** Reverse: D L E I F. Shift each letter by +1: E M F J G, which is the given code. The rule holds.

**Apply to BEACH.** Reverse: H C A E B. Shift each by +1: I D B F C, giving **IDBFC**.

| Option | Why wrong |
|---|---|
| A, C, D | Not equal to IDBFC (they contain letters that the rule cannot produce, for example P, G or a repeated C) |

**Key idea:** test the simplest transformations first (reverse, then shift). One example fixes a guess and a second example confirms it.

</details>
