# 2017 CS2 Q62: Which mislabelled box to open to identify all three

## Question

There are three boxes. One contains apples, another contains oranges and the last one contains both apples and oranges. All three are known to be incorrectly labelled. If you are permitted to open just one box and then pull out and inspect only one fruit, which box would you open to determine the contents of all three boxes?

- (A) The box labelled 'Apples'
- (B) The box labelled 'Apples and Oranges'
- (C) The box labelled 'Oranges'
- (D) Cannot be determined

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Key fact.** Every label is wrong, so no box holds what its label says. Only two assignments of contents to labels are possible:

| Label on box | Assignment 1 | Assignment 2 |
|---|---|---|
| Apples | Oranges | Both |
| Oranges | Both | Apples |
| Apples and Oranges | Apples | Oranges |

**Open the box labelled "Apples and Oranges".** In both assignments it holds a single fruit type, and the two assignments differ in which one:

- Draw an **apple**: this box holds only apples, so Assignment 1 holds. The "Apples" box is Oranges and the "Oranges" box is Both.
- Draw an **orange**: this box holds only oranges, so Assignment 2 holds. The "Apples" box is Both and the "Oranges" box is Apples.

One fruit settles all three boxes.

**Why the others fail.**

- (A) Opening the box labelled "Apples" and drawing an orange fits both assignments (it holds Oranges in the first, Both in the second), so you cannot tell which one applies.
- (C) Opening the box labelled "Oranges" has the same problem: drawing an apple fits both assignments.
- (D) is false, since (B) works.

Answer: **(B)**.

**Code check:** a program listed the two possible assignments and, for each choice of box to open, the fruit you might draw. Opening "Apples and Oranges" gives different single outcomes in the two assignments (apple or orange), so it identifies the assignment. Opening "Apples" or "Oranges" can give the same outcome in both assignments, so it does not decide.

**Key idea:** start with the box whose wrong label rules out the mixed contents, so it holds a single fruit type.

</details>
