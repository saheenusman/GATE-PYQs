# 2014 CS1 Q65: Internal planes in a tetrahedron joined to an inner point

## Question

(GA Set-7, Q10) When a point inside of a tetrahedron (a solid with four triangular surfaces) is connected by straight lines to its corners, how many (new) internal planes are created with these lines? _____________

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The inner point $O$ is joined to the 4 corners. Any 2 of these 4 lines fix a plane through $O$, and that plane contains one edge of the tetrahedron.

A tetrahedron has 6 edges, so the number of pairs of corners is

$$\binom{4}{2} = 6$$

Each plane $O$-corner-corner is a new internal plane: **6**.

**Key idea:** one plane per pair of joined corners, $\binom{4}{2}$.

</details>
