# 2022 CS Q3: Value of (r+2)(r+3)(r+4)(r+5) for a root of x²+2x+6

## Question

Let $r$ be a root of the equation $x^2 + 2x + 6 = 0$.

Then the value of the expression $(r+2)(r+3)(r+4)(r+5)$ is

- (A) $51$
- (B) $-51$
- (C) $126$
- (D) $-126$

<details class="success" markdown="1">
<summary>Answer</summary>

**D ($-126$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Pair the factors** so that both products share the same $r^2 + 7r$ term:

$$(r+2)(r+5) = r^2 + 7r + 10, \qquad (r+3)(r+4) = r^2 + 7r + 12$$

**Reduce using the equation.** From $r^2 = -2r - 6$ we get $r^2 + 7r = 5r - 6$. So the product is

$$(5r + 4)(5r + 6) = 25r^2 + 50r + 24 = 25(r^2 + 2r) + 24$$

Since $r^2 + 2r = -6$, this is $25(-6) + 24 = -126$.

**Why the others fail:** the roots are complex ($r = -1 \pm i\sqrt5$), so there is no sign guesswork from a real root. Only $-126$ comes out of the algebra above.

**Key idea:** reduce higher powers with the defining equation instead of computing the roots.

</details>
