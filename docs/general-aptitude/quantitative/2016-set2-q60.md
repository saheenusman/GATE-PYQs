# 2016 CS2 Q60: Ratio of power sums of the roots of a quadratic with product 4

## Question

(GA Set-6, Q5) In a quadratic function, the value of the product of the roots $(\alpha, \beta)$ is 4. Find the value of

$$\frac{\alpha^n + \beta^n}{\alpha^{-n} + \beta^{-n}}$$

- (A) $4/n$
- (B) $4^n$
- (C) $2^{2n-1}$
- (D) $4^{n-1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Rewrite the denominator over a common denominator:

$$\alpha^{-n} + \beta^{-n} = \frac{\alpha^n + \beta^n}{(\alpha\beta)^n}$$

So the ratio is

$$\frac{\alpha^n + \beta^n}{(\alpha^n + \beta^n)/(\alpha\beta)^n} = (\alpha\beta)^n = 4^n$$

**(B)**.

**Key idea:** the ratio simplifies to $(\alpha\beta)^n = 4^n$.

</details>
