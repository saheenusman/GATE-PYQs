# 2017 CS1 Q60: Probability that a k-digit number avoids the digits 0, 5 and 9

## Question

The probability that a $k$-digit number does NOT contain the digits $0$, $5$, or $9$ is

- (A) $0.3^{k}$
- (B) $0.6^{k}$
- (C) $0.7^{k}$
- (D) $0.9^{k}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C (official key). The exact value for true k-digit numbers is (10/9)(0.7)^k, so C is only the intended approximation: see the solution**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Idea.** Each of the $k$ digit positions must avoid $0$, $5$ and $9$. That leaves $7$ allowed digits $\lbrace 1,2,3,4,6,7,8\rbrace$ out of $10$.

**Official answer (C).** Treating each digit as independently one of the ten digits, each position is fine with probability $7/10 = 0.7$, so

$$P = 0.7^{k}$$

**Why the exact value differs slightly.** A genuine $k$-digit number cannot start with $0$.

- Total $k$-digit numbers: $9 \times 10^{k-1}$.
- Numbers using only the 7 allowed digits: $7^{k}$ (the leading digit is automatically non-zero).

$$P_{\text{exact}} = \frac{7^{k}}{9 \times 10^{k-1}} = \frac{10}{9}\,(0.7)^{k}$$

This equals $0.7^{k}$ only if leading zeros are allowed (i.e. digit strings of length $k$). For $k=1$ the exact value is $7/9 = 0.778$, not $0.7$.

None of the options is the exact value for true $k$-digit numbers. (C) is the closest and is what the key intends.

**Why the others fail.** $0.3^k$ is the probability of *using only* the forbidden digits. $0.6^k$ and $0.9^k$ correspond to 6 and 9 allowed digits.

**Code check:** counting every $k$-digit number for $k=1..5$ gave $7/9$, $49/90$, $343/900$, $2401/9000$ and $16807/90000$, which equal $\tfrac{10}{9}\,0.7^{k}$ exactly and are all larger than $0.7^{k}$.

**Status note:** marked `disputed` because the key's $0.7^k$ ignores the non-zero leading digit.

**Key idea:** the probability is the product of per-digit probabilities; the only subtlety is the leading digit of a true $k$-digit number.

</details>
