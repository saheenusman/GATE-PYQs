# 2020 CS Q9: Acute angles of two perpendicular lines with the X-axis

## Question

Two straight lines are drawn perpendicular to each other in X-Y plane. If $\alpha$ and $\beta$ are the acute angles the straight lines make with the X-axis, then $\alpha + \beta$ is ______.

- (A) $60^\circ$
- (B) $90^\circ$
- (C) $120^\circ$
- (D) $180^\circ$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the first line make an angle $\alpha$ with the X-axis, with $0^\circ < \alpha < 90^\circ$ (acute).

A line perpendicular to it is turned by $90^\circ$, so it makes an angle $\alpha + 90^\circ$ with the positive X-axis. That angle is obtuse. The acute angle the same line makes with the X-axis is its supplement:

$$\beta = 180^\circ - (\alpha + 90^\circ) = 90^\circ - \alpha.$$

Therefore

$$\alpha + \beta = 90^\circ.$$

**Check with slopes.** Perpendicular lines satisfy $m_1 m_2 = -1$, so $\tan\alpha \cdot \tan\beta = 1$ for the acute angles. That holds exactly when $\beta = 90^\circ - \alpha$.

**Why the others fail:** the sum is fixed at $90^\circ$ for every perpendicular pair, so $60^\circ$, $120^\circ$ and $180^\circ$ cannot be right.

**Key idea:** the two acute angles of a perpendicular pair are complementary.

</details>
