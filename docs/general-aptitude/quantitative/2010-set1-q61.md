# 2010 CS Q61: If 137+276=435, what is 731+672

## Question

If $137 + 276 = 435$, how much is $731 + 672$?

- (A) $534$
- (B) $1403$
- (C) $1623$
- (D) $1513$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The first sum is wrong in base $10$ ($137 + 276 = 413$), so the numbers are written in another base $b$.

**Find the base.** Units column: $7 + 6 = 13$ must end in the digit $5$ with a carry, so $13 = b + 5$ and $b = 8$.

**Check.** Tens: $3 + 7 + 1 = 11 = 8 + 3$, digit $3$, carry $1$. Hundreds: $1 + 2 + 1 = 4$. So $137 + 276 = 435$ in base $8$.

**Now add in base 8.**

| Column | Sum | Digit, carry |
|---|---|---|
| units | $1 + 2 = 3$ | $3$, $0$ |
| tens | $3 + 7 = 10$ | $2$, $1$ |
| hundreds | $7 + 6 + 1 = 14$ | $6$, $1$ |
| thousands | | $1$ |

The result is $1623_8$: (C).

- (A) $534$ and (D) $1513$ do not follow from a base-$8$ addition.
- (B) $1403$ is not the base-$8$ sum either. (The base-$10$ sum of the digit strings is $1403$.)

**Code check:** Python found base $8$ as the only base from $8$ to $11$ where $137 + 276 = 435$, and printed $731 + 672 = 1623$ in that base.

**Key idea:** if an addition looks wrong, test whether the numbers are in another base, using the units column first.

</details>
