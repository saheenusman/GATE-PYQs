# 2015 CS2 Q9: Which transformations of an arithmetic sequence stay arithmetic

## Question

If the list of letters P, R, S, T, U is an arithmetic sequence, which of the following are also in arithmetic sequence?

- I. 2P, 2R, 2S, 2T, 2U
- II. P-3, R-3, S-3, T-3, U-3
- III. $P^2, R^2, S^2, T^2, U^2$

- (A) I only
- (B) I and II
- (C) II and III
- (D) I and III

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the common difference be $d$, so consecutive terms differ by $d$.

- I: multiplying by 2 gives common difference $2d$. Still arithmetic.
- II: subtracting 3 shifts every term equally, so the difference is still $d$. Still arithmetic.
- III: squaring gives differences like $(a+d)^2 - a^2 = 2ad + d^2$, which depends on $a$. Not constant unless $d = 0$. Not arithmetic.

I and II: option (B). (A) misses II. (C) and (D) include III.

**Key idea:** scaling and shifting keep a sequence arithmetic; squaring does not.

</details>
