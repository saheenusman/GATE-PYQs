# 2014 CS3 Q65: Subtraction in base 8

## Question

(GA Set-9, Q10) Consider the equation: $(7526)_8 - (Y)_8 = (4364)_8$, where $(X)_N$ stands for $X$ to the base $N$. Find $Y$.

- (A) 1634
- (B) 1737
- (C) 3142
- (D) 3162

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$Y = (7526)_8 - (4364)_8$. Subtract digit by digit in base 8, borrowing 8:

| Column (right to left) | Working | Digit |
|---|---|---|
| 1st | $6 - 4$ | 2 |
| 2nd | $2 - 6$: borrow, $10 - 6$ | 4 |
| 3rd | $5 - 1 - 3$ | 1 |
| 4th | $7 - 4$ | 3 |

So $Y = (3142)_8$.

**Check in decimal:** $7526_8 = 3926$ and $4364_8 = 2292$, so the difference is $1634_{10} = 3142_8$.

(A) 1634 is the decimal difference, not written in base 8, so it is a trap. (B) 1737 and (D) 3162 do not satisfy the equation.

**Code check:** `oct(int('7526',8) - int('4364',8))` gives `0o3142`.

**Key idea:** borrow 8 (not 10) when subtracting in base 8.

</details>
