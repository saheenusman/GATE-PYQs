# 2023 CS Q9: f(x) = g(y) for all x and y

## Question

$f(x)$ and $g(y)$ are functions of $x$ and $y$, respectively, and $f(x) = g(y)$ for all real values of $x$ and $y$.

Which one of the following options is necessarily TRUE for all $x$ and $y$?

- (A) $f(x) = 0$ and $g(y) = 0$
- (B) $f(x) = g(y) = \text{constant}$
- (C) $f(x) \ne \text{constant}$ and $g(y) \ne \text{constant}$
- (D) $f(x) + g(y) = f(x) - g(y)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B ($f(x) = g(y) = \text{constant}$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Fix $y$ and vary $x$.** Then $g(y)$ is a fixed number, and $f(x)$ equals it for every $x$. So $f$ is constant. By the same argument, $g$ is constant, and both equal the same constant.

**Why the others fail:**
- **A**: the constant need not be 0 (take $f = g = 5$).
- **C**: says the opposite of what we proved.
- **D**: this holds only if $g(y) = 0$, which is not forced.

**Key idea:** if two independent variables always give equal values, the common value cannot depend on either.

</details>
