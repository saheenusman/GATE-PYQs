# 2018 CS Q7: Product xyz from p^-x = 1/q, q^-y = 1/r, r^-z = 1/p

## Question

If $pqr \neq 0$ and $p^{-x} = \dfrac{1}{q},\ q^{-y} = \dfrac{1}{r},\ r^{-z} = \dfrac{1}{p}$, what is the value of the product $xyz$?

- (A) $-1$
- (B) $\dfrac{1}{pqr}$
- (C) $1$
- (D) $pqr$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rewrite each condition with positive powers:**

$$p^{x} = q,\qquad q^{y} = r,\qquad r^{z} = p$$

**Chain them:**

$$p = r^{z} = (q^{y})^{z} = ((p^{x})^{y})^{z} = p^{xyz}$$

So $p^{xyz} = p^1$, which gives $xyz = 1$.

**Why the others fail:** $-1$ would come from mixing up the signs of the exponents. $\frac{1}{pqr}$ and $pqr$ depend on $p, q, r$, but $xyz$ is a pure number.

**Caveat:** this assumes $p \ne \pm1$. If $p=q=r=1$, every $x,y,z$ works, so the question implicitly assumes generic $p$.

**Key idea:** substitute the chain of powers back into the first variable and compare exponents.

</details>
