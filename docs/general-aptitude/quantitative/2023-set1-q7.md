# 2023 CS Q7: Compare 0.01t² and 4t

## Question

Consider two functions of time $t$:

$f(t) = 0.01\,t^2$, $g(t) = 4t$, where $0 < t < \infty$.

Now consider the following two statements:

(i) For some $t > 0$, $g(t) > f(t)$.

(ii) There exists a $T$ such that $f(t) > g(t)$ for all $t > T$.

Which one of the following options is TRUE?

- (A) only (i) is correct
- (B) only (ii) is correct
- (C) both (i) and (ii) are correct
- (D) neither (i) nor (ii) is correct

<details class="success" markdown="1">
<summary>Answer</summary>

**C (both (i) and (ii) are correct)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Look at the difference.**

$$f(t) - g(t) = 0.01t^2 - 4t = 0.01\,t\,(t - 400)$$

- For $0 < t < 400$ this is negative, so $g > f$. **(i) is true.**
- For $t > 400$ this is positive, so $f > g$. Take $T = 400$. **(ii) is true.**

**Key idea:** a quadratic eventually beats a linear function, but the linear one can lead for small $t$.

</details>
