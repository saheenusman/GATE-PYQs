# 2025 CS2 Q3: Solving Pe^x = Qe^(-x) for all x

## Question

If $Pe^{x} = Qe^{-x}$ for all real values of $x$, which one of the following statements is true?

- (A) $P = Q = 0$
- (B) $P = Q = 1$
- (C) $P = 1;\ Q = -1$
- (D) $\dfrac{P}{Q} = 0$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The equation must hold for **every** real $x$.

- At $x = 0$: $P = Q$.
- At $x = 1$: $Pe = Qe^{-1} = Pe^{-1}$, so $P(e - e^{-1}) = 0$. Since $e - e^{-1} \neq 0$, we get $P = 0$, hence $Q = 0$.

So $P = Q = 0$.

| Option | Why wrong |
|---|---|
| B | $P=Q=1$ gives $e^x = e^{-x}$, true only at $x = 0$ |
| C | $P=1, Q=-1$ gives $e^x = -e^{-x}$, never true |
| D | $P/Q = 0$ forces $P = 0$ but $Q \neq 0$, which fails at $x=0$ where $P=Q$ |

**Key idea:** $e^x$ and $e^{-x}$ are different functions, so only the zero coefficients make them match for all $x$.

</details>
