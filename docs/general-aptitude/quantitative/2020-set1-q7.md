# 2020 CS Q7: P = 3, R = 27, T = 243, find Q + S

## Question

If P = 3, R = 27, T = 243, then Q + S = ______.

- (A) 40
- (B) 80
- (C) 90
- (D) 110

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Spot the pattern.** P, Q, R, S, T are consecutive letters, and the given values are powers of 3:

| Letter | P | Q | R | S | T |
|---|---|---|---|---|---|
| Value | $3^1 = 3$ | $3^2 = 9$ | $3^3 = 27$ | $3^4 = 81$ | $3^5 = 243$ |

The given values P = 3, R = 27, T = 243 fit this exactly, so Q = 9 and S = 81.

$$Q + S = 9 + 81 = 90.$$

**Why the others fail:** the pattern fixes Q = 9 and S = 81, so the sum is exactly 90. The values 40, 80 and 110 do not follow from it.

**Key idea:** when values are given for alternate positions, check for a simple rule that also fills the gaps. Here, each letter is the next power of 3.

</details>
