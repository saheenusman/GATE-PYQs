# 2014 CS2 Q63: Values of |-x^3 + x^2 - x| when |x^2 - 2x + 3| = 11

## Question

(GA Set-8, Q8) If $x$ is real and $|x^2 - 2x + 3| = 11$, then possible values of $|-x^3 + x^2 - x|$ include

- (A) 2, 4
- (B) 2, 14
- (C) 4, 52
- (D) 14, 52

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$x^2 - 2x + 3 = (x-1)^2 + 2 > 0$, so the absolute value changes nothing:

$$x^2 - 2x + 3 = 11 \Rightarrow x^2 - 2x - 8 = 0 \Rightarrow x = 4 \text{ or } x = -2$$

Evaluate $|-x^3 + x^2 - x|$:

| $x$ | $-x^3 + x^2 - x$ | Absolute value |
|---|---|---|
| 4 | $-64 + 16 - 4 = -52$ | 52 |
| $-2$ | $8 + 4 + 2 = 14$ | 14 |

The values are 14 and 52: **D**.

**Key idea:** a quadratic that is always positive loses the absolute value.

</details>
