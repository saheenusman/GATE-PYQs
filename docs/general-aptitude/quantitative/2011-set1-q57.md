# 2011 CS Q57: Relation among P, Q and R from equal logarithm ratios

## Question

If $\text{Log}(P) = (1/2)\,\text{Log}(Q) = (1/3)\,\text{Log}(R)$, then which of the following options is **TRUE**?

- (A) $P^2 = Q^3 R^2$
- (B) $Q^2 = PR$
- (C) $Q^2 = R^3 P$
- (D) $R = P^2 Q^2$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the common value be $k$, so $\log P = k$, $\log Q = 2k$ and $\log R = 3k$. Hence $Q = P^2$ and $R = P^3$.

- (B) $Q^2 = P^4$ and $PR = P \cdot P^3 = P^4$: **true**.
- (A) $Q^3 R^2 = P^6 \cdot P^6 = P^{12}$, but $P^2$ is not that.
- (C) $R^3 P = P^9 \cdot P = P^{10}$, but $Q^2 = P^4$.
- (D) $P^2 Q^2 = P^2 P^4 = P^6$, but $R = P^3$.

So (B).

**Key idea:** set all three equal logarithms to k, so each variable is a power of P.

</details>
