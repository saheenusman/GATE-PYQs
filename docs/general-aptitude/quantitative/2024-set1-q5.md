# 2024 CS1 Q5: Value of (p⁴+q⁴)/(p²q²) from a log equation

## Question

For positive non-zero real variables $p$ and $q$, if

$$\log(p^2 + q^2) = \log p + \log q + 2\log 3,$$

then the value of $\dfrac{p^4 + q^4}{p^2 q^2}$ is

- (A) 79
- (B) 81
- (C) 9
- (D) 83

<details class="success" markdown="1">
<summary>Answer</summary>

**A (79)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Combine the logs:** $\log p + \log q + 2\log 3 = \log(9pq)$. So

$$p^2 + q^2 = 9pq.$$

**Square-completing trick:**

$$\frac{p^4+q^4}{p^2q^2} = \frac{(p^2+q^2)^2 - 2p^2q^2}{p^2q^2} = \left(\frac{p^2+q^2}{pq}\right)^2 - 2 = 9^2 - 2 = 79.$$

**Why the others fail:** 81 forgets the $-2$. 9 is the intermediate ratio. 83 has the wrong sign on the 2.

**Key idea:** $a^2 + b^2 = (a+b)^2 - 2ab$ turns a fourth-power expression into one in the known quantity.

</details>
