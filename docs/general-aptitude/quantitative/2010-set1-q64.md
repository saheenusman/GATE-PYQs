# 2010 CS Q64: Work rates of skilled, semi-skilled and unskilled workers

## Question

$5$ skilled workers can build a wall in $20$ days; $8$ semi-skilled workers can build a wall in $25$ days; $10$ unskilled workers can build a wall in $30$ days. If a team has $2$ skilled, $6$ semi-skilled and $5$ unskilled workers, how long will it take to build the wall?

- (A) $20$
- (B) $18$
- (C) $16$
- (D) $15$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Find the part of a wall one worker of each kind builds in one day.

- Skilled: $5 \times 20 = 100$ worker-days per wall, so $\tfrac{1}{100}$ per day.
- Semi-skilled: $8 \times 25 = 200$ worker-days per wall, so $\tfrac{1}{200}$ per day.
- Unskilled: $10 \times 30 = 300$ worker-days per wall, so $\tfrac{1}{300}$ per day.

The team builds, per day,

$$\frac{2}{100} + \frac{6}{200} + \frac{5}{300} = \frac{6 + 9 + 5}{300} = \frac{20}{300} = \frac{1}{15}.$$

So the wall takes $15$ days: (D).

- (A), (B) and (C) are longer than $15$ days, which would need a daily rate below $1/15$.

**Code check:** exact fractions in Python gave $1 / (2/100 + 6/200 + 5/300) = 15$.

**Key idea:** convert each group to a work rate (walls per day per worker) and add the rates.

</details>
