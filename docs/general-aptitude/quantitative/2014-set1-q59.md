# 2014 CS1 Q59: Value of z^2 + 1/z^2 from (z+1/z)^2 = 98

## Question

(GA Set-7, Q4) If $(z + 1/z)^2 = 98$, compute $(z^2 + 1/z^2)$.

<details class="success" markdown="1">
<summary>Answer</summary>

**96**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Expand the square:

$$(z + 1/z)^2 = z^2 + 2 + 1/z^2 = 98$$

$$z^2 + 1/z^2 = 98 - 2 = 96$$

**Code check:** `98 - 2` gives `96`.

**Key idea:** $(a+b)^2 = a^2 + 2ab + b^2$ with $ab = 1$.

</details>
