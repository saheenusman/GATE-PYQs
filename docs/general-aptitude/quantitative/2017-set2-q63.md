# 2017 CS2 Q63: Number of digits in the cube of a 30-digit number starting with 47

## Question

$X$ is a 30 digit number starting with the digit 4 followed by the digit 7. Then the number $X^3$ will have

- (A) 90 digits
- (B) 91 digits
- (C) 92 digits
- (D) 93 digits

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Bound $X$.** $X$ has 30 digits and starts with 47, so

$$4.7 \times 10^{29} \le X < 4.8 \times 10^{29}.$$

**Cube the bounds.**

$$4.7^3 = 103.823,\qquad 4.8^3 = 110.592.$$

$$1.03823\times10^{89} \le X^3 < 1.10592\times10^{89}.$$

Both ends lie between $10^{89}$ and $10^{90}$, so $X^3$ has $89 + 1 = 90$ digits: **(A)**.

**Why the others fail.** Since $X < 10^{30}$, we get $X^3 < 10^{90}$, so $X^3$ can never have more than 90 digits. That rules out (B), (C) and (D) outright.

**Why the leading digits matter.** The cube is at least $10^{89}$ only when $X \ge \sqrt[3]{100}\times10^{29} \approx 4.64\times10^{29}$. A start of 47 is above that, so the cube has 90 digits; a start of 45, for example, would give $4.5^3 = 91.1$, i.e. 89 digits.

**Code check:** the smallest and largest possible values of $X$, $47\times10^{28}$ and $48\times10^{28}-1$, both have cubes with 90 digits.

**Key idea:** bound $X$ using its leading digits, cube the bounds, and see which power of 10 they straddle.

</details>
