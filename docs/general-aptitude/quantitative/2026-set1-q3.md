# 2026 CS1 Q3: Games in a knock-out tournament

## Question

Consider a knock-out women's badminton singles tournament where there are no ties. The loser in each game is eliminated from the tournament. Every player plays until she is defeated or remains the last undefeated player. The last undefeated player is declared the winner of the tournament. If there are 64 players in the beginning of the tournament, how many games should be played in total to declare the winner of the tournament?

- (A) 127
- (B) 64
- (C) 63
- (D) 32

<details class="success" markdown="1">
<summary>Answer</summary>

**63**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Shortcut: count eliminations.** Each game eliminates exactly one player. To end up with one winner, 63 of the 64 players must be eliminated. So 63 games.

**Check by rounds:** $32 + 16 + 8 + 4 + 2 + 1 = 63$ games.

**Why the others fail:** 127 counts both players of each game. 64 is the number of players, not games. 32 is only the first round.

**Key idea:** in a knock-out tournament, games = players − 1.

</details>
