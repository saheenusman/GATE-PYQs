# 2025 CS2 Q8: Reading two recurrences from a table

## Question

Which one of the following options is correct for the given data in the table?

| Iteration $(i)$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Input $(I)$ | 20 | $-4$ | 10 | 15 |
| Output $(X)$ | 20 | 16 | 26 | 41 |
| Output $(Y)$ | 20 | $-80$ | $-800$ | $-12000$ |

- (A) $X(i) = X(i-1) + I(i)$;  $Y(i) = Y(i-1)\,I(i)$;  $i>0$
- (B) $X(i) = X(i-1)\,I(i)$;  $Y(i) = Y(i-1) + I(i)$;  $i>0$
- (C) $X(i) = X(i-1)\,I(i)$;  $Y(i) = Y(i-1)\,I(i)$;  $i>0$
- (D) $X(i) = X(i-1) + I(i)$;  $Y(i) = Y(i-1)\,I(i-1)$;  $i>0$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Test the pattern on each step.

**Column X** (a running sum):

$20 + (-4) = 16$, $16 + 10 = 26$, $26 + 15 = 41$.

**Column Y** (a running product):

$20 \times (-4) = -80$, $-80 \times 10 = -800$, $-800 \times 15 = -12000$.

So $X(i) = X(i-1) + I(i)$ and $Y(i) = Y(i-1)\,I(i)$, which is option A.

| Option | Why wrong |
|---|---|
| B, C | X is not a product: $20 \times (-4) = -80 \neq 16$ |
| D | Uses $I(i-1)$ for Y: $Y(1) = 20 \times 20 = 400 \neq -80$ |

**Key idea:** try each rule on the first step. One failed step eliminates an option.

</details>
