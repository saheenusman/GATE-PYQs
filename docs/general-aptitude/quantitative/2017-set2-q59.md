# 2017 CS2 Q59: Number of multiple choice questions in a 20-question, 100-mark test

## Question

A test has twenty questions worth 100 marks in total. There are two types of questions. Multiple choice questions are worth 3 marks each and essay questions are worth 11 marks each. How many multiple choice questions does the exam have?

- (A) 12
- (B) 15
- (C) 18
- (D) 19

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Let $m$ be the number of multiple choice questions;** then there are $20 - m$ essay questions.

$$3m + 11(20 - m) = 100 \;\Rightarrow\; 220 - 8m = 100 \;\Rightarrow\; m = 15.$$

Check: $15\cdot 3 + 5\cdot 11 = 45 + 55 = 100$.

So there are 15 multiple choice questions: **(B)**.

**Why the others fail.** For $m = 12$ the total is $36 + 88 = 124$; for $m = 18$ it is $54 + 22 = 76$; for $m = 19$ it is $57 + 11 = 68$.

**Code check:** a loop over $m = 0..20$ found $m = 15$ as the only solution.

**Key idea:** two unknowns with one count and one total, so substitute the essay count as $20 - m$.

</details>
