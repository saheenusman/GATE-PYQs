# 2017 CS2 Q60: Probability that two chosen socks are of the same colour

## Question

There are 3 red socks, 4 green socks and 3 blue socks. You choose 2 socks. The probability that they are of the same colour is

- (A) $\dfrac15$
- (B) $\dfrac{7}{30}$
- (C) $\dfrac14$
- (D) $\dfrac{4}{15}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count the pairs.** There are 10 socks, so $\binom{10}{2} = 45$ equally likely pairs.

**Same-colour pairs:**

| Colour | Socks | Pairs |
|---|---|---|
| red | 3 | $\binom32 = 3$ |
| green | 4 | $\binom42 = 6$ |
| blue | 3 | $\binom32 = 3$ |

Total $= 3 + 6 + 3 = 12$.

$$P = \frac{12}{45} = \frac{4}{15}.$$

This is **(D)**.

**Why the others fail.** (A) $\tfrac15 = 9/45$ misses the green pairs. (B) $\tfrac{7}{30}$ and (C) $\tfrac14$ do not come from counting pairs.

**Code check:** exact fractions in Python gave $12/45 = 4/15$.

**Key idea:** $\sum_c \binom{n_c}{2} \big/ \binom{N}{2}$ for "same colour" pairs.

</details>
