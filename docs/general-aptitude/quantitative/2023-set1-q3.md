# 2023 CS Q3: Fibonacci-like series, find F1

## Question

A series of natural numbers $F_1, F_2, F_3, F_4, F_5, F_6, F_7, \ldots$ obeys $F_{n+1} = F_n + F_{n-1}$ for all integers $n \ge 2$.

If $F_6 = 37$ and $F_7 = 60$, then what is $F_1$?

- (A) 4
- (B) 5
- (C) 8
- (D) 9

<details class="success" markdown="1">
<summary>Answer</summary>

**A (4)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Work backwards** using $F_{n-1} = F_{n+1} - F_n$:

| Term | Value |
|---|---|
| $F_7$ | 60 |
| $F_6$ | 37 |
| $F_5 = 60 - 37$ | 23 |
| $F_4 = 37 - 23$ | 14 |
| $F_3 = 23 - 14$ | 9 |
| $F_2 = 14 - 9$ | 5 |
| $F_1 = 9 - 5$ | **4** |

**Check forward:** $4+5=9,\ 5+9=14,\ 9+14=23,\ 14+23=37,\ 23+37=60$. ✓

**Why the others fail:** 5 is $F_2$, 9 is $F_3$, 8 appears nowhere in the series.

**Key idea:** run a recurrence backwards by rearranging it.

</details>
