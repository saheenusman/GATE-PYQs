# 2024 CS2 Q4: x/y + y/x from a log equation

## Question

For positive non-zero real variables $x$ and $y$, if

$$\ln\left(\frac{x+y}{2}\right) = \frac{1}{2}\left[\ln(x) + \ln(y)\right],$$

then the value of $\dfrac{x}{y} + \dfrac{y}{x}$ is

- (A) 1
- (B) 1/2
- (C) 2
- (D) 4

<details class="success" markdown="1">
<summary>Answer</summary>

**C (2)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Simplify:** $\ln\frac{x+y}{2} = \ln\sqrt{xy}$, so $\dfrac{x+y}{2} = \sqrt{xy}$.

That is **AM = GM**, which holds only when $x = y$.

Then $\dfrac{x}{y} + \dfrac{y}{x} = 1 + 1 = 2$.

**Why the others fail:** with $x = y$ the sum is exactly 2, so 1, 1/2 and 4 are impossible.

**Key idea:** equality in AM-GM forces the two numbers to be equal.

</details>
