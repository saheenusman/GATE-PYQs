# 2014 CS1 Q60: Real roots of ax^2 + b|x| + c = 0

## Question

(GA Set-7, Q5) The roots of $ax^2 + bx + c = 0$ are real and positive. $a$, $b$ and $c$ are real. Then $ax^2 + b|x| + c = 0$ has

- (A) no roots
- (B) 2 real roots
- (C) 3 real roots
- (D) 4 real roots

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the positive roots be $r_1, r_2$.

For $x \ge 0$, $|x| = x$, so the equation is the original one and gives $x = r_1, r_2$.

For $x < 0$, put $x = -t$ with $t > 0$. Then $|x| = t$ and the equation becomes $at^2 + bt + c = 0$, so $t = r_1, r_2$ and $x = -r_1, -r_2$.

The function is even, so the roots come in pairs $\pm r_1, \pm r_2$: **4 real roots**.

- (A), (B), (C): the roots are non-zero and each positive root has a negative mirror, so the count is even and equals 4.

**Caveat:** if the two positive roots were equal, there would be only 2 distinct roots. The key goes with 4, taking the roots as distinct.

**Key idea:** $f(|x|)$ is an even function, so roots reflect about 0.

</details>
