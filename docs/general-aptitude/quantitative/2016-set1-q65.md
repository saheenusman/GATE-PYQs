# 2016 CS1 Q65: Load giving failure in 5000 cycles under exponential decay

## Question

(GA Set-5, Q10) In a process, the number of cycles to failure decreases exponentially with an increase in load. At a load of 80 units, it takes 100 cycles for failure. When the load is halved, it takes 10000 cycles for failure. The load for which the failure will happen in 5000 cycles is ________.

- (A) 40.00
- (B) 46.02
- (C) 60.01
- (D) 92.02

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Model: $N(L) = A\,e^{-kL}$.

**Find $k$ from the two data points** ($L = 80 \to N = 100$, $L = 40 \to N = 10000$):

$$\frac{N(40)}{N(80)} = e^{40k} = \frac{10000}{100} = 100 \;\Rightarrow\; k = \frac{\ln 100}{40} \approx 0.11513$$

**Solve for $N = 5000$** relative to the point $(80, 100)$:

$$\frac{N(L)}{N(80)} = e^{k(80 - L)} = 50 \;\Rightarrow\; 80 - L = \frac{\ln 50}{k} = \frac{3.912}{0.11513} \approx 33.98$$

$$L \approx 46.02$$

That is **(B)**.

**Code check:** the same calculation gave $L = 46.02$.

**Key idea:** $\ln N$ is linear in the load: $L = 80 - \ln 50 / (\ln 100 / 40) \approx 46.02$.

</details>
