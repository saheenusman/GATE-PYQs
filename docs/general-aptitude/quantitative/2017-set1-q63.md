# 2017 CS1 Q63: Meaning of ((x + y) - |x - y|) / 2

## Question

The expression $\dfrac{(x+y) - |x-y|}{2}$ is equal to

- (A) the maximum of $x$ and $y$
- (B) the minimum of $x$ and $y$
- (C) 1
- (D) none of the above

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split on the sign of $x - y$.**

- If $x \ge y$: $|x-y| = x-y$, so the expression is $\dfrac{(x+y)-(x-y)}{2} = \dfrac{2y}{2} = y$, which is $\min(x,y)$.
- If $x < y$: $|x-y| = y-x$, so it is $\dfrac{(x+y)-(y-x)}{2} = \dfrac{2x}{2} = x$, again $\min(x,y)$.

So the expression is the **minimum** of $x$ and $y$: **(B)**.

**Why the others fail.** Flipping the sign (adding $|x-y|$) gives the maximum, which is (A). It is not a constant, so (C) is wrong, and (D) is wrong because (B) holds.

**Code check:** over 10,000 random pairs, the expression matched $\min(x,y)$ to $10^{-12}$.

**Key idea:** $\min(x,y) = \dfrac{x+y-|x-y|}{2}$ and $\max(x,y) = \dfrac{x+y+|x-y|}{2}$.

</details>
