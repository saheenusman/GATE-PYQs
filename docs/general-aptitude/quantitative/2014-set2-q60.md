# 2014 CS2 Q60: Value of an infinite nested square root

## Question

(GA Set-8, Q5) The value of $\sqrt{12 + \sqrt{12 + \sqrt{12 + \cdots}}}$ is

- (A) 3.464
- (B) 3.932
- (C) 4.000
- (D) 4.444

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $x$ be the value. The expression repeats itself under the first root, so

$$x = \sqrt{12 + x} \Rightarrow x^2 - x - 12 = 0 \Rightarrow (x-4)(x+3) = 0$$

$x$ is positive, so $x = 4$.

- (A) 3.464 is $\sqrt{12}$, the first term only.
- (B) and (D) do not satisfy $x^2 = 12 + x$.

**Key idea:** self-similar radical: set $x = \sqrt{a + x}$ and take the positive root.

</details>
