# 2016 CS1 Q64: Factor of a degree-7 polynomial

## Question

(GA Set-5, Q9) If $f(x) = 2x^7 + 3x - 5$, which of the following is a factor of $f(x)$?

- (A) $(x^3 + 8)$
- (B) $(x - 1)$
- (C) $(2x - 5)$
- (D) $(x + 1)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

By the factor theorem, $(x - a)$ divides $f(x)$ exactly when $f(a) = 0$.

| Option | Test | Result |
|---|---|---|
| (A) $x^3 + 8$ | root $x = -2$: $f(-2) = -267$ | no |
| (B) $x - 1$ | $f(1) = 2 + 3 - 5 = 0$ | **yes** |
| (C) $2x - 5$ | root $x = 2.5$: $f(2.5) \approx 1223.2$ | no |
| (D) $x + 1$ | $f(-1) = -2 - 3 - 5 = -10$ | no |

For (A), $x^3 + 8 = (x + 2)(x^2 - 2x + 4)$, so it can divide $f$ only if $f(-2) = 0$, which fails.

**Code check:** evaluated the four values above.

**Key idea:** factor theorem: $f(1) = 0$, so $(x - 1)$ divides $f$.

</details>
