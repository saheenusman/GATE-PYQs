# 2015 CS2 Q5: Maximum of one minus the absolute value of x

## Question

Consider a function $f(x) = 1 - |x|$ on $-1 \le x \le 1$. The value of $x$ at which the function attains a maximum, and the maximum value of the function are:

- (A) $0, -1$
- (B) $-1, 0$
- (C) $0, 1$
- (D) $-1, 2$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$|x| \ge 0$, so $f(x) = 1 - |x| \le 1$, with equality only when $|x| = 0$.

The maximum is $1$, attained at $x = 0$. Option (C).

(A) has the right $x$ but the wrong value: $f(0) = 1$, not $-1$. (B) and (D) use $x = -1$, where $f(-1) = 0$, a minimum on this interval.

**Key idea:** subtracting $|x|$ is smallest effect at $x = 0$, giving the peak value $1$.

</details>
