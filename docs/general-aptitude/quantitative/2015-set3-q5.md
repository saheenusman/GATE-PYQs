# 2015 CS3 Q5: Value of a linear function from two points

## Question

A function $f(x)$ is linear and has a value of 29 at $x = -2$ and 39 at $x = 3$. Find its value at $x = 5$.

- (A) 59
- (B) 45
- (C) 43
- (D) 35

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Slope: $m = \dfrac{39 - 29}{3 - (-2)} = \dfrac{10}{5} = 2$.

From $x = 3$ to $x = 5$ is 2 steps, so $f(5) = 39 + 2 \times 2 = 43$. Option (C).

(A) 59, (B) 45 and (D) 35 correspond to slopes of 10, 3 and $-2$ over that 2-step gap, none of which is the slope here.

**Key idea:** a linear function changes by the same amount for every unit step.

</details>
