# 2017 CS2 Q46: Rows returned by a query using > ALL on an empty set and > ANY

## Question

Consider the following database table named *top_scorer*.

| player | country | goals |
|---|---|---|
| Klose | Germany | 16 |
| Ronaldo | Brazil | 15 |
| G Müller | Germany | 14 |
| Fontaine | France | 13 |
| Pelé | Brazil | 12 |
| Klinsmann | Germany | 11 |
| Kocsis | Hungary | 11 |
| Batistuta | Argentina | 10 |
| Cubillas | Peru | 10 |
| Lato | Poland | 10 |
| Lineker | England | 10 |
| T Müller | Germany | 10 |
| Rahn | Germany | 10 |

Consider the following SQL query:

```sql
SELECT ta.player FROM top_scorer AS ta
WHERE ta.goals > ALL (SELECT tb.goals
                      FROM top_scorer AS tb
                      WHERE tb.country = 'Spain')
AND ta.goals > ANY (SELECT tc.goals
                    FROM top_scorer AS tc
                    WHERE tc.country = 'Germany')
```

The number of tuples returned by the above SQL query is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**First condition: `ta.goals > ALL (...Spain...)`.** No row has country Spain, so the subquery returns an **empty set**. A comparison with `ALL` over an empty set is **true** (vacuously), so this condition holds for every row.

**Second condition: `ta.goals > ANY (...Germany...)`.** The German goals are $16, 14, 11, 10, 10$. `> ANY` means greater than **at least one** of them, i.e. greater than the minimum, 10. So we need $\text{goals} > 10$.

**Rows with goals $> 10$:** Klose (16), Ronaldo (15), G Müller (14), Fontaine (13), Pelé (12), Klinsmann (11), Kocsis (11): **7** rows.

(The five players with 10 goals fail, because 10 is not greater than 10.)

**Code check:** SQLite has no `ALL`/`ANY`, so the query was run in an equivalent form: `NOT EXISTS (Spain row with goals >= ta.goals)` for `> ALL`, and `EXISTS (German row with goals < ta.goals)` for `> ANY`. It returned the same 7 players. (The mapping: `x > ALL(S)` is `NOT EXISTS (s IN S with NOT x > s)`; `x > ANY(S)` is `EXISTS (s IN S with x > s)`.)

**Key idea:** `> ALL` over an empty set is true; `> ANY` over an empty set would be false.

</details>
