# 2008 CS Q68: Equivalent relational algebra queries on R and S

## Question

Let $R$ and $S$ be two relations with the following schema:

$R(\underline{P}, \underline{Q}, R1, R2, R3)$

$S(\underline{P}, \underline{Q}, S1, S2)$

where $\lbrace P, Q \rbrace$ is the key for both schemas. Which of the following queries are equivalent?

- I. $\Pi_P(R \bowtie S)$
- II. $\Pi_P(R) \bowtie \Pi_P(S)$
- III. $\Pi_P\big(\Pi_{P,Q}(R) \cap \Pi_{P,Q}(S)\big)$
- IV. $\Pi_P\big(\Pi_{P,Q}(R) - (\Pi_{P,Q}(R) - \Pi_{P,Q}(S))\big)$

Options:

- (A) Only I and II
- (B) Only I and III
- (C) Only I, II and III
- (D) Only I, III and IV

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$R \bowtie S$ is the natural join on the common attributes $P$ and $Q$, so it keeps exactly the pairs $(p, q)$ that occur in **both** $R$ and $S$; then $\Pi_P$ lists their $P$ values.

- **III:** $\Pi_{P,Q}(R) \cap \Pi_{P,Q}(S)$ is the set of $(p,q)$ pairs in both relations, then project $P$: same as I.
- **IV:** $A - (A - B) = A \cap B$, so this is III again: same as I.
- **II:** $\Pi_P(R) \bowtie \Pi_P(S)$ keeps a value $p$ that appears in $R$ and also appears in $S$, but **not necessarily with the same $Q$**. For example $R$ has $(1, x)$ and $S$ has $(1, y)$: then II returns $1$, while I returns nothing.

So I, III and IV are equivalent and II is not: (D).

**Code check:** I evaluated all four queries on 20000 random small instances of $R$ and $S$ (keys $(P,Q)$ with 3 values each). III and IV agreed with I every time; II differed from I in 10113 of the 20000 instances.

**Key idea:** projecting $P$ from the *pairs* common to both relations is not the same as intersecting the projected $P$ values.

</details>
