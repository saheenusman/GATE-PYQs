# 2017 CS1 Q23: Average of department head-counts using a GROUP BY subquery

## Question

Consider a database that has the relation schema EMP (EmpId, EmpName, and DeptName). An instance of the schema EMP and a SQL query on it are given below.

| EmpId | EmpName | DeptName |
|---|---|---|
| 1 | XYA | AA |
| 2 | XYB | AA |
| 3 | XYC | AA |
| 4 | XYD | AA |
| 5 | XYE | AB |
| 6 | XYF | AB |
| 7 | XYG | AB |
| 8 | XYH | AC |
| 9 | XYI | AC |
| 10 | XYJ | AC |
| 11 | XYK | AD |
| 12 | XYL | AD |
| 13 | XYM | AE |

```sql
SELECT AVG(EC.Num)
FROM EC
WHERE (DeptName, Num) IN
    (SELECT DeptName, COUNT(EmpId) AS EC(DeptName, Num)
     FROM EMP
     GROUP BY DeptName)
```

The output of executing the SQL query is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2.6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The inner query.** It groups EMP by department and counts employees. The `AS EC(DeptName, Num)` part names that result `EC`:

| DeptName | Num |
|---|---|
| AA | 4 |
| AB | 3 |
| AC | 3 |
| AD | 2 |
| AE | 1 |

**The outer query.** It keeps rows of `EC` whose `(DeptName, Num)` pair is in the inner result. Every row of `EC` is in that result by construction, so all five rows stay. Then it averages `Num`:

$$\frac{4+3+3+2+1}{5} = \frac{13}{5} = 2.6$$

The answer is **2.6**.

**Code check:** in SQLite I rewrote the intended query with a common table expression, `WITH EC(DeptName, Num) AS (SELECT DeptName, COUNT(EmpId) FROM EMP GROUP BY DeptName) SELECT AVG(Num) FROM EC`, and it returned `2.6`.

**Note on the SQL.** As printed it is not valid standard SQL, because `EC` is defined inside the subquery but used in the outer `FROM`. The question's intent is the average of the per-department counts, which is what I computed.

**Key idea:** `GROUP BY` collapses each department to one row; the average is over departments, not over employees ($13/5$, not $13/13$).

</details>
