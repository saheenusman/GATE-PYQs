# 2019 CS2 Q61: Rows returned by a query with a missing join condition

## Question

A relational database contains two tables Student and Performance as shown below:

**Student**

| Roll_no. | Student_name |
|---|---|
| 1 | Amit |
| 2 | Priya |
| 3 | Vinit |
| 4 | Rohan |
| 5 | Smita |

**Performance**

| Roll_no. | Subject_code | Marks |
|---|---|---|
| 1 | A | 86 |
| 1 | B | 95 |
| 1 | C | 90 |
| 2 | A | 89 |
| 2 | C | 92 |
| 3 | C | 80 |

The primary key of the Student table is `Roll_no`. For the Performance table, the columns `Roll_no` and `Subject_code` together form the primary key. Consider the SQL query given below:

```sql
SELECT S.Student_name, sum(P.Marks)
FROM Student S, Performance P
WHERE P.Marks > 84
GROUP BY S.Student_name;
```

The number of rows returned by the above SQL query is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

There is **no join condition** between `S` and `P` in the `WHERE` clause. `FROM Student S, Performance P` is a **Cartesian product**: every student pairs with every performance row.

1. **Filter:** `P.Marks > 84` keeps the Performance rows with marks 86, 95, 90, 89, 92 (5 rows). The row with 80 is dropped.
2. **Product:** each of the 5 students pairs with these 5 rows: 25 rows.
3. **Group:** `GROUP BY S.Student_name` makes one group per student. All 5 students appear (even Vinit, Rohan and Smita, who have no marks above 84 of their own).

**5 rows**, each with the same sum $86+95+90+89+92 = 452$.

**Code check:** running the query in SQLite returns 5 rows, every one with the sum 452.

**Key idea:** a missing join predicate means a cross product, so every student appears in the result.

</details>
