# 2015 CS2 Q40: Tuples in the natural full outer join of two relations

## Question

Consider two relations $R_1(A,B)$ with the tuples $(1,5), (3,7)$ and $R_2(A,C) = (1,7), (4,9)$. Assume that $R(A,B,C)$ is the full natural outer join of $R_1$ and $R_2$. Consider the following tuples of the form $(A,B,C)$: $a = (1,5,\text{null})$, $b = (1,\text{null},7)$, $c = (3,\text{null},9)$, $d = (4,7,\text{null})$, $e = (1,5,7)$, $f = (3,7,\text{null})$, $g = (4,\text{null},9)$. Which one of the following statements is correct?

- (A) $R$ contains $a, b, e, f, g$ but not $c, d$.
- (B) $R$ contains all of $a, b, c, d, e, f, g$.
- (C) $R$ contains $e, f, g$ but not $a, b$.
- (D) $R$ contains $e$ but not $f, g$.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A natural full outer join matches rows on the shared column $A$, and keeps unmatched rows from **both** sides padded with null.

- $A = 1$: present in $R_1$ as $(1,5)$ and in $R_2$ as $(1,7)$. Matched, giving $(1,5,7) = e$.
- $A = 3$: only in $R_1$, as $(3,7)$. Padded: $(3,7,\text{null}) = f$.
- $A = 4$: only in $R_2$, as $(4,9)$. Padded: $(4,\text{null},9) = g$.

So $R = \lbrace e, f, g \rbrace$. The tuples $a$, $b$ (match 1 but with a null instead of the matched value), $c$ and $d$ (wrong pairings of 3 and 4) are not in $R$.

Option (C). (A) and (B) include $a$ or $b$, which would appear only in a join that fails to match key 1. (D) leaves out the unmatched rows, which is what a full outer join preserves.

**Key idea:** full outer join $=$ matched rows plus unmatched rows from both sides, null-padded.

</details>
