# 2015 CS1 Q61: Rows returned by a join with GROUP BY on a non-key column

## Question

Consider the following relations:

**Student**

| Roll_No | Student_Name |
|---|---|
| 1 | Raj |
| 2 | Rohit |
| 3 | Raj |

**Performance**

| Roll_No | Course | Marks |
|---|---|---|
| 1 | Math | 80 |
| 1 | English | 70 |
| 2 | Math | 75 |
| 3 | English | 80 |
| 2 | Physics | 65 |
| 3 | Math | 80 |

Consider the following SQL query.

```sql
SELECT S.Student_Name, sum(P.Marks)
FROM Student S, Performance P
WHERE S.Roll_No = P.Roll_No
GROUP BY S.Student_Name
```

The number of rows that will be returned by the SQL query is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The `WHERE` clause joins the tables on `Roll_No`, then `GROUP BY` forms one group per distinct **name**.

| Name | Roll_Nos | Rows joined | sum(Marks) |
|---|---|---|---|
| Raj | 1 and 3 | $80 + 70 + 80 + 80$ | 310 |
| Rohit | 2 | $75 + 65$ | 140 |

Two distinct names, so **2** rows. Roll 1 and roll 3 both belong to "Raj", so they fall into the *same* group even though they are different students.

**Key idea:** `GROUP BY` groups by the listed column's values (names), not by the primary key.

</details>
