# 2014 CS2 Q54: SQL query equivalent to an IN subquery with duplicates

## Question

SQL allows duplicate tuples in relations, and correspondingly defines the multiplicity of tuples in the result of joins. Which one of the following queries always gives the same answer as the nested query shown below:

```sql
select * from R where a in (select S.a from S)
```

- (A) `select R.* from R, S where R.a=S.a`
- (B) `select distinct R.* from R,S where R.a=S.a`
- (C) `select R.* from R,(select distinct a from S) as S1 where R.a=S1.a`
- (D) `select R.* from R,S where R.a=S.a and is unique R`

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The nested `IN` query returns each tuple of $R$ **once per copy in $R$**, whatever the number of matching tuples in $S$.

- (A) returns each $R$ tuple once **per matching $S$ tuple**: if $S$ has two rows with the same `a`, the $R$ tuple is repeated.
- (B) `distinct` also collapses genuine duplicates in $R$ itself, which the nested query keeps.
- (C) **correct.** The subquery `select distinct a from S` makes the `a` values unique, so each $R$ tuple matches at most one row, and the copies in $R$ are kept.
- (D) `is unique R` is not valid SQL as written.

**Code check:** in SQLite with $R = \lbrace (1,x),(1,x),(2,y),(3,z) \rbrace$ and $S$ having `a` values $1, 1, 2$:

| Query | Result |
|---|---|
| nested | $(1,x)\times 2,\ (2,y)$ |
| A | $(1,x)\times 4,\ (2,y)$ (different) |
| B | $(1,x),\ (2,y)$ (different) |
| C | $(1,x)\times 2,\ (2,y)$ (same) |

(D) is a syntax error, so it was not run.

**Key idea:** `IN` is a semi-join: deduplicate the inner side, not the outer side.

</details>
