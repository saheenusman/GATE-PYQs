# 2016 CS2 Q52: Number of tuples returned by an aggregate SQL query with a derived average

## Question

Consider the following database table named `water_schemes`:

| scheme_no | district_name | capacity |
|---|---|---|
| 1 | Ajmer | 20 |
| 1 | Bikaner | 10 |
| 2 | Bikaner | 10 |
| 3 | Bikaner | 20 |
| 1 | Churu | 10 |
| 2 | Churu | 20 |
| 1 | Dungargarh | 10 |

The number of tuples returned by the following SQL query is ______.

```sql
with total(name, capacity) as
    select district_name, sum(capacity)
    from water_schemes
    group by district_name
with total_avg(capacity) as
    select avg(capacity)
    from total
select name
    from total, total_avg
    where total.capacity >= total_avg.capacity
```

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1: `total`** (capacity summed per district):

| name | capacity |
|---|---|
| Ajmer | 20 |
| Bikaner | 40 |
| Churu | 30 |
| Dungargarh | 10 |

**Step 2: `total_avg`** is the average of these four totals: $(20 + 40 + 30 + 10)/4 = 25$. (Note it averages the *district totals*, not the seven rows.)

**Step 3:** keep districts with total $\ge 25$: Bikaner ($40$) and Churu ($30$). That is **2** tuples.

**Code check:** the printed query is not valid SQL as written (it needs commas and parentheses around the two CTEs). Rewritten as one valid `WITH total(...) AS (...), total_avg(...) AS (...)` query and run in SQLite, it returned Bikaner and Churu.

**Key idea:** district totals are 20, 40, 30, 10 (average 25), so Bikaner and Churu qualify.

</details>
