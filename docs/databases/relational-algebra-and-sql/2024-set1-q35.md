# 2024 CS1 Q35: Tuples in a selection over a join

## Question

Consider the following two relations, R(A,B) and S(A,C):

| R.A | R.B |
|---|---|
| 10 | 20 |
| 20 | 30 |
| 30 | 40 |
| 30 | 50 |
| 50 | 95 |

| S.A | S.C |
|---|---|
| 10 | 90 |
| 30 | 45 |
| 40 | 80 |

The total number of tuples obtained by evaluating the following expression is ________

$$\sigma_{B<C}\left(R \bowtie_{R.A = S.A} S\right)$$

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1: the join** on $R.A = S.A$.

| R tuple | Matches in S | Joined $(A, B, C)$ |
|---|---|---|
| (10, 20) | (10, 90) | (10, 20, 90) |
| (20, 30) | none (S has no A = 20) | |
| (30, 40) | (30, 45) | (30, 40, 45) |
| (30, 50) | (30, 45) | (30, 50, 45) |
| (50, 95) | none | |

The join has 3 tuples.

**Step 2: select $B < C$.**

- (10, 20, 90): $20 < 90$ ✓
- (30, 40, 45): $40 < 45$ ✓
- (30, 50, 45): $50 < 45$ ✗

**2 tuples.**

**Key idea:** do the join first (keep only matching $A$ values), then filter.

</details>
