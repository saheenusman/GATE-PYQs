# 2017 CS1 Q46: Rows in the relational division of CR by the courses taken by SA

## Question

Consider a database that has the relation schema CR(StudentName, CourseName). An instance of the schema CR is as given below.

| StudentName | CourseName |
|---|---|
| SA | CA |
| SA | CB |
| SA | CC |
| SB | CB |
| SB | CC |
| SC | CA |
| SC | CB |
| SC | CC |
| SD | CA |
| SD | CB |
| SD | CC |
| SD | CD |
| SE | CD |
| SE | CA |
| SE | CB |
| SF | CA |
| SF | CB |
| SF | CC |

The following query is made on the database.

$$T1 \leftarrow \pi_{\text{CourseName}}\big(\sigma_{\text{StudentName}=\text{'SA'}}(CR)\big)$$
$$T2 \leftarrow CR \div T1$$

The number of rows in $T2$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$T1$.** The courses taken by SA: $T1 = \lbrace CA, CB, CC\rbrace$.

**$T2 = CR \div T1$.** Division returns the students who are paired with **every** course in $T1$.

| Student | Courses | Has CA, CB and CC? |
|---|---|---|
| SA | CA, CB, CC | Yes |
| SB | CB, CC | No (no CA) |
| SC | CA, CB, CC | Yes |
| SD | CA, CB, CC, CD | Yes (CD is extra, which is allowed) |
| SE | CD, CA, CB | No (no CC) |
| SF | CA, CB, CC | Yes |

$T2 = \lbrace SA, SC, SD, SF\rbrace$, so it has **4** rows.

**Code check:** a "no course of $T1$ is missing" query in SQLite on the 18 rows returned `SA, SC, SD, SF`.

**Key idea:** $R \div S$ keeps the values that are related to *all* tuples of $S$; extra related tuples do not matter.

</details>
