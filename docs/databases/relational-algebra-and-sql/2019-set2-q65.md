# 2019 CS2 Q65: Tuples returned by a relational algebra query with a set difference

## Question

Consider the following relations $P(X, Y, Z)$, $Q(X, Y, T)$ and $R(Y, V)$.

**P**

| X | Y | Z |
|---|---|---|
| X1 | Y1 | Z1 |
| X1 | Y1 | Z2 |
| X2 | Y2 | Z2 |
| X2 | Y4 | Z4 |

**Q**

| X | Y | T |
|---|---|---|
| X2 | Y1 | 2 |
| X1 | Y2 | 5 |
| X1 | Y1 | 6 |
| X3 | Y3 | 1 |

**R**

| Y | V |
|---|---|
| Y1 | V1 |
| Y3 | V2 |
| Y2 | V3 |
| Y2 | V2 |

How many tuples will be returned by the following relational algebra query?

$$\pi_X\big(\sigma_{(P.Y = R.Y \,\wedge\, R.V = V2)}(P \times R)\big) - \pi_X\big(\sigma_{(Q.Y = R.Y \,\wedge\, Q.T > 2)}(Q \times R)\big)$$

Answer: ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**First part.** Join $P$ with the $R$ rows that have $V = V2$: $(Y3, V2)$ and $(Y2, V2)$.

- $P$ rows with $Y = Y3$: none.
- $P$ rows with $Y = Y2$: $(X2, Y2, Z2)$.

So $\pi_X = \lbrace X2 \rbrace$.

**Second part.** Keep $Q$ rows with $T > 2$: $(X1, Y2, 5)$ and $(X1, Y1, 6)$. Join with $R$ on $Y$:

- $Y2$ matches $(Y2, V3)$ and $(Y2, V2)$
- $Y1$ matches $(Y1, V1)$

So $\pi_X = \lbrace X1 \rbrace$ (duplicates vanish, because relational algebra works on sets).

**Difference:** $\lbrace X2 \rbrace - \lbrace X1 \rbrace = \lbrace X2 \rbrace$, which is **1 tuple**.

**Code check:** the two projections computed with Python sets are $\lbrace X2\rbrace$ and $\lbrace X1\rbrace$. The difference has size 1.

**Key idea:** project each side to $X$ first (sets remove duplicates), then subtract.

</details>
