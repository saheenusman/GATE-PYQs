# 2015 CS1 Q31: What SQL SELECT corresponds to in relational algebra

## Question

SELECT operation in SQL is equivalent to

- (A) the selection operation in relational algebra
- (B) the selection operation in relational algebra, except that SELECT in SQL retains duplicates
- (C) the projection operation in relational algebra
- (D) the projection operation in relational algebra, except that SELECT in SQL retains duplicates

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The `SELECT` clause lists the **columns** to return, which is relational-algebra **projection** ($\pi$). The row filter is the `WHERE` clause, which corresponds to relational-algebra selection ($\sigma$).

Relational algebra works on sets, so projection removes duplicates. SQL works on bags, so `SELECT` keeps duplicates unless `DISTINCT` is used.

Option (D). (A) and (B) confuse the name `SELECT` with the algebra operator $\sigma$. (C) ignores the duplicate difference.

**Key idea:** SQL `SELECT` $=$ projection $\pi$ that keeps duplicates; algebra selection $\sigma$ is the `WHERE` clause.

</details>
