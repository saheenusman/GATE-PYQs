# 2011 CS Q32: Value of Y for X = 7 after 128 doubling inserts

## Question

Consider a database table T containing two columns X and Y each of type `integer`. After the creation of the table, one record (X=1, Y=1) is inserted in the table.

Let MX and MY denote the respective maximum values of X and Y among all records in the table at any point in time. Using MX and MY, new records are inserted in the table 128 times with X and Y values being MX+1, 2\*MY+1 respectively. It may be noted that each time after the insertion, values of MX and MY change.

What will be the output of the following SQL query after the steps mentioned above are carried out?

`SELECT Y FROM T WHERE X=7;`

- (A) 127
- (B) 255
- (C) 129
- (D) 257

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $(X_k, Y_k)$ be the row after $k$ inserts, with $(X_0, Y_0) = (1, 1)$. Each insert adds $1$ to the current maximum $X$ and sets $Y = 2 \cdot \text{MY} + 1$. The newest row always holds the maximum of both columns, so

$$X_k = k + 1, \qquad Y_k = 2 Y_{k-1} + 1.$$

| $X$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| $Y$ | 1 | 3 | 7 | 15 | 31 | 63 | 127 |

In general $Y = 2^X - 1$. So the one row with $X = 7$ has $Y = 127$: (A).

- (B) $255 = 2^8 - 1$ is the value for $X = 8$.
- (C) $129 = 2^7 + 1$ and (D) $257 = 2^8 + 1$ do not follow the rule $Y = 2\,\text{MY} + 1$ from $Y_0 = 1$.

**Assumption.** The question treats `integer` as unbounded. After $128$ inserts $Y$ would be $2^{129} - 1$, which does not fit in any fixed-width integer. SQLite (64-bit) raises an error at $X = 64$, but only the row $X = 7$ matters here.

**Code check:** an SQLite run of the inserts gave $Y = 127$ for $X = 7$ (it overflowed after $62$ inserts, long after $X = 7$). A big-integer model of all $128$ inserts gave the same row and $Y_{128} = 2^{129} - 1$.

**Key idea:** each insert doubles-and-adds-one to Y, so the row with X = k has Y = 2^k - 1.

</details>
