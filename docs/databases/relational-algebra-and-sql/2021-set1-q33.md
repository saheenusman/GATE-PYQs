# 2021 CS1 Q33: Estimated size of a selection with OR

## Question

A relation $r(A,B)$ in a relational database has 1200 tuples. The attribute $A$ has integer values ranging from 6 to 20, and the attribute $B$ has integer values ranging from 1 to 20. Assume that the attributes $A$ and $B$ are independently distributed.

The estimated number of tuples in the output of $\sigma_{(A>10)\vee(B=18)}(r)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**820**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Assume each attribute is uniformly distributed over its range.

- $A$ takes 15 values (6 to 20). $A>10$ means 11 to 20, so $P(A>10)=\dfrac{10}{15}=\dfrac23$.
- $B$ takes 20 values. $P(B=18)=\dfrac1{20}$.
- Independence gives $P(A>10 \wedge B=18)=\dfrac23\cdot\dfrac1{20}=\dfrac1{30}$.

$P(A>10\ \vee\ B=18)=\dfrac23+\dfrac1{20}-\dfrac1{30}=\dfrac{41}{60}$

Estimated tuples $=1200\times\dfrac{41}{60}=\mathbf{820}$.

The key accepts **819 to 820** (for rounding) **or 205**. Enumerating the $15\times20=300$ value pairs, exactly 205 satisfy the condition, and $1200\times205/300=820$. So 205 looks like the count of qualifying value pairs, not tuples. The key does not say why it accepts 205, so that explanation is my guess. I report 820 as the main answer.

**Key idea:** selection size $=$ tuples $\times$ selectivity. For OR, use $P(X)+P(Y)-P(X\wedge Y)$.

</details>
