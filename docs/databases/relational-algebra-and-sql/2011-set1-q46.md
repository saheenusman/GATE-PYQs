# 2011 CS Q46: Row count of a natural join of two projections

## Question

Database table by name `Loan_Records` is given below.

| Borrower | Bank_Manager | Loan_Amount |
|---|---|---|
| Ramesh | Sunderajan | 10000.00 |
| Suresh | Ramgopal | 5000.00 |
| Mahesh | Sunderajan | 7000.00 |

What is the output of the following SQL query?

```sql
SELECT count(*)
FROM (
   (SELECT Borrower, Bank_Manager FROM Loan_Records) AS S
   NATURAL JOIN
   (SELECT Bank_Manager, Loan_Amount FROM Loan_Records) AS T
);
```

- (A) 3
- (B) 9
- (C) 5
- (D) 6

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The natural join of $S(\text{Borrower}, \text{Bank\_Manager})$ and $T(\text{Bank\_Manager}, \text{Loan\_Amount})$ matches rows on the common column $\text{Bank\_Manager}$.

| Bank_Manager | Rows in $S$ | Rows in $T$ | Joined rows |
|---|---|---|---|
| Sunderajan | $2$ (Ramesh, Mahesh) | $2$ ($10000$, $7000$) | $2 \times 2 = 4$ |
| Ramgopal | $1$ (Suresh) | $1$ ($5000$) | $1 \times 1 = 1$ |

Total $= 4 + 1 = 5$. So (C).

- (A) $3$ is the number of rows of the table itself; the join also pairs the two Sunderajan rows with each other.
- (B) $9$ is the size of the full cross product ($3 \times 3$), which ignores the join condition.
- (D) $6$: the join has only $5$ rows.

**Code check:** run in SQLite (the join wrapped in an extra `SELECT *` for that dialect): the join returned $5$ rows and `count(*)` was $5$. Only SQLite was used; other engines were not checked.

**Key idea:** a natural join on a repeated key multiplies the matching rows from each side (2 x 2 + 1 x 1).

</details>
