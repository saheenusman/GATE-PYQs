# 2010 CS Q19: Passengers with an AC reservation and age over 65 using EXISTS

## Question

A relational schema for a train reservation database is given below.

Passenger(pid, pname, age)
Reservation(pid, class, tid)

*Printed as is: the paper writes the second column of Reservation as `cass`; the query uses `class`, so I read it as `class`.*

**Table: Passenger**

| pid | pname | age |
|---|---|---|
| 0 | 'Sachin' | 65 |
| 1 | 'Rahul' | 66 |
| 2 | 'Sourav' | 67 |
| 3 | 'Anil' | 69 |

**Table: Reservation**

| pid | class | tid |
|---|---|---|
| 0 | 'AC' | 8200 |
| 1 | 'AC' | 8201 |
| 2 | 'SC' | 8201 |
| 5 | 'AC' | 8203 |
| 1 | 'SC' | 8204 |
| 3 | 'AC' | 8202 |

What pids are returned by the following SQL query for the above instance of the tables?

```sql
SELECT pid
FROM Reservation
WHERE class = 'AC' AND
  EXISTS (SELECT *
          FROM Passenger
          WHERE age > 65 AND
          Passenger.pid = Reservation.pid)
```

- (A) 1, 0
- (B) 1, 2
- (C) 1, 3
- (D) 1, 5

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For each Reservation row with class AC, `EXISTS` is true if some Passenger with the same pid has age over $65$.

| Reservation row | AC? | Passenger with same pid | age $> 65$? | Output |
|---|---|---|---|---|
| (0, AC, 8200) | yes | Sachin, 65 | no ($65$ is not $> 65$) | no |
| (1, AC, 8201) | yes | Rahul, 66 | yes | **1** |
| (2, SC, 8201) | no | | | no |
| (5, AC, 8203) | yes | none | no | no |
| (1, SC, 8204) | no | | | no |
| (3, AC, 8202) | yes | Anil, 69 | yes | **3** |

Result: pids $1$ and $3$: (C).

- (A) includes pid $0$, whose age is exactly $65$, not above it.
- (B) includes pid $2$, but that reservation is SC, not AC.
- (D) includes pid $5$, who has no row in Passenger.

**Code check:** the two tables and the query were loaded into SQLite and run; the result was `[(1,), (3,)]`.

**Key idea:** a correlated `EXISTS` is evaluated per outer row; strict `>` excludes age $65$.

</details>
