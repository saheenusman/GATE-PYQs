# 2012 CS Q51: SQL ALL over an empty subquery

## Question

**Common data for Questions 50 and 51** (relations A, B and C as in Q50).

How many tuples does the result of the following SQL query contain?

```sql
SELECT A.Id
FROM A
WHERE A.Age > ALL (SELECT B.Age
                   FROM B
                   WHERE B.Name = 'Arun')
```

- (A) 4
- (B) 3
- (C) 0
- (D) 1

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The subquery looks for rows of $B$ with `Name = 'Arun'`. Arun appears only in $A$, not in $B$ (whose names are Shreya, Hari, Rohit, Rohit). So the subquery returns an **empty set**.

`x > ALL (empty set)` is **true**, because there is no value in the set that $x$ fails to exceed. So every row of $A$ qualifies, and the query returns all $3$ Ids ($12, 15, 99$): (B).

- (C) $0$ would be the result of `> ANY` over an empty set, which is false.
- (A) $4$ is the size of $B$; the query never lists $B$.
- (D) $1$ would need a real maximum to compare against.

**Code check:** SQLite has no `ALL`, so I ran the equivalent `NOT EXISTS (... B.Name='Arun' AND NOT (A.Age > B.Age))`. It returned Ids $12, 15, 99$.

**Key idea:** `ALL` over an empty set is vacuously true; `ANY` over an empty set is false.

</details>
