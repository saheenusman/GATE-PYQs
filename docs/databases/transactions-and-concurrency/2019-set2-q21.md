# 2019 CS2 Q21: True statements about strict 2PL and Thomas' write rule

## Question

Consider the following two statements about database transaction schedules:

- I. Strict two-phase locking protocol generates conflict serializable schedules that are also recoverable.
- II. Timestamp-ordering concurrency control protocol with Thomas' Write Rule can generate view serializable schedules that are not conflict serializable.

Which of the above statements is/are TRUE?

- (A) I only
- (B) II only
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I is true.** Two-phase locking always gives conflict serializable schedules. Strict 2PL also holds exclusive locks until commit or abort, so no transaction reads uncommitted data. The schedules are therefore recoverable (indeed cascadeless).

**II is true.** Thomas' write rule *ignores* an obsolete write instead of aborting. Example with $TS(T_1) < TS(T_2)$:

$$r_1(Q)\;\; w_2(Q)\;\; w_1(Q)$$

$w_1(Q)$ arrives after $T_2$ has written $Q$. It is obsolete and is skipped. As submitted, the schedule has the conflicts $r_1(Q) \to w_2(Q)$ ($T_1 \to T_2$) and $w_2(Q) \to w_1(Q)$ ($T_2 \to T_1$), a cycle, so it is **not conflict serializable**. Because the late write has no effect, the outcome equals the serial order $T_1, T_2$, so it is **view serializable**.

**Why the others fail:** (A), (B) and (D) each deny at least one true statement.

**Key idea:** Thomas' write rule trades strict conflict order for extra view-serializable schedules.

</details>
