# 2024 CS2 Q27: Statements about Two-Phase Locking

## Question

Which of the following statements about the Two Phase Locking (2PL) protocol is/are TRUE?

- (A) 2PL permits only serializable schedules
- (B) With 2PL, a transaction always locks the data item being read or written just before every operation and always releases the lock just after the operation
- (C) With 2PL, once a lock is released on any data item inside a transaction, no more locks on any data item can be obtained inside that transaction
- (D) A deadlock is possible with 2PL

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

2PL has a **growing phase** (locks only acquired) and a **shrinking phase** (locks only released). After the first unlock, no new lock is allowed.

- **(A) True.** Any schedule produced by 2PL is conflict serializable.
- **(B) False.** Locking before and releasing right after each operation *violates* the two-phase rule: the transaction would release a lock and then acquire another one later.
- **(C) True.** That is the definition of the two-phase rule.
- **(D) True.** 2PL does not prevent deadlock: two transactions can each hold a lock the other needs.

**Key idea:** 2PL guarantees serializability but not freedom from deadlock.

</details>
