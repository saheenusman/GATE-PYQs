# 2021 CS2 Q42: Conflict serializability and recoverability of a schedule

## Question

Let S be the following schedule of operations of three transactions $T_1$, $T_2$ and $T_3$ in a relational database system:

$R_2(Y),\ R_1(X),\ R_3(Z),\ R_1(Y),\ W_1(X),\ R_2(Z),\ W_2(Y),\ R_3(X),\ W_3(Z)$

Consider the statements P and Q below:

P: S is conflict-serializable.

Q: If $T_3$ commits before $T_1$ finishes, then S is recoverable.

Which one of the following choices is correct?

- (A) Both P and Q are true.
- (B) P is true and Q is false.
- (C) P is false and Q is true.
- (D) Both P and Q are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**P: conflict-serializability.** List the conflicting pairs (different transactions, same item, at least one write), earlier operation first:

| pair | edge |
|---|---|
| $R_1(Y)$ before $W_2(Y)$ | $T_1\to T_2$ |
| $W_1(X)$ before $R_3(X)$ | $T_1\to T_3$ |
| $R_2(Z)$ before $W_3(Z)$ | $T_2\to T_3$ |

The precedence graph has edges $T_1\to T_2$, $T_1\to T_3$, $T_2\to T_3$ and no cycle (I checked this with a short script). So S is conflict-serializable, equivalent to $T_1,T_2,T_3$. P is **true**.

**Q: recoverability.** $T_3$ executes $R_3(X)$ after $W_1(X)$, so $T_3$ **reads from** $T_1$ (the script shows this is the only reads-from pair).

A schedule is recoverable only if a transaction commits after every transaction it read from. If $T_3$ commits **before** $T_1$ finishes, then $T_3$ commits first even though it read from $T_1$. If $T_1$ then aborts, $T_3$ has already committed on data that is rolled back. So S is **not** recoverable. Q is **false**.

P true and Q false, so (B).

**Key idea:** acyclic precedence graph means conflict-serializable; recoverable means a reader commits only after the writer it read from.

</details>
