# 2015 CS2 Q31: Which ACID property keeps the sum of two accounts constant

## Question

Consider the following transaction involving two bank accounts $x$ and $y$.

```
read(x); x := x - 50; write(x); read(y); y := y + 50; write(y)
```

The constraint that the sum of the accounts $x$ and $y$ should remain constant is that of

- (A) Atomicity
- (B) Consistency
- (C) Isolation
- (D) Durability

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The rule "$x + y$ stays the same" is an integrity constraint on the data. Preserving such constraints across a transaction is **consistency**.

- (A) *Atomicity* means all or none of the writes happen. It helps, but it is not the constraint itself.
- (C) *Isolation* is about concurrent transactions not interfering.
- (D) *Durability* is about committed data surviving failures.

Option (B).

**Key idea:** consistency means a transaction takes the database from one valid state to another, here with $x + y$ unchanged.

</details>
