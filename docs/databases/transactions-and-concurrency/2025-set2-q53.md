# 2025 CS2 Q53: Which schedules are conflict serializable

## Question

Consider the database transactions $T_1$ and $T_2$, and data items $X$ and $Y$. Which of the schedule(s) is/are conflict serializable?

| Transaction $T_1$ | Transaction $T_2$ |
|---|---|
| $R_1(X)$ | |
| | $W_2(X)$ |
| $W_1(Y)$ | |
| | $W_2(Y)$ |
| $R_1(X)$ | |
| | $COMMIT(T_2)$ |
| $W_1(X)$ | |
| $COMMIT(T_1)$ | |

- (A) $R_1(X), W_2(X), W_1(Y), W_2(Y), R_1(X), W_1(X), COMMIT(T_2), COMMIT(T_1)$
- (B) $W_2(X), R_1(X), W_2(Y), W_1(Y), R_1(X), COMMIT(T_2), W_1(X), COMMIT(T_1)$
- (C) $R_1(X), W_1(Y), W_2(X), W_2(Y), R_1(X), W_1(X), COMMIT(T_1), COMMIT(T_2)$
- (D) $W_2(X), R_1(X), W_1(Y), W_2(Y), R_1(X), COMMIT(T_2), W_1(X), COMMIT(T_1)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A schedule is conflict serializable iff its **precedence graph** has no cycle. Add an edge $T_i \to T_j$ when an operation of $T_i$ conflicts with a **later** operation of $T_j$ (same item, different transactions, at least one write).

| Schedule | Edges found | Cycle? |
|---|---|---|
| A | $R_1(X)$ before $W_2(X)$: $T_1 \to T_2$. $W_2(X)$ before the second $R_1(X)$: $T_2 \to T_1$ | **Yes** |
| **B** | $W_2(X)$ before both $R_1(X)$ and $W_1(X)$: $T_2 \to T_1$. $W_2(Y)$ before $W_1(Y)$: $T_2 \to T_1$. All edges go the same way | **No**: equivalent to $T_2$ then $T_1$ |
| C | $R_1(X)$ before $W_2(X)$: $T_1 \to T_2$. $W_2(X)$ before the second $R_1(X)$: $T_2 \to T_1$ | **Yes** |
| D | $W_2(X)$ before $R_1(X)$: $T_2 \to T_1$. $W_1(Y)$ before $W_2(Y)$: $T_1 \to T_2$ | **Yes** |

Only **B** is conflict serializable. I built the precedence graph by program for all four schedules and got the same result.

**Key idea:** build the precedence graph from conflicting pairs. One cycle means not conflict serializable.

</details>
