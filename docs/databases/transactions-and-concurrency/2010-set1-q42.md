# 2010 CS Q42: Serialization order of a schedule of three transactions

## Question

Consider the following schedule for transactions T1, T2 and T3:

| T1 | T2 | T3 |
|---|---|---|
| Read(X) | | |
| | Read(Y) | |
| | | Read(Y) |
| | Write(Y) | |
| Write(X) | | |
| | | Write(X) |
| | Read(X) | |
| | Write(X) | |

Which one of the schedules below is the correct serialization of the above?

- (A) $T1 \to T3 \to T2$
- (B) $T2 \to T1 \to T3$
- (C) $T2 \to T3 \to T1$
- (D) $T3 \to T1 \to T2$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Build the precedence graph: draw $T_i \to T_j$ when an operation of $T_i$ comes before a conflicting operation (same item, at least one write) of $T_j$.

| Item | Ordered operations | Edges |
|---|---|---|
| $X$ | R1, W1, W3, R2, W2 | $T1 \to T3$, $T1 \to T2$, $T3 \to T2$ |
| $Y$ | R2, R3, W2 | $T3 \to T2$ (R3 before W2) |

(R2 and R3 on $Y$ do not conflict. The read by $T2$ of $Y$ comes before $T2$'s own write.)

Edges: $T1 \to T3$, $T1 \to T2$, $T3 \to T2$. The graph has no cycle, so the schedule is conflict serializable, and the only topological order is $T1 \to T3 \to T2$: (A).

- (B), (C) and (D) each put $T2$ before $T1$ or $T3$ before $T1$, against an edge in the graph.

**Code check:** a Python script built the precedence graph from the schedule: edges $\lbrace 1 \to 2,\ 1 \to 3,\ 3 \to 2 \rbrace$, acyclic, topological order $1, 3, 2$.

**Key idea:** a schedule is conflict serializable iff its precedence graph is acyclic; the serial order is a topological order.

</details>
