# 2014 CS3 Q29: Conflict serializability of two schedules

## Question

Consider the transactions T1, T2, and T3 and the schedules S1 and S2 given below.

```
T1: r1(X); r1(Z); w1(X); w1(Z)
T2: r2(Y); r2(Z); w2(Z)
T3: r3(Y); r3(X); w3(Y)

S1: r1(X); r3(Y); r3(X); r2(Y); r2(Z); w3(Y); w2(Z); r1(Z); w1(X); w1(Z)
S2: r1(X); r3(Y); r2(Y); r3(X); r1(Z); r2(Z); w3(Y); w1(X); w2(Z); w1(Z)
```

Which one of the following statements about the schedules is TRUE?

- (A) Only S1 is conflict-serializable.
- (B) Only S2 is conflict-serializable.
- (C) Both S1 and S2 are conflict-serializable.
- (D) Neither S1 nor S2 is conflict-serializable.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Build the precedence graph: draw $T_i \to T_j$ if an operation of $T_i$ conflicts with, and comes before, one of $T_j$ (same item, different transactions, at least one write).

**S1**

| Item | Conflict | Edge |
|---|---|---|
| Y | $r_2(Y)$ before $w_3(Y)$ | $T_2 \to T_3$ |
| X | $r_3(X)$ before $w_1(X)$ | $T_3 \to T_1$ |
| Z | $w_2(Z)$ before $r_1(Z)$, $w_1(Z)$ | $T_2 \to T_1$ |

The graph $T_2 \to T_3 \to T_1$, $T_2 \to T_1$ has **no cycle**. S1 is conflict-serializable, equivalent to the serial order $T_2, T_3, T_1$.

**S2**

| Item | Conflict | Edge |
|---|---|---|
| Y | $r_2(Y)$ before $w_3(Y)$ | $T_2 \to T_3$ |
| X | $r_3(X)$ before $w_1(X)$ | $T_3 \to T_1$ |
| Z | $r_1(Z)$ before $w_2(Z)$ | $T_1 \to T_2$ |
| Z | $r_2(Z)$ before $w_1(Z)$ | $T_2 \to T_1$ |

$T_1 \to T_2 \to T_1$ is a **cycle**, so S2 is not conflict-serializable.

Only S1 is: **A**.

**Code check:** a precedence-graph program gives the S1 edges $\lbrace (2,1), (2,3), (3,1) \rbrace$ (acyclic) and finds a cycle in S2.

**Key idea:** a schedule is conflict-serializable iff its precedence graph is acyclic.

</details>
