# 2021 CS1 Q42: Conflict serializability of two schedules

## Question

Let $r_i(z)$ and $w_i(z)$ denote read and write operations respectively on a data item $z$ by a transaction $T_i$. Consider the following two schedules.

$S_1: r_1(x)\ r_1(y)\ r_2(x)\ r_2(y)\ w_2(y)\ w_1(x)$

$S_2: r_1(x)\ r_2(x)\ r_2(y)\ w_2(y)\ r_1(y)\ w_1(x)$

Which one of the following options is correct?

- (A) $S_1$ is conflict serializable, and $S_2$ is not conflict serializable.
- (B) $S_1$ is not conflict serializable, and $S_2$ is conflict serializable.
- (C) Both $S_1$ and $S_2$ are conflict serializable.
- (D) Neither $S_1$ nor $S_2$ is conflict serializable.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Draw an edge $T_i\to T_j$ for each pair of conflicting operations (same item, different transactions, at least one write) where $T_i$'s comes first.

**$S_1$**

- $r_1(y)$ before $w_2(y)$ gives $T_1\to T_2$.
- $r_2(x)$ before $w_1(x)$ gives $T_2\to T_1$.

The graph has a cycle, so $S_1$ is **not** conflict serializable.

**$S_2$**

- $r_2(x)$ before $w_1(x)$ gives $T_2\to T_1$.
- $w_2(y)$ before $r_1(y)$ gives $T_2\to T_1$.

Only $T_2\to T_1$, so there is no cycle. $S_2$ **is** conflict serializable (equivalent to $T_2$ then $T_1$).

So (B). A script built the precedence edges: $S_1$ gives $\lbrace(1,2),(2,1)\rbrace$ (cycle) and $S_2$ gives $\lbrace(2,1)\rbrace$ (acyclic).

**Key idea:** a schedule is conflict serializable iff its precedence graph has no cycle.

</details>
