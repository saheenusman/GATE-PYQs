# 2026 CS2 Q20: When two transactions do not conflict

## Question

Two transactions $T_1$ and $T_2$ run concurrently, and both access a data object $A$. For the two transactions **not to conflict** on $A$, which statement must be true?

- (A) Both $T_1$ and $T_2$ only read $A$
- (B) $T_1$ reads $A$ and $T_2$ writes $A$
- (C) $T_1$ writes $A$ and $T_2$ reads $A$
- (D) Both $T_1$ and $T_2$ write $A$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** Two operations of different transactions on the same item **conflict** if at least one of them is a **write**.

| $T_1$ | $T_2$ | Conflict? |
|---|---|---|
| read | read | **no** |
| read | write | yes (read-write) |
| write | read | yes (write-read) |
| write | write | yes (write-write) |

Only read-read is safe, so the answer is **(A)**.

**Why:** the order of two reads never changes what either transaction sees. If one of them writes, swapping the order changes what the other reads, or which value finally survives.

**Key idea:** conflicts need at least one write on the same data item.

</details>
