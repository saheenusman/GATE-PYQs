# 2007 CS Q64: Conflict serializability of two schedules

## Question

Consider the following schedules involving two transactions. Which one of the following statements is **TRUE**?

$$S_1: r_1(X);\ r_1(Y);\ r_2(X);\ r_2(Y);\ w_2(Y);\ w_1(X)$$
$$S_2: r_1(X);\ r_2(X);\ r_2(Y);\ w_2(Y);\ r_1(Y);\ w_1(X)$$

- (A) Both $S_1$ and $S_2$ are conflict serializable.
- (B) $S_1$ is conflict serializable and $S_2$ is not conflict serializable.
- (C) $S_1$ is not conflict serializable and $S_2$ is conflict serializable.
- (D) Both $S_1$ and $S_2$ are not conflict serializable.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Build the precedence graph: draw $T_i \to T_j$ for each pair of conflicting operations (same item, at least one write, different transactions) where $T_i$'s comes first.

**$S_1$:**
- $r_1(Y)$ before $w_2(Y)$ gives $T_1 \to T_2$.
- $r_2(X)$ before $w_1(X)$ gives $T_2 \to T_1$.

There is a cycle $T_1 \leftrightarrow T_2$, so $S_1$ is **not** conflict serializable.

**$S_2$:**
- $w_2(Y)$ before $r_1(Y)$ gives $T_2 \to T_1$.
- $r_2(X)$ before $w_1(X)$ gives $T_2 \to T_1$.
- $r_1(X)$ is before $r_2(X)$, but both are reads, so no edge.

Only $T_2 \to T_1$: no cycle, so $S_2$ is conflict serializable (equivalent to $T_2$ then $T_1$).

So (C).

- (A), (B) and (D) each get one of the two verdicts wrong.

**Code check:** Python precedence-graph builder: $S_1$ has edges $\lbrace T_1\to T_2,\ T_2\to T_1 \rbrace$ (cycle); $S_2$ has only $\lbrace T_2 \to T_1 \rbrace$.

**Key idea:** a schedule is conflict serializable iff its precedence graph is acyclic.
