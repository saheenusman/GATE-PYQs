# 2016 CS2 Q22: Ordering of precedence graph vertices that gives an equivalent serial schedule

## Question

Suppose a database schedule $S$ involves transactions $T_1, \dots, T_n$. Construct the precedence graph of $S$ with vertices representing the transactions and edges representing the conflicts. If $S$ is serializable, which one of the following orderings of the vertices of the precedence graph is guaranteed to yield a serial schedule?

- (A) Topological order
- (B) Depth-first order
- (C) Breadth-first order
- (D) Ascending order of transaction indices

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

If $S$ is conflict serializable, its precedence graph is a DAG, and every edge $T_i \to T_j$ says $T_i$ must precede $T_j$. A **topological order** respects every edge, so running the transactions serially in that order is equivalent to $S$. **(A)**.

Depth-first order, breadth-first order and index order need not respect all edges, so a conflicting pair could be put in the wrong order.

**Key idea:** topological orders of the (acyclic) precedence graph are the equivalent serial schedules.

</details>
