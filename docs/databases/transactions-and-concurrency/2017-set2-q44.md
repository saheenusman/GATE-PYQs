# 2017 CS2 Q44: Number of conflict-serializable schedules of two transactions

## Question

Two transactions $T_1$ and $T_2$ are given as

$$T_1: r_1(X)\, w_1(X)\, r_1(Y)\, w_1(Y)$$
$$T_2: r_2(Y)\, w_2(Y)\, r_2(Z)\, w_2(Z)$$

where $r_i(V)$ denotes a *read* operation by transaction $T_i$ on a variable $V$ and $w_i(V)$ denotes a *write* operation by transaction $T_i$ on a variable $V$. The total number of conflict serializable schedules that can be formed by $T_1$ and $T_2$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**54**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Total schedules.** Interleave two sequences of 4 operations each, keeping each transaction's own order: $\binom{8}{4} = 70$.

**Where can conflicts arise?** Only on a variable used by both transactions with at least one write. $X$ is used only by $T_1$ and $Z$ only by $T_2$, so only the four operations on $Y$ matter. Name them

$$A_3 = r_1(Y),\ A_4 = w_1(Y),\ B_1 = r_2(Y),\ B_2 = w_2(Y).$$

**When is a schedule conflict serializable?** It is iff the precedence graph on $\lbrace T_1,T_2\rbrace$ has no cycle. Conflicts on $Y$ run:

- $T_1 \to T_2$ if some $T_1$ op on $Y$ precedes a conflicting $T_2$ op;
- $T_2 \to T_1$ likewise.

A cycle needs both. So the schedule is serializable iff the $Y$-operations are **not interleaved**: either $T_2$'s two $Y$-ops come entirely before $T_1$'s two ($B_2 < A_3$), or entirely after ($A_4 < B_1$).

**Count them.**

- $T_1$'s $Y$-ops entirely first ($A_4 < B_1$): $A_4$ is $T_1$'s last operation, so all of $T_1$ comes before $T_2$'s first operation: **1** schedule.
- Schedules with $A_3 < B_2$: let $k \in \lbrace 3,4\rbrace$ be the number of $T_1$ ops before $B_2$. Ops before $B_2$: the first $k$ of $T_1$, with $B_1$ placed anywhere among them ($k+1$ ways); after $B_2$: the other $4-k$ of $T_1$ and $B_3, B_4$ ($\binom{6-k}{2}$ ways). Total $4\cdot3 + 5\cdot1 = 17$. So schedules with $B_2 < A_3$: $70 - 17 = $ **53**.

Conflict serializable: $53 + 1 = 54$. The other $17 - 1 = 16$ interleave the $Y$-operations and have a cycle.

**Code check:** a program enumerated all 70 interleavings and built each precedence graph. 54 are acyclic (53 equivalent to $T_2\,T_1$, 1 equivalent to $T_1\,T_2$) and 16 have a cycle.

**Key idea:** a schedule is conflict serializable iff its precedence graph is acyclic; only operations on shared variables matter.

</details>
