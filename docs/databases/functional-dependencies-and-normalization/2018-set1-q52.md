# 2018 CS Q52: Which schema is in 3NF but not BCNF

## Question

Consider the following four relational schemas. For each schema, all non-trivial functional dependencies are listed. The underlined attributes are the respective primary keys.

**Schema I:** Registration (<u>rollno</u>, courses). Field 'courses' is a set-valued attribute containing the set of courses a student has registered for. Non-trivial functional dependency: $rollno \to courses$

**Schema II:** Registration (<u>rollno</u>, <u>courseid</u>, email). Non-trivial functional dependencies: $rollno, courseid \to email$ and $email \to rollno$

**Schema III:** Registration (<u>rollno</u>, <u>courseid</u>, marks, grade). Non-trivial functional dependencies: $rollno, courseid \to marks, grade$ and $marks \to grade$

**Schema IV:** Registration (<u>rollno</u>, <u>courseid</u>, credit). Non-trivial functional dependencies: $rollno, courseid \to credit$ and $courseid \to credit$

Which one of the relational schemas above is in 3NF but not in BCNF?

- (A) Schema I
- (B) Schema II
- (C) Schema III
- (D) Schema IV

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**3NF** requires, for every non-trivial $X\to A$: $X$ is a superkey, or $A$ is a prime attribute. **BCNF** requires $X$ to be a superkey.

- **Schema I:** the set-valued `courses` violates 1NF, so it is not even in 1NF.
- **Schema II:** the keys are $\lbrace rollno, courseid\rbrace$ and $\lbrace email, courseid\rbrace$. The FD $email\to rollno$ has a non-superkey left side, so it **fails BCNF**. But $rollno$ is a prime attribute (part of a key), so it **passes 3NF**.
- **Schema III:** $marks\to grade$ has a non-superkey left side and $grade$ is non-prime: it **fails 3NF**.
- **Schema IV:** $courseid\to credit$ is a partial dependency on part of the key, with $credit$ non-prime: it **fails 3NF** (and 2NF).

Only Schema II is in 3NF but not BCNF: **B**.

**Code check:** a closure-based script gave: II has keys $\lbrace c,e\rbrace$, $\lbrace c,r\rbrace$, 3NF yes, BCNF no; III and IV are not in 3NF.

**Key idea:** 3NF allows a determinant that is not a superkey if the dependent attribute is prime; BCNF does not.

</details>
