# 2008 CS Q69: Normal forms of Book and Collection

## Question

Consider the following relational schemes for a library database:

- Book (Title, Author, Catalog_no, Publisher, Year, Price)
- Collection (Title, Author, Catalog_no)

with the following functional dependencies:

- I. Title Author $\to$ Catalog_no
- II. Catalog_no $\to$ Title Author Publisher Year
- III. Publisher Title Year $\to$ Price

Assume $\lbrace$Author, Title$\rbrace$ is the key for both schemes. Which of the following statements is true?

- (A) Both Book and Collection are in BCNF
- (B) Both Book and Collection are in 3NF only
- (C) Book is in 2NF and Collection is in 3NF
- (D) Both Book and Collection are in 2NF only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Keys.** From I and II, $\lbrace$Title, Author$\rbrace$ and $\lbrace$Catalog_no$\rbrace$ are both candidate keys of Book (each determines every attribute). The prime attributes are Title, Author and Catalog_no.

**Book.**

- III: Publisher, Title, Year $\to$ Price. The left side is not a superkey and Price is not prime, so Book is **not in 3NF** (and not BCNF): Price depends on a non-key set.
- Is it in 2NF? A partial dependency needs a non-prime attribute that depends on a *proper part* of a candidate key. Price depends on $\lbrace$Publisher, Title, Year$\rbrace$, which is not a subset of any candidate key, so there is no partial dependency. Book is in **2NF**.

**Collection.** The dependencies that apply are Title Author $\to$ Catalog_no and Catalog_no $\to$ Title Author. Both left sides are keys, so Collection is in **BCNF**, hence also in 3NF.

So "Book is in 2NF and Collection is in 3NF" is true: (C).

- (A) is false: Book is not in BCNF.
- (B) is false: Book is not in 3NF.
- (D) is false: Collection is in 3NF (indeed BCNF), so it is not in "2NF only".

**Code check:** an attribute-closure program found the keys, then checked every projected dependency. Book: keys $\lbrace$Catalog_no$\rbrace$ and $\lbrace$Author, Title$\rbrace$; BCNF false, 3NF false, 2NF true. Collection: BCNF true.

**Key idea:** be careful with the word "only": a relation in BCNF is also in 3NF and 2NF.

</details>
