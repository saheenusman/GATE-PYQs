# 2013 CS Q54: Number of candidate keys

## Question

**Statement for Linked Answer Questions 54 and 55.** Relation $R$ has eight attributes $ABCDEFGH$. Fields of $R$ contain only atomic values. $F = \lbrace CH \to G,\ A \to BC,\ B \to CFH,\ E \to A,\ F \to EG \rbrace$ is a set of functional dependencies (FDs) so that $F^+$ is exactly the set of FDs that hold for $R$.

How many candidate keys does the relation $R$ have?

- (A) 3
- (B) 4
- (C) 5
- (D) 6

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$D$ is in every key.** $D$ appears on no right-hand side, so it cannot be derived.

**Which attribute partners $D$?** Compute closures.

- $A^+$: $A \to BC$; $B \to CFH$; $F \to EG$. So $A^+ = ABCEFGH$. With $D$: all 8 attributes. **$AD$ is a key.**
- $B^+$: $B \to CFH$, $F \to EG$, $E \to A$, $A \to BC$. All except $D$. **$BD$ is a key.**
- $E^+$: $E \to A$, then as for $A$. **$DE$ is a key.**
- $F^+$: $F \to EG$, $E \to A$, ... **$DF$ is a key.**
- $C$, $G$ and $H$ never lead back to $A, B, E$ or $F$ (the only FD they trigger is $CH \to G$), so no set built from $D$ with only $C, G, H$ is a key.

Each of $AD, BD, DE, DF$ is minimal (neither attribute alone determines everything). That gives **4** candidate keys.

**Why the others fail:** 3 omits one of the four; 5 and 6 would need extra keys such as $CD$ or $GD$, which are not keys.

**Code check:** an exhaustive search over all attribute subsets found exactly the keys $AD, BD, DE, DF$; the prime attributes are $A, B, D, E, F$.

**Key idea:** start with attributes that never appear on a right-hand side, then add attributes whose closures cover the rest.

</details>
