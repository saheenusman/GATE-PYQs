# 2021 CS1 Q43: Lossless join test for two decompositions

## Question

Consider the relation $R(P,Q,S,T,X,Y,Z,W)$ with the following functional dependencies.

$PQ\to X;\quad P\to YX;\quad Q\to Y;\quad Y\to ZW$

Consider the decomposition of the relation $R$ into the constituent relations according to the following two decomposition schemes.

$D_1: R=[(P,Q,S,T);\ (P,T,X);\ (Q,Y);\ (Y,Z,W)]$

$D_2: R=[(P,Q,S);\ (T,X);\ (Q,Y);\ (Y,Z,W)]$

Which one of the following options is correct?

- (A) $D_1$ is a lossless decomposition, but $D_2$ is a lossy decomposition.
- (B) $D_1$ is a lossy decomposition, but $D_2$ is a lossless decomposition.
- (C) Both $D_1$ and $D_2$ are lossless decompositions.
- (D) Both $D_1$ and $D_2$ are lossy decompositions.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Candidate key.** $PQ$ gives $X$ (and $Y$ via $P\to YX$), and $Y\to ZW$ gives $Z,W$. $S$ and $T$ appear on no right-hand side, so the key is $PQST$.

**$D_1$.** The relation $(P,Q,S,T)$ already contains the whole key. Joining it with $(P,T,X)$, $(Q,Y)$ and $(Y,Z,W)$ brings in $X$ through $P\to X$, $Y$ through $Q\to Y$, and $Z,W$ through $Y\to ZW$. The chase table ends with a row of all "a" symbols, so $D_1$ is **lossless**.

**$D_2$.** No relation holds $P,Q,S,T$ together. The relation $(T,X)$ cannot be joined to $(P,Q,S)$: they share no attribute, and $T$ is not determined by anything. The chase never gives a full row of "a" symbols, so $D_2$ is **lossy**.

So (A). I ran the tableau (chase) test in a script: $D_1$ gives True and $D_2$ gives False.

**Key idea:** a decomposition is lossless iff the chase on the FDs yields a row of all distinguished symbols.

</details>
