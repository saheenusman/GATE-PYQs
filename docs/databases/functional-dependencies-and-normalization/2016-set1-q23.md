# 2016 CS1 Q23: Weakest normal form gained by a redesigned journal schema

## Question

A database of research articles in a journal uses the following schema.

(VOLUME, NUMBER, STARTPAGE, ENDPAGE, TITLE, YEAR, PRICE)

The primary key is (VOLUME, NUMBER, STARTPAGE, ENDPAGE) and the following functional dependencies exist in the schema.

- (VOLUME, NUMBER, STARTPAGE, ENDPAGE) $\rightarrow$ TITLE
- (VOLUME, NUMBER) $\rightarrow$ YEAR
- (VOLUME, NUMBER, STARTPAGE, ENDPAGE) $\rightarrow$ PRICE

The database is redesigned to use the following schemas.

- (VOLUME, NUMBER, STARTPAGE, ENDPAGE, TITLE, PRICE)
- (VOLUME, NUMBER, YEAR)

Which is the weakest normal form that the new database satisfies, but the old one does not?

- (A) 1NF
- (B) 2NF
- (C) 3NF
- (D) BCNF

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Old schema.** The key is $(V, N, S, E)$, but $(V, N) \rightarrow \text{YEAR}$ depends on only part of the key. That is a *partial dependency*, so the old schema is in 1NF but **not in 2NF** (and so not 3NF or BCNF either).

**New schemas.**

- $R_1(V, N, S, E, \text{TITLE}, \text{PRICE})$: the only determinant is the whole key, so it is in BCNF.
- $R_2(V, N, \text{YEAR})$: the key is $(V, N)$ and the only dependency is from the key, so it is in BCNF.

The new database satisfies 2NF, 3NF and BCNF; the old one satisfies none of those. The weakest of them is **2NF**.

**Why the others fail.** (A) 1NF is satisfied by both. (C) and (D) are satisfied by the new design too, but they are stronger than 2NF, and the question asks for the weakest.

**Key idea:** the old schema has a partial dependency, so the first normal form it fails is 2NF.

</details>
