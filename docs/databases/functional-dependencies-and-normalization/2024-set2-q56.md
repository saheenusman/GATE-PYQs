# 2024 CS2 Q56: Counting useful functional dependencies

## Question

A functional dependency $F: X \to Y$ is termed as a useful functional dependency if and only if it satisfies all the following three conditions:

- $X$ is not the empty set.
- $Y$ is not the empty set.
- Intersection of $X$ and $Y$ is the empty set.

For a relation $R$ with 4 attributes, the total number of possible useful functional dependencies is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**50**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each of the 4 attributes goes to exactly one of three places: in $X$, in $Y$, or in neither. That gives $3^4 = 81$ assignments, and they all have $X \cap Y = \emptyset$.

**Remove the bad ones:**

- $X$ empty: each attribute is in $Y$ or neither, $2^4 = 16$.
- $Y$ empty: also $2^4 = 16$.
- Both empty: counted twice above, $1$.

$$81 - 16 - 16 + 1 = 50.$$

(A brute-force count over all pairs of non-empty subsets with empty intersection also gives 50.)

**Key idea:** assign each attribute to $X$, $Y$ or neither, then use inclusion-exclusion to remove empty sides.

</details>
