# 2015 CS3 Q13: Identifying a trivial functional dependency

## Question

Consider the relation $X(P, Q, R, S, T, U)$ with the following set of functional dependencies

$$F = \lbrace \lbrace P, R \rbrace \to \lbrace S, T \rbrace,\ \lbrace P, S, U \rbrace \to \lbrace Q, R \rbrace \rbrace$$

Which of the following is the trivial functional dependency in $F^+$, where $F^+$ is the closure of $F$?

- (A) $\lbrace P, R \rbrace \to \lbrace S, T \rbrace$
- (B) $\lbrace P, R \rbrace \to \lbrace R, T \rbrace$
- (C) $\lbrace P, S \rbrace \to \lbrace S \rbrace$
- (D) $\lbrace P, S, U \rbrace \to \lbrace Q \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A functional dependency $X \to Y$ is **trivial** when $Y \subseteq X$. Such a dependency holds in every relation (reflexivity), so it is always in $F^+$.

| Option | Is RHS $\subseteq$ LHS? |
|---|---|
| A: $PR \to ST$ | No ($S, T \notin PR$). This is a given FD. |
| B: $PR \to RT$ | No, $T \notin PR$. It is in $F^+$ but only partly trivial. |
| **C: $PS \to S$** | **Yes.** Trivial. |
| D: $PSU \to Q$ | No, $Q \notin PSU$. Follows from $PSU \to QR$. |

Option (C).

**Key idea:** trivial means RHS $\subseteq$ LHS. An FD that is only partly trivial (like B) is still non-trivial.

</details>
