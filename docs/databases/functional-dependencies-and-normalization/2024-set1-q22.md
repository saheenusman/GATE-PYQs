# 2024 CS1 Q22: What first normal form allows and forbids

## Question

Which of the following statements about a relation R in first normal form (1NF) is/are TRUE?

- (A) R can have a multi-attribute key
- (B) R cannot have a foreign key
- (C) R cannot have a composite attribute
- (D) R cannot have more than one candidate key

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A relation is in 1NF when all attribute values are **atomic**: no repeating groups, no multi-valued attributes, no composite attributes stored as one value.

- **(A) True.** Composite keys (keys made of several attributes) are allowed in 1NF.
- **(B) False.** Foreign keys have nothing to do with 1NF. Any relation can have them.
- **(C) True.** Composite attributes (like an address with street, city) break atomicity and must be split into separate attributes.
- **(D) False.** A relation can have many candidate keys in any normal form.

**Key idea:** 1NF is about atomic values only. Keys are a concern for 2NF and above.

</details>
