# 2012 CS Q2: Which statement about 3NF and BCNF is true

## Question

Which of the following is **TRUE**?

- (A) Every relation in 3NF is also in BCNF
- (B) A relation R is in 3NF if every non-prime attribute of R is fully functionally dependent on every key of R
- (C) Every relation in BCNF is also in 3NF
- (D) No relation can be in both BCNF and 3NF

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

BCNF requires that for every non-trivial FD $X \to A$, $X$ is a superkey. 3NF is weaker: it also allows $X \to A$ when $A$ is a prime attribute. So every BCNF relation satisfies the 3NF condition, which is (C).

- (A) false. $R(A,B,C)$ with $AB \to C$ and $C \to B$ has keys $AB$ and $AC$. $C \to B$ is allowed in 3NF ($B$ is prime) but $C$ is not a superkey, so it is not in BCNF.
- (B) false. Full dependence on every key only removes partial dependencies (2NF). It does not exclude transitive ones: $R(A,B,C)$ with $A \to B$ and $B \to C$ has key $A$ and every non-prime attribute fully dependent on it, yet $B \to C$ breaks 3NF.
- (D) false, since every BCNF relation is also in 3NF.

**Key idea:** BCNF $\subset$ 3NF $\subset$ 2NF $\subset$ 1NF.

</details>
