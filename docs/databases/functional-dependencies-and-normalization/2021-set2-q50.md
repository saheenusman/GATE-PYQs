# 2021 CS2 Q50: Functional dependencies inferred from P->QR and RS->T

## Question

Suppose the following functional dependencies hold on a relation $U$ with attributes $P$, $Q$, $R$, $S$, and $T$:

$$P\to QR$$
$$RS\to T$$

Which of the following functional dependencies can be inferred from the above functional dependencies?

- (A) $PS\to T$
- (B) $R\to T$
- (C) $P\to R$
- (D) $PS\to Q$

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compute attribute closures.

- $\lbrace P\rbrace^+=\lbrace P,Q,R\rbrace$.
- $\lbrace R\rbrace^+=\lbrace R\rbrace$.
- $\lbrace P,S\rbrace^+$: from $P$ get $Q,R$; now $R,S$ are present, so get $T$. Result $\lbrace P,Q,R,S,T\rbrace$.

A dependency $X\to Y$ is inferred when $Y\subseteq X^+$.

- (A) $PS\to T$: $T\in\lbrace PS\rbrace^+$. **Yes** (pseudotransitivity: $P\to R$, so $PS\to RS\to T$).
- (B) $R\to T$: $T\notin\lbrace R\rbrace^+$. **No.** $T$ needs both $R$ and $S$.
- (C) $P\to R$: $R\in\lbrace P\rbrace^+$. **Yes** (decomposition of $P\to QR$).
- (D) $PS\to Q$: $Q\in\lbrace PS\rbrace^+$. **Yes** ($P\to Q$, then augment with $S$).

**Key idea:** test $X\to Y$ by computing $X^+$ and checking $Y\subseteq X^+$.

</details>
