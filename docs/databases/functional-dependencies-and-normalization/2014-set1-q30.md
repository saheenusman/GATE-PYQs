# 2014 CS1 Q30: Normal forms of a 2-attribute table; minimal cover

## Question

Given the following two statements:

**S1:** Every table with two single-valued attributes is in 1NF, 2NF, 3NF and BCNF.

**S2:** $AB \to C,\ D \to E,\ E \to C$ is a minimal cover for the set of functional dependencies $AB \to C,\ D \to E,\ AB \to E,\ E \to C$.

Which one of the following is **CORRECT**?

- (A) S1 is TRUE and S2 is FALSE.
- (B) Both S1 and S2 are TRUE.
- (C) S1 is FALSE and S2 is TRUE.
- (D) Both S1 and S2 are FALSE.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**S1 is true.** With attributes $X, Y$ the only non-trivial FDs are $X \to Y$ and $Y \to X$. Whenever $X \to Y$ holds, $X$ is a key, so every determinant is a superkey (BCNF). With no FDs, nothing violates anything. There is no composite key, so no partial dependency (2NF), and single-valued attributes give 1NF.

**S2 is false.** A minimal cover must be equivalent to the original set. In the original, $\lbrace A,B \rbrace^+ = \lbrace A,B,C,E \rbrace$ (because of $AB \to E$). In the proposed cover, $\lbrace A,B \rbrace^+ = \lbrace A,B,C \rbrace$, which loses $E$. $AB \to E$ is not redundant: $E$ cannot be derived from $AB$ using the other FDs.

**Code check:** closure of $AB$ is $\lbrace A,B,C,E \rbrace$ with the original FDs and $\lbrace A,B,C \rbrace$ with the proposed cover.

So S1 true, S2 false: **A**.

**Key idea:** a minimal cover must preserve every closure; check that each dropped FD is truly redundant.

</details>
