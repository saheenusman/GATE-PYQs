# 2022 CS Q31: Number of superkeys

## Question

Consider a relation $R(A, B, C, D, E)$ with the following three functional dependencies.

$AB \to C;\ BC \to D;\ C \to E;$

The number of superkeys in the relation $R$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find the candidate key.** $A$ and $B$ never appear on a right-hand side, so every key contains both. Check $AB$:

$$\lbrace A, B \rbrace^+ = \lbrace A, B, C, D, E \rbrace \quad (AB \to C,\ BC \to D,\ C \to E)$$

So $AB$ is the only candidate key.

**Count superkeys.** A superkey is any set containing $AB$. The other three attributes $C, D, E$ are free:

$$2^3 = 8$$

**Code check:** enumerating all 32 attribute sets and testing closure gave 8 superkeys.

**Key idea:** attributes that are never determined must be in every key; then count the supersets.

</details>
