# 2022 CS Q14: True statement about BCNF

## Question

In a relational data model, which one of the following statements is TRUE?

- (A) A relation with only two attributes is always in BCNF.
- (B) If all attributes of a relation are prime attributes, then the relation is in BCNF.
- (C) Every relation has at least one non-prime attribute.
- (D) BCNF decompositions preserve functional dependencies.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** With attributes $\lbrace X, Y \rbrace$ the only non-trivial FDs are $X \to Y$ and $Y \to X$. In each, the left side determines the whole relation, so it is a superkey. No FD violates BCNF.
- (B) False. All-prime attributes guarantees 3NF, not BCNF. Example: $R(A, B, C)$ with $AB \to C$ and $C \to A$ has keys $AB$ and $BC$, so all attributes are prime, yet $C \to A$ violates BCNF.
- (C) False. A relation whose only key is all its attributes (for example $R(A, B)$ with no FDs) has no non-prime attribute.
- (D) False. BCNF decomposition is lossless but may lose dependencies, as in the example under (B).

**Key idea:** every determinant of a two-attribute relation is automatically a key; BCNF can lose FDs, and all-prime gives only 3NF.

</details>
