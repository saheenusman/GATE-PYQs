# 2007 CS Q62: False statement about normal forms

## Question

Which one of the following statements is **FALSE**?

- (A) Any relation with two attributes is in BCNF.
- (B) A relation in which every key has only one attribute is in 2NF.
- (C) A prime attribute can be transitively dependent on a key in a 3NF relation.
- (D) A prime attribute can be transitively dependent on a key in a BCNF relation.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** With two attributes, every non-trivial FD has a single attribute on the left, and that attribute must then be a key (it determines the other), so BCNF holds.
- **(B) True.** 2NF forbids *partial* dependencies on part of a key. If every key is a single attribute, no part-of-a-key dependency can exist.
- **(C) True.** 3NF explicitly allows $X \to A$ where $A$ is prime, even if $X$ is not a superkey, which is how a prime attribute can depend transitively on a key.
- **(D) False.** BCNF requires the left side of every non-trivial FD to be a superkey, so no attribute (prime or not) can be transitively dependent on a key.

So (D) is the false statement.
