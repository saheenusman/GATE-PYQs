# 2017 CS1 Q16: Irreducible equivalent of a set of functional dependencies on R(V,W,X,Y,Z)

## Question

The following functional dependencies hold true for the relational schema $R\lbrace V, W, X, Y, Z\rbrace$:

$$V \to W,\quad VW \to X,\quad Y \to VX,\quad Y \to Z$$

Which of the following is irreducible equivalent for this set of functional dependencies?

- (A) $V \to W,\ V \to X,\ Y \to V,\ Y \to Z$
- (B) $V \to W,\ W \to X,\ Y \to V,\ Y \to Z$
- (C) $V \to W,\ V \to X,\ Y \to V,\ Y \to X,\ Y \to Z$
- (D) $V \to W,\ W \to X,\ Y \to V,\ Y \to X,\ Y \to Z$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Compute a canonical (irreducible) cover.**

1. **Single attribute on the right.** Split $Y \to VX$:
   $V\to W,\ VW\to X,\ Y\to V,\ Y\to X,\ Y\to Z$.
2. **Remove extraneous left attributes.** In $VW \to X$, $W$ is extraneous because $V \to W$ gives $V^{+}\ni W$, so $V \to X$ already follows from $V\to W,\ VW\to X$. Replace it with $V \to X$.
3. **Remove redundant dependencies.** $Y \to X$ follows from $Y \to V$ and $V \to X$, so drop it.

Result: $V\to W,\ V\to X,\ Y\to V,\ Y\to Z$, which is **(A)**.

**Why the others fail.**

- (B), (D) contain $W \to X$, which is not implied by the original set ($W^{+}=\lbrace W\rbrace$). They are not equivalent.
- (C) is equivalent but not irreducible: $Y \to X$ is redundant.

**Code check:** attribute-closure tests showed (A) and (C) are equivalent to the original set and (B), (D) are not. The only redundant dependency found in (A)-(D) was $Y\to X$ (in C and D). (A) had no redundant dependency and no extraneous attribute.

**Key idea:** irreducible = single-attribute right sides, no extraneous left attributes, no redundant dependencies.

</details>
