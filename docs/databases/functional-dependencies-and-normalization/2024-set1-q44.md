# 2024 CS1 Q44: Valid functional dependency inferences

## Question

The symbol $\to$ indicates functional dependency in the context of a relational database. Which of the following options is/are TRUE?

- (A) $(X,Y) \to (Z,W)$ implies $X \to (Z,W)$
- (B) $(X,Y) \to (Z,W)$ implies $(X,Y) \to Z$
- (C) $((X,Y) \to Z$ and $W \to Y)$ implies $(X,W) \to Z$
- (D) $(X \to Y$ and $Y \to Z)$ implies $X \to Z$

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) False.** Dropping $Y$ from the left side is not allowed. Counterexample: tuples $(X,Y,Z,W) = (1,1,1,1)$ and $(1,2,2,2)$. Here $(X,Y)$ is unique, so $(X,Y) \to (Z,W)$ holds, but both tuples have $X = 1$ with different $Z$, so $X \to (Z,W)$ fails.
- **(B) True.** *Decomposition:* if $A \to BC$ then $A \to B$ and $A \to C$.
- **(C) True.** From $W \to Y$ get $(X,W) \to (X,Y)$ (augmentation). Then $(X,Y) \to Z$ gives $(X,W) \to Z$ (transitivity). This is *pseudo-transitivity*.
- **(D) True.** Transitivity (Armstrong's axiom).

**Key idea:** use Armstrong's axioms (reflexivity, augmentation, transitivity) and a small counterexample table to refute a claim.

</details>
