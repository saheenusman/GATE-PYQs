# 2026 CS1 Q65: Counting superkeys from candidate keys

## Question

Consider a relation $R(A, B, C, D)$. If $\lbrace A, B \rbrace$ and $\lbrace A, C \rbrace$ are the only two candidate keys, the number of superkeys of $R$ is _____. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A **superkey** is any set of attributes that contains a candidate key. So count the subsets of $\lbrace A,B,C,D \rbrace$ that contain $\lbrace A,B \rbrace$ **or** contain $\lbrace A,C \rbrace$.

Both keys contain $A$, so every superkey contains $A$. Then it needs $B$ or $C$ (or both). $D$ is free.

| $B$ and $C$ choices (at least one) | $D$ choices | Count |
|---|---|---|
| $B$ only, $C$ only, or both: 3 | in or out: 2 | $3 \times 2 = 6$ |

The six superkeys: $AB$, $AC$, $ABC$, $ABD$, $ACD$, $ABCD$.

**Check with inclusion-exclusion.** Supersets of $AB$: $2^2 = 4$. Supersets of $AC$: $4$. Supersets of both ($ABC$): $2^1 = 2$. Total $4 + 4 - 2 = 6$.

**Verified** by listing all 16 subsets in Python.

**Key idea:** superkeys are all supersets of candidate keys. Count them with inclusion-exclusion.

</details>
