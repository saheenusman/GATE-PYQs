# 2021 CS2 Q16: Foreign keys in a relation scheme

## Question

Consider the following statements S1 and S2 about the relational data model:

S1: A relation scheme can have at most one foreign key.

S2: A foreign key in a relation scheme R cannot be used to refer to tuples of R.

Which one of the following choices is correct?

- (A) Both S1 and S2 are true.
- (B) S1 is true and S2 is false.
- (C) S1 is false and S2 is true.
- (D) Both S1 and S2 are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**S1 is false.** A relation can have any number of foreign keys. For example, `Enrolment(student_id, course_id)` has two foreign keys, one to `Student` and one to `Course`.

**S2 is false.** A foreign key may refer to the **same** relation. For example, `Employee(emp_id, manager_id)` where `manager_id` refers to `emp_id` of `Employee` (a self-referencing foreign key).

Both are false, so (D).

**Key idea:** a relation can have many foreign keys, and a foreign key can reference its own relation.

</details>
