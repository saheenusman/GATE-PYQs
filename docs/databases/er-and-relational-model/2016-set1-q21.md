# 2016 CS1 Q21: Which attribute set is not a superkey when VY is the primary key

## Question

Which of the following is NOT a superkey in a relational schema with attributes $V, W, X, Y, Z$ and primary key $VY$?

- (A) $VXYZ$
- (B) $VWXZ$
- (C) $VWXY$
- (D) $VWXYZ$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A superkey is any set of attributes that contains a key. Here the key is $VY$, so every set that includes both $V$ and $Y$ is a superkey.

| Option | Contains $V$ and $Y$? | Superkey? |
|---|---|---|
| (A) $VXYZ$ | yes | yes |
| (B) $VWXZ$ | no ($Y$ missing) | **no** |
| (C) $VWXY$ | yes | yes |
| (D) $VWXYZ$ | yes | yes (all attributes) |

(B) lacks $Y$, so nothing forces its tuples to be distinct, and it is not guaranteed to be a superkey.

**Assumption.** $VY$ is the only candidate key given. If another candidate key existed inside $VWXZ$, then (B) could be a superkey; the question gives none.

**Key idea:** a superkey is any superset of a key; $VWXZ$ misses the key attribute $Y$.

</details>
