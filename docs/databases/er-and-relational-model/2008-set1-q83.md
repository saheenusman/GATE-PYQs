# 2008 CS Q83: Attribute set of one of the tables

## Question

(Continuing the ER diagram of Q.82.) Which of the following is a correct attribute set for one of the tables for the correct answer to the above question?

- (A) $\lbrace M1, M2, M3, P1 \rbrace$
- (B) $\lbrace M1, P1, N1, N2 \rbrace$
- (C) $\lbrace M1, P1, N1 \rbrace$
- (D) $\lbrace M1, P1 \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Both readings of Q.82 contain the table that holds $M$ together with its many-to-one relationship $R1$:

$$M(\underline{M1}, M2, M3, P1),$$

with $P1$ as a foreign key to $P$. That is $\lbrace M1, M2, M3, P1 \rbrace$: (A). It appears in the key's 2-table answer and in my 3-table answer, so Q.83 does not depend on how Q.82 is settled.

- (B) mixes an $M$ attribute with $N$'s attributes. No table holds both.
- (C) and (D) leave out $M2$ and $M3$, so they cannot represent $M$.

**Key idea:** a many-to-one relationship is stored by adding the other entity's key to the table on the "many" side.

</details>
