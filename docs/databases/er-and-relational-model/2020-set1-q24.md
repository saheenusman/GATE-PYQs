# 2020 CS Q24: ER symbol for the identifying relationship of a weak entity set

## Question

Which one of the following is used to represent the supporting many-one relationships of a weak entity set in an entity-relationship diagram?

- (A) Diamonds with double/bold border
- (B) Rectangles with double/bold border
- (C) Ovals with double/bold border
- (D) Ovals that contain underlined identifiers

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A weak entity set has no key of its own. It depends on a strong ("owner") entity set through a many-one relationship, called the **identifying relationship**. In an ER diagram:

| Symbol | Meaning |
|---|---|
| Diamond | a relationship |
| **Diamond with double/bold border** | **the supporting (identifying) relationship of a weak entity set** |
| Rectangle with double/bold border | the weak entity set itself |
| Oval with double/bold border | a multivalued attribute |
| Oval with an underlined name | a key attribute |

The question asks about the *relationship*, so the answer is the double-bordered diamond.

**Why the others fail:**

- **(B)** draws the weak *entity set*, not its relationship.
- **(C)** draws a multivalued attribute.
- **(D)** draws a key attribute. A weak entity's partial key is marked with a dashed underline, and it is still an attribute, not a relationship.

**Key idea:** double rectangle is the weak entity, and double diamond is the relationship that supports it.

</details>
