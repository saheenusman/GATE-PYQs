# 2012 CS Q14: Which statement about the ER and relational models is incorrect

## Question

Given the basic ER and relational models, which of the following is **INCORRECT**?

- (A) An attribute of an entity can have more than one value
- (B) An attribute of an entity can be composite
- (C) In a row of a relational table, an attribute can have more than one value
- (D) In a row of a relational table, an attribute can have exactly one value or a NULL value

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The question asks for the false statement.

- (A) true. ER attributes can be multivalued (a person's phone numbers).
- (B) true. ER attributes can be composite (address = street, city, pin).
- (D) true. A relational attribute holds one atomic value or NULL.
- (C) **false.** The relational model requires atomic values (first normal form), so a cell cannot hold several values. A multivalued ER attribute is turned into a separate table.

So the incorrect statement is (C).

**Key idea:** ER allows multivalued and composite attributes; relational tables do not.

</details>
