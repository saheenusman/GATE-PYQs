# 2026 CS2 Q15: Schema levels and what they contain

## Question

In the context of DBMS, consider the two sets T and S.

| T | S |
|---|---|
| I: Logical schema | L: Views |
| II: Physical schema | M: File organization and indexes |
| III: External schema | N: Relations |

Which one of the following is the correct match from T to S?

- (A) I – L, II – M, III – N
- (B) I – M, II – L, III – N
- (C) I – N, II – M, III – L
- (D) I – N, II – L, III – M

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher (the three-schema architecture).**

| Level | What it describes | Contents |
|---|---|---|
| External (view) | what each user sees | **views** |
| Logical (conceptual) | the whole database structure | **relations** (tables, constraints) |
| Physical (internal) | how data is stored | **file organisation and indexes** |

So:

- I Logical schema $\to$ N Relations
- II Physical schema $\to$ M File organization and indexes
- III External schema $\to$ L Views

That is **(C)**: I–N, II–M, III–L.

**Key idea:** external = views for users, logical = relations, physical = files and indexes.

</details>
