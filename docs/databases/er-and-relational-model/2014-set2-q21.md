# 2014 CS2 Q21: Number of superkeys of R(E,F,G,H) when E is the key

## Question

The maximum number of superkeys for the relation schema $R(E,F,G,H)$ with $E$ as the key is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Any attribute set that contains the key $E$ is a superkey. The other three attributes $F, G, H$ can each be in or out:

$$2^3 = 8$$

The superkeys are $\lbrace E \rbrace$, $\lbrace E,F \rbrace$, $\lbrace E,G \rbrace$, $\lbrace E,H \rbrace$, $\lbrace E,F,G \rbrace$, $\lbrace E,F,H \rbrace$, $\lbrace E,G,H \rbrace$, $\lbrace E,F,G,H \rbrace$.

Sets without $E$ are not superkeys, since $E$ is the only key. So the maximum is 8.

**Key idea:** number of superkeys $= 2^{(\text{attributes} - \text{key size})}$ when there is a single one-attribute key.

</details>
