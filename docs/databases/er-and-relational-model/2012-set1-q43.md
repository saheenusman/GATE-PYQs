# 2012 CS Q43: Referential integrity between R1 and R2

## Question

Suppose $R_1(\underline{A}, B)$ and $R_2(\underline{C}, D)$ are two relation schemas. Let $r_1$ and $r_2$ be the corresponding relation instances. $B$ is a foreign key that refers to $C$ in $R_2$. If data in $r_1$ and $r_2$ satisfy referential integrity constraints, which of the following is **ALWAYS TRUE**?

- (A) $\Pi_B(r_1) - \Pi_C(r_2) = \emptyset$
- (B) $\Pi_C(r_2) - \Pi_B(r_1) = \emptyset$
- (C) $\Pi_B(r_1) = \Pi_C(r_2)$
- (D) $\Pi_B(r_1) - \Pi_C(r_2) \neq \emptyset$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Referential integrity says every (non-null) foreign key value in $r_1.B$ must appear as a value of the key $C$ in $r_2$. So $\Pi_B(r_1) \subseteq \Pi_C(r_2)$, and the difference $\Pi_B(r_1) - \Pi_C(r_2)$ is empty: (A).

- (B) false: $r_2$ may hold keys that no row of $r_1$ refers to.
- (C) false for the same reason; only $\subseteq$ is guaranteed, not equality.
- (D) says the opposite of the constraint.

NULL foreign keys are allowed; the answer reads $\Pi_B$ over the non-null values, which is how the key treats it.

**Key idea:** a foreign key's values are a subset of the referenced key's values.

</details>
