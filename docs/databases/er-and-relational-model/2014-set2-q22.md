# 2014 CS2 Q22: Value of X for which (StudentName, StudentAge) is not a key

## Question

Given an instance of the STUDENTS relation as shown below:

| StudentID | StudentName | StudentEmail | StudentAge | CPI |
|---|---|---|---|---|
| 2345 | Shankar | shankar@math | X | 9.4 |
| 1287 | Swati | swati@ee | 19 | 9.5 |
| 7853 | Shankar | shankar@cse | 19 | 9.4 |
| 9876 | Swati | swati@mech | 18 | 9.3 |
| 8765 | Ganesh | ganesh@civil | 19 | 8.7 |

For (StudentName, StudentAge) to be a key for this instance, the value $X$ should NOT be equal to ________________.

<details class="success" markdown="1">
<summary>Answer</summary>

**19**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A key needs unique values for every row. The pairs (StudentName, StudentAge) are:

| Row | Pair |
|---|---|
| 2345 | (Shankar, $X$) |
| 1287 | (Swati, 19) |
| 7853 | (Shankar, 19) |
| 9876 | (Swati, 18) |
| 8765 | (Ganesh, 19) |

Only the first and third rows share a name (Shankar). If $X = 19$ they become identical, which breaks uniqueness. For any other $X$ all five pairs differ.

**Code check:** testing $X = 18, 19, 20, 21$ shows a duplicate only for 19.

So $X$ must not be **19**.

**Key idea:** a key must have distinct values for every tuple of the instance.

</details>
