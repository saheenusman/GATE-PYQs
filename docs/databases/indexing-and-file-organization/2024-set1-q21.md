# 2024 CS1 Q21: Minimum occupancy in a B+ tree

## Question

In a B+ tree, the requirement of at least half-full (50%) node occupancy is relaxed for which one of the following cases?

- (A) Only the root node
- (B) All leaf nodes
- (C) All internal nodes
- (D) Only the leftmost leaf node

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a B+ tree, every node except the **root** must be at least half full (so the tree stays balanced and shallow). The root is allowed to have as few as 2 children (or, if it is a leaf, as few as 1 key).

**Why the others fail:** leaf nodes and non-root internal nodes must keep at least half occupancy. Even the leftmost leaf is not exempt.

**Key idea:** the 50% rule applies to every node except the root.

</details>
