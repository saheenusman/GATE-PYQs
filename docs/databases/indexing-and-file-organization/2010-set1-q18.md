# 2010 CS Q18: Minimum keys in a non-root node of a B+ tree with at most 5 keys per node

## Question

Consider a B+-tree in which the maximum number of keys in a node is $5$. What is the minimum number of keys in any non-root node?

- (A) $1$
- (B) $2$
- (C) $3$
- (D) $4$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A node with at most $5$ keys has at most $6$ children (pointers). Every non-root node must be at least half full:

- **Internal node:** at least $\lceil 6/2 \rceil = 3$ children, which means at least $3 - 1 = 2$ keys.
- **Leaf node:** at least $\lceil 5/2 \rceil = 3$ keys.

The smallest number of keys over all non-root nodes is therefore $2$ (in internal nodes): (B).

- (A) $1$ would allow an internal node with only $2$ children, which is below half full.
- (C) $3$ is the minimum for a **leaf**, not for every non-root node.
- (D) $4$ is too high for any minimum: it is almost full.

**Key idea:** a non-root internal node needs at least $\lceil m/2 \rceil$ children (here $m = 6$), so at least $\lceil m/2 \rceil - 1 = 2$ keys.

</details>
