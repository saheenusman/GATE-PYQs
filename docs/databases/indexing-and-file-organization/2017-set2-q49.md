# 2017 CS2 Q49: Maximum order of a B+ tree for 512-byte blocks

## Question

In a B+ tree, if the search-key value is 8 bytes long, the block size is 512 bytes and the block pointer size is 2 bytes, then the maximum order of the B+ tree is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**52**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Order of a B+ tree.** The order $n$ is the maximum number of **block pointers** in a node. An internal node with $n$ pointers holds $n - 1$ search keys, and the node must fit in one block:

$$n \times 2 + (n-1) \times 8 \le 512.$$

$$10n - 8 \le 512 \;\Rightarrow\; 10n \le 520 \;\Rightarrow\; n \le 52.$$

The maximum order is $n = 52$.

**Check:** $n = 52$ uses $52\cdot2 + 51\cdot8 = 104 + 408 = 512$ bytes (full block); $n = 53$ would need $522$ bytes.

**Code check:** a loop over $n$ confirmed the largest $n$ with $2n + 8(n-1) \le 512$ is 52.

**Status note:** the question gives only a block-pointer size, so the standard internal-node layout (pointers and keys only) is used. This matches the official key.

**Key idea:** $n \cdot (\text{pointer size}) + (n-1)\cdot(\text{key size}) \le \text{block size}$.

</details>
