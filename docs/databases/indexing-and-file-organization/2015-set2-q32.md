# 2015 CS2 Q32: Nodes fetched for a range query on a B+ tree

## Question

With reference to the B+ tree index of order 1 shown below, the minimum number of nodes (including the Root node) that must be fetched in order to satisfy the following query: "Get all records with a search key greater than or equal to 7 and less than 15" is ______.

![B+ tree. The root holds 9. Its left child holds 5 and its right child holds 13 and 17. The leaf level, linked left to right, holds the nodes [1, 3], [5, 7], [9, 11], [13, 15] and [17].](../../assets/2015/set2-q32.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Descend to the leaf holding the first key in range (7), then follow the **leaf links** to the right until the keys reach 15.

| Step | Node fetched |
|---|---|
| 1 | root $[9]$ ($7 < 9$, go left) |
| 2 | internal $[5]$ ($7 \ge 5$, go right) |
| 3 | leaf $[5, 7]$ (contains 7) |
| 4 | leaf $[9, 11]$ (next leaf, holds 9 and 11) |
| 5 | leaf $[13, 15]$ (holds 13; 15 is excluded) |

The next leaf $[17]$ is not needed, because the leaf $[13, 15]$ already shows that keys have reached 15.

Total: **5** nodes.

**Key idea:** a B+ tree range query costs one root-to-leaf descent plus a walk along the linked leaves.

</details>
