# 2007 CS Q63: Order of a leaf node in a B+-tree

## Question

The order of a leaf node in a $B^+$-tree is the maximum number of (value, data record pointer) pairs it can hold. Given that the block size is 1K bytes, data record pointer is 7 bytes long, the value field is 9 bytes long and a block pointer is 6 bytes long, what is the order of the leaf node?

- (A) 63
- (B) 64
- (C) 67
- (D) 68

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A leaf node holds $n$ (value, record pointer) pairs plus **one block pointer** (to the next leaf). It must fit in a block of $1024$ bytes:
$$n(9 + 7) + 6 \le 1024 \;\Rightarrow\; 16n \le 1018 \;\Rightarrow\; n \le 63.6.$$

So the order is $63$: (A).

- (B) 64 comes from $1024/16$, forgetting the 6-byte block pointer ($64 \cdot 16 + 6 = 1030 > 1024$).
- (C) and (D) come from mixing in the wrong field sizes. For example $\lfloor 1024/15 \rfloor = 68$ uses only value + block pointer.

**Code check:** Python: the largest $n$ with $16n + 6 \le 1024$ is $63$.

**Key idea:** a leaf holds $n$ (value, record pointer) pairs and one next-leaf block pointer: $n(V + P_r) + P_b \le B$.
