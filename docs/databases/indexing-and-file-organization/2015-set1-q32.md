# 2015 CS1 Q32: Name of an index whose order matches the data file's order

## Question

A file is organized so that the ordering of data records is the same as or close to the ordering of data entries in some index. Then that index is called

- (A) Dense
- (B) Sparse
- (C) Clustered
- (D) Unclustered

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An index is **clustered** when the physical order of the data records matches (or nearly matches) the order of the index entries.

- (A) *Dense* means an index entry for every record, which says nothing about record order.
- (B) *Sparse* means an entry for only some records (one per block).
- (D) *Unclustered* is the opposite case: the record order is unrelated to the index order.

**Key idea:** clustered $=$ the data file is sorted (or nearly) on the index key.

</details>
