# 2019 CS2 Q24: Incorrect statement about B+ trees

## Question

Which one of the following statements is NOT correct about the B+ tree data structure used for creating an index of a relational database table?

- (A) B+ Tree is a height-balanced tree
- (B) Non-leaf nodes have pointers to data records
- (C) Key values in each node are kept in sorted order
- (D) Each leaf node has a pointer to the next leaf node

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a B+ tree, **only the leaf nodes** point to data records. Non-leaf (internal) nodes hold keys and child pointers, used only to guide the search. So (B) is the incorrect statement.

**The others are correct:**

- (A) All leaves are at the same depth.
- (C) Keys inside each node are kept sorted.
- (D) Leaves are chained, which makes range scans fast.

**Key idea:** B+ trees keep data pointers in leaves only. B-trees are the ones that store them in internal nodes too.

</details>
