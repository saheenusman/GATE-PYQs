# 2025 CS2 Q57: Parent key after splitting a B+ tree leaf

## Question

In a $B^+$-tree where each node can hold at most four key values, a root to leaf path consists of the following nodes:

$A = (49, 77, 83, -)$, $B = (7, 19, 33, 44)$, $C = (20^*, 22^*, 25^*, 26^*)$

The $*$-marked keys signify that these are data entries in a leaf.

Assume that a pointer between keys $k_1$ and $k_2$ points to a subtree containing keys in $[k_1, k_2)$, and that when a leaf is created, the smallest key in it is copied up into its parent.

A record with key value 23 is inserted into the $B^+$-tree.

The smallest key value in the parent of the leaf that contains $25^*$ is __________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**33**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Where 23 goes.** Node $A$ sends keys in $[19, 33)$ down through $B$ to leaf $C$ (the pointer between 19 and 33 of $B$). So 23 goes into $C = (20,22,25,26)$, which is **full**.

**Step 1: split the leaf.** The five keys $20, 22, 23, 25, 26$ split into $(20, 22)$ and $(23, 25, 26)$. The smallest key of the new leaf, **23**, is copied up into $B$.

**Step 2: $B$ overflows.** $B$ would have five keys $7, 19, 23, 33, 44$, but holds at most four. It splits, and the middle key **23** moves up into $A$ (which has room, since $A$ has only three keys):

$$B_1 = (7, 19), \qquad B_2 = (33, 44), \qquad A = (23, 49, 77, 83).$$

**Step 3: find the parent of the leaf containing $25^*$.** Leaf $(23, 25, 26)$ holds keys in $[23, 33)$. That range lies to the left of 33 in the new node $B_2 = (33, 44)$, so its parent is $B_2$.

The smallest key of $B_2$ is **33**.

If the leaf were split as $(20,22,23)$ and $(25,26)$ instead, the key copied up would be 25. $B$ would then split around 25 with the same result $B_2 = (33, 44)$, so the answer is 33 either way.

**Key idea:** a leaf split copies a key up, and a full internal node splits by *moving* its middle key up. Track which new node covers the range that holds the key.

</details>
