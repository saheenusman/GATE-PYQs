# 2008 CS Q16: Fields on which a clustering index is defined

## Question

A clustering index is defined on the fields which are of type

- (A) non-key and ordering
- (B) non-key and non-ordering
- (C) key and ordering
- (D) key and non-ordering

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The file is **physically ordered** on the indexing field, and that field is **not a key**, so many records can share a value; the index points to the first block of each group (cluster) of equal values.

| Index type | Indexing field |
|---|---|
| Primary index | key, ordering |
| **Clustering index** | **non-key, ordering** |
| Secondary index | non-ordering (key or non-key) |

So a clustering index is on a non-key, ordering field: (A).

- (B) and (D) describe fields the file is not ordered on, which is the case for a secondary index.
- (C) is a primary index.

**Key idea:** clustering index = ordered file + non-key field; primary = ordered + key; secondary = not ordered.

</details>
