# 2015 CS3 Q39: Maximum keys in a non-leaf node of a B+ tree

## Question

Consider a B+ tree in which the search key is 12 bytes long, block size is 1024 bytes, record pointer is 10 bytes long and block pointer is 8 bytes long. The maximum number of keys that can be accommodated in each non-leaf node of the tree is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**50**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A non-leaf node with $n$ keys has $n + 1$ block pointers. It must fit in one block:

$$12\,n + 8\,(n+1) \le 1024 \;\Rightarrow\; 20n \le 1016 \;\Rightarrow\; n \le 50.8$$

So the maximum is $n = 50$.

**Answer: 50.**

The 10-byte record pointer is used only in **leaf** nodes, so it does not enter this calculation.

**Check:** $12 \times 50 + 8 \times 51 = 600 + 408 = 1008 \le 1024$, while $n = 51$ gives $612 + 416 = 1028 > 1024$.

**Key idea:** internal node: $n$ keys $+$ $(n+1)$ block pointers. Leaf node: keys plus record pointers.

</details>
