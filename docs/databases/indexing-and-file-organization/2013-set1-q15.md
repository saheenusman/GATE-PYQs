# 2013 CS Q15: Clustered index

## Question

An index is clustered, if

- (A) it is on a set of fields that form a candidate key.
- (B) it is on a set of fields that include the primary key.
- (C) the data records of the file are organized in the same order as the data entries of the index.
- (D) the data records of the file are organized not in the same order as the data entries of the index.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Definition.** A clustered index is one where the physical order of the data records matches the order of the index's data entries (its search key order). There can be at most one clustered index per file.

**Why the others fail:**

- (A), (B) describe keys; any index (clustered or not) can be built on a candidate key or on a set containing the primary key.
- (D) is the definition of an **unclustered** (secondary) index.

**Key idea:** clustered means record order equals index order.

</details>
