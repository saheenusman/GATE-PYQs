# 2014 CS2 Q46: Newton-Raphson oscillation

## Question

In the Newton-Raphson method, an initial guess of $x_0 = 2$ is made and the sequence $x_0, x_1, x_2, \ldots$ is obtained for the function

$$0.75x^3 - 2x^2 - 2x + 4 = 0$$

Consider the statements

- (I) $x_3 = 0$.
- (II) The method converges to a solution in a finite number of iterations.

Which of the following is TRUE?

- (A) Only I
- (B) Only II
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Newton-Raphson: $x_{n+1} = x_n - f(x_n)/f'(x_n)$ with

$$f(x) = 0.75x^3 - 2x^2 - 2x + 4, \qquad f'(x) = 2.25x^2 - 4x - 2.$$

| $n$ | $x_n$ | $f(x_n)$ | $f'(x_n)$ | $x_{n+1}$ |
|---|---|---|---|---|
| 0 | 2 | $-2$ | $-1$ | 0 |
| 1 | 0 | 4 | $-2$ | 2 |
| 2 | 2 | $-2$ | $-1$ | 0 |

The sequence is $2, 0, 2, 0, \ldots$ and cycles forever.

- (I) $x_3 = 0$: **true**.
- (II) false: the iterates oscillate, so the method never converges.

So only I is true: **A**.

**Code check:** running 8 iterations in Python gives $2, 0, 2, 0, 2, 0, 2, 0, 2$.

**Classification flag:** numerical methods have no topic of their own. Filed under `differentiation-and-optimization` as the nearest calculus topic (the method uses $f'$).

**Key idea:** Newton-Raphson can fall into a cycle instead of converging; trace the iterates.

</details>
