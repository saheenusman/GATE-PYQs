# 2024 CS1 Q11: Non-differentiable points of max(x, x³)

## Question

Let $f : \mathbb{R} \to \mathbb{R}$ be a function such that $f(x) = \max\lbrace x, x^3 \rbrace$, $x \in \mathbb{R}$, where $\mathbb{R}$ is the set of all real numbers. The set of all points where $f(x)$ is NOT differentiable is

- (A) $\lbrace -1, 1, 2 \rbrace$
- (B) $\lbrace -2, -1, 1 \rbrace$
- (C) $\lbrace 0, 1 \rbrace$
- (D) $\lbrace -1, 0, 1 \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$f$ is a maximum of two smooth functions, so it can fail to be differentiable only where the two curves cross.

**Crossings:** $x = x^3 \Rightarrow x(x-1)(x+1) = 0 \Rightarrow x = -1, 0, 1$.

**Which branch is larger?**

| Interval | Larger of $x$ and $x^3$ | Slope |
|---|---|---|
| $x < -1$ | $x$ | 1 |
| $-1 < x < 0$ | $x^3$ | $3x^2$ |
| $0 < x < 1$ | $x$ | 1 |
| $x > 1$ | $x^3$ | $3x^2$ |

**Compare the slopes on both sides of each crossing:**

| Point | Left slope | Right slope | Differentiable? |
|---|---|---|---|
| $-1$ | 1 | 3 | No |
| $0$ | 0 | 1 | No |
| $1$ | 1 | 3 | No |

The one-sided slopes differ at all three points, so $f$ has corners at $-1, 0, 1$.

**Key idea:** a max of two functions has a corner wherever they cross with different slopes.

</details>
