# 2020 CS Q11: Which functions are increasing everywhere on [0,1]

## Question

Consider the functions

- I. $e^{-x}$
- II. $x^2 - \sin x$
- III. $\sqrt{x^3 + 1}$

Which of the above functions is/are increasing everywhere in $[0,1]$?

- (A) III only
- (B) II only
- (C) II and III only
- (D) I and III only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A function is increasing on an interval if its derivative is $\ge 0$ everywhere on it. Check each derivative.

| Function | Derivative | On $[0,1]$ |
|---|---|---|
| I. $e^{-x}$ | $-e^{-x}$ | always negative, so **decreasing** |
| II. $x^2 - \sin x$ | $2x - \cos x$ | equals $-1$ at $x=0$, so **decreases near 0** |
| III. $\sqrt{x^3+1}$ | $\dfrac{3x^2}{2\sqrt{x^3+1}}$ | $\ge 0$ (zero only at $x=0$), so **increasing** |

**Function II in detail.** At $x = 0$ the derivative is $0 - \cos 0 = -1 < 0$. Concretely, $f(0) = 0$ but $f(0.2) = 0.04 - \sin 0.2 \approx -0.159$, so the function has already dropped. It starts increasing only later, where $2x = \cos x$ (near $x \approx 0.45$), so it is not increasing *everywhere* on $[0,1]$.

I also checked all three numerically on a fine grid over $[0,1]$: only III never decreases.

**Why the others fail:** I and II each decrease somewhere on $[0,1]$, so every option containing I or II is wrong. Only (A) contains III alone.

**Key idea:** "increasing everywhere on an interval" means $f'(x) \ge 0$ at *every* point. One bad stretch, like II near 0, rules the function out.

</details>
