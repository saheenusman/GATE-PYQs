# 2008 CS Q25: Number of extrema of a quartic curve

## Question

A point on a curve is said to be an extremum if it is a local minimum or a local maximum. The number of distinct extrema for the curve $3x^4 - 16x^3 + 24x^2 + 37$ is

- (A) 0
- (B) 1
- (C) 2
- (D) 3

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$$f'(x) = 12x^3 - 48x^2 + 48x = 12x(x - 2)^2.$$

The stationary points are $x = 0$ and $x = 2$. Check the **sign of $f'$** around each:

| Interval | $x < 0$ | $0 < x < 2$ | $x > 2$ |
|---|---|---|---|
| Sign of $12x(x-2)^2$ | $-$ | $+$ | $+$ |

- At $x = 0$ the sign changes from $-$ to $+$: a local **minimum**.
- At $x = 2$ the factor $(x-2)^2$ does not change sign, so $f'$ stays positive: **not** an extremum (a stationary point of inflection).

So there is exactly **one** extremum: (B).

- (C) counts $x = 2$, and (D) counts a nonexistent third point. (A) forgets $x = 0$.

**Code check:** $f'$ evaluated at $-1, 1, 1.9, 2.1, 3$ has signs $-,+,+,+,+$, and $12x(x-2)^2$ matched $f'$ numerically.

**Key idea:** a stationary point is an extremum only if the first derivative changes sign there; a double root does not.

</details>
