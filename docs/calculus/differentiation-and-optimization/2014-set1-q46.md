# 2014 CS1 Q46: Value of t with f(x) = x sin x

## Question

The function $f(x) = x\sin x$ satisfies the following equation: $f''(x) + f(x) + t\cos x = 0$. The value of $t$ is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**-2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$$f'(x) = \sin x + x\cos x$$

$$f''(x) = \cos x + \cos x - x\sin x = 2\cos x - x\sin x$$

Put into the equation:

$$2\cos x - x\sin x + x\sin x + t\cos x = (2 + t)\cos x = 0$$

This holds for all $x$ only if $2 + t = 0$, so $t = -2$.

**Code check:** `sympy` simplifies $f'' + f + t\cos x$ to `(t + 2)*cos(x)`.

**Key idea:** differentiate twice with the product rule; the $x\sin x$ terms cancel.

</details>
