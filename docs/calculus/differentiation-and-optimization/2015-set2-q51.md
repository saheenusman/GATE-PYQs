# 2015 CS2 Q51: Missing expression in the secant method

## Question

The secant method is used to find the root of an equation $f(x) = 0$. It is started from two distinct estimates $x_a$ and $x_b$ for the root. It is an iterative procedure involving linear interpolation to a root. The iteration stops if $f(x_b)$ is very small and then $x_b$ is the solution. The procedure is given below. Observe that there is an expression which is missing and is marked by `?`. Which is the suitable expression that is to be put in place of `?` so that it follows all steps of the secant method?

```
Secant
Initialize: xa, xb, eps, N   // eps = convergence indicator
                             // N = maximum no. of iterations
fb = f(xb)
i = 0
while (i < N and |fb| > eps) do
    i = i + 1                // update counter
    xt = ?                   // missing expression for
                             // intermediate value
    xa = xb                  // reset xa
    xb = xt                  // reset xb
    fb = f(xb)               // function value at new xb
end while
if |fb| > eps then           // loop is terminated with i=N
    write "Non-convergence"
else
    write "return xb"
end if
```

- (A) $x_b - (f_b - f(x_a))\, f_b / (x_b - x_a)$
- (B) $x_a - (f_a - f(x_a))\, f_a / (x_b - x_a)$
- (C) $x_b - (x_b - x_a)\, f_b / (f_b - f(x_a))$
- (D) $x_a - (x_b - x_a)\, f_a / (f_b - f(x_a))$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The next estimate is where the straight line through $(x_a, f(x_a))$ and $(x_b, f_b)$ crosses the $x$-axis. Starting from the newest point $x_b$:

$$x_t = x_b - f_b \cdot \frac{x_b - x_a}{f_b - f(x_a)}$$

The fraction is the reciprocal of the slope, so it is $\Delta x / \Delta f$. This is option (C).

- (A) multiplies by $\Delta f / \Delta x$, which is the slope itself, not its reciprocal.
- (B) has $f_a - f(x_a) = 0$ in the numerator, so $x_t = x_a$ and the iteration never moves. It also uses $f_a$, which the procedure never stores.
- (D) uses $f_a$ too. The procedure only keeps $f_b$.

**Code check:** for $f(x) = x^3 - 2x - 5$ with $x_a = 2$, $x_b = 3$: (C) gives $2.0588$, (A) gives $-269$, (B) gives $2$. Running (C) for 8 iterations converges to $2.09455$, the true root.

**Note on (D).** If $f_a$ were read as $f(x_a)$, (D) would be the same line's root (it gave $2.0588$ as well), since the line crosses the axis at one point whichever end you start from. The key rules it out because the pseudo-code defines no $f_a$ and keeps only $f_b$.

**Key idea:** secant step $x_{n+1} = x_n - f(x_n)\,\dfrac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}$.

</details>
