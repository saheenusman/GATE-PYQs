# 2012 CS Q9: Local minima of sin(x) on a closed interval

## Question

Consider the function $f(x) = \sin(x)$ in the interval $x \in [\pi/4,\, 7\pi/4]$. The number and location(s) of the local minima of this function are

- (A) One, at $\pi/2$
- (B) One, at $3\pi/2$
- (C) Two, at $\pi/2$ and $3\pi/2$
- (D) Two, at $\pi/4$ and $3\pi/2$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$f'(x) = \cos x$ is zero at $\pi/2$ and $3\pi/2$ inside the interval.

| Point | $f$ | Behaviour |
|---|---|---|
| $\pi/4$ (left end) | $0.707$ | rises to the right: **local min** |
| $\pi/2$ | $1$ | **local max** |
| $3\pi/2$ | $-1$ | **local min** |
| $7\pi/4$ (right end) | $-0.707$ | rises from the left: local max |

So the local minima are at $\pi/4$ and $3\pi/2$: (D).

This counts an end point as a local minimum of $f$ restricted to the interval, which is how the key reads it. If end points were excluded the answer would be (B), so the question depends on this convention.

- (A), (C) treat $\pi/2$ as a minimum; it is a maximum ($f'' = -\sin x < 0$).
- (B) misses the end point $\pi/4$.

**Code check:** a scan of $\sin x$ on a fine grid over the interval found local minima at $x/\pi = 0.25$ and $1.5$.

**Key idea:** on a closed interval, check the end points as well as the critical points.

</details>
