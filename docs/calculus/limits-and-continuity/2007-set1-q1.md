# 2007 CS Q1: Continuity and differentiability of |x|

## Question

Consider the following two statements about the function $f(x) = |x|$:

- P. $f(x)$ is continuous for all real values of $x$
- Q. $f(x)$ is differentiable for all real values of $x$

Which of the following is **TRUE**?

- (A) P is true and Q is false.
- (B) P is false and Q is true.
- (C) Both P and Q are true.
- (D) Both P and Q are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**P (continuity).** $|x|$ is a composition of continuous functions, and at $0$: $\lim_{x\to0^-}|x| = \lim_{x\to0^+}|x| = 0 = f(0)$. So P is true.

**Q (differentiability).** At $x = 0$ the one-sided derivatives are
$$\lim_{h\to0^+}\frac{|h|}{h} = 1,\qquad \lim_{h\to0^-}\frac{|h|}{h} = -1.$$
They differ, so $f'(0)$ does not exist. Q is false.

So P true, Q false: (A).

- (B) has it backwards: differentiable implies continuous, so Q true and P false is impossible.
- (C) fails because of the corner at $0$.
- (D) fails because P is true.
