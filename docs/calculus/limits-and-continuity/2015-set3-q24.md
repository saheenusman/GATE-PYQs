# 2015 CS3 Q24: Limit of (1 + x squared) to the power e to the minus x

## Question

The value of $\displaystyle\lim_{x \to \infty} (1 + x^2)^{e^{-x}}$ is

- (A) $0$
- (B) $\dfrac12$
- (C) $1$
- (D) $\infty$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

This is of the form $\infty^0$. Take the logarithm:

$$\ln L = \lim_{x\to\infty} e^{-x}\ln(1+x^2) = \lim_{x\to\infty}\frac{\ln(1+x^2)}{e^x}$$

By L'Hôpital's rule:

$$\lim \frac{2x/(1+x^2)}{e^x} = 0$$

So $\ln L = 0$ and $L = e^0 = 1$. Option (C).

**Code check:** a symbolic limit gives $1$.

**Key idea:** an exponential grows faster than any logarithm, so $e^{-x}\ln(1+x^2) \to 0$ and the power tends to $1$.

</details>
