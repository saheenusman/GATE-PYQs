# 2015 CS1 Q12: Limit of x to the power 1/x as x tends to infinity

## Question

$\lim_{x \to \infty} x^{1/x}$ is

- (A) $\infty$
- (B) 0
- (C) 1
- (D) Not defined

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write $x^{1/x} = e^{(\ln x)/x}$.

As $x \to \infty$, $\dfrac{\ln x}{x} \to 0$ (a logarithm grows slower than any positive power). So

$$\lim_{x\to\infty} x^{1/x} = e^0 = 1$$

- (A) $\infty$: the base grows but the exponent shrinks to 0, and the exponent wins.
- (B) $0$: $x^{1/x} > 1$ for $x > 1$, so it never goes below 1.
- (D) the limit exists.

**Key idea:** take logs; $\ln x / x \to 0$, so the form $\infty^0$ tends to $1$.

</details>
