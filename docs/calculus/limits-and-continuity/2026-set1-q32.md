# 2026 CS1 Q32: Continuity at a point with a log term

## Question

Consider the function $f: \mathbb{R} \to \mathbb{R}$ defined as follows:

$$f(x) = \begin{cases} c_1 e^{x} - c_2 \log_e\!\left(\dfrac{1}{x}\right), & \text{if } x > 0 \\[2mm] 3, & \text{otherwise} \end{cases}$$

where $c_1, c_2 \in \mathbb{R}$. If $f$ is continuous at $x = 0$, then $c_1 + c_2 = $ ________. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Continuity at 0** needs $\lim_{x \to 0^+} f(x) = f(0) = 3$. (From the left, $f$ is constant 3, so that side is fine.)

**Right-hand limit:**

$$\lim_{x \to 0^+}\left[c_1 e^x - c_2 \ln\tfrac{1}{x}\right]$$

- $c_1 e^x \to c_1$, which is finite.
- $\ln\frac{1}{x} \to +\infty$ as $x \to 0^+$.

For the limit to be finite, the infinite term must vanish, so **$c_2 = 0$**. Then the limit is $c_1$, and $c_1 = 3$.

$c_1 + c_2 = 3 + 0 = \mathbf{3}$.

**Why $c_2 \ne 0$ fails:** the expression would go to $-\infty$ (if $c_2 > 0$) or $+\infty$ (if $c_2 < 0$), never to 3.

**Key idea:** continuity needs a finite limit equal to the function value. Unbounded terms like $\ln(1/x)$ must have zero coefficient.

</details>
