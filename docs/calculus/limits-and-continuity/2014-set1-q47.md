# 2014 CS1 Q47: Intermediate value theorem on [0,2] with f(0)=f(2)=-1, f(1)=1

## Question

A function $f(x)$ is continuous in the interval $[0,2]$. It is known that $f(0) = f(2) = -1$ and $f(1) = 1$. Which one of the following statements must be true?

- (A) There exists a $y$ in the interval $(0,1)$ such that $f(y) = f(y+1)$
- (B) For every $y$ in the interval $(0,1)$, $f(y) = f(2-y)$
- (C) The maximum value of the function in the interval $(0,2)$ is 1
- (D) There exists a $y$ in the interval $(0,1)$ such that $f(y) = -f(2-y)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A** (official key); **D** also follows

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Disputed.** The official key is **A**, but my working shows that **D** must also be true.

**A (key).** Let $g(y) = f(y) - f(y+1)$. It is continuous on $[0,1]$, with $g(0) = f(0) - f(1) = -2$ and $g(1) = f(1) - f(2) = 2$. By the intermediate value theorem $g(y) = 0$ for some $y \in (0,1)$. True.

**D (also true).** Let $h(y) = f(y) + f(2-y)$. It is continuous on $[0,1]$, with $h(0) = f(0) + f(2) = -2$ and $h(1) = 2f(1) = 2$. So $h(y) = 0$ for some $y \in (0,1)$, which is $f(y) = -f(2-y)$. True.

**B and C are not forced.**

- (B) needs $f$ symmetric about $x=1$. A piecewise-linear $f$ through $(0,-1), (0.5, 0), (1,1), (1.5,-1), (2,-1)$ has $f(0.5) = 0 \ne f(1.5) = -1$.
- (C) $f$ may rise above 1 near $x = 1$, for example a peak of 2 at $x = 0.9$.

**Code check:** for 200 random continuous piecewise-linear $f$ satisfying the three conditions, both $g$ and $h$ had a zero in $(0,1)$ every time.

I have not chosen between A and D. The key answer is A, but D follows from the same theorem.

**Key idea:** apply the intermediate value theorem to a continuous difference or sum with opposite signs at the ends.

</details>
