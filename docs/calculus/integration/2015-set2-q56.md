# 2015 CS2 Q56: Continuity, boundedness and area of x to the power -1/3

## Question

Let $f(x) = x^{-(1/3)}$ and $A$ denote the area of the region bounded by $f(x)$ and the X-axis, when $x$ varies from $-1$ to $1$. Which of the following statements is/are TRUE?

- (I) $f$ is continuous in $[-1, 1]$
- (II) $f$ is not bounded in $[-1, 1]$
- (III) $A$ is nonzero and finite

- (A) II only
- (B) III only
- (C) II and III only
- (D) I, II and III

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Take $x^{1/3}$ as the real cube root, so $f$ is defined for negative $x$ too.

**(I) False.** $f(0)$ is undefined ($1/0$), so $f$ is not continuous on $[-1,1]$.

**(II) True.** As $x \to 0$, $|f(x)| \to \infty$. For example $f(10^{-6}) = 100$ and $f(10^{-12}) = 10^4$.

**(III) True.** The area uses $|f|$, which is symmetric about 0:

$$A = 2\int_0^1 x^{-1/3}\,dx = 2\left[\tfrac{3}{2}x^{2/3}\right]_0^1 = 3$$

The integral is improper at $0$ but converges (the exponent $-1/3 > -1$).

So II and III: option (C). (A) misses III. (B) misses II. (D) includes I.

**Code check:** a symbolic integration gives $A = 3$.

**Careful.** The *signed* integral of $f$ over $[-1,1]$ is $0$ (odd function, principal value). The area is not that integral: it is $\int |f|$, which is $3$.

**Key idea:** $\int_0^1 x^{-p}\,dx$ converges iff $p < 1$. An unbounded function can still enclose a finite area.

</details>
