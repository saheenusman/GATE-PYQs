# 2014 CS3 Q6: Definite integral of |x sin x| over [0, 2pi]

## Question

If $\displaystyle\int_0^{2\pi} |x \sin x|\, dx = k\pi$, then the value of $k$ is equal to ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$\sin x \ge 0$ on $[0,\pi]$ and $\sin x \le 0$ on $[\pi, 2\pi]$, and $x > 0$, so we split at $\pi$.

An antiderivative of $x \sin x$ is $F(x) = -x\cos x + \sin x$ (integration by parts).

- $\int_0^\pi x\sin x\,dx = F(\pi) - F(0) = \pi - 0 = \pi$.
- $\int_\pi^{2\pi} |x \sin x|\,dx = -\big(F(2\pi) - F(\pi)\big) = -(-2\pi - \pi) = 3\pi$.

Total $= \pi + 3\pi = 4\pi$, so $k = 4$.

**Code check:** numerical integration (SciPy `quad`, split at $\pi$) gives $4.0000 \times \pi$.

**Key idea:** split the integral where the integrand changes sign before removing the absolute value.

</details>
