# 2011 CS Q31: Definite integral of a ratio of complex exponentials

## Question

Given $i = \sqrt{-1}$, what will be the evaluation of the definite integral $\displaystyle\int_0^{\pi/2} \frac{\cos x + i \sin x}{\cos x - i \sin x}\, dx$ ?

- (A) $0$
- (B) $2$
- (C) $-i$
- (D) $i$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

By Euler's formula $\cos x + i \sin x = e^{ix}$ and $\cos x - i \sin x = e^{-ix}$, so the integrand is

$$\frac{e^{ix}}{e^{-ix}} = e^{2ix}.$$

$$\int_0^{\pi/2} e^{2ix}\,dx = \left[\frac{e^{2ix}}{2i}\right]_0^{\pi/2} = \frac{e^{i\pi} - 1}{2i} = \frac{-2}{2i} = -\frac{1}{i} = i$$

since $\dfrac{1}{i} = -i$. So (D).

- (A) $0$ would need the integral of $\cos 2x + i \sin 2x$ to cancel, but the imaginary part $\int_0^{\pi/2} \sin 2x\,dx = 1$.
- (B) $2$ and (C) $-i$ are not the value $i$ found above.

**Code check:** a numerical trapezoid integration over $[0, \pi/2]$ gave $1.0$ in the imaginary part and $0$ in the real part, that is $i$.

**Key idea:** the integrand is e^{2ix}; integrate it like an ordinary exponential and use e^{i pi} = -1.

</details>
