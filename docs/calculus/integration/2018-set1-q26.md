# 2018 CS Q26: Integral of x cos(x squared) from 0 to pi/4

## Question

The value of $\displaystyle\int_0^{\pi/4} x\cos(x^2)\,dx$ correct to three decimal places (assuming that $\pi = 3.14$) is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**0.27 to 0.30**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Substitute** $u = x^2$, so $du = 2x\,dx$. The limits become $0$ and $\pi^2/16$:

$$\int_0^{\pi/4} x\cos(x^2)\,dx = \frac12\int_0^{\pi^2/16}\cos u\,du = \frac12\sin\!\left(\frac{\pi^2}{16}\right)$$

**Numbers with $\pi = 3.14$:** $\pi^2 = 9.8596$, so $\pi^2/16 = 0.616225$, and $\sin(0.616225) = 0.57796$.

$$\frac12(0.57796) \approx 0.289$$

The key's range is 0.27 to 0.30.

**Code check:** Simpson's rule on the original integral gave 0.28898; the closed form gave the same.

**Key idea:** $x\,dx$ is half of $d(x^2)$, so the substitution $u=x^2$ removes the $x$ factor.

</details>
