# 2015 CS3 Q54: Integral of f from a functional equation with f(x) and f(1/x)

## Question

If for non-zero $x$, $a f(x) + b f\!\left(\dfrac1x\right) = \dfrac1x - 25$ where $a \ne b$ then $\displaystyle\int_1^2 f(x)\,dx$ is

- (A) $\dfrac{1}{a^2 - b^2}\left[a(\ln 2 - 25) + \dfrac{47b}{2}\right]$
- (B) $\dfrac{1}{a^2 - b^2}\left[a(2\ln 2 - 25) - \dfrac{47b}{2}\right]$
- (C) $\dfrac{1}{a^2 - b^2}\left[a(2\ln 2 - 25) + \dfrac{47b}{2}\right]$
- (D) $\dfrac{1}{a^2 - b^2}\left[a(\ln 2 - 25) - \dfrac{47b}{2}\right]$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find $f(x)$.** Write the equation, and the same equation with $x$ replaced by $1/x$:

$$(1)\quad a f(x) + b f(1/x) = \tfrac1x - 25$$
$$(2)\quad a f(1/x) + b f(x) = x - 25$$

Multiply (1) by $a$ and (2) by $b$, then subtract to remove $f(1/x)$:

$$(a^2 - b^2) f(x) = \frac{a}{x} - 25a - bx + 25b$$

**Integrate from 1 to 2.**

- $\int_1^2 \frac{a}{x}\,dx = a\ln 2$
- $\int_1^2 bx\,dx = \frac{3b}{2}$
- $\int_1^2 25(a - b)\,dx = 25(a - b)$

$$(a^2 - b^2)\int_1^2 f = a\ln 2 - \frac{3b}{2} - 25a + 25b = a(\ln 2 - 25) + \frac{47b}{2}$$

since $25 - \tfrac32 = \tfrac{47}{2}$. Option (A).

- (B) and (C) have $2\ln 2$, but $\int_1^2 dx/x = \ln 2$.
- (D) has the wrong sign on the $47b/2$ term.

**Code check:** solving the two equations symbolically and integrating gives exactly option (A).

**Key idea:** substitute $x \to 1/x$ to get a second equation, then solve the pair for $f(x)$.

</details>
