# 2025 CS2 Q12: Solving an integral equation for x

## Question

The value of $x$ such that $x > 1$, satisfying the equation $\displaystyle\int_1^x t\ln t\, dt = \frac14$ is

- (A) $\sqrt e$
- (B) $e$
- (C) $e^2$
- (D) $e^{-1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Integrate by parts with $u = \ln t$ and $dv = t\,dt$:

$$\int t\ln t\,dt = \frac{t^2}{2}\ln t - \int \frac{t^2}{2}\cdot\frac1t\,dt = \frac{t^2}{2}\ln t - \frac{t^2}{4}.$$

Evaluate from 1 to $x$ (at $t = 1$ the value is $0 - \tfrac14$):

$$\int_1^x t\ln t\,dt = \frac{x^2}{2}\ln x - \frac{x^2}{4} + \frac14.$$

Set this equal to $\tfrac14$:

$$\frac{x^2}{2}\ln x - \frac{x^2}{4} = 0 \;\Rightarrow\; \frac{x^2}{4}(2\ln x - 1) = 0.$$

Since $x > 1$, $x^2 \ne 0$, so $\ln x = \tfrac12$ and $x = \sqrt e$.

| Option | Check |
|---|---|
| **A, $\sqrt e$** | $\ln x = \frac12$ |
| B, $e$ | $\ln x = 1$ |
| C, $e^2$ | $\ln x = 2$ |
| D, $e^{-1}$ | Less than 1, excluded by $x>1$ |

A symbolic solver also returns $\sqrt e$.

**Key idea:** use integration by parts for $\int t\ln t\,dt$.

</details>
