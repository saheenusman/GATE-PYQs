# 2009 CS Q25: Integral of (1 - tan x)/(1 + tan x) from 0 to pi/4

## Question

$$\int_0^{\pi/4} \frac{1 - \tan x}{1 + \tan x}\,dx$$

evaluates to

- (A) $0$
- (B) $1$
- (C) $\ln 2$
- (D) $\tfrac{1}{2}\ln 2$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Since $\tan\frac{\pi}{4} = 1$,

$$\frac{1 - \tan x}{1 + \tan x} = \frac{\tan\frac{\pi}{4} - \tan x}{1 + \tan\frac{\pi}{4}\tan x} = \tan\!\left(\frac{\pi}{4} - x\right).$$

Substitute $u = \frac{\pi}{4} - x$; the limits $0 \to \frac{\pi}{4}$ become $\frac{\pi}{4} \to 0$, and $dx = -du$, so

$$\int_0^{\pi/4} \tan\!\left(\frac{\pi}{4} - x\right)dx = \int_0^{\pi/4} \tan u \, du = \big[-\ln\cos u\big]_0^{\pi/4} = -\ln\frac{1}{\sqrt 2} = \frac{1}{2}\ln 2.$$

So (D).

- (A) $0$ is impossible: the integrand is positive on $(0, \pi/4)$.
- (B) $1$ is impossible: the integrand is at most $1$ and the interval has length $\pi/4 < 1$.
- (C) $\ln 2 \approx 0.693$ is twice the true value, $\approx 0.347$.

**Code check:** a midpoint-rule numerical integration with $200000$ steps gave $0.346574$, equal to $\tfrac12 \ln 2 = 0.346574$ (and not $\ln 2 = 0.693147$).

**Key idea:** recognise the tangent subtraction formula, then the substitution $u = \pi/4 - x$ leaves $\int \tan u\,du$.

</details>
