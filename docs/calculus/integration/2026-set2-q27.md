# 2026 CS2 Q27: Definite integral with a parameter

## Question

For a real number $a$, let $I(a) = \displaystyle\int_{-1}^{1}(3x^2 - ax + 1)\,dx$. Which of the following statements is/are true?

- (A) The value of $I(a)$ is independent of the value of $a$
- (B) The value of $I(a)$ can vary with the value of $a$
- (C) There exists $a \in (-\infty, +\infty)$ such that $I(a)$ is a positive real number
- (D) There exists $a \in (-\infty, +\infty)$ such that $I(a)$ is a negative real number

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Compute by parts:**

- $\displaystyle\int_{-1}^{1} 3x^2\,dx = \big[x^3\big]_{-1}^{1} = 2$
- $\displaystyle\int_{-1}^{1} (-ax)\,dx = 0$, because $x$ is an **odd** function and the interval is symmetric.
- $\displaystyle\int_{-1}^{1} 1\,dx = 2$

So $I(a) = 2 + 0 + 2 = 4$ for **every** $a$.

- **(A) True.** The $a$-term vanishes, so $I$ does not depend on $a$.
- **(B) False.** For the same reason.
- **(C) True.** $I(a) = 4 > 0$, so any $a$ works.
- **(D) False.** $I(a)$ is never negative.

**Key idea:** the integral of an odd function over $[-c, c]$ is 0.

</details>
