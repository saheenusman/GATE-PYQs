# 2014 CS3 Q47: Integral of x^2 cos x from 0 to pi

## Question

The value of the integral given below is

$$\int_0^{\pi} x^2 \cos x\, dx$$

- (A) $-2\pi$
- (B) $\pi$
- (C) $-\pi$
- (D) $2\pi$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Integrate by parts twice. An antiderivative of $x^2\cos x$ is

$$F(x) = x^2 \sin x + 2x\cos x - 2\sin x.$$

(Check: $F'(x) = 2x\sin x + x^2\cos x + 2\cos x - 2x\sin x - 2\cos x = x^2 \cos x$.)

$$F(\pi) = 0 + 2\pi(-1) - 0 = -2\pi, \qquad F(0) = 0.$$

$$\int_0^\pi x^2\cos x\,dx = F(\pi) - F(0) = -2\pi.$$

**Code check:** SymPy returns `-2*pi`.

**Key idea:** repeated integration by parts: $\int x^2\cos x = x^2\sin x - \int 2x \sin x$.

</details>
