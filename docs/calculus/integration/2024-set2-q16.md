# 2024 CS2 Q16: Integral of a function with f(x) + f(2−x) = 1

## Question

Let $f(x)$ be a continuous function from $\mathbb{R}$ to $\mathbb{R}$ such that

$$f(x) = 1 - f(2 - x).$$

Which one of the following options is the CORRECT value of $\displaystyle\int_0^2 f(x)\,dx$ ?

- (A) 0
- (B) 1
- (C) 2
- (D) $-1$

<details class="success" markdown="1">
<summary>Answer</summary>

**B (1)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $I = \int_0^2 f(x)\,dx$.

**Substitute $x \to 2 - x$:** the limits $0$ and $2$ swap back to themselves, so

$$I = \int_0^2 f(2 - x)\,dx.$$

**Add the two forms of $I$:**

$$2I = \int_0^2 \big[f(x) + f(2-x)\big]\,dx = \int_0^2 1\,dx = 2 \Rightarrow I = 1.$$

**Check with examples.** $f(x) = \tfrac{1}{2}$ and $f(x) = \tfrac{x}{2}$ both satisfy the condition and both integrate to 1 over $[0, 2]$.

**Key idea:** use the symmetry $x \to a - x$ on $[0, a]$ and add the two integrals.

</details>
