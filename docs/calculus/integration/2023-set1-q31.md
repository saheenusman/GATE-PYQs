# 2023 CS Q31: Triple integral of an odd integrand

## Question

The value of the definite integral

$$\int_{-3}^{3}\int_{-2}^{2}\int_{-1}^{1} \left(4x^2 y - z^3\right) dz\, dy\, dx$$

is ______. (Rounded off to the nearest integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split the integral.**

$$\int\!\!\int\!\!\int 4x^2 y\; dz\,dy\,dx \;-\; \int\!\!\int\!\!\int z^3\; dz\,dy\,dx$$

- First part: $\int_{-2}^{2} y\,dy = 0$ because $y$ is an **odd** function over a symmetric range. So the whole term is 0.
- Second part: $\int_{-1}^{1} z^3\,dz = 0$ for the same reason.

Total: $0 - 0 = \mathbf{0}$.

**Code check:** `sympy` evaluated the iterated integral to 0.

**Key idea:** odd integrands over symmetric limits integrate to zero.

</details>
