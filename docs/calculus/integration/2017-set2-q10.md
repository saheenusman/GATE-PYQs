# 2017 CS2 Q10: Constants R and S from f'(1/2) and the integral of f

## Question

If $f(x) = R\sin\!\left(\dfrac{\pi x}{2}\right) + S$, $f'\!\left(\dfrac12\right) = \sqrt2$ and $\displaystyle\int_0^1 f(x)\,dx = \dfrac{2R}{\pi}$, then the constants $R$ and $S$ are, respectively,

- (A) $\dfrac{2}{\pi}$ and $\dfrac{16}{\pi}$
- (B) $\dfrac{2}{\pi}$ and $0$
- (C) $\dfrac{4}{\pi}$ and $0$
- (D) $\dfrac{4}{\pi}$ and $\dfrac{16}{\pi}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Use the derivative condition for $R$.**

$$f'(x) = R\cdot\frac{\pi}{2}\cos\!\left(\frac{\pi x}{2}\right)$$

At $x = \tfrac12$: $\cos(\pi/4) = \tfrac{\sqrt2}{2}$, so

$$f'\!\left(\tfrac12\right) = R\cdot\frac{\pi}{2}\cdot\frac{\sqrt2}{2} = \frac{\pi\sqrt2}{4}R = \sqrt2 \;\Rightarrow\; R = \frac{4}{\pi}$$

**Use the integral condition for $S$.**

$$\int_0^1 \left(R\sin\frac{\pi x}{2} + S\right)dx = R\left[-\frac{2}{\pi}\cos\frac{\pi x}{2}\right]_0^1 + S = \frac{2R}{\pi} + S$$

Setting this equal to $\dfrac{2R}{\pi}$ gives $S = 0$.

So $R = \dfrac{4}{\pi}$ and $S = 0$: **(C)**.

**Why the others fail.** (A) and (B) use $R = 2/\pi$, which makes $f'(1/2) = \sqrt2/2$. (A) and (D) use $S\ne0$, which breaks the integral condition.

**Code check:** with $R = 4/\pi$, $S = 0$, the derivative at $\tfrac12$ equals $1.41421\ldots = \sqrt2$ and Simpson's rule gives $\int_0^1 f = 0.81057 = 2R/\pi$. Options A and B fail the derivative test, and A and D fail the integral test.

**Key idea:** each condition fixes one constant: the derivative condition fixes $R$, the integral condition then fixes $S$.

</details>
