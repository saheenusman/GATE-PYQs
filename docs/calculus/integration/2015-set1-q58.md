# 2015 CS1 Q58: Definite integral of cos(1/x) over x squared

## Question

$$\int_{1/\pi}^{2/\pi} \frac{\cos(1/x)}{x^2}\, dx = \text{______}.$$

<details class="success" markdown="1">
<summary>Answer</summary>

**-1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Substitute $u = 1/x$, so $du = -\dfrac{dx}{x^2}$.

Limits: $x = 1/\pi \Rightarrow u = \pi$ and $x = 2/\pi \Rightarrow u = \pi/2$.

$$\int_{1/\pi}^{2/\pi} \frac{\cos(1/x)}{x^2}\,dx = -\int_{\pi}^{\pi/2} \cos u \, du = \int_{\pi/2}^{\pi} \cos u\, du = \sin\pi - \sin\frac{\pi}{2} = -1$$

**Key idea:** $u = 1/x$ turns the integrand into $-\cos u\,du$.

</details>
