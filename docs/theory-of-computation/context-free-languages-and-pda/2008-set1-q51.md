# 2008 CS Q51: Matching language features with languages and grammars

## Question

Match the following:

| | |
|---|---|
| E. Checking that identifiers are declared before their use | P. $L = \lbrace a^n b^m c^n d^m \mid n \ge 1,\ m \ge 1 \rbrace$ |
| F. Number of formal parameters in the declaration of a function agrees with the number of actual parameters in a use of that function | Q. $X \to XbX \mid XcX \mid dXf \mid g$ |
| G. Arithmetic expressions with matched pairs of parentheses | R. $L = \lbrace wcw \mid w \in (a+b)^* \rbrace$ |
| H. Palindromes | S. $X \to bXb \mid cXc \mid \varepsilon$ |

- (A) E - P, F - R, G - Q, H - S
- (B) E - R, F - P, G - S, H - Q
- (C) E - R, F - P, G - Q, H - S
- (D) E - P, F - R, G - S, H - Q

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **E - R.** "Declared before use" means the identifier written at the use site is a **copy** of one written earlier: this is $\lbrace wcw \rbrace$ (the copy language), which is not context-free.
- **F - P.** Matching formal parameters with actual parameters is also a copy-type check. In $a^n b^m c^n d^m$ the $a$'s match the $c$'s and the $b$'s match the $d$'s (crossing dependencies), which is not context-free either.
- **G - Q.** Matched parentheses and operators are **nested**: in $X \to XbX \mid XcX \mid dXf \mid g$, the pair $d \ldots f$ plays the role of parentheses, $b, c$ are operators and $g$ is an operand.
- **H - S.** Palindromes are nested ($X \to bXb \mid cXc \mid \varepsilon$).

That gives E-R, F-P, G-Q, H-S: (C).

- (A), (B) and (D) each swap E/F with P/R or G/H with Q/S, which mixes up a nested language with a crossing or copy language.

**Key idea:** nested structure (parentheses, palindromes) is context-free, while copy structure ($wcw$, matching counts) is not.

</details>
