# 2025 CS2 Q24: Which languages a DPDA can accept

## Question

Which ONE of the following languages is accepted by a deterministic pushdown automaton?

- (A) Any regular language.
- (B) Any context-free language.
- (C) Any language accepted by a non-deterministic pushdown automaton.
- (D) Any decidable language.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Option | Verdict | Reason |
|---|---|---|
| **A** | **True** | A DFA is a DPDA that never touches its stack, so every regular language is accepted |
| B | False | DPDAs accept only the **deterministic** CFLs. The palindrome language $\lbrace ww^R\rbrace$ is context-free but needs non-determinism to guess the middle |
| C | False | Non-deterministic PDAs are strictly more powerful than deterministic ones, by the palindrome example |
| D | False | Decidable languages include non-context-free ones, such as $\lbrace a^nb^nc^n\rbrace$, which no PDA accepts |

**Key idea:** regular $\subset$ deterministic CFL $\subset$ CFL $\subset$ decidable.

</details>
