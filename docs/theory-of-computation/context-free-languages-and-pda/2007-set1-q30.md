# 2007 CS Q30: Class of the language 0^i 2 1^i

## Question

The language $L = \lbrace 0^i 2 1^i \mid i \ge 0 \rbrace$ over the alphabet $\lbrace 0, 1, 2 \rbrace$ is

- (A) not recursive.
- (B) is recursive and is a deterministic CFL.
- (C) is a regular language.
- (D) is not a deterministic CFL but a CFL.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A deterministic PDA accepts $L$: push a symbol for each $0$, switch state on the single $2$ (the marker tells it where the middle is, so no guessing is needed), then pop one symbol per $1$, and accept when the stack is back at the bottom. So $L$ is a **deterministic CFL**.

Every CFL is recursive (decidable), so $L$ is recursive too: (B).

- (A) is false: CFLs are decidable.
- (C) is false: matching the counts of $0$s and $1$s is not possible with finite memory (pumping lemma).
- (D) is false: the middle marker makes it deterministic. (Without the marker, $\lbrace 0^i1^i \rbrace$ is still deterministic; it is $ww^R$ that is not.)
