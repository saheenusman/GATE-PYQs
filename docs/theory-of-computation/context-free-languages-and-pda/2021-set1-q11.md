# 2021 CS1 Q11: Which operation need not preserve context-freeness

## Question

Suppose that $L_1$ is a regular language and $L_2$ is a context-free language. Which one of the following languages is NOT necessarily context-free?

- (A) $L_1 \cap L_2$
- (B) $L_1 \cdot L_2$
- (C) $L_1 - L_2$
- (D) $L_1 \cup L_2$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

CFLs are closed under union, concatenation and intersection with a regular language. They are **not** closed under complement.

- (A) CFL $\cap$ regular is a CFL. Closed.
- (B) Concatenation of two CFLs is a CFL (regular languages are CFLs).
- (C) $L_1-L_2=L_1\cap\overline{L_2}$. The complement $\overline{L_2}$ need not be context-free, so this need not be a CFL. **Correct.** For example, take $L_1=\Sigma^*$ and $L_2=\lbrace ww\rbrace$'s complement (a CFL). Then $L_1-L_2=\lbrace ww\rbrace$, which is not a CFL.
- (D) Union of two CFLs is a CFL.

**Key idea:** CFLs are not closed under complement, so $L_1-L_2$ is not guaranteed to be context-free.

</details>
