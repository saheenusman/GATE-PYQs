# 2022 CS Q48: Context-free and deterministic context-free languages

## Question

Consider the following languages:

$L_1 = \lbrace ww \mid w \in \lbrace a, b \rbrace^* \rbrace$

$L_2 = \lbrace a^n b^n c^m \mid m, n \ge 0 \rbrace$

$L_3 = \lbrace a^m b^n c^n \mid m, n \ge 0 \rbrace$

Which of the following statements is/are FALSE?

- (A) $L_1$ is not context-free but $L_2$ and $L_3$ are deterministic context-free.
- (B) Neither $L_1$ nor $L_2$ is context-free.
- (C) $L_2$, $L_3$ and $L_2 \cap L_3$ all are context-free.
- (D) Neither $L_1$ nor its complement is context-free.

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Facts.**
- $L_1 = \lbrace ww \rbrace$ is not context-free.
- $L_2$ and $L_3$ are deterministic context-free (match $a$ with $b$, then skip the free block; or skip the free block, then match $b$ with $c$).
- $L_2 \cap L_3 = \lbrace a^n b^n c^n \mid n \ge 0 \rbrace$, which is not context-free.
- The complement of $L_1$ is context-free, even though $L_1$ is not. A string is outside $L_1$ if it has odd length or has a mismatch at positions $i$ and $i + n/2$, which a PDA can guess.

**Test each statement** (we want the false ones):
- (A) True.
- (B) **False**, because $L_2$ is context-free.
- (C) **False**, because $L_2 \cap L_3$ is not context-free.
- (D) **False**, because the complement of $L_1$ is context-free.

**Key idea:** context-free languages are not closed under intersection or complement, and the complement of $\lbrace ww \rbrace$ is the standard example of a CFL whose complement is not a CFL.

</details>
