# 2017 CS2 Q40: Classifying four languages: regular, context-free, recursive

## Question

Consider the following languages.

- $L_1 = \lbrace a^p \mid p \text{ is a prime number} \rbrace$
- $L_2 = \lbrace a^n b^m c^{2m} \mid n \ge 0,\ m \ge 0 \rbrace$
- $L_3 = \lbrace a^n b^n c^{2n} \mid n \ge 0 \rbrace$
- $L_4 = \lbrace a^n b^n \mid n \ge 1 \rbrace$

Which of the following are CORRECT?

- I. $L_1$ is context-free but not regular.
- II. $L_2$ is not context-free.
- III. $L_3$ is not context-free but recursive.
- IV. $L_4$ is deterministic context-free.

Options:

- (A) I, II and IV only
- (B) II and III only
- (C) I and IV only
- (D) III and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I. False.** $L_1$ is not regular, and it is **not context-free either**: every context-free language over a one-letter alphabet is regular, and $L_1$ is not regular, so it cannot be context-free.

**II. False.** $L_2 = a^* \cdot \lbrace b^m c^{2m}\rbrace$ is context-free, for example $S \to AB$, $A \to aA \mid \epsilon$, $B \to bBcc \mid \epsilon$.

**III. True.** $L_3 = \lbrace a^nb^nc^{2n}\rbrace$ is not context-free (pumping lemma for CFLs: one pumped part cannot keep three different counts in the ratio $1:1:2$). It is **recursive**: a program can check the form $a^*b^*c^*$ and compare the three counts, which always halts.

**IV. True.** $L_4 = \lbrace a^nb^n \mid n\ge1\rbrace$ is accepted by a DPDA: push for each $a$, pop for each $b$, accept when the stack returns to its start symbol after at least one $b$.

True statements: III and IV, which is **(D)**.

**Why the others fail.** (A), (C) include I (wrong) and (A), (B) include II (wrong).

**Status note:** the reasoning is conceptual (no program applies); the answer matches the official key.

**Key idea:** a unary CFL is always regular; CFLs cannot keep three counts in step, but such languages remain decidable.

</details>
