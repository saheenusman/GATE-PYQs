# 2018 CS Q45: Which of four languages are context-free

## Question

Consider the following languages:

- I. $\lbrace a^m b^n c^p d^q \mid m + p = n + q,\ \text{where } m,n,p,q \ge 0\rbrace$
- II. $\lbrace a^m b^n c^p d^q \mid m = n \text{ and } p = q,\ \text{where } m,n,p,q \ge 0\rbrace$
- III. $\lbrace a^m b^n c^p d^q \mid m = n = p \text{ and } p \ne q,\ \text{where } m,n,p,q \ge 0\rbrace$
- IV. $\lbrace a^m b^n c^p d^q \mid mn = p + q,\ \text{where } m,n,p,q \ge 0\rbrace$

Which of the languages above are context-free?

- (A) I and IV only
- (B) I and II only
- (C) II and III only
- (D) II and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**II is context-free.** It is $\lbrace a^nb^n\rbrace\cdot\lbrace c^pd^p\rbrace$, a concatenation of two CFLs.

**I is context-free.** Split on whether $m \ge n$.
- If $m = n + k$, then $q = p + k$, and the string is $a^k\,(a^nb^n)(c^pd^p)\,d^k$: a nested pair $a^k\ldots d^k$ around two matched blocks.
- If $n = m + k$, then $p = q + k$, and the string is $(a^mb^m)(b^kc^k)(c^qd^q)$: three matched blocks in a row.

Each case has a CFG, and CFLs are closed under union.

**III is not context-free.** It needs $a^n b^n c^n$ with an unrelated $d^q$, $q \ne n$. Pumping lemma sketch: take $a^Nb^Nc^Nd^{N+1}$. Pumping inside the $a,b,c$ part (the pumped window touches at most two blocks) breaks $m=n=p$. Pumping only the $d$'s can set $q = N$, which breaks $p \ne q$.

**IV is not context-free.** Matching $c^pd^q$ against the *product* $mn$ needs more than one stack counter. Pumping sketch: take $a^Nb^Nc^{N^2}$ ($q=0$). Pumping $a$'s or $b$'s changes $mn$ but not $p$; pumping $c$'s changes $p$ but not $mn$.

Only I and II are context-free: **B**.

**Hand-derived:** no code applies here; III and IV use pumping-lemma sketches rather than full proofs.

**Key idea:** one stack can compare two counts (sums or equality of adjacent blocks), but not three-way equality or a product.

</details>
