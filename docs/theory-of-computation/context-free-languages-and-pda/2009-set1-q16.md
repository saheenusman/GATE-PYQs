# 2009 CS Q16: Which statement about automata and languages is FALSE

## Question

Which one of the following is FALSE?

- (A) There is a unique minimal DFA for every regular language.
- (B) Every NFA can be converted to an equivalent PDA.
- (C) Complement of every context-free language is recursive.
- (D) Every nondeterministic PDA can be converted to an equivalent deterministic PDA.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) **True.** For a regular language the minimal DFA is unique up to renaming of states (Myhill-Nerode).
- (B) **True.** Regular languages are context-free. A PDA that simulates the NFA and never uses its stack accepts the same language.
- (C) **True.** Every context-free language is decidable (for example by the CYK algorithm), so it is recursive. Recursive languages are closed under complement, so the complement is recursive too, even though it need not be context-free.
- (D) **False.** Deterministic PDAs are strictly weaker than nondeterministic PDAs. The language $\lbrace w w^R \mid w \in \lbrace 0,1 \rbrace^* \rbrace$ (even-length palindromes) is accepted by an NPDA but by no DPDA, since a DPDA cannot guess where the middle is.

So the false statement is (D).

**Code check:** none (all four statements are theorems, nothing to run).

**Key idea:** unlike finite automata, nondeterminism adds power for pushdown automata: DPDA $\subsetneq$ NPDA.

</details>
