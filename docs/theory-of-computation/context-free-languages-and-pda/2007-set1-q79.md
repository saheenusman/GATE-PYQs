# 2007 CS Q79: Number of derivation trees of aabbab

## Question

(Linked with Q.78: the same grammar.)

**Q.79** For the correct string in Q.78, how many derivation trees are there?

- (A) 1
- (B) 2
- (C) 3
- (D) 4

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The correct string is $aabbab$. It starts with $a$, so the first rule is $S \to aB$, and $B$ must derive $abbab$. The only rule giving $B$ a first symbol $a$ is $B \to aBB$, so the remaining $B\,B$ must derive $bbab$. Split it into two parts $w_1 w_2$, each derived from $B$:

- $w_1 = b$ ($B \to b$) and $w_2 = bab$ ($B \to bS$ with $S \Rightarrow ab$ via $S \to aB$, $B \to b$). **Tree 1:** $S \Rightarrow aB \Rightarrow aaBB \Rightarrow aabB \Rightarrow aabbS \Rightarrow aabbaB \Rightarrow aabbab$.
- $w_1 = bba$ ($B \to bS$ with $S \Rightarrow ba$ via $S \to bA$, $A \to a$) and $w_2 = b$ ($B \to b$). **Tree 2:** $S \Rightarrow aB \Rightarrow aaBB \Rightarrow aabSB \Rightarrow aabbAB \Rightarrow aabbaB \Rightarrow aabbab$.
- The only other split of $bbab$ into two non-empty parts is $bb\,|\,ab$, and it fails: $B \Rightarrow bb$ would need $B \to bS$ with $S \Rightarrow b$, but every string derived from $S$ has length at least 2.

So there are exactly $2$ derivation trees: (B).

- (A) misses one of the two splits.
- (C) and (D) count derivations that do not exist.

**Code check:** Python parse-tree counter (dynamic programming over spans, as in CYK): exactly 2 trees for $aabbab$.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** count derivation trees by the different ways the right-hand side can split the string; the grammar is ambiguous for $aabbab$.

</details>
