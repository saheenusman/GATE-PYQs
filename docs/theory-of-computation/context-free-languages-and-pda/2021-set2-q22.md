# 2021 CS2 Q22: Which combinations of a regular and a context-free language are context-free

## Question

Let $L_1$ be a regular language and $L_2$ be a context-free language. Which of the following languages is/are context-free?

- (A) $L_1\cap\overline{L_2}$
- (B) $\overline{\overline{L_1}\cup\overline{L_2}}$
- (C) $L_1\cup(L_2\cup\overline{L_2})$
- (D) $(L_1\cap L_2)\cup(\overline{L_1}\cap L_2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

CFLs are closed under union and under intersection with a regular language. They are **not** closed under complement, but regular languages are.

- (A) $L_1\cap\overline{L_2}$: $\overline{L_2}$ need not be a CFL, so this need not be a CFL. For $L_1=\Sigma^*$ it is $\overline{L_2}$. **Not necessarily.**
- (B) By De Morgan, $\overline{\overline{L_1}\cup\overline{L_2}}=L_1\cap L_2$, which is regular $\cap$ CFL, so a CFL. **Yes.**
- (C) $L_2\cup\overline{L_2}=\Sigma^*$, so the language is $L_1\cup\Sigma^*=\Sigma^*$, which is regular. **Yes.**
- (D) $(L_1\cap L_2)\cup(\overline{L_1}\cap L_2)=(L_1\cup\overline{L_1})\cap L_2=L_2$, a CFL. **Yes.**

Answer: **B, C and D**.

**Key idea:** simplify with set identities first. Only the complement of a CFL is a problem.

</details>
