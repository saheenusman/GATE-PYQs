# 2011 CS Q8: Pair of machine models with different expressive power

## Question

Which of the following pairs have **DIFFERENT** expressive power?

- (A) Deterministic finite automata (DFA) and Non-deterministic finite automata (NFA)
- (B) Deterministic push down automata (DPDA) and Non-deterministic push down automata (NPDA)
- (C) Deterministic single-tape Turing machine and Non-deterministic single-tape Turing machine
- (D) Single-tape Turing machine and multi-tape Turing machine

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) Same power: the subset construction turns an NFA into an equivalent DFA. Both accept exactly the regular languages.
- (B) **Different power.** NPDAs accept all context-free languages, DPDAs only the deterministic ones. For example $\lbrace ww^R \mid w \in \lbrace a, b \rbrace^* \rbrace$ is accepted by an NPDA but by no DPDA.
- (C) Same power: a deterministic TM can simulate a non-deterministic one by searching its computation tree breadth-first (only slower).
- (D) Same power: a multi-tape TM can be simulated on one tape (with a polynomial slowdown).

So the pair with different power is (B).

**Classification note.** The question compares the finite-automata, pushdown and Turing-machine levels. The deciding pair is DPDA/NPDA, so it is filed under `context-free-languages-and-pda`, with the other two topics as `also`.

**Key idea:** non-determinism adds power for pushdown automata, but not for finite automata or Turing machines.

</details>
