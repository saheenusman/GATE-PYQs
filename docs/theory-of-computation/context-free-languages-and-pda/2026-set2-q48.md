# 2026 CS2 Q48: Constraints that keep a^i b^j c^k d^l context-free

## Question

Let $\Sigma = \lbrace a, b, c, d \rbrace$ and $L = \lbrace a^i b^j c^k d^\ell \mid i, j, k, \ell \ge 0 \rbrace$. Which of the following constraints ensure(s) that the language $L$ is context-free?

- (A) $i + k = j + \ell$
- (B) $i = k$ and $j = \ell$
- (C) $i = \ell$ and $j = k$
- (D) $i + j = k + \ell$

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A PDA has one stack. It can compare **one** count against another count if the comparisons are *nested* (last pushed, first popped). It cannot do two *crossing* comparisons.

**(C) $i = \ell$ and $j = k$: context-free.** The pairs are nested: $a^i \ [\, b^j c^j \,]\ d^i$. Push the $a$'s, push the $b$'s, pop for $c$'s, then pop for $d$'s. A grammar: $S \to aSd \mid T$, $T \to bTc \mid \epsilon$.

**(D) $i + j = k + \ell$: context-free.** Push one symbol for each $a$ and each $b$ ($i+j$ symbols). Pop one for each $c$ and each $d$. Accept if the stack is empty at the end. One counter is enough.

**(A) $i + k = j + \ell$: context-free.** Rewrite as $i - j = \ell - k$. Use a stack that stores the signed difference: the $a$'s add, the $b$'s subtract (if the stack is empty it starts counting the other sign), the $c$'s add more, and the $d$'s subtract until the stack is empty. One counter with a sign is still one stack.

**(B) $i = k$ and $j = \ell$: not context-free.** This is $a^i b^j c^i d^j$, with *crossing* pairs ($a$ with $c$, $b$ with $d$). The pumping lemma for CFLs rules it out: any pumped window of length at most $p$ lies within two adjacent blocks, so pumping breaks one pairing but not the other.

| Option | Pairing | Context-free? |
|---|---|---|
| A | one signed counter | yes |
| B | crossing ($a$-$c$, $b$-$d$) | **no** |
| C | nested ($a$-$d$, $b$-$c$) | yes |
| D | one counter | yes |

**Verified:** this question rests on proofs (PDA constructions and the pumping lemma) rather than something a program can run, so I checked the construction logic by hand against the key.

**Key idea:** nested equalities are context-free, crossing equalities are not. A single sum or difference condition needs only one counter.
