# 2015 CS3 Q44: Which languages are context-free

## Question

Which of the following languages are context-free?

$$L_1 = \lbrace a^m b^n a^n b^m \mid m, n \ge 1 \rbrace$$
$$L_2 = \lbrace a^m b^n a^m b^n \mid m, n \ge 1 \rbrace$$
$$L_3 = \lbrace a^m b^n \mid m = 2n + 1 \rbrace$$

- (A) $L_1$ and $L_2$ only
- (B) $L_1$ and $L_3$ only
- (C) $L_2$ and $L_3$ only
- (D) $L_3$ only

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_1$ is context-free.** The $a^m \ldots b^m$ and $b^n \ldots a^n$ parts are *nested*, so a stack handles them. A grammar:

$$S \to aSb \mid aTb, \qquad T \to bTa \mid ba$$

**$L_2$ is not context-free.** The pairs are *crossed* ($a$ with $a$, $b$ with $b$), like the copy language. Take $s = a^p b^p a^p b^p$ in the pumping lemma. Since $|vwx| \le p$, the pumped part touches at most two neighbouring blocks. Pumping changes those but not the block each must match (first $a$ block with third, first $b$ block with fourth), so the pumped string leaves the language.

**$L_3$ is context-free.** $a^{2n+1}b^n$: for every $b$ there are two $a$'s, plus one extra:

$$S \to aaSb \mid a$$

So $L_1$ and $L_3$: option (B).

- (A) and (C) include $L_2$.
- (D) misses $L_1$.

**Key idea:** nested dependencies are context-free. Crossed dependencies are not.

</details>
