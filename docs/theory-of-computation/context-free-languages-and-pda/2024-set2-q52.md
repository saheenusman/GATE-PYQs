# 2024 CS2 Q52: Counting symbols in a context-free grammar

## Question

Consider a context-free grammar $G$ with the following 3 rules.

$$S \to aS, \qquad S \to aSbS, \qquad S \to c$$

Let $w \in L(G)$. Let $n_a(w)$, $n_b(w)$, $n_c(w)$ denote the number of times $a$, $b$, $c$ occur in $w$, respectively. Which of the following statements is/are TRUE?

- (A) $n_a(w) > n_b(w)$
- (B) $n_a(w) > n_c(w) - 2$
- (C) $n_c(w) = n_b(w) + 1$
- (D) $n_c(w) = n_b(w) * 2$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Track what each rule adds:**

| Rule | $a$ | $b$ | $c$ | Number of $S$ left |
|---|---|---|---|---|
| $S \to aS$ | +1 | 0 | 0 | same |
| $S \to aSbS$ | +1 | +1 | 0 | +1 |
| $S \to c$ | 0 | 0 | +1 | −1 |

Start with one $S$ and end with none. The only rule that adds an $S$ is $aSbS$ (once per $b$), and the only rule that removes one is $S \to c$. So the number of $c$'s is one more than the number of $b$'s:

$$n_c = n_b + 1.\quad\text{(C) is true.}$$

Every $b$ comes with an $a$ from the same rule, so $n_a \ge n_b = n_c - 1 > n_c - 2$. **(B) is true.**

- **(A) False.** $acbc$ is derivable ($S \to aSbS \to acbc$): $n_a = n_b = 1$.
- **(D) False.** $c$ alone has $n_b = 0$, so $n_c = 1 \ne 0$.

(Checked against all 116 derivable strings of length up to 11.)

**Key idea:** count how each rule changes the number of pending non-terminals to relate terminal counts.

</details>
