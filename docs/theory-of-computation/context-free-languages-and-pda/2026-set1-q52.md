# 2026 CS1 Q52: Counting a's and b's in a context-free grammar

## Question

Consider the context-free grammar $G$ with start symbol $S$, terminals $a, b$ and non-terminals $A, B$:

$$S \to abaABAbba$$

$$A \to aaBBAb \mid bBabaa$$

$$B \to aBb \mid ab$$

For a string $s \in L(G)$, let $n_1(s)$ be the number of $a$'s and $n_2(s)$ the number of $b$'s. Which statements are true?

- (A) There is a string $s \in L(G)$ with $n_1(s) < n_2(s)$
- (B) For every string $s \in L(G)$, $n_1(s) \ge n_2(s)$
- (C) There is a string $s \in L(G)$ with $n_1(s) > 2 n_2(s)$
- (D) For every string $s \in L(G)$, $n_1(s) \le 2 n_2(s)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count $a$'s minus $b$'s for each non-terminal.** Let $\delta = n_1 - n_2$.

**$B$:** both productions add equal numbers of $a$ and $b$ ($aBb$ adds one each, $ab$ adds one each). So $B$ always gives $a^k b^k$, $k \ge 1$, and $\delta(B) = 0$.

**$A$:**

- $A \to bBabaa$: terminals $b, a, b, a, a$ have 3 $a$'s and 2 $b$'s, plus a balanced $B$. So $\delta = +1$.
- $A \to aaBBAb$: terminals $a, a, b$ give $\delta = +1$, plus balanced $B$'s, plus a smaller $A$.

So each use of $A \to aaBBAb$ adds $+1$ and the final $A \to bBabaa$ adds $+1$. Hence $\delta(A) = m + 1 \ge 1$, where $m$ is the number of times the recursive rule is used.

**$S$:** $abaABAbba$ has 3 $a$'s and 3 $b$'s in its terminals, so $\delta(S) = \delta(A_1) + \delta(A_2) \ge 2$.

So $n_1 \ge n_2 + 2$ for every string.

- **(A) false**, **(B) true** (always $n_1 > n_2$).

**The upper bound.** Each recursive step of $A$ adds a $b$ in the text $aaBBAb$, and the base case contributes 2 $b$'s, so the number of $b$'s grows at least as fast as $\delta$. In detail $n_2 \ge 3 + (m_1 + 2) + (m_2 + 2) > \delta = (m_1 + 1) + (m_2 + 1)$, so $n_1 = n_2 + \delta < 2 n_2$.

- **(C) false**, **(D) true**.

**Verified.** I generated 20,000 random strings from the grammar: $n_1 < n_2$ never happened, $n_1 > 2n_2$ never happened, and the smallest $n_1 - n_2$ seen was 2.

**Key idea:** to compare symbol counts in a grammar, compute the difference per non-terminal and add it up along the recursion.

</details>
