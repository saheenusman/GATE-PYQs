# 2014 CS3 Q36: Which of 0^n 1^n, w c w^r and w w^r are deterministic CFLs

## Question

Consider the following languages over the alphabet $\Sigma = \lbrace 0, 1, c \rbrace$:

- $L_1 = \lbrace 0^n 1^n \mid n \ge 0 \rbrace$
- $L_2 = \lbrace w c w^r \mid w \in \lbrace 0,1 \rbrace^* \rbrace$
- $L_3 = \lbrace w w^r \mid w \in \lbrace 0,1 \rbrace^* \rbrace$

Here, $w^r$ is the reverse of the string $w$. Which of these languages are deterministic Context-free languages?

- (A) None of the languages
- (B) Only $L_1$
- (C) Only $L_1$ and $L_2$
- (D) All the three languages

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **$L_1$ is a DCFL.** Push a symbol for each 0, then pop one for each 1. No guessing is needed.
- **$L_2$ is a DCFL.** Push the symbols of $w$ until the marker $c$ is read, then pop and compare against $w^r$. The marker $c$ tells the machine exactly when to switch, so it is deterministic.
- **$L_3$ is a CFL but not a DCFL.** There is no marker, so a PDA must **guess** where $w$ ends and $w^r$ begins. For example, $00$ is in $L_3$ (with $w = 0$) and so is $0000$ (with $w = 00$). After reading $00$ a deterministic PDA must already accept, yet it must also be ready to continue, and it cannot tell where the middle is. It is a standard result that this language is not deterministic.

So only $L_1$ and $L_2$: **C**.

- (A), (B) miss $L_2$ (or $L_1$) which are DCFLs.
- (D) is wrong because of $L_3$.

**Key idea:** a middle marker ($c$) makes the palindrome-like language deterministic; without it the PDA has to guess.

</details>
