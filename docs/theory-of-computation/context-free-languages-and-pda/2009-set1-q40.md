# 2009 CS Q40: Intersection of {a^m b^m c a^n b^n} and {a^i b^j c^k}

## Question

Let $L = L_1 \cap L_2$, where $L_1$ and $L_2$ are languages as defined below:

$L_1 = \lbrace a^m b^m c a^n b^n \mid m, n \ge 0 \rbrace$

$L_2 = \lbrace a^i b^j c^k \mid i, j, k \ge 0 \rbrace$

Then $L$ is

- (A) not recursive.
- (B) regular.
- (C) context-free but not regular.
- (D) recursively enumerable but not context-free.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A string of $L_1$ looks like $a^m b^m \; c \; a^n b^n$. A string of $L_2$ has the form $a^* b^* c^*$: after the first $c$ there may be only more $c$s, never an $a$ or $b$.

So for $a^m b^m c a^n b^n$ to lie in $L_2$, the part $a^n b^n$ after the $c$ must be empty. That forces $n = 0$, and

$$L = \lbrace a^m b^m c \mid m \ge 0 \rbrace.$$

- **Context-free:** generated by $S \to aSb \mid c$.
- **Not regular:** by the pumping lemma. Take $a^p b^p c$ and pump inside the first $p$ symbols (all $a$s): the number of $a$s changes and the number of $b$s does not.

So $L$ is context-free but not regular: (C).

- (A) is false: every context-free language is recursive.
- (B) is false: $\lbrace a^m b^m \rbrace$-type counting is not regular.
- (D) is false: $L$ is context-free, so the "but not context-free" part fails.

**Code check:** all strings over $\lbrace a, b, c \rbrace$ of length $0$ to $12$ were tested for membership in $L_1 \cap L_2$. The members were exactly $c, abc, aabbc, aaabbbc, aaaabbbbc$ and $a^5 b^5 c$ ($6$ strings), with $0$ mismatches against $\lbrace a^m b^m c \rbrace$.

**Key idea:** intersecting with $a^* b^* c^*$ kills the second counted block, leaving a single $a^m b^m$ count.

</details>
