# 2011 CS Q26: Statement that is not true about three languages

## Question

Consider the languages $L_1$, $L_2$ and $L_3$ as given below.

$L_1 = \lbrace 0^p 1^q \mid p, q \in \mathbb{N} \rbrace$,

$L_2 = \lbrace 0^p 1^q \mid p, q \in \mathbb{N} \text{ and } p = q \rbrace$ and

$L_3 = \lbrace 0^p 1^q 0^r \mid p, q, r \in \mathbb{N} \text{ and } p = q = r \rbrace$.

Which of the following statements is **NOT TRUE**?

- (A) Push Down Automata (PDA) can be used to recognize $L_1$ and $L_2$
- (B) $L_1$ is a regular language
- (C) All the three languages are context free
- (D) Turing machines can be used to recognize all the languages

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- $L_1 = 0^* 1^*$ is regular.
- $L_2 = \lbrace 0^n 1^n \rbrace$ is context free (a PDA pushes the $0$s and pops for each $1$) but not regular.
- $L_3 = \lbrace 0^n 1^n 0^n \rbrace$ is **not** context free. By the pumping lemma for CFLs, a pumpable substring of $0^n 1^n 0^n$ can touch at most two of the three blocks, so pumping breaks the equal counts.

Check each statement:

- (A) true: $L_1$ and $L_2$ are context free, so a PDA recognizes both.
- (B) true.
- (C) **not true**, because $L_3$ is not context free: (C).
- (D) true: Turing machines recognize all three (they recognize all context-free and many more languages).

**Key idea:** 0^n 1^n 0^n needs two counts at once, which is beyond a single stack; it is context sensitive, not context free.

</details>
