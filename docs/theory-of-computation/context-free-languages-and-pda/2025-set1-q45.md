# 2025 CS1 Q45: Are two a-b-c languages context-free

## Question

Consider the following two languages over the alphabet $\lbrace a, b, c\rbrace$, where $m$ and $n$ are natural numbers.

$$L_1 = \lbrace a^m b^m c^{m+n} \mid m, n \ge 1\rbrace$$

$$L_2 = \lbrace a^m b^n c^{m+n} \mid m, n \ge 1\rbrace$$

Which ONE of the following statements is CORRECT?

- (A) Both $L_1$ and $L_2$ are context-free languages.
- (B) $L_1$ is a context-free language but $L_2$ is not a context-free language.
- (C) $L_1$ is not a context-free language but $L_2$ is a context-free language.
- (D) Neither $L_1$ nor $L_2$ are context-free languages.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_2$ is context-free.** Write $a^m b^n c^{m+n} = a^m\,(b^n c^n)\,c^m$. The $a^m \dots c^m$ part nests around the $b^nc^n$ part:

$$S \to a\,S\,c \mid a\,T\,c, \qquad T \to b\,T\,c \mid bc.$$

(A PDA pushes for each $a$ and each $b$, then pops for each $c$.)

**$L_1$ is not context-free.** Here $a^m b^m$ must match, and the number of $c$'s must be **more than** $m$ (it is $m+n$ with $n \ge 1$). A PDA would need to use its stack once to match $a$'s with $b$'s, and again to count $c$'s against the same $m$: one stack cannot do both.

Pumping-lemma argument with pumping length $p$ and $s = a^p b^p c^{p+1} \in L_1$. Split $s = uvwxy$ with $|vwx| \le p$ and $|vx| \ge 1$. Since the block of $b$'s has length $p$, $vwx$ cannot touch both $a$'s and $c$'s. Consider the cases:

- **$vx$ lies inside the $c$'s.** Pumping down ($i = 0$) leaves at most $p$ $c$'s, but we need more than $m = p$. Out of the language.
- **$vx$ contains no $c$, so only $a$'s and $b$'s.** If it adds unequal amounts to the $a$ and $b$ counts, then $\#a \ne \#b$ after pumping up. If it adds the same amount $k \ge 1$ to both, then $m = p+k$ but there are still only $p+1 \le p+k$ $c$'s, so we no longer have more $c$'s than $m$. Out of the language.
- **$vwx$ spans the $b$'s and $c$'s with $vx$ containing at least one $b$.** Pumping down removes a $b$ but no $a$, so $\#a \ne \#b$. Out of the language.

So no decomposition works, and $L_1$ is not context-free.

| Option | Verdict |
|---|---|
| A, B | Claim $L_1$ is context-free: false |
| **C** | Correct |
| D | Claims $L_2$ is not context-free: false |

**Key idea:** a PDA's single stack can compare two counts, but not use one count against two others at once.

</details>
