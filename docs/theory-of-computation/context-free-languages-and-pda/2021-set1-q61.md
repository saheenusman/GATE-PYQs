# 2021 CS1 Q61: Strings of length 100 accepted by a given PDA

## Question

In a pushdown automaton $P=(Q,\Sigma,\Gamma,\delta,q_0,F)$, a transition of the form

$$p\ \xrightarrow{\ a,\,X\to Y\ }\ q$$

where $p,q\in Q$, $a\in\Sigma\cup\lbrace\epsilon\rbrace$, and $X,Y\in\Gamma\cup\lbrace\epsilon\rbrace$, represents $(q,Y)\in\delta(p,a,X)$.

Consider the following pushdown automaton over the input alphabet $\Sigma=\lbrace a,b\rbrace$ and stack alphabet $\Gamma=\lbrace\#,A\rbrace$. The transitions are:

| From | Label | To |
|---|---|---|
| $q_0$ (start) | $\epsilon,\epsilon\to\#$ | $q_1$ |
| $q_1$ | $a,\epsilon\to A$ | $q_1$ (self-loop) |
| $q_1$ | $\epsilon,\epsilon\to\epsilon$ | $q_2$ |
| $q_2$ | $b,A\to\epsilon$ | $q_2$ (self-loop) |
| $q_2$ | $\epsilon,A\to A$ | $q_3$ (accepting) |

The number of strings of length 100 accepted by the above pushdown automaton is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**50**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What the machine does.**

- $q_0\to q_1$ pushes `#` as a bottom marker.
- In $q_1$ it reads $m$ letters `a` and pushes one `A` for each.
- It moves to $q_2$ and reads $n$ letters `b`, popping one `A` for each.
- The last move $q_2\to q_3$ (labelled $\epsilon,A\to A$) reads nothing and pops nothing. It only needs an `A` on top of the stack. Then it accepts, with all input consumed.

So the string $a^mb^n$ is accepted iff the stack still has an `A` after $n$ pops, i.e. $m-n\ge1$, that is $m>n$.

**Counting.** Length 100 means $m+n=100$. The condition $m>n$ means $100-n>n$, so $n\le49$. Each $n=0,1,\ldots,49$ gives exactly one string, and different $n$ give different strings. That is **50** strings.

(The check $m>n$ rules out $m=n=50$: the stack would be left with only `#` on top, so $q_2\to q_3$ cannot fire.)

I simulated the PDA with a search over all configurations and counted accepted strings for lengths 2 to 12: 1, 2, 3, 4, 5, 6, which is length/2. At length 100 that is 50.

**Key idea:** a PDA that checks "an `A` is on top" without popping accepts $a^mb^n$ with $m>n$.

</details>
