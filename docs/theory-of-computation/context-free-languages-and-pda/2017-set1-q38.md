# 2017 CS1 Q38: Which of L1 union L2 and L1 intersect L2 are context-free

## Question

Consider the following languages over the alphabet $\Sigma = \lbrace a, b, c\rbrace$. Let $L_1 = \lbrace a^{n} b^{n} c^{m} \mid m, n \ge 0\rbrace$ and $L_2 = \lbrace a^{m} b^{n} c^{n} \mid m, n \ge 0\rbrace$.

Which of the following are context-free languages?

- I. $L_1 \cup L_2$
- II. $L_1 \cap L_2$

Options:

- (A) I only
- (B) II only
- (C) I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_1$ and $L_2$ are context-free.**

- $L_1$: match $a$'s with $b$'s, then any number of $c$'s: $S \to AC$, $A \to aAb \mid \epsilon$, $C \to cC \mid \epsilon$.
- $L_2$: any number of $a$'s, then match $b$'s with $c$'s.

**I. Union: context-free.** CFLs are closed under union (add $S \to S_1 \mid S_2$).

**II. Intersection: not context-free.** A string in both has $\#a = \#b$ (from $L_1$) and $\#b = \#c$ (from $L_2$), so

$$L_1 \cap L_2 = \lbrace a^{n} b^{n} c^{n} \mid n \ge 0\rbrace$$

This is the standard non-context-free language (the pumping lemma for CFLs rules it out). CFLs are not closed under intersection.

So I only: **(A)**.

**Why the others fail.** (B) and (C) claim the intersection is context-free. (D) denies that the union is.

**Status note:** this is a theory question with no program to run. My reasoning matches the official key.

**Key idea:** CFLs are closed under union but not intersection; the classic witness is $a^nb^nc^m \cap a^mb^nc^n = a^nb^nc^n$.

</details>
