# 2023 CS Q39: Language of a context-free grammar

## Question

Consider the context-free grammar $G$ below

$$S \to aSb \mid X$$
$$X \to aX \mid Xb \mid a \mid b$$

where $S$ and $X$ are non-terminals, and $a$ and $b$ are terminal symbols. The starting non-terminal is $S$.

Which one of the following statements is CORRECT?

- (A) The language generated by $G$ is $(a+b)^*$
- (B) The language generated by $G$ is $a^*(a+b)b^*$
- (C) The language generated by $G$ is $a^*b^*(a+b)$
- (D) The language generated by $G$ is not a regular language

<details class="success" markdown="1">
<summary>Answer</summary>

**B ($a^*(a+b)b^*$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Language of $X$.** $X$ adds any number of $a$'s on the left and $b$'s on the right, and ends with a single $a$ or $b$ in the middle:

$$L(X) = a^i\,(a+b)\,b^j \quad (i, j \ge 0)$$

**Language of $S$.** Each $S \to aSb$ adds one $a$ on the left and one $b$ on the right, then $S \to X$ finishes:

$$L(S) = a^k\,a^i(a+b)b^j\,b^k = a^p\,(a+b)\,b^q$$

Since $p = k+i$ and $q = j+k$ can be any non-negative numbers, $L(S) = a^*(a+b)b^*$.

**Why the others fail:**
- **A**: $(a+b)^*$ contains the empty string and $ba$. $G$ generates neither: every string has exactly one "middle" letter, and no $b$ is ever followed by an $a$.
- **C**: $a^*b^*(a+b)$ contains $ba$ (take $b$ from $b^*$ and $a$ as the last letter), which $G$ cannot generate.
- **D**: the language is regular, as shown.

**Code check:** enumerating all strings derivable up to length 9 gave exactly $a^*(a+b)b^*$.

**Key idea:** the $aSb$ rule only adds matching letters at the ends, and both $X$ rules add letters on one side. The result is a regular language.

</details>
