# 2014 CS3 Q15: Shortest string not in a four-block regular expression

## Question

The length of the shortest string NOT in the language (over $\Sigma = \lbrace a, b \rbrace$) of the following regular expression is ______.

$$a^*b^*(ba)^*a^*$$

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Check strings by length.

- **Length 0, 1:** $\varepsilon$, $a$, $b$ are all matched (take empty or single blocks).
- **Length 2:** $aa$, $ab$, $bb$ are matched by $a^*$ or $b^*$ blocks, and $ba$ by $(ba)^*$.
- **Length 3:** $bab$ is **not** matched. Every string in the language has the form $a^i b^j (ba)^k a^l$. For $bab$, $i = 0$, and:
  - $j = 0$: then $bab = (ba)^k a^l$. For $k = 1$ the leftover is $b$, which $a^l$ cannot match; $k = 0$ fails since $bab$ is not all $a$'s.
  - $j = 1$: the rest is $ab = (ba)^k a^l$, which fails since $ab$ does not start with $b$ and is not all $a$'s.
  - $j \ge 2$: impossible, since $bab$ has only one leading $b$.

**Code check:** with Python's `re.fullmatch`, every string of length $\le 2$ matches, and of the 8 strings of length 3 only `bab` does not.

**Key idea:** to find the shortest string outside a regular language, enumerate by length until one fails.

</details>
