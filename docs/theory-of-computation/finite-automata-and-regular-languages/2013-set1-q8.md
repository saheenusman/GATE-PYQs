# 2013 CS Q8: L1 L2* ∪ L1*

## Question

Consider the languages $L_1 = \Phi$ and $L_2 = \lbrace a \rbrace$.
Which one of the following represents $L_1 L_2^{*} \cup L_1^{*}$ ?

- (A) $\lbrace \epsilon \rbrace$
- (B) $\Phi$
- (C) $a^{*}$
- (D) $\lbrace \epsilon, a \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- $L_1 L_2^* = \Phi \cdot a^* = \Phi$, because concatenating with the empty language gives the empty language.
- $L_1^* = \Phi^* = \lbrace \epsilon \rbrace$, because the star always includes the empty string.

Union: $\Phi \cup \lbrace \epsilon \rbrace = \lbrace \epsilon \rbrace$.

**Why the others fail:**

- (B) forgets that $\Phi^* = \lbrace \epsilon \rbrace$.
- (C), (D) wrongly keep $a$ from $L_2$; it is wiped out by the concatenation with $\Phi$.

**Key idea:** $\Phi \cdot L = \Phi$ but $\Phi^* = \lbrace \epsilon \rbrace$.

</details>
