# 2009 CS Q41: Strings accepted by a 3-state DFA

## Question

![A DFA with three states in a row, called q0, q1 and q2 from left to right. An arrow from outside points into q0, the start state. q0 has a self-loop labelled 1 and an edge labelled 0 to q1. q1 has an edge labelled 0 to q2 and an edge labelled 1 back to q0. q2 is the accepting state, drawn with a double circle. q2 has a self-loop labelled 0 and an edge labelled 1 back to q0.](../../assets/2009/set1-q41.png)

The above DFA accepts the set of all strings over $\lbrace 0, 1 \rbrace$ that

- (A) begin either with 0 or 1.
- (B) end with 0.
- (C) end with 00.
- (D) contain the substring 00.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Name the states $q_0, q_1, q_2$ from left to right ($q_0$ is the start, $q_2$ accepts). They count the **trailing zeros** of the input read so far:

- $q_0$: the string ends in $1$, or is empty (no trailing $0$).
- $q_1$: exactly one trailing $0$.
- $q_2$: two or more trailing $0$s.

A $1$ always sends the DFA back to $q_0$, and a $0$ moves one step toward $q_2$ (and stays there). So the DFA accepts exactly the strings that **end with $00$**: (C).

| Input | Path | Accepted? |
|---|---|---|
| $00$ | $q_0, q_1, q_2$ | yes |
| $100$ | $q_0, q_0, q_1, q_2$ | yes |
| $000$ | $q_0, q_1, q_2, q_2$ | yes |
| $10$ | $q_0, q_0, q_1$ | no |
| $001$ | $q_0, q_1, q_2, q_0$ | no |

- (A) is false: $1$ begins with $1$ but ends in $q_0$, and is rejected.
- (B) is false: $10$ ends with $0$ but stops in $q_1$, and is rejected.
- (D) is false: $001$ contains $00$ but the final $1$ returns it to $q_0$, so it is rejected.

**Code check:** the DFA was simulated on every binary string of length $0$ to $14$ ($32767$ strings): it accepted exactly those ending in $00$, with $0$ mismatches.

**Key idea:** read what each state remembers (here, the number of trailing zeros, capped at $2$); the accepting state then names the language.

</details>
