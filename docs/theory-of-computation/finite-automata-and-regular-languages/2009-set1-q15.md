# 2009 CS Q15: Language of the regular expression (0+1)*0(0+1)*0(0+1)*

## Question

Which one of the following languages over the alphabet $\lbrace 0, 1 \rbrace$ is described by the regular expression:

$(0 + 1)^* 0 (0 + 1)^* 0 (0 + 1)^*$ ?

- (A) The set of all strings containing the substring 00.
- (B) The set of all strings containing at most two 0's.
- (C) The set of all strings containing at least two 0's.
- (D) The set of all strings that begin and end with either 0 or 1.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The expression has two explicit $0$s, with $(0+1)^*$ (any string) before, between and after them. So a string matches exactly when it has **two $0$s somewhere**, in any positions, with anything between them. Extra $0$s are absorbed by the $(0+1)^*$ parts. That is "at least two $0$'s": (C).

- (A) is false: $010$ matches the expression (its two $0$s are not adjacent) but does not contain $00$.
- (B) is false: $000$ matches the expression but has three $0$s.
- (D) is false: $11$ begins and ends with $1$, but it has no $0$ and does not match.

**Code check:** the expression was tested against every binary string of length $0$ to $12$ ($8191$ strings): it matched exactly the strings with at least two $0$s, with $0$ mismatches. Spot checks: $010$ and $000$ match, $11$ and $0$ do not.

**Key idea:** each fixed symbol in the expression is a required occurrence; $(0+1)^*$ around it allows anything else.

</details>
