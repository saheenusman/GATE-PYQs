# 2021 CS2 Q57: Regular expressions for binary numbers divisible by 3

## Question

Which of the following regular expressions represent(s) the set of all binary numbers that are divisible by three? Assume that the string $\epsilon$ is divisible by three.

- (A) `(0 + 1(01*0)*1)*`
- (B) `(0 + 11 + 10(1 + 00)*01)*`
- (C) `(0*(1(01*0)*1)*)*`
- (D) `(0 + 11 + 11(1 + 00)*00)*`

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the DFA with states = remainder mod 3: reading bit $b$ from remainder $r$ goes to $(2r+b)\bmod3$. A string is divisible by 3 exactly when the DFA ends in remainder 0.

The standard expressions describe the loops through state 0:

- `0` stays in 0.
- `1(01*0)*1` goes 0→1, loops 1→2→1 (via `01*0`), and returns 1→0.

That gives (A), and (C) is (A) with extra `0*` and `*`, which does not change the language. (B) is the other standard form, using `11` and `10(1+00)*01`.

**Check by running:** I tested each expression against $\text{int}(s,2)\bmod3=0$ for every binary string of length 0 to 14 (including the empty string). (A), (B), (C) match exactly. (D) does not: for example `1001` (nine) is divisible by 3 but cannot be produced, since every non-empty block in (D) either is `0` or starts with `11`.

**Key idea:** think of the remainder-mod-3 DFA, and read off a regular expression for the closed walks through state 0.

</details>
