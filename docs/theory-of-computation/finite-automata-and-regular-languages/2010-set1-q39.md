# 2010 CS Q39: Regular expression for bit strings with an even number of 1s

## Question

Let $L = \lbrace w \in (0+1)^* \mid w \text{ has even number of 1s} \rbrace$, i.e. $L$ is the set of all bit strings with even number of 1s. Which one of the regular expressions below represents $L$?

- (A) $(0^*10^*1)^*$
- (B) $0^*(10^*10^*)^*$
- (C) $0^*(10^*1^*)^*0^*$
- (D) $0^*1(10^*1)^*10^*$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$L$ contains strings with zero 1s (such as $\varepsilon$ and $000$) and strings where the 1s come in pairs, with 0s anywhere.

- (B) $0^*(10^*10^*)^*$: leading 0s, then blocks each holding exactly two 1s with 0s anywhere around them. Every string in $L$ is generated and nothing else. **Correct.**
- (A) $(0^*10^*1)^*$ cannot produce $0$: every block ends in a 1, so a string with no 1s is only $\varepsilon$. Wrong.
- (C) $0^*(10^*1^*)^*0^*$ generates $1$ (one iteration with $0^*$ and $1^*$ both empty), which has an odd number of 1s. Wrong.
- (D) $0^*1(10^*1)^*10^*$ always has $1 + 2k + 1$ ones, at least two, so it misses $\varepsilon$ and $0$. Wrong.

So (B).

**Code check:** each expression was matched (full match) against all binary strings of length up to $8$; only (B) agrees with "even number of 1s" on all of them.

**Key idea:** pair up the 1s; each pair may be surrounded by any number of 0s.

</details>
