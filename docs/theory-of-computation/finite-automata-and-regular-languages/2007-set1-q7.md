# 2007 CS Q7: Which statement about regular sets is true

## Question

Which of the following is **TRUE**?

- (A) Every subset of a regular set is regular.
- (B) Every finite subset of a non-regular set is regular.
- (C) The union of two non-regular sets is not regular.
- (D) Infinite union of finite sets is regular.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(B) True.** Every finite set of strings is regular (a finite union of single-string languages), whatever set it was taken from.
- (A) False. $\Sigma^*$ is regular, but its subset $\lbrace a^nb^n \mid n \ge 0 \rbrace$ is not.
- (C) False. $L = \lbrace a^nb^n \rbrace$ and its complement $\overline{L}$ are both non-regular, yet $L \cup \overline{L} = \Sigma^*$ is regular.
- (D) False. $\lbrace a^nb^n \rbrace = \bigcup_{n}\lbrace a^nb^n \rbrace$ is an infinite union of finite (one-string) sets and is not regular.

**Code check:** not applicable (closure-property reasoning).

**Key idea:** regular languages are closed under finite union only, not arbitrary subsets, unions of non-regular sets or infinite unions.
