# 2021 CS2 Q27: Strings of length 8 accepted by a DFA

## Question

Consider the following deterministic finite automaton (DFA).

![A DFA with start state on the left. From the start state, input 0 goes to the upper state of the second column and input 1 goes to the lower state. Both second-column states go to the upper state of the third column on 0 and to the lower state on 1. Both third-column states go to the accepting state on the right on 0 and 1. The accepting state loops to itself on 0 and 1.](../../assets/2021/set2-q27.png)

The number of strings of length 8 accepted by the above automaton is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**256**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Read the automaton column by column.

- After the 1st symbol: in one of the two states of column 2.
- After the 2nd symbol: in one of the two states of column 3.
- After the 3rd symbol: in the accepting state, whatever the symbol was (both edges are labelled $0,1$).
- From the accepting state every symbol loops back to it.

So a string is accepted exactly when its length is at least 3.

Every string of length 8 qualifies:

$$2^8=256.$$

I also enumerated all 256 strings with a small simulation: all 256 end in the accepting state.

**Key idea:** if every path to the accepting trap state has length at most 3, accepting means just "length $\ge 3$".

</details>
