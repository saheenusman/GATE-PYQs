# 2015 CS2 Q60: Regular expression for X0 from a right-linear grammar

## Question

Consider the alphabet $\Sigma = \lbrace 0, 1 \rbrace$, the null/empty string $\lambda$ and the sets of strings $X_0$, $X_1$, and $X_2$ generated by the corresponding non-terminals of a regular grammar. $X_0$, $X_1$, and $X_2$ are related as follows.

$$X_0 = 1\,X_1$$
$$X_1 = 0\,X_1 + 1\,X_2$$
$$X_2 = 0\,X_1 + \lbrace \lambda \rbrace$$

Which one of the following choices precisely represents the strings in $X_0$?

- (A) $10(0^* + (10)^*)1$
- (B) $10(0^* + (10)^*)^*1$
- (C) $1(0 + 10)^*1$
- (D) $10(0 + 10)^*1 + 110(0 + 10)^*1$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Substitute $X_2$ into $X_1$:

$$X_1 = 0X_1 + 1(0X_1 + \lambda) = (0 + 10)X_1 + 1$$

This has the form $X = \alpha X + \beta$, whose solution (Arden's rule) is $X = \alpha^*\beta$:

$$X_1 = (0 + 10)^*\,1$$

$$X_0 = 1X_1 = 1(0 + 10)^*1$$

Option (C).

**Why the others fail.** The shortest string of $X_0$ is $11$ ($X_0 \to 1X_1 \to 1\cdot 1X_2 \to 11$). Options (A), (B) and (D) all need a $0$ right after the opening $1$ (or $11$), so none of them generates $11$.

**Code check:** I generated every string of $X_0$ up to length 10 from the three equations and compared with each option as a regex. Only (C) matches exactly. (A), (B) and (D) all miss strings such as $11$.

**Key idea:** solve a right-linear system by substitution and Arden's rule: $X = \alpha X + \beta \Rightarrow X = \alpha^*\beta$.

</details>
