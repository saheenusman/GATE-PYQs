# 2015 CS2 Q46: Which of three languages are regular

## Question

Which of the following languages is/are regular?

- $L_1$: $\lbrace w x w^R \mid w, x \in \lbrace a, b \rbrace^* \text{ and } |w|, |x| > 0 \rbrace$, where $w^R$ is the reverse of string $w$
- $L_2$: $\lbrace a^n b^m \mid m \ne n \text{ and } m, n \ge 0 \rbrace$
- $L_3$: $\lbrace a^p b^q c^r \mid p, q, r \ge 0 \rbrace$

- (A) $L_1$ and $L_3$ only
- (B) $L_2$ only
- (C) $L_2$ and $L_3$ only
- (D) $L_3$ only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_1$ is regular.** A string $w x w^R$ starts with the first symbol of $w$ and ends with that same symbol. With $|w| \ge 1$ and $|x| \ge 1$, it is any string of length at least 3 whose first and last symbols are equal. (Conversely, any such string works with $w$ = its first symbol, $x$ = the middle part, $w^R$ = its last symbol.) Checking only the first and last symbol, plus a length of at least 3, needs a finite automaton.

**$L_2$ is not regular.** If it were, then $\overline{L_2} \cap a^*b^*$ would be regular (closed under complement and intersection). That intersection is $\lbrace a^n b^n \rbrace$, which is not regular. Contradiction.

**$L_3$ is regular.** It is described by the regular expression $a^*b^*c^*$.

$L_1$ and $L_3$ only: option (A).

**Key idea:** $L_1$ collapses to "first symbol equals last symbol"; $L_2$ needs unbounded counting.

</details>
