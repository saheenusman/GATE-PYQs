# 2020 CS Q18: Union of regular languages and infinite union

## Question

Consider the following statements.

- I. If $L_1 \cup L_2$ is regular, then both $L_1$ and $L_2$ must be regular.
- II. The class of regular languages is closed under infinite union.

Which of the above statements is/are TRUE?

- (A) I only
- (B) II only
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Statement I is false.** Take $L_1 = \lbrace a^n b^n \mid n \ge 0 \rbrace$ (not regular) and $L_2 = \Sigma^*$ (regular). Then

$$L_1 \cup L_2 = \Sigma^*,$$

which is regular, yet $L_1$ is not.

**Statement II is false.** Each single string is a regular language, since a finite language is regular. Take $L_n = \lbrace a^n b^n \rbrace$ for $n = 0, 1, 2, \dots$ Each $L_n$ is regular, but

$$\bigcup_{n \ge 0} L_n = \lbrace a^n b^n \mid n \ge 0 \rbrace,$$

which is not regular. Regular languages are closed only under *finite* unions.

**Why the other options fail:** (A), (B) and (C) each claim at least one of the false statements.

**Key idea:** closure under union holds for two (hence finitely many) regular languages, but a union of infinitely many regular languages can be non-regular.

</details>
