# 2016 CS2 Q42: NFA with all accepting states and a regular language closed under every intersection

## Question

Consider the following two statements:

- I. If all states of an NFA are accepting states then the language accepted by the NFA is $\Sigma^*$.
- II. There exists a regular language $A$ such that for all languages $B$, $A \cap B$ is regular.

Which one of the following is CORRECT?

- (A) Only I is true
- (B) Only II is true
- (C) Both I and II are true
- (D) Both I and II are false

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I is false.** An NFA can have all states accepting and still reject strings: it only accepts a string if some run can *finish* (it can get stuck). For example, a one-state NFA over $\lbrace a, b \rbrace$ with a self-loop on $a$ only accepts $a^*$, not $\Sigma^*$.

**II is true.** Take $A = \emptyset$ (a regular language). Then $A \cap B = \emptyset$ is regular for every language $B$, including non-regular ones. (So is $A = $ any finite language.)

Only II is true: **(B)**.

**Key idea:** I fails when runs can get stuck; II holds with $A = \emptyset$.

</details>
