# 2011 CS Q24: Language operation that is always regular

## Question

Let $P$ be a regular language and $Q$ be a context-free language such that $Q \subseteq P$. (For example, let $P$ be the language represented by the regular expression $p^* q^*$ and $Q$ be $\lbrace p^n q^n \mid n \in \mathbb{N} \rbrace$.) Then which of the following is **ALWAYS** regular?

- (A) $P \cap Q$
- (B) $P - Q$
- (C) $\Sigma^* - P$
- (D) $\Sigma^* - Q$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the example $P = p^* q^*$, $Q = \lbrace p^n q^n \rbrace$.

- (A) $P \cap Q = Q$ because $Q \subseteq P$. Here it is $\lbrace p^n q^n \rbrace$, which is not regular.
- (B) $P - Q = \lbrace p^i q^j \mid i \ne j \rbrace$, which is not regular.
- (C) $\Sigma^* - P$ is the complement of a regular language. Regular languages are closed under complement, so this is **always regular**: (C).
- (D) $\Sigma^* - Q$ is regular only if $Q$ is regular (the complement of a regular language is regular). Here $Q$ is not regular, so it is not.

So the answer is (C).

**Key idea:** regular languages are closed under complement; intersecting with or subtracting a non-regular subset can break regularity.

</details>
