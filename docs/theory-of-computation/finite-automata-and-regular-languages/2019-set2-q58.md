# 2019 CS2 Q58: Minimum DFA states for permutations composing to the identity

## Question

Let $\Sigma$ be the set of all bijections from $\lbrace 1, \dots, 5 \rbrace$ to $\lbrace 1, \dots, 5 \rbrace$, where $id$ denotes the identity function, i.e. $id(j) = j,\ \forall j$. Let $\circ$ denote composition on functions. For a string $x = x_1 x_2 \cdots x_n \in \Sigma^*$, $n \ge 0$, let $\pi(x) = x_1 \circ x_2 \circ \cdots \circ x_n$.

Consider the language $L = \lbrace x \in \Sigma^* \mid \pi(x) = id \rbrace$. The minimum number of states in any DFA accepting $L$ is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**120**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The alphabet is all $5! = 120$ permutations, the group $S_5$. After reading a prefix $x$ the DFA only needs to remember the composed permutation $\pi(x)$. That gives **at most 120 states**, with start state $id$ and accepting state $id$.

**All 120 are reachable.** Reading the single symbol $p$ from the start reaches the state $p$.

**No two states can be merged.** Take states $p \ne q$. Read the symbol $p^{-1}$ next:

- from $p$ we reach $p \circ p^{-1} = id$, which accepts
- from $q$ we reach $q \circ p^{-1} \ne id$, which rejects

So $p$ and $q$ are distinguishable. There is also no dead state, since from any state you can return to $id$.

The minimum DFA has exactly **120** states.

**Code check:** the reachable set from $id$ has 120 permutations, and partition refinement on the 120-state machine ends with 120 classes.

**Key idea:** a DFA that tracks a group element needs one state per element. Inverses distinguish them all.

</details>
