# 2019 CS2 Q17: Which language operation does not keep regularity

## Question

If $L$ is a regular language over $\Sigma = \lbrace a, b \rbrace$, which one of the following languages is NOT regular?

- (A) $L \cdot L^R = \lbrace xy \mid x \in L,\ y^R \in L \rbrace$
- (B) $\lbrace ww^R \mid w \in L \rbrace$
- (C) $\mathrm{Prefix}(L) = \lbrace x \in \Sigma^* \mid \exists y \in \Sigma^* \text{ such that } xy \in L \rbrace$
- (D) $\mathrm{Suffix}(L) = \lbrace y \in \Sigma^* \mid \exists x \in \Sigma^* \text{ such that } xy \in L \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

(The paper prints $xy \subset L$ in option (C). It is read as $xy \in L$, the usual definition of prefix.)

**(B) is not regular in general.** Take $L = \Sigma^*$, which is regular. Then $\lbrace ww^R \mid w \in L\rbrace$ is the set of all even-length palindromes, which is not regular. So (B) can fail.

**The others are always regular:**

- (A) $y^R \in L$ means $y \in L^R$. Regular languages are closed under reversal and concatenation, so $L \cdot L^R$ is regular.
- (C) Prefix: in a DFA for $L$, make every state that can reach an accepting state accepting.
- (D) Suffix: let the NFA start from any state reachable from the old start state.

**Key idea:** closure properties. A counterexample with $L = \Sigma^*$ kills $\lbrace ww^R\rbrace$.

</details>
