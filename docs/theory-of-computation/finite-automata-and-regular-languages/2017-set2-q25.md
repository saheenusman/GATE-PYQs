# 2017 CS2 Q25: Minimum DFA states for L = { w1 a w2 : |w1| = 2, |w2| >= 3 }

## Question

The minimum possible number of states of a deterministic finite automaton that accepts the regular language $L = \lbrace w_1 a w_2 \mid w_1, w_2 \in \lbrace a, b \rbrace^*,\ |w_1| = 2,\ |w_2| \ge 3 \rbrace$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What the language says.** The 3rd symbol must be $a$, and at least 3 more symbols must follow it. So $L$ = strings of length $\ge 6$ whose 3rd symbol is $a$.

**States** (name = what has been seen):

| State | Meaning | Shortest suffix that leads to acceptance |
|---|---|---|
| $q_0$ | nothing read | 6 symbols |
| $q_1$ | 1 symbol read | 5 symbols |
| $q_2$ | 2 symbols read | $a$ + 3 symbols = 4 |
| $q_3$ | 3rd symbol was $a$ | 3 symbols |
| $q_4$ | 1 symbol after that | 2 symbols |
| $q_5$ | 2 symbols after that | 1 symbol |
| $q_6$ | $\ge 3$ symbols after that (accepting, loops on $a,b$) | 0 (already accepting) |
| dead | 3rd symbol was $b$ | none |

Transitions: $q_0 \xrightarrow{a,b} q_1 \xrightarrow{a,b} q_2$; $q_2 \xrightarrow{a} q_3$, $q_2 \xrightarrow{b}$ dead; $q_3 \to q_4 \to q_5 \to q_6$ on both letters; $q_6$ and dead loop on both letters.

**Minimal.** The "shortest accepting suffix" lengths are $6,5,4,3,2,1,0,\infty$, all different, so all 8 states are pairwise distinguishable. The minimum is **8**.

**Code check:** counting Myhill–Nerode classes by brute force (all prefixes up to length 8, tested against all suffixes up to length 8) gave exactly 8 classes.

**Key idea:** count distinguishable prefixes; here that is 7 "progress" states plus one dead state.

</details>
