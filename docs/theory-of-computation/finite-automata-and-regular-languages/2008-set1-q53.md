# 2008 CS Q53: Which of the given languages are regular

## Question

Which of the following are regular sets?

- I. $\lbrace a^n b^{2m} \mid n \ge 0,\ m \ge 0 \rbrace$
- II. $\lbrace a^n b^m \mid n = 2m \rbrace$
- III. $\lbrace a^n b^m \mid n \ne m \rbrace$
- IV. $\lbrace xcy \mid x, y \in \lbrace a, b \rbrace^* \rbrace$

Options:

- (A) I and IV only
- (B) I and III only
- (C) I only
- (D) IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I. Regular.** It is $a^*(bb)^*$: any number of $a$'s followed by an even number of $b$'s. No counting between the two blocks is needed.
- **II. Not regular.** To check $n = 2m$ the machine must remember the exact number of $a$'s read, which needs unbounded memory (pumping lemma).
- **III. Not regular.** Checking $n \ne m$ needs the same unbounded count (its complement within $a^*b^*$ is $\lbrace a^n b^n \rbrace$, which is not regular).
- **IV. Regular.** It is all strings over $\lbrace a, b, c \rbrace$ with exactly one $c$: $(a+b)^* c (a+b)^*$.

So I and IV: (A).

- (B) wrongly includes III, (C) leaves out IV, and (D) leaves out I.

**Key idea:** a language is regular when it needs only finitely many states; comparing two unbounded counts ($n = 2m$, $n \ne m$) does not.

</details>
