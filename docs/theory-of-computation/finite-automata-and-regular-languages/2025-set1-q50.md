# 2025 CS1 Q50: Language accepted by a four-state DFA

## Question

Consider the following deterministic finite automaton (DFA) defined over the alphabet $\Sigma = \lbrace a, b\rbrace$. Identify which of the following language(s) is/are accepted by the given DFA.

![A DFA with four states in a row, called q0 (start), q1, q2, q3 (accepting, double circle). q0 has a self-loop on a, and goes to q1 on b. q1 has a self-loop on b, and goes to q2 on a. q2 goes to q3 on b, and back to q0 on a. q3 goes to q2 on a, and back to q1 on b.](../../assets/2025/set1-q50.png)

- (A) The set of all strings containing an even number of $b$'s.
- (B) The set of all strings containing the pattern $bab$.
- (C) The set of all strings ending with the pattern $bab$.
- (D) The set of all strings not containing the pattern $aba$.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Read the transitions from the figure:

| State | on $a$ | on $b$ |
|---|---|---|
| $q_0$ (start) | $q_0$ | $q_1$ |
| $q_1$ | $q_2$ | $q_1$ |
| $q_2$ | $q_0$ | $q_3$ |
| $q_3$ (accepting) | $q_2$ | $q_1$ |

Each state records the **longest suffix read so far that is a prefix of $bab$**:

| State | Meaning |
|---|---|
| $q_0$ | no useful suffix ($\varepsilon$) |
| $q_1$ | suffix $b$ |
| $q_2$ | suffix $ba$ |
| $q_3$ | suffix $bab$ |

This is the standard pattern-matching automaton for **ending** in $bab$. Note that from $q_3$ the DFA does **not** stay: on $a$ it goes to $q_2$ and on $b$ to $q_1$, so it leaves the accepting state.

I checked the DFA against each description on every string of length at most 12:

| Option | Same language as the DFA? |
|---|---|
| A: even number of $b$'s | No. The DFA accepts $bbab$, which has 3 $b$'s |
| B: contains $bab$ | No. $babb$ contains $bab$, but the DFA rejects it (it ends in $q_1$) |
| **C: ends with $bab$** | **Yes** |
| D: does not contain $aba$ | No. The DFA accepts $ababab$, which contains $aba$. It also rejects $a$, which does not contain $aba$ |

**Key idea:** if the accepting state has outgoing transitions back into the automaton and no sink, the language is a *suffix* condition ("ends with"), not a "contains" condition.

</details>
