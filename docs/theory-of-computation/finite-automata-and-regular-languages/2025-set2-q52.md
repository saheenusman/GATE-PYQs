# 2025 CS2 Q52: Which languages are regular

## Question

Let $\Sigma = \lbrace a,b,c\rbrace$. For $x \in \Sigma^*$, and $\alpha \in \Sigma$, let $\#_\alpha(x)$ denote the number of occurrences of $\alpha$ in $x$.

Which one or more of the following option(s) define(s) regular language(s)?

- (A) $\lbrace a^m b^n \mid m,n \ge 0\rbrace$
- (B) $\lbrace a,b\rbrace^* \cap \lbrace a^m b^n c^{m-n} \mid m \ge n \ge 0\rbrace$
- (C) $\lbrace w \mid w \in \lbrace a,b\rbrace^*,\ \#_a(w) \equiv 2 \pmod 7 \text{ and } \#_b(w) \equiv 3 \pmod 9\rbrace$
- (D) $\lbrace w \mid w \in \lbrace a,b\rbrace^*,\ \#_a(w) \equiv 2 \pmod 7 \text{ and } \#_a(w) = \#_b(w)\rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) Regular.** It is the language of $a^*b^*$.

**(B) Not regular.** Strings in $\lbrace a,b\rbrace^*$ contain no $c$. In $a^mb^nc^{m-n}$ the number of $c$'s is $m-n$, so a string with no $c$ needs $m - n = 0$. The intersection is $\lbrace a^nb^n \mid n \ge 0\rbrace$, which is the classic non-regular language.

**(C) Regular.** Track $\#_a \bmod 7$ and $\#_b \bmod 9$ together in one state: $7 \times 9 = 63$ states. Accept in the state $(2, 3)$. This is a DFA.

**(D) Not regular.** The condition $\#_a = \#_b$ needs unbounded counting. Intersecting with the regular set $a^*b^*$ leaves $\lbrace a^nb^n \mid n \equiv 2 \pmod 7\rbrace$, which is not regular (the pumping lemma applies as for $a^nb^n$).

**Key idea:** counting *modulo* a constant needs finitely many states; comparing two unbounded counts does not.

</details>
