# 2017 CS1 Q22: Minimum DFA states for (a+b)*b(a+b)

## Question

Consider the language $L$ given by the regular expression $(a+b)^{*}\,b\,(a+b)$ over the alphabet $\lbrace a, b\rbrace$. The smallest number of states needed in a deterministic finite-state automaton (DFA) accepting $L$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The language.** $L$ is the set of strings whose **second-last symbol is $b$**.

**What a DFA must remember.** To decide at the end, it must know the last two symbols, so the states are

$$\lbrace aa,\ ab,\ ba,\ bb\rbrace$$

(use $aa$ for the start state, since a missing symbol behaves like $a$). On input $c$, state $xy$ moves to $yc$. The accepting states are $ba$ and $bb$.

**All four are needed.** One symbol separates each pair:

- $ba, bb$ (accepting) vs $aa, ab$ (rejecting): separated by the empty string.
- $aa$ vs $ab$: append $a$. $aa \to aa$ (reject) but $ab \to ba$ (accept).
- $ba$ vs $bb$: append $a$. $ba \to aa$ (reject) but $bb \to ba$ (accept).

So no two states merge. The minimum is **4**.

**Code check:** subset construction from the 3-state NFA gave 4 DFA states, and partition refinement left them in 4 classes.

**Key idea:** "$k$-th symbol from the end is $b$" needs $2^k$ DFA states; here $k=2$.

</details>
