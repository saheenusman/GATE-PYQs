# 2008 CS Q9: Language of strings a^p with p prime

## Question

Which of the following is true for the language $\lbrace a^p \mid p \text{ is a prime} \rbrace$?

- (A) It is not accepted by a Turing Machine
- (B) It is regular but not context-free
- (C) It is context-free but not regular
- (D) It is neither regular nor context-free, but accepted by a Turing machine

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Not regular.** Suppose it were regular with pumping length $n$. Take a prime $p \ge n$ and pump: $a^p = xyz$ with $|y| = k \ge 1$. Then $xy^{p+1}z = a^{p + pk} = a^{p(k+1)}$, whose length $p(k+1)$ is composite. So the pumped string is not in the language, a contradiction.

**Not context-free.** The same idea works with the CFL pumping lemma: for $uvwxy$ with $|vx| = k \ge 1$, the string $uv^{p+1}wx^{p+1}y$ has length $p + pk = p(k+1)$, which is composite. (Also, over a one-letter alphabet every CFL is regular, so "not regular" already gives "not CFL".)

**Accepted by a Turing machine.** Primality is decidable: count the $a$'s and test divisibility. A TM can do this, so the language is even decidable.

So the language is neither regular nor context-free, but it is accepted by a TM: (D).

- (A) is false: primality testing is easy for a TM.
- (B) and (C) are false: it is not regular, so (B) fails; it is not context-free, so (C) fails.

**Key idea:** $\lbrace a^p \mid p \text{ prime}\rbrace$ is a unary language whose lengths follow a non-arithmetic pattern, so pumping kills regular and context-free, but a TM can test primality.

</details>
