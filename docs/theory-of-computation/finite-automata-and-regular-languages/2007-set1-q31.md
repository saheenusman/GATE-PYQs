# 2007 CS Q31: Which language is regular

## Question

Which of the following languages is regular?

- (A) $\lbrace ww^R \mid w \in \lbrace 0,1 \rbrace^+ \rbrace$
- (B) $\lbrace ww^R x \mid x, w \in \lbrace 0,1 \rbrace^+ \rbrace$
- (C) $\lbrace wxw^R \mid x, w \in \lbrace 0,1 \rbrace^+ \rbrace$
- (D) $\lbrace xww^R \mid x, w \in \lbrace 0,1 \rbrace^+ \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(C) is regular.** A string is in $\lbrace wxw^R \rbrace$ exactly when it has length $\ge 3$ and its first and last symbols are equal. ($\Leftarrow$: take $w$ to be the first symbol and $x$ the middle part. $\Rightarrow$: the first symbol of $w$ is the last symbol of $w^R$.) A DFA only needs to remember the first symbol and the last symbol seen, so it is regular.

- (A) $\lbrace ww^R \rbrace$ is the even-length palindromes, a standard non-regular language (needs to remember the first half).
- (B) The prefix $ww^R$ can be arbitrarily long and the automaton must match it, so it is not regular. It is also the reversal of (D) (reverse $ww^Rx$ to get $x^R w w^R$, and $x^R$ ranges over $\lbrace 0,1 \rbrace^+$). Regular languages are closed under reversal, so (B) and (D) are either both regular or both not.
- (D) is therefore non-regular too.

**Code check:** Python Myhill-Nerode experiment: counting distinct rows of the membership table for prefixes and suffixes up to length 4, 6, 8, 10 gives 7, 7, 7, 7 classes for (C) (stays constant, so regular) but 31, 127, 511, 2047 for (A), 10, 34, 110, 398 for (B) and 11, 30, 92, 316 for (D) (growing without bound, so non-regular). The non-regularity of (B) and (D) is therefore supported by this experiment and by the reversal argument; I did not write out a pumping-lemma proof.

**Key idea:** $wxw^R$ with a free middle only constrains the first and last symbols, which a DFA can store; matching a whole half needs a stack.
