# 2024 CS2 Q62: Strings of length at most 4 with an odd number of a's

## Question

Let $L_1$ be the language represented by the regular expression $b^*ab^*(ab^*ab^*)^*$ and $L_2 = \lbrace w \in (a+b)^* \mid |w| \le 4 \rbrace$, where $|w|$ denotes the length of string $w$. The number of strings in $L_2$ which are also in $L_1$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**15**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Describe $L_1$.** One mandatory $a$, then any number of pairs $ab^*ab^*$. Each pair adds two $a$s. So $L_1$ is the set of strings with an **odd number of $a$s**.

**Count strings of length $n$ with an odd number of $a$s:** exactly half of the $2^n$ strings, i.e. $2^{n-1}$ (for $n \ge 1$).

| Length | Strings with odd $a$s |
|---|---|
| 1 | 1 |
| 2 | 2 |
| 3 | 4 |
| 4 | 8 |

Total $= 1 + 2 + 4 + 8 = 15$. (A brute-force regex match gave 15 as well.)

**Key idea:** for a fixed length, exactly half of the binary strings have an odd count of any symbol.

</details>
