# 2023 CS Q63: Minimum DFA: no three consecutive 1s

## Question

Consider the language $L$ over the alphabet $\lbrace 0, 1 \rbrace$, given below:

$L = \lbrace w \in \lbrace 0,1 \rbrace^* \mid w \text{ does not contain three or more consecutive 1's} \rbrace$.

The minimum number of states in a Deterministic Finite-State Automaton (DFA) for $L$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Remember how many 1s end the input so far.** Four situations are different from the future's point of view:

| State | Meaning | Final? |
|---|---|---|
| $q_0$ | last symbol is 0 (or start) | yes |
| $q_1$ | ends with exactly one 1 | yes |
| $q_2$ | ends with exactly two 1s | yes |
| $q_3$ | seen $111$ | no (dead) |

Transitions: $q_0 \xrightarrow{0} q_0$, $q_0 \xrightarrow{1} q_1$, $q_1 \xrightarrow{0} q_0$, $q_1 \xrightarrow{1} q_2$, $q_2 \xrightarrow{0} q_0$, $q_2 \xrightarrow{1} q_3$, and $q_3$ loops on both symbols.

**No two of these can be merged.** Each pair is told apart by some suffix:

- $q_3$ vs the rest: the empty suffix (only $q_3$ rejects).
- $q_2$ vs $q_0$ or $q_1$: the suffix $1$ (from $q_2$ it reaches $q_3$ and rejects).
- $q_1$ vs $q_0$: the suffix $11$ (from $q_1$ it rejects, from $q_0$ it accepts).

**Code check:** grouping all strings up to length 5 by how they behave with every suffix gave exactly 4 classes (Myhill–Nerode).

**Key idea:** count the Myhill–Nerode classes. A complete DFA also needs the dead state.

</details>
