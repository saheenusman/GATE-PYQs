# 2012 CS Q25: Membership in L star for L equal to ab, aa, baa

## Question

Given the language $L = \lbrace ab, aa, baa \rbrace$, which of the following strings are in $L^*$?

1. `abaabaaabaa`
2. `aaaabaaaa`
3. `baaaaabaaaab`
4. `baaaaabaa`

Options:

- (A) 1, 2 and 3
- (B) 2, 3 and 4
- (C) 1, 2 and 4
- (D) 1, 3 and 4

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A string is in $L^*$ if it splits into words from $L$.

| # | String | Split | In $L^*$? |
|---|---|---|---|
| 1 | `abaabaaabaa` | `ab` `aa` `baa` `ab` `aa` | yes |
| 2 | `aaaabaaaa` | `aa` `aa` `baa` `aa` | yes |
| 3 | `baaaaabaaaab` | none | **no** |
| 4 | `baaaaabaa` | `baa` `aa` `baa` | yes |

For 3: the string must start with `baa`, and the last `b` can only end a word `ab` (needs an `a` just before it) or start `baa` (needs two letters after it). After `baa` the rest is `aaabaaaab`. Taking `aa`, then `ab` leaves `aaaab`, which ends in a lone `b` that no split can absorb.

So 1, 2 and 4: (C).

**Code check:** a dynamic-programming membership test gave true, true, false, true for strings 1 to 4.

**Key idea:** to test $w \in L^*$, check that it can be cut into pieces from $L$; every `b` must sit inside `ab` or `baa`.

</details>
