# 2021 CS1 Q48: DFA for strings ending in 011

## Question

Consider the following language.

$$L=\lbrace w\in\lbrace0,1\rbrace^*\mid w \text{ ends with the substring } 011\rbrace$$

Which one of the following deterministic finite automata accepts $L$?

![Four DFAs (A) to (D), each with four states in a row. The first state is the start state and has a loop on 1, and 0 leads to the second state, which has a loop on 0 and goes to the third state on 1. The third state goes back to the second on 0 and to the fourth on 1. The fourth state is accepting. (A) has a loop on 1 at the fourth state and 0 back to the second. (B) has a loop on 0 and 1 at the fourth state. (C) sends 1 from the fourth state back to the third and 0 back to the second. (D) sends 1 from the fourth state back to the start state and 0 back to the second.](../../assets/2021/set1-q48.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Name the states by the longest useful suffix read: $q_0$ (none), $q_1$ (ends in 0), $q_2$ (ends in 01), $q_3$ (ends in 011, accepting).

Correct transitions: $q_0$: 0 to $q_1$, 1 to $q_0$. $q_1$: 0 to $q_1$, 1 to $q_2$. $q_2$: 0 to $q_1$, 1 to $q_3$. $q_3$: 0 to $q_1$ (suffix 0), **1 to $q_0$** (suffix 11 helps no pattern).

- (A) $q_3$ loops on 1, so it accepts `0111`, which does not end in 011. Wrong.
- (B) $q_3$ is absorbing, so it accepts `0110`. Wrong.
- (C) $q_3$ goes to $q_2$ on 1, so it accepts `01111`. Wrong.
- (D) **Correct.** It has exactly the transitions above.

I coded all four machines as read from the figure and compared them with "ends with 011" on every string up to length 10. A fails on `0111`, B on `0110`, C on `01111`, and D has no mismatch.

**Key idea:** in a DFA for "ends with $s$", each state remembers the longest suffix that is a prefix of $s$.

</details>
