# 2021 CS2 Q46: Infinite regular languages and undecidable subsets

## Question

Consider the following two statements about regular languages:

$S_1$: Every infinite regular language contains an undecidable language as a subset.

$S_2$: Every finite language is regular.

Which one of the following choices is correct?

- (A) Only $S_1$ is true.
- (B) Only $S_2$ is true.
- (C) Both $S_1$ and $S_2$ are true.
- (D) Neither $S_1$ nor $S_2$ is true.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$S_2$ is true.** A finite language $\lbrace w_1,\dots,w_k\rbrace$ is the regular expression $w_1+\dots+w_k$ (or $\emptyset$ for the empty language).

**$S_1$ is true.** A counting argument works.

- An infinite regular language $L$ is a countably infinite set of strings.
- A countably infinite set has uncountably many subsets (its power set).
- Every decidable language is decided by some Turing machine, and there are only countably many Turing machines, so there are only countably many decidable languages.

Hence some subset of $L$ is not decidable. Note that $S_1$ asks for a subset that is undecidable. It does not say $L$ itself is undecidable (it is regular, so it is decidable).

Both are true, so (C).

**Key idea:** an infinite set has uncountably many subsets, but only countably many languages are decidable.

</details>
