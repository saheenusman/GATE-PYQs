# 2008 CS Q52: Matching NFAs with regular expressions

## Question

Match the following NFAs with the regular expressions they correspond to.

![Four NFAs labelled P, Q, R and S. Each has three states: a top-left state A, a right state B and a bottom state C. The start arrow points at C. In every machine C has an edge labelled 0 to A and A has an edge to B and an edge to C. B has a self-loop and an edge labelled 1 back to A. In P: A goes to B on 0 and to C on 0, B loops on 1, and B and C are accepting. In Q: A goes to B on 1 and to C on 0, B loops on 0, and only C is accepting. In R: A goes to B on 1 and to C on 1, B loops on 0, and only C is accepting. In S: the same as R but B is also accepting.](../../assets/2008/set1-q52.png)

1. $\varepsilon + 0(01^*1 + 00)^*01^*$
2. $\varepsilon + 0(10^*1 + 00)^*0$
3. $\varepsilon + 0(10^*1 + 10)^*1$
4. $\varepsilon + 0(10^*1 + 10)^*10^*$

- (A) P - 2, Q - 1, R - 3, S - 4
- (B) P - 1, Q - 3, R - 2, S - 4
- (C) P - 1, Q - 2, R - 3, S - 4
- (D) P - 3, Q - 2, R - 1, S - 4

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Call the states A (top-left), B (right) and C (bottom, the start state). In every machine C is accepting and has only one move: C $\xrightarrow{0}$ A. So each language starts with $\varepsilon$ or with $0$, then continues from A. That is why every expression has the shape $\varepsilon + 0(\ldots)^*(\ldots)$.

From A, a **loop back to A** and a way to **finish** gives the middle and the tail:

| NFA | Loops from A back to A | Ways to stop (accepting) | Language |
|---|---|---|---|
| P | via B: $0\,1^*\,1$; via C: $0\,0$ | A $\xrightarrow{0}$ B then $1^*$ (B accepts); A $\xrightarrow{0}$ C ($= 01^*$ with no 1) | $\varepsilon + 0(01^*1 + 00)^*01^*$ = **1** |
| Q | via B: $1\,0^*\,1$; via C: $0\,0$ | A $\xrightarrow{0}$ C | $\varepsilon + 0(10^*1 + 00)^*0$ = **2** |
| R | via B: $1\,0^*\,1$; via C: $1\,0$ | A $\xrightarrow{1}$ C | $\varepsilon + 0(10^*1 + 10)^*1$ = **3** |
| S | as R | A $\xrightarrow{1}$ C, or A $\xrightarrow{1}$ B then $0^*$ (B accepts) | $\varepsilon + 0(10^*1 + 10)^*10^*$ = **4** |

So P-1, Q-2, R-3, S-4: (C).

- (A), (B) and (D) each pair at least one machine with the wrong expression. For example, in (D) R-1 fails because $001$ is generated by expression 1 but is not accepted by R.

**Code check:** I encoded the four NFAs and the four expressions and compared them on all binary strings of length up to 12. Each NFA matched exactly one expression: P with 1, Q with 2, R with 3, S with 4.

**Key idea:** read an NFA as "path from the start to the first return to a hub state, repeated, then a final path", and compare it with the shape of the expression.

</details>
