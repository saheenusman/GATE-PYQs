# 2025 CS1 Q28: False statements about an n-state NFA

## Question

A regular language $L$ is accepted by a non-deterministic finite automaton (NFA) with $n$ states. Which of the following statement(s) is/are FALSE?

- (A) $L$ may have an accepting NFA with $< n$ states.
- (B) $L$ may have an accepting DFA with $< n$ states.
- (C) There exists a DFA with $\le 2^n$ states that accepts $L$.
- (D) Every DFA that accepts $L$ has $> 2^n$ states.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The question asks for the **false** statements.

| Option | True or false | Reason |
|---|---|---|
| A | True | The given NFA need not be minimal. For example a 3-state NFA for $a^*$ can be replaced by a 1-state NFA |
| B | True | Same example: the minimal DFA for $a^*$ has 1 state, which is fewer than $n$ |
| C | True | The **subset construction** turns an $n$-state NFA into a DFA with at most $2^n$ states (one per subset) |
| **D** | **False** | $2^n$ is only an **upper bound**. Many languages need far fewer, for instance $a^*$ needs just 1 state |

Only (D) is false.

**Key idea:** NFA to DFA may blow up to $2^n$ states in the worst case. It is not always needed, and no DFA is forced to be that large.

</details>
