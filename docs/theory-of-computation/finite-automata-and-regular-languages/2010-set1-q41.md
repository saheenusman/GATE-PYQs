# 2010 CS Q41: Minimum NFA size for all substrings of a length-n string

## Question

Let $w$ be any string of length $n$ in $\lbrace 0, 1 \rbrace^*$. Let $L$ be the set of all substrings of $w$. What is the minimum number of states in a non-deterministic finite automaton that accepts $L$?

- (A) $n - 1$
- (B) $n$
- (C) $n + 1$
- (D) $2^{n-1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Upper bound.** Build a chain $q_0 \to q_1 \to \dots \to q_n$ where the arrow $q_{i-1} \to q_i$ reads the $i$-th symbol of $w$. Make every state accepting, and add $\varepsilon$-moves from $q_0$ to every $q_i$ so a substring can start anywhere. That is $n + 1$ states, and it accepts exactly the substrings of $w$.

**Lower bound.** $w$ itself is in $L$, so the NFA has an accepting path with $n$ transitions. If a state repeated on that path, the loop could be pumped to accept strings longer than $n$. But $L$ has no string longer than $n$. So all $n + 1$ states on the path are distinct.

The minimum is $n + 1$: (C).

- (A) and (B) are too small by the pumping argument.
- (D) $2^{n-1}$ is the kind of blow-up a DFA can need, not an NFA.

**Key idea:** a finite language whose longest word has length $n$ needs at least $n + 1$ states, and a chain with $\varepsilon$-entries reaches that bound.

</details>
