# 2016 CS2 Q17: Regularity of languages given by two simple grammars

## Question

Language $L_1$ is defined by the grammar: $S_1 \rightarrow aS_1b \mid \varepsilon$

Language $L_2$ is defined by the grammar: $S_2 \rightarrow abS_2 \mid \varepsilon$

Consider the following statements:

- P: $L_1$ is regular
- Q: $L_2$ is regular

Which one of the following is TRUE?

- (A) Both P and Q are true
- (B) P is true and Q is false
- (C) P is false and Q is true
- (D) Both P and Q are false

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- $L_1 = \lbrace a^n b^n \mid n \ge 0 \rbrace$ needs to count the $a$'s, so it is **not regular** (pumping lemma). P is false.
- $L_2 = \lbrace (ab)^n \mid n \ge 0 \rbrace = (ab)^*$ is **regular**. Q is true.

So P is false and Q is true: **(C)**.

**Key idea:** $L_1 = a^n b^n$ is not regular; $L_2 = (ab)^*$ is.

</details>
