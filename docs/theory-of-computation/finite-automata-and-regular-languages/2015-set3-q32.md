# 2015 CS3 Q32: Minimum states of a DFA for the complement of a language

## Question

Let $L$ be the language represented by the regular expression $\Sigma^*0011\Sigma^*$ where $\Sigma = \lbrace 0, 1 \rbrace$. What is the minimum number of states in a DFA that recognizes $\overline{L}$ (complement of $L$)?

- (A) 4
- (B) 5
- (C) 6
- (D) 8

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$L$ is the set of strings that contain $0011$. A DFA for it tracks the longest prefix of $0011$ seen as a suffix:

| State | Meaning | on 0 | on 1 |
|---|---|---|---|
| $q_0$ | nothing | $q_1$ | $q_0$ |
| $q_1$ | `0` | $q_2$ | $q_0$ |
| $q_2$ | `00` | $q_2$ | $q_3$ |
| $q_3$ | `001` | $q_1$ | $q_4$ |
| $q_4$ | `0011` seen | $q_4$ | $q_4$ |

For $L$, only $q_4$ accepts. For $\overline{L}$ (complete DFA, swap accepting and rejecting), $q_0$ to $q_3$ accept and $q_4$ is a rejecting trap. Complementing a complete DFA keeps the same number of states.

**All 5 are distinguishable:**

- $q_4$ vs the rest: only $q_4$ rejects.
- $q_3$ vs $q_0, q_1, q_2$: input `1` sends $q_3$ to the trap, and the others stay accepting.
- $q_2$ vs $q_0, q_1$: input `11` sends $q_2$ to the trap, while $q_0, q_1$ stay accepting.
- $q_1$ vs $q_0$: input `011` sends $q_1$ to the trap, and $q_0$ stays accepting.

So the minimum is **5**: option (B). (A) 4 would merge two distinguishable states.

**Code check:** partition refinement on this DFA leaves 5 classes.

**Key idea:** a complete minimal DFA for $L$ and for $\overline{L}$ have the same number of states.

</details>
