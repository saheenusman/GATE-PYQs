# 2014 CS2 Q36: Counting occurrences: 110 vs 011, and 000 vs 111

## Question

Let $L_1 = \lbrace w \in \lbrace 0,1 \rbrace^* \mid w \text{ has at least as many occurrences of (110)'s as (011)'s} \rbrace$. Let $L_2 = \lbrace w \in \lbrace 0,1 \rbrace^* \mid w \text{ has at least as many occurrences of (000)'s as (111)'s} \rbrace$. Which one of the following is TRUE?

- (A) $L_1$ is regular but not $L_2$
- (B) $L_2$ is regular but not $L_1$
- (C) Both $L_1$ and $L_2$ are regular
- (D) Neither $L_1$ nor $L_2$ are regular

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_1$ is regular.** Occurrences may overlap, but each is tied to a maximal block of 1s of length $\ge 2$:

- a 011 occurs once at the start of such a block if a 0 comes **before** it,
- a 110 occurs once at the end of such a block if a 0 comes **after** it.

A block in the middle of the string gives one of each. Only a block at the very start (no 0 before) or at the very end (no 0 after) gives one without the other. So $\#110 - \#011 \in \lbrace -1, 0, 1 \rbrace$ always, and the difference depends only on how the string starts and ends. A DFA with a few states can track that, so $L_1$ is regular.

**Code check:** over all binary strings up to length 18, $|\#110 - \#011| \le 1$. For 000 versus 111 the difference reaches 16.

**$L_2$ is not regular.** Intersect with the regular language $0^*1^*$. A string $0^a1^b$ with $a, b \ge 3$ has $a-2$ occurrences of 000 and $b-2$ of 111, so it is in $L_2$ iff $a \ge b$. The intersection $\lbrace 0^a1^b \mid a \ge b \ge 3 \rbrace$ is not regular (pumping lemma), and regular languages are closed under intersection, so $L_2$ is not regular.

So (A). (B), (C) and (D) each get at least one wrong.

**Key idea:** if two counts can differ by at most a constant, a DFA can track the difference; if the difference is unbounded, it cannot.

</details>
