# 2008 CS Q49: Product automaton of two finite automata

## Question

Given below are two finite state automata ($\to$ indicates the start state and F indicates a final state).

**Y:**

| | a | b |
|---|---|---|
| $\to 1$ | 1 | 2 |
| 2 (F) | 2 | 1 |

**Z:**

| | a | b |
|---|---|---|
| $\to 1$ | 2 | 2 |
| 2 (F) | 1 | 1 |

Which of the following represents the product automaton $Z \times Y$?

**(A)**

| | a | b |
|---|---|---|
| $\to P$ | S | R |
| Q | R | S |
| R (F) | Q | P |
| S | Q | P |

**(B)**

| | a | b |
|---|---|---|
| $\to P$ | S | Q |
| Q | R | S |
| R (F) | Q | P |
| S | P | Q |

**(C)**

| | a | b |
|---|---|---|
| $\to P$ | Q | S |
| Q | R | S |
| R (F) | Q | P |
| S | Q | P |

**(D)**

| | a | b |
|---|---|---|
| $\to P$ | S | Q |
| Q | S | R |
| R (F) | Q | P |
| S | Q | P |

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is (A). Computing the product, I find that **no option matches exactly**. Both views follow.

**The product.** A state of $Z \times Y$ is a pair $(z, y)$. The start state is $(1,1)$ and the final state is $(2,2)$ (both components final). Both machines move on the same symbol:

| State | Pair | on a | on b |
|---|---|---|---|
| $\to P$ | $(1,1)$ | $(2,1)$ | $(2,2)$ |
| $Q$ | $(1,2)$ | $(2,2)$ | $(2,1)$ |
| $R$ (F) | $(2,2)$ | $(1,2)$ | $(1,1)$ |
| $S$ | $(2,1)$ | $(1,1)$ | $(1,2)$ |

Naming $(2,1) = S$ and $(2,2) = R$ (forced by $P$'s row and the final state), this is the table:

| | a | b |
|---|---|---|
| $\to P$ | S | R |
| Q | R | S |
| R (F) | Q | P |
| S | P | Q |

**Comparison with the options** (counting differing table entries out of 8, with the best possible naming of states):

- (A) differs only in row $S$ (it has $Q, P$ instead of $P, Q$): **2 entries**.
- (B) differs only in the $b$-entry of row $P$ (it has $Q$ instead of $R$): **1 entry**.
- (C) differs in **4** entries and (D) in **5**.

So (A) is close to the correct table and the key's choice, but it is not exactly the product automaton. By entry count (B) is even closer, though it is also not exact. I record the key (A) and mark the question disputed, since none of the printed tables is correct as given.

**Code check:** a script built the product automaton, tried every naming of the four states with $P$ as start and $R$ as final, and counted mismatches against each option: A 2, B 1, C 4, D 5, and none 0.

**Key idea:** the product automaton runs both machines on the same input, and its final states are the pairs where both are final.
