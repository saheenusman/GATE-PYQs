# 2018 CS Q16: Size of the minimal DFA for an n-state NFA

## Question

Let $N$ be an NFA with $n$ states. Let $k$ be the number of states of a minimal DFA which is equivalent to $N$. Which one of the following is necessarily true?

- (A) $k \ge 2^n$
- (B) $k \ge n$
- (C) $k \le n^2$
- (D) $k \le 2^n$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Subset construction.** Each DFA state stands for a subset of the NFA's $n$ states, so the equivalent DFA has at most $2^n$ states. The *minimal* DFA is never larger, so $k \le 2^n$.

**Why the others fail:**
- **A** ($k\ge 2^n$): false. An NFA for $\Sigma^*$ with $n$ states has a 1-state minimal DFA.
- **B** ($k\ge n$): false for the same example.
- **C** ($k\le n^2$): false. The language "the $n$-th symbol from the end is 1" has an NFA with $n+1$ states but needs $2^n$ DFA states.

**Key idea:** NFA to DFA can blow up states exponentially ($2^n$ is the upper bound), but it can also shrink them.

</details>
