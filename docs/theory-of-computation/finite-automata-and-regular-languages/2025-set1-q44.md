# 2025 CS1 Q44: Are alpha-beta-alpha languages regular

## Question

Consider the following two languages over the alphabet $\lbrace a, b\rbrace$:

$$L_1 = \lbrace \alpha\beta\alpha \mid \alpha \in \lbrace a,b\rbrace^{+} \text{ AND } \beta \in \lbrace a,b\rbrace^{+}\rbrace$$

$$L_2 = \lbrace \alpha\beta\alpha \mid \alpha \in \lbrace a\rbrace^{+} \text{ AND } \beta \in \lbrace a,b\rbrace^{+}\rbrace$$

Which ONE of the following statements is CORRECT?

- (A) Both $L_1$ and $L_2$ are regular languages.
- (B) $L_1$ is a regular language but $L_2$ is not a regular language.
- (C) $L_1$ is not a regular language but $L_2$ is a regular language.
- (D) Neither $L_1$ nor $L_2$ is a regular language.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_2$ is regular.** Here $\alpha$ is a block of $a$'s, so a string is in $L_2$ iff it can be split as $a^k\,\beta\,a^k$. Taking $k=1$ always works if the string starts with $a$, ends with $a$, and has length $\ge 3$ (then $\beta$ is the non-empty middle). Conversely every string of $L_2$ starts and ends with $a$ and has length $\ge 3$. So

$$L_2 = a\,(a+b)^+\,a,$$

which is regular. (Checked against the definition for all strings of length up to 9.)

**$L_1$ is not regular.** Here $\alpha$ may be any string, so $\alpha$ can start with $a$ and end with $b$. Intersect $L_1$ with the regular language $a b^+ a b^+$. For $w = a b^p a b^q$, the string $\alpha$ is both a prefix and a suffix of $w$, so it starts with $a$. The only suffixes of $w$ that start with $a$ are $w$ itself and $a b^q$, so $\alpha = a b^q$. That is a prefix of $w$ only if $q \le p$, and $\beta$ must be non-empty, which needs $|w| \ge 2|\alpha| + 1$, i.e. $p > q$. Hence

$$L_1 \cap a b^+ a b^+ = \lbrace a b^p a b^q \mid p > q \ge 1\rbrace,$$

which is not regular (it compares two unbounded counts). Regular languages are closed under intersection, so $L_1$ cannot be regular.

**Myhill-Nerode view.** After reading $ab^pa$, the suffix $b^q$ ($q \ge 1$) is accepted exactly when $q < p$. So the strings $ab^pa$ for different $p \ge 2$ are pairwise distinguishable, giving infinitely many classes. I confirmed by computer that the seven strings $p = 2,\dots,8$ have seven different acceptance patterns.

| Option | Verdict |
|---|---|
| A, B | Say $L_1$ regular: false |
| **C** | Correct |
| D | Says $L_2$ not regular: false |

**Key idea:** if $\alpha$ is restricted to one repeated letter, "starts and ends with the same letter" is all that matters (regular). If $\alpha$ is arbitrary, the matching of the whole prefix with the suffix needs unbounded memory.

</details>
