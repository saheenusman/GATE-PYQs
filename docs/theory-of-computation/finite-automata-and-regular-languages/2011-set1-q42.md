# 2011 CS Q42: Minimum DFA states for strings of length a multiple of n

## Question

Definition of a language $L$ with alphabet $\lbrace a \rbrace$ is given as following.

$L = \lbrace a^{nk} \mid k > 0, \text{ and } n \text{ is a positive integer constant} \rbrace$

What is the minimum number of states needed in a DFA to recognize $L$?

- (A) $k + 1$
- (B) $n + 1$
- (C) $2^{n+1}$
- (D) $2^{k+1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$L$ contains the strings $a^m$ with $m > 0$ and $m$ a multiple of $n$.

A DFA must count the length modulo $n$, which needs $n$ states $q_0, \ldots, q_{n-1}$ (state $q_i$ means length $\equiv i \pmod n$), with $q_0$ accepting. But the **empty string** has length $0 \equiv 0 \pmod n$ and is *not* in $L$, while $a^n$ is. So the start state must be distinct from the accepting $q_0$ reached after at least one symbol. That adds one more state.

Total: $n + 1$ states: (B).

Myhill-Nerode check: the classes are $\varepsilon$ and one class for each residue of $m \bmod n$ with $m \ge 1$, which is $n + 1$ classes.

- (A) $k + 1$: $k$ is a bound variable of the language, not a parameter of the automaton.
- (C), (D) are exponential and never needed for a unary counter.

**Code check:** the number of Myhill-Nerode classes of $L$ for $n = 1, \ldots, 6$ was $2, 3, 4, 5, 6, 7$, that is $n + 1$.

**Key idea:** counting modulo n takes n states, and the empty string (not in L) needs one extra start state.

</details>
