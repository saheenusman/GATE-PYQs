# 2022 CS Q12: Regular expression for a given finite automaton

## Question

Which one of the following regular expressions correctly represents the language of the finite automaton given below?

![An automaton with a non-accepting start state and two accepting states. From the start state, a goes to the top accepting state and b goes to the bottom accepting state. The top accepting state loops on b and returns to the start state on b. The bottom accepting state loops on a and returns to the start state on a.](../../assets/2022/set1-q12.png)

- (A) $ab^*bab^* + ba^*aba^*$
- (B) $(ab^*b)^*ab^* + (ba^*a)^*ba^*$
- (C) $(ab^*b + ba^*a)^*(a^* + b^*)$
- (D) $(ba^*a + ab^*b)^*(ab^* + ba^*)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read the automaton.** Call the start state $q_0$ (not accepting), the top state $q_1$ and the bottom state $q_2$ (both accepting).

- $q_0 \xrightarrow{a} q_1$, $q_1 \xrightarrow{b} q_1$, $q_1 \xrightarrow{b} q_0$
- $q_0 \xrightarrow{b} q_2$, $q_2 \xrightarrow{a} q_2$, $q_2 \xrightarrow{a} q_0$

The automaton is nondeterministic: on $b$, $q_1$ can stay or return to $q_0$.

**Loops back to $q_0$.** One round trip is either $a\,b^*\,b$ (go to $q_1$, loop on $b$, return on $b$) or $b\,a^*\,a$. So any number of round trips is $(ab^*b + ba^*a)^*$.

**Ending.** Stop in $q_1$ after $a\,b^*$, or in $q_2$ after $b\,a^*$. Total language:

$$(ba^*a + ab^*b)^*\,(ab^* + ba^*)$$

which is option D. The empty string is not accepted because $q_0$ is not accepting, and D does not generate it.

**Why the others fail** (shortest strings where they differ from the automaton):
- (A) rejects $a$, which the automaton accepts.
- (B) cannot mix the two kinds of round trips. It rejects $abbaa$, which the automaton accepts.
- (C) generates the empty string, which the automaton rejects.

**Code check:** each expression and the NFA were compared on all strings over $\lbrace a, b \rbrace$ up to length 10. Only D agrees everywhere.

**Key idea:** write the language as (round trips back to the start)* followed by one way of ending in an accepting state.

</details>
