# 2017 CS2 Q39: Extended transition function of an epsilon-NFA on the string aba

## Question

Let $\delta$ denote the transition function and $\hat\delta$ denote the extended transition function of the $\epsilon$-NFA whose transition table is given below:

| $\delta$ | $\epsilon$ | $a$ | $b$ |
|---|---|---|---|
| $\to q_0$ | $\lbrace q_2\rbrace$ | $\lbrace q_1\rbrace$ | $\lbrace q_0\rbrace$ |
| $q_1$ | $\lbrace q_2\rbrace$ | $\lbrace q_2\rbrace$ | $\lbrace q_3\rbrace$ |
| $q_2$ | $\lbrace q_0\rbrace$ | $\emptyset$ | $\emptyset$ |
| $q_3$ | $\emptyset$ | $\emptyset$ | $\lbrace q_2\rbrace$ |

Then $\hat\delta(q_2, aba)$ is

- (A) $\emptyset$
- (B) $\lbrace q_0, q_1, q_3\rbrace$
- (C) $\lbrace q_0, q_1, q_2\rbrace$
- (D) $\lbrace q_0, q_2, q_3\rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Method.** Start from the $\epsilon$-closure of $q_2$. For each input symbol, move on that symbol, then take the $\epsilon$-closure again.

**$\epsilon$-closures:** $q_0 \to q_2 \to q_0$, so $\text{ecl}(q_0) = \text{ecl}(q_2) = \lbrace q_0, q_2\rbrace$; $\text{ecl}(q_1) = \lbrace q_1, q_2, q_0\rbrace$; $\text{ecl}(q_3) = \lbrace q_3\rbrace$.

| Step | Current set | Move | After $\epsilon$-closure |
|---|---|---|---|
| start | | | $\lbrace q_0, q_2\rbrace$ |
| read $a$ | $\lbrace q_0, q_2\rbrace$ | $\delta(q_0,a) \cup \delta(q_2,a) = \lbrace q_1\rbrace$ | $\lbrace q_0, q_1, q_2\rbrace$ |
| read $b$ | $\lbrace q_0, q_1, q_2\rbrace$ | $\lbrace q_0\rbrace \cup \lbrace q_3\rbrace \cup \emptyset = \lbrace q_0, q_3\rbrace$ | $\lbrace q_0, q_2, q_3\rbrace$ |
| read $a$ | $\lbrace q_0, q_2, q_3\rbrace$ | $\lbrace q_1\rbrace$ | $\lbrace q_0, q_1, q_2\rbrace$ |

So $\hat\delta(q_2, aba) = \lbrace q_0, q_1, q_2\rbrace$: **(C)**.

**Why the others fail.**

- (A) forgets the $\epsilon$-moves, so $q_2$ has no $a$-transition.
- (B) is not even $\epsilon$-closed: it contains $q_1$ but not $q_2$, and $q_1 \to q_2$ on $\epsilon$.
- (D) is the set after reading only $ab$, not the final one.

**Code check:** a short program implementing the closure-and-move steps printed the sets in the table, ending with $\lbrace q_0, q_1, q_2\rbrace$.

**Key idea:** $\hat\delta$ for an $\epsilon$-NFA is closure, then (move, closure) for each symbol.

</details>
