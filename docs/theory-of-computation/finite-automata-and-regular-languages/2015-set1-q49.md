# 2015 CS1 Q49: States in the minimal DFA for the intersection of two DFA languages

## Question

![Two DFAs. M has a start state with a self-loop on b, an a-transition to an accepting state with a self-loop on a, and a b-transition back to the start state. N has a start state with a self-loop on a, a b-transition to an accepting state with a self-loop on b, and an a-transition back to the start state.](../../assets/2015/set1-q49.png)

Consider the DFAs M and N given above. The number of states in a minimal DFA that accepts the language $L(M) \cap L(N)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read each DFA by its last symbol.**

- In $M$, reading $a$ always goes to the accepting state and reading $b$ always goes to the start (non-accepting) state. So $M$ accepts strings whose **last symbol is $a$**.
- In $N$, reading $b$ always goes to the accepting state and reading $a$ always goes back to the start. So $N$ accepts strings whose **last symbol is $b$**.

No non-empty string ends in both $a$ and $b$, and the empty string is rejected by both (start states are not accepting). So

$$L(M) \cap L(N) = \emptyset$$

The minimal DFA for $\emptyset$ has a single non-accepting state looping on $a$ and $b$: **1 state**.

**Key idea:** the intersection here is empty, and the empty language needs only one state.

</details>
