# 2016 CS1 Q18: Regular expression for binary strings with 00 and 11

## Question

Which one of the following regular expressions represents the language: the set of all binary strings having two consecutive 0s and two consecutive 1s?

- (A) $(0+1)^* 0011 (0+1)^* + (0+1)^* 1100 (0+1)^*$
- (B) $(0+1)^* \big(00(0+1)^* 11 + 11(0+1)^* 00\big)(0+1)^*$
- (C) $(0+1)^* 00 (0+1)^* + (0+1)^* 11 (0+1)^*$
- (D) $00(0+1)^* 11 + 11(0+1)^* 00$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The strings must contain **both** $00$ and $11$ as substrings. These two substrings cannot overlap (one is made of 0s, the other of 1s), so one occurs before the other:

$$(0+1)^*\,\big(00(0+1)^*11 \;+\; 11(0+1)^*00\big)\,(0+1)^*$$

That is option (B).

**Why the others fail.**

| Option | Problem | Example |
|---|---|---|
| (A) | forces $0011$ or $1100$ to be *adjacent* | $001011$ is in the language but not matched |
| (C) | "or", not "and" | $00$ is matched but has no $11$ |
| (D) | the string must *start* with $00$ and *end* with $11$ (or the reverse) | $00110$ is in the language but not matched |

**Code check:** testing every binary string of length up to $10$ against each expression, (B) agreed with "contains $00$ and $11$" on all of them, and (A), (C), (D) each failed on the examples above.

**Key idea:** two non-overlapping required substrings appear in one of two orders, with $(0+1)^*$ before, between and after.

</details>
