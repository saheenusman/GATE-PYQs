# 2014 CS2 Q15: Concatenation of the languages a^n and b^n

## Question

If $L_1 = \lbrace a^n \mid n \ge 0 \rbrace$ and $L_2 = \lbrace b^n \mid n \ge 0 \rbrace$, consider

- (I) $L_1 \cdot L_2$ is a regular language
- (II) $L_1 \cdot L_2 = \lbrace a^n b^n \mid n \ge 0 \rbrace$

Which one of the following is CORRECT?

- (A) Only (I)
- (B) Only (II)
- (C) Both (I) and (II)
- (D) Neither (I) nor (II)

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Concatenation joins any string of $L_1$ with any string of $L_2$, with **independent** counts:

$$L_1 \cdot L_2 = \lbrace a^m b^n \mid m, n \ge 0 \rbrace = a^*b^*$$

**(I) is true.** $a^*b^*$ is a regular expression.

**(II) is false.** $a^n b^n$ forces the same count of $a$ and $b$; $L_1 \cdot L_2$ contains $aab$ (m = 2, n = 1), which is not in $\lbrace a^n b^n \rbrace$.

So only (I): **A**.

**Key idea:** concatenation does not tie the two exponents together; that is what makes $a^n b^n$ non-regular and $a^*b^*$ regular.

</details>
