# 2012 CS Q46: Missing arcs of a DFA for at most two zeros in any 3 symbols

## Question

Consider the set of strings on $\lbrace 0,1 \rbrace$ in which, *every substring of 3 symbols* has at most *two* zeros. For example, $001110$ and $011001$ are in the language, but $100010$ is not. All strings of length less than 3 are also in the language. A partially completed DFA that accepts this language is shown below.

![A partial DFA. The start state is epsilon. Epsilon goes to 0 on 0 and to 1 on 1. State 0 goes to 00 on 0 and to 01 on 1. State 1 goes to 10 on 0 and to 11 on 1. State 01 goes to 10 on 0. State 10 goes to 01 on 1. State 11 has a self loop on 1. State q is a separate non-accepting state with a self loop on 0 and 1. All states except q are accepting.](../../assets/2012/set1-q46.png)

The missing arcs in the DFA are given by a table with rows for the source state (00, 01, 10, 11) and columns for the target state (00, 01, 10, 11, q); an entry is the arc label.

**(A)**

| | 00 | 01 | 10 | 11 | q |
|---|---|---|---|---|---|
| **00** | 1 | 0 | | | |
| **01** | | | | 1 | |
| **10** | 0 | | | | |
| **11** | | | 0 | | |

**(B)**

| | 00 | 01 | 10 | 11 | q |
|---|---|---|---|---|---|
| **00** | | 0 | | | 1 |
| **01** | | 1 | | | |
| **10** | | | 0 | | |
| **11** | | 0 | | | |

**(C)**

| | 00 | 01 | 10 | 11 | q |
|---|---|---|---|---|---|
| **00** | | 1 | | | 0 |
| **01** | | 1 | | | |
| **10** | | | 0 | | |
| **11** | | 0 | | | |

**(D)**

| | 00 | 01 | 10 | 11 | q |
|---|---|---|---|---|---|
| **00** | | 1 | | | 0 |
| **01** | | | | 1 | |
| **10** | 0 | | | | |
| **11** | | | 0 | | |

<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each state remembers the last two symbols read, so after reading $x$ the new state is (second symbol of the old state) followed by $x$. The state $q$ is the dead state for "a window with three zeros".

**The five missing arcs:**

| From | On | To | Why |
|---|---|---|---|
| 00 | 0 | q | window `000` has three zeros |
| 00 | 1 | 01 | last two symbols become `01` |
| 01 | 1 | 11 | last two become `11` |
| 10 | 0 | 00 | last two become `00` (window `100` has two zeros) |
| 11 | 0 | 10 | last two become `10` |

In table form (row $=$ from, column $=$ to, entry $=$ label): $(00,q)=0$, $(00,01)=1$, $(01,11)=1$, $(10,00)=0$, $(11,10)=0$. This is table (D).

**Why the others fail:**

- (A) sends $00 \xrightarrow{1} 00$ and $00 \xrightarrow{0} 01$, both wrong.
- (B) has $00 \xrightarrow{0} 01$ and $00 \xrightarrow{1} q$: the labels are swapped.
- (C) has $01 \xrightarrow{1} 01$, $10 \xrightarrow{0} 10$ and $11 \xrightarrow{0} 01$, none of which tracks the last two symbols.

**Code check:** I completed the DFA with each option's arcs and compared it with the language on every binary string of length up to $12$. Only (D) matched.

**Key idea:** a sliding-window DFA stores the last $k$ symbols as its state.

</details>
