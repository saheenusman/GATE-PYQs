# 2018 CS Q17: Closure properties of recursively enumerable languages

## Question

The set of all recursively enumerable languages is

- (A) closed under complementation.
- (B) closed under intersection.
- (C) a subset of the set of all recursive languages.
- (D) an uncountable set.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Check each option.**

- **A:** false. If RE languages were closed under complement, every RE language would also be co-RE, hence recursive. The halting language is RE but not recursive.
- **B:** **true.** To accept $L_1\cap L_2$, run both Turing machines (alternately) and accept when both accept.
- **C:** false. It is the other way round: every recursive language is RE, but not conversely.
- **D:** false. Each RE language is accepted by a Turing machine, which has a finite description. There are only countably many such descriptions, so the set is countably infinite.

**Key idea:** RE languages are closed under union, intersection, concatenation and star, but not under complement.

</details>
