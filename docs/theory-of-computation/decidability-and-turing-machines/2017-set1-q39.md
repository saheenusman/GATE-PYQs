# 2017 CS1 Q39: Computable total function f and recursiveness of L_f = {x#f(x)}

## Question

Let $A$ and $B$ be finite alphabets and let $\#$ be a symbol outside both $A$ and $B$. Let $f$ be a total function from $A^{*}$ to $B^{*}$. We say $f$ is *computable* if there exists a Turing machine $M$ which given an input $x$ in $A^{*}$, always halts with $f(x)$ on its tape. Let $L_f$ denote the language $\lbrace x\#f(x) \mid x \in A^{*}\rbrace$. Which of the following statements is true:

- (A) $f$ is computable if and only if $L_f$ is recursive.
- (B) $f$ is computable if and only if $L_f$ is recursively enumerable.
- (C) If $f$ is computable then $L_f$ is recursive, but not conversely.
- (D) If $f$ is computable then $L_f$ is recursively enumerable, but not conversely.

<details class="success" markdown="1">
<summary>Answer</summary>

**A (official key). My analysis agrees that A is true, but B is also true: see the solution**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**($\Rightarrow$) $f$ computable implies $L_f$ recursive.** Given a string $w$:

1. If $w$ is not of the form $x\#y$ with $x\in A^*$, $y\in B^*$, reject.
2. Otherwise run $M$ on $x$ (it always halts) to get $f(x)$.
3. Accept iff $f(x) = y$.

This always halts, so $L_f$ is recursive. That already makes it recursively enumerable.

**($\Leftarrow$) $L_f$ recursive implies $f$ computable.** Given $x$, list the strings $y \in B^*$ in order and run the decider on $x\#y$ for each. Because $f$ is total, $x\#f(x)\in L_f$, so some $y$ is accepted. Output the first accepted $y$. It halts for every $x$.

So $f$ computable $\iff$ $L_f$ recursive. **(A) is true**, which also makes (C) and (D) false (each claims the converse fails).

**The catch: (B) is also true.** Suppose only that $L_f$ is recursively enumerable, with recognizer $M'$. Given $x$, dovetail $M'$ on $x\#y$ over all $y$. Since $f$ is total, exactly one $y$ ($=f(x)$) is accepted, and the search finds it in finite time. So $f$ is computable. Together with "computable implies recursive implies r.e.", we get $f$ computable $\iff$ $L_f$ r.e., which is exactly (B).

**Why this is flagged.** For a *total* $f$, "recursive" and "recursively enumerable" coincide for $L_f$, so (A) and (B) are both true. The official key picks **(A)**. I record it as the key, but note that the question has two correct options.

**Status note:** marked `disputed` for that reason. No program applies here (the argument is a proof).

**Key idea:** for a total function, the graph $\lbrace x\#f(x)\rbrace$ being r.e. already makes it recursive, because the unique partner $f(x)$ can be searched for.

</details>
