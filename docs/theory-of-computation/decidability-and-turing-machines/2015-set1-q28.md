# 2015 CS1 Q28: Closure properties of CFL and recursively enumerable languages

## Question

For any two languages $L_1$ and $L_2$ such that $L_1$ is context-free and $L_2$ is recursively enumerable but not recursive, which of the following is/are necessarily true?

- I. $\overline{L_1}$ (complement of $L_1$) is recursive
- II. $\overline{L_2}$ (complement of $L_2$) is recursive
- III. $\overline{L_1}$ is context-free
- IV. $L_1 \cup L_2$ is recursively enumerable

- (A) I only
- (B) III only
- (C) III and IV only
- (D) I and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I: True.** Every context-free language is decidable (e.g. by CYK), so it is recursive. Recursive languages are closed under complement.
- **II: False.** If $\overline{L_2}$ were recursive, then $L_2$ would be recursive too. But $L_2$ is not recursive.
- **III: False.** CFLs are not closed under complement. For example $L_1 = \overline{\lbrace a^nb^nc^n \mid n \ge 0\rbrace}$ is context-free, but its complement $\lbrace a^nb^nc^n \rbrace$ is not.
- **IV: True.** $L_1$ is recursive and $L_2$ is RE, and RE languages are closed under union.

So I and IV: option (D). (A) omits IV. (B) and (C) include III.

**Key idea:** CFL $\subset$ recursive $\subset$ RE; recursive is closed under complement, CFL is not.

</details>
