# 2022 CS Q23: True statements about recursive languages

## Question

Which of the following statements is/are TRUE?

- (A) Every subset of a recursively enumerable language is recursive.
- (B) If a language $L$ and its complement $\overline{L}$ are both recursively enumerable, then $L$ must be recursive.
- (C) Complement of a context-free language must be recursive.
- (D) If $L_1$ and $L_2$ are regular, then $L_1 \cap L_2$ must be deterministic context-free.

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) False.** $\Sigma^*$ is recursively enumerable, and its subsets include non-recursive languages (even non-r.e. ones).
- **(B) True.** If both $L$ and $\overline{L}$ are r.e., run the two recognizers in parallel. Exactly one halts, which decides membership.
- **(C) True.** Every context-free language is context-sensitive, and context-sensitive languages are closed under complement and are recursive. (Also, a CYK-style algorithm decides any CFL, so the complement is decided by flipping the answer.)
- **(D) True.** Regular languages are closed under intersection, and every regular language is deterministic context-free.

**Key idea:** r.e. and co-r.e. together give recursive; the decidable classes are closed under complement.

</details>
