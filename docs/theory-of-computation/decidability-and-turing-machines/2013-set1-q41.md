# 2013 CS Q41: Undecidable problems

## Question

Which of the following is/are undecidable?

1. $G$ is a CFG. Is $L(G) = \Phi$?
2. $G$ is a CFG. Is $L(G) = \Sigma^*$?
3. $M$ is a Turing machine. Is $L(M)$ regular?
4. $A$ is a DFA and $N$ is an NFA. Is $L(A) = L(N)$?

- (A) 3 only
- (B) 3 and 4 only
- (C) 1, 2 and 3 only
- (D) 2 and 3 only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

1. **Decidable.** Check whether the start symbol is "productive": a simple marking algorithm on the grammar.
2. **Undecidable.** Universality of a CFG is undecidable (via reduction from the Post correspondence problem or from TM computations).
3. **Undecidable.** By Rice's theorem, "is $L(M)$ regular?" is a non-trivial property of the language, so it is undecidable.
4. **Decidable.** Convert the NFA to a DFA, then test equivalence of two DFAs (minimise or check the product automaton).

Undecidable: 2 and 3, so (D).

**Why the others fail:** (A) misses 2; (B) calls 4 undecidable; (C) calls 1 undecidable.

**Key idea:** for CFGs, emptiness is decidable but universality is not; for TMs, any non-trivial language property is undecidable (Rice).

</details>
