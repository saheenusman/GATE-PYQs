# 2016 CS1 Q17: Which of four decision problems are undecidable

## Question

Which of the following decision problems are undecidable?

- I. Given NFAs $N_1$ and $N_2$, is $L(N_1) \cap L(N_2) = \Phi$?
- II. Given a CFG $G = (N, \Sigma, P, S)$ and a string $x \in \Sigma^*$, does $x \in L(G)$?
- III. Given CFGs $G_1$ and $G_2$, is $L(G_1) = L(G_2)$?
- IV. Given a TM $M$, is $L(M) = \Phi$?

- (A) I and IV only
- (B) II and III only
- (C) III and IV only
- (D) II and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Problem | Decidable? | Reason |
|---|---|---|
| I | yes | build the product automaton for the intersection and check whether any accepting state is reachable |
| II | yes | CYK (or any CFG parser) decides membership |
| III | **no** | equivalence of CFGs is undecidable |
| IV | **no** | emptiness of a Turing machine's language is undecidable (Rice's theorem) |

Undecidable: III and IV, which is **(C)**.

**Why the others fail.** (A) contains I and (B)/(D) contain II, and both of those are decidable.

**Key idea:** CFG equivalence and TM emptiness are undecidable; NFA intersection emptiness and CFG membership are decidable.

</details>
