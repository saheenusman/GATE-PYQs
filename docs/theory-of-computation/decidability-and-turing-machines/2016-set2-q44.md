# 2016 CS2 Q44: Decidability of three step-count and acceptance properties of Turing machines

## Question

Consider the following languages.

$$L_1 = \lbrace \langle M \rangle \mid M \text{ takes at least 2016 steps on some input} \rbrace$$
$$L_2 = \lbrace \langle M \rangle \mid M \text{ takes at least 2016 steps on all inputs} \rbrace$$
$$L_3 = \lbrace \langle M \rangle \mid M \text{ accepts } \varepsilon \rbrace$$

where for each Turing machine $M$, $\langle M \rangle$ denotes a specific encoding of $M$. Which one of the following is TRUE?

- (A) $L_1$ is recursive and $L_2$, $L_3$ are not recursive
- (B) $L_2$ is recursive and $L_1$, $L_3$ are not recursive
- (C) $L_1$, $L_2$ are recursive and $L_3$ is not recursive
- (D) $L_1$, $L_2$, $L_3$ are recursive

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$L_1$ and $L_2$ are recursive.** In its first $2016$ steps a machine can read only the first $2016$ symbols of its input. So for $L_1$ it is enough to simulate $M$ for $2016$ steps on every input of length at most $2016$ (finitely many), and accept if any run lasts the full $2016$ steps. For $L_2$, simulate on every such input and check that all of them last $2016$ steps. Both procedures always halt.

**$L_3$ is not recursive.** "Does $M$ accept $\varepsilon$?" is the halting problem for the empty input (undecidable; it is also non-trivial, so Rice's theorem applies).

$L_1, L_2$ recursive and $L_3$ not: **(C)**.

**Key idea:** step-bounded properties need only finitely many inputs; acceptance of $\varepsilon$ is undecidable.

</details>
