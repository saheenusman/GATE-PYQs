# 2007 CS Q6: Which problem is undecidable

## Question

Which of the following problems is undecidable?

- (A) Membership problem for CFGs.
- (B) Ambiguity problem for CFGs.
- (C) Finiteness problem for FSAs.
- (D) Equivalence problem for FSAs.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) Membership for CFGs is decidable (CYK, or any parser for a grammar in Chomsky normal form).
- **(B) Ambiguity of a CFG is undecidable** (it can be reduced from the Post Correspondence Problem).
- (C) Finiteness of a regular language is decidable (look for a reachable, co-reachable cycle in the DFA).
- (D) Equivalence of FSAs is decidable (minimise both, or test the symmetric difference for emptiness).

So (B).
