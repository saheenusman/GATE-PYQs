# 2025 CS2 Q25: Which question about grammars is decidable

## Question

Let $G_1$, $G_2$ be Context Free Grammars (CFGs) and $R$ be a regular expression. For a grammar $G$, let $L(G)$ denote the language generated by $G$.

Which ONE among the following questions is decidable?

- (A) Is $L(G_1) = L(G_2)$?
- (B) Is $L(G_1) \cap L(G_2) = \emptyset$?
- (C) Is $L(G_1) = L(R)$?
- (D) Is $L(G_1) = \emptyset$?

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Question | Decidable? | Reason |
|---|---|---|
| A, equivalence of two CFGs | No | Undecidable |
| B, is the intersection of two CFLs empty | No | Undecidable (it encodes the Post Correspondence Problem) |
| C, is $L(G_1) = L(R)$ | No | Taking $R = \Sigma^*$ gives "is $L(G_1) = \Sigma^*$?" (universality), which is undecidable |
| **D, is $L(G_1) = \emptyset$** | **Yes** | Compute the set of *productive* non-terminals (those that derive some terminal string) by a fixed-point iteration. $L(G_1)$ is empty iff the start symbol is not productive |

**Key idea:** emptiness and membership are decidable for CFGs. Equivalence, universality and intersection-emptiness are not.

</details>
