# 2017 CS2 Q41: Which of four decision problems are undecidable

## Question

Let $L(R)$ be the language represented by regular expression $R$. Let $L(G)$ be the language generated by a context free grammar $G$. Let $L(M)$ be the language accepted by a Turing machine $M$. Which of the following decision problems are undecidable?

- I. Given a regular expression $R$ and a string $w$, is $w \in L(R)$?
- II. Given a context-free grammar $G$, is $L(G) = \emptyset$?
- III. Given a context-free grammar $G$, is $L(G) = \Sigma^*$ for some alphabet $\Sigma$?
- IV. Given a Turing machine $M$ and a string $w$, is $w \in L(M)$?

Options:

- (A) I and IV only
- (B) II and III only
- (C) II, III and IV only
- (D) III and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I. Decidable.** Convert $R$ to a finite automaton and simulate it on $w$.

**II. Decidable.** Emptiness of a CFG is decidable: mark variables that can derive terminal strings, and check whether $S$ is marked.

**III. Undecidable.** "Is $L(G) = \Sigma^*$?" (universality) is undecidable for CFGs, unlike for regular languages.

**IV. Undecidable.** This is the acceptance problem $A_{TM}$ for Turing machines.

Undecidable: III and IV, which is **(D)**.

**Why the others fail.** (A) calls the regular-expression membership problem undecidable. (B), (C) include II, the emptiness test, which is decidable.

**Status note:** standard decidability results (no program applies); the answer matches the official key.

**Key idea:** CFGs: membership, emptiness and finiteness are decidable; universality, equivalence and ambiguity are not.

</details>
