# 2012 CS Q24: Which of four problems and closure statements are decidable

## Question

Which of the following problems are decidable?

1. Does a given program ever produce an output?
2. If $L$ is a context-free language, then, is $\overline{L}$ also context-free?
3. If $L$ is a regular language, then, is $\overline{L}$ also regular?
4. If $L$ is a recursive language, then, is $\overline{L}$ also recursive?

Options:

- (A) 1, 2, 3, 4
- (B) 1, 2
- (C) 2, 3, 4
- (D) 3, 4

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**1 is undecidable.** "Does this program ever produce output?" reduces from the halting problem, so by Rice's theorem it cannot be decided.

**2, 3, 4 are closure questions.** The key reads them as: is the statement true for every such $L$ (a trivially decidable yes) or not?

- **2:** CFLs are **not** closed under complement. $L = \lbrace a^n b^n c^m \rbrace \cup \lbrace a^n b^m c^m \rbrace$ is context-free, but its complement is not. So the statement fails and does not count.
- **3:** regular languages are closed under complement (swap accepting and non-accepting states of a DFA). True.
- **4:** recursive languages are closed under complement (swap the decider's accept and reject). True.

So 3 and 4: (D).

- (A) includes 1, which is undecidable, and 2, which fails.
- (B) is 1 and 2, both excluded.
- (C) includes 2, since CFLs are not closed under complement.

**Interpretation.** Items 2-4 are written as closure properties, not as decision problems; the reading above is the one that reproduces the official key.

**Key idea:** regular and recursive languages are closed under complement; context-free languages are not.

</details>
