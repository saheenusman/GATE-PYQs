# 2023 CS Q24: Closure under intersection

## Question

Which of the following statements is/are CORRECT?

- (A) The intersection of two regular languages is regular.
- (B) The intersection of two context-free languages is context-free.
- (C) The intersection of two recursive languages is recursive.
- (D) The intersection of two recursively enumerable languages is recursively enumerable.

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**A (true).** Run the product of the two DFAs and accept when both accept.

**B (false).** $L_1 = \lbrace a^n b^n c^m \rbrace$ and $L_2 = \lbrace a^m b^n c^n \rbrace$ are both context-free, but $L_1 \cap L_2 = \lbrace a^n b^n c^n \rbrace$ is not.

**C (true).** Run both deciders. Each halts, so accept if both accept.

**D (true).** Run both machines on the input (one after the other is enough, since each accepting run is finite) and accept if both accept. If either never halts, the input is not in that language, so rejecting by looping is allowed.

**Key idea:** CFLs are not closed under intersection. Regular, recursive and recursively enumerable languages are.

</details>
