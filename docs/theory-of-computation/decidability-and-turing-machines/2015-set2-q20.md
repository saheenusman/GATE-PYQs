# 2015 CS2 Q20: True statements about decidability and NP

## Question

Consider the following statements.

- I. The complement of every Turing decidable language is Turing decidable
- II. There exists some language which is in NP but is not Turing decidable
- III. If $L$ is a language in NP, $L$ is Turing decidable

Which of the above statements is/are true?

- (A) Only II
- (B) Only III
- (C) Only I and II
- (D) Only I and III

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I: True.** A decider for $L$ gives a decider for $\overline{L}$ by swapping accept and reject.
- **II: False.** Every language in NP has a nondeterministic polynomial-time machine, which can be simulated deterministically in exponential time. So it is decidable.
- **III: True.** The same reason: NP $\subseteq$ EXPTIME $\subseteq$ decidable.

I and III: option (D). (A) says II is true. (B) omits I. (C) includes II.

**Key idea:** NP $\subseteq$ decidable, and decidable languages are closed under complement.

</details>
