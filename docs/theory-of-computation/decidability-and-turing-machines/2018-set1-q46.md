# 2018 CS Q46: Which of four problems are undecidable

## Question

Consider the following problems. $L(G)$ denotes the language generated by a grammar $G$. $L(M)$ denotes the language accepted by a machine $M$.

- (I) For an unrestricted grammar $G$ and a string $w$, whether $w \in L(G)$
- (II) Given a Turing machine $M$, whether $L(M)$ is regular
- (III) Given two grammars $G_1$ and $G_2$, whether $L(G_1) = L(G_2)$
- (IV) Given an NFA $N$, whether there is a deterministic PDA $P$ such that $N$ and $P$ accept the same language.

Which one of the following statements is correct?

- (A) Only I and II are undecidable
- (B) Only III is undecidable
- (C) Only II and IV are undecidable
- (D) Only I, II and III are undecidable

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(I) undecidable.** Membership for unrestricted (type-0) grammars is equivalent to the halting problem.
- **(II) undecidable.** "Is $L(M)$ regular?" is a non-trivial property of RE languages, so Rice's theorem applies.
- **(III) undecidable.** Equivalence of grammars is undecidable (already for context-free grammars).
- **(IV) decidable.** Every regular language is accepted by some deterministic PDA, so for every NFA the answer is "yes". The decision procedure is trivial.

Undecidable: I, II and III only, so **D**.

**Why the others fail:** A and B leave out undecidable problems. C wrongly calls IV undecidable.

**Key idea:** Rice's theorem covers non-trivial properties of TM languages; regular $\subseteq$ DCFL makes IV trivially "yes".

</details>
