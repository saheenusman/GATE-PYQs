# 2019 CS2 Q44: Which sets of languages and programs are uncountable

## Question

Consider the following sets:

- S1. Set of all recursively enumerable languages over the alphabet $\lbrace 0, 1 \rbrace$
- S2. Set of all syntactically valid C programs
- S3. Set of all languages over the alphabet $\lbrace 0, 1 \rbrace$
- S4. Set of all non-regular languages over the alphabet $\lbrace 0, 1 \rbrace$

Which of the above sets are uncountable?

- (A) S1 and S2
- (B) S3 and S4
- (C) S2 and S3
- (D) S1 and S4

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A set is countable if its elements can be listed one by one. Anything described by a **finite string** over a finite alphabet is countable.

| Set | Countable? | Reason |
|---|---|---|
| S1 | **Countable** | Each RE language has a Turing machine, and a TM is a finite string. There are only countably many TMs |
| S2 | **Countable** | A C program is a finite string over a finite alphabet |
| S3 | **Uncountable** | It is the power set of $\lbrace 0,1\rbrace^*$, which is countably infinite. By Cantor's theorem the power set is uncountable |
| S4 | **Uncountable** | It is all languages (uncountable) minus the regular ones (countably many). Removing a countable set from an uncountable one leaves it uncountable |

So S3 and S4 are uncountable.

**Why the others fail:** (A), (C) and (D) each include S1 or S2, which are countable.

**Key idea:** machines and programs are finite strings, so countable. Languages are infinite sets of strings, so there are uncountably many.

</details>
