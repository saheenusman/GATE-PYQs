# 2021 CS1 Q22: Which language is not recursive

## Question

Let $\langle M\rangle$ denote an encoding of an automaton $M$. Suppose that $\Sigma=\lbrace 0,1\rbrace$. Which of the following languages is/are NOT recursive?

- (A) $L=\lbrace\langle M\rangle \mid M \text{ is a DFA such that } L(M)=\emptyset\rbrace$
- (B) $L=\lbrace\langle M\rangle \mid M \text{ is a DFA such that } L(M)=\Sigma^*\rbrace$
- (C) $L=\lbrace\langle M\rangle \mid M \text{ is a PDA such that } L(M)=\emptyset\rbrace$
- (D) $L=\lbrace\langle M\rangle \mid M \text{ is a PDA such that } L(M)=\Sigma^*\rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) DFA emptiness: check whether any accepting state is reachable. Decidable.
- (B) DFA universality: complement the DFA, then test emptiness. Decidable.
- (C) PDA emptiness: convert to a CFG and test whether the start symbol is productive. Decidable.
- (D) PDA universality ($L(M)=\Sigma^*$): **undecidable**. So this language is not recursive.

Answer: **D**.

**Key idea:** emptiness is decidable for DFA and PDA. Universality is decidable for DFA but undecidable for PDA and CFG.

</details>
