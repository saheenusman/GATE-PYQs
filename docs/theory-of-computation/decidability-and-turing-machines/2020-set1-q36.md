# 2020 CS Q36: Which Turing machine languages are undecidable

## Question

Which of the following languages are undecidable? Note that $\langle M \rangle$ indicates encoding of the Turing machine $M$.

$L_1 = \lbrace \langle M \rangle \mid L(M) = \emptyset \rbrace$

$L_2 = \lbrace \langle M, w, q \rangle \mid M \text{ on input } w \text{ reaches state } q \text{ in exactly 100 steps} \rbrace$

$L_3 = \lbrace \langle M \rangle \mid L(M) \text{ is not recursive} \rbrace$

$L_4 = \lbrace \langle M \rangle \mid L(M) \text{ contains at least 21 members} \rbrace$

- (A) $L_1, L_3$, and $L_4$ only
- (B) $L_1$ and $L_3$ only
- (C) $L_2$ and $L_3$ only
- (D) $L_2, L_3$, and $L_4$ only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rice's theorem.** Any non-trivial property of the *language* a Turing machine accepts is undecidable. "Non-trivial" means some machines have the property and some do not.

| Language | Property of | Verdict | Reason |
|---|---|---|---|
| $L_1$ | $L(M)$: empty | **Undecidable** | Non-trivial: some machines accept nothing, others do not. (This is the emptiness problem.) |
| $L_2$ | the *run* of $M$ on $w$ | **Decidable** | Just simulate $M$ on $w$ for 100 steps (a finite amount of work) and check the state. It is not a property of $L(M)$, so Rice's theorem does not apply. |
| $L_3$ | $L(M)$: not recursive | **Undecidable** | Non-trivial: a machine for $\emptyset$ has a recursive language, while a machine for the halting language does not. |
| $L_4$ | $L(M)$: at least 21 strings | **Undecidable** | Non-trivial: $\emptyset$ has none, while $\Sigma^*$ has infinitely many. |

Undecidable: $L_1, L_3, L_4$.

**Why the other options fail:** (B) misses $L_4$. (C) and (D) include $L_2$, which is decidable.

**Key idea:** a question about *what language* a machine accepts is undecidable (Rice). A question about a *bounded run* of a machine can be answered by simulation.

</details>
