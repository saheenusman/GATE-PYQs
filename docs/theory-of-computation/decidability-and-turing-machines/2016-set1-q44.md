# 2016 CS1 Q44: Reductions involving a recursive and a recursively enumerable language

## Question

Let $X$ be a recursive language and $Y$ be a recursively enumerable but not recursive language. Let $W$ and $Z$ be two languages such that $\overline{Y}$ reduces to $W$, and $Z$ reduces to $\overline{X}$ (reduction means the standard many-one reduction). Which one of the following statements is TRUE?

- (A) $W$ can be recursively enumerable and $Z$ is recursive.
- (B) $W$ can be recursive and $Z$ is recursively enumerable.
- (C) $W$ is not recursively enumerable and $Z$ is recursive.
- (D) $W$ is not recursively enumerable and $Z$ is not recursive.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$W$.** $Y$ is recursively enumerable but not recursive, so $\overline{Y}$ is **not** recursively enumerable (if both $Y$ and $\overline{Y}$ were r.e., $Y$ would be recursive). Since $\overline{Y} \le_m W$ and many-one reductions carry r.e.-ness backwards, if $W$ were r.e. then $\overline{Y}$ would be r.e., a contradiction. So $W$ is **not r.e.**

**$Z$.** $X$ is recursive, so $\overline{X}$ is recursive. Since $Z \le_m \overline{X}$, $Z$ is decidable by first reducing and then deciding $\overline{X}$. So $Z$ is **recursive**.

So: $W$ is not r.e. and $Z$ is recursive, **(C)**.

**Why the others fail.** (A) and (B) say $W$ could be r.e. or recursive, which is impossible. (D) says $Z$ is not recursive, which is false.

**Key idea:** $A \le_m B$ passes decidability and r.e.-ness from $B$ back to $A$.

</details>
