# 2022 CS Q46: Undecidable problems about Turing machines

## Question

Which of the following is/are undecidable?

- (A) Given two Turing machines $M_1$ and $M_2$, decide if $L(M_1) = L(M_2)$.
- (B) Given a Turing machine $M$, decide if $L(M)$ is regular.
- (C) Given a Turing machine $M$, decide if $M$ accepts all strings.
- (D) Given a Turing machine $M$, decide if $M$ takes more than 1073 steps on every string.

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) Undecidable.** Equivalence of TMs is undecidable.
- **(B) Undecidable.** "Is $L(M)$ regular?" is a non-trivial property of the language, so Rice's theorem applies.
- **(C) Undecidable.** "Is $L(M) = \Sigma^*$?" is also a non-trivial property of the language (Rice's theorem).
- **(D) Decidable.** This is a property of the machine's running time, not only of its language. If $M$ takes at most 1073 steps on some string, then it reads at most 1073 symbols of it, so a string of length at most 1073 already shows this. To decide, run $M$ for 1073 steps on each of the finitely many strings of length at most 1073 (including the empty string). If any run halts within 1073 steps, answer no; otherwise answer yes.

**Key idea:** Rice's theorem covers non-trivial properties of $L(M)$; a bounded-step property can be checked by finite simulation.

</details>
