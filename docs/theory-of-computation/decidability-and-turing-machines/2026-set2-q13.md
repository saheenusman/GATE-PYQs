# 2026 CS2 Q13: What 'M decides L' means

## Question

Which one of the following statements is equivalent to the assertion: *Turing machine $M$ decides the language $L \subseteq \lbrace 0, 1 \rbrace^*$*?

- (A) $M$ halts on all input strings in $\lbrace 0,1 \rbrace^*$
- (B) $M$ accepts all input strings in $L$
- (C) $M$ rejects all input strings in $\lbrace 0,1 \rbrace^* - L$
- (D) $M$ accepts all input strings in $L$ and rejects all input strings in $\lbrace 0,1 \rbrace^* - L$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A TM *decides* $L$ if on every input it halts, saying *accept* for strings in $L$ and *reject* for strings not in $L$. A TM that only *recognises* $L$ may loop forever on strings outside $L$.

Deciding needs both halves:

- accept every string in $L$, **and**
- reject every string not in $L$ (so it also halts there).

| Option | What it misses |
|---|---|
| (A) halts on all inputs | does not say *which* answer it gives, so it could decide a different language |
| (B) accepts all strings in $L$ | allows looping or accepting outside $L$ (this is only recognising) |
| (C) rejects all strings outside $L$ | says nothing about strings in $L$ (it could loop on them) |
| **(D)** accepts $L$ and rejects the complement | exactly the definition |

**Key idea:** decide = always halts with the correct accept or reject. Recognise = accepts exactly $L$ but may never halt otherwise.

</details>
