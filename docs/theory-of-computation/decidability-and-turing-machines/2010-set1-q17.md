# 2010 CS Q17: Which closure statement is not necessarily true

## Question

Let $L_1$ be a recursive language. Let $L_2$ and $L_3$ be languages that are recursively enumerable but not recursive. Which of the following statements is **not** necessarily true?

- (A) $L_2 - L_1$ is recursively enumerable
- (B) $L_1 - L_3$ is recursively enumerable
- (C) $L_2 \cap L_1$ is recursively enumerable
- (D) $L_2 \cup L_1$ is recursively enumerable

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Recursive languages are closed under complement. RE languages are closed under union and intersection, but **not** under complement.

- (A) $L_2 - L_1 = L_2 \cap \overline{L_1}$. $\overline{L_1}$ is recursive, hence RE, so this is an intersection of two RE languages: RE. True.
- (B) $L_1 - L_3 = L_1 \cap \overline{L_3}$. Since $L_3$ is RE but not recursive, $\overline{L_3}$ is **not** RE. Intersecting with $L_1$ need not fix that. Example: $L_1 = \Sigma^*$ gives $L_1 - L_3 = \overline{L_3}$, which is not RE. **Not necessarily true.**
- (C) $L_2 \cap L_1$: RE is closed under intersection. True.
- (D) $L_2 \cup L_1$: RE is closed under union. True.

So (B).

**Key idea:** subtracting an RE language is the same as intersecting with its complement, which need not be RE.

</details>
