# 2013 CS Q17: Closure properties of TMs

## Question

Which of the following statements is/are **FALSE**?

1. For every non-deterministic Turing machine, there exists an equivalent deterministic Turing machine.
2. Turing recognizable languages are closed under union and complementation.
3. Turing decidable languages are closed under intersection and complementation.
4. Turing recognizable languages are closed under union and intersection.

- (A) 1 and 4 only
- (B) 1 and 3 only
- (C) 2 only
- (D) 3 only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

1. **True.** A deterministic TM simulates an NTM by breadth-first search over its computation tree.
2. **False.** Recognizable (RE) languages are closed under union but **not** under complementation. If they were, RE would equal co-RE, making the halting problem decidable.
3. **True.** Decidable languages are closed under all Boolean operations: run both deciders and combine (or swap the accept and reject states).
4. **True.** Union: run both machines in parallel and accept if either accepts. Intersection: run them one after the other (or in parallel) and accept if both accept.

Only statement 2 is false, so the answer is (C).

**Why the others fail:** (A), (B), (D) each name a true statement (1, 3 or 4) as false.

**Key idea:** RE is closed under union and intersection but not complement; decidable languages are closed under all three.

</details>
