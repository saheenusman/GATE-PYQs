# 2014 CS3 Q35: Which problem is undecidable

## Question

Which one of the following problems is undecidable?

- (A) Deciding if a given context-free grammar is ambiguous.
- (B) Deciding if a given string is generated by a given context-free grammar.
- (C) Deciding if the language generated by a given context-free grammar is empty.
- (D) Deciding if the language generated by a given context-free grammar is finite.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) **Undecidable.** Ambiguity of a CFG can be shown undecidable by reduction from the Post Correspondence Problem.
- (B) decidable: membership is solved by the CYK algorithm (in $O(n^3)$).
- (C) decidable: emptiness is solved by marking the variables that derive terminal strings and checking whether the start symbol is marked.
- (D) decidable: finiteness is solved by checking whether the (useful, cleaned-up) grammar has a cycle among its variables.

**Classification flag:** this is about CFGs, but the main point is decidability. Filed under `decidability-and-turing-machines`, with `context-free-languages-and-pda` as the second topic.

**Key idea:** membership, emptiness and finiteness are decidable for CFLs; ambiguity (and equivalence, universality) are not.

</details>
