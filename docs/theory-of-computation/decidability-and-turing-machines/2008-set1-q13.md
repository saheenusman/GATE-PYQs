# 2008 CS Q13: A language and its complement both recursively enumerable

## Question

If $L$ and $\overline{L}$ are recursively enumerable then $L$ is

- (A) regular
- (B) context-free
- (C) context-sensitive
- (D) recursive

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $M_1$ accept $L$ and $M_2$ accept $\overline{L}$. For any input $w$, run $M_1$ and $M_2$ **in parallel** (alternating steps). Exactly one of them eventually accepts $w$:

- if $M_1$ accepts, then $w \in L$;
- if $M_2$ accepts, then $w \notin L$.

So the combined machine always halts and decides $L$, which makes $L$ **recursive** (decidable). This is Post's theorem.

- (A), (B) and (C) are too strong. Any non-regular, non-context-free recursive language, such as $\lbrace a^{p} \mid p \text{ prime} \rbrace$, satisfies the hypothesis.

**Key idea:** a language is recursive exactly when both it and its complement are recursively enumerable.

</details>
