# 2021 CS1 Q49: Turing machines that take more than 2021 steps

## Question

For a Turing machine $M$, $\langle M\rangle$ denotes an encoding of $M$. Consider the following two languages.

$L_1=\lbrace\langle M\rangle\mid M \text{ takes more than 2021 steps on all inputs}\rbrace$

$L_2=\lbrace\langle M\rangle\mid M \text{ takes more than 2021 steps on some input}\rbrace$

Which one of the following options is correct?

- (A) Both $L_1$ and $L_2$ are decidable.
- (B) $L_1$ is decidable and $L_2$ is undecidable.
- (C) $L_1$ is undecidable and $L_2$ is decidable.
- (D) Both $L_1$ and $L_2$ are undecidable.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In 2021 steps a Turing machine can read at most the first 2021 symbols of its input. So what happens in the first 2021 steps depends only on the first 2021 input symbols (padded with blanks if the input is shorter).

**Decider for $L_1$ and $L_2$.** There are finitely many such prefixes, namely all strings of length at most 2021. For each one, simulate $M$ for 2021 steps and note whether $M$ is still running.

- $M\in L_1$ iff $M$ is still running after 2021 steps on **every** prefix.
- $M\in L_2$ iff $M$ is still running after 2021 steps on **some** prefix.

Both checks use a bounded search and bounded simulation, so both languages are **decidable**. (A).

(B), (C) and (D) call one of them undecidable. Rice's theorem does not apply here because the property is about running time, not about the language $L(M)$, and the step bound makes it finite.

**Key idea:** a property that depends only on a bounded number of steps is decidable by brute-force simulation.

</details>
