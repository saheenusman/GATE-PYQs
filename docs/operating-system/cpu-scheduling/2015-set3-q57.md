# 2015 CS3 Q57: Scheduling scheme with the lowest average turnaround time

## Question

For the processes listed in the following table, which of the following scheduling schemes will give the lowest average turnaround time?

| Process | Arrival Time | Processing Time |
|---|---|---|
| A | 0 | 3 |
| B | 1 | 6 |
| C | 4 | 4 |
| D | 6 | 2 |

- (A) First Come First Serve
- (B) Non-preemptive Shortest Job First
- (C) Shortest Remaining Time
- (D) Round Robin with Quantum value two

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Turnaround time $=$ finish time $-$ arrival time.

| Scheme | Finish order and times | Turnaround (A, B, C, D) | Average |
|---|---|---|---|
| FCFS | A 3, B 9, C 13, D 15 | 3, 8, 9, 9 | 7.25 |
| Non-preemptive SJF | A 3, B 9, D 11, C 15 | 3, 8, 11, 5 | 6.75 |
| **SRT** | A 3, C 8, D 10, B 15 | 3, 14, 4, 4 | **6.25** |
| RR, quantum 2 | A 5, D 11, C 13, B 15 | 5, 14, 9, 5 | 8.25 |

Shortest Remaining Time is lowest: option (C).

**Details.**

- In SRT, $C$ (4) preempts $B$ (5 left) at time 4. At time 6, $C$ and $D$ both have 2 left. Either choice gives the same total (25), so the tie does not matter.
- In RR, a process arriving at the same instant that another is preempted can be queued either first or last. Both give 8.25.

**Code check:** a simulation of all four schemes gives these averages.

**Key idea:** SRT is optimal for average turnaround time among these schemes because it always runs the job with the least work left.

</details>
