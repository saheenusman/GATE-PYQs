# 2017 CS1 Q24: Average waiting time under preemptive shortest remaining time first

## Question

Consider the following CPU processes with arrival times (in milliseconds) and length of CPU bursts (in milliseconds) as given below:

| Process | Arrival time | Burst time |
|---|---|---|
| P1 | 0 | 7 |
| P2 | 3 | 3 |
| P3 | 5 | 5 |
| P4 | 6 | 2 |

If the pre-emptive shortest remaining time first scheduling algorithm is used to schedule the processes, then the average waiting time across all processes is ______ milliseconds.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Gantt chart.**

| Time | Event |
|---|---|
| 0 to 3 | P1 runs (3 ms done, 4 left). |
| 3 | P2 arrives (3) and is shorter than P1's remaining 4, so P2 preempts. |
| 3 to 6 | P2 runs and finishes at 6 (at 5, P3 arrives with 5; P2 has 1 left, so no switch). |
| 6 | P4 arrives (2). Ready: P1 (4), P3 (5), P4 (2). P4 is shortest. |
| 6 to 8 | P4 runs. |
| 8 to 12 | P1 runs (4 left). |
| 12 to 17 | P3 runs. |

**Waiting time** $=$ completion $-$ arrival $-$ burst:

| Process | Completion | Waiting |
|---|---|---|
| P1 | 12 | $12-0-7 = 5$ |
| P2 | 6 | $6-3-3 = 0$ |
| P3 | 17 | $17-5-5 = 7$ |
| P4 | 8 | $8-6-2 = 0$ |

$$\text{Average} = \frac{5+0+7+0}{4} = 3$$

The answer is **3**.

**Code check:** a one-millisecond-step SRTF simulation produced the same timeline (P1, P2, P4, P1, P3) and an average waiting time of $3.0$.

**Key idea:** SRTF re-picks the smallest remaining time at every arrival and completion.

</details>
