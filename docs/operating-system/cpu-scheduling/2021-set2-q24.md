# 2021 CS2 Q24: Correct statements about CPU scheduling

## Question

Which of the following statement(s) is/are correct in the context of CPU scheduling?

- (A) Turnaround time includes waiting time.
- (B) The goal is to only maximize CPU utilization and minimize throughput.
- (C) Round-robin policy can be used even when the CPU time required by each of the processes is not known apriori.
- (D) Implementing preemptive scheduling needs hardware support.

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) **True.** Turnaround $=$ waiting time $+$ burst (execution) time $+$ I/O time. Waiting is part of it.
- (B) False. Scheduling aims to maximize CPU utilization **and throughput**. Minimizing throughput makes no sense.
- (C) **True.** Round-robin gives each process a fixed time slice and does not need to know burst lengths in advance. (SJF does.)
- (D) **True.** Preemption needs a hardware timer that raises an interrupt, so that the OS regains control.

Answer: **A, C and D**.

**Key idea:** throughput is to be maximized, round-robin needs no burst estimates, and preemption needs a timer interrupt.

</details>
