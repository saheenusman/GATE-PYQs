# 2022 CS Q42: Round-robin schedule and context switches

## Question

Consider four processes P, Q, R, and S scheduled on a CPU as per round robin algorithm with a time quantum of 4 units. The processes arrive in the order P, Q, R, S, all at time $t = 0$. There is exactly one context switch from S to Q, exactly one context switch from R to Q, and exactly two context switches from Q to R. There is no context switch from S to P. Switching to a ready process after the termination of another process is also considered a context switch. Which one of the following is NOT possible as CPU burst time (in time units) of these processes?

- (A) P = 4, Q = 10, R = 6, S = 2
- (B) P = 2, Q = 9, R = 5, S = 1
- (C) P = 4, Q = 12, R = 5, S = 4
- (D) P = 3, Q = 7, R = 7, S = 3

<details class="success" markdown="1">
<summary>Answer</summary>

**D ($P = 3, Q = 7, R = 7, S = 3$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Simulate each option.** The queue starts as P, Q, R, S. Each turn runs for $\min(4, \text{remaining})$ and the process goes to the back if unfinished.

| Option | Order of runs | S→Q | R→Q | Q→R | S→P |
| --- | --- | --- | --- | --- | --- |
| (A) | P Q R S Q R Q | 1 | 1 | 2 | 0 |
| (B) | P Q R S Q R Q | 1 | 1 | 2 | 0 |
| (C) | P Q R S Q R Q | 1 | 1 | 2 | 0 |
| (D) | P Q R S Q R | 1 | **0** | 2 | 0 |

In (A), (B) and (C) P and S finish in their first turn (each burst is at most 4), so the second round is Q, R, then a third Q turn after R. Counts match the required (1, 1, 2, 0).

In (D) the bursts are Q = 7 and R = 7, so each needs only two turns. The schedule ends with R's second turn and never switches from R to Q, so the required "one switch from R to Q" fails.

**Answer:** D is the one that is not possible.

**Code check:** a round-robin simulator counting switches between different consecutive processes confirmed the table.

**Key idea:** count the turns each process needs, $\lceil \text{burst} / 4 \rceil$, and read the switch counts off the resulting order.

</details>
