# 2014 CS3 Q32: Average waiting time under SRTF

## Question

An operating system uses *shortest remaining time first* scheduling algorithm for pre-emptive scheduling of processes. Consider the following set of processes with their arrival times and CPU burst times (in milliseconds):

| Process | Arrival Time | Burst Time |
|---|---|---|
| P1 | 0 | 12 |
| P2 | 2 | 4 |
| P3 | 3 | 6 |
| P4 | 8 | 5 |

The average waiting time (in milliseconds) of the processes is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5.5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

At every time unit, run the process with the smallest remaining time.

| Time | Running | Why |
|---|---|---|
| 0-2 | P1 | only process (rem 10 at t=2) |
| 2-6 | P2 | arrives with 4 $<$ 10; at t=3, P3 (6) $>$ P2's rem 3 |
| 6-12 | P3 | P3 (6) $<$ P1 (10); at t=8, P4 (5) $>$ P3's rem 4 |
| 12-17 | P4 | 5 $<$ P1 (10) |
| 17-27 | P1 | last |

Completion times: P2 = 6, P3 = 12, P4 = 17, P1 = 27.

$$\text{Waiting} = \text{completion} - \text{arrival} - \text{burst}$$

| Process | Waiting time |
|---|---|
| P1 | $27 - 0 - 12 = 15$ |
| P2 | $6 - 2 - 4 = 0$ |
| P3 | $12 - 3 - 6 = 3$ |
| P4 | $17 - 8 - 5 = 4$ |

$$\text{Average} = \frac{15 + 0 + 3 + 4}{4} = \frac{22}{4} = 5.5.$$

**Code check:** a time-step SRTF simulation gives the same completion times and an average of 5.5.

**Key idea:** SRTF is the pre-emptive form of SJF; re-decide whenever a process arrives.

</details>
