# 2007 CS Q55: Waiting time of P2 under SRT scheduling

## Question

An operating system uses Shortest Remaining Time first (SRT) process scheduling algorithm. Consider the arrival times and execution times for the following processes:

| Process | Execution time | Arrival time |
|---|---|---|
| P1 | 20 | 0 |
| P2 | 25 | 15 |
| P3 | 10 | 30 |
| P4 | 15 | 45 |

What is the total waiting time for process P2?

- (A) 5
- (B) 15
- (C) 40
- (D) 55

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

SRT always runs the process with the least remaining time, preempting when a shorter job arrives.

| Time | Event |
|---|---|
| 0-20 | P1 runs. P2 arrives at 15 (needs 25), but P1 has only 5 left, so P1 continues. |
| 20-30 | P2 runs (25 left, then 15 left). |
| 30 | P3 arrives needing 10 < 15, so P3 preempts P2. |
| 30-40 | P3 runs and finishes. |
| 40-55 | P2 resumes. P4 arrives at 45 (needs 15), but P2 has 10 left, so P2 continues and finishes at 55. |
| 55-70 | P4 runs. |

For P2: completion $= 55$, arrival $= 15$, burst $= 25$.
$$\text{waiting} = 55 - 15 - 25 = 15.$$

(B).

- (A) 5 is the time P1 still had left when P2 arrived.
- (C) 40 is P2's turnaround time ($55 - 15$).
- (D) 55 is its completion time.

**Code check:** Python unit-step SRT simulation: P2 finishes at 55, turnaround 40, waiting 15 (P1: 0, P3: 0, P4: 10).

**Key idea:** waiting time = turnaround time - burst time = (completion - arrival) - burst.

</details>
