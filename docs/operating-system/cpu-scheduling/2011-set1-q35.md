# 2011 CS Q35: Average waiting time under preemptive SJF

## Question

Consider the following table of arrival time and burst time for three processes P0, P1 and P2.

| Process | Arrival time | Burst Time |
|---|---|---|
| P0 | 0 ms | 9 ms |
| P1 | 1 ms | 4 ms |
| P2 | 2 ms | 9 ms |

The pre-emptive shortest job first scheduling algorithm is used. Scheduling is carried out only at arrival or completion of processes. What is the average waiting time for the three processes?

- (A) 5.0 ms
- (B) 4.33 ms
- (C) 6.33 ms
- (D) 7.33 ms

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Decisions are made only at arrivals and completions.

| Time | Event | Run |
|---|---|---|
| $0$ | P0 arrives (the only process) | P0 |
| $1$ | P1 arrives; P0 has $8$ left, P1 needs $4$, so P1 preempts | P1 |
| $2$ | P2 arrives; P1 has $3$ left, shorter than $9$, so P1 continues | P1 |
| $5$ | P1 completes; P0 has $8$ left, P2 has $9$ | P0 |
| $13$ | P0 completes | P2 |
| $22$ | P2 completes | |

Gantt chart: P0 $[0,1]$, P1 $[1,5]$, P0 $[5,13]$, P2 $[13,22]$.

Waiting time $=$ completion $-$ arrival $-$ burst:

- P0: $13 - 0 - 9 = 4$
- P1: $5 - 1 - 4 = 0$
- P2: $22 - 2 - 9 = 11$

$$\text{Average} = \frac{4 + 0 + 11}{3} = 5.0 \text{ ms}$$

So (A).

**Code check:** a simulation of the schedule gave completion times $13, 5, 22$ and waiting times $4, 0, 11$, average $5.0$.

**Key idea:** preemptive SJF is shortest remaining time first; waiting time = completion - arrival - burst.

</details>
