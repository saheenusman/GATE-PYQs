# 2012 CS Q31: Completion order under FCFS and round robin with quantum 2

## Question

Consider the 3 processes, P1, P2 and P3 shown in the table.

| Process | Arrival time | Time units required |
|---|---|---|
| P1 | 0 | 5 |
| P2 | 1 | 7 |
| P3 | 3 | 4 |

The completion order of the 3 processes under the policies FCFS and RR2 (round robin scheduling with CPU quantum of 2 time units) are

- (A) FCFS: P1, P2, P3; RR2: P1, P2, P3
- (B) FCFS: P1, P3, P2; RR2: P1, P3, P2
- (C) FCFS: P1, P2, P3; RR2: P1, P3, P2
- (D) FCFS: P1, P3, P2; RR2: P1, P2, P3

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**FCFS** runs in arrival order: P1 ($0$-$5$), P2 ($5$-$12$), P3 ($12$-$16$). Completion order: **P1, P2, P3**.

**RR2** (a process that arrives goes to the back of the queue):

| Time | Runs | Remaining after | Queue after |
|---|---|---|---|
| 0-2 | P1 | 3 | P2, P1 |
| 2-4 | P2 | 5 | P1, P3, P2 |
| 4-6 | P1 | 1 | P3, P2, P1 |
| 6-8 | P3 | 2 | P2, P1, P3 |
| 8-10 | P2 | 3 | P1, P3, P2 |
| 10-11 | P1 | 0 (done at 11) | P3, P2 |
| 11-13 | P3 | 0 (done at 13) | P2 |
| 13-16 | P2 | done at 16 | |

(P2 runs $13$-$15$ then $15$-$16$ with nothing else waiting.) Completion order: **P1, P3, P2**.

So FCFS: P1, P2, P3 and RR2: P1, P3, P2: (C).

No tie arises: arrivals at times 1 and 3 never coincide with a quantum expiry.

**Code check:** a scheduler simulation gave FCFS $\to$ P1, P2, P3 and RR2 $\to$ P1, P3, P2 under both tie conventions.

**Key idea:** in round robin a short job that arrives late can finish before a long job that arrived earlier.

</details>
