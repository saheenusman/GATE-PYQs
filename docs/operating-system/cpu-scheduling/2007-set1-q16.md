# 2007 CS Q16: Match scheduling algorithms with applications

## Question

Group 1 contains some CPU scheduling algorithms and Group 2 contains some applications. Match entries in Group 1 to entries in Group 2.

| Group 1 | Group 2 |
|---|---|
| P. Gang Scheduling | 1. Guaranteed Scheduling |
| Q. Rate Monotonic Scheduling | 2. Real-time Scheduling |
| R. Fair Share Scheduling | 3. Thread Scheduling |

- (A) P-3; Q-2; R-1
- (B) P-1; Q-2; R-3
- (C) P-2; Q-3; R-1
- (D) P-1; Q-3; R-2

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **P. Gang scheduling** schedules the related threads of one process together, at the same time, on different processors: **3 (thread scheduling)**.
- **Q. Rate monotonic scheduling** assigns fixed priorities by period for periodic tasks with deadlines: **2 (real-time scheduling)**.
- **R. Fair share scheduling** (with guaranteed scheduling) promises each user or process an equal or specified share of CPU time: **1 (guaranteed scheduling)**.

So P-3, Q-2, R-1: (A).

- (B), (C) and (D) each pair rate monotonic or gang scheduling with the wrong group; only (A) puts Q with real-time.

**Code check:** not applicable (matching question).

**Classification note:** borderline. The matching spans thread and real-time scheduling, but all three are CPU scheduling policies, so I filed it under `cpu-scheduling` rather than `processes-and-threads`.

**Wording caveat:** the pairing of fair share with "guaranteed scheduling" is textbook-style rather than precise, but it is the only consistent matching among the options.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** gang scheduling groups threads of a process, rate monotonic is the classic real-time policy, fair share gives guaranteed CPU shares.
