# 2017 CS2 Q51: Average waiting time under preemptive priority scheduling

## Question

Consider the set of processes with arrival time (in milliseconds), CPU burst time (in milliseconds), and priority (0 is the highest priority) shown below. None of the processes have I/O burst time.

| Process | Arrival Time | Burst Time | Priority |
|---|---|---|---|
| $P_1$ | 0 | 11 | 2 |
| $P_2$ | 5 | 28 | 0 |
| $P_3$ | 12 | 2 | 3 |
| $P_4$ | 2 | 10 | 1 |
| $P_5$ | 9 | 16 | 4 |

The average waiting time (in milliseconds) of all the processes using preemptive priority scheduling algorithm is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**29**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rule:** at every moment run the ready process with the smallest priority number; a new arrival with higher priority preempts the running one.

**Gantt chart.**

| Time | Running | Why |
|---|---|---|
| 0 to 2 | $P_1$ | only process (2 of 11 done) |
| 2 to 5 | $P_4$ | arrives with priority 1, beats $P_1$ (priority 2) (3 of 10 done) |
| 5 to 33 | $P_2$ | arrives with priority 0 and runs its full 28 |
| 33 to 40 | $P_4$ | highest priority among $P_1, P_3, P_4, P_5$ (7 left) |
| 40 to 49 | $P_1$ | next (9 left) |
| 49 to 51 | $P_3$ | priority 3 |
| 51 to 67 | $P_5$ | priority 4 |

**Waiting time** = completion $-$ arrival $-$ burst:

| Process | Completion | Waiting |
|---|---|---|
| $P_1$ | 49 | $49 - 0 - 11 = 38$ |
| $P_2$ | 33 | $33 - 5 - 28 = 0$ |
| $P_3$ | 51 | $51 - 12 - 2 = 37$ |
| $P_4$ | 40 | $40 - 2 - 10 = 28$ |
| $P_5$ | 67 | $67 - 9 - 16 = 42$ |

$$\text{average} = \frac{38 + 0 + 37 + 28 + 42}{5} = \frac{145}{5} = 29 \text{ ms}.$$

**Code check:** a millisecond-by-millisecond simulation produced the same Gantt chart and waiting times, with average 29.0.

**Key idea:** waiting time $=$ turnaround $-$ burst; with preemption, a running process is replaced only by a strictly higher priority arrival.

</details>
