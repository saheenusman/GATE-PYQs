# 2024 CS2 Q37: Average waiting time under SRTF and non-preemptive SJF

## Question

Consider a single processor system with four processes A, B, C, and D, represented as given below, where for each process the first value is its arrival time, and the second value is its CPU burst time.

A (0, 10), B (2, 6), C (4, 3), and D (6, 7).

Which one of the following options gives the average waiting times when preemptive Shortest Remaining Time First (SRTF) and Non-Preemptive Shortest Job First (NP-SJF) CPU scheduling algorithms are applied to the processes?

- (A) SRTF = 6, NP-SJF = 7
- (B) SRTF = 6, NP-SJF = 7.5
- (C) SRTF = 7, NP-SJF = 7.5
- (D) SRTF = 7, NP-SJF = 8.5

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Waiting time = completion − arrival − burst.

**SRTF (preemptive).**

| Time | Running | Reason |
|---|---|---|
| 0–2 | A | only process (A has 8 left) |
| 2–4 | B | B (6) shorter than A's 8 left |
| 4–7 | C | C (3) shorter than B's 4 left |
| 7–11 | B | B (4 left) shortest among B 4, D 7, A 8 |
| 11–18 | D | D (7) before A (8) |
| 18–26 | A | |

| | A | B | C | D |
|---|---|---|---|---|
| Completion | 26 | 11 | 7 | 18 |
| Waiting | 16 | 3 | 0 | 5 |

Average $= 24/4 = 6$.

**NP-SJF.** A runs 0–10 (the only process at time 0). Then among B (6), C (3), D (7): C 10–13, B 13–19, D 19–26.

| | A | B | C | D |
|---|---|---|---|---|
| Waiting | 0 | 11 | 6 | 13 |

Average $= 30/4 = 7.5$.

**Key idea:** SRTF re-decides whenever a process arrives. NP-SJF decides only when the CPU becomes free. (Both schedules were also reproduced with a small simulator.)

</details>
