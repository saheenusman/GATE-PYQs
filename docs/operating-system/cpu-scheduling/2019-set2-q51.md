# 2019 CS2 Q51: Burst time that gives average waiting time of 1 ms under SRTF

## Question

Consider the following four processes with arrival times (in milliseconds) and their length of CPU bursts (in milliseconds) as shown below:

| Process | P1 | P2 | P3 | P4 |
|---|---|---|---|---|
| Arrival time | 0 | 1 | 3 | 4 |
| CPU burst time | 3 | 1 | 3 | Z |

These processes are run on a single processor using preemptive Shortest Remaining Time First scheduling algorithm. If the average waiting time of the processes is 1 millisecond, then the value of Z is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Waiting time $=$ completion $-$ arrival $-$ burst. Total waiting must be $4 \times 1 = 4$ ms.

**Try $Z = 2$.**

| Time | Runs | Reason |
|---|---|---|
| 0 to 1 | P1 | only process |
| 1 to 2 | P2 | P2 (burst 1) beats P1 (2 left) |
| 2 to 4 | P1 | P1 (2 left) is shortest. At 3, P3 arrives (3) but P1 has 1 left, so no preemption |
| 4 to 6 | P4 | P4 (2) beats P3 (3) |
| 6 to 9 | P3 | last one |

| Process | Completion | Waiting |
|---|---|---|
| P1 | 4 | $4 - 0 - 3 = 1$ |
| P2 | 2 | $2 - 1 - 1 = 0$ |
| P3 | 9 | $9 - 3 - 3 = 3$ |
| P4 | 6 | $6 - 4 - 2 = 0$ |

Total $= 4$, average $= 1$. So $Z = 2$.

**Code check:** a preemptive SRTF simulator for $Z = 1$ to $6$ gives averages $0.75, 1.0, 1.25, 1.25, 1.25, 1.25$. Only $Z = 2$ gives exactly 1.

**Key idea:** SRTF always runs the process with the least remaining time. Preempt only when a newcomer is strictly shorter.

</details>
