# 2016 CS1 Q20: Scheduling algorithm minimising average waiting time for CPU-bound processes

## Question

Consider an arbitrary set of CPU-bound processes with unequal CPU burst lengths submitted at the same time to a computer system. Which one of the following process scheduling algorithms would minimize the average waiting time in the ready queue?

- (A) Shortest remaining time first
- (B) Round-robin with time quantum less than the shortest CPU burst
- (C) Uniform random
- (D) Highest priority first with priority proportional to CPU burst length

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Shortest-job-first style scheduling is provably optimal for average waiting time. All processes arrive together, so shortest remaining time first (SRTF) behaves exactly like SJF here.

**Worked example.** Bursts $3, 6, 9$, all arriving at time $0$:

| Algorithm | Waiting times | Average |
|---|---|---|
| SRTF / SJF | $0, 3, 9$ | $4$ |
| Highest priority = longest burst first | $0, 9, 15$ | $8$ |
| Round-robin, quantum $1$ | $4, 8, 9$ | $7$ |

**Why the others fail.**

- (B) Round-robin with a tiny quantum shares the CPU equally, so short jobs wait behind slices of long jobs.
- (C) Uniform random order is on average no better than a fixed arbitrary order.
- (D) Priority proportional to burst length means *longest* first, the worst order for average waiting time.

**Code check:** simulating the three bursts gave average waiting times $4$ (SJF), $8$ (longest first) and $7$ (round-robin, quantum $1$).

**Key idea:** SJF/SRTF minimises average waiting time; longest-first is the worst case.

</details>
