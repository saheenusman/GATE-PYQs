# 2017 CS1 Q40: Belady's anomaly under random replacement and LRU

## Question

Recall that Belady's anomaly is that the page-fault rate may *increase* as the number of allocated frames increases. Now, consider the following statements:

- S1: *Random page replacement* algorithm (where a page chosen at random is replaced) suffers from Belady's anomaly
- S2: *LRU page replacement* algorithm suffers from Belady's anomaly

Which of the following is CORRECT?

- (A) S1 is true, S2 is true
- (B) S1 is true, S2 is false
- (C) S1 is false, S2 is true
- (D) S1 is false, S2 is false

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Stack algorithms.** A page replacement algorithm is a *stack algorithm* if, at every moment, the set of pages held with $k$ frames is a subset of the set held with $k+1$ frames. Such algorithms never show Belady's anomaly, since adding a frame can only turn faults into hits.

**S2 is false.** LRU keeps the $k$ most recently used pages, which is always contained in the $k+1$ most recently used pages. LRU is a stack algorithm, so it has no anomaly.

**S1 is true.** Random replacement does not keep that inclusion property. Its victim choices are independent of the number of frames, and one possible sequence of random choices is exactly FIFO's choices. FIFO is the classic anomaly case on the reference string $1,2,3,4,1,2,5,1,2,3,4,5$: 9 faults with 3 frames but 10 with 4 frames. So random replacement *can* produce more faults with more frames.

So S1 true, S2 false: **(B)**.

**Why the others fail.** (A), (C) say LRU suffers from the anomaly. (D) says random replacement cannot, but it can.

**Code check:** FIFO on that string gave 9 and 10 faults for 3 and 4 frames. Enumerating every possible random-victim choice showed 9 faults is achievable with 3 frames and 10 with 4 frames. LRU on that string gave 10 and 8, and across 20,000 random reference strings LRU never had a fault count rise when frames were added.

**Key idea:** only stack algorithms (LRU, OPT) are immune to Belady's anomaly; FIFO and random replacement are not.

</details>
