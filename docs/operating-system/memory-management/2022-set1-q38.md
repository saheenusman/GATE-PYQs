# 2022 CS Q38: False statement about TLB and page tables

## Question

Which one of the following statements is FALSE?

- (A) The TLB performs an associative search in parallel on all its valid entries using page number of incoming virtual address.
- (B) If the virtual address of a word given by CPU has a TLB hit, but the subsequent search for the word results in a cache miss, then the word will always be present in the main memory.
- (C) The memory access time using a given inverted page table is always same for all incoming virtual addresses.
- (D) In a system that uses hashed page tables, if two distinct virtual addresses V1 and V2 map to the same value while hashing, then the memory access time of these addresses will not be the same.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** A TLB is a fully associative cache of page-table entries, compared in parallel.
- **(B) True.** A TLB hit means the page has a valid mapping, so the page is resident in main memory. A cache miss then just means the word is fetched from memory.
- **(C) False.** An inverted page table is searched (usually through a hash), and the number of probes depends on the address. So the access time is not the same for all addresses.
- **(D) True** (the key treats it as true). Addresses that hash to the same value share a chain, so they are found after different numbers of probes, and the later one in the chain costs more.

**Key idea:** inverted and hashed page tables have variable lookup cost because of searching and collision chains.

</details>
