# 2025 CS2 Q58: Outer-index bits in two-level paging

## Question

A computer system supports a logical address space of $2^{32}$ bytes. It uses two-level hierarchical paging with a page size of 4096 bytes. A logical address is divided into a $b$-bit index to the outer page table, an offset within the page of the inner page table, and an offset within the desired page. Each entry of the inner page table uses eight bytes. All the pages in the system have the same size.

The value of $b$ is ___________ . (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**11**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Every page (including a page that holds part of the inner page table) is $4096 = 2^{12}$ bytes.

| Field | Reasoning | Bits |
|---|---|---|
| Offset within the desired page | page size $2^{12}$ | 12 |
| Index into an inner page table | one inner table fills one page: $4096 / 8 = 512 = 2^9$ entries | 9 |
| Index into the outer page table | the rest | $b$ |

The three fields must add up to the 32-bit logical address:

$$b + 9 + 12 = 32 \Rightarrow b = 11.$$

**Key idea:** the inner page table is sized to fit exactly in one page, so its entry count is page size / entry size.

</details>
