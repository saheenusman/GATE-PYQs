# 2024 CS2 Q64: Pages used by a two-level page table

## Question

Consider a 32-bit system with 4 KB page size and page table entries of size 4 bytes each. Assume 1 KB = $2^{10}$ bytes. The OS uses a 2-level page table for memory management, with the page table containing an outer page directory and an inner page table. The OS allocates a page for the outer page directory upon process creation. The OS uses demand paging when allocating memory for the inner page table, i.e., a page of the inner page table is allocated only if it contains at least one valid page table entry.

An active process in this system accesses 2000 unique pages during its execution, and none of the pages are swapped out to disk. After it completes the page accesses, let $X$ denote the minimum and $Y$ denote the maximum number of pages across the two levels of the page table of the process.

The value of $X + Y$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**1028**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Sizes.** Page = 4 KB, entry = 4 B, so one page holds $4096/4 = 1024$ entries. A 32-bit address has a 20-bit page number, which splits into **10 bits** for the outer directory and **10 bits** for an inner table. The outer directory is exactly 1 page, with 1024 entries, one per inner table.

**Each inner table page covers 1024 virtual pages.**

**Minimum ($X$).** Pack the 2000 pages into consecutive virtual pages:

$$\text{inner pages} = \lceil 2000 / 1024 \rceil = 2,\qquad X = 1 + 2 = 3.$$

**Maximum ($Y$).** Spread the pages so that each lies in a different inner table. But the directory has only 1024 entries, so at most 1024 inner tables exist:

$$\text{inner pages} = \min(2000, 1024) = 1024,\qquad Y = 1 + 1024 = 1025.$$

$$X + Y = 3 + 1025 = 1028.$$

**Key idea:** the minimum packs pages tightly. The maximum is capped by the number of directory entries, not by the number of pages accessed.

</details>
