# 2026 CS2 Q54: Size of a TLB in bytes

## Question

A system has a TLB with a **reach** of 1 MB (the total physical memory accessible through its entries). Pages are 4 KB. The virtual address space is 64 GB and the physical address space is 1 GB. Each TLB entry stores a 4-bit process id, the page number, the frame number, and a 2-bit control field.

The size of the TLB in bytes is _____. (answer in integer) (Note: 1K $= 2^{10}$, 1M $= 2^{20}$, 1G $= 2^{30}$)

<details class="success" markdown="1">
<summary>Answer</summary>

**1536**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1: number of entries.**

$$\text{entries} = \frac{\text{reach}}{\text{page size}} = \frac{2^{20}}{2^{12}} = 2^8 = 256.$$

**Step 2: bits per entry.**

| Field | Bits | Why |
|---|---|---|
| process id | 4 | given |
| page number | 24 | virtual address $= 2^{36}$ (64 GB), offset $= 12$ bits, so $36 - 12 = 24$ |
| frame number | 18 | physical address $= 2^{30}$ (1 GB), so $30 - 12 = 18$ |
| control | 2 | given |
| **Total** | **48** | = 6 bytes |

**Step 3: total size.**

$$256 \times 48\ \text{bits} = 256 \times 6\ \text{bytes} = 1536\ \text{bytes}.$$

**Key idea:** page and frame number widths are the address width minus the page-offset bits; the TLB size is entries times bits per entry.

</details>
