# 2025 CS1 Q14: Page table entries with 32-bit logical addresses

## Question

Consider a demand paging memory management system with 32-bit logical address, 20-bit physical address, and page size of 2048 bytes. Assuming that the memory is byte addressable, what is the maximum number of entries in the page table?

- (A) $2^{21}$
- (B) $2^{20}$
- (C) $2^{22}$
- (D) $2^{24}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The page table has **one entry per logical page**, so its size depends only on the **logical** address space and the page size.

Page size $= 2048 = 2^{11}$ bytes, so the offset takes 11 bits. The page number takes the remaining

$$32 - 11 = 21 \text{ bits},$$

so there are $2^{21}$ pages, and the page table has up to $2^{21}$ entries.

The 20-bit physical address is a distractor. It only gives $2^{20-11} = 2^9$ frames, which determines the width of each entry, not how many entries there are.

**Key idea:** page-table entries = number of logical pages $= 2^{\text{logical bits} - \text{offset bits}}$.

</details>
