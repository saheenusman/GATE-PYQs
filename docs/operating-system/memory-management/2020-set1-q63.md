# 2020 CS Q63: Average memory access time with a TLB and page faults

## Question

Consider a paging system that uses 1-level page table residing in main memory and a TLB for address translation. Each main memory access takes 100 ns and TLB lookup takes 20 ns. Each page transfer to/from the disk takes 5000 ns. Assume that the TLB hit ratio is 95%, page fault rate is 10%. Assume that for 20% of the total page faults, a dirty page has to be written back to disk before the required page is read in from disk. TLB update time is negligible. The average memory access time in ns (round off to 1 decimal places) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**155** (the key accepts 154.5 to 155.5)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Reading of the question.** A page that is in the TLB is already in memory, so a page fault can only happen on a **TLB miss**. The 10% page fault rate is therefore applied to the TLB-miss path (the page-table reference). This is the reading the official key follows.

**Page fault service time.** Reading the page takes 5000 ns. In 20% of faults a dirty page is written back first, which costs another 5000 ns:

$$5000 + 0.2 \times 5000 = 6000 \text{ ns}.$$

**Each case:**

| Case | Probability | Time (ns) |
|---|---|---|
| TLB hit | 0.95 | $20 + 100 = 120$ |
| TLB miss, no fault | $0.05 \times 0.9$ | $20 + 100 + 100 = 220$ |
| TLB miss, page fault | $0.05 \times 0.1$ | $220 + 6000 = 6220$ |

(On a miss: TLB lookup, then the page-table access, then the data access. A fault adds the service time.)

**Average:**

$$0.95(120) + 0.045(220) + 0.005(6220) = 114 + 9.9 + 31.1 = 155 \text{ ns}.$$

The same value comes out as $125 + 0.005 \times 6000 = 155$, where 125 is the average with no faults.

**The other reading.** If the 10% fault rate were applied to *all* accesses, the result would be $125 + 0.1 \times 6000 = 725$ ns. That does not match the key, and it is physically inconsistent (a TLB hit means the page is resident).

**Key idea:** page faults can occur only when the translation is not in the TLB, so the fault rate multiplies the TLB miss rate.

</details>
