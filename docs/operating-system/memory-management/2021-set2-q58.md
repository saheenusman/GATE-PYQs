# 2021 CS2 Q58: Minimum page-table memory for a 3-level page table

## Question

Consider a three-level page table to translate a 39-bit virtual address to a physical address as shown below.

```
<------------- 39-bit virtual address ------------->
| Level 1 | Level 2 | Level 3 |    Page     |
| offset  | offset  | offset  |   offset    |
|  9 bits |  9 bits |  9 bits |   12 bits   |
```

The page size is 4KB ($1\text{KB}=2^{10}$ bytes) and page table entry size at every level is 8 bytes. A process $P$ is currently using 2GB ($1\text{GB}=2^{30}$ bytes) virtual memory which is mapped to 2GB of physical memory. The minimum amount of memory required for the page table of $P$ across all levels is ______ KB.

<details class="success" markdown="1">
<summary>Answer</summary>

**4108**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each page-table page holds $2^9$ entries of 8 bytes, which is $2^{12}=4$ KB. Every table is exactly one page.

Pages to map: $2\text{ GB}/4\text{ KB}=2^{31}/2^{12}=2^{19}$.

Allocate only the tables that are needed, assuming the best (contiguous) layout:

| level | tables | why |
|---|---|---|
| 3 | $2^{19}/2^{9}=1024$ | one entry per page, 512 per table |
| 2 | $1024/512=2$ | one entry per level-3 table |
| 1 | 1 | one entry per level-2 table (2 of 512 used) |

Total tables $=1024+2+1=1027$.

Memory $=1027\times4\text{ KB}=4108\text{ KB}$.

**Key idea:** count the pages mapped, then the number of tables needed at each level, bottom up; the minimum assumes the mapped addresses are contiguous.

</details>
