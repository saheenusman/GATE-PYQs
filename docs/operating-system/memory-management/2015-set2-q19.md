# 2015 CS2 Q19: Minimum TLB tag length for a set-associative TLB

## Question

A computer system implements a 40-bit virtual address, page size of 8 kilobytes, and a 128-entry translation look-aside buffer (TLB) organized into 32 sets each having four ways. Assume that the TLB tag does not store any process id. The minimum length of the TLB tag in bits is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**22**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Page offset: $8\text{ KB} = 2^{13}$, so 13 bits.
- Virtual page number: $40 - 13 = 27$ bits.
- TLB set index: 32 sets $= 2^5$, so 5 bits.
- Tag $=$ virtual page number $-$ index $= 27 - 5 = 22$ bits.

(128 entries / 4 ways = 32 sets, which agrees with the given 32 sets.)

**Key idea:** tag $=$ virtual address bits $-$ page offset bits $-$ set index bits.

</details>
