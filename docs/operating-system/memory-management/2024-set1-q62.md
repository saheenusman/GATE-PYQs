# 2024 CS1 Q62: Virtual to physical address with paging

## Question

Consider a memory management system that uses a page size of 2 KB. Assume that both the physical and virtual addresses start from 0. Assume that the pages 0, 1, 2, and 3 are stored in the page frames 1, 3, 2, and 0, respectively. The physical address (in decimal format) corresponding to the virtual address 2500 (in decimal format) is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**6596**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Page size $= 2\text{ KB} = 2048$ bytes.

**Split the virtual address:**

$$\text{page} = \lfloor 2500 / 2048 \rfloor = 1,\qquad \text{offset} = 2500 \bmod 2048 = 452.$$

**Look up page 1:** it is stored in frame **3**.

**Physical address** $= 3 \times 2048 + 452 = 6144 + 452 = 6596$.

**Key idea:** physical address $=$ frame number $\times$ page size $+$ offset.

</details>
