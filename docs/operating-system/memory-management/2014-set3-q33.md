# 2014 CS3 Q33: Effective memory access time with a TLB

## Question

Consider a paging hardware with a TLB. Assume that the entire page table and all the pages are in the physical memory. It takes 10 milliseconds to search the TLB and 80 milliseconds to access the physical memory. If the TLB hit ratio is 0.6, the effective memory access time (in milliseconds) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**122**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The TLB is searched on every access.

- **TLB hit** (probability 0.6): TLB search $+$ one memory access $= 10 + 80 = 90$ ms.
- **TLB miss** (probability 0.4): TLB search $+$ page-table access $+$ data access $= 10 + 80 + 80 = 170$ ms.

$$\text{EMAT} = 0.6 \times 90 + 0.4 \times 170 = 54 + 68 = 122 \text{ ms}.$$

**Code check:** `0.6*(10+80) + 0.4*(10+80+80)` gives `122.0`.

**Key idea:** the TLB lookup time is paid on both hits and misses; a miss adds one extra memory access for the page table.

</details>
