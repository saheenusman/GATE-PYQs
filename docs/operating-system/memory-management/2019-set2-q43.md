# 2019 CS2 Q43: Distinct virtual addresses covered by a TLB

## Question

Assume that in a certain computer, the virtual addresses are 64 bits long and the physical addresses are 48 bits long. The memory is word addressable. The page size is 8 kB and the word size is 4 bytes. The Translation Look-aside Buffer (TLB) in the address translation path has 128 valid entries. At most how many distinct virtual addresses can be translated without any TLB miss?

- (A) $16 \times 2^{10}$
- (B) $256 \times 2^{10}$
- (C) $4 \times 2^{20}$
- (D) $8 \times 2^{20}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each TLB entry maps **one page**. The memory is **word** addressable, so count addresses in words.

| Quantity | Value |
|---|---|
| Page size | 8 kB $= 2^{13}$ bytes |
| Word size | 4 B $= 2^2$ bytes |
| Words per page | $2^{13}/2^2 = 2^{11}$ |
| TLB entries | $128 = 2^7$ |

$$\text{distinct addresses} = 2^7 \cdot 2^{11} = 2^{18} = 256 \times 2^{10}.$$

**Why the others fail:** (A), (C) and (D) equal $2^{14}$, $2^{22}$ and $2^{23}$, which would need pages of $2^7$, $2^{15}$ or $2^{16}$ words. None matches 8 kB with 4-byte words. Counting bytes instead would give $2^{20}$, which is not an option either.

**Key idea:** TLB reach is entries times page size, counted in the unit the memory is addressed in.

</details>
