# 2014 CS2 Q33: Which page replacement policy matches optimal on a cyclic scan

## Question

A computer has twenty physical page frames which contain pages numbered 101 through 120. Now a program accesses the pages numbered 1, 2, ..., 100 in that order, and repeats the access sequence THRICE. Which one of the following page replacement policies experiences the same number of page faults as the optimal page replacement policy for this program?

- (A) Least-recently-used
- (B) First-in-first-out
- (C) Last-in-first-out
- (D) Most-recently-used

<details class="success" markdown="1">
<summary>Answer</summary>

**D** (official key; see the reading note)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Disputed (reading-dependent).** The key is **D**. It holds if the pages 101-120 already in memory are treated as free frames. If they stay resident as ordinary pages, I find no option that matches.

**Setup.** 300 accesses over 100 distinct pages, 20 frames, and the program never touches 101-120.

- **LRU and FIFO** fault on every access (300). On a cyclic scan longer than memory, each page is evicted before its reuse.
- **Optimal** evicts the page used farthest ahead. It keeps a fixed set of pages that are re-used soon, so many accesses in passes 2 and 3 hit. It faults **260** times.
- **MRU** evicts the page just used, so it also keeps a fixed set and the rest cycle through the last frame, like optimal.

**Code check.** I simulated all five policies:

| Policy | 20 frames empty at the start | 101-120 resident |
|---|---|---|
| Optimal | 260 | 260 |
| LRU | 300 | 300 |
| FIFO | 300 | 300 |
| LIFO | 262 | 300 |
| MRU | **260** | 300 |

With the frames effectively empty, MRU equals optimal (260) and LIFO is close but not equal (262), which gives key D. With 101-120 resident, MRU never evicts them (the most recently used page is always the one just loaded), so MRU faults on all 300 accesses and none of the four options equals 260.

I have not chosen between the readings. The key's answer D is the only option that can match, and only under the first reading.

**Key idea:** on a cyclic scan larger than memory, LRU and FIFO are worst case; MRU behaves like optimal.

</details>
