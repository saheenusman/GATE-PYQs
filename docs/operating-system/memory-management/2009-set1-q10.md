# 2009 CS Q10: Essential content of a page table entry

## Question

The essential content(s) in each entry of a page table is/are

- (A) virtual page number.
- (B) page frame number.
- (C) both virtual page number and page frame number.
- (D) access right information.

<details class="success" markdown="1">
<summary>Answer</summary>

**B** (my answer; the supplied key leaves Q10 blank)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Official key:** the key table in the supplied PDF has no entry for Q10, so I cannot check against it. The answer below is my own reasoning.

In a standard page table the **virtual page number is the index** into the table. Entry number $v$ is the entry for page $v$, so the page number need not be stored in the entry. What the translation needs from the entry is **where the page is in memory**: the page frame number. So the essential content is the page frame number: (B).

- (A) is wrong: the virtual page number is implied by the position of the entry, so it is not stored.
- (C) is wrong for the same reason: only the frame number is essential.
- (D) is wrong: protection (access right) bits, a valid bit, dirty and reference bits are usually present, but they are extra control information. Translation still works without them.

**Status note:** marked `unverified` because the key gives no answer to compare with. This is a conceptual question, so there is no code to run. (An inverted or hashed page table does store the page number, but the question refers to an ordinary page table.)

**Key idea:** the page table is indexed by virtual page number, so each entry's essential content is the frame number.
