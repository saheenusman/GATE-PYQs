# 2024 CS2 Q24: Responsibilities of the MMU

## Question

Which of the following tasks is/are the responsibility/responsibilities of the memory management unit (MMU) in a system with paging-based memory management?

- (A) Allocate a new page table for a newly created process
- (B) Translate a virtual address to a physical address using the page table
- (C) Raise a trap when a virtual address is not found in the page table
- (D) Raise a trap when a process tries to write to a page marked with read-only permission in the page table

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The MMU is **hardware** that works on every memory access. The **OS** does the bookkeeping.

- **(A) Not the MMU.** Allocating a page table for a new process is done by the OS in software.
- **(B) MMU.** Translating a virtual address to a physical address through the page table (with the TLB) is its main job.
- **(C) MMU.** If the page is missing or invalid, the MMU raises a page-fault trap for the OS to handle.
- **(D) MMU.** The MMU checks the protection bits and traps on a write to a read-only page.

**Key idea:** the OS sets up the page tables, and the MMU hardware uses them and raises traps.

</details>
