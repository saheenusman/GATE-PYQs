# 2008 CS Q67: Bits to address the next level in a three-level page table

## Question

A processor uses 36 bit physical addresses and 32 bit virtual addresses, with a page frame size of 4 Kbytes. Each page table entry is of size 4 bytes. A three level page table is used for virtual to physical address translation, where the virtual address is used as follows:

- bits 30-31 are used to index into the first level page table,
- bits 21-29 are used to index into the second level page table,
- bits 12-20 are used to index into the third level page table, and
- bits 0-11 are used as offset within the page.

The number of bits required for addressing the next level page table (or page frame) in the page table entry of the first, second and third level page tables are respectively

- (A) 20, 20 and 20
- (B) 24, 24 and 24
- (C) 24, 24 and 20
- (D) 25, 25 and 24

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Sizes of the tables.**

- Second and third level tables are indexed by 9 bits, so each has $2^9$ entries of 4 bytes: $2^9 \times 4 = 2^{11}$ bytes (2 KB).
- The first level table has $2^2 = 4$ entries (16 bytes).

**Bits needed in each entry** (physical address is 36 bits):

- The **third level** entries point to a **page frame** of $2^{12}$ bytes, so a frame number needs $36 - 12 = 24$ bits.
- The **first and second level** entries point to a **next-level table** of size $2^{11}$ bytes. A table can start at any 2 KB boundary, so its address needs $36 - 11 = 25$ bits.

So the first, second and third level entries need $25$, $25$ and $24$ bits: (D).

- (A) 20 bits is $32 - 12$: it ignores that physical addresses are 36 bits.
- (B) 24, 24, 24 would be right only if every table occupied a whole 4 KB frame. Here the tables are only 2 KB.
- (C) treats the third level as 20 bits, which is wrong for a frame number.

**Key idea:** the bits in an entry equal the physical address width minus the log of the size (alignment) of the object it points to.

</details>
