# 2016 CS1 Q49: Page fault difference between LIFO and optimal replacement

## Question

Consider a computer system with ten physical page frames. The system is provided with an access sequence $(a_1, a_2, \dots, a_{20}, a_1, a_2, \dots, a_{20})$, where each $a_i$ is a distinct virtual page number. The difference in the number of page faults between the last-in-first-out page replacement policy and the optimal page replacement policy is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**LIFO.** First pass: $a_1, \dots, a_{10}$ fill the frames (10 faults). Then each new page replaces the most recently loaded one, so $a_{11}$ replaces $a_{10}$, $a_{12}$ replaces $a_{11}$, and so on up to $a_{20}$ (10 more faults). After the first pass the frames hold $a_1, \dots, a_9$ and $a_{20}$.

Second pass: $a_1, \dots, a_9$ hit; $a_{10}$ faults (replaces $a_{20}$), $a_{11}$ faults (replaces $a_{10}$), and so on to $a_{20}$: that is $11$ faults.

$$\text{LIFO} = 20 + 11 = 31$$

**Optimal.** OPT evicts the page whose next use is farthest away. Simulating it gives $30$ faults in total (the same $20$ in the first pass, and $10$ in the second).

$$\text{difference} = 31 - 30 = 1$$

**Code check:** simulating both policies with $10$ frames gave $31$ (LIFO) and $30$ (OPT).

**Key idea:** simulate both policies: LIFO gives 31 faults, OPT gives 30.

</details>
