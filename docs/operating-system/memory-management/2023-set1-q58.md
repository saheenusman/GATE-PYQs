# 2023 CS Q58: Levels of a multi-level page table

## Question

Consider a computer system with 57-bit virtual addressing using multi-level tree-structured page tables with $L$ levels for virtual to physical address translation. The page size is 4 KB (1 KB = 1024 B) and a page table entry at any of the levels occupies 8 bytes.

The value of $L$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Offset bits.** $4\text{ KB} = 2^{12}$ bytes, so 12 bits.

**Bits per level.** A page table sits in one page, so it holds $4096 / 8 = 512 = 2^9$ entries. Each level indexes 9 bits.

**Levels needed.** Address bits to translate: $57 - 12 = 45$.

$$L = \frac{45}{9} = 5$$

**Key idea:** each level of the page table consumes $\log_2(\text{page size} / \text{entry size})$ bits.

</details>
