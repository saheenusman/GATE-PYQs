# 2013 CS Q52: Page size with a 3-level page table

## Question

**Statement for Linked Answer Questions 52 and 53.** A computer uses 46-bit virtual address, 32-bit physical address, and a three-level paged page table organization. The page table base register stores the base address of the first-level table ($T_1$), which occupies exactly one page. Each entry of $T_1$ stores the base address of a page of the second-level table ($T_2$). Each entry of $T_2$ stores the base address of a page of the third-level table ($T_3$). Each entry of $T_3$ stores a page table entry (PTE). The PTE is 32 bits in size. The processor used in the computer has a 1 MB 16-way set associative virtually indexed physically tagged cache. The cache block size is 64 bytes.

What is the size of a page in KB in this computer?

- (A) 2
- (B) 4
- (C) 8
- (D) 16

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the page size be $2^p$ bytes. A table entry is 4 bytes (32 bits), and each table is one page, so a table holds $2^p/4 = 2^{p-2}$ entries.

The 46-bit virtual address splits into three table indices and one page offset:

$$3\,(p-2) + p = 46 \;\Rightarrow\; 4p = 52 \;\Rightarrow\; p = 13$$

Page size $= 2^{13}$ B $= 8$ KB.

**Check.** Each table index is $11$ bits ($2048$ entries of 4 B $= 8$ KB), and $11\cdot3 + 13 = 46$.

**Why the others fail:** 2 KB, 4 KB and 16 KB give $p = 11, 12, 14$, so the address would have $3(p-2)+p = 38, 42, 50$ bits, not 46.

**Code check:** solving the equation numerically gave $p = 13$.

**Key idea:** every level indexes a one-page table, so index bits per level $= \log_2(\text{page size}/\text{PTE size})$.

</details>
