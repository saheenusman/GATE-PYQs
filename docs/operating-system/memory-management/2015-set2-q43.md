# 2015 CS2 Q43: Virtual address length from the maximum page table size

## Question

A computer system implements 8 kilobyte pages and a 32-bit physical address space. Each page table entry contains a valid bit, a dirty bit, three permission bits, and the translation. If the maximum size of the page table of a process is 24 megabytes, the length of the virtual address supported by the system is ______ bits.

<details class="success" markdown="1">
<summary>Answer</summary>

**36**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Page offset: $8\text{ KB} = 2^{13}$, so 13 bits.
- Frame number: $32 - 13 = 19$ bits (this is the "translation" part of an entry).
- Entry size: $1 + 1 + 3 + 19 = 24$ bits $= 3$ bytes.
- Number of entries: $\dfrac{24\text{ MB}}{3\text{ B}} = \dfrac{24 \times 2^{20}}{3} = 8 \times 2^{20} = 2^{23}$.
- So there are $2^{23}$ virtual pages, i.e. a 23-bit page number.

Virtual address length $= 23 + 13 = 36$ bits.

**Key idea:** page table size $=$ (number of pages) $\times$ (entry size); read off the page-number bits and add the offset.

</details>
