# 2014 CS1 Q33: Page faults with optimal replacement (3 frames)

## Question

Assume that there are 3 page frames which are initially empty. If the page reference string is 1, 2, 3, 4, 2, 1, 5, 3, 2, 4, 6, the number of page faults using the *optimal replacement policy* is__________.

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Optimal replaces the page whose next use is farthest in the future.

| Ref | Frames after | Fault | Evicted (reason) |
|---|---|---|---|
| 1 | 1 | F | |
| 2 | 1 2 | F | |
| 3 | 1 2 3 | F | |
| 4 | 1 2 4 | F | 3 (used after 1 and 2) |
| 2 | 1 2 4 | | hit |
| 1 | 1 2 4 | | hit |
| 5 | 5 2 4 | F | 1 (never used again) |
| 3 | 3 2 4 | F | 5 (never used again) |
| 2 | 3 2 4 | | hit |
| 4 | 3 2 4 | | hit |
| 6 | 6 2 4 or similar | F | any of 3, 2, 4 (none used again) |

Faults: 1, 2, 3, 4, 5, 3, 6 $= 7$.

**Code check:** an optimal-replacement simulation reports 7 faults.

**Key idea:** optimal evicts the page used farthest ahead (or never again).

</details>
