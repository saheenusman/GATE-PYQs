# 2018 CS Q20: Page fault rate from the effective access time

## Question

Consider a process executing on an operating system that uses demand paging. The average time for a memory access in the system is $M$ units if the corresponding memory page is available in memory, and $D$ units if the memory access causes a page fault. It has been experimentally measured that the average time taken for a memory access in the process is $X$ units.

Which one of the following is the correct expression for the page fault rate experienced by the process?

- (A) $\dfrac{D-M}{X-M}$
- (B) $\dfrac{X-M}{D-M}$
- (C) $\dfrac{D-X}{D-M}$
- (D) $\dfrac{X-M}{D-X}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Effective access time with fault rate $p$:**

$$X = (1-p)M + pD = M + p(D-M)$$

**Solve for $p$:**

$$p = \frac{X-M}{D-M}$$

**Sanity check:** if $X = M$ then $p = 0$; if $X = D$ then $p = 1$. Option B does both.

**Why the others fail:** A is the reciprocal of B. C gives $p = 1$ when $X=M$. D gives $p = 1$ at $X=D$ only by division by zero.

**Key idea:** effective access time is a weighted average of the hit time and the fault time.

</details>
