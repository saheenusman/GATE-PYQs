# 2025 CS1 Q54: Optimal page replacement with only 4 references of look-ahead

## Question

In optimal page replacement algorithm, information about all future page references is available to the operating system (OS). A modification of the optimal page replacement algorithm is as follows:

The OS correctly predicts only up to next 4 page references (including the current page) at the time of allocating a frame to a page.

A process accesses the pages in the following order of page numbers:

$$1,\ 3,\ 2,\ 4,\ 2,\ 3,\ 1,\ 2,\ 4,\ 3,\ 1,\ 4.$$

If the system has three memory frames that are initially empty, the number of page faults that will occur during execution of the process is ________ . (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

At a page fault the OS looks at the current reference and the next 3 (4 in all). Among the resident pages it evicts the one whose next use is **farthest within that window**, or any one that does not appear in the window.

| Time | Ref | Hit/fault | Window | Resident pages and their next use in the window | Evict | Frames after |
|---|---|---|---|---|---|---|
| 0 | 1 | fault | | free frame | | 1 |
| 1 | 3 | fault | | free frame | | 1, 3 |
| 2 | 2 | fault | | free frame | | 1, 3, 2 |
| 3 | 4 | **fault** | 4, 2, 3, 1 | 2 at +1, 3 at +2, 1 at +3 | **1** | 4, 3, 2 |
| 4 | 2 | hit | | | | 4, 3, 2 |
| 5 | 3 | hit | | | | 4, 3, 2 |
| 6 | 1 | **fault** | 1, 2, 4, 3 | 2 at +1, 4 at +2, 3 at +3 | **3** | 4, 1, 2 |
| 7 | 2 | hit | | | | 4, 1, 2 |
| 8 | 4 | hit | | | | 4, 1, 2 |
| 9 | 3 | **fault** | 3, 1, 4 | 1 at +1, 4 at +2, 2 **not in window** | **2** | 4, 1, 3 |
| 10 | 1 | hit | | | | 4, 1, 3 |
| 11 | 4 | hit | | | | 4, 1, 3 |

Faults: 3 (initial) $+$ 3 (at times 3, 6, 9) $= 6$.

A short simulation of this rule also gives 6 faults.

**Key idea:** at a fault, evict the resident page that is used farthest in the future *within the known window*, and prefer a page that does not appear at all.

</details>
