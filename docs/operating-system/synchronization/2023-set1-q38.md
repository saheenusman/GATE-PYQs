# 2023 CS Q38: Minimum final value of X with binary and counting semaphores

## Question

Consider the two functions `incr` and `decr` shown below.

```c
incr(){            decr(){
  wait(s);           wait(s);
  X = X+1;           X = X-1;
  signal(s);         signal(s);
}                  }
```

There are 5 threads each invoking `incr` once, and 3 threads each invoking `decr` once, on the same shared variable $X$. The initial value of $X$ is 10.

Suppose there are two implementations of the semaphore `s`, as follows:

I-1: `s` is a binary semaphore initialized to 1.

I-2: `s` is a counting semaphore initialized to 2.

Let $V_1$, $V_2$ be the values of $X$ at the end of execution of all the threads with implementations I-1, I-2, respectively. Which one of the following choices corresponds to the minimum possible values of $V_1$, $V_2$, respectively?

- (A) 15, 7
- (B) 7, 7
- (C) 12, 7
- (D) 12, 8

<details class="success" markdown="1">
<summary>Answer</summary>

**C (12, 7)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I-1 (binary, init 1).** Only one thread at a time is inside the critical section, so updates never overlap. The result is fixed:

$$V_1 = 10 + 5 - 3 = 12$$

**I-2 (counting, init 2).** Two threads can be inside at once, so a **lost update** is possible (read-modify-write interleaves).

*How to reach 7.* Let one `decr` read $X = 10$ and pause. The other slot then runs all 5 `incr` threads, one after another, raising $X$ to 15. The paused `decr` now writes $10 - 1 = 9$, wiping out all five increments. Then the two remaining `decr` threads run: $9 \to 8 \to 7$.

*Why not lower.* Every decrement can be applied at most once and increments can only add, so the lowest value is $10 - 3 = 7$.

**Code check:** exhaustively exploring every interleaving gave $V_1 \in \lbrace 12 \rbrace$ and $V_2 \in \lbrace 7, 8, \ldots, 15 \rbrace$. So the minimum pair is $(12, 7)$.

**Why the others fail:** A has $V_1 = 15$ (impossible for a mutex). B has $V_1 = 7$ (a mutex cannot lose updates). D has $V_2 = 8$, which is not the minimum.

**Key idea:** a binary semaphore gives mutual exclusion. A counting semaphore with count 2 does not, so lost updates can occur.

</details>
