# 2013 CS Q39: Semaphores for two cooperating processes

## Question

A certain computation generates two arrays `a` and `b` such that `a[i] = f(i)` for $0 \le i < n$ and `b[i] = g(a[i])` for $0 \le i < n$. Suppose this computation is decomposed into two concurrent processes $X$ and $Y$ such that $X$ computes the array `a` and $Y$ computes the array `b`. The processes employ two binary semaphores $R$ and $S$, both initialized to zero. The array `a` is shared by the two processes. The structures of the processes are shown below.

```c
Process X:                      Process Y:
private i;                      private i;
for (i=0; i<n; i++) {           for (i=0; i<n; i++) {
    a[i] = f(i);                    EntryY(R, S);
    ExitX(R, S);                    b[i] = g(a[i]);
}                               }
```

Which one of the following represents the **CORRECT** implementations of `ExitX` and `EntryY`?

- (A) `ExitX: P(R); V(S)` and `EntryY: P(S); V(R)`
- (B) `ExitX: V(R); V(S)` and `EntryY: P(R); P(S)`
- (C) `ExitX: P(S); V(R)` and `EntryY: V(S); P(R)`
- (D) `ExitX: V(R); P(S)` and `EntryY: V(S); P(R)`

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Requirement.** $Y$ may use `a[i]` only after $X$ has computed it, and signals must not be lost (the semaphores are binary).

**(C) works.**

- $Y$: `V(S)` then `P(R)`. $Y$ first announces it is ready for item $i$, then waits for $R$.
- $X$: after computing `a[i]`, `P(S)` (waits for $Y$'s readiness), then `V(R)` to release $Y$.

So $Y$ passes `P(R)` only after $X$ has computed `a[i]`. $X$'s next `V(R)` needs a new `P(S)`, which needs $Y$'s next `V(S)`, which comes after $Y$ consumed the previous $R$. Hence $R$ and $S$ never go above 1 and no signal is lost.

**Why the others fail:**

- (A) $X$ runs `P(R)` and $Y$ runs `P(S)` first, with both semaphores 0: immediate deadlock.
- (B) $X$ can run ahead: a second `V(R)` while $R=1$ is lost. $Y$ then waits forever for an $R$ that never comes.
- (D) Same loss: $X$ runs `V(R)` twice before $Y$ consumes it, so with $n=2$ $X$ finishes and $Y$ blocks on `P(R)`.

**Code check:** a state-space search over $n=3$ found no deadlock and no early read of `a` for (C), and a deadlock for (A), (B) and (D).

**Key idea:** use a handshake pair so that each binary semaphore is signalled at most once before it is consumed.

</details>
