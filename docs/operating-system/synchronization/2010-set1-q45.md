# 2010 CS Q45: How many times P0 prints with three binary semaphores

## Question

The following program consists of $3$ concurrent processes and $3$ binary semaphores. The semaphores are initialized as $S_0 = 1$, $S_1 = 0$, $S_2 = 0$.

```
Process P0            Process P1      Process P2
while (true) {        wait(S1);       wait(S2);
    wait(S0);         release(S0);    release(S0);
    print '0';
    release(S1);
    release(S2);
}
```

How many times will process P0 print '0'?

- (A) At least twice
- (B) Exactly twice
- (C) Exactly thrice
- (D) Exactly once

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only P0 loops. P1 and P2 each run **once**: each waits for its semaphore, then releases $S_0$.

- P0 prints once first, because $S_0 = 1$. It then releases $S_1$ and $S_2$, which lets P1 and P2 each run.
- Each of P1 and P2 releases $S_0$ once, so there are at most **two** more chances for P0 to pass `wait(S0)`.
- $S_0$ is **binary**. If both P1 and P2 release before P0 waits again, the second release is lost (the value stays $1$), and P0 passes only once more: total $2$ prints.
- If P0 takes $S_0$ between the two releases, both releases count and P0 passes twice more: total $3$ prints.

So the number of prints is $2$ or $3$, depending on scheduling: **at least twice**, (A).

- (B) exactly twice and (C) exactly thrice are each possible, but neither is guaranteed.
- (D) does not happen: once P1 and P2 are scheduled, P0 prints at least twice.

**Code check:** a Python search over every interleaving of the three processes (binary semaphores, P1 and P2 run once, P0 loops) reached only the stuck states with total prints $2$ or $3$.

**Key idea:** a binary semaphore does not count; two releases in a row collapse to one. Hence the outcome depends on scheduling.

</details>
