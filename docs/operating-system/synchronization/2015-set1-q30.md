# 2015 CS1 Q30: Distinct values of a shared variable after two concurrent functions

## Question

The following two functions `P1` and `P2` that share a variable `B` with an initial value of 2 execute concurrently.

```c
P1() {            P2() {
    C = B - 1;        D = 2 * B;
    B = 2 * C;        B = D - 1;
}                 }
```

The number of distinct values that `B` can possibly take after the execution is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each function has two statements, so there are $\binom{4}{2} = 6$ interleavings. Label them 1a, 1b (P1) and 2a, 2b (P2). Start with $B = 2$.

| Order | Working | Final $B$ |
|---|---|---|
| 1a 1b 2a 2b | $C=1,\ B=2;\ D=4,\ B=3$ | 3 |
| 1a 2a 1b 2b | $C=1;\ D=4;\ B=2;\ B=3$ | 3 |
| 1a 2a 2b 1b | $C=1;\ D=4;\ B=3;\ B=2$ | 2 |
| 2a 1a 1b 2b | $D=4;\ C=1;\ B=2;\ B=3$ | 3 |
| 2a 1a 2b 1b | $D=4;\ C=1;\ B=3;\ B=2$ | 2 |
| 2a 2b 1a 1b | $D=4,\ B=3;\ C=2;\ B=4$ | 4 |

Distinct values: $\lbrace 2, 3, 4 \rbrace$, so **3**.

**Code check:** a short Python script that enumerated all 6 interleavings gave the same set $\lbrace 2, 3, 4 \rbrace$.

**Key idea:** list every interleaving of the unsynchronised statements; the result depends on the order (a race condition).

</details>
