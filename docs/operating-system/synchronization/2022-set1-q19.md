# 2022 CS Q19: Semaphore initialisation to print BCABCA...

## Question

Consider the following threads, T1, T2, and T3 executing on a single processor, synchronized using three binary semaphore variables, S1, S2, and S3, operated upon using standard `wait()` and `signal()`. The threads can be context switched in any order and at any time.

| T1 | T2 | T3 |
| --- | --- | --- |
| `while(true){` | `while(true){` | `while(true){` |
| `wait(S3);` | `wait(S1);` | `wait(S2);` |
| `print("C");` | `print("B");` | `print("A");` |
| `signal(S2); }` | `signal(S3); }` | `signal(S1); }` |

Which initialization of the semaphores would print the sequence BCABCABCA....?

- (A) S1 = 1; S2 = 1; S3 = 1
- (B) S1 = 1; S2 = 1; S3 = 0
- (C) S1 = 1; S2 = 0; S3 = 0
- (D) S1 = 0; S2 = 1; S3 = 1

<details class="success" markdown="1">
<summary>Answer</summary>

**C ($S_1 = 1, S_2 = 0, S_3 = 0$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Follow the signals around the ring.** T2 prints B and signals S3. T1 waits on S3, prints C and signals S2. T3 waits on S2, prints A and signals S1. T2 waits on S1. So the order of threads is forced to be $T2 \to T1 \to T3 \to T2 \ldots$, which prints B, C, A, B, C, A, ...

**Initial values.** For the output to start with B, only T2 may be able to run first, so $S_1 = 1$. T1 and T3 must be blocked, so $S_3 = 0$ and $S_2 = 0$. That is option C.

**Why the others fail:**
- (A) all three threads can start, so the output can begin with A or C.
- (B) $S_2 = 1$ lets T3 print A first.
- (D) $S_1 = 0$ blocks T2, so B cannot come first. With $S_2 = 1$ and $S_3 = 1$ the output can start with A or C.

**Code check:** an exhaustive search over all interleavings of the three threads. Only $(1, 0, 0)$ always produced `BCABCABCA` as the first 9 characters. The others reach other prefixes (for example `ABCABCABC` for option D).

**Key idea:** semaphores chain the threads in a cycle; only the thread whose semaphore starts at 1 may run first.

</details>
