# 2019 CS2 Q33: Max minus min final value of a shared variable

## Question

Consider three concurrent processes P1, P2 and P3 as shown below, which access a shared variable D that has been initialized to 100.

| P1 | P2 | P3 |
|---|---|---|
| ⋮ | ⋮ | ⋮ |
| D = D + 20 | D = D − 50 | D = D + 10 |
| ⋮ | ⋮ | ⋮ |

The processes are executed on a uniprocessor system running a time-shared operating system. If the minimum and maximum possible values of D after the three processes have completed execution are X and Y respectively, then the value of Y − X is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**80**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Model.** There is no mutual exclusion. Each statement is really three steps: **load** D, **add or subtract**, **store**. The scheduler can switch between steps. The final D is whatever the **last store** wrote.

**Maximum, $Y = 130$.** Make P2's update get lost:

1. P2 loads 100.
2. P3 runs fully: $D = 110$.
3. P1 loads 110.
4. P2 stores $100 - 50 = 50$.
5. P1 stores $110 + 20 = 130$.

**Minimum, $X = 50$.** Nothing is ever below 100 until P2 stores, so P2 always computes $100 - 50 = 50$ when it loads first. If another process stores last, it writes at least $50 + 10 = 60$ (P3) or $50 + 20 = 70$ (P1). The lowest possible final value is **50**, with P2's store last.

$$Y - X = 130 - 50 = 80.$$

**Code check:** enumerating all 1680 interleavings of the three 3-step processes gives the reachable final values $\lbrace 50, 60, 70, 80, 110, 120, 130 \rbrace$. Largest minus smallest is 80.

**Key idea:** a lost update makes the last store win. Max and min come from choosing which updates get overwritten.

</details>
