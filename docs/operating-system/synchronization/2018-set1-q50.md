# 2018 CS Q50: Semaphore placeholders in producer-consumer

## Question

Consider the following solution to the producer-consumer synchronization problem. The shared buffer size is $N$. Three semaphores *empty*, *full* and `mutex` are defined with respective initial values of $0$, $N$ and $1$. Semaphore *empty* denotes the number of available slots in the buffer, for the consumer to read from. Semaphore *full* denotes the number of available slots in the buffer, for the producer to write to. The placeholder variables, denoted by `P, Q, R,` and `S`, in the code below can be assigned either *empty* or *full*. The valid semaphore operations are: `wait()` and `signal()`.

```c
Producer:              Consumer:
do{                    do{
    wait(P);               wait(R);
    wait(mutex);           wait(mutex);
    //Add item to buffer   //Consume item from buffer
    signal(mutex);         signal(mutex);
    signal(Q);             signal(S);
}while(1);             }while(1);
```

Which one of the following assignments to P, Q, R and S will yield the correct solution?

- (A) P: *full*, Q: *full*, R: *empty*, S: *empty*
- (B) P: *empty*, Q: *empty*, R: *full*, S: *full*
- (C) P: *full*, Q: *empty*, R: *empty*, S: *full*
- (D) P: *empty*, Q: *full*, R: *full*, S: *empty*

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read the names as the question defines them** (they are swapped from the usual convention):
- *full* $= N$ initially $=$ free slots the producer can write to.
- *empty* $= 0$ initially $=$ items the consumer can read.

**Producer.** It must wait for a free slot, so `wait(full)`: **P = full**. After adding an item it must tell the consumer there is something to read: `signal(empty)`: **Q = empty**.

**Consumer.** It must wait for an item, so `wait(empty)`: **R = empty**. After consuming it frees a slot: `signal(full)`: **S = full**.

This is option **C**.

**Why the others fail:**
- **A:** the producer signals *full*, so slots increase when it writes: buffer overflow.
- **B** and **D:** the producer waits on *empty* $=0$ while the consumer waits on *full* $=N$; the consumer can read from an empty buffer.

**Code check:** an exhaustive search of semaphore and buffer states for $N=2$: A overflows, B and D underflow, C has no violation or deadlock.

**Key idea:** a process waits on the resource it consumes and signals the resource it produces.

</details>
