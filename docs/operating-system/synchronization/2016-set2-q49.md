# 2016 CS2 Q49: Largest initial semaphore value for which some P operation stays blocked

## Question

Consider a non-negative counting semaphore $S$. The operation $P(S)$ decrements $S$, and $V(S)$ increments $S$. During an execution, 20 $P(S)$ operations and 12 $V(S)$ operations are issued in some order. The largest initial value of $S$ for which at least one $P(S)$ operation will remain blocked is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the initial value be $S$. If no $P$ stays blocked, the final value is

$$S + 12 - 20 = S - 8 \ge 0.$$

So at least one $P$ remains blocked exactly when it is impossible to complete all $20$ $P$'s, which happens if $S - 8 < 0$, i.e. $S < 8$. (The order is ours to choose: put all $P$'s before the $V$'s so the semaphore runs out.)

The largest such integer is $S = 7$.

**Check with $S = 7$.** Issue all $20$ $P$'s first: $7$ succeed, $13$ block. The $12$ $V$'s wake $12$ of them. One $P$ is still blocked. ✓

With $S = 8$ every $P$ can finish (the net is $0$), so $8$ fails.

**Key idea:** need $S + 12 < 20$, so the largest integer $S$ is 7.

</details>
