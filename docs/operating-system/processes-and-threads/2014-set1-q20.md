# 2014 CS1 Q20: Which statement about threads is FALSE

## Question

Which one of the following is **FALSE**?

- (A) User level threads are not scheduled by the kernel.
- (B) When a user level thread is blocked, all other threads of its process are blocked.
- (C) Context switching between user level threads is faster than context switching between kernel level threads.
- (D) Kernel level threads cannot share the code segment.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Threads of one process, kernel-level or user-level, **share the code segment** (and the data, heap and open files). Only the stack and registers are per thread. So (D) is false.

- (A) true: the kernel sees only the process, and a run-time library schedules the user threads.
- (B) true: a blocking system call blocks the whole process because the kernel does not know about the other threads.
- (C) true: a user-level switch needs no kernel entry or mode switch.

**Key idea:** threads share code, data and files; each has its own stack and registers.

</details>
