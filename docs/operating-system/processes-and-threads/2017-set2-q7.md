# 2017 CS2 Q7: What all threads of a process share

## Question

Which of the following is/are shared by all the threads in a process?

- I. Program counter
- II. Stack
- III. Address space
- IV. Registers

Options:

- (A) I and II only
- (B) III only
- (C) IV only
- (D) III and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Per-thread state.** Each thread must have its own execution context, so it has its own:

- **Program counter** (I): different threads are at different instructions.
- **Stack** (II): holds that thread's local variables and return addresses.
- **Registers** (IV): hold that thread's current values.

**Shared state.** All threads of a process live in the **address space** (III), which holds the code, global data, heap and open files.

So only III is shared: **(B)**.

**Why the others fail.** (A), (C), (D) each include PC, stack or registers, which are private to each thread.

**Status note:** operating-system theory (no program applies); the answer matches the official key.

**Key idea:** threads share the address space (code, globals, heap) but each has its own PC, registers and stack.

</details>
