# 2015 CS3 Q14: Maximum number of processes in the Ready state with n CPUs

## Question

The maximum number of processes that can be in *Ready* state for a computer system with $n$ CPUs is

- (A) $n$
- (B) $n^2$
- (C) $2^n$
- (D) Independent of $n$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only the **Running** state is limited by the number of CPUs: at most $n$ processes run at once.

The **Ready** queue holds every process that is runnable but waiting for a CPU. Its size is limited by memory and the OS's process table, not by $n$. So it is independent of $n$. Option (D).

(A), (B) and (C) wrongly tie the Ready count to the CPU count.

**Key idea:** the CPU count bounds *Running*, not *Ready*.

</details>
