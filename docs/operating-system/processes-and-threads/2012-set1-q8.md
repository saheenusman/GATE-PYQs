# 2012 CS Q8: Number of child processes after three fork calls

## Question

A process executes the code

```c
fork();
fork();
fork();
```

The total number of **child** processes created is

- (A) 3
- (B) 4
- (C) 7
- (D) 8

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each `fork()` doubles the number of processes, because the parent and every earlier child all continue to the next line.

| After | Processes |
|---|---|
| start | 1 |
| 1st fork | 2 |
| 2nd fork | 4 |
| 3rd fork | 8 |

Total $2^3 = 8$ processes. One is the original, so $8 - 1 = 7$ are children: (C).

- (A) counts only the three calls.
- (B) is $2^2$.
- (D) counts the original process too.

**Code check:** compiled with `gcc -Wall` and run; each of the processes wrote one byte to a shared file. The file held 8 bytes: 8 processes, 7 children.

**Key idea:** $n$ unconditional `fork()` calls give $2^n$ processes, so $2^n - 1$ children.

</details>
