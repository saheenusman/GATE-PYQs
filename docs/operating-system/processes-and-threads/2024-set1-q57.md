# 2024 CS1 Q57: Number of printf calls with fork in a loop

## Question

Consider the following code snippet using the `fork()` and `wait()` system calls. Assume that the code compiles and runs correctly, and that the system calls run successfully without any errors.

```c
int x = 3;
while(x > 0) {
  fork();
  printf("hello");
  wait(NULL);
  x--;
}
```

The total number of times the printf statement is executed is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**14**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $f(x)$ be the total number of `printf` calls made by one process that enters the loop with the counter at $x$ (and all processes it creates).

- `fork()` makes **two** processes, parent and child, both with the same $x$.
- Each prints once (2 prints), then each decrements $x$ and continues. Each of them then behaves like a process entering the loop with $x - 1$.

$$f(x) = 2 + 2f(x-1),\quad f(0) = 0.$$

| $x$ | $f(x)$ |
|---|---|
| 1 | 2 |
| 2 | $2 + 4 = 6$ |
| 3 | $2 + 12 = 14$ |

Equivalent view: iteration 1 has 2 processes printing, iteration 2 has 4, iteration 3 has 8: $2 + 4 + 8 = 14$.

**Verified.** I ran it with `fflush(stdout)` after each `printf` and counted 14 lines.

**Note.** Without a flush or newline, `"hello"` sits in the stdio buffer and `fork()` copies the buffer, so the *text* on a pipe could contain extra "hello"s. The question counts executions of the `printf` statement, which is still 14.

**Key idea:** every `fork()` in a loop doubles the number of processes. Here each process runs the loop with the counter reduced by one.

</details>
