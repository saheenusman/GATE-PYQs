# 2008 CS Q66: Number of child processes created by fork in a loop

## Question

A process executes the following code:

```c
for (i = 0; i < n; i++) fork();
```

The total number of child processes created is

- (A) $n$
- (B) $2^n - 1$
- (C) $2^n$
- (D) $2^{n+1} - 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each `fork()` doubles the number of processes, because every existing process (parent and earlier children) executes the next `fork()` too. After $n$ iterations there are $2^n$ processes in total. One of them is the original, so the number of **child** processes created is $2^n - 1$: (B).

| $n$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| total processes | 2 | 4 | 8 | 16 |
| children created | 1 | 3 | 7 | 15 |

- (A) $n$ counts only the original process's own forks.
- (C) $2^n$ counts the original process too.
- (D) $2^{n+1} - 1$ is the number of nodes in a binary tree of depth $n$, one level too many.

**Code check:** I ran the loop with real `fork()` calls for $n = 1, 2, 3, 4$, with every created process writing one byte to a pipe: 1, 3, 7 and 15 processes were created, matching $2^n - 1$.

**Key idea:** every fork doubles the process count, so $n$ forks in a loop create $2^n - 1$ children.

</details>
