# 2019 CS2 Q27: Number of child processes created by forks in a loop

## Question

The following C program is executed on a Unix/Linux system:

```c
#include <unistd.h>
int main()
{
    int i;
    for (i=0; i<10; i++)
        if (i%2 == 0) fork();
    return 0;
}
```

The total number of child processes created is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**31**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`fork()` runs when $i$ is even: $i = 0, 2, 4, 6, 8$. That is **5 forks**. The return value is ignored, so **every** process (parent and child) carries on with the loop and takes part in the later forks. Each fork therefore doubles the number of processes.

| After $i =$ | Processes |
|---|---|
| start | 1 |
| 0 | 2 |
| 2 | 4 |
| 4 | 8 |
| 6 | 16 |
| 8 | 32 |

Total processes $= 2^5 = 32$. One is the original, so child processes $= 32 - 1 = $ **31**.

**Code check:** compiled with `gcc -Wall` (no warnings). An instrumented copy, where each process appends a line to a file at exit, logged 32 lines, so 31 children.

**Key idea:** $n$ forks executed by every process give $2^n$ processes in total and $2^n - 1$ children.

</details>
