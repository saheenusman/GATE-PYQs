# 2023 CS Q23: Which events guarantee a switch to kernel mode

## Question

Which one or more of the following options guarantee that a computer system will transition from user mode to kernel mode?

- (A) Function Call
- (B) `malloc` Call
- (C) Page Fault
- (D) System Call

<details class="success" markdown="1">
<summary>Answer</summary>

**C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**System call (D).** It executes a trap instruction, which always enters kernel mode.

**Page fault (C).** It is a hardware exception. The CPU always jumps to the kernel's fault handler.

**Why the others do not guarantee it:**
- **Function call:** an ordinary jump within user code. No mode change.
- **`malloc`:** a library routine that usually serves requests from memory it already owns. It enters the kernel (via `brk` or `mmap`) only when it needs more memory, so a switch is not guaranteed.

**Key idea:** only traps and exceptions (system calls, page faults, interrupts) force a switch to kernel mode.

</details>
