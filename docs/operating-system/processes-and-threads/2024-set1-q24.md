# 2024 CS1 Q24: Statements about threads

## Question

Which of the following statements about threads is/are TRUE?

- (A) Threads can only be implemented in kernel space
- (B) Each thread has its own file descriptor table for open files
- (C) All the threads belonging to a process share a common stack
- (D) Threads belonging to a process are by default not protected from each other

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) False.** Threads can be implemented in **user space** (user-level threads managed by a library) as well as in kernel space.
- **(B) False.** The file descriptor table belongs to the **process**. All its threads share it.
- **(C) False.** Each thread has its **own stack** (and its own registers and program counter). Threads share code, heap and globals.
- **(D) True.** Threads share one address space, so one thread can read or overwrite another's data. The OS does not isolate them from each other.

**Key idea:** threads share code, heap, globals and open files, but have private stacks and registers.

</details>
