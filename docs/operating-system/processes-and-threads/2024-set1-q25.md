# 2024 CS1 Q25: Impossible process state transitions

## Question

Which of the following process state transitions is/are NOT possible?

- (A) Running to Ready
- (B) Waiting to Running
- (C) Ready to Waiting
- (D) Running to Terminated

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the standard five-state model:

| Transition | Cause | Possible? |
|---|---|---|
| Running → Ready | time slice expires / pre-emption | Yes |
| Waiting → Ready | the awaited event occurs | Yes |
| **Waiting → Running** | would skip the scheduler | **No** |
| **Ready → Waiting** | only a running process can issue a blocking request | **No** |
| Running → Terminated | process exits | Yes |

- A waiting process first moves to **Ready**. Only the scheduler moves a ready process to Running.
- A ready process is not executing, so it cannot start waiting for I/O.

**Key idea:** blocking happens only from Running, and unblocking leads to Ready, never directly to Running.

</details>
