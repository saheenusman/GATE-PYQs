# 2023 CS Q22: Saved on a thread context switch (same process)

## Question

Which one or more of the following need to be saved on a context switch from one thread ($T_1$) of a process to another thread ($T_2$) of the same process?

- (A) Page table base register
- (B) Stack pointer
- (C) Program counter
- (D) General purpose registers

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Threads of one process share the address space.** So the page table (and its base register) stays the same: nothing to save or switch. **A is not needed.**

**Each thread has its own execution state**, which must be saved so $T_1$ can resume later:
- **Stack pointer** (each thread has its own stack): needed.
- **Program counter**: needed.
- **General purpose registers**: needed.

**Key idea:** a thread switch inside a process saves CPU state but not the memory map. A process switch also changes the page table base register.

</details>
