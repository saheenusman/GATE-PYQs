# 2017 CS1 Q18: What threads of the same process share

## Question

Threads of a process share

- (A) global variables but not heap.
- (B) heap but not global variables.
- (C) neither global variables nor heap.
- (D) both heap and global variables.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What is shared.** All threads of one process live in the same address space. They share the code, the global and static data, the **heap**, and open files.

**What is private to each thread.** Its stack (local variables, return addresses), its registers (including the program counter), and its thread ID.

So threads share **both** the heap and global variables: **(D)**.

**Why the others fail.** (A), (B) and (C) each deny sharing for one or both of the heap and the global data, but both sit in the common address space. A pointer to heap memory handed to another thread works for exactly this reason.

**Key idea:** threads share everything except stack and registers.

</details>
