# 2026 CS1 Q35: Minimum resources for a deadlock-free system

## Question

A system has $k$ instances of a resource $R$ shared by 5 processes. Each process needs a maximum of two instances. A process can request or release only one instance at a time, and it can request its second instance only after acquiring the first.

The minimum value of $k$ for the system to be deadlock-free is _____. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Worst case.** Deadlock is most likely when every process holds some resources but needs one more. Each process needs at most 2 instances, so the worst case is every process holding **1** instance and waiting for its second.

- That uses $5 \times 1 = 5$ instances.
- If $k = 5$, nothing is left, so all five wait forever: **deadlock** is possible.
- If $k = 6$, one instance is still free. Some process can take it, finish with 2 instances, and release both. The others can then proceed.

**Formula.** For $n$ processes each needing at most $m$ instances:

$$k_{\min} = n(m-1) + 1 = 5 \times 1 + 1 = 6.$$

**Check.**

| $k$ | Deadlock possible? |
|---|---|
| 5 | yes (all five hold one and wait) |
| 6 | no |
| 7 | no |

**Key idea:** give each process one less than its maximum, then add one more. That extra instance guarantees someone can finish.

</details>
