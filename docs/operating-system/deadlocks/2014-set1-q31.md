# 2014 CS1 Q31: Banker's algorithm: which request can be permitted

## Question

An operating system uses the *Banker's algorithm* for deadlock avoidance when managing the allocation of three resource types X, Y, and Z to three processes P0, P1, and P2. The table given below presents the current system state. Here, the *Allocation* matrix shows the current number of resources of each type allocated to each process and the *Max* matrix shows the maximum number of resources of each type required by each process during its execution.

| | Alloc X | Alloc Y | Alloc Z | Max X | Max Y | Max Z |
|---|---|---|---|---|---|---|
| P0 | 0 | 0 | 1 | 8 | 4 | 3 |
| P1 | 3 | 2 | 0 | 6 | 2 | 0 |
| P2 | 2 | 1 | 1 | 3 | 3 | 3 |

There are 3 units of type X, 2 units of type Y and 2 units of type Z still available. The system is currently in a **safe** state. Consider the following independent requests for additional resources in the current state:

REQ1: P0 requests 0 units of X, 0 units of Y and 2 units of Z

REQ2: P1 requests 2 units of X, 0 units of Y and 0 units of Z

Which one of the following is **TRUE**?

- (A) Only REQ1 can be permitted.
- (B) Only REQ2 can be permitted.
- (C) Both REQ1 and REQ2 can be permitted.
- (D) Neither REQ1 nor REQ2 can be permitted.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Need $=$ Max $-$ Allocation: P0 $(8,4,2)$, P1 $(3,0,0)$, P2 $(1,2,2)$. Available $(3,2,2)$.

**REQ1** (P0 takes $(0,0,2)$). Available becomes $(3,2,0)$, P0 holds $(0,0,3)$ with need $(8,4,0)$.

| Step | Run | Available after |
|---|---|---|
| 1 | P1 (needs $(3,0,0)$) | $(6,4,0)$ |
| 2 | P2 needs $Z=2$, only 0 free | stuck |
| 3 | P0 needs $X=8$, only 6 free | stuck |

Unsafe, so REQ1 is **denied**.

**REQ2** (P1 takes $(2,0,0)$). Available becomes $(1,2,2)$, P1 holds $(5,2,0)$ with need $(1,0,0)$.

| Step | Run | Available after |
|---|---|---|
| 1 | P1 (needs $(1,0,0)$) | $(6,4,2)$ |
| 2 | P2 (needs $(1,2,2)$) | $(8,5,3)$ |
| 3 | P0 (needs $(8,4,2)$) | $(8,5,4)$ |

Safe sequence P1, P2, P0, so REQ2 is **granted**.

**Code check:** a safety-algorithm program returns unsafe for REQ1 and safe for REQ2.

Only REQ2: **B**.

**Key idea:** grant a request only if a safe sequence still exists afterwards.

</details>
