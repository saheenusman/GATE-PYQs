# 2007 CS Q57: Which process finishes last (safe sequence)

## Question

A single processor system has three resource types X, Y, and Z, which are shared by three processes. There are 5 units of each resource type. Consider the following scenario, where the column *alloc* denotes the number of units of each resource type allocated to each process, and the column *request* denotes the number of units of each resource type requested by a process in order to complete execution. Which of these processes will finish LAST?

| | alloc X Y Z | request X Y Z |
|---|---|---|
| P0 | 1 2 1 | 1 0 3 |
| P1 | 2 0 1 | 0 1 2 |
| P2 | 2 2 1 | 1 2 0 |

- (A) P0
- (B) P1
- (C) P2
- (D) None of the above, since the system is in a deadlock.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Available $=$ total $-$ allocated $= (5,5,5) - (5,4,3) = (0,1,2)$.

| Step | Available | Who can run? |
|---|---|---|
| start | $(0,1,2)$ | P0 needs $(1,0,3)$: no. P1 needs $(0,1,2)$: **yes**. P2 needs $(1,2,0)$: no. |
| after P1 releases $(2,0,1)$ | $(2,1,3)$ | P0 needs $(1,0,3)$: **yes**. P2 needs $(1,2,0)$: no (Y: 2 > 1). |
| after P0 releases $(1,2,1)$ | $(3,3,4)$ | P2 needs $(1,2,0)$: **yes**. |

The only safe order is P1, P0, P2, so P2 finishes last: (C). The system is not deadlocked: (D) is wrong.

- (A) P0 must run before P2 (P2 needs the Y units that P0 releases).
- (B) P1 is the only process that can start.

**Code check:** Python: tried all 6 orders with the banker's rule; the only feasible sequence is P1, P0, P2.

**Key idea:** find a safe sequence by repeatedly running any process whose request fits in the available vector, then reclaiming its allocation.
