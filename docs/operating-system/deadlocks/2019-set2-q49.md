# 2019 CS2 Q49: Condition that keeps all other processes from finishing

## Question

Consider the following snapshot of a system running $n$ concurrent processes. Process $i$ is holding $X_i$ instances of a resource R, $1 \le i \le n$. Assume that all instances of R are currently in use. Further, for all $i$, process $i$ can place a request for at most $Y_i$ additional instances of R while holding the $X_i$ instances it already has. Of the $n$ processes, there are exactly two processes $p$ and $q$ such that $Y_p = Y_q = 0$. Which one of the following conditions guarantees that no other process apart from $p$ and $q$ can complete execution?

- (A) $X_p + X_q < \mathrm{Min}\,\lbrace Y_k \mid 1 \le k \le n,\ k \ne p,\ k \ne q \rbrace$
- (B) $X_p + X_q < \mathrm{Max}\,\lbrace Y_k \mid 1 \le k \le n,\ k \ne p,\ k \ne q \rbrace$
- (C) $\mathrm{Min}\,(X_p, X_q) \ge \mathrm{Min}\,\lbrace Y_k \mid 1 \le k \le n,\ k \ne p,\ k \ne q \rbrace$
- (D) $\mathrm{Min}\,(X_p, X_q) \le \mathrm{Max}\,\lbrace Y_k \mid 1 \le k \le n,\ k \ne p,\ k \ne q \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

All instances are in use, so **0 are free** now.

- $p$ and $q$ need nothing more ($Y = 0$), so they can finish. When both finish they release $X_p + X_q$ instances.
- Another process $k$ can finish only if its extra demand $Y_k$ is at most the free count.
- The free count can reach at most $X_p + X_q$ unless some other process finishes first. And no other process can start finishing at 0 free instances if every $Y_k \ge 1$.

To guarantee **no** other process finishes, **every** other process must need more than $X_p + X_q$:

$$X_p + X_q < Y_k \text{ for all } k \ne p, q \;\Longleftrightarrow\; X_p + X_q < \mathrm{Min}\,\lbrace Y_k \rbrace.$$

**Why the others fail:**

- (B) compares with the **max**. Some $Y_k$ below $X_p + X_q$ can still exist, so that process could finish.
- (C) and (D) use $\mathrm{Min}(X_p, X_q)$, which ignores that both $p$ and $q$ release their instances.

**Code check:** a random simulation (20,000 trials) found no case where (A) held and another process could still finish. For (B), (C) and (D) there were many such cases.

**Key idea:** the guarantee must hold for the weakest other process, the one with the smallest $Y_k$.

</details>
