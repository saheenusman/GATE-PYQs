# 2018 CS Q34: Largest K that always avoids deadlock

## Question

Consider a system with 3 processes that share 4 instances of the same resource type. Each process can request a maximum of $K$ instances. Resource instances can be requested and released only one at a time. The largest value of $K$ that will always avoid deadlock is ____.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Worst case for deadlock:** every process holds $K-1$ instances and is waiting for one more. This is a deadlock only if no instance is free, that is, if

$$3(K-1)\ \ge\ 4$$

**Deadlock cannot happen** if $3(K-1) + 1 \le 4$, because then at least one instance is free or one process already has all it needs, and it can finish and release.

$$3(K-1)\le 3 \;\Rightarrow\; K \le 2$$

**Check $K=3$:** holdings $(2,1,1)$ use all 4 instances, and every process wants one more, which is a deadlock. For $K = 2$ the worst case is each holding 1 with 1 free, and someone can always finish.

The largest safe value is **2**.

**Key idea:** with $n$ processes and $R$ instances, deadlock is impossible if $n(K-1) + 1 \le R$.

</details>
