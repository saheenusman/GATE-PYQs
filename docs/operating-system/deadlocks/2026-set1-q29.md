# 2026 CS1 Q29: FALSE statements about deadlocks

## Question

With respect to deadlocks in an operating system, which of the following statements is/are **FALSE**?

- (A) Banker's algorithm is used to prevent deadlocks
- (B) Deadlock formation can be prevented by ensuring that the hold and wait condition is not allowed
- (C) An assignment edge in a resource allocation graph is marked from a process to a resource
- (D) A safe state guarantees that all processes can finish without formation of a deadlock

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** Three different ideas, often mixed up:

| Idea | What it does |
|---|---|
| Prevention | break one of the four necessary conditions in the design |
| Avoidance | grant a request only if the state stays *safe* (Banker's algorithm) |
| Detection and recovery | allow deadlock, then find and fix it |

**(A) False.** Banker's algorithm is deadlock **avoidance** (it needs advance knowledge of maximum demands). Prevention means removing a necessary condition by design.

**(B) True.** If a process may never hold one resource while waiting for another (hold and wait is removed), a deadlock cannot form. This is a standard prevention method.

**(C) False.** In a resource allocation graph:

- a **request edge** goes from process to resource ($P \to R$),
- an **assignment edge** goes from resource to process ($R \to P$).

The statement reverses the direction.

**(D) True.** In a safe state there is an order in which every process can get its maximum and finish, so no deadlock forms (as long as that order is followed).

So the false ones are **A and C**.

**Key idea:** prevention changes the rules, avoidance checks each request (Banker's), and in a resource allocation graph assignment edges point from resource to process.

</details>
