# 2010 CS Q46: When can the resource requests of k processes deadlock

## Question

A system has $n$ resources $R_0, \dots, R_{n-1}$, and $k$ processes $P_0, \dots, P_{k-1}$. The implementation of the resource request logic of each process $P_i$ is as follows:

```
if (i % 2 == 0) {
    if (i < n)     request R_i;
    if (i + 2 < n) request R_(i+2);
}
else {
    if (i < n)     request R_(n-i);
    if (i + 2 < n) request R_(n-i-2);
}
```

In which one of the following situations is a deadlock possible?

- (A) $n = 40$, $k = 26$
- (B) $n = 21$, $k = 12$
- (C) $n = 20$, $k = 10$
- (D) $n = 41$, $k = 19$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each process requests a first resource, keeps it, then requests a second one. A deadlock needs a circular wait: processes where each wants the resource held by the next.

**What each process holds and wants.**

- Even $i$: holds $R_i$, wants $R_{i+2}$.
- Odd $i$: holds $R_{n-i}$, wants $R_{n-i-2}$.

**Case (B), $n = 21$, $k = 12$.**

- $P_8$ (even): holds $R_8$, wants $R_{10}$.
- $P_{11}$ (odd): holds $R_{21-11} = R_{10}$, wants $R_{21-11-2} = R_8$.

$P_8$ waits for $P_{11}$ and $P_{11}$ waits for $P_8$: a deadlock. So (B).

**Why the others cannot deadlock.**

- (A) $n = 40$, (C) $n = 20$: $n$ is even, so even processes use only even resources and odd processes use only odd ones. Within each group every process wants a resource with a larger index than it holds (even: $R_i$ then $R_{i+2}$) or one held by a process with a larger index (odd: $P_i$ wants $R_{n-i-2}$, which $P_{i+2}$ holds). That ordering has no cycle.
- (D) $n = 41$, $k = 19$: even processes use resources $R_0$ to $R_{20}$, odd processes ($i \le 17$) use $R_{41-i}$ with $24 \le 41-i$. The two groups never share a resource, so no cycle can form.

**Code check:** for each option, a Python script built the "waits for" graph between processes and searched for a cycle whose processes hold distinct resources. Only (B) had one (processes $8$ and $11$).

**Key idea:** deadlock needs a cycle in the wait-for graph; here it appears only when an even process and an odd process request the same two resources in opposite order.

</details>
