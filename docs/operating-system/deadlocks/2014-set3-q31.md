# 2014 CS3 Q31: Minimum tape units to avoid deadlock

## Question

A system contains three programs and each requires three tape units for its operation. The minimum number of tape units which the system must have such that deadlocks never arise is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The worst case for deadlock: every program holds one unit **fewer** than it needs and waits for one more. Each holds $3 - 1 = 2$ units, so $3 \times 2 = 6$ units are held and all three wait.

With 6 tape units this can happen and nobody can proceed. With **7** units there is always one free unit, which some program takes to finish, release its units, and let the others proceed. So deadlock is impossible.

$$n_{\min} = p(r - 1) + 1 = 3 \times 2 + 1 = 7.$$

**Key idea:** for $p$ processes each needing at most $r$ units of one resource type, $p(r-1)+1$ units guarantee freedom from deadlock.

</details>
