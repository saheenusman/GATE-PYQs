# 2016 CS1 Q48: Total head movement under C-LOOK disk scheduling

## Question

Consider a disk queue with requests for I/O to blocks on cylinders 47, 38, 121, 191, 87, 11, 92, 10. The C-LOOK scheduling algorithm is used. The head is initially at cylinder number 63, moving towards larger cylinder numbers on its servicing pass. The cylinders are numbered from 0 to 199. The total head movement (in number of cylinders) incurred while servicing these requests is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**346**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

C-LOOK goes up to the **last request** in the direction of travel (not the disk end), jumps to the **lowest pending request**, then continues upward.

**Order of service.** Requests above $63$ in increasing order: $87, 92, 121, 191$. Then jump to the lowest request, $10$, and continue: $10, 11, 38, 47$.

| Move | Distance |
|---|---|
| $63 \to 191$ (serving 87, 92, 121, 191) | $128$ |
| $191 \to 10$ (the jump) | $181$ |
| $10 \to 47$ (serving 10, 11, 38, 47) | $37$ |

$$128 + 181 + 37 = 346$$

**Code check:** the same calculation in code gave $346$.

**Note.** The official key $346$ counts the return jump ($191 \to 10$) as head movement.

**Key idea:** go up to the last request, jump to the lowest request, and continue up; count all three legs.

</details>
