# 2014 CS2 Q20: FAT file system: maximum file size on a 100 million byte disk

## Question

A FAT (file allocation table) based file system is being used and the total overhead of each entry in the FAT is 4 bytes in size. Given a $100 \times 10^6$ bytes disk on which the file system is stored and data block size is $10^3$ bytes, the maximum size of a file that can be stored on this disk in units of $10^6$ bytes is ____________.

<details class="success" markdown="1">
<summary>Answer</summary>

**99.6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Number of blocks: $\dfrac{100 \times 10^6}{10^3} = 10^5$.
- The FAT has one 4-byte entry per block: $4 \times 10^5$ bytes, which occupies $4 \times 10^5 / 10^3 = 400$ blocks.
- Blocks left for file data: $10^5 - 400 = 99{,}600$.

$$99{,}600 \times 10^3 \text{ B} = 99.6 \times 10^6 \text{ B}$$

**Code check:** `(100e6 - 4*1e5)/1e6` gives `99.6`.

**Key idea:** the FAT itself takes space on the same disk, so subtract it before counting data blocks.

</details>
