# 2014 CS1 Q44: LRU miss ratio when reuse distance is bounded by k

## Question

An access sequence of cache block addresses is of length $N$ and contains $n$ unique block addresses. The number of unique block addresses between two consecutive accesses to the same block address is bounded above by $k$. What is the miss ratio if the access sequence is passed through a cache of associativity $A \ge k$ exercising least-recently-used replacement policy?

- (A) $n/N$
- (B) $1/N$
- (C) $1/A$
- (D) $k/n$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Between two accesses to the same block, at most $k$ other distinct blocks are touched. With LRU and $A \ge k$ ways, that block is still among the $A$ most recently used, so it has **not** been evicted. Every repeated access is therefore a hit.

The only misses are the **first** access to each unique block: $n$ misses in $N$ accesses.

$$\text{miss ratio} = \frac{n}{N}$$

- (B) would need a single unique block ($n = 1$).
- (C) and (D) involve $A$ or $k$, which do not change the miss count once $A \ge k$.

**Key idea:** if the reuse distance is at most the associativity, LRU gives only compulsory misses.

</details>
