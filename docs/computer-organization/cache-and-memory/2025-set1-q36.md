# 2025 CS1 Q36: Tag storage for a direct-mapped cache

## Question

Consider a memory system with 1M bytes of main memory and 16K bytes of cache memory. Assume that the processor generates 20-bit memory address, and the cache block size is 16 bytes. If the cache uses direct mapping, how many bits will be required to store all the tag values? [Assume memory is byte addressable, $1\text{K} = 2^{10}$, $1\text{M} = 2^{20}$.]

- (A) $6 \times 2^{10}$
- (B) $8 \times 2^{10}$
- (C) $2^{12}$
- (D) $2^{14}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Split the 20-bit address for a direct-mapped cache:

| Field | Size | Why |
|---|---|---|
| Block offset | 4 bits | block size $16 = 2^4$ bytes |
| Index | 10 bits | number of lines $= 16\text{K}/16 = 1024 = 2^{10}$ |
| Tag | $20 - 10 - 4 = 6$ bits | the rest |

Every cache line stores one tag, so the total tag storage is

$$1024 \times 6 = 6 \times 2^{10} \text{ bits}.$$

| Option | Mistake |
|---|---|
| B, $8 \times 2^{10}$ | Uses an 8-bit tag |
| C, $2^{12}$ and D, $2^{14}$ | $2^{14}$ is the cache size in **bytes**, and $2^{12}$ is not any field of this design |

**Key idea:** total tag bits $=$ (number of lines) $\times$ (tag bits per line).

</details>
