# 2014 CS2 Q44: Doubling cache associativity

## Question

If the associativity of a processor cache is doubled while keeping the capacity and block size unchanged, which one of the following is guaranteed to be NOT affected?

- (A) Width of tag comparator
- (B) Width of set index decoder
- (C) Width of way selection multiplexor
- (D) Width of processor to main memory data bus

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Capacity and block size are fixed, so

$$\text{number of sets} = \frac{\text{capacity}}{\text{block size} \times \text{associativity}}$$

halves when associativity doubles.

- (A) the set index loses 1 bit, so the **tag gains 1 bit**, and the tag comparator gets wider. Affected.
- (B) the **index decoder** is 1 bit narrower. Affected.
- (C) with twice as many ways per set, the **way-select multiplexer** is wider (twice the inputs). Affected.
- (D) the processor-to-memory data bus carries blocks or words between the cache and memory. Its width is a separate design choice, not tied to how the cache is organised internally. **Not affected.**

**Key idea:** associativity changes index, tag and way-select hardware, not the memory interface.

</details>
