# 2013 CS Q20: Set-associative mapping range

## Question

In a $k$-way set associative cache, the cache is divided into $v$ sets, each of which consists of $k$ lines. The lines of a set are placed in sequence one after another. The lines in set $s$ are sequenced before the lines in set $(s+1)$. The main memory blocks are numbered 0 onwards. The main memory block numbered $j$ must be mapped to any one of the cache lines from

- (A) $(j \bmod v) * k$ to $(j \bmod v) * k + (k-1)$
- (B) $(j \bmod v)$ to $(j \bmod v) + (k-1)$
- (C) $(j \bmod k)$ to $(j \bmod k) + (v-1)$
- (D) $(j \bmod k) * v$ to $(j \bmod k) * v + (v-1)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Block $j$ goes to set $s = j \bmod v$ (there are $v$ sets).
- Set $s$ has $k$ lines, and sets are laid out one after another, so set $s$ starts at line $s \cdot k$ and ends at line $s\cdot k + (k-1)$.

So the line range is $(j \bmod v)\cdot k$ to $(j\bmod v)\cdot k + (k-1)$: option (A).

**Why the others fail:**

- (B) forgets that each set holds $k$ lines, so the start index is not $s$.
- (C), (D) take the modulus with $k$, but block-to-set mapping uses the number of sets $v$.

**Key idea:** set index $= j \bmod v$; first line of the set $= $ set index $\times k$.

</details>
