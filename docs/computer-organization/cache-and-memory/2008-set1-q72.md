# 2008 CS Q72: Array element with the same cache index as ARR[0][0]

## Question

(Same setting as Q.71.) Which of the following array elements has the same cache index as `ARR[0][0]`?

- (A) `ARR[0][4]`
- (B) `ARR[4][0]`
- (C) `ARR[0][5]`
- (D) `ARR[5][0]`

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The cache has $2048$ sets of $16$-byte blocks, so the **set index** is bits 4 to 14 of the address, and addresses that differ by a multiple of $2048 \times 16 = 32768$ bytes ($2^{15}$) fall in the same set.

The array starts at `0xFF000000`, so `ARR[0][0]` is in set $0$. A row of the array has $1024 \times 8 = 8192$ bytes. The byte offsets from `ARR[0][0]` are:

| Element | Offset (bytes) | Set |
|---|---|---|
| `ARR[0][4]` | $4 \times 8 = 32$ | 2 |
| `ARR[0][5]` | $5 \times 8 = 40$ | 2 |
| `ARR[4][0]` | $4 \times 8192 = 32768$ | **0** |
| `ARR[5][0]` | $5 \times 8192 = 40960$ | 512 |

Only `ARR[4][0]`, at offset $2^{15}$, wraps around to set $0$: (B).

- (A) and (C) lie in the block two blocks after `ARR[0][0]`, which is set 2.
- (D) is in set 512.

**Code check:** the simulator printed the sets 0, 2, 0, 2 and 512 for `ARR[0][0]`, `[0][4]`, `[4][0]`, `[0][5]` and `[5][0]`.

**Key idea:** elements whose addresses differ by a multiple of (number of sets $\times$ block size) map to the same set.

</details>
