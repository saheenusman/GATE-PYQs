# 2014 CS2 Q55: Maximum stores per millisecond with 8 memory modules

## Question

Consider a main memory system that consists of 8 memory modules attached to the system bus, which is one word wide. When a write request is made, the bus is occupied for 100 nanoseconds (ns) by the data, address, and control signals. During the same 100 ns, and for 500 ns thereafter, the addressed memory module executes one cycle accepting and storing the data. The (internal) operation of different memory modules may overlap in time, but only one request can be on the bus at any time. The maximum number of stores (of one word each) that can be initiated in 1 millisecond is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**10000**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each store keeps the bus busy for 100 ns, and keeps its module busy for $100 + 500 = 600$ ns from the start.

If stores go to the modules in turn, a module gets a new request every $8 \times 100 = 800$ ns. That is longer than its 600 ns busy time, so a module is always free when its turn comes. (At least $600/100 = 6$ modules are needed to avoid any wait; 8 is enough.)

So the **bus is the bottleneck**: one store can start every 100 ns.

$$\frac{1\ \text{ms}}{100\ \text{ns}} = \frac{10^{-3}}{10^{-7}} = 10^4 = 10000.$$

**Key idea:** with enough interleaved modules, throughput is limited by the shared bus, not by the memory cycle time.

**Classification flag:** memory interleaving and bus timing are filed under `cache-and-memory` (main-memory side), since `io-and-storage` is for devices.

</details>
