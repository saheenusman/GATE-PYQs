# 2014 CS2 Q9: TAG bits of a 4-way set-associative cache

## Question

A 4-way set-associative cache memory unit with a capacity of 16 KB is built using a block size of 8 words. The word length is 32 bits. The size of the physical address space is 4 GB. The number of bits for the TAG field is _____

<details class="success" markdown="1">
<summary>Answer</summary>

**20**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Address bits: $4\text{ GB} = 2^{32}$, so 32 bits.
- Block size: $8 \times 4\text{ B} = 32\text{ B} = 2^5$, so the offset is 5 bits.
- Blocks: $16\text{ KB}/32\text{ B} = 512$; sets $= 512/4 = 128 = 2^7$, so the index is 7 bits.

$$\text{TAG} = 32 - 7 - 5 = 20 \text{ bits}$$

**Code check:** `32 - log2(128) - log2(32)` gives 20.

**Key idea:** address $=$ tag $+$ set index $+$ block offset.

</details>
