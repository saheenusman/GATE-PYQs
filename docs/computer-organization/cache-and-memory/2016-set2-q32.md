# 2016 CS2 Q32: Tag width of a 512 KB 8-way set associative cache

## Question

The width of the physical address on a machine is 40 bits. The width of the tag field in a 512 KB 8-way set associative cache is ______ bits.

<details class="success" markdown="1">
<summary>Answer</summary>

**24**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The block size is not given, and it does not matter.

$$\text{sets} \times \text{block size} = \frac{512\ \text{KB}}{8} = 2^{19-3} = 2^{16}\ \text{bytes}$$

So the set-index bits and block-offset bits together are $16$. The tag is the rest:

$$40 - 16 = 24\ \text{bits}$$

**Code check:** for block sizes of $32$ B and $64$ B the tag came out as $24$ bits both times.

**Key idea:** index + offset $= \log_2(512\text{ KB}/8) = 16$ bits, so tag $= 40 - 16$.

</details>
