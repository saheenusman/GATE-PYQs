# 2021 CS1 Q32: Tag bits in a direct-mapped cache

## Question

Consider a computer system with a byte-addressable primary memory of size $2^{32}$ bytes. Assume the computer system has a direct-mapped cache of size 32 KB ($1\text{ KB}=2^{10}$ bytes), and each cache block is of size 64 bytes.

The size of the tag field is ______ bits.

<details class="success" markdown="1">
<summary>Answer</summary>

**17**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Address width: $\log_2 2^{32}=32$ bits.
- Block offset: $64=2^6$ bytes, so 6 bits.
- Number of cache blocks: $32\text{ KB}/64\text{ B}=2^{15}/2^6=2^9=512$, so 9 index bits.
- Tag $=32-9-6=\mathbf{17}$ bits.

Checked with a script: 17.

**Key idea:** address = tag + index + offset. For direct mapping, index bits $=\log_2(\text{number of blocks})$.

</details>
