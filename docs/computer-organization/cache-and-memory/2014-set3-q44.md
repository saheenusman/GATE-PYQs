# 2014 CS3 Q44: Average memory access time with different read/write costs

## Question

The memory access time is 1 nanosecond for a read operation with a hit in cache, 5 nanoseconds for a read operation with a miss in cache, 2 nanoseconds for a write operation with a hit in cache and 10 nanoseconds for a write operation with a miss in cache. Execution of a sequence of instructions involves 100 instruction fetch operations, 60 memory operand read operations and 40 memory operand write operations. The cache hit-ratio is 0.9. The average memory access time (in nanoseconds) in executing the sequence of instructions is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1.68**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Instruction fetches are reads, so there are $100 + 60 = 160$ reads and $40$ writes: 200 accesses in all.

- Average read time: $0.9 \times 1 + 0.1 \times 5 = 1.4$ ns.
- Average write time: $0.9 \times 2 + 0.1 \times 10 = 2.8$ ns.

$$\text{AMAT} = \frac{160 \times 1.4 + 40 \times 2.8}{200} = \frac{224 + 112}{200} = 1.68 \text{ ns}.$$

**Code check:** the computation above gives `1.68`.

**Key idea:** weight each access type by how often it occurs, and apply the hit ratio within each type.

</details>
