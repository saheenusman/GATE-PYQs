# 2020 CS Q40: Which addresses map to the same set of a 4-way cache

## Question

A computer system with a word length of 32 bits has a 16 MB byte-addressable main memory and a 64 KB, 4-way set associative cache memory with a block size of 256 bytes. Consider the following four physical addresses represented in hexadecimal notation.

A1 = 0x42C8A4, A2 = 0x546888, A3 = 0x6A289C, A4 = 0x5E4880

Which one of the following is TRUE?

- (A) A1 and A4 are mapped to different cache sets.
- (B) A2 and A3 are mapped to the same cache set.
- (C) A3 and A4 are mapped to the same cache set.
- (D) A1 and A3 are mapped to the same cache set.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split the address.**

| Quantity | Value | Bits |
|---|---|---|
| Physical address | 16 MB $= 2^{24}$ bytes | 24 |
| Block offset | 256 bytes $= 2^8$ | 8 |
| Number of blocks | $64\,\text{KB} / 256\,\text{B} = 256$ | |
| Number of sets | $256 / 4 = 64 = 2^6$ | 6 (set index) |
| Tag | $24 - 8 - 6$ | 10 |

So the set index is bits 13 to 8 of the address. In hex, the last byte (two digits) is the offset. The set index is the low 6 bits of the byte just before it.

| Address | Middle byte (bits 15 to 8) | Binary | Low 6 bits | Set |
|---|---|---|---|---|
| A1 = 0x42C8A4 | C8 | 1100 1000 | 001000 | **8** |
| A2 = 0x546888 | 68 | 0110 1000 | 101000 | **40** |
| A3 = 0x6A289C | 28 | 0010 1000 | 101000 | **40** |
| A4 = 0x5E4880 | 48 | 0100 1000 | 001000 | **8** |

A1 and A4 share set 8. A2 and A3 share set 40. I computed these in code as well.

**Check the options:**

- **(A)** false: A1 and A4 are in the *same* set (8).
- **(B)** **true**: A2 and A3 are both in set 40.
- **(C)** false: A3 is in set 40 and A4 in set 8.
- **(D)** false: A1 is in set 8 and A3 in set 40.

**Key idea:** set index $=$ (address $\div$ block size) mod (number of sets). Associativity only changes how many sets there are.

</details>
