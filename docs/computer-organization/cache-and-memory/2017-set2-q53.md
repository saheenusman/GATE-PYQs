# 2017 CS2 Q53: Tag bits for a direct-mapped cache with 512 lines and 32-byte blocks

## Question

Consider a machine with a byte addressable main memory of $2^{32}$ bytes divided into blocks of size 32 bytes. Assume that a direct mapped cache having 512 cache lines is used with this machine. The size of the tag field in bits is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**18**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Address split** for a direct-mapped cache: tag | line index | block offset.

- Address width: $\log_2 2^{32} = 32$ bits.
- Block offset: $\log_2 32 = 5$ bits.
- Line index: $\log_2 512 = 9$ bits.

$$\text{tag} = 32 - 9 - 5 = 18 \text{ bits}.$$

**Code check:** the arithmetic gave offset 5, index 9 and tag 18.

**Key idea:** tag $=$ address bits $-$ index bits $-$ offset bits.

</details>
