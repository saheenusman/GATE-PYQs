# 2010 CS Q7: Refreshing all cells of a 4 MB DRAM memory built from 1M x 1 chips

## Question

A main memory unit with a capacity of 4 megabytes is built using $1\text{M} \times 1$-bit DRAM chips. Each DRAM chip has $1\text{K}$ rows of cells with $1\text{K}$ cells in each row. The time taken for a single refresh operation is $100$ nanoseconds. The time required to perform one refresh operation on all the cells in the memory unit is

- (A) $100$ nanoseconds
- (B) $100 \times 2^{10}$ nanoseconds
- (C) $100 \times 2^{20}$ nanoseconds
- (D) $3200 \times 2^{20}$ nanoseconds

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key in the supplied PDF is (D). My reading of the question gives (B). Both follow.

**Chip count.** $4\text{ MB} = 2^{22} \times 8 = 32 \times 2^{20}$ bits. Each chip holds $1\text{M} = 2^{20}$ bits, so the memory has $32$ chips.

**What the key assumes (D).** Every cell is refreshed by its own operation, one after another, across all $32$ chips:

$$32 \times 2^{20} \times 100 = 3200 \times 2^{20} \text{ ns}$$

**What I get (B).** In a DRAM, one refresh operation refreshes a whole **row**, and all chips are refreshed at the same time. Then the time is set by the number of rows in one chip:

$$1\text{K rows} \times 100 \text{ ns} = 100 \times 2^{10} \text{ ns}$$

The question gives "$1\text{K}$ rows with $1\text{K}$ cells in each row" for exactly this reason. Option (B) is also the answer I found in other published solutions, but the supplied key says (D). The question does not say whether refresh is per cell or per row, so I do not treat either reading as settled.

- (A) $100$ ns is a single refresh operation, not a pass over the whole memory.
- (C) $100 \times 2^{20}$ ns refreshes one chip cell by cell; it ignores the other $31$ chips.

**Code check:** arithmetic only: $32 \times 2^{20} \times 100 = 3200 \times 2^{20}$ and $1024 \times 100 = 100 \times 2^{10}$. No program to run.

**Key idea:** the answer depends on the refresh unit. Per row and all chips in parallel gives $100 \times 2^{10}$; per cell and serial gives $3200 \times 2^{20}$.

</details>
