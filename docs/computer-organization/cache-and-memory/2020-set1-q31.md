# 2020 CS Q31: Average memory access time for a direct-mapped cache

## Question

A direct mapped cache memory of 1 MB has a block size of 256 bytes. The cache has an access time of 3 ns and a hit rate of 94%. During a cache miss, it takes 20 ns to bring the first word of a block from the main memory, while each subsequent word takes 5 ns. The word size is 64 bits. The average memory access time in ns (round off to 1 decimal place) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**13.3** (the key also accepts **13.5**)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Miss penalty.** A word is 64 bits $= 8$ bytes, so a 256-byte block has $256 / 8 = 32$ words. Bringing the block from main memory takes

$$20 + 31 \times 5 = 175 \text{ ns}.$$

The cache size (1 MB) and the direct mapping are not needed for this calculation.

**Two standard formulas**, and the official key accepts both:

| Formula | Calculation | Result |
|---|---|---|
| Weighted average of hit and miss times | $0.94 \times 3 + 0.06 \times 175 = 2.82 + 10.5$ | **13.32 ≈ 13.3** |
| Hit time + miss rate × miss penalty | $3 + 0.06 \times 175 = 3 + 10.5$ | **13.5** |

The first treats a miss as taking 175 ns in total. The second charges the 3 ns cache lookup on every access (hit or miss) and then adds the block transfer time on a miss. The question does not say which convention it uses, which is why the key accepts both values.

I checked both numbers in code.

**Key idea:** the miss penalty is the time to bring a whole block. Here it is the first word plus the remaining 31 words, not one word.

</details>
