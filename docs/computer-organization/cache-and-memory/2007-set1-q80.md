# 2007 CS Q80: Total cache misses accessing a 50 x 50 array twice

## Question

**Statement for Linked Answer Questions 80 & 81.** Consider a machine with a byte addressable main memory of $2^{16}$ bytes. Assume that a direct mapped data cache consisting of 32 lines of 64 bytes each is used in the system. A $50 \times 50$ two-dimensional array of bytes is stored in the main memory starting from memory location 1100H. Assume that the data cache is initially empty. The complete array is accessed twice. Assume that the contents of the data cache do not change in between the two accesses.

**Q.80** How many data cache misses will occur in total?

- (A) 48
- (B) 50
- (C) 56
- (D) 59

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- The array occupies $50 \times 50 = 2500$ bytes starting at $1100\text{H} = 4352$.
- Block size $64$: $4352 / 64 = 68$ exactly, so the array starts on a block boundary at **block 68** and covers $\lceil 2500/64 \rceil = 40$ blocks, blocks $68$ to $107$.
- Direct mapped, 32 lines: block $b$ goes to line $b \bmod 32$. Blocks $68..95$ go to lines $4..31$; blocks $96..107$ go to lines $0..11$.

**First pass:** each of the 40 blocks is fetched once: $40$ misses (a block is only re-fetched if its line is stolen). Lines $4..11$ are used twice (blocks $68..75$ first, then replaced by blocks $100..107$).

**Second pass:** lines $0..3$ (blocks $96..99$) and lines $12..31$ still hold the right blocks: hits. Lines $4..11$ now hold blocks $100..107$, but the pass starts again with blocks $68..75$: $8$ misses, which replace $100..107$. When the pass reaches blocks $100..107$ they are gone again: $8$ more misses. Second pass: $16$ misses.

Total $= 40 + 16 = 56$: (C).

- (A) 48 counts $40 + 8$ and forgets that blocks $100..107$ miss again.
- (B) 50 and (D) 59 do not match any consistent count.

**Code check:** Python direct-mapped cache simulation (32 lines, 64-byte blocks), accessing bytes $4352..6851$ twice: 40 misses in the first pass and 16 in the second, 56 in total.

**Key idea:** map the array to block numbers, then to lines with $b \bmod 32$; two blocks on the same line conflict when the array spans more than the cache.
