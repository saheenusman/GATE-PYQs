# 2025 CS2 Q55: Average access time with a two-level cache and miss penalties

## Question

Given a computing system with two levels of cache (L1 and L2) and a main memory. The first level (L1) cache access time is 1 nanosecond (ns) and the "hit rate" for L1 cache is 90% while the processor is accessing the data from L1 cache. Whereas, for the second level (L2) cache, the "hit rate" is 80% and the "miss penalty" for transferring data from L2 cache to L1 cache is 10 ns. The "miss penalty" for the data to be transferred from main memory to L2 cache is 100 ns.

Then the average memory access time in this system in nanoseconds is ___________ . (rounded off to one decimal place)

<details class="success" markdown="1">
<summary>Answer</summary>

**4.0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the standard form $\text{AMAT} = \text{hit time} + \text{miss rate} \times \text{miss penalty}$, applied level by level.

- L1 hit time $= 1$ ns, L1 miss rate $= 10\% = 0.1$.
- The L1 miss penalty is the cost of getting the data from L2: $10$ ns to transfer it, plus, if L2 also misses ($20\% = 0.2$), another $100$ ns from main memory:

$$\text{L1 miss penalty} = 10 + 0.2 \times 100 = 30 \text{ ns}.$$

$$\text{AMAT} = 1 + 0.1 \times 30 = 4.0 \text{ ns}.$$

**Key idea:** the L1 miss penalty is itself a small AMAT: the transfer time from L2 plus L2's miss rate times its own penalty.

</details>
