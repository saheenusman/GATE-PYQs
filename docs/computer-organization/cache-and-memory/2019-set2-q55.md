# 2019 CS2 Q55: Maximum memory bandwidth for a cache with a given miss penalty

## Question

A certain processor deploys a single-level cache. The cache block size is 8 words and the word size is 4 bytes. The memory system uses a 60-MHz clock. To service a cache miss, the memory controller first takes 1 cycle to accept the starting address of the block, it then takes 3 cycles to fetch all the eight words of the block, and finally transmits the words of the requested block at the rate of 1 word per cycle. The maximum bandwidth for the memory system when the program running on the processor issues a series of read operations is ________ $\times 10^6$ bytes/sec.

<details class="success" markdown="1">
<summary>Answer</summary>

**160**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Cycles per block.**

| Phase | Cycles |
|---|---|
| Accept address | 1 |
| Fetch the block | 3 |
| Transmit 8 words at 1 word per cycle | 8 |
| **Total** | **12** |

**Bytes per block:** $8 \text{ words} \times 4 \text{ B} = 32$ B.

**Bandwidth** with the clock at $60 \times 10^6$ cycles/s:

$$\frac{32 \text{ B}}{12 \text{ cycles}} \times 60 \times 10^6 \text{ cycles/s} = 160 \times 10^6 \text{ B/s}.$$

**Key idea:** bandwidth $=$ bytes moved per miss divided by cycles per miss, times the clock rate.

</details>
