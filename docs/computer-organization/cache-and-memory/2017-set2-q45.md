# 2017 CS2 Q45: Average read access time with I-cache, D-cache, L2 and main memory

## Question

The read access times and the hit ratios for different caches in a memory hierarchy are as given below.

| Cache | Read access time (in nanoseconds) | Hit ratio |
|---|---|---|
| I-cache | 2 | 0.8 |
| D-cache | 2 | 0.9 |
| L2-cache | 8 | 0.9 |

The read access time of main memory is 90 nanoseconds. Assume that the caches use the referred-word-first read policy and the write back policy. Assume that all the caches are direct mapped caches. Assume that the dirty bit is always 0 for all the blocks in the caches. In execution of a program, 60% of memory reads are for instruction fetch and 40% are for memory operand fetch. The average read access time in nanoseconds (up to 2 decimal places) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4.72**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Model used.** A read first looks in its L1 cache. On a miss it goes to L2; on an L2 miss it goes to main memory. With referred-word-first, the processor gets the requested word as soon as it arrives, so no block-fill time is added. The time of each level is paid when that level is accessed.

**Time to service an L1 miss** (L2 access, plus memory on an L2 miss):

$$t_{\text{miss}} = 8 + 0.1 \times 90 = 17 \text{ ns}.$$

**Instruction reads** (I-cache hit ratio 0.8):

$$t_I = 2 + 0.2 \times 17 = 5.4 \text{ ns}.$$

**Data reads** (D-cache hit ratio 0.9):

$$t_D = 2 + 0.1 \times 17 = 3.7 \text{ ns}.$$

**Weighted average:**

$$0.6 \times 5.4 + 0.4 \times 3.7 = 3.24 + 1.48 = 4.72 \text{ ns}.$$

**Code check:** the program gave $4.72$ for this model. An alternative that treats the L2 and memory times as *replacing* (not adding to) the L1 time, $0.6(0.8\cdot2 + 0.2\cdot16.2) + 0.4(0.9\cdot 2 + 0.1\cdot16.2) = 4.272$, does not match the official key, so the additive (look-up-then-next-level) model is the intended one.

**Status note:** the answer matches the official key under the additive model stated above; the question does not state the model, which is why the alternative figure is shown.

**Key idea:** $T_{avg} = t_{L1} + (1-h_{L1})\,\big[t_{L2} + (1-h_{L2})\,t_{mem}\big]$, weighted by the instruction/data mix.

</details>
