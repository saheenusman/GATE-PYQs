# 2017 CS1 Q51: Conflict misses of a 2-way LRU cache over a repeated access sequence

## Question

Consider a 2-way set associative cache with 256 blocks and uses LRU replacement. Initially the cache is empty. Conflict misses are those misses which occur due to contention of multiple blocks for the same cache set. Compulsory misses occur due to first time access to the block. The following sequence of accesses to memory blocks

`(0, 128, 256, 128, 0, 128, 256, 128, 1, 129, 257, 129, 1, 129, 257, 129)`

is repeated 10 times. The number of *conflict misses* experienced by the cache is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**76**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Sets.** 256 blocks with 2 ways gives $256/2 = 128$ sets. Block $b$ goes to set $b \bmod 128$:

- Blocks $0, 128, 256$ all map to **set 0**.
- Blocks $1, 129, 257$ all map to **set 1**.

Each set sees three blocks competing for 2 ways. The two sets behave identically, so trace set 0 under LRU. The cache shows the set contents, least recently used first.

**Round 1** (sequence $0,128,256,128,0,128,256,128$):

| Access | Result | Set after |
|---|---|---|
| 0 | miss (compulsory) | [0] |
| 128 | miss (compulsory) | [0, 128] |
| 256 | miss (compulsory), evicts 0 | [128, 256] |
| 128 | hit | [256, 128] |
| 0 | miss (conflict), evicts 256 | [128, 0] |
| 128 | hit | [0, 128] |
| 256 | miss (conflict), evicts 0 | [128, 256] |
| 128 | hit | [256, 128] |

Round 1: 5 misses per set, of which 3 are compulsory and 2 are conflict.

**Later rounds.** Each round starts and ends in the state [256, 128], and has 4 misses per set (the accesses to $0$ and $256$, each twice), all conflict misses.

**Totals** for both sets together:

- Compulsory: $3 + 3 = 6$ (once per distinct block).
- Round 1: $2\times5 = 10$ misses, so $10 - 6 = 4$ conflict.
- Rounds 2 to 10: $9 \times 2 \times 4 = 72$ conflict.

$$\text{Conflict misses} = 4 + 72 = 76$$

The answer is **76**.

**Code check:** an LRU simulation of the 160 accesses gave 82 misses: 6 compulsory and **76 conflict**, with 10 misses in round 1 and 8 in each later round.

**Key idea:** conflict misses are all misses after a block's first access; three blocks cycling through a 2-way set under LRU keep evicting each other.

</details>
