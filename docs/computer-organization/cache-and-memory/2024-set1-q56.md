# 2024 CS1 Q56: Speedup from a perfect cache

## Question

A given program has 25% load/store instructions. Suppose the ideal CPI (cycles per instruction) without any memory stalls is 2. The program exhibits 2% miss rate on instruction cache and 8% miss rate on data cache. The miss penalty is 100 cycles. The speedup (rounded off to two decimal places) achieved with a perfect cache (i.e., with NO data or instruction cache misses) is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**3.00**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Stall cycles per instruction.**

- Instruction fetch happens for **every** instruction: $0.02 \times 100 = 2$.
- Data accesses happen for 25% of instructions: $0.25 \times 0.08 \times 100 = 2$.

**CPI with the real caches** $= 2 + 2 + 2 = 6$. **CPI with a perfect cache** $= 2$.

$$\text{Speedup} = \frac{6}{2} = 3.00.$$

**Key idea:** instruction misses apply to every instruction. Data misses apply only to the load/store fraction.

</details>
