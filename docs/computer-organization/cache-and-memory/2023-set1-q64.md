# 2023 CS Q64: Tag bits in an 8-way set associative cache

## Question

An 8-way set associative cache of size 64 KB (1 KB = 1024 bytes) is used in a system with 32-bit address. The address is sub-divided into TAG, INDEX, and BLOCK OFFSET.

The number of bits in the TAG is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**19**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The block size is not given, but it does not matter.

**INDEX + OFFSET bits.** The cache has 8 ways, so each way holds $64\text{ KB} / 8 = 8\text{ KB} = 2^{13}$ bytes. Every byte of a way is addressed by index and offset together, so

$$\text{INDEX} + \text{OFFSET} = 13 \text{ bits}$$

(Splitting it differently, e.g. a larger block, moves bits between OFFSET and INDEX but their sum stays 13.)

**TAG.**

$$32 - 13 = 19 \text{ bits}$$

**Key idea:** $\text{tag} = \text{address bits} - \log_2(\text{cache size} / \text{associativity})$.

</details>
