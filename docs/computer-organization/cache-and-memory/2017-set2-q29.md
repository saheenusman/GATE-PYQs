# 2017 CS2 Q29: Miss rates of L1 and L2 from the average memory access time

## Question

In a two-level cache system, the access times of $L_1$ and $L_2$ caches are 1 and 8 clock cycles, respectively. The miss penalty from the $L_2$ cache to main memory is 18 clock cycles. The miss rate of $L_1$ cache is twice that of $L_2$. The average memory access time (AMAT) of this cache system is 2 cycles. The miss rates of $L_1$ and $L_2$ respectively are:

- (A) 0.111 and 0.056
- (B) 0.056 and 0.111
- (C) 0.0892 and 0.1784
- (D) 0.1784 and 0.0892

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**AMAT for two levels.** Let $m_1, m_2$ be the miss rates of $L_1, L_2$:

$$\text{AMAT} = 1 + m_1\,(8 + m_2 \cdot 18).$$

**Use the given conditions.** $m_1 = 2m_2$ and AMAT $= 2$:

$$1 + 2m_2\,(8 + 18 m_2) = 2 \;\Rightarrow\; 36 m_2^2 + 16 m_2 - 1 = 0.$$

$$m_2 = \frac{-16 + \sqrt{256 + 144}}{72} = \frac{-16 + 20}{72} = \frac{1}{18} \approx 0.056, \qquad m_1 = 2m_2 = \frac19 \approx 0.111.$$

So $L_1$: 0.111 and $L_2$: 0.056 is **(A)**.

**Why the others fail.**

- (B) swaps the two rates: AMAT $\approx 1.56$.
- (D) has $m_1 = 0.1784$ and gives AMAT $\approx 2.71$.
- (C) is the tricky one: AMAT $\approx 2.0$, but it has $m_2 = 2m_1$, the **reverse** of what the question says ($m_1 = 2m_2$). It solves the same equation with the ratio swapped, so it violates the given condition.

**Code check:** the quadratic's positive root gave $m_2 = 0.05556$, $m_1 = 0.11111$, AMAT $= 2.0000$. Evaluating the four options gave AMAT $1.9999$ (A), $1.5599$ (B), $2.0000$ (C), $2.7136$ (D); only (A) also satisfies $m_1 = 2m_2$.

**Key idea:** $\text{AMAT} = t_1 + m_1(t_2 + m_2 \cdot \text{penalty})$. Check every given condition, not just the final AMAT.

</details>
