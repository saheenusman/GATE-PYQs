# 2013 CS Q53: Page colours for a VIPT cache

## Question

**Statement for Linked Answer Questions 52 and 53.** A computer uses 46-bit virtual address, 32-bit physical address, and a three-level paged page table organization. The page table base register stores the base address of the first-level table ($T_1$), which occupies exactly one page. Each entry of $T_1$ stores the base address of a page of the second-level table ($T_2$). Each entry of $T_2$ stores the base address of a page of the third-level table ($T_3$). Each entry of $T_3$ stores a page table entry (PTE). The PTE is 32 bits in size. The processor used in the computer has a 1 MB 16-way set associative virtually indexed physically tagged cache. The cache block size is 64 bytes.

What is the minimum number of page colours needed to guarantee that no two synonyms map to different sets in the processor cache of this computer?

- (A) 2
- (B) 4
- (C) 8
- (D) 16

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Cache geometry.** $1\text{ MB} / (16 \text{ ways} \times 64\text{ B}) = 1024 = 2^{10}$ sets. So the cache index uses 10 bits and the block offset uses 6 bits: the cache is indexed by address bits $[15:0]$, 16 bits in all.

**Page geometry.** Page size is 8 KB (from Q52), so the page offset is 13 bits: bits $[12:0]$.

**Overlap.** Bits $[15:13]$ lie in the **page number** but also feed the cache index. Synonyms (different virtual pages for the same physical page) may differ in these 3 bits, and so land in different sets.

To prevent that, the OS must give synonyms the same value in these 3 bits: $2^3 = 8$ page colours.

**Why the others fail:** 2, 4 or 16 colours correspond to 1, 2 or 4 overlapping bits; there are 3.

**Code check:** the bit counts gave 3 overlapping bits, so 8 colours.

**Flag:** the topic is shared between operating systems (page colouring) and computer organization (VIPT caches). Filed under `cache-and-memory`, with `memory-management` as additional.

**Key idea:** page colours $= 2^{(\text{index}+\text{offset bits}) - \text{page offset bits}}$ for a VIPT cache.

</details>
