# 2021 CS2 Q37: Write-through L1 and write-allocate statements

## Question

Assume a two-level inclusive cache hierarchy, L1 and L2, where L2 is the larger of the two. Consider the following statements.

$S_1$: Read misses in a write through L1 cache do not result in writebacks of dirty lines to the L2.

$S_2$: Write allocate policy must be used in conjunction with write through caches and no-write allocate policy is used with writeback caches.

Which of the following statements is correct?

- (A) $S_1$ is true and $S_2$ is false
- (B) $S_1$ is false and $S_2$ is true
- (C) $S_1$ is true and $S_2$ is true
- (D) $S_1$ is false and $S_2$ is false

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$S_1$ is true.** A write-through cache sends every write to the next level at once, so it never holds a dirty line. When a read miss evicts a line, there is nothing to write back.

**$S_2$ is false.** Two things are wrong with it.

- Write-allocate and no-write-allocate are independent of the write policy. Any combination is legal.
- The pairing it states is backwards from the usual one: write-through is normally paired with **no**-write-allocate (no point loading a line you will write through anyway), and write-back is normally paired with write-allocate.

So (A).

- (B) and (D) call $S_1$ false.
- (C) calls $S_2$ true.

**Key idea:** write-through caches have no dirty lines; write-allocate is a separate choice from write-through or write-back.

</details>
