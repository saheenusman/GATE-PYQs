# 2018 CS Q33: Memory time left after DRAM refresh

## Question

A 32-bit wide main memory unit with a capacity of 1 GB is built using 256M $\times$ 4-bit DRAM chips. The number of rows of memory cells in the DRAM chip is $2^{14}$. The time taken to perform one refresh operation is 50 nanoseconds. The refresh period is 2 milliseconds. The percentage (rounded to the closest integer) of the time available for performing the memory read/write operations in the main memory unit is __________.

<details class="success" markdown="1">
<summary>Answer</summary>

**59.0 to 60.0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Chips.** 1 GB $= 2^{30}$ bytes $= 2^{28}$ words of 32 bits. A chip holds $256\text{M}\times 4$ bits, so $32/4 = 8$ chips sit side by side. They are refreshed together, so we only compute the time for one chip.

**Refresh time per period.** One refresh operation refreshes one row, and every row must be refreshed within 2 ms:

$$2^{14}\times 50\text{ ns} = 16384\times50\text{ ns} = 819.2\ \mu\text{s}$$

**Fraction used for refresh:** $\dfrac{819.2\ \mu\text{s}}{2000\ \mu\text{s}} = 40.96\%$.

**Time left for read/write:** $100 - 40.96 = 59.04\%\approx$ **59**. The key's range is 59.0 to 60.0.

**Key idea:** refresh steals (rows $\times$ refresh time) out of each refresh period; the rest is available for access.

</details>
