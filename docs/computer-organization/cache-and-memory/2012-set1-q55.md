# 2012 CS Q55: Size of the cache tag directory

## Question

**Statement for Linked Answer Questions 54 and 55** (cache as in Q54: $256$ KByte, $4$-way set associative, block size $32$ Bytes, $32$-bit addresses; each tag directory entry holds the address tag plus $2$ valid bits, $1$ modified bit and $1$ replacement bit).

The size of the cache tag directory is

- (A) 160 Kbits
- (B) 136 Kbits
- (C) 40 Kbits
- (D) 32 Kbits

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

There is one directory entry per cache block, $8192$ in all (from Q54).

Each entry: $16$ (tag) $+ 2$ (valid) $+ 1$ (modified) $+ 1$ (replacement) $= 20$ bits.

$$8192 \times 20 = 163840 \text{ bits} = 160 \text{ Kbits}.$$

This is (A).

- (B) $136\text{ Kbits} = 17$ bits per entry, so it leaves out three of the status bits.
- (C) $40\text{ Kbits} = 5$ bits per entry, and (D) $32\text{ Kbits} = 4$ bits per entry, so they count (almost) only the status bits and forget the tag.

The answer depends on the tag size from Q54; a wrong Q54 would carry into this one.

**Code check:** $8192 \times (16 + 4) = 163840$ bits $= 160$ Kbits.

**Key idea:** directory size $=$ number of blocks $\times$ (tag + status bits per entry).

</details>
