# 2011 CS Q11: Highest priority interrupt among four sources

## Question

A computer handles several interrupt sources of which the following are relevant for this question.

- Interrupt from CPU temperature sensor (raises interrupt if CPU temperature is too high)
- Interrupt from Mouse (raises interrupt if the mouse is moved or a button is pressed)
- Interrupt from Keyboard (raises interrupt when a key is pressed or released)
- Interrupt from Hard Disk (raises interrupt when a disk read is completed)

Which one of these will be handled at the **HIGHEST** priority?

- (A) Interrupt from Hard Disk
- (B) Interrupt from Mouse
- (C) Interrupt from Keyboard
- (D) Interrupt from CPU temperature sensor

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Interrupt priority follows **urgency**: how bad it is to delay the handler.

| Source | Cost of delay |
|---|---|
| CPU temperature | hardware damage or forced shutdown |
| Hard disk | data may be overrun or the device sits idle |
| Keyboard | a keystroke can be buffered for a while |
| Mouse | a lost or late movement is barely noticeable |

The temperature sensor signals a condition that threatens the machine itself, so it gets the highest priority: (D).

- (A) disk comes next, since late service wastes a fast device.
- (B), (C) human input devices are slow and tolerant of delay; the mouse is the lowest.

This is a convention question: no rule fixes the order, but this ordering is the standard one and matches the key.

**Key idea:** interrupts are ranked by how costly a delay is; hardware-safety events outrank I/O, and slow human devices rank lowest.

</details>
