# 2026 CS1 Q59: Total disk transfer time with seeks and rotation

## Question

Consider a hard disk with a rotational speed of 15000 rpm. The time to move the read/write head from a track to its adjacent track is 1 millisecond. Initially, the head is on track 0. The number of sectors per track is 400. The sector size is 1024 bytes. It is necessary to transfer data from 10 randomly located sectors in each of the following tracks in the order: 5, 12 and 7.

The total time for the data transfer (in milliseconds) from the hard disk is ________. (rounded off to one decimal place)

<details class="success" markdown="1">
<summary>Answer</summary>

**77.3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rotation.** 15000 rpm means one revolution takes $60000/15000 = 4$ ms.

**Seek time (1 ms per track):**

| Move | Tracks | Time |
|---|---|---|
| 0 to 5 | 5 | 5 ms |
| 5 to 12 | 7 | 7 ms |
| 12 to 7 | 5 | 5 ms |
| **Total** | | **17 ms** |

**Per sector** (random location):

- Rotational latency, on average half a turn: $4/2 = 2$ ms
- Transfer time: $4/400 = 0.01$ ms
- Total: $2.01$ ms

**Per track:** $10 \times 2.01 = 20.1$ ms. For 3 tracks: $60.3$ ms.

**Total** $= 17 + 60.3 = \mathbf{77.3}$ ms.

**Key idea:** disk time = seek + rotational latency + transfer. "Randomly located" means use the *average* half-rotation latency for each sector.

</details>
