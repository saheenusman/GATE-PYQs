# 2024 CS2 Q53: Time to read a randomly placed file from disk

## Question

Consider a disk with the following specifications: rotation speed of 6000 RPM, average seek time of 5 milliseconds, 500 sectors/track, 512-byte sectors. A file has content stored in 3000 sectors located randomly on the disk. Assuming average rotational latency, the total time (in seconds, rounded off to 2 decimal places) to read the entire file from the disk is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**30.06**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The sectors are at random places, so **each sector needs its own seek and rotational wait**.

- Rotation time: $60 / 6000 = 10$ ms.
- Average rotational latency: $10/2 = 5$ ms.
- Average seek: 5 ms.
- Transfer of one sector: $10 \text{ ms} / 500 = 0.02$ ms.

**Per sector:** $5 + 5 + 0.02 = 10.02$ ms.

$$3000 \times 10.02 \text{ ms} = 30{,}060 \text{ ms} = 30.06 \text{ s}.$$

The official range is 29.50 to 30.50, and 30.06 lies in it. (Ignoring the transfer time gives 30.00, also in range.)

**Key idea:** for random access, every block costs seek + rotational latency + transfer.

</details>
