# 2011 CS Q44: Time to load 100 libraries from random disk locations

## Question

An application loads 100 libraries at startup. Loading each library requires exactly one disk access. The seek time of the disk to a random location is given as 10 ms. Rotational speed of disk is 6000 rpm. If all 100 libraries are loaded from random locations on the disk, how long does it take to load all libraries? (The time to transfer data from the disk block once the head has been positioned at the start of the block may be neglected.)

- (A) 0.50 s
- (B) 1.50 s
- (C) 1.25 s
- (D) 1.00 s

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For a random location the head needs a seek and then, on average, half a rotation.

- One rotation at $6000$ rpm takes $60 / 6000 = 10$ ms.
- Average rotational latency $= \tfrac12 \times 10 = 5$ ms.
- Time per access $= 10 + 5 = 15$ ms (transfer neglected).

$$100 \times 15 \text{ ms} = 1500 \text{ ms} = 1.50 \text{ s}$$

So (B).

- (A) $0.50$ s and (D) $1.00$ s leave out the seek or the rotation.
- (C) $1.25$ s would need $12.5$ ms per access, not $15$ ms.

**Code check:** $100 \times (10 + 5) / 1000 = 1.5$ s.

**Key idea:** random access time = seek + average rotational latency (half a rotation) + transfer.

</details>
