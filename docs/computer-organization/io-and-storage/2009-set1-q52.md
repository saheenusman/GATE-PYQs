# 2009 CS Q52: Disk address of the 1039th sector

## Question

**Common data for Questions 51 and 52.** (Same disk as Question 51: $63$ sectors per track, $10$ platters with $2$ recording surfaces each, $1000$ cylinders; address $\langle c, h, s \rangle$; the $0^{\text{th}}$ sector is $\langle 0, 0, 0 \rangle$, the $1^{\text{st}}$ is $\langle 0, 0, 1 \rangle$, and so on.)

**Q52.** The address of $1039^{\text{th}}$ sector is

- (A) $\langle 0, 15, 31 \rangle$
- (B) $\langle 0, 16, 30 \rangle$
- (C) $\langle 0, 16, 31 \rangle$
- (D) $\langle 0, 17, 31 \rangle$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Numbering starts at $0$, so the $1039^{\text{th}}$ sector means sector number $1039$ (the $1^{\text{st}}$ sector is $\langle 0, 0, 1 \rangle$).

Divide by the $63$ sectors per track:

$$1039 = 16 \times 63 + 31.$$

So it is sector $31$ of track number $16$. A cylinder has $20$ tracks (one per surface), and $16 < 20$, so this is still cylinder $0$ and surface $16$: $\langle 0, 16, 31 \rangle$: (C).

- (A) $\langle 0, 15, 31 \rangle$ is sector number $976$.
- (B) $\langle 0, 16, 30 \rangle$ is sector number $1038$. That would be the $1039^{\text{th}}$ sector only if counting started from $1$, but the question counts from $0$.
- (D) $\langle 0, 17, 31 \rangle$ is sector number $1102$.

**Code check:** $1039 = (0 \times 20 + 16) \times 63 + 31$. Evaluating the four options gave $976$, $1038$, $1039$ and $1102$.

**Key idea:** repeated division: by $63$ for the sector, then by $20$ for the surface and cylinder.

</details>
