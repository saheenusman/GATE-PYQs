# 2021 CS2 Q30: Data transfer rate with DMA cycle stealing

## Question

Consider a computer system with DMA support. The DMA module is transferring one 8-bit character in one CPU cycle from a device to memory through *cycle stealing* at regular intervals. Consider a 2 MHz processor. If 0.5% processor cycles are used for DMA, the data transfer rate of the device is ______ bits per second.

<details class="success" markdown="1">
<summary>Answer</summary>

**80000**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A 2 MHz processor has $2\times10^{6}$ cycles per second.

DMA steals $0.5\%$ of them:

$$2\times10^{6}\times0.005=10^{4}\ \text{cycles/s}.$$

Each stolen cycle moves one 8-bit character:

$$10^{4}\times8=80\,000\ \text{bits/s}.$$

**Key idea:** in cycle stealing, one stolen CPU cycle moves one unit of data; rate = stolen cycles per second × bits per cycle.

</details>
