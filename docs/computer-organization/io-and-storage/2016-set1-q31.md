# 2016 CS1 Q31: Number of DMA bus takeovers for a 29,154 KB transfer

## Question

The size of the data count register of a DMA controller is 16 bits. The processor needs to transfer a file of 29,154 kilobytes from disk to main memory. The memory is byte addressable. The minimum number of times the DMA controller needs to get the control of the system bus from the processor to transfer the file from the disk to main memory is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**456**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**One bus takeover moves at most $2^{16}$ bytes.** The 16-bit count register holds the number of bytes still to move, and memory is byte addressable, so one setup transfers at most

$$2^{16} = 65{,}536\ \text{bytes} = 64\ \text{KB}$$

**Number of takeovers.**

$$\left\lceil \frac{29{,}154\ \text{KB}}{64\ \text{KB}} \right\rceil = \lceil 455.53 \rceil = 456$$

The last takeover moves the remaining partial block.

**Assumption.** Each takeover moves one block of up to $2^{16}$ bytes (block or burst mode), which is how the official key counts.

**Key idea:** each DMA transfer is limited by the count register to $2^{16}$ bytes; divide and round up.

</details>
