# 2022 CS Q17: Highest throughput bulk transfer from disk

## Question

Which one of the following facilitates transfer of bulk data from hard disk to main memory with the highest throughput?

- (A) DMA based I/O transfer
- (B) Interrupt driven I/O transfer
- (C) Polling based I/O transfer
- (D) Programmed I/O transfer

<details class="success" markdown="1">
<summary>Answer</summary>

**A (DMA based I/O transfer)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**DMA moves blocks without the CPU.** After the CPU sets up the transfer (address, count), the DMA controller copies the data between the device and memory by itself, stealing bus cycles, and interrupts the CPU once at the end. The CPU is not involved for each word, so throughput is highest for bulk data.

**Why the others fail:** polling, interrupt-driven and programmed I/O all pass every byte or word through the CPU. Polling wastes time in a busy loop. Interrupt-driven I/O pays an interrupt-handling cost per word. Programmed I/O ties up the CPU for the whole transfer.

**Key idea:** DMA offloads the per-word work from the CPU, which matters most for large block transfers.

</details>
