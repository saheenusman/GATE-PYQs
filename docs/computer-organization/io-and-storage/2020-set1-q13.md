# 2020 CS Q13: True statements about interrupts, polling and DMA

## Question

Consider the following statements.

- I. Daisy chaining is used to assign priorities in attending interrupts.
- II. When a device raises a vectored interrupt, the CPU does polling to identify the source of interrupt.
- III. In polling, the CPU periodically checks the status bits to know if any device needs its attention.
- IV. During DMA, both the CPU and DMA controller can be bus masters at the same time.

Which of the above statements is/are TRUE?

- (A) I and II only
- (B) I and IV only
- (C) I and III only
- (D) III only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Statement | Verdict | Reason |
|---|---|---|
| I | **True** | In daisy chaining the interrupt acknowledge passes along the devices in order, so the device nearest the CPU has the highest priority. |
| II | **False** | In a *vectored* interrupt the device itself supplies the vector (the address of its service routine), so the CPU does not need to poll. Polling is used for *non-vectored* interrupts. |
| III | **True** | This is the definition of polling. |
| IV | **False** | A bus has one master at a time. During DMA the controller takes the bus (burst or cycle stealing) and the CPU is held off. |

True statements: I and III.

**Why the other options fail:** (A) includes II, (B) includes IV, and (D) leaves out I. Each is wrong for one of those reasons.

**Key idea:** vectored interrupts identify the source without polling, and only one bus master can drive the bus at a time.

</details>
