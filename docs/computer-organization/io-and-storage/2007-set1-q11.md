# 2007 CS Q11: Disk pack capacity and sector address bits

## Question

Consider a disk pack with 16 surfaces, 128 tracks per surface and 256 sectors per track. 512 bytes of data are stored in a bit serial manner in a sector. The capacity of the disk pack and the number of bits required to specify a particular sector in the disk are respectively:

- (A) 256 Mbyte, 19 bits
- (B) 256 Mbyte, 28 bits
- (C) 512 Mbyte, 20 bits
- (D) 64 Gbyte, 28 bits

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Number of sectors: $16 \times 128 \times 256 = 2^4 \cdot 2^7 \cdot 2^8 = 2^{19}$.

Capacity: $2^{19} \times 512\ \text{B} = 2^{19} \cdot 2^9 = 2^{28}$ bytes $= 256$ MB.

Bits to name one **sector**: $\log_2 2^{19} = 19$.

So 256 MB and 19 bits: (A).

- (B) 28 bits would address a *byte*, not a sector.
- (C) and (D) have the wrong capacity (512 MB and 64 GB).

"Bit serial" only says how bits are written within a sector; it does not change the capacity.

**Code check:** Python: $16\cdot128\cdot256 = 524288$ sectors ($=2^{19}$), capacity $256.0$ MB.

**Key idea:** sector address = (surface, track, sector) = $\log_2$ of the sector count; capacity = sectors $\times$ bytes per sector.
