# 2009 CS Q51: Sector number of the disk address <400,16,29>

## Question

**Common data for Questions 51 and 52.** A hard disk has 63 sectors per track, 10 platters each with 2 recording surfaces and 1000 cylinders. The address of a sector is given as a triple $\langle c, h, s \rangle$, where $c$ is the cylinder number, $h$ is the surface number and $s$ is the sector number. Thus, the $0^{\text{th}}$ sector is addressed as $\langle 0, 0, 0 \rangle$, the $1^{\text{st}}$ sector as $\langle 0, 0, 1 \rangle$, and so on.

**Q51.** The address $\langle 400, 16, 29 \rangle$ corresponds to sector number:

- (A) 505035
- (B) 505036
- (C) 505037
- (D) 505038

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

There are $10 \times 2 = 20$ surfaces, so each cylinder has $20$ tracks, and each track has $63$ sectors. Sectors are numbered cylinder by cylinder, surface by surface, then by sector:

$$\text{sector number} = (c \times 20 + h) \times 63 + s.$$

For $\langle 400, 16, 29 \rangle$:

$$(400 \times 20 + 16) \times 63 + 29 = 8016 \times 63 + 29 = 505008 + 29 = 505037.$$

So (C).

- (A) $505035$, (B) $505036$ and (D) $505038$ are not equal to $505037$, so they are wrong.

**Code check:** the formula gave $505037$, matching only option (C).

**Key idea:** disk addresses are a mixed-radix number: sector within track, track within cylinder, then cylinder.

</details>
