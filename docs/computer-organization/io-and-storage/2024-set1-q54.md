# 2024 CS1 Q54: Number of cylinders in a hard disk

## Question

Consider a 512 GB hard disk with 32 storage surfaces. There are 4096 sectors per track and each sector holds 1024 bytes of data. The number of cylinders in the hard disk is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**4096**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Capacity per cylinder** (one track on each surface):

$$32 \text{ surfaces} \times 4096 \text{ sectors} \times 1024 \text{ B} = 2^5 \cdot 2^{12} \cdot 2^{10} = 2^{27} \text{ B}.$$

**Disk capacity:** $512 \text{ GB} = 2^9 \cdot 2^{30} = 2^{39}$ bytes.

$$\text{cylinders} = \frac{2^{39}}{2^{27}} = 2^{12} = 4096.$$

**Key idea:** capacity = cylinders × surfaces × sectors per track × bytes per sector.

</details>
