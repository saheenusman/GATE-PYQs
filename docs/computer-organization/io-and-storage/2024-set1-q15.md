# 2024 CS1 Q15: The false statement about DMA and interrupts

## Question

Which one of the following statements is FALSE?

- (A) In the cycle stealing mode of DMA, one word of data is transferred between an I/O device and main memory in a stolen cycle
- (B) For bulk data transfer, the burst mode of DMA has a higher throughput than the cycle stealing mode
- (C) Programmed I/O mechanism has a better CPU utilization than the interrupt driven I/O mechanism
- (D) The CPU can start executing an interrupt service routine faster with vectored interrupts than with non-vectored interrupts

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** In cycle stealing, the DMA controller takes the bus for one cycle at a time to move one word.
- **(B) True.** Burst mode holds the bus for a whole block, so it moves bulk data faster than one word at a time.
- **(C) False.** In programmed I/O the CPU **polls** the device in a busy loop, wasting cycles. Interrupt-driven I/O lets the CPU do useful work until the device interrupts. So interrupt-driven I/O has the *better* CPU utilization.
- **(D) True.** A vectored interrupt supplies the ISR address directly. Non-vectored interrupts need the CPU to run code to find out which device interrupted.

**Key idea:** polling burns CPU time. Interrupts and DMA free the CPU.

</details>
