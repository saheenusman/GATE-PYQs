# 2013 CS Q28: Micro-operation sequence

## Question

Consider the following sequence of micro-operations.

```
MBR <- PC
MAR <- X
PC  <- Y
Memory <- MBR
```

Which one of the following is a possible operation performed by this sequence?

- (A) Instruction fetch
- (B) Operand fetch
- (C) Conditional branch
- (D) Initiation of interrupt service

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Trace the four steps:

1. $MBR \leftarrow PC$: the current PC (the return address) is put in the data register.
2. $MAR \leftarrow X$: the address $X$ (for example the stack top or a fixed save location) goes to the address register.
3. $PC \leftarrow Y$: control jumps to $Y$ (the interrupt service routine's address).
4. $Memory \leftarrow MBR$: the old PC is **stored** to memory at $X$.

Saving the PC, then loading a new PC, is what the hardware does when an interrupt is accepted: (D).

**Why the others fail:**

- (A) A fetch reads memory ($MAR \leftarrow PC$; $MBR \leftarrow$ Memory); here memory is written.
- (B) An operand fetch also reads memory.
- (C) A conditional branch only changes the PC; it does not store the old PC.

**Flag:** micro-operation level; filed under `io-and-storage` since interrupts belong with I/O.

**Key idea:** push the PC to memory and load a new PC is the interrupt/call pattern.

</details>
