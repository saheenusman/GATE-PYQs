# 2026 CS2 Q18: Vectored and daisy-chain interrupts

## Question

Consider the following two statements about interrupt handling mechanisms in a CPU.

**S1:** In non-vectored interrupt mechanism, it usually takes more time to start the Interrupt Service Routine (ISR) when compared to that in a vectored interrupt mechanism.

**S2:** In daisy-chain interrupt mechanism, the CPU polls all the input devices individually to determine the source of the interrupt.

Which one of the following options is correct with respect to S1 and S2?

- (A) Both S1 and S2 are true
- (B) Both S1 and S2 are false
- (C) S1 is true and S2 is false
- (D) S1 is false and S2 is true

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**S1: True.**

- *Vectored:* the device supplies the ISR address (vector), so the CPU jumps straight to it.
- *Non-vectored:* the CPU jumps to one common routine, which must then find out which device interrupted (usually by polling) before it can run the right ISR. That takes extra time.

**S2: False.**

- In **daisy chaining** the devices are wired in series. The interrupt acknowledge signal passes along the chain and the first requesting device (closest to the CPU) captures it and puts its vector on the bus.
- The CPU does **not** poll each device individually. Individual polling is a different method (software polling).

So S1 is true and S2 is false, option (C).

**Key idea:** vectored interrupts skip the "who interrupted?" search; daisy chaining resolves priority in hardware by passing the acknowledge along the chain.

</details>
