# 2021 CS1 Q63: Time to run 100 instructions on a five-stage pipeline

## Question

A five-stage pipeline has stage delays of 150, 120, 150, 160 and 140 nanoseconds. The registers that are used between the pipeline stages have a delay of 5 nanoseconds each.

The total time to execute 100 independent instructions on this pipeline, assuming there are no pipeline stalls, is ______ nanoseconds.

<details class="success" markdown="1">
<summary>Answer</summary>

**17160**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The clock period must cover the slowest stage plus the register delay:

$$T=\max(150,120,150,160,140)+5=165\text{ ns}.$$

For $k$ stages and $n$ instructions with no stalls, the pipeline needs $k+n-1$ cycles:

$$(5+100-1)\times165=104\times165=\mathbf{17160}\text{ ns}.$$

Checked in a script: 17160.

**Key idea:** cycle time = slowest stage + register overhead. Total cycles = $k+n-1$.

</details>
