# 2015 CS3 Q49: Anti-dependence among five register instructions

## Question

Consider the following code sequence having five instructions $I_1$ to $I_5$. Each of these instructions has the following format.

`OP Ri, Rj, Rk`

where operation OP is performed on contents of registers Rj and Rk and the result is stored in register Ri.

```
I1: ADD R1, R2, R3
I2: MUL R7, R1, R3
I3: SUB R4, R1, R5
I4: ADD R3, R2, R4
I5: MUL R7, R8, R9
```

Consider the following three statements.

- S1: There is an anti-dependence between instructions $I_2$ and $I_5$
- S2: There is an anti-dependence between instructions $I_2$ and $I_4$
- S3: Within an instruction pipeline an anti-dependence always creates one or more stalls

Which one of above statements is/are correct?

- (A) Only S1 is true
- (B) Only S2 is true
- (C) Only S1 and S3 are true
- (D) Only S2 and S3 are true

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An **anti-dependence** (WAR) is when a later instruction *writes* a register that an earlier instruction *reads*.

- **S1 False.** $I_2$ (`MUL R7, R1, R3`) writes R7. $I_5$ also writes R7. Two writes to the same register are an **output** dependence (WAW), not anti.
- **S2 True.** $I_2$ *reads* R3, and the later $I_4$ (`ADD R3, R2, R4`) *writes* R3. That is a WAR, an anti-dependence.
- **S3 False.** In a normal in-order pipeline, operands are read early and results are written late, so a WAR hazard cannot occur and causes no stall. It matters only if instructions are reordered, and register renaming removes it.

Only S2: option (B).

**Code check:** listing every pair of instructions by hazard type gives RAW for $(I_1, I_2)$, $(I_1, I_3)$ and $(I_3, I_4)$; WAR for $(I_1, I_4)$ and $(I_2, I_4)$; WAW for $(I_2, I_5)$.

**Key idea:** RAW is true dependence, WAR is anti-dependence, WAW is output dependence.

</details>
