# 2008 CS Q36: Statements about hazards that are NOT true in a pipeline

## Question

Which of the following are NOT true in a pipelined processor?

- I. Bypassing can handle all RAW hazards
- II. Register renaming can eliminate all register carried WAR hazards
- III. Control hazard penalties can be eliminated by dynamic branch prediction

Options:

- (A) I and II only
- (B) I and III only
- (C) II and III only
- (D) I, II and III

<details class="success" markdown="1">
<summary>Answer</summary>

**C** (official key; see the Solution: disputed)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is (C), II and III. I get (B), I and III. Both views follow.

**Checking each statement.**

- **I. Not true.** Bypassing (forwarding) handles most RAW hazards, but not all: a **load followed by an instruction that uses the loaded value** still needs a stall, because the data is not available until the end of the memory stage.
- **II. True.** Renaming gives each write a fresh physical register, which removes WAR (and WAW) hazards completely, assuming enough physical registers.
- **III. Not true.** Dynamic branch prediction reduces control hazard penalties but does not eliminate them: a misprediction still flushes the pipeline.

So the statements that are NOT true are I and III: (B).

**Key's view.** The key's (C) would need statement II to be false and I to be true. The note in the supplied key has question marks beside the answer. Statement I contradicts the load-use hazard, and statement II holds in the idealised sense that the question uses, so I cannot derive (C). I record the key and mark the question disputed.

**Key idea:** forwarding cannot fix load-use hazards and prediction cannot remove mispredictions, but renaming does remove WAR hazards.

</details>
