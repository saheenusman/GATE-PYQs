# 2016 CS2 Q33: New clock frequency after splitting the longest pipeline stage

## Question

Consider a 3 GHz (gigahertz) processor with a three-stage pipeline and stage latencies $\tau_1$, $\tau_2$, and $\tau_3$ such that $\tau_1 = 3\tau_2/4 = 2\tau_3$. If the longest pipeline stage is split into two pipeline stages of equal latency, the new frequency is ______ GHz, ignoring delays in the pipeline registers.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $\tau_1 = 12$ units. Then $\tau_2 = 4\tau_1/3 = 16$ and $\tau_3 = \tau_1/2 = 6$.

- The clock period is set by the longest stage: $16$ units $\leftrightarrow$ $3$ GHz.
- Split $\tau_2$ into $8 + 8$. The stages are now $12, 8, 8, 6$, so the new longest stage is $12$ (the old $\tau_1$).

$$f_{\text{new}} = 3 \times \frac{16}{12} = 4\ \text{GHz}$$

The key accepts $3.9$ to $4.1$.

**Key idea:** stages $12, 16, 6$ become $12, 8, 8, 6$: frequency scales by $16/12$, from 3 to 4 GHz.

</details>
