# 2024 CS2 Q31: Data dependences in an instruction sequence

## Question

An instruction format has the following structure:

`Instruction Number: Opcode destination reg, source reg-1, source reg-2`

Consider the following sequence of instructions to be executed in a pipelined processor:

```
I1: DIV R3, R1, R2
I2: SUB R5, R3, R4
I3: ADD R3, R5, R6
I4: MUL R7, R3, R8
```

Which of the following statements is/are TRUE?

- (A) There is a RAW dependency on R3 between I1 and I2
- (B) There is a WAR dependency on R3 between I1 and I3
- (C) There is a RAW dependency on R3 between I2 and I3
- (D) There is a WAW dependency on R3 between I3 and I4

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

List what each instruction **writes** and **reads**:

| Instr | Writes | Reads |
|---|---|---|
| I1 | R3 | R1, R2 |
| I2 | R5 | R3, R4 |
| I3 | R3 | R5, R6 |
| I4 | R7 | R3, R8 |

- **(A) True.** I1 writes R3 and I2 reads it afterwards: read-after-write on R3.
- **(B) False.** I1 *writes* R3 and I3 *writes* R3: that is **WAW**, not WAR. (WAR on R3 exists between I2 and I3: I2 reads R3, then I3 writes it.)
- **(C) False.** I2 writes R5 and I3 reads R5: the RAW is on **R5**, not R3.
- **(D) False.** I4 does not write R3. (I4 *reads* R3, a RAW with I3.)

**Key idea:** RAW = read after write, WAR = write after read, WAW = write after write. Check which register and which instructions.

</details>
