# 2015 CS3 Q48: Minimum average latency from a reservation table

## Question

Consider the following reservation table for a pipeline having three stages $S_1$, $S_2$ and $S_3$.

| | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| $S_1$ | X | | | | X |
| $S_2$ | | X | | X | |
| $S_3$ | | | X | | |

The minimum average latency (MAL) is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Forbidden latencies** are the distances between two X's in the *same row* (using a stage twice at that spacing would collide):

- $S_1$: $5 - 1 = 4$
- $S_2$: $4 - 2 = 2$
- $S_3$: none

Forbidden $= \lbrace 2, 4 \rbrace$. Collision vector (bits $C_4 C_3 C_2 C_1$): $1010$.

**State diagram.** From a state $S$, a permitted latency $l$ leads to $(S \gg l) \,\text{OR}\, 1010$. Any latency $\ge 5$ returns to the start.

| From | Latency | To |
|---|---|---|
| 1010 | 1 | 1111 |
| 1010 | 3 | 1011 |
| 1010 | $\ge 5$ | 1010 |
| 1111 | $\ge 5$ | 1010 |
| 1011 | 3 | 1011 |
| 1011 | $\ge 5$ | 1010 |

**Cycles and averages:**

| Cycle | Average |
|---|---|
| $(1, 5)$ | $(1+5)/2 = 3$ |
| $(3)$ repeated | 3 |
| $(3, 5)$ | 4 |
| $(5)$ | 5 |

**Answer: MAL = 3.**

**Code check:** a search over the state graph finds the same forbidden set $\lbrace 2, 4 \rbrace$ and a smallest cycle average of 3.

**Key idea:** forbidden latencies give the collision vector. MAL is the smallest average over the cycles of the state diagram.

</details>
