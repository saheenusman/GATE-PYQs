# 2014 CS1 Q43: Speedup of a 6-stage pipeline with stalls

## Question

Consider a 6-stage instruction pipeline, where all stages are perfectly balanced. Assume that there is no cycle-time overhead of pipelining. When an application is executing on this 6-stage pipeline, the speedup achieved with respect to non-pipelined execution if 25% of the instructions incur 2 pipeline stall cycles is _______________________.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Ideal pipelined CPI is 1. Stalls add $0.25 \times 2 = 0.5$ cycles per instruction on average:

$$CPI_{pipe} = 1 + 0.5 = 1.5$$

A non-pipelined machine takes 6 stage-times per instruction, with the same cycle time as one stage (balanced, no overhead). So

$$\text{Speedup} = \frac{6}{1.5} = 4$$

**Key idea:** speedup $=$ pipeline depth $/ (1 + \text{stall cycles per instruction})$.

</details>
