# 2014 CS3 Q9: Highest peak clock frequency among pipelines

## Question

Consider the following processors (ns stands for nanoseconds). Assume that the pipeline registers have zero latency.

- P1: Four-stage pipeline with stage latencies 1 ns, 2 ns, 2 ns, 1 ns.
- P2: Four-stage pipeline with stage latencies 1 ns, 1.5 ns, 1.5 ns, 1.5 ns.
- P3: Five-stage pipeline with stage latencies 0.5 ns, 1 ns, 1 ns, 0.6 ns, 1 ns.
- P4: Five-stage pipeline with stage latencies 0.5 ns, 0.5 ns, 1 ns, 1 ns, 1.1 ns.

Which processor has the highest peak clock frequency?

- (A) P1
- (B) P2
- (C) P3
- (D) P4

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The clock period must be at least the **slowest stage** (the registers add no delay), so the peak frequency is $1/\max(\text{stage latency})$.

| Processor | Slowest stage | Peak frequency |
|---|---|---|
| P1 | 2 ns | 0.5 GHz |
| P2 | 1.5 ns | 0.67 GHz |
| P3 | 1 ns | **1.00 GHz** |
| P4 | 1.1 ns | 0.91 GHz |

P3 has the shortest bottleneck stage, so the highest frequency: **C**.

**Code check:** computing $1/\max$ for each list gives 0.5, 0.667, 1.0, 0.909 GHz.

**Key idea:** the clock period of a pipeline equals its slowest stage latency.

</details>
