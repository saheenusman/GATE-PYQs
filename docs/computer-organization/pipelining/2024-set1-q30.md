# 2024 CS1 Q30: Forwarding in a five-stage pipeline

## Question

Consider a 5-stage pipelined processor with Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Register Writeback (WB) stages. Which of the following statements about forwarding is/are CORRECT?

- (A) In a pipelined execution, forwarding means the result from a source stage of an earlier instruction is passed on to the destination stage of a later instruction
- (B) In forwarding, data from the output of the MEM stage can be passed on to the input of the EX stage of the next instruction
- (C) Forwarding cannot prevent all pipeline stalls
- (D) Forwarding does not require any extra hardware to retrieve the data from the pipeline stages

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** That is the definition: a result is sent straight from a later pipeline stage of the older instruction to the stage of the newer instruction that needs it, without waiting for write-back.
- **(B) True.** For example, a loaded value available at the output of MEM can be forwarded to the EX input of the following instruction.
- **(C) True.** A load followed by an instruction that uses its result (load-use hazard) still needs a one-cycle stall even with forwarding.
- **(D) False.** Forwarding needs **extra hardware**: bypass paths from the pipeline registers, multiplexers at the ALU inputs, and comparison logic to detect dependences.

**Key idea:** forwarding reduces stalls by adding bypass paths and muxes, but it cannot remove all hazards.

</details>
