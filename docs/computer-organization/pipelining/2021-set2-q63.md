# 2021 CS2 Q63: Speedup from operand forwarding in a 5-stage pipeline

## Question

Consider a pipelined processor with 5 stages, Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each stage of the pipeline, except the EX stage, takes one cycle. Assume that the ID stage merely decodes the instruction and the register read is performed in the EX stage. The EX stage takes one cycle for ADD instruction and two cycles for MUL instruction. Ignore pipeline register latencies.

Consider the following sequence of 8 instructions:

ADD, MUL, ADD, MUL, ADD, MUL, ADD, MUL

Assume that every MUL instruction is data-dependent on the ADD instruction just before it and every ADD instruction (except the first ADD) is data-dependent on the MUL instruction just before it. The *Speedup* is defined as follows:

$$\text{Speedup}=\frac{\text{Execution time without operand forwarding}}{\text{Execution time with operand forwarding}}$$

The Speedup achieved in executing the given instruction sequence on the pipelined processor (rounded to 2 decimal places) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1.88**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**With forwarding.** A result is forwarded as soon as its EX ends, so a dependent instruction starts EX right after the previous one finishes EX. The EX stage is then busy all the time.

- Total EX cycles: $4\times1+4\times2=12$.
- The first EX is in cycle 3 (IF 1, ID 2), so the last EX ends in cycle $3+12-1=14$.
- Then MEM (15) and WB (16): **16 cycles**.

**Without forwarding.** The register is written in WB, and the next instruction reads it in EX. So a dependent instruction's EX starts in the cycle **after** the producer's WB.

| instr | EX cycles | MEM | WB |
|---|---|---|---|
| 1 ADD | 3 | 4 | 5 |
| 2 MUL | 6-7 | 8 | 9 |
| 3 ADD | 10 | 11 | 12 |
| 4 MUL | 13-14 | 15 | 16 |
| 5 ADD | 17 | 18 | 19 |
| 6 MUL | 20-21 | 22 | 23 |
| 7 ADD | 24 | 25 | 26 |
| 8 MUL | 27-28 | 29 | **30** |

**30 cycles.**

$$\text{Speedup}=\frac{30}{16}=1.875\approx1.88.$$

A cycle-by-cycle simulation script gives the same 16 and 30. The key accepts 1.87 to 1.88. (If one allowed the register to be written and read in the same cycle, no-forwarding would take 23 cycles and the speedup would be about 1.44, which is outside the key.)

**Key idea:** forwarding lets a dependent instruction use a result right after EX instead of after WB.

</details>
