# 2018 CS Q60: Clock cycles for 100 instructions in a 5-stage pipeline

## Question

The instruction pipeline of a RISC processor has the following stages: Instruction Fetch (IF), Instruction Decode (ID), Operand Fetch (OF), Perform Operation (PO) and Writeback (WB). The IF, ID, OF and WB stages take 1 clock cycle each for every instruction. Consider a sequence of 100 instructions. In the PO stage, 40 instructions take 3 clock cycles each, 35 instructions take 2 clock cycles each, and the remaining 25 instructions take 1 clock cycle each. Assume that there are no data hazards and no control hazards.

The number of clock cycles required for completion of execution of the sequence of instructions is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**219**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**PO is the bottleneck.** Every other stage takes 1 cycle, while PO takes at least 1 cycle, so once the first instruction reaches PO, the PO stage is busy continuously (the next instruction is always waiting in OF).

**Total PO time:**

$$40\times3 + 35\times2 + 25\times1 = 120 + 70 + 25 = 215\text{ cycles}$$

**Add the ends of the pipeline.**
- Before the first PO: IF, ID, OF take $3$ cycles.
- After the last PO: WB takes $1$ cycle.

$$3 + 215 + 1 = 219$$

**Code check:** a stage-by-stage simulation (start time of each stage = max(previous instruction done in that stage, this instruction done in the previous stage)) gave **219**.

**Key idea:** in a pipeline with one slow, variable stage, total time is fill time + sum of the slow stage + drain time.

</details>
