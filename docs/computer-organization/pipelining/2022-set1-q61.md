# 2022 CS Q61: Speedup from a branch predictor

## Question

A processor $X_1$ operating at 2 GHz has a standard 5-stage RISC instruction pipeline having a base CPI (cycles per instruction) of one without any pipeline hazards. For a given program $P$ that has 30% branch instructions, control hazards incur 2 cycles stall for every branch. A new version of the processor $X_2$ operating at same clock frequency has an additional branch predictor unit (BPU) that completely eliminates stalls for correctly predicted branches. There is neither any savings nor any additional stalls for wrong predictions. There are no structural hazards and data hazards for $X_1$ and $X_2$. If the BPU has a prediction accuracy of 80%, the speed up (rounded off to two decimal places) obtained by $X_2$ over $X_1$ in executing $P$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1.43 (accepted range 1.42 to 1.45)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**CPI of $X_1$:** every branch stalls 2 cycles.

$$\text{CPI}_1 = 1 + 0.3 \times 2 = 1.6$$

**CPI of $X_2$:** only the 20% mispredicted branches stall.

$$\text{CPI}_2 = 1 + 0.3 \times 0.2 \times 2 = 1.12$$

**Speedup** (same clock and same instruction count):

$$\frac{1.6}{1.12} \approx 1.4286 \approx 1.43$$

**Key idea:** with equal clock and instruction count, speedup is the ratio of CPIs.

</details>
