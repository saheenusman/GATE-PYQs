# 2025 CS1 Q37: Bits left for the immediate operand

## Question

A processor has 64 general-purpose registers and 50 distinct instruction types. An instruction is encoded in 32-bits. What is the maximum number of bits that can be used to store the immediate operand for the given instruction?

```
ADD R1, #25     // R1 = R1 + 25
```

- (A) 16
- (B) 20
- (C) 22
- (D) 24

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count the bits the other fields need.

| Field | Reasoning | Bits |
|---|---|---|
| Opcode | 50 instruction types need $\lceil \log_2 50 \rceil = 6$ bits | 6 |
| Register R1 | 64 registers need $\log_2 64 = 6$ bits | 6 |
| Immediate | what is left of 32 | $32 - 6 - 6 = $ **20** |

`ADD R1, #25` has **one** register operand (R1 is both source and destination) and one immediate, so only one register field is needed.

| Option | Mistake |
|---|---|
| A, 16 | Subtracts two register fields |
| C, 22 and D, 24 | Subtract too little (for example, a 4-bit opcode, or no register field) |

**Key idea:** immediate width $=$ instruction length $-$ opcode bits $-$ register-field bits.

</details>
