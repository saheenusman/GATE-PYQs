# 2026 CS2 Q44: Maximum C-type opcodes with variable-size opcodes

## Question

Consider a processor that has 16 general purpose registers and it uses 2-byte instruction format for all its instructions. Variable-sized opcodes are permitted. There are three different types of instructions: M-type, R-type, and C-type.

- Each M-type instruction has 2 register operands and a 6-bit immediate operand.
- Each R-type instruction has 3 register operands.
- Each C-type instruction has a register operand and a 6-bit offset value.

If there are 2 unique M-type opcodes and 7 unique R-type opcodes, which one of the following options gives the maximum number of unique opcodes possible for C-type instructions?

- (A) 8
- (B) 4
- (C) 64
- (D) 16

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Setup.** 16 registers need 4 bits each. The instruction has 16 bits.

| Type | Operand bits | Opcode bits |
|---|---|---|
| M | 4 + 4 + 6 = 14 | 2 |
| R | 4 + 4 + 4 = 12 | 4 |
| C | 4 + 6 = 10 | 6 |

**Expanding opcodes (prefix coding):**

1. M uses a 2-bit opcode: $2^2 = 4$ codes. 2 are used, so **2 are free**.
2. Each free 2-bit code can be extended by 2 more bits to a 4-bit R-type opcode: $2 \times 4 = 8$ codes.
3. R-type uses 7, so **1** 4-bit code is free.
4. Extend that one by 2 more bits to a 6-bit C-type opcode: $1 \times 4 = 4$.

So at most **4** C-type opcodes.

**Why the others fail:** 8 and 16 would need more free prefixes than the M and R types leave. 64 is every 6-bit pattern and ignores the codes already taken.

**Key idea:** expanding opcodes: each unused shorter code is a prefix that multiplies by $2^{\text{extra bits}}$.

</details>
