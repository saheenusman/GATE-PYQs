# 2025 CS2 Q61: Clock cycle time from instruction mix and run time

## Question

An application executes $6.4 \times 10^8$ number of instructions in 6.3 seconds. There are four types of instructions, the details of which are given in the table. The duration of a clock cycle in nanoseconds is _________. (rounded off to one decimal place)

| Instruction type | Clock cycles required per instruction (CPI) | Number of instructions executed |
|---|---|---|
| Branch | 2 | $2.25 \times 10^8$ |
| Load | 5 | $1.20 \times 10^8$ |
| Store | 4 | $1.65 \times 10^8$ |
| Arithmetic | 3 | $1.30 \times 10^8$ |

<details class="success" markdown="1">
<summary>Answer</summary>

**3.0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Total clock cycles** $= \sum (\text{CPI} \times \text{count})$:

| Type | CPI $\times$ count | Cycles |
|---|---|---|
| Branch | $2 \times 2.25 \times 10^8$ | $4.5 \times 10^8$ |
| Load | $5 \times 1.20 \times 10^8$ | $6.0 \times 10^8$ |
| Store | $4 \times 1.65 \times 10^8$ | $6.6 \times 10^8$ |
| Arithmetic | $3 \times 1.30 \times 10^8$ | $3.9 \times 10^8$ |
| **Total** | | $21 \times 10^8 = 2.1 \times 10^9$ |

(The instruction counts add up to $6.4 \times 10^8$, matching the statement.)

**Clock cycle time** $=$ total time $/$ total cycles:

$$\frac{6.3 \text{ s}}{2.1 \times 10^9} = 3 \times 10^{-9} \text{ s} = 3.0 \text{ ns}.$$

The average CPI is $2.1 \times 10^9 / 6.4 \times 10^8 \approx 3.28$, which is not needed.

**Key idea:** execution time $=$ (total cycles) $\times$ (cycle time), and total cycles is the sum of CPI times instruction count.

</details>
