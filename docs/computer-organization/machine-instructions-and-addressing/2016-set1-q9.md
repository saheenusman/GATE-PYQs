# 2016 CS1 Q9: Address bus width for a word-addressable 4 GB memory

## Question

A processor can support a maximum memory of 4 GB, where the memory is word-addressable (a word consists of two bytes). The size of the address bus of the processor is at least ______ bits.

<details class="success" markdown="1">
<summary>Answer</summary>

**31**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$$4\ \text{GB} = 2^{32}\ \text{bytes}$$

Each word is $2$ bytes, so the number of words is

$$\frac{2^{32}}{2} = 2^{31}$$

Each word needs its own address, so $31$ address bits are required.

(With byte addressing it would be $32$; word addressing saves one bit.)

**Key idea:** addressable units are words: $2^{32}/2 = 2^{31}$ words, so 31 bits.

</details>
