# 2023 CS Q41: Fill the operands in assembly for a[i] = b[i] * 8

## Question

Consider the given C-code and its corresponding assembly code, with a few operands U1 to U4 being unknown. Some useful information as well as the semantics of each unique assembly instruction is annotated as inline comments in the code. The memory is byte-addressable.

C code:

```c
int a[10], b[10], i;
// int is 32-bit
for (i=0; i<10; i++)
  a[i] = b[i] * 8;
```

Assembly code (`;` starts a comment):

```
;r1-r5 are 32-bit integer registers
;initialize r1=0, r2=10
;initialize r3, r4 with base
;address of a, b
L01: jeq r1, r2, end ;if r1==r2 goto end
L02: lw  r5, 0(r4)   ;r5 <- Mem[r4+0]
L03: shl r5, r5, U1  ;r5 <- r5 << U1
L04: sw  r5, 0(r3)   ;Mem[r3+0] <- r5
L05: add r3, r3, U2  ;r3 <- r3+U2
L06: add r4, r4, U3
L07: add r1, r1, 1
L08: jmp U4          ;goto U4
L09: end
```

Which one of the following options is a CORRECT replacement for operands in the position (U1, U2, U3, U4) in the above assembly code?

- (A) (8, 4, 1, L02)
- (B) (3, 4, 4, L01)
- (C) (8, 1, 1, L02)
- (D) (3, 1, 1, L01)

<details class="success" markdown="1">
<summary>Answer</summary>

**B ((3, 4, 4, L01))**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**U1: the shift amount.** Multiplying by 8 is a left shift by $\log_2 8 = 3$. So $U1 = 3$ (a shift by 8 would multiply by 256).

**U2, U3: pointer steps.** Memory is byte-addressable and an `int` is 32 bits = 4 bytes. To move to the next array element, each base pointer must advance by **4**. So $U2 = U3 = 4$.

**U4: where to jump.** After one iteration the code must go back and test the loop condition `i < 10` again. That test is `jeq r1, r2, end` at `L01`. Jumping to `L02` would skip the check and run past the end of the arrays. So $U4 = \text{L01}$.

Result: $(3, 4, 4, \text{L01})$, option **B**.

**Why the others fail:** A and C shift by 8. C and D advance by 1 byte, and A/C jump to L02.

**Code check:** a C program confirmed that `b[i]*8 == b[i]<<3` for the array and that `sizeof(int)` is 4.

**Key idea:** array stride = element size in bytes. A multiply by $2^k$ is a shift by $k$.

</details>
