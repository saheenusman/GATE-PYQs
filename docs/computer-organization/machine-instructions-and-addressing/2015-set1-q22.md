# 2015 CS1 Q22: What an address field can specify in three-address instructions

## Question

For computers based on three-address instruction formats, each address field can be used to specify which of the following:

- (S1) A memory operand
- (S2) A processor register
- (S3) An implied accumulator register

- (A) Either S1 or S2
- (B) Either S2 or S3
- (C) Only S2 and S3
- (D) All of S1, S2 and S3

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a three-address format (`op dest, src1, src2`) every address field explicitly names an operand location, which is a memory address (S1) or a register (S2).

An **implied accumulator** (S3) is the hallmark of *one-address* machines: the accumulator is not named in any field. With three explicit fields there is nothing implied.

So each field is either S1 or S2: option (A). (B), (C) and (D) all include S3.

**Key idea:** an implied accumulator belongs to one-address formats, not three-address ones.

</details>
