# 2017 CS1 Q11: Addressing mode to access a struct field from its base address

## Question

Consider the C `struct` defined below:

```c
struct data {
   int marks[100];
   char grade;
   int cnumber;
};
struct data student;
```

The base address of `student` is available in register R1. The field `student.grade` can be accessed efficiently using

- (A) Post-increment addressing mode, `(R1)+`
- (B) Pre-decrement addressing mode, `-(R1)`
- (C) Register direct addressing mode, `R1`
- (D) Index addressing mode, `X(R1)`, where `X` is an offset represented in 2's complement 16-bit representation.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Where the field lives.** `grade` comes after `marks[100]`. With 4-byte `int`, that is $100 \times 4 = 400$ bytes from the base, so `student.grade` is at address $R1 + 400$. A constant offset from a base register is exactly **index (displacement) addressing**, `400(R1)`. The offset 400 fits easily in a 16-bit 2's complement value.

**Why the others fail.**

- (A) `(R1)+` uses the address in R1, then increments R1. It reaches the start of the struct (`marks[0]`), not `grade`.
- (B) `-(R1)` decrements R1 first, so it reaches memory *before* the struct.
- (C) Register direct means the operand *is* R1 (the base address value), not memory at an address.

So **(D)**.

**Code check:** `offsetof(struct data, grade)` printed 400 with `sizeof(int) == 4`.

**Key idea:** a field at a fixed offset from a base address is the textbook use of displacement (index) addressing.

</details>
