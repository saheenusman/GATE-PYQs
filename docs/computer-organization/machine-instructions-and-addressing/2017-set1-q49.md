# 2017 CS1 Q49: PC-relative branch offset that jumps back to instruction i

## Question

Consider a RISC machine where each instruction is exactly 4 bytes long. Conditional and unconditional branch instructions use PC-relative addressing mode with Offset specified in bytes to the target location of the branch instruction. Further the Offset is always with respect to the address of the next instruction in the program sequence. Consider the following instruction sequence

| Instr. No. | Instruction |
|---|---|
| i | `add R2, R3, R4` |
| i+1 | `sub R5, R6, R7` |
| i+2 | `cmp R1, R9, R10` |
| i+3 | `beq R1, Offset` |

If the target of the branch instruction is `i`, then the decimal value of the `Offset` is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**-16**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Addresses.** Let instruction $i$ be at address $A$. Instructions are 4 bytes long, so

| Instruction | Address |
|---|---|
| $i$ | $A$ |
| $i+1$ | $A+4$ |
| $i+2$ | $A+8$ |
| $i+3$ (the `beq`) | $A+12$ |
| next instruction, $i+4$ | $A+16$ |

**Offset.** The offset is measured from the address of the *next* instruction (the PC value after fetching `beq`), which is $A+16$:

$$\text{target} = (A + 16) + \text{Offset} = A \;\Rightarrow\; \text{Offset} = -16$$

The answer is **-16**.

**Common slip.** Measuring from the branch itself gives $-12$. The question states the offset is relative to the next instruction, so it is $-16$.

**Key idea:** PC-relative offset $=$ target address $-$ (address of the branch $+$ instruction size).

</details>
