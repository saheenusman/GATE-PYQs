# 2007 CS Q73: Return address pushed on an interrupt during INC R3

## Question

(Common data of Q.71.) Assume that the memory is byte addressable and the word size is 32 bits. If an interrupt occurs during the execution of the instruction "INC R3", what return address will be pushed on to the stack?

- (A) 1005
- (B) 1020
- (C) 1024
- (D) 1040

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A word is 4 bytes, so instruction sizes in bytes are 8 (2 words) or 4 (1 word). Starting at byte address 1000:

| Instruction | Address |
|---|---|
| `MOV R1, (3000)` | 1000 (8 bytes) |
| `LOOP: MOV R2, (R3)` | 1008 |
| `ADD R2, R1` | 1012 |
| `MOV (R3), R2` | 1016 |
| `INC R3` | 1020 |
| `DEC R1` | 1024 |
| `BNZ LOOP` | 1028 (8 bytes) |
| `HALT` | 1036 |

While `INC R3` (at 1020) is executing, the program counter already holds the address of the next instruction, `DEC R1` at **1024**. That is what is pushed as the return address: (C).

- (A) 1005 is not an instruction boundary.
- (B) 1020 is the address of `INC R3` itself (it would re-execute the instruction).
- (D) 1040 is past the end of the program.

**Code check:** Python address computation from the instruction sizes: `INC R3` at 1020, `DEC R1` at 1024.

**Key idea:** on an interrupt the PC (already pointing at the next instruction) is saved, so the return address is the address after the interrupted instruction.
