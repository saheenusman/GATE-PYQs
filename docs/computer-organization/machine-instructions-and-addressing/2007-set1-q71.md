# 2007 CS Q71: Data memory references of a loop program (word addressable)

## Question

**Common data for Questions 71, 72, 73.** Consider the following program segment. Here R1, R2 and R3 are the general purpose registers.

| Instruction | Operation | Instruction size (no. of words) |
|---|---|---|
| MOV R1, (3000) | R1 <- M[3000] | 2 |
| LOOP: MOV R2, (R3) | R2 <- M[R3] | 1 |
| ADD R2, R1 | R2 <- R1 + R2 | 1 |
| MOV (R3), R2 | M[R3] <- R2 | 1 |
| INC R3 | R3 <- R3 + 1 | 1 |
| DEC R1 | R1 <- R1 - 1 | 1 |
| BNZ LOOP | Branch on not zero | 2 |
| HALT | Stop | 1 |

Assume that the content of memory location 3000 is 10 and the content of the register R3 is 2000. The content of each of the memory locations from 2000 to 2010 is 100. The program is loaded from the memory location 1000. All the numbers are in decimal.

**Q.71** Assume that the memory is word addressable. The number of memory references for accessing the data in executing the program completely is

- (A) 10
- (B) 11
- (C) 20
- (D) 21

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only **data** accesses count (not instruction fetches).

- `MOV R1, (3000)` reads $M[3000]$ once: 1 reference. $R_1 = 10$.
- The loop body runs until `DEC R1` makes $R_1 = 0$, which is **10 iterations**. Each iteration has two data references: the read in `MOV R2, (R3)` and the write in `MOV (R3), R2`: 2 per iteration.

Total $= 1 + 10 \times 2 = 21$: (D).

- (A) 10 and (B) 11 count only one access per iteration.
- (C) 20 forgets the initial read of location 3000.

**Code check:** Python trace of the program: 21 data memory references.

**Key idea:** count data references only: one initial load, plus a read and a write per loop iteration.
