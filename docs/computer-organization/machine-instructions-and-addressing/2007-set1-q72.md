# 2007 CS Q72: Memory contents after the loop program

## Question

(Common data of Q.71.) Assume that the memory is word addressable. After the execution of this program, the content of memory location 2010 is

- (A) 100
- (B) 101
- (C) 102
- (D) 110

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In iteration $k$ ($k = 0, \dots, 9$) the program does $M[2000 + k] \leftarrow M[2000 + k] + R_1$ with $R_1 = 10 - k$. So locations $2000$ to $2009$ are updated:
$M[2000] = 110,\ M[2001] = 109,\ \dots,\ M[2009] = 101$.

The loop stops after 10 iterations, when $R_3$ has reached $2010$ and $R_1 = 0$. Location $2010$ is never touched, so it still holds $100$: (A).

- (B) 101 is $M[2009]$ (the last location updated).
- (D) 110 is $M[2000]$.
- (C) 102 is not produced by any iteration.

**Code check:** Python trace: final $M[2010] = 100$, $M[2009] = 101$, $M[2000] = 110$.

**Key idea:** a loop that updates $M[R_3]$ and then increments $R_3$ ten times touches ten locations, 2000 to 2009.

</details>
