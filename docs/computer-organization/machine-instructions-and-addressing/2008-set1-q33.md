# 2008 CS Q33: Properties of the auto-increment addressing mode

## Question

Which of the following is/are true of the auto-increment addressing mode?

- I. It is useful in creating self-relocating code
- II. If it is included in an Instruction Set Architecture, then an additional ALU is required for effective address calculation
- III. The amount of increment depends on the size of the data item accessed

Options:

- (A) I only
- (B) II only
- (C) III only
- (D) II and III only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In auto-increment mode the operand address is in a register, and the register is incremented after the access.

- **I. False.** Self-relocating (position-independent) code relies on PC-relative addressing, not on auto-increment.
- **II. False.** The effective address is simply the register's value. The increment can be done by a small incrementer or the existing adder in parallel, so no additional ALU is required for the effective address.
- **III. True.** The register is advanced by the size of the item accessed (1, 2, 4 or 8 bytes), so that it points at the next item. That is why the mode suits array and stack walks.

Only III is true: (C).

**Key idea:** auto-increment steps the pointer by the operand size, which makes it ideal for walking arrays.

</details>
