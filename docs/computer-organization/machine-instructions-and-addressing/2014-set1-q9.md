# 2014 CS1 Q9: Maximum immediate operand in a 32-bit instruction

## Question

A machine has a 32-bit architecture, with 1-word long instructions. It has 64 registers, each of which is 32 bits long. It needs to support 45 instructions, which have an immediate operand in addition to two register operands. Assuming that the immediate operand is an unsigned integer, the maximum value of the immediate operand is ____________.

<details class="success" markdown="1">
<summary>Answer</summary>

**16383**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each instruction is one 32-bit word. Fields:

| Field | Bits |
|---|---|
| Opcode (45 instructions, $2^5 < 45 \le 2^6$) | 6 |
| Register 1 (64 registers) | 6 |
| Register 2 | 6 |
| Immediate | $32 - 18 = 14$ |

An unsigned 14-bit value has maximum $2^{14} - 1 = 16383$.

**Code check:** `2**(32-6-6-6) - 1` gives `16383`.

**Key idea:** the opcode needs $\lceil \log_2 45 \rceil = 6$ bits; the immediate gets what is left.

</details>
