# 2024 CS1 Q55: Best number of cores with parallel overhead

## Question

The baseline execution time of a program on a 2 GHz single core machine is 100 nanoseconds (ns). The code corresponding to 90% of the execution time can be fully parallelized. The overhead for using an additional core is 10 ns when running on a multicore system. Assume that all cores in the multicore system run their share of the parallelized code for an equal amount of time.

The number of cores that minimize the execution time of the program is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The serial part takes $10$ ns. The parallel part takes $90/n$ ns on $n$ cores. Each *additional* core costs 10 ns of overhead, so the overhead is $10(n-1)$.

$$T(n) = 10 + \frac{90}{n} + 10(n-1).$$

| $n$ | $T(n)$ (ns) |
|---|---|
| 1 | 100 |
| 2 | 65 |
| **3** | **60** |
| 4 | 62.5 |
| 5 | 68 |

The minimum is at $n = 3$. (If the overhead is read as $10n$ instead, every value shifts by 10 and $n = 3$ is still the minimum.) The 2 GHz clock is not needed.

**Key idea:** more cores shrink the parallel part but add overhead, so the best point is where the two trends balance. Here $90/n$ and $10n$ balance near $n = 3$.

</details>
