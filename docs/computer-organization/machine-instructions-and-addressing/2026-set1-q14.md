# 2026 CS1 Q14: Addressing modes and data structures

## Question

Match each addressing mode in List I with a data element or an element of a data structure (in a high-level language) in List II:

| List I | List II |
|---|---|
| P. Immediate | 1. Element of an array |
| Q. Indirect | 2. Pointer |
| R. Base with index | 3. Element of a record |
| S. Base with offset/displacement | 4. Constant |

- (A) P–4, Q–3, R–1, S–2
- (B) P–4, Q–2, R–1, S–3
- (C) P–1, Q–4, R–3, S–2
- (D) P–2, Q–3, R–1, S–4

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Match each mode with what it computes:**

| Mode | Effective address | Fits |
|---|---|---|
| Immediate | none, value is in the instruction | **Constant** (4) |
| Indirect | EA = memory[address] | **Pointer** (2) |
| Base + index | EA = base + index reg | **Array element** (1) |
| Base + displacement | EA = base + fixed offset | **Record field** (3) |

- An array element has a *variable* position, so a base (array start) plus an index register fits.
- A record field has a *fixed* offset from the record start, so base plus displacement fits.
- A pointer holds an address, so you go through it once more: indirect.

**Why the others fail:** (A) pairs indirect with a record and displacement with a pointer. (C) pairs immediate with an array. (D) pairs immediate with a pointer.

**Key idea:** immediate = constant, indirect = pointer, base+index = array, base+displacement = record field.

</details>
