# 2024 CS2 Q57: Opcode space with a fixed 32-bit instruction format

## Question

A processor with 16 general purpose registers uses a 32-bit instruction format. The instruction format consists of an opcode field, an addressing mode field, two register operand fields, and a 16-bit scalar field. If 8 addressing modes are to be supported, the maximum number of unique opcodes possible for every addressing mode is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**32**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Add up the fixed fields (in bits):

| Field | Bits |
|---|---|
| Addressing mode (8 modes) | $\log_2 8 = 3$ |
| Two register operands (16 registers each) | $2 \times \log_2 16 = 8$ |
| Scalar | 16 |
| **Total fixed** | **27** |

The opcode gets the rest: $32 - 27 = 5$ bits, so $2^5 = 32$ opcodes. The opcode field is separate from the mode field, so every addressing mode can use all 32 opcodes.

**Key idea:** subtract all the other fields from the instruction length. The remaining bits are the opcode.

</details>
