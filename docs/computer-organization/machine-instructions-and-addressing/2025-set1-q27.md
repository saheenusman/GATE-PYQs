# 2025 CS1 Q27: What arithmetic the partial data path can perform

## Question

A partial data path of a processor is given in the figure, where RA, RB, and RZ are 32-bit registers. Which option(s) is/are CORRECT related to arithmetic operations using the data path as shown?

![Partial data path. Register RA (32 bit) and a 32-bit immediate value feed Mux_A, which has a select input "Select RA/immediate". Register RB (32 bit) and a 32-bit immediate value feed Mux_B, which has a select input "Select RB/immediate". The outputs of the two multiplexers are the two inputs of the ALU, which has an ALU control input. The ALU output goes to register RZ (32 bit).](../../assets/2025/set1-q27.png)

- (A) The data path can implement arithmetic operations involving two registers.
- (B) The data path can implement arithmetic operations involving one register and one immediate value.
- (C) The data path can implement arithmetic operations involving two immediate values.
- (D) The data path can only implement arithmetic operations involving one register and one immediate value.

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each ALU input has its own multiplexer with its own select line, so the two choices are **independent**:

| Mux_A selects | Mux_B selects | ALU computes on |
|---|---|---|
| RA | RB | two registers |
| RA | immediate | register and immediate |
| immediate | RB | immediate and register |
| immediate | immediate | two immediate values |

| Option | Verdict |
|---|---|
| **A** | True: first row |
| **B** | True: second and third rows |
| **C** | True: last row. Both muxes can pick an immediate, and the figure shows an immediate input into each mux |
| D | False: it also supports two registers and two immediates, so it is not limited to one of each |

**Key idea:** two separate multiplexers mean any combination of register or immediate on each ALU input.

</details>
