# 2025 CS2 Q28: What belongs to the Instruction Set Architecture

## Question

Which of the following is/are part of an Instruction Set Architecture of a processor?

- (A) The size of the cache memory
- (B) The clock frequency of the processor
- (C) The number of cache memory levels
- (D) The total number of registers

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The **ISA** is the programmer-visible interface: instructions, addressing modes, data types, and the **architectural registers** that instructions name.

| Option | In the ISA? | Reason |
|---|---|---|
| A, cache size | No | A hardware (microarchitecture) detail. A program runs unchanged with any cache size |
| B, clock frequency | No | An implementation property |
| C, number of cache levels | No | An implementation detail |
| **D, number of registers** | **Yes** | Instructions name registers directly, so their number and width are part of the interface |

**Key idea:** the ISA contains what software can see and use. Cache and clock are implementation choices.

</details>
