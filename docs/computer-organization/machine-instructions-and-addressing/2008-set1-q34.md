# 2008 CS Q34: Properties of the RFE (Return From Exception) instruction

## Question

Which of the following must be true for the RFE (Return From Exception) instruction on a general purpose processor?

- I. It must be a trap instruction
- II. It must be a privileged instruction
- III. An exception cannot be allowed to occur during execution of an RFE instruction

Options:

- (A) I only
- (B) II only
- (C) I and II only
- (D) I, II and III only

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I. Not required.** A trap instruction is one that *causes* a transfer into the exception handler. RFE does the opposite: it returns from the handler. It need not be a trap.
- **II. Must be true.** RFE restores the processor status (including the user/kernel mode bit) saved at the exception. If user programs could execute it, they could switch themselves into kernel mode. So it must be **privileged**.
- **III. Not required.** Nothing forces the hardware to forbid every exception while an RFE executes (for example, the RFE instruction itself may take a page fault on fetch, or the restored state may raise another fault). The statement is too strong to be a "must".

Only II must hold: (B).

**Classification note:** exception return is on the border between computer organization and operating systems. I filed it under `machine-instructions-and-addressing` because RFE is an instruction-set question.

**Key idea:** the instruction that restores the mode bit must be privileged.

</details>
