# 2023 CS Q45: IEEE-754 multiplication

## Question

Consider the IEEE-754 single precision floating point numbers $P = \texttt{0xC1800000}$ and $Q = \texttt{0x3F5C2EF4}$.

Which one of the following corresponds to the product of these numbers (i.e., $P \times Q$), represented in the IEEE-754 single precision format?

- (A) 0x404C2EF4
- (B) 0x405C2EF4
- (C) 0xC15C2EF4
- (D) 0xC14C2EF4

<details class="success" markdown="1">
<summary>Answer</summary>

**C (0xC15C2EF4)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Decode $P$ = 0xC1800000.** Sign 1 (negative). Exponent field $10000011_2 = 131$, so the exponent is $131 - 127 = 4$. Mantissa 0, so the value is $-1.0 \times 2^4 = -16$.

**Decode $Q$ = 0x3F5C2EF4.** Sign 0. Exponent field $01111110_2 = 126$, so the exponent is $-1$. Mantissa is $\texttt{5C2EF4}$, so $Q = 1.\texttt{5C2EF4}_{\text{frac}} \times 2^{-1} \approx 0.86$.

**Multiply.** Because $P$ is exactly $-2^4$, the product only changes the sign and exponent of $Q$:

- Sign: negative, so 1.
- Exponent: $126 + 4 = 130 = 10000010_2$.
- Mantissa: unchanged, $\texttt{5C2EF4}$.

Assemble: $1\ |\ 10000010\ |\ \texttt{5C2EF4}$ gives bits `1100 0001 0101 1100 0010 1110 1111 0100`, which is **0xC15C2EF4**.

**Code check:** Python's single-precision `struct` pack of $-16 \times 0.86009\ldots$ gives `C15C2EF4`.

**Why the others fail:** A and B are positive (wrong sign). D has a different mantissa.

**Key idea:** multiplying by a power of two only adds to the exponent field.

</details>
