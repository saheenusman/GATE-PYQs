# 2025 CS1 Q25: Valid 2's complement forms of -6

## Question

The number $-6$ can be represented as 1010 in 4-bit 2's complement representation. Which of the following is/are CORRECT 2's complement representation(s) of $-6$?

- (A) 1000 1010 in 8-bits
- (B) 1111 1010 in 8-bits
- (C) 1000 0000 0000 1010 in 16-bits
- (D) 1111 1111 1111 1010 in 16-bits

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

To widen a 2's complement number, **sign-extend**: copy the sign bit into the new high bits. Here the sign bit of 1010 is 1, so pad with 1s.

| Width | Correct form | Value check |
|---|---|---|
| 8 bits | 1111 1010 | $-128 + 122 = -6$ |
| 16 bits | 1111 1111 1111 1010 | $-65536 + 65530 = -6$ |

| Option | Verdict |
|---|---|
| A: 1000 1010 | Pads with a 1 followed by 0s (sign-magnitude style). Its value is $-128 + 10 = -118$ |
| **B: 1111 1010** | Correct |
| C: 1000 0000 0000 1010 | Value is $-32768 + 10 = -32758$ |
| **D: 1111 1111 1111 1010** | Correct |

**Key idea:** sign extension keeps the value by repeating the sign bit. Padding with zeros or a lone 1 changes the value.

</details>
