# 2026 CS1 Q36: Adding two IEEE 754 single-precision numbers

## Question

Consider the real valued variables X, Y and Z represented using the IEEE 754 single-precision floating-point format. The binary representations of X and Y in hexadecimal notation are as follows:

X: `35C00000`  Y: `34A00000`

Let $Z = X + Y$. Which one of the following is the binary representation of $Z$, in hexadecimal notation?

- (A) `35C80000`
- (B) `35CC0000`
- (C) `35E80000`
- (D) `35EC0000`

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Format.** 1 sign bit, 8 exponent bits (bias 127), 23 fraction bits. Value $= 1.f \times 2^{e-127}$.

**Decode X = `35C00000`:**

- Bits: `0 01101011 1000...`
- $e = 107$, so exponent $= -20$. Mantissa $= 1.1_2 = 1.5$.
- $X = 1.5 \times 2^{-20}$.

**Decode Y = `34A00000`:**

- Bits: `0 01101001 0100...`
- $e = 105$, so exponent $= -22$. Mantissa $= 1.01_2 = 1.25$.
- $Y = 1.25 \times 2^{-22}$.

**Add.** Align to $2^{-22}$: $X = 6 \times 2^{-22}$.

$Z = (6 + 1.25) \times 2^{-22} = 7.25 \times 2^{-22} = 1.8125 \times 2^{-20}$

The mantissa $1.8125 = 1.1101_2$, exponent stays $-20$, so $e = 107$ (`01101011`).

**Encode:** `0 01101011 1101 0000...` becomes `0011 0101 1110 1000 0000...` which is **`35E80000`**.

**Key idea:** align exponents, add mantissas, renormalize, then repack sign, exponent and fraction.

</details>
