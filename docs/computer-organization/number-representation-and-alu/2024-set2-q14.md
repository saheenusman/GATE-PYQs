# 2024 CS2 Q14: Largest IEEE 754 single-precision number

## Question

The format of a single-precision floating-point number as per the IEEE 754 standard is: Sign (1 bit), Exponent (8 bits), Mantissa (23 bits).

Choose the largest floating-point number among the following options.

| Option | Sign | Exponent | Mantissa |
|---|---|---|---|
| (A) | 0 | 0111 1111 | 1111 1111 1111 1111 1111 111 |
| (B) | 0 | 1111 1110 | 1111 1111 1111 1111 1111 111 |
| (C) | 0 | 1111 1111 | 1111 1111 1111 1111 1111 111 |
| (D) | 0 | 0111 1111 | 0000 0000 0000 0000 0000 000 |

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The value of a normal number is $(-1)^s \times 1.m \times 2^{e - 127}$.

| Option | Exponent field | Value |
|---|---|---|
| (A) | $0111\,1111 = 127$ | $\approx 1.99999988 \times 2^0 \approx 2$ |
| (B) | $1111\,1110 = 254$ | $\approx 1.99999988 \times 2^{127} \approx 3.4 \times 10^{38}$ |
| (C) | $1111\,1111 = 255$ | **not a number** (all-ones exponent with non-zero mantissa is NaN) |
| (D) | $127$ | $1.0 \times 2^0 = 1$ |

An all-ones exponent is reserved for infinity (zero mantissa) and NaN (non-zero mantissa), so (C) is a NaN and cannot be compared as "largest". Among actual numbers, (B) is the biggest. It is in fact the largest finite single-precision number.

**Key idea:** exponent 255 is reserved. The largest normal exponent is 254.

</details>
