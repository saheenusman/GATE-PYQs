# 2017 CS2 Q12: Decimal value of a given 32-bit IEEE-754 single precision number

## Question

Given the following binary number in 32-bit (single precision) IEEE-754 format:

$$00111110011011010000000000000000$$

The decimal value closest to this floating-point number is

- (A) $1.45 \times 10^{1}$
- (B) $1.45 \times 10^{-1}$
- (C) $2.27 \times 10^{-1}$
- (D) $2.27 \times 10^{1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split the 32 bits** as sign (1) | exponent (8) | fraction (23):

| Field | Bits | Value |
|---|---|---|
| Sign | `0` | positive |
| Exponent | `01111100` | $124$, so the true exponent is $124 - 127 = -3$ |
| Fraction | `11011010000000000000000` | $0.1101101_2 = 0.8515625$ |

**Value.** With the hidden leading 1:

$$(1 + 0.8515625)\times 2^{-3} = 1.8515625 \times 0.125 = 0.2314453\ldots \approx 2.31\times10^{-1}$$

The closest option is $2.27\times10^{-1}$: **(C)**.

**Why the others are far.** (A) $14.5$ and (D) $22.7$ are about 100 times too large. (B) $0.145$ is off by $0.086$, while (C) $0.227$ is off by $0.004$.

**Code check:** `struct.unpack('>f', ...)` on the 32 bits gave $0.2314453125$. Distances to the options: A $14.27$, B $0.0864$, C $0.0044$, D $22.47$.

**Key idea:** value $=(-1)^{s}\times(1.\text{fraction})\times 2^{E-127}$.

</details>
