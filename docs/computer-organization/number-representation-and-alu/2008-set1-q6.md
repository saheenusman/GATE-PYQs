# 2008 CS Q6: Radix in which the square root of 121 is 11

## Question

Let $r$ denote the number system radix. The only value(s) of $r$ that satisfy the equation $\sqrt{121_r} = 11_r$ is/are

- (A) decimal 10
- (B) decimal 11
- (C) decimal 10 and 11
- (D) any value $> 2$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In radix $r$: $121_r = r^2 + 2r + 1 = (r+1)^2$ and $11_r = r + 1$. So

$$\sqrt{121_r} = \sqrt{(r+1)^2} = r + 1 = 11_r,$$

which holds for **every** radix in which the digits used are legal. The digit $2$ is used, so $r \ge 3$, i.e. any $r > 2$: (D).

- (A), (B) and (C) wrongly single out particular values.

**Code check:** for $r = 3, 4, 5, 10, 11, 12$ the program gave $\sqrt{121_r} = r+1 = 11_r$ in every case.

**Classification note:** this is positional number notation, so I filed it under `number-representation-and-alu`.

**Key idea:** $121_r = (r+1)^2$ in any radix, so its square root is $11_r$ whenever the digits are valid.

</details>
