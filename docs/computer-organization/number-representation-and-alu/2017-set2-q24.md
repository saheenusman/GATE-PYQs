# 2017 CS2 Q24: Base b in which x^2 - 13x + 36 = 0 has roots 5 and 6

## Question

Consider a quadratic equation $x^2 - 13x + 36 = 0$ with coefficients in a base $b$. The solutions of this equation in the same base $b$ are $x = 5$ and $x = 6$. Then $b =$ ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read the coefficients in base $b$.** $13_b = 1\cdot b + 3 = b+3$ and $36_b = 3b + 6$. So the equation is

$$x^2 - (b+3)\,x + (3b+6) = 0.$$

**Sum of roots.** $5 + 6 = 11 = b + 3 \Rightarrow b = 8$.

**Product of roots.** $5 \times 6 = 30 = 3b + 6 \Rightarrow b = 8$.

Both conditions agree, so $b = 8$. Check: $25 - 11\cdot5 + 30 = 0$ and $36 - 11\cdot 6 + 30 = 0$.

**Code check:** testing every base from 7 to 39 (the digit 6 needs $b \ge 7$) with both roots, only $b = 8$ works.

**Key idea:** use the sum and product of roots, and write each coefficient as a base-$b$ polynomial in $b$.

</details>
