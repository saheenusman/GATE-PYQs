# 2021 CS2 Q28: Binary fraction equal to a decimal with unknown digits

## Question

If $x$ and $y$ are two decimal digits and $(0.1101)_2=(0.8xy5)_{10}$, the decimal value of $x+y$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Convert the binary fraction:

$$(0.1101)_2=\tfrac12+\tfrac14+\tfrac1{16}=0.5+0.25+0.0625=0.8125.$$

Compare with $0.8xy5$: $x=1$ and $y=2$, so $x+y=3$.

**Key idea:** each fractional bit has weight $2^{-k}$; add the weights of the 1 bits.

</details>
