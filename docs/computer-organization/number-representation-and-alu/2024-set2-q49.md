# 2024 CS2 Q49: Numbers equal to 224 in base 5

## Question

Which of the following is/are EQUAL to $224$ in radix-5 (i.e., base-5) notation?

- (A) 64 in radix-10
- (B) 100 in radix-8
- (C) 50 in radix-16
- (D) 121 in radix-7

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Convert $224_5$ to decimal:** $2 \times 25 + 2 \times 5 + 4 = 64$.

| Option | Value in decimal |
|---|---|
| (A) $64_{10}$ | 64 ✓ |
| (B) $100_8$ | $1 \times 64 = 64$ ✓ |
| (C) $50_{16}$ | $5 \times 16 = 80$ ✗ |
| (D) $121_7$ | $49 + 14 + 1 = 64$ ✓ |

**Key idea:** convert everything to decimal and compare.

</details>
