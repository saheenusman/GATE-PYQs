# 2021 CS2 Q54: Little-endian value that is 255 more than the big-endian value

## Question

If the numerical value of a 2-byte unsigned integer on a little endian computer is 255 more than that on a big endian computer, which of the following choices represent(s) the unsigned integer on a little endian computer?

- (A) 0x6665
- (B) 0x0001
- (C) 0x4243
- (D) 0x0100

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the two bytes in memory be $a$ (lower address) followed by $b$.

- Big endian value: $256a+b$.
- Little endian value: $256b+a$.

The little-endian value is 255 more:

$$256b+a=256a+b+255\ \Rightarrow\ 255(b-a)=255\ \Rightarrow\ b=a+1.$$

The little-endian value written in hex is $b\,a$ (high byte $b$, low byte $a$), so its **high byte must be exactly one more than its low byte**.

| option | high byte $b$ | low byte $a$ | $b=a+1$? |
|---|---|---|---|
| (A) 0x6665 | 0x66 | 0x65 | yes |
| (B) 0x0001 | 0x00 | 0x01 | no ($b=a-1$) |
| (C) 0x4243 | 0x42 | 0x43 | no ($b=a-1$) |
| (D) 0x0100 | 0x01 | 0x00 | yes |

A script that byte-swaps each value and subtracts confirms it: 0x6665 and 0x0100 give $+255$, and 0x0001 and 0x4243 give $-255$.

**Key idea:** the same two bytes read big endian and little endian are the byte-swapped values of each other.

</details>
