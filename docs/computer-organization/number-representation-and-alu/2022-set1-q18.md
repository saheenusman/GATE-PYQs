# 2022 CS Q18: Overflow in 4-bit 2's complement addition

## Question

Let R1 and R2 be two 4-bit registers that store numbers in 2's complement form. For the operation R1+R2, which one of the following values of R1 and R2 gives an arithmetic overflow?

- (A) R1 = 1011 and R2 = 1110
- (B) R1 = 1100 and R2 = 1010
- (C) R1 = 0011 and R2 = 0100
- (D) R1 = 1001 and R2 = 1111

<details class="success" markdown="1">
<summary>Answer</summary>

**B (R1 = 1100 and R2 = 1010)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**4-bit 2's complement range:** $-8$ to $+7$. Overflow happens when the true sum is outside this range, which happens when both operands have the same sign and the result has the opposite sign.

| Option | Values | True sum | Fits in $[-8, 7]$? |
| --- | --- | --- | --- |
| (A) | $-5 + (-2)$ | $-7$ | yes |
| (B) | $-4 + (-6)$ | $-10$ | **no** |
| (C) | $3 + 4$ | $7$ | yes |
| (D) | $-7 + (-1)$ | $-8$ | yes |

In (B): $1100 + 1010 = 1\,0110$. The 4-bit result is $0110 = +6$, which is positive although both inputs were negative. That is overflow.

**Key idea:** overflow is detected by the sign rule (or by comparing the carry into and out of the sign bit), not by the carry out alone.

</details>
