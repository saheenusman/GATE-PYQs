# 2026 CS2 Q34: Decoding an IEEE 754 single-precision number

## Question

The 32-bit IEEE 754 single precision representation of a number is `0xC2710000`. The number in decimal representation is ________. (rounded off to two decimal places)

<details class="success" markdown="1">
<summary>Answer</summary>

**−60.25**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Bits of `C2710000`:** `1100 0010 0111 0001 0000 ...`

| Field | Bits | Value |
|---|---|---|
| Sign | `1` | negative |
| Exponent | `10000100` | $132$, so $132 - 127 = 5$ |
| Fraction | `1110001 0000...` | $0.5 + 0.25 + 0.125 + 2^{-7} = 0.8828125$ |

Mantissa $= 1.8828125$.

Value $= -1.8828125 \times 2^{5} = -60.25$.

**Sanity check:** $60.25 = 111100.01_2 = 1.1110001_2 \times 2^5$. Matches.

**Key idea:** subtract the bias 127 from the exponent field, add the hidden 1 to the fraction.

</details>
