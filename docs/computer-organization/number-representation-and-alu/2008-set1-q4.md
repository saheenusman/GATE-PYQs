# 2008 CS Q4: Meaning of the all-zero word in IEEE floating point

## Question

In the IEEE floating point representation the hexadecimal value `0x00000000` corresponds to

- (A) the normalized value $2^{-127}$
- (B) the normalized value $2^{-126}$
- (C) the normalized value $+0$
- (D) the special value $+0$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In IEEE 754 single precision, `0x00000000` has sign bit $0$, exponent field $0$ and fraction $0$. An exponent field of all zeros is **reserved**: it denotes zero (fraction $= 0$) or a denormalized number (fraction $\ne 0$). So this word is the **special value $+0$**: (D).

- (A) and (B) would be normalized numbers, but a normalized number needs an exponent field from $1$ to $254$. The smallest normalized value is $2^{-126}$ (exponent field $1$, fraction $0$), which is not the all-zero word.
- (C) is wrong because zero cannot be normalized: a normalized number has an implied leading $1$, so it is never zero.

**Key idea:** exponent field $0$ and fraction $0$ is the special value $\pm 0$, not a normalized number.

</details>
