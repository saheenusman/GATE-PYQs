# 2014 CS2 Q45: IEEE-754 single precision encoding of -14.25

## Question

The value of a *float* type variable is represented using the single-precision 32-bit floating point format of IEEE-754 standard that uses 1 bit for sign, 8 bits for biased exponent and 23 bits for mantissa. A *float* type variable $X$ is assigned the decimal value of $-14.25$. The representation of $X$ in hexadecimal notation is

- (A) C1640000H
- (B) 416C0000H
- (C) 41640000H
- (D) C16C0000H

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Convert:** $14.25 = 1110.01_2 = 1.11001_2 \times 2^3$.

- Sign: negative, so **1**.
- Exponent: $3 + 127 = 130 = 10000010_2$.
- Mantissa (23 bits): `11001` followed by 18 zeros.

$$1\ 10000010\ 11001000000000000000000$$

Regroup in fours: `1100 0001 0110 0100 0000 ...` $=$ **C1640000** in hex.

**Code check:** `struct.pack('>f', -14.25).hex()` gives `c1640000`.

Wrong options:

- (B) `416C0000` has sign 0 and mantissa `1101100...`: $+14.75$.
- (C) `41640000` has sign 0: it is $+14.25$.
- (D) `C16C0000` has the right sign but mantissa `1101100...`: $-14.75$.

**Key idea:** $(-1)^s \times 1.m \times 2^{e-127}$; normalise, add the bias 127, and regroup the bits.

</details>
