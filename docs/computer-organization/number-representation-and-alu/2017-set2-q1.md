# 2017 CS2 Q1: Octal form of the 16-bit hexadecimal value BCA9

## Question

The representation of the value of a 16-bit unsigned integer $X$ in hexadecimal number system is BCA9. The representation of the value of $X$ in octal number system is

- (A) 571244
- (B) 736251
- (C) 571247
- (D) 136251

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Hex to binary.** Each hex digit is 4 bits:

$$\text{B}=1011,\ \text{C}=1100,\ \text{A}=1010,\ 9=1001 \;\Rightarrow\; 1011\,1100\,1010\,1001$$

**Binary to octal.** Group the 16 bits in threes **from the right** (the leftmost group has one bit):

$$1\ |\ 011\ |\ 110\ |\ 010\ |\ 101\ |\ 001 \;=\; 1\,3\,6\,2\,5\,1$$

So $X = 136251_8$: **(D)**.

**Why the others fail.** Each of (A), (B), (C) has a different decimal value than $\text{BCA9}_{16} = 48297$ (they are $193188$, $244905$ and $193191$). They come from grouping the bits from the left, or from reading the wrong bit pattern.

**Code check:** `format(0xBCA9, 'o')` gave `136251`, and the three other options evaluate to the decimal values above.

**Key idea:** convert hex to binary, then regroup in threes starting from the least significant bit.

</details>
