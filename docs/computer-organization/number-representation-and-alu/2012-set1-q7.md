# 2012 CS Q7: IEEE single precision form of 0.5

## Question

The decimal value $0.5$ in IEEE single precision floating point representation has

- (A) fraction bits of 000...000 and exponent value of 0
- (B) fraction bits of 000...000 and exponent value of $-1$
- (C) fraction bits of 100...000 and exponent value of 0
- (D) no exact representation

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write $0.5 = 1.0 \times 2^{-1}$. IEEE single precision stores a leading $1$ implicitly, so:

- fraction bits: all $0$ (the mantissa is exactly $1.0$)
- exponent value: $-1$ (stored as $-1 + 127 = 126$)

That is (B).

- (A) would encode $1.0 \times 2^{0} = 1$.
- (C) would encode $1.1_2 \times 2^{0} = 1.5$.
- (D) false: $0.5$ is a power of two, so it is exact.

**Code check:** packing $0.5$ as a 32-bit float gives `0 01111110 000...0` (hex `3F000000`): sign $0$, exponent field $126$, fraction all zeros.

**Key idea:** the value is $(-1)^s \times 1.f \times 2^{e - 127}$; powers of two have an all-zero fraction.

</details>
