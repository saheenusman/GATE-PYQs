# 2016 CS1 Q33: Addition time of a carry lookahead adder with fan-in 2

## Question

Consider a carry lookahead adder for adding two $n$-bit integers, built using gates of fan-in at most two. The time to perform addition using this adder is

- (A) $\Theta(1)$
- (B) $\Theta(\log n)$
- (C) $\Theta(\sqrt{n})$
- (D) $\Theta(n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A carry lookahead adder computes generate and propagate signals for each bit, then combines them with a prefix (tree) structure instead of rippling the carry.

- Each gate has at most 2 inputs, so combining $n$ signals takes a tree of depth $\lceil \log_2 n \rceil$.
- The carries for all positions are obtained in $\Theta(\log n)$ gate delays, then the sums in $O(1)$ more.

So the time is $\Theta(\log n)$, **(B)**.

**Why the others fail.**

- (A) $\Theta(1)$ would need gates with unbounded fan-in.
- (C) $\Theta(\sqrt n)$ has no basis in a lookahead tree (it appears in carry-skip designs).
- (D) $\Theta(n)$ is the ripple-carry adder.

**Key idea:** fan-in 2 limits a carry lookahead to a binary tree of depth $\log n$.

</details>
