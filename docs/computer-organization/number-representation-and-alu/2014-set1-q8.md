# 2014 CS1 Q8: Radix in which 312/20 = 13.1

## Question

The base (or radix) of the number system such that the following equation holds is____________.

$$\frac{312}{20} = 13.1$$

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the radix be $r$. Then $312_r = 3r^2 + r + 2$, $20_r = 2r$, and $13.1_r = r + 3 + \tfrac1r$.

$$\frac{3r^2 + r + 2}{2r} = r + 3 + \frac1r$$

Multiply by $2r$:

$$3r^2 + r + 2 = 2r^2 + 6r + 2 \Rightarrow r^2 - 5r = 0 \Rightarrow r = 5$$

($r = 0$ is not a base.)

**Check in base 5:** $312_5 = 82$, $20_5 = 10$, and $82/10 = 8.2$. $13.1_5 = 5 + 3 + 0.2 = 8.2$. It matches.

**Code check:** a scan over $r = 4..16$ finds only $r = 5$.

**Key idea:** write each numeral as a polynomial in the radix and solve.

</details>
