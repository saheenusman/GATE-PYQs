# 2019 CS2 Q14: Decimal -28 in 16-bit two's complement

## Question

In 16-bit 2's complement representation, the decimal number $-28$ is:

- (A) 1111 1111 0001 1100
- (B) 0000 0000 1110 0100
- (C) 1111 1111 1110 0100
- (D) 1000 0000 1110 0100

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Take the magnitude, invert, add 1.

| Step | 16-bit value |
|---|---|
| $28$ | 0000 0000 0001 1100 |
| invert | 1111 1111 1110 0011 |
| add 1 | **1111 1111 1110 0100** |

**Why the others fail:**

- (A) is $\mathrm{FF1C}_{16}$, which is $-228$.
- (B) is $\mathrm{00E4}_{16} = +228$.
- (D) is $\mathrm{80E4}_{16}$, which is $-32540$ in two's complement. Its pattern (sign bit set, then the magnitude 228) is the sign-magnitude form of $-228$.

**Key idea:** $-x$ in two's complement is "invert all bits, then add 1".

</details>
