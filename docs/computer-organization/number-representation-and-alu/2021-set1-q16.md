# 2021 CS1 Q16: Base 3 number 210 in hexadecimal

## Question

Let the representation of a number in base 3 be 210. What is the hexadecimal representation of the number?

- (A) 15
- (B) 21
- (C) D2
- (D) 528

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$210_3=2\cdot3^2+1\cdot3^1+0\cdot3^0=18+3+0=21$.

$21=1\cdot16+5$, so the hexadecimal form is $15_{16}$.

- (B) 21 is the decimal value.
- (C) D2 is $210$ read as decimal.
- (D) 528 is not obtained from any valid conversion.

Verified with a script: `int('210',3)` gives 21 and `hex(21)` gives `0x15`.

**Key idea:** convert to decimal first, then to the target base.

</details>
