# 2017 CS1 Q7: Range of an unsigned fixed-point number with f fraction bits

## Question

The $n$-bit fixed-point representation of an unsigned real number $X$ uses $f$ bits for the fraction part. Let $i = n - f$. The range of decimal values for $X$ in this representation is

- (A) $2^{-f}$ to $2^{i}$
- (B) $2^{-f}$ to $(2^{i} - 2^{-f})$
- (C) $0$ to $2^{i}$
- (D) $0$ to $(2^{i} - 2^{-f})$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Smallest value.** All bits zero gives $X = 0$.

**Largest value.** All bits one. The integer part has $i$ bits and its maximum is $2^{i}-1$. The fraction part has $f$ bits and its maximum is $1 - 2^{-f}$. Adding:

$$(2^{i}-1) + (1-2^{-f}) = 2^{i} - 2^{-f}$$

So the range is $0$ to $2^{i} - 2^{-f}$: **(D)**.

**Why the others fail.**

- (A), (B) start at $2^{-f}$, but that is the *smallest non-zero* value (resolution). Zero is representable.
- (A), (C) end at $2^{i}$, which needs one more bit and is not representable.

**Key idea:** the largest unsigned fixed-point value is $2^{i}-2^{-f}$, one resolution step below $2^{i}$.

</details>
