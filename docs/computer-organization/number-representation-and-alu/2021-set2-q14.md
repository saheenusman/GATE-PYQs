# 2021 CS2 Q14: Smallest normalized positive IEEE 754 single-precision number

## Question

The format of the single-precision floating-point representation of a real number as per the IEEE 754 standard is as follows:

| sign | exponent | mantissa |
|---|---|---|

Which one of the following choices is correct with respect to the *smallest* normalized positive number represented using the standard?

- (A) exponent = 00000000 and mantissa = 00000000000000000000000
- (B) exponent = 00000000 and mantissa = 00000000000000000000001
- (C) exponent = 00000001 and mantissa = 00000000000000000000000
- (D) exponent = 00000001 and mantissa = 00000000000000000000001

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For normalized numbers the exponent field runs from 00000001 to 11111110. An exponent field of 00000000 means zero or a **denormal** number, so (A) and (B) are not normalized.

The value is $1.F\times2^{E-127}$. It is smallest with the smallest exponent field ($E=1$) and smallest fraction ($F=0$): $1.0\times2^{-126}\approx1.1755\times10^{-38}$.

- (A) is zero.
- (B) is the smallest **denormal**, $2^{-149}\approx1.4\times10^{-45}$, not normalized.
- (C) **Correct.**
- (D) is slightly larger than (C).

Checked by reading the bit patterns as floats: `0x00800000` gives 1.17549e-38, and `0x00000001` gives 1.4013e-45 (denormal).

**Key idea:** an all-zero exponent field is reserved for zero and denormals, so the smallest normalized exponent field is 1.

</details>
