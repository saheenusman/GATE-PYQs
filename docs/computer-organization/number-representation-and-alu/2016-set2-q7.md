# 2016 CS2 Q7: Operand B giving the longest ripple-carry latency when A is one

## Question

Consider an eight-bit ripple-carry adder for computing the sum of $A$ and $B$, where $A$ and $B$ are integers represented in 2's complement form. If the decimal value of $A$ is one, the decimal value of $B$ that leads to the longest latency for the sum to stabilize is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**-1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The latency is longest when a carry has to travel through **all** stages.

$A = 1 = 0000\,0001$.

- Stage 0 generates a carry only if $B_0 = 1$ (since $A_0 = 1$).
- Each later stage must pass that carry on: it propagates when $A_i \oplus B_i = 1$. Since $A_i = 0$ for $i \ge 1$, we need $B_i = 1$.

So $B = 1111\,1111$, which is $-1$ in 2's complement. (The sum is $0$, but the carry rippled across all eight stages first.)

**Key idea:** $B = 1111\,1111$ makes the carry generated at bit 0 propagate through every stage.

</details>
