# 2026 CS1 Q22: Overflow in sign-magnitude arithmetic

## Question

Consider the 8-bit signed integers $X$, $Y$ and $Z$ represented using the sign-magnitude form. The binary representations of $X$ and $Y$ are as follows:

$X$: `10110100`  $Y$: `01001100`

Which of the following operations to compute $Z$ result(s) in an arithmetic overflow?

- (A) $Z = X + Y$
- (B) $Z = X - Y$
- (C) $Z = -X + Y$
- (D) $Z = -X - Y$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** 8-bit sign-magnitude: 1 sign bit, 7 magnitude bits. Range is $-127$ to $+127$.

**Values:** $X = 10110100$ gives sign 1, magnitude $0110100 = 52$, so $X = -52$. $Y = 01001100$ gives $+76$.

| Option | Result | In range? |
|---|---|---|
| (A) $X + Y$ | $-52 + 76 = 24$ | yes |
| (B) $X - Y$ | $-52 - 76 = -128$ | **no, overflow** |
| (C) $-X + Y$ | $52 + 76 = 128$ | **no, overflow** |
| (D) $-X - Y$ | $52 - 76 = -24$ | yes |

Note that $-128$ is representable in two's complement but **not** in sign-magnitude.

**Key idea:** sign-magnitude range is symmetric ($\pm 127$), so $\pm 128$ overflows.

</details>
