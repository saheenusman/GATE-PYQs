# 2016 CS1 Q7: Decimal value of a 16-bit two's complement integer

## Question

The 16-bit 2's complement representation of an integer is `1111 1111 1111 0101`; its decimal representation is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**-11**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The leading bit is $1$, so the number is negative.

**Take the 2's complement to get the magnitude.**

- Invert the bits: `0000 0000 0000 1010` $= 10$.
- Add 1: $11$.

So the value is $-11$.

**Cross-check.** $65{,}536 - \text{(unsigned value)}$, with unsigned value $= 65{,}525$ (since $\texttt{0xFFF5} = 65525$), gives $11$, so the number is $-11$.

**Code check:** `0b1111111111110101 - 65536` evaluates to $-11$.

**Key idea:** negative 2's complement: invert, add 1, then attach the minus sign.

</details>
