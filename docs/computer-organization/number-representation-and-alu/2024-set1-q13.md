# 2024 CS1 Q13: Overflow in 5-bit two's complement arithmetic

## Question

Consider a system that uses 5 bits for representing signed integers in 2's complement format. In this system, two integers $A$ and $B$ are represented as $A = 01010$ and $B = 11010$. Which one of the following operations will result in either an arithmetic overflow or an arithmetic underflow?

- (A) $A + B$
- (B) $A - B$
- (C) $B - A$
- (D) $2 * B$

<details class="success" markdown="1">
<summary>Answer</summary>

**B ($A - B$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Range.** With 5 bits in two's complement the values go from $-16$ to $+15$.

**Decode the operands.** $A = 01010 = +10$. $B = 11010 = -16 + 10 = -6$.

| Operation | Value | In range $[-16, 15]$? |
|---|---|---|
| $A + B$ | $10 - 6 = 4$ | yes |
| $A - B$ | $10 + 6 = 16$ | **no, overflow** |
| $B - A$ | $-6 - 10 = -16$ | yes (10000) |
| $2B$ | $-12$ | yes (10100) |

Only $A - B = 16$ exceeds $+15$.

**Key idea:** compute the true result and compare with the representable range. Note that $-16$ itself is still in range.

</details>
