# 2023 CS Q32: Convert radix 4 to radix 5

## Question

A particular number is written as 132 in radix-4 representation. The same number in radix-5 representation is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**110**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**To decimal.**

$$132_4 = 1\cdot 4^2 + 3\cdot 4 + 2 = 16 + 12 + 2 = 30$$

**To radix 5.** $30 = 1\cdot 25 + 1\cdot 5 + 0$, so the digits are $1, 1, 0$:

$$30 = 110_5$$

**Key idea:** convert through decimal. Repeated division by the new base gives the digits.

</details>
