# 2010 CS Q8: 8 times a 16-bit two's complement number

## Question

$P$ is a 16-bit signed integer. The 2's complement representation of $P$ is $(\text{F87B})_{16}$. The 2's complement representation of $8 \times P$ is

- (A) $(\text{C3D8})_{16}$
- (B) $(\text{187B})_{16}$
- (C) $(\text{F878})_{16}$
- (D) $(\text{987B})_{16}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Multiplying by $8 = 2^3$ is a left shift by $3$ bits, and the top bits that overflow are dropped (the result is still $16$ bits).

$$\text{F87B} = 1111\ 1000\ 0111\ 1011_2$$

Shift left by $3$ and fill with zeros:

$$1100\ 0011\ 1101\ 1000_2 = \text{C3D8}$$

The value is $-1925$, so $8P = -15400$, and $-15400 + 65536 = 50136 = \text{C3D8}_{16}$. This fits in $16$ bits, so there is no overflow. Answer: (A).

- (B) $187B$ comes from shifting the hex digits, not the bits.
- (C) $F878$ only changes the last hex digit; a shift changes every digit.
- (D) $987B$ keeps the low digits $87B$ unchanged, which no multiplication by $8$ would do.

**Code check:** Python: `((0xF87B - 0x10000) * 8) & 0xFFFF` gives `0xc3d8`.

**Key idea:** a left shift by $k$ multiplies by $2^k$ in two's complement, as long as the result fits in the word.

</details>
