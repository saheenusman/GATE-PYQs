# 2018 CS Q43: Which decimals fit an 8-bit fixed-point format

## Question

Consider the unsigned 8-bit fixed point binary number representation below,

`b7 b6 b5 b4 b3 . b2 b1 b0`

where the position of the binary point is between $b_3$ and $b_2$. Assume $b_7$ is the most significant bit. Some of the decimal numbers listed below cannot be represented exactly in the above representation:

- (i) 31.500
- (ii) 0.875
- (iii) 12.100
- (iv) 3.001

Which one of the following statements is true?

- (A) None of (i), (ii), (iii), (iv) can be exactly represented
- (B) Only (ii) cannot be exactly represented
- (C) Only (iii) and (iv) cannot be exactly represented
- (D) Only (i) and (ii) cannot be exactly represented

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Format.** There are 5 integer bits (range 0 to 31) and 3 fraction bits, so the fraction is a multiple of $2^{-3} = 0.125$. The largest value is $31.875$.

**A number is exact if it is a multiple of $0.125$ in range:**

| Number | In units of 0.125 | Exact? |
|---|---|---|
| 31.500 | $252$ | yes ($11111.100$) |
| 0.875 | $7$ | yes ($00000.111$) |
| 12.100 | $96.8$ | no |
| 3.001 | $24.008$ | no |

Only (iii) and (iv) cannot be represented exactly: **C**.

**Why the others fail:** A and B claim (i) or (ii) fail, but both are sums of powers of 2 within range. D lists the two representable numbers as the failures.

**Code check:** exact-fraction arithmetic (multiply by 8, test for an integer) agreed with the table.

**Key idea:** with $f$ fraction bits, only multiples of $2^{-f}$ are exact.

</details>
