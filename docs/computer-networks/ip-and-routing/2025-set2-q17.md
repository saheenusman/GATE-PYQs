# 2025 CS2 Q17: Routing protocol families and their algorithms

## Question

Consider the routing protocols given in List I and the names given in List II:

| List I | List II |
|---|---|
| (i) Distance vector routing | (a) Bellman-Ford |
| (ii) Link state routing | (b) Dijkstra |

For matching of items in List I with those in List II, which ONE of the following options is CORRECT?

- (A) (i) - (a) and (ii) - (b)
- (B) (i) - (a) and (ii) - (a)
- (C) (i) - (b) and (ii) - (a)
- (D) (i) - (b) and (ii) - (b)

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Distance vector routing** works by exchanging distance estimates with neighbours and relaxing them repeatedly. This is the distributed **Bellman-Ford** algorithm (RIP is an example).
- **Link state routing** floods every router's links to all routers, so each router knows the whole graph and runs **Dijkstra's** shortest-path algorithm locally (OSPF is an example).

So (i)-(a) and (ii)-(b): option A. Options B, C and D each pair at least one family with the wrong algorithm.

**Key idea:** distance vector = Bellman-Ford, link state = Dijkstra.

</details>
