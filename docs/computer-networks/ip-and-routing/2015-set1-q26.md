# 2015 CS1 Q26: IP header field a router does not modify

## Question

Which one of the following fields of an IP header is NOT modified by a typical IP router?

- (A) Checksum
- (B) Source address
- (C) Time to Live (TTL)
- (D) Length

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A router forwards the datagram with only these changes:

- TTL is decremented at every hop, so (C) changes.
- The header checksum is recomputed because TTL changed, so (A) changes.
- Length changes when the router fragments the datagram, so (D) can change.
- The **source address** identifies the original sender and is never rewritten by a normal router (only a NAT device does this). So (B) is not modified.

**Key idea:** TTL, checksum (and length on fragmentation) change in transit; the source address does not.

</details>
