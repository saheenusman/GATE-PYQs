# 2026 CS2 Q33: Usable addresses for a subnet mask

## Question

If an IP network uses a subnet mask of 255.255.240.0, the maximum number of IP addresses that can be assigned to network interfaces is _____. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**4094**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count the host bits.** The mask is 255.255.240.0:

$$240 = 11110000_2$$

So the mask has $8 + 8 + 4 = 20$ ones (a /20) and $32 - 20 = 12$ zeros. There are **12 host bits**.

**Total addresses** in the network: $2^{12} = 4096$.

**Usable addresses:** subtract the network address (all host bits 0) and the broadcast address (all host bits 1):

$$4096 - 2 = 4094.$$

**Verified:** 12 host bits, $2^{12} - 2 = 4094$.

**Key idea:** assignable hosts $= 2^{h} - 2$ where $h$ is the number of zero bits in the mask.

</details>
