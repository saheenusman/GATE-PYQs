# 2017 CS2 Q20: Maximum router addresses in the IPv4 record route option

## Question

The maximum number of IPv4 router addresses that can be listed in the record route (RR) option field of an IPv4 header is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**9**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Space available.** The IPv4 header length field is 4 bits (in 32-bit words), so the header is at most $15 \times 4 = 60$ bytes. The fixed part is 20 bytes, leaving **at most 40 bytes for options**.

**Record Route option layout:**

| Part | Size |
|---|---|
| Option type | 1 byte |
| Option length | 1 byte |
| Pointer | 1 byte |
| Each recorded IPv4 address | 4 bytes |

So the addresses fit in $40 - 3 = 37$ bytes:

$$\left\lfloor \frac{37}{4} \right\rfloor = 9$$

**Answer: 9** (using 36 bytes, with 1 byte left over).

**Code check:** `(40 - 3) // 4` gave 9.

**Key idea:** options get at most 40 bytes, and the 3-byte RR header leaves room for 9 four-byte addresses.

</details>
