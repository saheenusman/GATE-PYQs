# 2024 CS1 Q65: Number of IP fragments delivered after two links

## Question

Consider sending an IP datagram of size 1420 bytes (including 20 bytes of IP header) from a sender to a receiver over a path of two links with a router between them. The first link (sender to router) has an MTU (Maximum Transmission Unit) size of 542 bytes, while the second link (router to receiver) has an MTU size of 360 bytes. The number of fragments that would be delivered at the receiver is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each fragment carries a 20-byte header, and the data in every fragment except the last must be a **multiple of 8 bytes**.

**Data to send:** $1420 - 20 = 1400$ bytes.

**Link 1 (MTU 542).** Max data per fragment $= 542 - 20 = 522$, rounded down to a multiple of 8: **520**.

$$1400 = 520 + 520 + 360 \;\Rightarrow\; 3 \text{ fragments.}$$

**Link 2 (MTU 360).** Max data per fragment $= 360 - 20 = 340$, rounded down to a multiple of 8: **336**. The router fragments each incoming fragment again:

| Incoming data | Split |
|---|---|
| 520 | 336 + 184 |
| 520 | 336 + 184 |
| 360 | 336 + 24 |

That is $2 + 2 + 2 = 6$ fragments. Fragments are reassembled only at the receiver, so the receiver gets **6**.

**Key idea:** round data size down to a multiple of 8 and re-fragment at every link whose MTU is smaller.

</details>
