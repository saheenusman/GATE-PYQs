# 2023 CS Q65: Longest prefix match in a forwarding table

## Question

The forwarding table of a router is shown below.

| Subnet Number | Subnet Mask | Interface ID |
|---|---|---|
| 200.150.0.0 | 255.255.0.0 | 1 |
| 200.150.64.0 | 255.255.224.0 | 2 |
| 200.150.68.0 | 255.255.255.0 | 3 |
| 200.150.68.64 | 255.255.255.224 | 4 |
| Default | | 0 |

A packet addressed to a destination address 200.150.68.118 arrives at the router. It will be forwarded to the interface with ID ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rule.** Among all entries that match, choose the one with the **longest mask**.

| Entry | Prefix | Covers | Matches 200.150.68.118? |
|---|---|---|---|
| 1 | /16 | 200.150.0.0 to 200.150.255.255 | yes |
| 2 | /19 | 200.150.64.0 to 200.150.95.255 | yes (68 is in 64 to 95) |
| 3 | /24 | 200.150.68.0 to 200.150.68.255 | yes |
| 4 | /27 | 200.150.68.64 to 200.150.68.95 | **no** (118 > 95) |

Entries 1, 2, 3 match. The longest prefix is entry 3 (/24), so the packet goes to **interface 3**.

**Code check:** a Python `ipaddress` test agreed with this table.

**Key idea:** routers use longest-prefix match. Entry 4 looks the most specific, but the address is outside its range.

</details>
