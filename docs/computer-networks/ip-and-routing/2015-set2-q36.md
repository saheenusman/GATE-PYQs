# 2015 CS2 Q36: Next hop for four addresses using longest prefix match

## Question

Consider the following routing table at an IP router:

| Network No. | Net Mask | Next Hop |
|---|---|---|
| 128.96.170.0 | 255.255.254.0 | Interface 0 |
| 128.96.168.0 | 255.255.254.0 | Interface 1 |
| 128.96.166.0 | 255.255.254.0 | R2 |
| 128.96.164.0 | 255.255.252.0 | R3 |
| 0.0.0.0 | Default | R4 |

For each IP address in Group I identify the correct choice of the next hop from Group II using the entries from the routing table above.

| Group I | | Group II | |
|---|---|---|---|
| i) | 128.96.171.92 | a) | Interface 0 |
| ii) | 128.96.167.151 | b) | Interface 1 |
| iii) | 128.96.163.151 | c) | R2 |
| iv) | 128.96.165.121 | d) | R3 |
| | | e) | R4 |

- (A) i-a, ii-c, iii-e, iv-d
- (B) i-a, ii-d, iii-b, iv-e
- (C) i-b, ii-c, iii-d, iv-e
- (D) i-b, ii-c, iii-e, iv-d

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only the third octet matters. A mask of 254 keeps all but the last bit of that octet (blocks of 2). A mask of 252 keeps all but the last two bits (blocks of 4).

| Address | Third octet | Matches | Next hop |
|---|---|---|---|
| i) 128.96.171.92 | $171 \,\&\, 254 = 170$ | 128.96.170.0 | Interface 0 (a) |
| ii) 128.96.167.151 | $167 \,\&\, 254 = 166$ | 128.96.166.0 (also in 164.0/22) | R2 (c) |
| iii) 128.96.163.151 | $163$ | no listed network | default, R4 (e) |
| iv) 128.96.165.121 | $165 \,\&\, 252 = 164$ | 128.96.164.0 | R3 (d) |

For ii), two entries match, 128.96.166.0 (mask /23) and 128.96.164.0 (mask /22). The router picks the **longest prefix**, the /23 entry, so R2.

i-a, ii-c, iii-e, iv-d: option (A).

**Key idea:** AND the address with each mask, then choose the matching entry with the longest prefix.

</details>
