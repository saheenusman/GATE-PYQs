# 2008 CS Q57: Maximum hosts per subnet with mask 255.255.248.0

## Question

If a class B network on the Internet has a subnet mask of 255.255.248.0, what is the maximum number of hosts per subnet?

- (A) 1022
- (B) 1023
- (C) 2046
- (D) 2047

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$255.255.248.0$ in binary is $11111111.11111111.11111000.00000000$: $16 + 5 = 21$ ones. The mask leaves $32 - 21 = 11$ host bits.

Hosts per subnet $= 2^{11} - 2 = 2048 - 2 = 2046$ (the all-zeros network address and the all-ones broadcast address cannot be assigned): (C).

- (A) 1022 would be $2^{10} - 2$ (10 host bits).
- (B) 1023 and (D) 2047 forget to subtract both reserved addresses (they subtract only one).

**Code check:** a one-line calculation gave $2046$.

**Key idea:** usable hosts per subnet $= 2^{\text{host bits}} - 2$.

</details>
