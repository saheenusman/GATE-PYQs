# 2025 CS1 Q40: Longest-prefix match in a routing table

## Question

A packet with the destination IP address 145.36.109.70 arrives at a router whose routing table is shown. Which interface will the packet be forwarded to?

| Subnet Address | Subnet Mask (in CIDR notation) | Interface |
|---|---|---|
| 145.36.0.0 | /16 | E1 |
| 145.36.128.0 | /17 | E2 |
| 145.36.64.0 | /18 | E3 |
| 145.36.255.0 | /24 | E4 |
| Default | -- | E5 |

- (A) E3
- (B) E1
- (C) E2
- (D) E5

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Routers use **longest-prefix match**: among all matching entries, the one with the longest mask wins.

The destination is 145.36.109.70. Its third byte is $109 = 01101101_2$. Test each entry:

| Entry | Compare on | Match? |
|---|---|---|
| 145.36.0.0 /16 | first 16 bits: 145.36 | Yes |
| 145.36.128.0 /17 | first 17 bits: third byte must start with `1` ($128 = 10000000_2$) | No: 109 starts with `0` |
| 145.36.64.0 /18 | first 18 bits: third byte must start with `01` ($64 = 01000000_2$) | **Yes**: 109 starts with `01` |
| 145.36.255.0 /24 | third byte must equal 255 | No |
| Default | anything | Yes (shortest prefix) |

Matching entries: /16 (E1), /18 (E3) and the default (E5). The longest prefix is **/18**, so the packet goes to **E3**.

**Key idea:** use the longest matching prefix, not the first match in the table.

</details>
