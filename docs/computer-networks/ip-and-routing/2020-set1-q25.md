# 2020 CS Q25: True statements about the functionality of an IP router

## Question

Consider the following statements about the functionality of an IP based router.

- I. A router does not modify the IP packets during forwarding.
- II. It is not necessary for a router to implement any routing protocol.
- III. A router should reassemble IP fragments if the MTU of the outgoing link is larger than the size of the incoming IP packet.

Which of the above statements is/are TRUE?

- (A) I and II only
- (B) I only
- (C) II and III only
- (D) II only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Statement | Verdict | Reason |
|---|---|---|
| I | **False** | A router decrements the TTL field of every packet it forwards, and so must update the header checksum. (It may also fragment the packet.) |
| II | **True** | Routing protocols fill the routing table automatically, but a router can run with a **static** table set by an administrator. |
| III | **False** | Reassembly is done only at the **destination host**. A router forwards fragments as they are, even if the outgoing MTU is larger. |

True: II only.

**Why the other options fail:** (A) and (B) include I, and (C) includes III.

**Key idea:** routers change TTL and checksum, may fragment but never reassemble, and do not need a dynamic routing protocol.

</details>
