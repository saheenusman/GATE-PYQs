# 2007 CS Q67: Subnetting a class B address with a 6-bit subnet number

## Question

The address of a class B host is to be split into subnets with a 6-bit subnet number. What is the maximum number of subnets and the maximum number of hosts in each subnet?

- (A) 62 subnets and 262142 hosts.
- (B) 64 subnets and 262142 hosts.
- (C) 62 subnets and 1022 hosts.
- (D) 64 subnets and 1024 hosts.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A class B address has a 16-bit network part and a 16-bit host part. Taking 6 bits of the host part for the subnet number leaves $16 - 6 = 10$ bits for hosts.

- **Subnets:** $2^6 - 2 = 62$ (the all-zeros and all-ones subnet numbers were reserved in classical subnetting).
- **Hosts per subnet:** $2^{10} - 2 = 1022$ (all-zeros is the network address, all-ones is the broadcast address).

So 62 subnets and 1022 hosts: (C).

- (A) and (B) give 262142 hosts, which is $2^{18} - 2$, as if 18 bits remained.
- (D) counts all 64 subnets and 1024 hosts, forgetting the reserved addresses.

**Code check:** Python arithmetic: $2^6-2=62$, $2^{10}-2=1022$.

**Convention caveat:** the "62" uses the old rule that excludes the all-zeros and all-ones subnets. Modern CIDR practice allows both, which would make it 64 subnets. Option (C) is the only one that is consistent with the classical rule for both counts, so I chose it.

**Key idea:** subnets $= 2^{s} - 2$ (classical rule), hosts per subnet $= 2^{h} - 2$.

</details>
