# 2025 CS2 Q18: Which protocol cannot appear in the IPv4 protocol field

## Question

A machine receives an IPv4 datagram. The protocol field of the IPv4 header has the protocol number of a protocol X.

Which ONE of the following is NOT a possible candidate for X?

- (A) Internet Control Message Protocol (ICMP)
- (B) Internet Group Management Protocol (IGMP)
- (C) Open Shortest Path First (OSPF)
- (D) Routing Information Protocol (RIP)

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The IPv4 protocol field names the protocol carried **directly inside the IP payload**.

| Protocol | How it is carried | Protocol number |
|---|---|---|
| ICMP | directly over IP | 1 |
| IGMP | directly over IP | 2 |
| OSPF | directly over IP | 89 |
| **RIP** | **inside UDP** (port 520), not directly in IP | the IP header says 17 (UDP), never a number for RIP |

So RIP can never appear as the protocol number in an IP header: option D.

**Key idea:** OSPF, ICMP and IGMP sit directly on IP, but RIP rides on UDP, so IP only ever sees "UDP".

</details>
