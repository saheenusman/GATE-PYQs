# 2023 CS Q25: Incorrect statements about OSPF

## Question

Which of the following statements is/are INCORRECT about the OSPF (Open Shortest Path First) routing protocol used in the Internet?

- (A) OSPF implements Bellman-Ford algorithm to find shortest paths.
- (B) OSPF uses Dijkstra's shortest path algorithm to implement least-cost path routing.
- (C) OSPF is used as an inter-domain routing protocol.
- (D) OSPF implements hierarchical routing.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**A (incorrect).** OSPF is a *link-state* protocol. Each router learns the whole topology and runs **Dijkstra**. Bellman-Ford is the distance-vector method (RIP).

**B (correct).** Dijkstra is used for least-cost paths.

**C (incorrect).** OSPF is an **intra-domain** (interior) protocol, used inside one autonomous system. BGP is the inter-domain protocol.

**D (correct).** OSPF splits an AS into areas around a backbone area, which is hierarchical routing.

**Key idea:** OSPF = link-state, Dijkstra, within an AS, with areas.

</details>
