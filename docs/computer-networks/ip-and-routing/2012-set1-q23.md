# 2012 CS Q23: Number of Class C networks in IPv4

## Question

In the IPv4 addressing format, the number of networks allowed under Class C addresses is

- (A) $2^{14}$
- (B) $2^{7}$
- (C) $2^{21}$
- (D) $2^{24}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A Class C address starts with the bits `110`, then has a $21$-bit network number and an $8$-bit host number ($3 + 21 + 8 = 32$). So there are $2^{21}$ Class C networks: (C).

- (A) $2^{14}$ is the number of Class B networks.
- (B) $2^{7}$ is the number of Class A networks.
- (D) $2^{24}$ is the number of host addresses in a Class A network.

**Key idea:** the class prefix bits are fixed, so networks $= 2^{32 - \text{prefix bits} - \text{host bits}}$.

</details>
