# 2022 CS Q22: Number of subnets in an enterprise network

## Question

Consider an enterprise network with two Ethernet segments, a web server and a firewall, connected via three routers as shown below.

![A firewall, with a line to the Internet, is connected to the left router and to the top router. The top router is connected to the web server and to the right router. The left router and the right router each connect to a separate Ethernet segment with several hosts.](../../assets/2022/set1-q22.png)

What is the number of subnets inside the enterprise network?

- (A) 3
- (B) 12
- (C) 6
- (D) 8

<details class="success" markdown="1">
<summary>Answer</summary>

**C (6)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Each separate network segment is one subnet.** Every point-to-point link between two devices is its own subnet, and each Ethernet segment is one subnet. Reading the figure (the link to the Internet is outside the enterprise network):

1. Firewall – left router
2. Firewall – top router
3. Top router – web server
4. Top router – right router
5. Left router – left Ethernet segment
6. Right router – right Ethernet segment

That is **6** subnets.

**Why the others fail:** hosts on one Ethernet segment share a subnet, so counting interfaces or hosts overcounts. Only 6 matches the six links and segments in the figure.

**Key idea:** routers separate subnets; count the distinct links and shared segments, not the devices.

**Figure note:** the count depends on how the lines in the figure connect the devices. This reading gives the official answer.

</details>
