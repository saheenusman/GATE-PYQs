# 2010 CS Q47: Subnet mask that would put two hosts in different networks

## Question

Suppose computers A and B have IP addresses $10.105.1.113$ and $10.105.1.91$ respectively and they both use the same net mask $N$. Which of the values of $N$ given below should **not** be used if A and B should belong to the same network?

- (A) $255.255.255.0$
- (B) $255.255.255.128$
- (C) $255.255.255.192$
- (D) $255.255.255.224$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only the last octet differs: $113 = 0111\ 0001_2$ and $91 = 0101\ 1011_2$. Apply each mask to the last octet:

| Mask (last octet) | $113$ AND mask | $91$ AND mask | Same network? |
|---|---|---|---|
| $0$ | $0$ | $0$ | yes |
| $128$ | $0$ | $0$ | yes |
| $192$ | $64$ | $64$ | yes |
| $224$ | $96$ | $64$ | **no** |

With $255.255.255.224$ the hosts land in subnets $10.105.1.96/27$ and $10.105.1.64/27$. So $N$ must not be (D).

- (A), (B), (C) give identical network addresses for both hosts.

**Code check:** Python's `ipaddress` module: the two addresses are in the same network for the first three masks and in different networks for $255.255.255.224$.

**Key idea:** two hosts are on the same network iff address AND mask is equal; longer masks split the address range into smaller subnets.

</details>
