# 2024 CS1 Q31: IP header fields changed by a NAT device

## Question

Which of the following fields is/are modified in the IP header of a packet going out of a network address translation (NAT) device from an internal network to an external network?

- (A) Source IP
- (B) Destination IP
- (C) Header Checksum
- (D) Total Length

<details class="success" markdown="1">
<summary>Answer</summary>

**A and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For an outgoing packet the NAT replaces the **private source address** with its own public address (and usually the source port, in the transport header).

- **(A) Modified.** Source IP changes.
- **(B) Not modified.** The destination is the external host and stays the same.
- **(C) Modified.** The header checksum covers the source address, so it must be recomputed.
- **(D) Not modified.** Replacing one 4-byte address by another 4-byte address leaves the length unchanged.

**Key idea:** changing a field covered by the IP checksum forces the checksum to change too.

</details>
