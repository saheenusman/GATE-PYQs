# 2018 CS Q64: Fragmentation offset of the third fragment

## Question

Consider an IP packet with a length of 4,500 bytes that includes a 20-byte IPv4 header and a 40-byte TCP header. The packet is forwarded to an IPv4 router that supports a Maximum Transmission Unit (MTU) of 600 bytes. Assume that the length of the IP header in all the outgoing fragments of this packet is 20 bytes. Assume that the fragmentation offset value stored in the first fragment is 0.

The fragmentation offset value stored in the third fragment is _______.

<details class="success" markdown="1">
<summary>Answer</summary>

**144**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Data to carry.** The 4500-byte packet has a 20-byte header, so the payload is $4500 - 20 = 4480$ bytes (the 40-byte TCP header is part of this payload).

**Largest payload per fragment.** The MTU is 600 bytes and each fragment has a 20-byte header, so at most $600-20 = 580$ payload bytes. The offset field counts in units of 8 bytes, so every fragment except the last must carry a multiple of 8 bytes: $\lfloor580/8\rfloor\times8 = 576$.

**Offsets (in 8-byte units):**

| Fragment | Payload bytes | Starts at byte | Offset field |
|---|---|---|---|
| 1 | 576 | 0 | 0 |
| 2 | 576 | 576 | $576/8 = 72$ |
| 3 | 576 | 1152 | $1152/8 = 144$ |

The third fragment's offset is **144**.

**Key idea:** the fragment offset is the byte position divided by 8, and non-final fragments carry the largest multiple of 8 that fits under the MTU.

</details>
