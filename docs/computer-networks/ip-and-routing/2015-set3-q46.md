# 2015 CS3 Q46: Last host address of a /27 network

## Question

In the network 200.10.11.144/27, the fourth octet (in decimal) of the last IP address of the network which can be assigned to a host is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**158**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A /27 mask leaves $32 - 27 = 5$ host bits, so each block has $2^5 = 32$ addresses. In the fourth octet the mask is $224$ ($11100000$).

$$144 = 10010000_2 \;\Rightarrow\; 144 \,\&\, 224 = 128$$

So 200.10.11.144 lies in the block starting at **128**:

| | Fourth octet |
|---|---|
| Network address | 128 |
| First host | 129 |
| Last host | **158** |
| Broadcast | 159 |

**Answer: 158.**

**Key idea:** the last usable host is the broadcast address minus 1.

</details>
