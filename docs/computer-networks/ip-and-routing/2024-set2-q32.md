# 2024 CS2 Q32: IP header fields every router modifies

## Question

Which of the following fields of an IP header is/are always modified by any router before it forwards the IP packet?

- (A) Source IP Address
- (B) Protocol
- (C) Time to Live (TTL)
- (D) Header Checksum

<details class="success" markdown="1">
<summary>Answer</summary>

**C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **TTL** is decremented at every router. **(C) always modified.**
- **Header checksum** covers the header, which has just changed (TTL), so it is recomputed at every hop. **(D) always modified.**
- **Source IP** is not changed by an ordinary router (only a NAT device does that).
- **Protocol** (TCP, UDP, ...) is not touched by routers.

**Key idea:** a normal router changes TTL and therefore the checksum, and nothing else.

</details>
