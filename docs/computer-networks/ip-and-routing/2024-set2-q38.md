# 2024 CS2 Q38: CIDR prefix for an address range

## Question

Which one of the following CIDR prefixes exactly represents the range of IP addresses 10.12.2.0 to 10.12.3.255?

- (A) 10.12.2.0/23
- (B) 10.12.2.0/24
- (C) 10.12.0.0/22
- (D) 10.12.2.0/22

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Size of the range.** From 10.12.2.0 to 10.12.3.255 there are $2 \times 256 = 512$ addresses $= 2^9$. So 9 host bits and the prefix length is $32 - 9 = 23$.

**Alignment.** A /23 block must begin at a multiple of 512 addresses. In the third octet that means an even value. The third octet here is 2, so 10.12.2.0/23 is a valid block, and it ends at 10.12.3.255. ✓ (A script that summarises the range returns exactly `10.12.2.0/23`.)

**Why the others fail:**

- **/24** covers only 256 addresses (10.12.2.0 to 10.12.2.255).
- **10.12.0.0/22** covers 10.12.0.0 to 10.12.3.255, which is 1024 addresses and includes extra ones.
- **10.12.2.0/22** is not a valid block address (it normalises to 10.12.0.0/22).

**Key idea:** number of addresses $= 2^{32 - \text{prefix}}$, and the block must start on a multiple of its size.

</details>
