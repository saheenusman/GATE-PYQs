# 2014 CS3 Q26: CIDR longest-prefix match for 131.23.151.76

## Question

An IP router implementing Classless Inter-domain Routing (CIDR) receives a packet with address 131.23.151.76. The router's routing table has the following entries:

| Prefix | Output Interface Identifier |
|---|---|
| 131.16.0.0/12 | 3 |
| 131.28.0.0/14 | 5 |
| 131.19.0.0/16 | 2 |
| 131.22.0.0/15 | 1 |

The identifier of the output interface on which this packet will be forwarded is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compare the second octet (23) with each prefix. Only that octet matters, since the first octet is 131 in all entries and the mask ends inside the second octet for /12, /14 and /15.

| Prefix | Range of 2nd octet | Matches 23? |
|---|---|---|
| 131.16.0.0/12 | 16 to 31 | yes |
| 131.28.0.0/14 | 28 to 31 | no |
| 131.19.0.0/16 | 19 only | no |
| 131.22.0.0/15 | 22 to 23 | yes |

Two entries match: /12 and /15. A CIDR router picks the **longest prefix**, which is /15, so the packet goes out on interface **1**.

**Code check:** Python's `ipaddress` module confirms that only the /12 and /15 networks contain 131.23.151.76.

**Key idea:** among all matching prefixes, forward on the longest one.

</details>
