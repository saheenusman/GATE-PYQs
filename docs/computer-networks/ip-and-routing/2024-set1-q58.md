# 2024 CS1 Q58: Longest-prefix match and packet counts

## Question

Consider the entries shown below in the forwarding table of an IP router. Each entry consists of an IP prefix and the corresponding next hop router for packets whose destination IP address matches the prefix. The notation "/N" in a prefix indicates a subnet mask with the most significant N bits set to 1.

| Prefix | Next hop router |
|---|---|
| 10.1.1.0/24 | R1 |
| 10.1.1.128/25 | R2 |
| 10.1.1.64/26 | R3 |
| 10.1.1.192/26 | R4 |

This router forwards 20 packets each to 5 hosts. The IP addresses of the hosts are 10.1.1.16, 10.1.1.72, 10.1.1.132, 10.1.1.191, and 10.1.1.205. The number of packets forwarded via the next hop router R2 is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**40**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Routers use the **longest matching prefix**. Only the last octet differs, so write each prefix as a range of that octet:

| Prefix | Last octet range | Next hop |
|---|---|---|
| 10.1.1.0/24 | 0 to 255 | R1 |
| 10.1.1.128/25 | 128 to 255 | R2 |
| 10.1.1.64/26 | 64 to 127 | R3 |
| 10.1.1.192/26 | 192 to 255 | R4 |

**Match each host (longest prefix wins):**

| Host (last octet) | Matches | Chosen |
|---|---|---|
| 16 | /24 only | R1 |
| 72 | /24, /26 (64–127) | R3 |
| 132 | /24, /25 | **R2** |
| 191 | /24, /25 (191 is below 192, so not in the /26) | **R2** |
| 205 | /24, /25, /26 (192–255) | R4 |

Two hosts (132 and 191) go via R2: $2 \times 20 = 40$ packets.

**Key idea:** among all matching prefixes, take the longest. Watch the boundaries of the ranges: 191 is just outside 10.1.1.192/26.

</details>
