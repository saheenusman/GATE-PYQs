# 2017 CS2 Q9: True statements about RIP and OSPF

## Question

Consider the following statements about the routing protocols, Routing Information Protocol (RIP) and Open Shortest Path First (OSPF) in an IPv4 network.

- I: RIP uses distance vector routing
- II: RIP packets are sent using UDP
- III: OSPF packets are sent using TCP
- IV: OSPF operation is based on link-state routing

Which of the statements above are CORRECT?

- (A) I and IV only
- (B) I, II and III only
- (C) I, II and IV only
- (D) II, III and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Check each statement.**

| Statement | Truth | Reason |
|---|---|---|
| I. RIP is distance vector | True | Routers exchange distance (hop-count) tables with neighbours. |
| II. RIP uses UDP | True | RIP messages go over UDP port 520. |
| III. OSPF uses TCP | **False** | OSPF is carried **directly over IP** (protocol number 89), not over TCP or UDP. |
| IV. OSPF is link-state | True | Routers flood link-state advertisements and run Dijkstra. |

True: I, II, IV. That is **(C)**.

**Why the others fail.** (A) leaves out II, which is true. (B) and (D) include III, which is false.

**Status note:** protocol facts (no program applies); the answer matches the official key.

**Key idea:** RIP is distance-vector over UDP; OSPF is link-state and runs directly over IP.

</details>
