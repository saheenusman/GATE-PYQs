# 2014 CS3 Q25: IP header fields that may change in transit

## Question

Host A (on TCP/IP v4 network A) sends an IP datagram D to host B (also on TCP/IP v4 network B). Assume that no error occurred during the transmission of D. When D reaches B, which of the following IP header field(s) may be different from that of the original datagram D?

- (i) TTL
- (ii) Checksum
- (iii) Fragment Offset

- (A) (i) only
- (B) (i) and (ii) only
- (C) (ii) and (iii) only
- (D) (i), (ii) and (iii)

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(i) TTL:** every router decrements it, so it differs on arrival.
- **(ii) Checksum:** the header checksum covers the header, including TTL. Each router recomputes it after the TTL change, so it differs.
- **(iii) Fragment offset:** if a router forwards D onto a link with a smaller MTU, it fragments D, and the pieces get their own fragment offsets (and flags and total length). So the field may differ on arrival.

All three can change: **D**.

**Key idea:** TTL changes at each hop (so the checksum changes too), and fragmentation in transit changes offset fields.

</details>
