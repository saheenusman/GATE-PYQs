# 2016 CS2 Q25: Order of packets when a browser fetches a page after a restart

## Question

Identify the correct sequence in which the following packets are transmitted on the network by a host when a browser requests a webpage from a remote server, assuming that the host has just been restarted.

- (A) HTTP GET request, DNS query, TCP SYN
- (B) DNS query, HTTP GET request, TCP SYN
- (C) DNS query, TCP SYN, HTTP GET request
- (D) TCP SYN, DNS query, HTTP GET request

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

1. The browser has only a host name, so the host first sends a **DNS query** to get the server's IP address.
2. With the address known, it opens a connection with a **TCP SYN**.
3. Once the connection is established, it sends the **HTTP GET** request.

DNS query, TCP SYN, HTTP GET: **(C)**. (On a freshly restarted host there may also be ARP or DHCP packets earlier; they are not among the options.)

**Key idea:** name resolution (DNS), then connection (TCP SYN), then request (HTTP GET).

</details>
