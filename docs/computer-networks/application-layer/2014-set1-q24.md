# 2014 CS1 Q24: Algorithms used to generate a message digest

## Question

Which of the following are used to generate a message digest by the network security protocols?

(P) RSA  (Q) SHA-1  (R) DES  (S) MD5

- (A) P and R only
- (B) Q and R only
- (C) Q and S only
- (D) R and S only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A message digest is the output of a **hash function**. SHA-1 (Q) and MD5 (S) are hash functions.

- RSA (P) is a public-key algorithm for encryption and signatures. It signs a digest but does not produce one.
- DES (R) is a symmetric block cipher.

So Q and S only: **C**.

**Classification flag:** network security is not a separate topic here. It is filed under `application-layer`, as with similar earlier questions.

**Key idea:** digests come from hash functions (MD5, SHA); RSA and DES are ciphers.

</details>
