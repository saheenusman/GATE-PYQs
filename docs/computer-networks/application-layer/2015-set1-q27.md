# 2015 CS1 Q27: Protocols that can use multiple TCP connections

## Question

In one of the pairs of protocols given below, both the protocols can use multiple TCP connections between the same client and the server. Which one is that?

- (A) HTTP, FTP
- (B) HTTP, TELNET
- (C) FTP, SMTP
- (D) HTTP, SMTP

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **HTTP** can open several TCP connections to the same server: parallel connections for page objects, or one connection per object in non-persistent HTTP.
- **FTP** uses a separate **control connection** (port 21) and a **data connection** for each transfer.
- TELNET uses a single connection. SMTP delivers all messages over a single connection per session.

So only (A) has both protocols using multiple connections. (B), (C) and (D) each contain TELNET or SMTP.

**Key idea:** FTP always uses control plus data connections, and HTTP can use several.

</details>
