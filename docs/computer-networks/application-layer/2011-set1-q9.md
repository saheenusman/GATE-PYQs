# 2011 CS Q9: Action not supported by pure HTML

## Question

HTML (HyperText Markup Language) has language elements which permit certain actions other than describing the structure of the web document. Which one of the following actions is **NOT** supported by pure HTML (without any server or client side scripting) pages?

- (A) Embed web objects from different sites into the same page
- (B) Refresh the page automatically after a specified interval
- (C) Automatically redirect to another page upon download
- (D) Display the client time as part of the page

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) supported: `<iframe>`, `<object>`, `<embed>` and `<img>` can pull content from other sites.
- (B) supported: `<meta http-equiv="refresh" content="30">` reloads the page every $30$ seconds.
- (C) supported: `<meta http-equiv="refresh" content="0; url=...">` redirects to another page as soon as the page loads.
- (D) **not supported.** The time on the client machine is not available to markup. Showing it needs a script running in the browser (for example JavaScript), which the question rules out: (D).

**Classification note.** HTML is not named in the current syllabus. Earlier years put the HTML questions under `application-layer`, so this one follows them.

**Key idea:** HTML is static markup; reading the client's clock needs client-side scripting.

</details>
