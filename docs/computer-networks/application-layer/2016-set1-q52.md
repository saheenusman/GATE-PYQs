# 2016 CS1 Q52: Correct way to send a digitally signed message

## Question

Consider that $B$ wants to send a message $m$ that is digitally signed to $A$. Let the pair of private and public keys for $A$ and $B$ be denoted by $K_x^-$ and $K_x^+$ for $x = A, B$, respectively. Let $K_x(m)$ represent the operation of encrypting $m$ with a key $K_x$ and $H(m)$ represent the message digest. Which one of the following indicates the CORRECT way of sending the message $m$ along with the digital signature to $A$?

- (A) $\lbrace m, K_B^+(H(m)) \rbrace$
- (B) $\lbrace m, K_B^-(H(m)) \rbrace$
- (C) $\lbrace m, K_A^-(H(m)) \rbrace$
- (D) $\lbrace m, K_A^+(m) \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A digital signature proves the sender: only $B$ can create it, and anyone can verify it. So $B$ computes the digest $H(m)$ and encrypts it with **its own private key** $K_B^-$. The receiver $A$ decrypts with $B$'s public key $K_B^+$ and compares with $H(m)$.

$$\lbrace m,\ K_B^-(H(m)) \rbrace$$

That is **(B)**.

**Why the others fail.**

- (A) $K_B^+(H(m))$: anyone can encrypt with $B$'s public key, so this proves nothing about the sender.
- (C) $K_A^-(H(m))$: $B$ does not have $A$'s private key.
- (D) $K_A^+(m)$: this gives confidentiality (only $A$ can read it), not authentication.

**Key idea:** sign the digest with the sender's private key; verify with the sender's public key.

</details>
