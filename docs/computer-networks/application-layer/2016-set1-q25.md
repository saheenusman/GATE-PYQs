# 2016 CS1 Q25: Which of HTTP, FTP, TCP and POP3 are stateful application layer protocols

## Question

Which of the following is/are example(s) of stateful application layer protocols?

- (i) HTTP
- (ii) FTP
- (iii) TCP
- (iv) POP3

- (A) (i) and (ii) only
- (B) (ii) and (iii) only
- (C) (ii) and (iv) only
- (D) (iv) only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Protocol | Layer | Stateful? |
|---|---|---|
| (i) HTTP | application | no, each request is independent (state is added with cookies) |
| (ii) FTP | application | **yes**, the control connection remembers login and current directory |
| (iii) TCP | **transport** | stateful, but not an application layer protocol |
| (iv) POP3 | application | **yes**, it moves through authorization, transaction and update states |

Stateful application layer protocols: FTP and POP3, which is **(C)**.

**Why the others fail.** (A) includes stateless HTTP, (B) includes TCP, which is not an application layer protocol, and (D) leaves out FTP.

**Key idea:** FTP and POP3 keep session state at the application layer; HTTP is stateless and TCP is not an application protocol.

</details>
