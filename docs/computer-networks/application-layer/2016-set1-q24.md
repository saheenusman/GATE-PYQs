# 2016 CS1 Q24: Which protocol is not used to resolve one form of address to another

## Question

Which one of the following protocols is NOT used to resolve one form of address to another one?

- (A) DNS
- (B) ARP
- (C) DHCP
- (D) RARP

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Protocol | What it resolves |
|---|---|
| DNS | host name $\rightarrow$ IP address |
| ARP | IP address $\rightarrow$ MAC address |
| RARP | MAC address $\rightarrow$ IP address |
| DHCP | **assigns** an IP configuration to a host; it does not translate one address form into another |

So the protocol that does not resolve an address is **DHCP**, option (C).

**Key idea:** DHCP assigns addresses; DNS, ARP and RARP translate between address forms.

</details>
