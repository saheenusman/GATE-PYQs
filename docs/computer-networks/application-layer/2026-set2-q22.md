# 2026 CS2 Q22: A protocol that may broadcast messages

## Question

Which one of the following protocols may need to broadcast some of its messages?

- (A) SMTP
- (B) FTP
- (C) DHCP
- (D) HTTP

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**DHCP.** A client that has no IP address yet cannot send to a specific server, so it **broadcasts** a `DHCPDISCOVER` message to find any DHCP server (and the server's offer may also be broadcast).

The others (SMTP, FTP, HTTP) use TCP connections between two known hosts, so they use unicast only.

**Key idea:** broadcast is needed when the sender does not know the destination yet, as in DHCP discovery.

</details>
