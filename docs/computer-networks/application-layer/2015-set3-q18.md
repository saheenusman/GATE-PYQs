# 2015 CS3 Q18: HTML tag that makes relative URLs resolve to the server

## Question

In a web server, ten WebPages are stored with the URLs of the form `http://www.yourname.com/var.html`; where, *var* is a different number from 1 to 10 for each Webpage. Suppose, the client stores the Webpage with *var* = 1 (say W1) in local machine, edits and then tests. Rest of the WebPages remains on the web server. W1 contains several relative URLs of the form "*var*.html" referring to the other WebPages. Which one of the following statements needs to be added in W1, so that all the relative URLs in W1 refer to the appropriate WebPages on the web server?

- (A) `<a href: "http://www.yourname.com/", href: "...var.html">`
- (B) `<base href: "http://www.yourname.com/">`
- (C) `<a href: "http://www.yourname.com/">`
- (D) `<base href: "http://www.yourname.com/", range: "...var.html">`

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A relative URL such as `3.html` is resolved against a **base URL**. On the client's machine the base is the local file, so the links would point to local files that do not exist.

The `<base>` element sets the base URL for every relative link in the page. With

`<base href="http://www.yourname.com/">`

in `W1`, `3.html` becomes `http://www.yourname.com/3.html`. Option (B).

- (A) and (C) use `<a>`, which only makes one hyperlink and does not change how other links resolve.
- (D) uses `<base>` but adds a `range` attribute, which does not exist.

**Note.** The paper writes `href:` with a colon. Real HTML writes `href="..."`. Only the tag matters here.

**Key idea:** `<base href>` sets the base for all relative URLs in a page.

</details>
