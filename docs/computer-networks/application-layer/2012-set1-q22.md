# 2012 CS Q22: Transport layer protocol used for electronic mail

## Question

Which of the following transport layer protocols is used to support electronic mail?

- (A) SMTP
- (B) IP
- (C) TCP
- (D) UDP

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Email is carried by SMTP (and fetched with POP3 or IMAP), and these application protocols need reliable, ordered delivery. They therefore run over **TCP**: (C).

- (A) SMTP is itself an *application* layer protocol, not a transport protocol.
- (B) IP is the network layer.
- (D) UDP is unreliable; mail servers do not use it.

**Key idea:** SMTP, POP3, IMAP, HTTP and FTP all run over TCP.

</details>
