# 2026 CS1 Q19: HTTP 1.1 and TCP connections

## Question

Which of the following statements is/are true for the interaction of a web browser with a web server using HTTP 1.1?

- (A) HTTP 1.1 facilitates downloading multiple objects of the same webpage over the same TCP connection, if the objects are stored in the same server
- (B) HTTP 1.1 facilitates downloading multiple objects of the same webpage over the same TCP connection, even if they are stored in different servers
- (C) HTTP 1.1 facilitates sending a request for downloading one object without waiting for a previously requested object to be downloaded completely
- (D) HTTP 1.1 facilitates downloading multiple webpages on the same server to be downloaded over a single TCP connection

<details class="success" markdown="1">
<summary>Answer</summary>

**A, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** HTTP 1.1 uses **persistent connections** by default and allows **pipelining**.

- **(A) True.** Many objects (images, scripts) of one page from the same server travel over one TCP connection (persistent connection).
- **(B) False.** A TCP connection goes to **one** server. Objects on a different server need a different connection.
- **(C) True.** With pipelining the client can send the next request before the previous response has fully arrived.
- **(D) True.** The persistent connection is not tied to one page. Several pages from the same server can reuse it.

**Key idea:** persistent means one TCP connection per **server**, reused for many requests, and requests can be pipelined.

</details>
