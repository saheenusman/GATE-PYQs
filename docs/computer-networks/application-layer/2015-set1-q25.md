# 2015 CS1 Q25: False statements comparing XML and HTML

## Question

Which of the following statements is/are FALSE?

- I. XML overcomes the limitations in HTML to support a structured way of organizing content.
- II. XML specification is not case sensitive while HTML specification is case sensitive.
- III. XML supports user defined tags while HTML uses pre-defined tags.
- IV. XML tags need not be closed while HTML tags must be closed.

- (A) II only
- (B) I only
- (C) II and IV only
- (D) III and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- I: True. XML describes structured data, which HTML was not designed to do.
- **II: False.** It is the other way round: XML **is** case sensitive and HTML is not.
- III: True. XML lets you define your own tags, HTML has a fixed set.
- **IV: False.** XML tags **must** be closed (well-formedness), while HTML tolerates unclosed tags such as `<br>` or `<p>`.

False: II and IV, option (C). (A) misses IV. (B) calls a true statement false. (D) calls the true III false.

**Key idea:** XML is strict (case-sensitive, always closed), HTML is lenient.

</details>
