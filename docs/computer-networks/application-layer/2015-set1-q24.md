# 2015 CS1 Q24: Number of keys for pairwise secret communication among N people

## Question

Suppose that everyone in a group of $N$ people wants to communicate secretly with the $N-1$ others using a symmetric key cryptographic system. The communication between any two persons should not be decodable by the others in the group. The number of keys required in the system as a whole to satisfy the confidentiality requirement is

- (A) $2N$
- (B) $N(N-1)$
- (C) $N(N-1)/2$
- (D) $(N-1)^2$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A symmetric key is shared by exactly **one pair** of people (anyone else holding it could decode their messages). One key is needed per unordered pair:

$$\binom{N}{2} = \frac{N(N-1)}{2}$$

Check with $N = 3$: three pairs, so 3 keys. (B) $N(N-1) = 6$ counts ordered pairs, double counting because the key for A-to-B is the same as for B-to-A. (A) $2N = 6$ and (D) $(N-1)^2 = 4$ also give the wrong count.

**Key idea:** one symmetric key per unordered pair, $N(N-1)/2$ in total.

</details>
