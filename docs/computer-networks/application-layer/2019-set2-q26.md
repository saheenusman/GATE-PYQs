# 2019 CS2 Q26: Protocols to send and retrieve e-mail

## Question

Which of the following protocol pairs can be used to send and retrieve e-mails (in that order)?

- (A) IMAP, POP3
- (B) SMTP, POP3
- (C) SMTP, MIME
- (D) IMAP, SMTP

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**SMTP** sends (pushes) mail from a client to a server and between servers. **POP3** retrieves mail from the server to the client.

**Why the others fail:**

- (A) IMAP and POP3 are both for retrieval, and there is nothing to send with.
- (C) MIME is a message format (attachments, encodings), not a retrieval protocol.
- (D) Both protocols are real but in the wrong order: IMAP retrieves, SMTP sends.

**Key idea:** SMTP is for sending. POP3 and IMAP are for retrieving.

</details>
