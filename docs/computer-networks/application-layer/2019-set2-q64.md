# 2019 CS2 Q64: Prime factor of an RSA modulus from its totient

## Question

In an RSA cryptosystem, the value of the public modulus parameter $n$ is 3007. If it is also known that $\varphi(n) = 2880$, where $\varphi(\cdot)$ denotes Euler's Totient Function, then the prime factor of $n$ which is greater than 50 is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**97**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $n = pq$ with primes $p, q$. Then

$$\varphi(n) = (p-1)(q-1) = n - (p+q) + 1.$$

So $p + q = n - \varphi(n) + 1 = 3007 - 2880 + 1 = 128$.

$p$ and $q$ are the roots of $x^2 - 128x + 3007 = 0$:

$$\text{discriminant} = 128^2 - 4 \cdot 3007 = 16384 - 12028 = 4356 = 66^2,$$

$$x = \frac{128 \pm 66}{2} = 97 \text{ or } 31.$$

Check: $31 \times 97 = 3007$. The prime factor above 50 is **97**.

**Code check:** a symbolic solve of the quadratic and a factorisation of 3007 both give $31$ and $97$.

**Key idea:** knowing both $n$ and $\varphi(n)$ reveals $p+q$ and $pq$, so the primes are the roots of a quadratic. This is why $\varphi(n)$ must stay secret in RSA.

</details>
