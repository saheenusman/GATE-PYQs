# 2017 CS1 Q44: Private RSA key from p = 13, q = 17 and public key 35

## Question

In a RSA cryptosystem, a participant A uses two prime numbers $p = 13$ and $q = 17$ to generate her public and private keys. If the public key of A is 35, then the private key of A is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**11**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Compute the modulus data.**

$$n = pq = 13 \times 17 = 221,\qquad \varphi(n) = (p-1)(q-1) = 12 \times 16 = 192$$

**Find $d$.** The private key $d$ satisfies $e\,d \equiv 1 \pmod{\varphi(n)}$ with $e = 35$. Check $\gcd(35, 192) = 1$, so $d$ exists. Extended Euclid:

$$192 = 5\cdot35 + 17,\qquad 35 = 2\cdot17 + 1$$

$$1 = 35 - 2\cdot17 = 35 - 2(192 - 5\cdot35) = 11\cdot35 - 2\cdot192$$

So $35 \cdot 11 \equiv 1 \pmod{192}$ and $d = 11$.

**Check.** $35 \times 11 = 385 = 2 \times 192 + 1$.

The answer is **11**.

**Code check:** `pow(35, -1, 192)` gave $11$.

**Key idea:** in RSA, $d$ is the inverse of $e$ modulo $\varphi(n) = (p-1)(q-1)$.

</details>
