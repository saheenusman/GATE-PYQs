# 2013 CS Q13: Digital signature key sequence

## Question

Using public key cryptography, X adds a digital signature $\sigma$ to message $M$, encrypts $\langle M, \sigma \rangle$, and sends it to Y, where it is decrypted. Which one of the following sequences of keys is used for the operations?

- (A) Encryption: X's private key followed by Y's private key; Decryption: X's public key followed by Y's public key
- (B) Encryption: X's private key followed by Y's public key; Decryption: X's public key followed by Y's private key
- (C) Encryption: X's public key followed by Y's private key; Decryption: Y's public key followed by X's private key
- (D) Encryption: X's private key followed by Y's public key; Decryption: Y's private key followed by X's public key

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Sender X:**

1. Sign: encrypt the digest with **X's private key**, so anyone can verify it with X's public key.
2. Encrypt $\langle M,\sigma\rangle$ with **Y's public key**, so only Y can read it.

**Receiver Y** undoes the steps in reverse order:

1. Decrypt with **Y's private key**.
2. Verify the signature with **X's public key**.

That is exactly (D).

**Why the others fail:**

- (A) uses private keys that the other side does not hold (Y's private key to encrypt).
- (B) decrypts in the wrong order: X's public key cannot open data locked with Y's public key.
- (C) signs with a public key, which proves nothing.

**Key idea:** sign with your private key, encrypt with the receiver's public key; decrypt in reverse order.

</details>
