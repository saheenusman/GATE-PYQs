# 2010 CS Q16: Which one is not a client-server application

## Question

Which one of the following is **not** a client server application?

- (A) Internet chat
- (B) Web browsing
- (C) E-mail
- (D) Ping

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Internet chat, web browsing, e-mail:** each has a client program that connects to a server program (a chat server, a web server, a mail server) using an application-layer protocol.
- **Ping:** it sends an ICMP echo request and the destination host's network layer answers with an echo reply. There is no application-layer server process on the other side. It is a network diagnostic tool, not a client-server application.

So (D).

**Classification note and judgement:** this answer rests on how "client-server application" is read, so it has no code check. Ping does have a requesting side and a replying side, but the reply comes from the operating system's ICMP handler and not from a server program, which is why it is not counted. Matches the official key.

**Key idea:** client-server applications need a server process at the application layer; ping works at the network layer with ICMP.

</details>
