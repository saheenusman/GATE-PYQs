# 2020 CS Q35: TCP connections to load a page with five images over non-persistent HTTP

## Question

Assume that you have made a request for a web page through your web browser to a web server. Initially the browser cache is empty. Further, the browser is configured to send HTTP requests in non-persistent mode. The web page contains text and five very small images. The minimum number of TCP connections required to display the web page completely in your browser is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In **non-persistent** HTTP, every request/response pair uses its own TCP connection, and the connection is closed after the response.

| Object | Connections |
|---|---|
| The HTML page (text) | 1 |
| Five images | 5 (one each) |
| **Total** | **6** |

The browser may open several connections in parallel to save time, but that does not change the *number*. The cache is empty, so no object can be skipped.

**Key idea:** non-persistent HTTP needs one TCP connection per object, so the page plus its five images need $1 + 5 = 6$.

</details>
