# 2015 CS2 Q35: The incorrect statement about HTTP cookies

## Question

Which one of the following statements is NOT correct about HTTP cookies?

- (A) A cookie is a piece of code that has the potential to compromise the security of an Internet user
- (B) A cookie gains entry to the user's work area through an HTTP header
- (C) A cookie has an expiry date and time
- (D) Cookies can be used to track the browsing pattern of a user at a particular site

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A cookie is a small piece of **data** (a name-value pair with attributes), not executable code, so it cannot run on its own or break in as a program.

- (A) **Not correct.** A cookie is not code.
- (B) Correct. Cookies are carried in HTTP headers (`Set-Cookie`, `Cookie`).
- (C) Correct. A cookie can carry an `Expires` or `Max-Age` attribute.
- (D) Correct. Sites use cookies to track visits and sessions.

Option (A).

**Key idea:** cookies are passive data sent in HTTP headers; they are not programs.

</details>
