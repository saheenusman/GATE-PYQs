# 2022 CS Q35: DNS query-response pairs for www.gate.org.in

## Question

Consider the resolution of the domain name `www.gate.org.in` by a DNS resolver. Assume that no resource records are cached anywhere across the DNS servers and that iterative query mechanism is used in the resolution. The number of DNS query-response pairs involved in completely resolving the domain name is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Walk down the hierarchy.** With iterative queries, the resolver contacts each server in turn:

| # | Server asked | Reply |
| --- | --- | --- |
| 1 | root | refers to the `.in` server |
| 2 | `in` | refers to the `org.in` server |
| 3 | `org.in` | refers to the `gate.org.in` server |
| 4 | `gate.org.in` | returns the address of `www.gate.org.in` |

That is **4** query-response pairs.

**Assumption:** the question counts the resolver's queries to the root, `in`, `org.in` and `gate.org.in` servers. The query from the host to its local resolver is not counted. This matches the official answer.

**Key idea:** an iterative resolution takes one query per level of the name, ending at the authoritative server.

</details>
