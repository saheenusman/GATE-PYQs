# 2011 CS Q4: Application protocols for the three email activities

## Question

Consider different activities related to email.

- m1: Send an email from a mail client to a mail server
- m2: Download an email from mailbox server to a mail client
- m3: Checking email in a web browser

Which is the application level protocol used in each activity?

| Option | m1 | m2 | m3 |
|---|---|---|---|
| (A) | HTTP | SMTP | POP |
| (B) | SMTP | FTP | HTTP |
| (C) | SMTP | POP | HTTP |
| (D) | POP | SMTP | IMAP |

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **m1** (client to server, sending): **SMTP**, the mail submission and transfer protocol.
- **m2** (mailbox server to client, retrieval): **POP** (IMAP is the other retrieval protocol).
- **m3** (reading mail in a web browser): **HTTP**, since the browser talks to a webmail server over the web.

That is the row of (C).

- (A) SMTP cannot retrieve mail and HTTP is not the client-to-server sending protocol of a mail client.
- (B) FTP is for file transfer, not mailbox download.
- (D) POP is a retrieval protocol, not a sending one, and a browser does not use IMAP directly.

**Key idea:** SMTP pushes mail, POP/IMAP pull mail, and webmail rides on HTTP.

</details>
