# 2014 CS3 Q23: Incorrect pair of OSI layer and functionality

## Question

In the following pairs of OSI protocol layer/sub-layer and its functionality, the **INCORRECT** pair is

- (A) Network layer and Routing
- (B) Data Link Layer and Bit synchronization
- (C) Transport layer and End-to-end process communication
- (D) Medium Access Control sub-layer and Channel sharing

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) correct: the network layer routes packets from source to destination.
- (B) **incorrect:** bit synchronisation (agreeing on bit boundaries and clocking) is done by the **physical layer**. The data link layer handles framing, error control and flow control.
- (C) correct: the transport layer provides end-to-end (process-to-process) communication.
- (D) correct: the MAC sub-layer arbitrates access to a shared channel.

**Key idea:** the physical layer deals with bits and their timing; the data link layer deals with frames.

</details>
