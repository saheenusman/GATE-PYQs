# 2007 CS Q70: Match protocols with layers

## Question

Match the following:

| | |
|---|---|
| P. SMTP | 1. Application layer |
| Q. BGP | 2. Transport layer |
| R. TCP | 3. Data link layer |
| S. PPP | 4. Network layer |
| | 5. Physical layer |

- (A) P-2, Q-1, R-3, S-5
- (B) P-1, Q-4, R-2, S-3
- (C) P-1, Q-4, R-2, S-5
- (D) P-2, Q-4, R-1, S-3

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **SMTP** (mail transfer): application layer (1).
- **BGP** (inter-domain routing): treated here as a network-layer routing protocol (4).
- **TCP**: transport layer (2).
- **PPP** (point-to-point link protocol, framing and link control): data link layer (3).

So P-1, Q-4, R-2, S-3: (B).

- (A) puts SMTP at the transport layer and PPP at the physical layer.
- (C) puts PPP at the physical layer; PPP frames data, which is a data-link function.
- (D) puts SMTP at the transport layer and TCP at the application layer.

**Code check:** not applicable (matching question).

**Borderline:** BGP is strictly an application-layer protocol (it runs over TCP), but it is a *routing* protocol and textbooks often list it with the network layer. The options force this reading, since only (B) gets SMTP, TCP and PPP right.
