# 2015 CS3 Q56: Time to send 10000 bits in two packets through a store-and-forward switch

## Question

Two hosts are connected via a packet switch with $10^7$ bits per second links. Each link has a propagation delay of 20 microseconds. The switch begins forwarding a packet 35 microseconds after it receives the same. If 10000 bits of data are to be transmitted between the two hosts using a packet size of 5000 bits, the time elapsed between the transmission of the first bit of data and the reception of the last bit of the data in microseconds is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**1575**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Two packets of 5000 bits. Transmission time per packet per link: $5000 / 10^7 = 500\ \mu s$.

**Packet 1** (all times in $\mu s$):

- Host sends it from 0 to 500. Fully received at the switch at $500 + 20 = 520$.
- The switch waits 35: starts forwarding at 555, and finishes sending at $555 + 500 = 1055$.
- Last bit reaches host B at $1055 + 20 = 1075$.

**Packet 2:**

- Host sends it from 500 to 1000. Fully received at the switch at $1000 + 20 = 1020$.
- Ready to forward at $1020 + 35 = 1055$. The outgoing link frees up at exactly 1055 (packet 1 just finished), so it starts at 1055 and ends at 1555.
- Last bit reaches host B at $1555 + 20 = 1575$.

**Answer: 1575.**

**Assumption.** "Receives the same" is read as the switch having the **whole** packet (store-and-forward). This reading gives the official key.

**Code check:** the timeline above, computed step by step, ends at 1075 for packet 1 and 1575 for packet 2.

**Key idea:** with store-and-forward, pipeline the packets: the switch forwards packet 1 while the host is still sending packet 2.

</details>
