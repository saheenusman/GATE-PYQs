# 2012 CS Q10: PDU of the application layer

## Question

The protocol data unit (PDU) for the application layer in the Internet stack is

- (A) Segment
- (B) Datagram
- (C) Message
- (D) Frame

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Layer | PDU |
|---|---|
| Application | **Message** |
| Transport | Segment (TCP) or datagram (UDP) |
| Network | Datagram or packet |
| Link | Frame |

So the application layer's PDU is a message: (C).

- (A) is the transport layer's (TCP).
- (B) is the network layer's.
- (D) is the link layer's.

**Key idea:** each layer wraps the PDU from above with its own header: message, segment, datagram, frame.

</details>
