# 2017 CS2 Q35: Transmission and propagation delay for a 50,000-byte file over a 10,000 km link

## Question

Consider two hosts $X$ and $Y$, connected by a single direct link of rate $10^6$ bits/sec. The distance between the two hosts is 10,000 km and the propagation speed along the link is $2 \times 10^8$ m/sec. Host $X$ sends a file of 50,000 bytes as one large message to host $Y$ continuously. Let the transmission and propagation delays be $p$ milliseconds and $q$ milliseconds, respectively. Then the values of $p$ and $q$ are

- (A) $p = 50$ and $q = 100$
- (B) $p = 50$ and $q = 400$
- (C) $p = 100$ and $q = 50$
- (D) $p = 400$ and $q = 50$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Transmission delay** = message size / link rate:

$$p = \frac{50{,}000 \times 8 \text{ bits}}{10^6 \text{ bits/s}} = 0.4 \text{ s} = 400 \text{ ms}.$$

**Propagation delay** = distance / signal speed:

$$q = \frac{10{,}000 \text{ km}}{2\times 10^{8} \text{ m/s}} = \frac{10^{7}\text{ m}}{2\times10^{8}\text{ m/s}} = 0.05 \text{ s} = 50 \text{ ms}.$$

So $p = 400$ and $q = 50$: **(D)**.

**Why the others fail.** (A), (B) have $p = 50$ ms, which is what you get if you forget to multiply bytes by 8 ($50{,}000/10^6$); their $q$ values (100, 400) do not match $d/s = 50$ ms either. (C) has $p = 100$, which is not the transmission delay under any reading of 400,000 bits at $10^6$ bits/s.

**Code check:** the arithmetic above evaluated to exactly 400.0 ms and 50.0 ms.

**Key idea:** transmission delay $= L/R$ (convert bytes to bits); propagation delay $= d/s$.

</details>
