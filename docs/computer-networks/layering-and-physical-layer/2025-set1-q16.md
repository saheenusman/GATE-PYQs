# 2025 CS1 Q16: Matching OSI layers with their functions

## Question

Identify the ONE CORRECT matching between the OSI layers and their corresponding functionalities as shown.

| OSI Layers | Functionalities |
|---|---|
| (a) Network layer | (I) Packet routing |
| (b) Transport layer | (II) Framing and error handling |
| (c) Datalink layer | (III) Host to host communication |

- (A) (a)-(I), (b)-(II), (c)-(III)
- (B) (a)-(I), (b)-(III), (c)-(II)
- (C) (a)-(II), (b)-(I), (c)-(III)
- (D) (a)-(III), (b)-(II), (c)-(I)

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Layer | Main function | Match |
|---|---|---|
| Network | Moves packets from source to destination across networks, choosing routes | (I) packet routing |
| Transport | End-to-end (host-to-host, between the communicating applications) delivery, reliability, flow control | (III) host to host communication |
| Data link | Groups bits into **frames** on one link and detects or handles errors on that link | (II) framing and error handling |

So (a)-(I), (b)-(III), (c)-(II): option B.

| Option | Why wrong |
|---|---|
| A | Gives framing to the transport layer and host-to-host to the data link layer |
| C | Gives routing to the transport layer |
| D | Gives framing to the transport layer and routing to the data link layer |

**Key idea:** data link = frames on one link, network = routing between networks, transport = end-to-end between hosts.

</details>
