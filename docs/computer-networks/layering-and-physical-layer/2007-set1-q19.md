# 2007 CS Q19: Bit rate with Manchester encoding in Ethernet

## Question

In Ethernet when Manchester encoding is used, the bit rate is:

- (A) Half the baud rate.
- (B) Twice the baud rate.
- (C) Same as the baud rate.
- (D) None of the above.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Manchester encoding puts a voltage transition in the middle of every bit, so each bit is sent as **two** signal elements (for example low-high for 0, high-low for 1).

Baud rate counts signal elements per second, so it is twice the bit rate; equivalently the bit rate is **half the baud rate**: (A).

- (B) has the relationship inverted.
- (C) would hold for plain NRZ, which uses one signal element per bit.
- (D) is wrong because (A) is correct. (10 Mbps Ethernet signals at 20 Mbaud.)

**Key idea:** Manchester uses two signal elements per bit, so baud rate $= 2 \times$ bit rate.
