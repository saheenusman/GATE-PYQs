# 2013 CS Q36: Maximum Ethernet cable length

## Question

Determine the maximum length of the cable (in km) for transmitting data at a rate of 500 Mbps in an Ethernet LAN with frames of size 10,000 bits. Assume the signal speed in the cable to be 2,00,000 km/s.

- (A) 1
- (B) 2
- (C) 2.5
- (D) 5

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

CSMA/CD needs the transmission time to be at least the round-trip propagation time, so a sender is still transmitting when a collision signal returns.

$$T_t \ge 2 T_p$$

- $T_t = 10{,}000 / (500\times10^6) = 20\ \mu s$
- $T_p \le 10\ \mu s$ (half of $T_t$)
- Distance $= T_p \times v = 10\times10^{-6}\ \text{s} \times 2\times10^{5}\ \text{km/s} = 2$ km

**Why the others fail:**

- (A) 1 km satisfies the condition, but it is not the **maximum** length.
- (C) 2.5 km needs $2T_p = 25\ \mu s > 20\ \mu s = T_t$, so a sender could finish before a collision is heard.
- (D) 5 km is even longer ($2T_p = 50\ \mu s$) and fails the same way.

**Code check:** the arithmetic gave 2 km.

**Key idea:** CSMA/CD requires $T_t \ge 2T_p$, so max length $= v \cdot T_t / 2$.

</details>
