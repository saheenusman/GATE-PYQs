# 2014 CS3 Q24: Input bit string for a bit-stuffed output

## Question

A bit-stuffing based framing protocol uses an 8-bit delimiter pattern of 01111110. If the output bit-string after stuffing is 01111100101, then the input bit-string is

- (A) 0111110100
- (B) 0111110101
- (C) 0111111101
- (D) 0111111111

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The delimiter has six 1s in a row. To stop that pattern occurring in the data, the sender inserts a **0 after every run of five consecutive 1s**.

Read the output `01111100101` from the left:

`0` `11111` **`0`** `0` `1` `0` `1`

After the five 1s, the next 0 is the stuffed bit. Remove it:

$$01111\,1\,0101 \to 0111110101.$$

Check by stuffing each option:

| Option | After stuffing |
|---|---|
| A `0111110100` | `01111100100` (last bit differs) |
| **B** `0111110101` | **`01111100101`** (matches) |
| C `0111111101` | `01111101101` |
| D `0111111111` | `01111101111` |

**Code check:** a stuffing function applied to the four options reproduces the table.

**Key idea:** on the receiver side, drop the 0 that follows any five consecutive 1s.

</details>
