# 2019 CS2 Q39: How a host finds the MAC address of another host

## Question

Suppose that in an IP-over-Ethernet network, a machine X wishes to find the MAC address of another machine Y in its subnet. Which one of the following techniques can be used for this?

- (A) X sends an ARP request packet to the local gateway's IP address which then finds the MAC address of Y and sends to X
- (B) X sends an ARP request packet to the local gateway's MAC address which then finds the MAC address of Y and sends to X
- (C) X sends an ARP request packet with broadcast MAC address in its local subnet
- (D) X sends an ARP request packet with broadcast IP address in its local subnet

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Y is on the **same subnet**, so X resolves Y directly. X does not know Y's MAC, so it sends an ARP request inside an Ethernet frame whose destination is the **broadcast MAC address** (FF:FF:FF:FF:FF:FF). Every host on the subnet receives it, and only Y replies, in a unicast frame, with its MAC.

**Why the others fail:**

- (A) and (B) involve the gateway. The gateway is for off-subnet traffic, and it is not asked to find Y's MAC for X.
- (D) ARP frames are addressed at the link layer. The IP broadcast address belongs to IP datagrams, not to ARP requests.

**Key idea:** ARP asks "who has this IP?" by broadcast at the link layer. The owner answers by unicast.

</details>
