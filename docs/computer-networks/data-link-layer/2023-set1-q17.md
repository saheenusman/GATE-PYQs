# 2023 CS Q17: Stop-and-Wait: scenario with lowest utilization

## Question

Suppose two hosts are connected by a point-to-point link and they are configured to use Stop-and-Wait protocol for reliable data transfer. Identify in which one of the following scenarios, the utilization of the link is the lowest.

- (A) Longer link length and lower transmission rate
- (B) Longer link length and higher transmission rate
- (C) Shorter link length and lower transmission rate
- (D) Shorter link length and higher transmission rate

<details class="success" markdown="1">
<summary>Answer</summary>

**B (longer link, higher transmission rate)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Utilization.** Let $T_t$ be the transmission time and $T_p$ the propagation delay:

$$U = \frac{T_t}{T_t + 2T_p} = \frac{1}{1 + 2a}, \qquad a = \frac{T_p}{T_t}$$

$U$ is lowest when $a$ is largest.

- A **longer link** raises $T_p$.
- A **higher transmission rate** shortens $T_t$.

Both push $a$ up, so the lowest utilization is at **B**.

**Why the others fail:** A and C have a lower rate (larger $T_t$), D has a short link. Each gives a smaller $a$ than B.

**Key idea:** Stop-and-Wait wastes time waiting for the ACK, so fast, long links suffer most.

</details>
