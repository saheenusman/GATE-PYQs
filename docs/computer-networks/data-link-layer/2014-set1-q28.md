# 2014 CS1 Q28: Selective repeat: bits needed for the sequence number

## Question

Consider a selective repeat sliding window protocol that uses a frame size of 1 KB to send data on a 1.5 Mbps link with a one-way latency of 50 msec. To achieve a link utilization of 60%, the minimum number of bits required to represent the sequence number field is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Frame transmission time: $T_t = \dfrac{1\text{ KB}}{1.5\text{ Mbps}} = \dfrac{8192}{1.5 \times 10^6} \approx 5.46$ ms.

Utilisation with window $W$:

$$U = \frac{W\,T_t}{T_t + 2T_p} \ge 0.6 \Rightarrow W \ge \frac{0.6\,(5.46 + 100)}{5.46} \approx 11.6 \Rightarrow W = 12$$

Selective repeat needs a sequence space of $2W = 24$ numbers so that old and new windows do not overlap:

$$2^n \ge 24 \Rightarrow n = 5$$

**Code check:** with 1 KB $= 1024$ bytes, $W = 11.59 \to 12$; with 1 KB $= 1000$ bytes, $W = 11.85 \to 12$. Both give $n = 5$.

**Key idea:** SR needs $2W$ sequence numbers; $W$ comes from the utilisation formula.

</details>
