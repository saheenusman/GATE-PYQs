# 2016 CS1 Q55: Sender throughput of Stop-and-Wait ARQ with unequal link rates

## Question

A sender uses the Stop-and-Wait ARQ protocol for reliable transmission of frames. Frames are of size 1000 bytes and the transmission rate at the sender is 80 Kbps (1 Kbps = 1000 bits/second). Size of an acknowledgement is 100 bytes and the transmission rate at the receiver is 8 Kbps. The one-way propagation delay is 100 milliseconds.

Assuming no frame is lost, the sender throughput is ______ bytes/second.

<details class="success" markdown="1">
<summary>Answer</summary>

**2500**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In Stop-and-Wait, one frame is sent per full cycle. Add up the delays in one cycle.

| Part | Calculation | Time |
|---|---|---|
| Send the frame | $8000\ \text{bits} / 80{,}000\ \text{bps}$ | $100$ ms |
| Frame propagation | given | $100$ ms |
| Send the ACK | $800\ \text{bits} / 8000\ \text{bps}$ | $100$ ms |
| ACK propagation | given | $100$ ms |
| **Cycle** | | **$400$ ms** |

**Throughput.**

$$\frac{1000\ \text{bytes}}{0.4\ \text{s}} = 2500\ \text{bytes/s}$$

**Key idea:** one frame per 400 ms cycle: $1000 / 0.4 = 2500$ bytes/s.

</details>
