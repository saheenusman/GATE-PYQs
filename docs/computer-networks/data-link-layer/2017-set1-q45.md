# 2017 CS1 Q45: Efficiency of Stop-and-Wait ARQ with given frame sizes and delays

## Question

The values of parameters for the Stop-and-Wait ARQ protocol are as given below:

- Bit rate of the transmission channel = 1 Mbps.
- Propagation delay from sender to receiver = 0.75 ms.
- Time to process a frame = 0.25 ms.
- Number of bytes in the information frame = 1980.
- Number of bytes in the acknowledge frame = 20.
- Number of overhead bytes in the information frame = 20.

Assume that there are no transmission errors. Then, the transmission efficiency (expressed in percentage) of the Stop-and-Wait ARQ protocol for the above parameters is ______ (correct to 2 decimal places).

<details class="success" markdown="1">
<summary>Answer</summary>

**88.34** (the key accepts 86.5 to 89.5)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Times at 1 Mbps** ($1$ byte $= 8\ \mu s$):

- Information frame: $1980 \times 8\ \mu s = 15.84$ ms
- Acknowledgement frame: $20 \times 8\ \mu s = 0.16$ ms
- Useful data in the frame: $(1980-20)$ bytes $= 1960$ bytes, i.e. $15.68$ ms of transmission

**One cycle of Stop-and-Wait.**

$$T = T_{\text{frame}} + t_p + t_{\text{proc}} + T_{\text{ack}} + t_p = 15.84 + 0.75 + 0.25 + 0.16 + 0.75 = 17.75\text{ ms}$$

**Efficiency** (useful time over cycle time):

$$\eta = \frac{15.68}{17.75} \approx 0.8834 = \mathbf{88.34\%}$$

**Official range.** The key accepts **86.5 to 89.5**, so 88.34 is inside it.

**Other readings that also land in range.**

- Counting all 1980 bytes as useful: $15.84/17.75 = 89.24\%$.
- Charging the 0.25 ms processing twice (once per side): $15.68/18.00 = 87.11\%$.
- Dropping the processing time altogether gives $89.60\%$, which is *outside* the range, so processing time has to be included.

**Code check:** a short calculation reproduced $T=17.75$ ms and $88.34\%$, and the three variants above.

**Key idea:** efficiency $=$ useful transmission time $\big/$ (frame time $+$ ack time $+$ two propagation delays $+$ processing).

</details>
