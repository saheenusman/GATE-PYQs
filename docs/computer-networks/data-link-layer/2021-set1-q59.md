# 2021 CS1 Q59: Sender window needed for 50% utilization

## Question

Consider the sliding window flow-control protocol operating between a sender and a receiver over a full-duplex error-free link. Assume the following:

- The time taken for processing the data frame by the receiver is negligible.
- The time taken for processing the acknowledgement frame by the sender is negligible.
- The sender has infinite number of frames available for transmission.
- The size of the data frame is 2,000 bits and the size of the acknowledgement frame is 10 bits.
- The link data rate in each direction is 1 Mbps ($=10^6$ bits per second).
- One way propagation delay of the link is 100 milliseconds.

The minimum value of the sender's window size in terms of the number of frames, (rounded to the nearest integer) needed to achieve a link utilization of 50% is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**51**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Times (in ms).**

- Data frame transmission: $2000/10^6\text{ s}=2$ ms.
- Ack transmission: $10/10^6\text{ s}=0.01$ ms.
- Round trip: $2\times100=200$ ms of propagation.

One cycle (send the first frame, then get its ack back): $2+200+0.01=202.01$ ms.

In a window of $W$ frames, the sender is busy for $W\times2$ ms out of each 202.01 ms cycle (as long as $W$ frames do not fill the whole cycle). Utilization:

$$U=\frac{2W}{202.01}\ge0.5\ \Rightarrow\ W\ge50.5025$$

The smallest whole window is **51** frames.

If the 0.01 ms ack time is ignored, $W\ge50.5$, which also gives 51. The official key accepts **50 to 52**, so rounding 50.5 down to 50, or counting the ack time and taking 52, are accepted. My answer is 51. I computed the value in a script: 50.5025.

**Key idea:** $U=\dfrac{W\,T_t}{T_t+2T_p+T_{ack}}$ for sliding window, so $W=\dfrac{U(T_t+2T_p+T_{ack})}{T_t}$.

</details>
