# 2019 CS2 Q59: Minimum number of 8-port switches to connect 15 machines

## Question

Consider that 15 machines need to be connected in a LAN using 8-port Ethernet switches. Assume that these switches do not have any separate uplink ports. The minimum number of switches needed is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

With no uplink ports, a switch connects to another switch through an ordinary port, using up a port on each side. Connecting $k$ switches into one network (a tree) needs $k - 1$ links, which use $2(k-1)$ ports.

Ports needed: $15$ (machines) $+ 2(k-1)$. Ports available: $8k$.

| $k$ | Needed | Available | Enough? |
|---|---|---|---|
| 1 | 15 | 8 | No |
| 2 | 17 | 16 | No |
| **3** | 19 | 24 | **Yes** |

Condition: $15 + 2(k-1) \le 8k \iff 13 \le 6k \iff k \ge 3$ (since $13/6 \approx 2.17$).

**Key idea:** every switch-to-switch link costs two ports, so count machine ports and trunk ports together.

</details>
