# 2017 CS1 Q32: CRC codeword for 01011011 with generator x^3 + x + 1

## Question

A computer network uses polynomials over $GF(2)$ for error checking with 8 bits as information bits and uses $x^{3} + x + 1$ as the generator polynomial to generate the check bits. In this network, the message $01011011$ is transmitted as

- (A) $01011011010$
- (B) $01011011011$
- (C) $01011011101$
- (D) $01011011100$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Set-up.** The generator $x^3+x+1$ is the bit string $1011$ (degree 3, so 3 check bits). Append three zeros to the message and divide by $1011$ using XOR (mod-2 division):

$$01011011\,000 \;\div\; 1011$$

**Division, step by step.** Each time the leftmost 1 is found, XOR $1011$ into the four bits starting there:

| Working bits | Leading 1 at bit | Window | Window XOR $1011$ | Result |
|---|---|---|---|---|
| `01011011000` | 1 | `1011` | `0000` | `00000011000` |
| `00000011000` | 6 | `1100` | `0111` | `00000001110` |
| `00000001110` | 7 | `1110` | `0101` | `00000000101` |

Bits are numbered from 0 on the left. After the last XOR the three low bits are the remainder:

$$\text{remainder} = 101$$

The transmitted codeword is the message followed by the remainder:

$$01011011\;101 = 01011011101$$

This is **(C)**.

**Check.** A valid codeword must be divisible by $1011$ (remainder $000$). Dividing $01011011101$ by $1011$ leaves $000$.

**Why the others fail.** Dividing each candidate by $1011$ leaves a non-zero remainder: (A) $111$, (B) $110$, (D) $001$. So none is a valid codeword.

**Code check:** an XOR long-division program gave check bits $101$. The remainders of the four options were $111$, $110$, $000$ and $001$ for (A), (B), (C), (D).

**Key idea:** CRC check bits are the remainder of (message followed by zeros) divided by the generator; the codeword is then exactly divisible by the generator.

</details>
