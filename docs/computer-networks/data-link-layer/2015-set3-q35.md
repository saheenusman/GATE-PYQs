# 2015 CS3 Q35: Signal speed from the minimum frame size of a CSMA/CD network

## Question

Consider a CSMA/CD network that transmits data at a rate of 100 Mbps ($10^8$ bits per second) over a 1 km (kilometer) cable with no repeaters. If the minimum frame size required for this network is 1250 bytes, what is the signal speed (km/sec) in the cable?

- (A) 8000
- (B) 10000
- (C) 16000
- (D) 20000

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For collision detection, transmitting the minimum frame must take at least one round trip:

$$T_t = 2\,T_p$$

$$T_t = \frac{1250 \times 8\ \text{bits}}{10^8\ \text{bits/s}} = 100\ \mu s \;\Rightarrow\; T_p = 50\ \mu s$$

$$\text{speed} = \frac{1\ \text{km}}{50 \times 10^{-6}\ \text{s}} = 20000\ \text{km/s}$$

Option (D).

The other options would come from using $T_t = T_p$ (speed 10000 for $T_p = 100\ \mu s$) or other mistaken ratios.

**Code check:** the arithmetic above gives exactly 20000.

**Key idea:** minimum frame size $= 2 \times T_p \times$ bandwidth.

</details>
