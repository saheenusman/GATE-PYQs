# 2016 CS2 Q53: Minimum CSMA/CD frame size for given bandwidth and propagation time

## Question

A network has a data transmission bandwidth of $20 \times 10^6$ bits per second. It uses CSMA/CD in the MAC layer. The maximum signal propagation time from one node to another node is 40 microseconds. The minimum size of a frame in the network is ______ bytes.

<details class="success" markdown="1">
<summary>Answer</summary>

**200**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For CSMA/CD the transmission time must be at least the round-trip propagation time, so the sender is still transmitting when a collision signal returns:

$$T_t \ge 2T_p \;\Rightarrow\; L_{\min} = 2 \cdot T_p \cdot B$$

$$L_{\min} = 2 \times 40 \times 10^{-6} \times 20 \times 10^{6} = 1600\ \text{bits} = 200\ \text{bytes}$$

**Code check:** the same product evaluates to $200.0$ bytes.

**Key idea:** $L_{\min} = 2 T_p B = 1600$ bits $= 200$ bytes.

</details>
