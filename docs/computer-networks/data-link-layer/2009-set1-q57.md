# 2009 CS Q57: Bits needed for sequence numbers on a long link

## Question

**Statement for linked answer questions 57 and 58.** Frames of 1000 bits are sent over a $10^6$ bps duplex link between two hosts. The propagation time is 25 ms. Frames are to be transmitted into this link to maximally pack them in transit (within the link).

**Q57.** What is the minimum number of bits ($l$) that will be required to represent the sequence numbers distinctly? Assume that no time gap needs to be given between transmission of two frames.

- (A) $l = 2$
- (B) $l = 3$
- (C) $l = 4$
- (D) $l = 5$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Transmission time of one frame:**

$$\frac{1000\ \text{bits}}{10^6\ \text{bits/s}} = 1\ \text{ms}.$$

Frames are sent back to back, so one frame enters the link every $1$ ms. A frame spends $25$ ms in the link, so about

$$\frac{25\ \text{ms}}{1\ \text{ms}} = 25$$

frames are in transit at once (the bandwidth-delay product is $10^6 \times 0.025 = 25000$ bits, which is $25$ frames; counting the frame still being sent makes it $26$).

All these frames need distinct sequence numbers, so we need at least $25$ (or $26$) numbers:

$$2^l \ge 25 \Rightarrow l \ge 5.$$

So $l = 5$: (D).

- (A), (B), (C): $2^2 = 4$, $2^3 = 8$ and $2^4 = 16$ are all fewer than the $25$ frames in the link.

**Code check:** the arithmetic was run: transmission time $1.000$ ms, frames in the link $25.0$, and $\lceil \log_2 25 \rceil = \lceil \log_2 26 \rceil = 5$.

**Key idea:** the number of frames in flight is the bandwidth-delay product divided by the frame size; the sequence numbers must distinguish all of them.

</details>
