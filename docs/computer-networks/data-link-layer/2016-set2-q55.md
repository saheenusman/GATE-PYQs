# 2016 CS2 Q55: Sequence number bits for 100 percent utilisation with selective repeat

## Question

Consider a $128 \times 10^3$ bits/second satellite communication link with one way propagation delay of 150 milliseconds. Selective retransmission (repeat) protocol is used on this link to send data with a frame size of 1 kilobyte. Neglect the transmission time of acknowledgement. The minimum number of bits required for the sequence number field to achieve 100% utilization is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Frames in flight needed.**

- Frame transmission time: $T_t = \dfrac{8192\ \text{bits}}{128000\ \text{bits/s}} = 64\ \text{ms}$ (with $1\ \text{KB} = 1024$ bytes).
- One cycle, from the start of sending a frame until its ACK returns: $T_t + 2T_p = 64 + 300 = 364\ \text{ms}$.
- Window needed for $100\%$ utilisation: $W = \lceil 364/64 \rceil = \lceil 5.69 \rceil = 6$ frames.

**Selective repeat needs sequence numbers for twice the window**, so that old and new frames in the receiver window cannot be confused:

$$2W = 12 \le 2^k \;\Rightarrow\; k = 4\ \text{bits}$$

(With $1\ \text{KB} = 1000$ bytes, $T_t = 62.5$ ms, $W = \lceil 362.5/62.5 \rceil = 6$ again, and the answer is the same.)

**Code check:** both frame-size conventions gave window $6$ and $4$ sequence bits.

**Key idea:** window $= 6$ frames; selective repeat needs $2 \times 6 = 12$ sequence numbers, so 4 bits.

</details>
