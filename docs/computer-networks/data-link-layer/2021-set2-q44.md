# 2021 CS2 Q44: CRC check bits for message 11000

## Question

Consider the cyclic redundancy check (CRC) based error detecting scheme having the generator polynomial $X^3+X+1$. Suppose the message $m_4m_3m_2m_1m_0=11000$ is to be transmitted. Check bits $c_2c_1c_0$ are appended at the end of the message by the transmitter using the above CRC scheme. The transmitted bit string is denoted by $m_4m_3m_2m_1m_0c_2c_1c_0$. The value of the checkbit sequence $c_2c_1c_0$ is

- (A) 101
- (B) 110
- (C) 100
- (D) 111

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The generator $X^3+X+1$ is the bit string $1011$ (degree 3, so 3 check bits).

Append 3 zeros to the message: $11000\,000$. Divide by $1011$ using XOR:

| step | bits | XOR with 1011 | result |
|---|---|---|---|
| 1 | 1100 | 1011 | 0111 |
| 2 | 1110 | 1011 | 0101 |
| 3 | 1010 | 1011 | 0001 |

Bringing down the remaining bits, the final 3-bit remainder is **100**. So $c_2c_1c_0=100$ and the transmitted string is 11000100.

**Second check with polynomials mod $X^3+X+1$:** $X^3=X+1$, so $X^6=X^2+1$ and $X^7=1$. The message with 3 zeros appended is $X^7+X^6$, so

$$X^7+X^6\equiv1+X^2+1=X^2\ \Rightarrow\ 100.$$

A script doing the same division also gives 100.

- (A), (B), (D) are what one gets from slips such as appending the wrong number of zeros or stopping early.

**Key idea:** append $r$ zeros, divide by the generator over GF(2) (XOR); the remainder is the check bits.

</details>
