# 2021 CS2 Q64: Throughput of pure ALOHA

## Question

Consider a network using the pure ALOHA medium access control protocol, where each frame is of length 1,000 bits. The channel transmission rate is 1 Mbps ($=10^6$ bits per second). The aggregate number of transmissions across all the nodes (including new frame transmissions and retransmitted frames due to collisions) is modelled as a Poisson process with a rate of 1,000 frames per second. Throughput is defined as the average number of frames successfully transmitted per second. The throughput of the network (rounded to the nearest integer) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**135**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Frame time: $T=\dfrac{1000\text{ bits}}{10^6\text{ bits/s}}=1\text{ ms}$.

Offered load (frames per frame time): $G=1000\text{ frames/s}\times10^{-3}\text{ s}=1$.

Pure ALOHA throughput per frame time: $S=Ge^{-2G}=e^{-2}\approx0.1353$.

In frames per second:

$$1000\times0.1353\approx135.$$

The key accepts 130 to 140.

**Key idea:** a pure ALOHA frame succeeds if no other frame starts within $2T$ of it, which has probability $e^{-2G}$.

</details>
