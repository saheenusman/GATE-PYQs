# 2024 CS2 Q55: Minimum Ethernet frame size for collision detection

## Question

Consider an Ethernet segment with a transmission speed of $10^8$ bits/sec and a maximum segment length of 500 meters. If the speed of propagation of the signal in the medium is $2 \times 10^8$ meters/sec, then the minimum frame size (in bits) required for collision detection is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**500**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

To detect a collision, the sender must still be transmitting when the collision signal comes back from the far end. So the frame transmission time must be at least the **round-trip propagation time**.

- One-way propagation: $500 / (2 \times 10^8) = 2.5\ \mu s$.
- Round trip: $2 \times 2.5 = 5\ \mu s$.

**Minimum frame size** $=$ bandwidth $\times$ round-trip time:

$$10^8 \times 5 \times 10^{-6} = 500 \text{ bits.}$$

**Key idea (CSMA/CD):** $L_{min} = 2 \times t_{prop} \times \text{bandwidth}$.

</details>
