# 2007 CS Q68: CRC message for the polynomial x^3 + 1

## Question

The message 11001001 is to be transmitted using the CRC polynomial $x^3 + 1$ to protect it from errors. The message that should be transmitted is:

- (A) 11001001000
- (B) 11001001011
- (C) 11001010
- (D) 110010010011

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The generator $x^3 + 1$ is $1001$ (degree 3). Append $3$ zeros to the message: $11001001\,000$. Divide by $1001$ using XOR (mod-2 division) and take the 3-bit remainder:

| Step | 4-bit window | Leading bit | XOR with | Window after |
|---|---|---|---|---|
| 1 | 1100 | 1 | 1001 | 0101 |
| 2 | 1011 | 1 | 1001 | 0010 |
| 3 | 0100 | 0 | 0000 | 0100 |
| 4 | 1000 | 1 | 1001 | 0001 |
| 5 | 0011 | 0 | 0000 | 0011 |
| 6 | 0110 | 0 | 0000 | 0110 |
| 7 | 1100 | 1 | 1001 | 0101 |
| 8 | 1010 | 1 | 1001 | 0011 |

(Each step looks at the 4 bits starting at the next position, using the bits already updated by earlier steps; the last 3 bits after step 8 are the remainder.)

Remainder $= 011$. Transmit message plus remainder: $11001001\,011$ = **11001001011**: (B).

- (A) appends only zeros, which is not the codeword.
- (C) has no check bits at all.
- (D) appends 4 bits, but the generator has degree 3.

**Code check:** Python mod-2 long division of `11001001000` by `1001`: remainder `011`; the codeword `11001001011` is divisible by `1001`.

**Key idea:** CRC: append $r$ zeros ($r$ = degree), divide by the generator mod 2, and append the remainder.

</details>
