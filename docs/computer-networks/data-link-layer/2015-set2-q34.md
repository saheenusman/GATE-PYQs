# 2015 CS2 Q34: Propagation delay from stop-and-wait efficiency of 25 percent

## Question

A link has a transmission speed of $10^6$ bits/sec. It uses data packets of size 1000 bytes each. Assume that the acknowledgment has negligible transmission delay, and that its propagation delay is the same as the data propagation delay. Also assume that the processing delays at nodes are negligible. The efficiency of the stop-and-wait protocol in this setup is exactly 25%. The value of the one-way propagation delay (in milliseconds) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**12**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Transmission time: $T_t = \dfrac{8000\text{ bits}}{10^6\text{ bits/s}} = 8$ ms.
- One cycle $= T_t + 2T_p$ (data goes out, ack comes back, ack transmission negligible).

$$\text{Efficiency} = \frac{T_t}{T_t + 2T_p} = 0.25 \;\Rightarrow\; T_t + 2T_p = 32\text{ ms} \;\Rightarrow\; 2T_p = 24 \;\Rightarrow\; T_p = 12\text{ ms}$$

This question's key uses the standard $T_t/(T_t + 2T_p)$ model, which is the model I used for 2015 CS1 Q36.

**Key idea:** stop-and-wait efficiency is $T_t/(T_t + 2T_p)$, where $T_p$ is the one-way delay.

</details>
