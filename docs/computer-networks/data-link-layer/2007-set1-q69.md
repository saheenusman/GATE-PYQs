# 2007 CS Q69: Sequence number bits for the sliding window protocol

## Question

The distance between two stations $M$ and $N$ is $L$ kilometres. All frames are $K$ bits long. The propagation delay per kilometre is $t$ seconds. Let $R$ bits/second be the channel capacity. Assuming that processing delay is negligible, the *minimum* number of bits for the sequence number field in a frame for maximum utilization, when the *sliding window protocol* is used, is:

- (A) $\left\lceil \log_2 \dfrac{2LtR + 2K}{K} \right\rceil$
- (B) $\left\lceil \log_2 \dfrac{2LtR}{K} \right\rceil$
- (C) $\left\lceil \log_2 \dfrac{2LtR + K}{K} \right\rceil$
- (D) $\left\lceil \log_2 \dfrac{2LtR + K}{2K} \right\rceil$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- Transmission time of a frame: $T_t = K/R$.
- Propagation delay: $T_p = Lt$.

For maximum utilization the sender must keep sending for the whole round trip, so the window must cover
$$W = 1 + \frac{2T_p}{T_t} = 1 + \frac{2LtR}{K} = \frac{2LtR + K}{K} \text{ frames}.$$

The sequence-number field must be able to number $W$ frames:
$$\left\lceil \log_2 \frac{2LtR + K}{K} \right\rceil \text{ bits.}$$

(C).

- (A) has an extra $K$ in the numerator, which would be $W + 1$.
- (B) drops the 1 (the frame being sent) from the window.
- (D) divides by $2K$ instead of $K$, halving the window.

**Code check:** not applicable (formula derivation).

**Assumption:** the answer takes the number of sequence numbers to be equal to the window size. A strict treatment (go-back-N needs $W+1$ numbers, selective repeat $2W$) would change the formula, but (C) is the only option consistent with the standard textbook reading.

**Key idea:** window size for full utilization is $1 + 2T_p/T_t$, and the sequence-number space must be at least the window size.
