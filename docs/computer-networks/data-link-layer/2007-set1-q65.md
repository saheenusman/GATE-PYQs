# 2007 CS Q65: Probability that exactly one station transmits in a slot

## Question

There are $n$ stations in a slotted LAN. Each station attempts to transmit with a probability $p$ in each time slot. What is the probability that **ONLY** one station transmits in a given time slot?

- (A) $np(1-p)^{n-1}$
- (B) $(1-p)^{n-1}$
- (C) $p(1-p)^{n-1}$
- (D) $1 - (1-p)^{n-1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Choose which station transmits ($n$ ways). That station transmits ($p$) and each of the other $n - 1$ stays silent ($1-p$ each):
$$P = n \cdot p\,(1-p)^{n-1}.$$

(A). This is the success probability of slotted ALOHA.

- (B) is the probability that $n-1$ specific stations are all silent.
- (C) is the probability that one **particular** station is the only transmitter; it misses the factor $n$ for the choice of station.
- (D) is the probability that at least one of $n-1$ stations transmits.

**Code check:** Python Monte Carlo ($n = 7$, $p = 0.3$, 200,000 slots): observed $0.2468$ against $np(1-p)^{n-1} = 0.2471$; formula (C) would give $0.0353$.
