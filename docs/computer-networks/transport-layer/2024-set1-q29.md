# 2024 CS1 Q29: Sequence and acknowledgement numbers in the TCP handshake

## Question

TCP client P successfully establishes a connection to TCP server Q. Let $N_P$ denote the sequence number in the SYN sent from P to Q. Let $N_Q$ denote the acknowledgement number in the SYN ACK from Q to P. Which of the following statements is/are CORRECT?

- (A) The sequence number $N_P$ is chosen randomly by P
- (B) The sequence number $N_P$ is always 0 for a new connection
- (C) The acknowledgement number $N_Q$ is equal to $N_P$
- (D) The acknowledgement number $N_Q$ is equal to $N_P + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** TCP picks an **initial sequence number (ISN)** that is hard to guess (random or pseudo-random), which also helps avoid confusion with old segments and spoofing.
- **(B) False.** The ISN is not fixed at 0.
- **(C) False.** The SYN consumes one sequence number, so the receiver acknowledges the *next* byte expected.
- **(D) True.** The SYN ACK acknowledges the SYN with $N_Q = N_P + 1$.

**Key idea:** a SYN (and a FIN) counts as one sequence number, so the ACK is ISN + 1.

</details>
