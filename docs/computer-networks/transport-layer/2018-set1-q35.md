# 2018 CS Q35: Time before a TCP sequence number is reused

## Question

Consider a long-lived TCP session with an end-to-end bandwidth of 1 Gbps ($= 10^9$ bits-per-second). The session starts with a sequence number of 1234. The minimum time (in seconds, rounded to the closest integer) before this sequence number can be used again is _______.

<details class="success" markdown="1">
<summary>Answer</summary>

**34 to 35**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Sequence numbers count bytes** and are 32 bits wide, so they wrap after $2^{32}$ bytes.

**Time to send $2^{32}$ bytes at 1 Gbps:**

$$\frac{2^{32}\times 8\ \text{bits}}{10^9\ \text{bits/s}} = \frac{34\,359\,738\,368}{10^9}\approx 34.36\ \text{s}$$

Rounded to the closest integer: **34**. The key's range is 34 to 35.

**The starting number 1234 is a distractor:** the wrap-around time is the same whatever the start.

**Key idea:** the minimum reuse time is the time to send $2^{32}$ bytes at line rate.

</details>
