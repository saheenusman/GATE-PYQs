# 2014 CS1 Q27: TCP: time to return to 32 KB congestion window after timeout

## Question

Let the size of congestion window of a TCP connection be 32 KB when a timeout occurs. The round trip time of the connection is 100 msec and the maximum segment size used is 2 KB. The time taken (**in msec**) by the TCP connection to get back to 32 KB congestion window is _________.

<details class="success" markdown="1">
<summary>Answer</summary>

**1100**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

On a timeout, TCP sets $ssthresh = 32/2 = 16$ KB and restarts with $cwnd = 1$ MSS $= 2$ KB.

**Slow start** (doubles each RTT) until $ssthresh$:

$$2 \to 4 \to 8 \to 16 \text{ KB}: \ 3 \text{ RTTs}$$

**Congestion avoidance** (adds 1 MSS $= 2$ KB each RTT):

$$16 \to 32 \text{ KB}: \ (32-16)/2 = 8 \text{ RTTs}$$

Total $= 11$ RTTs $= 11 \times 100 = 1100$ ms.

The key accepts 1100 to 1300, which allows for textbook variants (for example counting one extra RTT at the start or at the threshold).

**Code check:** `3 + (32-16)//2` gives 11 RTTs, so 1100 ms.

**Key idea:** slow start up to $ssthresh = cwnd/2$, then linear growth of 1 MSS per RTT.

</details>
