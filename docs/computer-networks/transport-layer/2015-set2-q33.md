# 2015 CS2 Q33: Order of socket calls on a server

## Question

Identify the correct order in which a server process must invoke the function calls `accept`, `bind`, `listen`, and `recv` according to UNIX socket API.

- (A) listen, accept, bind, recv
- (B) bind, listen, accept, recv
- (C) bind, accept, listen, recv
- (D) accept, listen, bind, recv

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A TCP server sets up and serves a connection in this order:

1. `bind`: attach the socket to a local address and port.
2. `listen`: mark the socket as passive and start queueing connection requests.
3. `accept`: take a queued connection and obtain a new connected socket.
4. `recv`: read data on that connected socket.

Option (B). Each other option breaks the dependency: `listen` needs a bound socket, `accept` needs a listening socket, and `recv` needs an accepted connection.

**Key idea:** server order is bind, listen, accept, then recv.

</details>
