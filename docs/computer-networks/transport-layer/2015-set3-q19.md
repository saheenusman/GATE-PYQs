# 2015 CS3 Q19: Statements about TCP connections

## Question

Consider the following statements.

- I. TCP connections are full duplex
- II. TCP has no option for selective acknowledgement
- III. TCP connections are message streams

- (A) Only I is correct
- (B) Only I and III are correct
- (C) Only II and III are correct
- (D) All of I, II and III are correct

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I. True.** Data flows in both directions on one TCP connection at the same time.
- **II. False.** TCP does have selective acknowledgement (the SACK option, RFC 2018).
- **III. False.** TCP is a **byte stream**: it does not preserve message boundaries. (UDP keeps them.)

Only I is correct: option (A).

**Key idea:** TCP is full duplex and byte-oriented, and supports SACK as an option.

</details>
