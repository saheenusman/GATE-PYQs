# 2018 CS Q23: Match protocol fields with their lengths in bits

## Question

Match the following:

| Field | | Length in bits |
|---|---|---|
| P. UDP Header's Port Number | I. | 48 |
| Q. Ethernet MAC Address | II. | 8 |
| R. IPv6 Next Header | III. | 32 |
| S. TCP Header's Sequence Number | IV. | 16 |

- (A) P-III, Q-IV, R-II, S-I
- (B) P-II, Q-I, R-IV, S-III
- (C) P-IV, Q-I, R-II, S-III
- (D) P-IV, Q-I, R-III, S-II

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Field sizes:**

| Field | Bits | Match |
|---|---|---|
| UDP port number | 16 | P-IV |
| Ethernet MAC address | 48 | Q-I |
| IPv6 Next Header | 8 | R-II |
| TCP sequence number | 32 | S-III |

This is option **C**.

**Why the others fail:** A gives the port 32 bits and the MAC 16. B gives the port 8 bits. D gives the Next Header 32 bits and the sequence number 8.

**Key idea:** port numbers are 16 bits, MAC addresses 48, TCP sequence numbers 32, and the IPv6 Next Header field is one byte.

</details>
