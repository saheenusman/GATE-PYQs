# 2015 CS1 Q23: False statements about a TCP connection

## Question

Suppose two hosts use a TCP connection to transfer a large file. Which of the following statements is/are FALSE with respect to the TCP connection?

- I. If the sequence number of a segment is $m$, then the sequence number of the subsequent segment is always $m+1$.
- II. If the estimated round trip time at any given point of time is $t$ sec, the value of the retransmission timeout is always set to greater than or equal to $t$ sec.
- III. The size of the advertised window never changes during the course of the TCP connection.
- IV. The number of unacknowledged bytes at the sender is always less than or equal to the advertised window.

- (A) III only
- (B) I and III only
- (C) I and IV only
- (D) II and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I: False.** TCP numbers **bytes**. The next segment's sequence number is $m$ plus the number of data bytes in the previous segment, not $m+1$.
- **II: True.** The timeout is set above the estimated RTT (SRTT plus a safety margin), so it is at least $t$.
- **III: False.** The receiver changes the advertised window as its buffer fills and drains (flow control).
- **IV: True.** The sender never has more unacknowledged data in flight than the receiver advertised.

False statements: I and III, option (B). (A) misses I. (C) wrongly calls IV false. (D) wrongly calls II and IV false.

**Key idea:** TCP sequence numbers count bytes, and the advertised window is dynamic.

</details>
