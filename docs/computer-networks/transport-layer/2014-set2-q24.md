# 2014 CS2 Q24: Socket call that makes a TCP socket passive

## Question

Which one of the following socket API functions converts an unconnected active TCP socket into a passive socket?

- (A) connect
- (B) bind
- (C) listen
- (D) accept

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A new socket is *active* by default (it can initiate a connection). `listen()` marks it **passive**, so it waits for incoming connections and queues them.

- (A) `connect()` uses an active socket to start a connection.
- (B) `bind()` only attaches a local address and port.
- (D) `accept()` takes a queued connection off a socket that is *already* listening.

**Classification flag:** the socket API is filed under `transport-layer`.

**Key idea:** the server sequence is `socket`, `bind`, `listen`, `accept`.

</details>
