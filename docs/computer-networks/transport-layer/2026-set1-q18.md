# 2026 CS1 Q18: True statement about a TCP connection

## Question

With respect to a TCP connection between a client and a server, which one of the following statements is true?

- (A) The client and server use a two-way handshake mechanism before the start of data transmission
- (B) The server cannot initiate closing of the connection before the client initiates closing of the connection
- (C) The TCP connection is half-duplex
- (D) The client and server can initiate closing of the connection at the same time

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) False.** TCP uses a **three-way** handshake (SYN, SYN-ACK, ACK) to open a connection.

**(B) False.** Either side can close first. The server can send `FIN` before the client does.

**(C) False.** TCP is **full-duplex**: both sides can send data at the same time on one connection.

**(D) True.** Both sides may send `FIN` at the same moment. This is called a *simultaneous close*, and TCP handles it (each side goes through `FIN_WAIT` and `CLOSING` states).

**Key idea:** TCP opens with 3 messages, is full duplex, and closing can be started by either end, even both at once.

</details>
