# 2013 CS Q12: Transport protocols for applications

## Question

The transport layer protocols used for real time multimedia, file transfer, DNS and email, respectively are

- (A) TCP, UDP, UDP and TCP
- (B) UDP, TCP, TCP and UDP
- (C) UDP, TCP, UDP and TCP
- (D) TCP, UDP, TCP and UDP

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Application | Transport | Reason |
|---|---|---|
| Real-time multimedia | UDP | tolerates loss, needs low delay |
| File transfer (FTP) | TCP | needs reliable, ordered delivery |
| DNS | UDP | small query/response (TCP only for large zone transfers) |
| Email (SMTP) | TCP | reliable delivery of the whole message |

This is UDP, TCP, UDP, TCP: option (C).

**Why the others fail:** (A), (B) and (D) each swap at least one of these. (B), for example, would run email over UDP.

**Key idea:** delay-sensitive or short request/reply traffic uses UDP; bulk reliable transfer uses TCP.

</details>
