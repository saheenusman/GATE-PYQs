# 2007 CS Q20: Which application uses UDP

## Question

Which one of the following uses UDP as the transport protocol?

- (A) HTTP
- (B) Telnet
- (C) DNS
- (D) SMTP

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

DNS queries are short request/reply exchanges, so DNS uses **UDP** (port 53) by default: (C). It falls back to TCP only for large responses and zone transfers.

- (A) HTTP, (B) Telnet and (D) SMTP all need reliable, ordered byte streams, so they run over **TCP**.

**Key idea:** short, query-style protocols such as DNS use UDP; stream-oriented protocols (HTTP, Telnet, SMTP) use TCP.
