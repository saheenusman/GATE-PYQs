# 2008 CS Q17: Which system call sends SYN packets

## Question

Which of the following system calls results in the sending of SYN packets?

- (A) `socket`
- (B) `bind`
- (C) `listen`
- (D) `connect`

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

TCP's three-way handshake starts when the **active** side (the client) calls `connect()`: the kernel sends a **SYN** segment to the server.

- (A) `socket()` only creates the socket (a descriptor).
- (B) `bind()` attaches a local address and port. No packet is sent.
- (C) `listen()` marks the socket as passive and sets up the connection queue. It waits for SYNs; it does not send them. (The server answers with SYN-ACK when a SYN arrives.)

So only `connect` sends a SYN: (D).

**Key idea:** the client's `connect()` triggers the SYN; the server's `listen()` and `accept()` receive it.

</details>
