# 2018 CS Q24: True statements about TCP slow start

## Question

Consider the following statements regarding the slow start phase of the TCP congestion control algorithm. Note that $cwnd$ stands for the TCP congestion window and MSS denotes the Maximum Segment Size.

- (i) The $cwnd$ increases by 2 MSS on every successful acknowledgment.
- (ii) The $cwnd$ approximately doubles on every successful acknowledgement.
- (iii) The $cwnd$ increases by 1 MSS every round trip time.
- (iv) The $cwnd$ approximately doubles every round trip time.

Which one of the following is correct?

- (A) Only (ii) and (iii) are true
- (B) Only (i) and (iii) are true
- (C) Only (iv) is true
- (D) Only (i) and (iv) are true

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**In slow start**, $cwnd$ grows by **1 MSS for every ACK received**. If $cwnd$ segments are in flight, about $cwnd$ ACKs come back in one RTT, so $cwnd$ roughly **doubles every RTT**.

- **(i)** false: the increase per ACK is 1 MSS, not 2.
- **(ii)** false: per ACK it grows by 1 MSS, it does not double.
- **(iii)** false: growth of 1 MSS per RTT is *congestion avoidance*, not slow start.
- **(iv)** **true:** exponential growth, doubling each RTT.

Only (iv) is true: **C**.

**Key idea:** slow start is exponential per RTT (+1 MSS per ACK); congestion avoidance is linear (+1 MSS per RTT).

</details>
