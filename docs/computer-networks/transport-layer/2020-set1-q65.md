# 2020 CS Q65: TCP congestion window after 60 ms

## Question

Consider a TCP connection between a client and a server with the following specifications: the round trip time is 6 ms, the size of the receiver advertised window is 50 KB, slow-start threshold at the client is 32 KB, and the maximum segment size is 2 KB. The connection is established at time $t = 0$. Assume that there are no timeouts and errors during transmission. Then the size of the congestion window (in KB) at time $t + 60$ ms after all acknowledgements are processed is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**44**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Setup.** TCP starts in slow start with $cwnd = 1\ \text{MSS} = 2$ KB. Once per RTT (6 ms):

- Slow start (while $cwnd <$ ssthresh = 32 KB): $cwnd$ doubles.
- Congestion avoidance ($cwnd \ge$ 32 KB): $cwnd$ grows by 1 MSS = 2 KB.
- The window actually sent is $\min(cwnd,\ \text{rwnd} = 50\ \text{KB})$. $cwnd$ stays under 50 KB throughout, so rwnd never binds.

**Timeline** (60 ms = 10 RTTs):

| Time (ms) | $cwnd$ (KB) | Phase |
|---|---|---|
| 0 | 2 | slow start |
| 6 | 4 | slow start |
| 12 | 8 | slow start |
| 18 | 16 | slow start |
| 24 | 32 | reaches ssthresh |
| 30 | 34 | congestion avoidance |
| 36 | 36 | congestion avoidance |
| 42 | 38 | congestion avoidance |
| 48 | 40 | congestion avoidance |
| 54 | 42 | congestion avoidance |
| 60 | **44** | congestion avoidance |

The congestion window at 60 ms is **44 KB**, below the 50 KB advertised window. I generated the table with a short simulation of the same rules.

**Key idea:** exponential growth up to ssthresh, then linear (+1 MSS per RTT). The sending window is capped by the smaller of $cwnd$ and the receiver's window.

</details>
