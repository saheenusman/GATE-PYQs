# 2025 CS1 Q22: TCP flags in the three-way handshake

## Question

Consider the 3-way handshaking protocol for TCP connection establishment. Let the three packets exchanged during the connection establishment be denoted as P1, P2, and P3, in order. Which of the following option(s) is/are TRUE with respect to TCP header flags that are set in the packets?

- (A) P3: SYN = 1, ACK = 1
- (B) P2: SYN = 1, ACK = 1
- (C) P2: SYN = 0, ACK = 1
- (D) P1: SYN = 1

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Packet | Sent by | Flags | Purpose |
|---|---|---|---|
| P1 | client | **SYN = 1** (ACK = 0) | Asks to open a connection |
| P2 | server | **SYN = 1, ACK = 1** | Accepts, and sends its own initial sequence number |
| P3 | client | **ACK = 1** (SYN = 0) | Confirms the server's SYN |

| Option | Verdict |
|---|---|
| A: P3 has SYN = 1 | False. P3 only acknowledges, so SYN is 0 |
| **B: P2 has SYN = 1, ACK = 1** | True |
| C: P2 has SYN = 0 | False. The server must also send SYN |
| **D: P1 has SYN = 1** | True |

**Key idea:** SYN, then SYN+ACK, then ACK.

</details>
