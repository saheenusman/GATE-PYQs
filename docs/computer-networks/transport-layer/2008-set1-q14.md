# 2008 CS Q14: Maximum data the application layer can pass to TCP

## Question

What is the maximum size of data that the application layer can pass on to the TCP layer below?

- (A) Any size
- (B) $2^{16}$ bytes $-$ size of TCP header
- (C) $2^{16}$ bytes
- (D) 1500 bytes

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

TCP is a **byte-stream** service. The application hands TCP a stream, and TCP itself breaks it into segments that fit the MSS and the IP and link limits. The application layer is therefore **not limited** in how much it passes down: (A).

- (B) and (C) are limits on a single IP datagram or segment (the 16-bit length field), not on what the application may write.
- (D) 1500 bytes is the Ethernet MTU, again a per-frame limit below TCP.

**Classification note:** the question is about the application/transport boundary. I filed it under `transport-layer`, since it is about what TCP does with application data.

**Key idea:** segment size limits apply below TCP; the application can write any amount, and TCP segments it.

</details>
