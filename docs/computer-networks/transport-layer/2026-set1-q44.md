# 2026 CS1 Q44: Time to send a segment in TCP slow start

## Question

A TCP sender establishes a connection and starts sending. The slow-start threshold is 10000 segments. The round-trip time is a fixed 1 ms. The sender always has data, segments are numbered from 1, and no segment is lost. Let $t$ be the time (in ms) at which the transmission of segment number 2000 starts.

Which option is correct?

- (A) $9 \le t < 10$
- (B) $10 \le t < 11$
- (C) $11 \le t < 12$
- (D) $12 \le t < 13$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** In slow start the congestion window $cwnd$ **doubles every RTT**. It starts at 1 segment. One round of sending takes one RTT (1 ms).

| Round | Starts at | $cwnd$ | Segments sent |
|---|---|---|---|
| 0 | 0 ms | 1 | 1 |
| 1 | 1 ms | 2 | 2, 3 |
| 2 | 2 ms | 4 | 4 to 7 |
| 3 | 3 ms | 8 | 8 to 15 |
| $r$ | $r$ ms | $2^r$ | $2^r$ to $2^{r+1}-1$ |

Segment 2000 lies in round $r$ with $2^r \le 2000 < 2^{r+1}$. Since $2^{10} = 1024$ and $2^{11} = 2048$, that is round **10**, which starts at $t = 10$ ms.

Round 10 has $cwnd = 1024$, which is below the threshold of 10000, so we are still in slow start the whole time.

Segment 2000 starts after the first $2000 - 1024 = 976$ segments of round 10 are already out. All of a round's segments go out within that round's RTT (the window is sent back to back), so $t$ falls inside $[10, 11)$.

**Key idea:** in slow start, round $r$ starts at $r$ RTT and sends $2^r$ segments, so segment $n$ is in round $\lfloor \log_2 n \rfloor$.

</details>
