# 2026 CS2 Q58: Rounds of slow start before congestion avoidance

## Question

A new TCP connection has a receiver advertised window constant at 48 KB, a maximum segment size (MSS) of 2 KB, and a slow-start threshold of 16 KB. Assume there are no timeouts or duplicate ACKs.

The number of transmission rounds required for the connection to reach the **congestion avoidance** phase is _____. (answer in integer) (1K $= 2^{10}$)

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** TCP starts in slow start with $cwnd = 1$ MSS and doubles it each round. When $cwnd$ reaches the slow-start threshold, it switches to congestion avoidance (additive increase).

The sender window is $\min(cwnd, 48\ \text{KB})$, and the threshold (16 KB) is below 48 KB, so the threshold decides.

| Round | $cwnd$ |
|---|---|
| 1 | 2 KB |
| 2 | 4 KB |
| 3 | 8 KB |
| 4 | 16 KB $=$ threshold |

At round 4 the window equals the threshold, so the connection moves to congestion avoidance after **4** rounds.

**Key idea:** slow start doubles each round until $cwnd$ reaches the threshold; count the doublings from 1 MSS.

</details>
