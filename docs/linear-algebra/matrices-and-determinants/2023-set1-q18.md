# 2023 CS Q18: Determinants of two permuted circulant matrices

## Question

Let

$$A = \begin{bmatrix} 1&2&3&4\\ 4&1&2&3\\ 3&4&1&2\\ 2&3&4&1 \end{bmatrix}, \quad B = \begin{bmatrix} 3&4&1&2\\ 4&1&2&3\\ 1&2&3&4\\ 2&3&4&1 \end{bmatrix}.$$

Let $\det(A)$ and $\det(B)$ denote the determinants of the matrices $A$ and $B$, respectively. Which one of the options given below is TRUE?

- (A) $\det(A) = \det(B)$
- (B) $\det(B) = -\det(A)$
- (C) $\det(A) = 0$
- (D) $\det(AB) = \det(A) + \det(B)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B ($\det(B) = -\det(A)$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Compare the rows.** Let the rows of $A$ be $R_1 = 1234$, $R_2 = 4123$, $R_3 = 3412$, $R_4 = 2341$. Then $B$ has rows $R_3, R_2, R_1, R_4$: it is $A$ with **rows 1 and 3 swapped**.

**Swapping two rows changes the sign of the determinant**, so $\det(B) = -\det(A)$. That is **B**.

**Check with numbers.** $\det(A) = -160$ and $\det(B) = 160$.

**Why the others fail:**
- **A**: the signs differ.
- **C**: $\det(A) = -160 \ne 0$.
- **D**: $\det(AB) = \det(A)\det(B) = -25600$, but $\det(A) + \det(B) = 0$.

**Code check:** `sympy` gave $\det A = -160$, $\det B = 160$, $\det(AB) = -25600$.

**Key idea:** a row swap flips the sign of the determinant. $\det(AB)$ is a product, not a sum.

</details>
