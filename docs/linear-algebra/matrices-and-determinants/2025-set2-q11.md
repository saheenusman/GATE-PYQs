# 2025 CS2 Q11: Eighth power of a 2x2 matrix

## Question

If $A = \begin{pmatrix} 1 & 2 \\ 2 & -1 \end{pmatrix}$, then which ONE of the following is $A^8$?

- (A) $\begin{pmatrix} 25 & 0 \\ 0 & 25 \end{pmatrix}$
- (B) $\begin{pmatrix} 125 & 0 \\ 0 & 125 \end{pmatrix}$
- (C) $\begin{pmatrix} 625 & 0 \\ 0 & 625 \end{pmatrix}$
- (D) $\begin{pmatrix} 3125 & 0 \\ 0 & 3125 \end{pmatrix}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Square the matrix first:

$$A^2 = \begin{pmatrix} 1\cdot1 + 2\cdot2 & 1\cdot2 + 2\cdot(-1) \\ 2\cdot1 + (-1)\cdot2 & 2\cdot2 + (-1)(-1) \end{pmatrix} = \begin{pmatrix} 5 & 0 \\ 0 & 5 \end{pmatrix} = 5I.$$

Then

$$A^8 = (A^2)^4 = (5I)^4 = 5^4 I = 625\, I = \begin{pmatrix} 625 & 0 \\ 0 & 625 \end{pmatrix}.$$

| Option | Value |
|---|---|
| A | $5^2 I$, which is $A^4$ |
| B | $5^3 I$, which would be "$A^6$" |
| C | $5^4 I = A^8$ |
| D | $5^5 I$, which would be "$A^{10}$" |

(A numerical matrix power gives the same result.)

**Key idea:** look for a power that simplifies, here $A^2 = 5I$.

</details>
