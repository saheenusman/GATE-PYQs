# 2025 CS2 Q14: Determinant of M - N when L cubed is the identity

## Question

Let $L$, $M$, and $N$ be non-singular matrices of order 3 satisfying the equations

$$L^2 = L^{-1},\quad M = L^8 \text{ and } N = L^2.$$

Which ONE of the following is the value of the determinant of $(M - N)$?

- (A) 0
- (B) 1
- (C) 2
- (D) 3

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

From $L^2 = L^{-1}$, multiply by $L$: $L^3 = I$.

Then

$$M = L^8 = L^{6+2} = (L^3)^2 L^2 = L^2.$$

Also $N = L^2$. So $M = N$ and

$$M - N = 0 \text{ (the zero matrix)}, \qquad \det(M - N) = 0.$$

(For example, with $L$ a cyclic permutation matrix, $L^3 = I$ and $\det(L^8 - L^2) = 0$, which I confirmed numerically.)

**Key idea:** $L^3 = I$ lets you reduce exponents modulo 3: $L^8 = L^2$.

</details>
