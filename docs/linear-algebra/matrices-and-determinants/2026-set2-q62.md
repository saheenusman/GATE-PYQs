# 2026 CS2 Q62: Determinant of a scaled matrix

## Question

The determinant of a $4 \times 4$ matrix $A$ is 3. The value of the determinant of $2A$ is ________. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**48**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Multiplying a matrix by a scalar $k$ multiplies **every row** by $k$. Each row scaling multiplies the determinant by $k$. For an $n \times n$ matrix:

$$\det(kA) = k^n \det(A)$$

So $\det(2A) = 2^4 \times 3 = 16 \times 3 = \mathbf{48}$.

**Common slip:** writing $2 \times 3 = 6$. That is only right for scaling a *single* row.

**Key idea:** $\det(kA) = k^n\det A$ for an $n \times n$ matrix.

</details>
