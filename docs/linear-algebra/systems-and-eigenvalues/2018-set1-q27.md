# 2018 CS Q27: Largest eigenvalue of a rank-one matrix u v^T

## Question

Consider a matrix $A = uv^T$ where $u = \begin{pmatrix}1\\2\end{pmatrix},\ v = \begin{pmatrix}1\\1\end{pmatrix}$. Note that $v^T$ denotes the transpose of $v$. The largest eigenvalue of $A$ is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Form the matrix:**

$$A = uv^T = \begin{pmatrix}1\\2\end{pmatrix}\begin{pmatrix}1&1\end{pmatrix} = \begin{pmatrix}1&1\\2&2\end{pmatrix}$$

**Eigenvalues.** The rows are proportional, so $\det A = 0$ and one eigenvalue is $0$. The trace is $1 + 2 = 3$, and the eigenvalues sum to the trace, so the other is $3$.

**Shortcut:** $A u = u(v^Tu) = (v^Tu)\,u$, so $u$ is an eigenvector with eigenvalue $v^Tu = 1 + 2 = 3$.

The largest eigenvalue is **3**.

**Code check:** `numpy.linalg.eigvals` returned 0 and 3.

**Key idea:** a rank-one matrix $uv^T$ has eigenvalues $v^Tu$ and $0$ (the rest).

</details>
