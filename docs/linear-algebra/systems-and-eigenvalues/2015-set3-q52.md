# 2015 CS3 Q52: Condition for a homogeneous system to have a non-trivial solution

## Question

If the following system has non-trivial solution,

$$px + qy + rz = 0$$
$$qx + ry + pz = 0$$
$$rx + py + qz = 0,$$

then which one of the following options is TRUE?

- (A) $p - q + r = 0$ or $p = q = -r$
- (B) $p + q - r = 0$ or $p = -q = r$
- (C) $p + q + r = 0$ or $p = q = r$
- (D) $p - q + r = 0$ or $p = -q = -r$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A homogeneous system has a non-trivial solution exactly when its coefficient determinant is $0$. The matrix is circulant:

$$\det\begin{bmatrix} p & q & r \\ q & r & p \\ r & p & q \end{bmatrix} = -(p+q+r)\,(p^2+q^2+r^2-pq-qr-rp)$$

The second factor equals $\tfrac12\big[(p-q)^2 + (q-r)^2 + (r-p)^2\big]$, which is $0$ only when $p = q = r$.

So the determinant is $0$ iff

$$p + q + r = 0 \quad\text{or}\quad p = q = r$$

Option (C).

**Why the others fail.** Take $p = q = r = 1$. The system has the non-trivial solution $(1, -1, 0)$, but options (A), (B) and (D) all need $p - q + r = 0$ or $p + q - r = 0$ (which equal 1) or a sign pattern that $p=q=r=1$ does not satisfy.

**Code check:** a symbolic determinant gives exactly the factorisation above.

**Key idea:** non-trivial solution of $Ax = 0$ $\iff$ $\det A = 0$. The determinant of a $3 \times 3$ circulant factors as above.

</details>
