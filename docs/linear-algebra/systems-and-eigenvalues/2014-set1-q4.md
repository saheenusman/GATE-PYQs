# 2014 CS1 Q4: Number of solutions of 4 equations in 3 unknowns

## Question

Consider the following system of equations:

```
3x + 2y = 1
4x + 7z = 1
x + y + z = 3
x - 2y + 7z = 0
```

The number of solutions for this system is __________________

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Four equations, three unknowns. The system has a solution only if rank$(A)$ = rank$([A|b])$.

From the first two: $y = (1-3x)/2$ and $z = (1-4x)/7$. Put into the third:

$$x + \frac{1-3x}{2} + \frac{1-4x}{7} = 3 \Rightarrow 14x + 7 - 21x + 2 - 8x = 42 \Rightarrow x = -2.2$$

So $y = 3.8$, $z = 1.4$.

Check the fourth: $-2.2 - 7.6 + 9.8 = 0$. It holds, so the four equations are consistent and the solution is **unique**.

**Code check:** rank$(A)$ = rank$([A|b])$ = 3, and the least-squares residual is about $10^{-15}$. Exactly **1** solution.

**Key idea:** rank$(A)$ = rank$([A|b])$ = number of unknowns gives a unique solution.

</details>
