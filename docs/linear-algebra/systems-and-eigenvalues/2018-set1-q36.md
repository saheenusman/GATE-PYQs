# 2018 CS Q36: A matrix whose only eigenvectors are multiples of (1, 4)

## Question

Consider a matrix $\mathbf{P}$ whose only eigenvectors are the multiples of $\begin{pmatrix}1\\4\end{pmatrix}$.

Consider the following statements.

- (I) $\mathbf{P}$ does not have an inverse
- (II) $\mathbf{P}$ has a repeated eigenvalue
- (III) $\mathbf{P}$ cannot be diagonalized

Which one of the following options is correct?

- (A) Only I and III are necessarily true
- (B) Only II is necessarily true
- (C) Only I and II are necessarily true
- (D) Only II and III are necessarily true

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$\mathbf{P}$ is $2\times2$ (its eigenvector has 2 entries). Its eigenvectors span only one dimension.

**(II) true.** Two distinct eigenvalues would give two independent eigenvectors. There is only one direction, so the single eigenvalue is repeated.

**(III) true.** A $2\times2$ matrix is diagonalizable only with two independent eigenvectors. It has one, so $\mathbf{P}$ cannot be diagonalized.

**(I) not necessarily true.** $\mathbf{P}$ is singular only if the repeated eigenvalue is 0. Take

$$\mathbf{P} = \begin{pmatrix}-2&1\\-16&6\end{pmatrix}$$

Then $\mathbf{P}\begin{pmatrix}1\\4\end{pmatrix} = \begin{pmatrix}2\\8\end{pmatrix} = 2\begin{pmatrix}1\\4\end{pmatrix}$, the eigenvalue 2 is repeated, $\det\mathbf{P} = 4 \ne 0$, and the only eigenvectors are multiples of $(1,4)^T$. So $\mathbf{P}$ can be invertible.

Only II and III are necessarily true: **D**.

**Code check:** `numpy` confirmed eigenvalues $(2, 2)$ and $\det = 4$ for this matrix, and a singular example (eigenvalue 0) for contrast.

**Key idea:** one eigen-direction in a $2\times2$ matrix means a repeated eigenvalue and a defective (non-diagonalizable) matrix.

</details>
