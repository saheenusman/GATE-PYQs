# 2016 CS2 Q4: Solvability of systems with m equations in n variables

## Question

Consider the systems, each consisting of $m$ linear equations in $n$ variables.

- I. If $m < n$, then all such systems have a solution
- II. If $m > n$, then none of these systems has a solution
- III. If $m = n$, then there exists a system which has a solution

Which one of the following is CORRECT?

- (A) I, II and III are true
- (B) Only II and III are true
- (C) Only III is true
- (D) None of them is true

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **I is false.** An underdetermined system can still be inconsistent: $x + y + z = 1$ and $x + y + z = 2$ ($m = 2 < n = 3$) has no solution.
- **II is false.** An overdetermined system can be consistent, e.g. repeat the same equation twice.
- **III is true.** Some square system has a solution, e.g. $x = 0$, $y = 0$ (the homogeneous system always has the trivial solution).

Only III is true: **(C)**.

**Key idea:** $m$ versus $n$ does not decide solvability; one counter-example each kills I and II.

</details>
