# 2025 CS1 Q23: Which statements hold for a 2x2 system with parameter k

## Question

Consider the given system of linear equations for variables $x$ and $y$, where $k$ is a real-valued constant. Which of the following option(s) is/are CORRECT?

$$x + ky = 1$$
$$kx + y = -1$$

- (A) There is exactly one value of $k$ for which the above system of equations has no solution.
- (B) There exist an infinite number of values of $k$ for which the system of equations has no solution.
- (C) There exists exactly one value of $k$ for which the system of equations has exactly one solution.
- (D) There exists exactly one value of $k$ for which the system of equations has an infinite number of solutions.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The determinant of the coefficient matrix is

$$\begin{vmatrix} 1 & k \\ k & 1 \end{vmatrix} = 1 - k^2.$$

**If $k \ne \pm 1$:** $\det \neq 0$, so there is **exactly one** solution.

**If $k = 1$:** the equations are $x + y = 1$ and $x + y = -1$. Contradictory: **no solution**.

**If $k = -1$:** the equations are $x - y = 1$ and $-x + y = -1$, which is the same equation twice: **infinitely many solutions**.

| $k$ | Outcome |
|---|---|
| $1$ | no solution |
| $-1$ | infinitely many solutions |
| every other $k$ | exactly one solution |

| Option | Verdict |
|---|---|
| **A** | True: only $k = 1$ |
| B | False: only one such value |
| C | False: *all* $k \ne \pm 1$ give a unique solution, not just one value |
| **D** | True: only $k = -1$ |

A symbolic solver confirmed each case.

**Key idea:** when $\det = 0$, compare the right-hand sides: consistent gives infinitely many solutions, inconsistent gives none.

</details>
