# 2017 CS1 Q3: Solutions of Ax = b when b is the sum of the columns of a singular A

## Question

Let $c_1, \ldots, c_n$ be scalars, not all zero, such that $\sum_{i=1}^{n} c_i a_i = 0$ where $a_i$ are column vectors in $\mathbb{R}^n$. Consider the set of linear equations

$$Ax = b$$

where $A = [a_1, \ldots, a_n]$ and $b = \sum_{i=1}^{n} a_i$. The set of equations has

- (A) a unique solution at $x = J_n$ where $J_n$ denotes an $n$-dimensional vector of all 1
- (B) no solution
- (C) infinitely many solutions
- (D) finitely many solutions

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The equations are consistent.** Since $b = a_1 + \cdots + a_n = A\,J_n$, the vector $x = J_n$ is a solution. So (B) is out.

**$A$ is singular.** The condition $\sum c_i a_i = 0$ with not all $c_i$ zero means $A\,c = 0$ for the non-zero vector $c = (c_1,\ldots,c_n)^T$. The columns are linearly dependent, so the null space of $A$ is non-trivial.

**Many solutions.** If $x_0$ is a solution, then $x_0 + t\,c$ is also a solution for every real $t$:

$$A(x_0 + t\,c) = Ax_0 + t\,Ac = b + 0 = b$$

That gives infinitely many solutions: **(C)**.

**Why the others fail.**

- (A): $J_n$ is a solution, but not the only one, because $J_n + t\,c$ also works.
- (B): the system is consistent, as shown.
- (D): a consistent system over $\mathbb{R}$ with a non-trivial null space has infinitely many solutions, never a finite number greater than one.

**Key idea:** a consistent system with linearly dependent columns (non-trivial null space) has infinitely many solutions.

</details>
