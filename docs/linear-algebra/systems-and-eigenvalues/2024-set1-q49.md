# 2024 CS1 Q49: Solutions of Ax = 0 for a wide matrix

## Question

Let $A$ be any $n \times m$ matrix, where $m > n$. Which of the following statements is/are TRUE about the system of linear equations $Ax = 0$?

- (A) There exist at least $m - n$ linearly independent solutions to this system
- (B) There exist $m - n$ linearly independent vectors such that every solution is a linear combination of these vectors
- (C) There exists a non-zero solution in which at least $m - n$ variables are 0
- (D) There exists a solution in which at least $n$ variables are non-zero

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

By rank-nullity, the solution space has dimension $m - \operatorname{rank}(A) \ge m - n$, since $\operatorname{rank}(A) \le n$.

- **(A) True.** The solution space has at least $m - n$ linearly independent vectors.
- **(B) False.** This claims the dimension is *exactly* $m - n$. If $A$ has rank below $n$ the null space is bigger. Example: $A = \begin{bmatrix} 1&0&0 \\ 1&0&0 \end{bmatrix}$ has $m - n = 1$, but its solutions $(0, s, t)$ need 2 vectors.
- **(C) False.** Take $A = \begin{bmatrix} 1&1&1 \\ 1&2&3 \end{bmatrix}$. Every solution is a multiple of $(1,-2,1)$, which has no zero entry, but $m - n = 1$ requires at least one zero.
- **(D) False.** Take $A = \begin{bmatrix} 1&0&0 \\ 0&1&0 \end{bmatrix}$. Every solution is $(0,0,t)$, with only 1 non-zero entry, but $n = 2$.

**Key idea:** rank-nullity gives a *lower* bound on the number of independent solutions of a wide system, not an exact count.

</details>
