# 2008 CS Q3: Values of alpha for which a linear system has a unique solution

## Question

The following system of equations

$$\begin{aligned} x_1 + x_2 + 2x_3 &= 1 \\ x_1 + 2x_2 + 3x_3 &= 2 \\ x_1 + 4x_2 + \alpha x_3 &= 4 \end{aligned}$$

has a unique solution. The only possible value(s) for $\alpha$ is/are

- (A) 0
- (B) either 0 or 1
- (C) one of 0, 1 or $-1$
- (D) any real number

<details class="success" markdown="1">
<summary>Answer</summary>

**C** (official key; see the Solution: disputed)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is (C). My calculation shows that none of the four options is exactly right. Both views follow.

**The coefficient determinant.**

$$\det\begin{pmatrix} 1 & 1 & 2 \\ 1 & 2 & 3 \\ 1 & 4 & \alpha \end{pmatrix} = 1(2\alpha - 12) - 1(\alpha - 3) + 2(4 - 2) = \alpha - 5.$$

A $3 \times 3$ system has a unique solution exactly when this determinant is non-zero, i.e. for **every $\alpha \ne 5$**. For $\alpha = 5$ the rank of the coefficient matrix and the augmented matrix is $2$, so there are infinitely many solutions.

**Comparison with the options.**

- (C) says that $\alpha$ must be one of $0, 1, -1$. But $\alpha = 2$, $\alpha = 6$ and so on also give unique solutions, so "the only possible values" is wrong.
- (D) "any real number" is wrong only at the single value $\alpha = 5$. It is the closest option.
- (A) and (B) are also too restrictive.

**Key's view.** The key's explanation says the rank is 3 for an unlisted condition on $\alpha$ and 2 otherwise (the symbols were lost in the supplied PDF), then picks (C). I cannot reproduce (C) from the system as printed. I record (C) and mark the question disputed.

**Code check:** the determinant is $-6, -5, -4, -3, 0, 1$ for $\alpha = -1, 0, 1, 2, 5, 6$; the rank of both matrices is 3 except at $\alpha = 5$ (rank 2).

**Key idea:** a square system has a unique solution iff its coefficient determinant is non-zero.

</details>
