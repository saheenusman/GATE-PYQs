# 2017 CS1 Q31: Eigenvalues of a rank-2 symmetric matrix with sum of squared entries 50

## Question

Let $A$ be $n \times n$ real valued square symmetric matrix of rank $2$ with $\displaystyle\sum_{i=1}^{n}\sum_{j=1}^{n} A_{ij}^{2} = 50$. Consider the following statements.

- (I) One eigenvalue must be in $[-5, 5]$.
- (II) The eigenvalue with the largest magnitude must be strictly greater than $5$.

Which of the above statements about eigenvalues of $A$ is/are necessarily CORRECT?

- (A) Both (I) and (II)
- (B) (I) only
- (C) (II) only
- (D) Neither (I) nor (II)

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Turn the entry sum into eigenvalues.** For a real symmetric $A$,

$$\sum_{i,j} A_{ij}^2 = \operatorname{tr}(A^TA) = \operatorname{tr}(A^2) = \sum_k \lambda_k^2$$

Rank $2$ means exactly two non-zero eigenvalues $\lambda_1, \lambda_2$ (a symmetric matrix is diagonalizable). So

$$\lambda_1^2 + \lambda_2^2 = 50$$

**(I) is true.** If both $|\lambda_1|, |\lambda_2| > 5$ then $\lambda_1^2 + \lambda_2^2 > 50$, a contradiction. So at least one has $|\lambda| \le 5$. (If $n > 2$ there are also zero eigenvalues, which lie in $[-5,5]$ anyway.)

**(II) is false.** The larger magnitude satisfies $\lambda_{\max}^2 \ge 25$, so $|\lambda_{\max}| \ge 5$. Equality is possible: take $\lambda_1 = \lambda_2 = 5$, i.e. $A = \text{diag}(5, 5, 0)$. It is symmetric, has rank 2 and $\sum A_{ij}^2 = 50$, but its largest eigenvalue magnitude is exactly $5$, not strictly greater.

So (I) only: **(B)**.

**Code check:** $\text{diag}(5,5,0)$ gave rank 2, entry sum 50, and eigenvalues $0, 5, 5$. In 2000 random rank-2 symmetric matrices with entry sum 50, every one had an eigenvalue in $[-5,5]$.

**Key idea:** $\sum A_{ij}^2 = \sum\lambda_k^2$ for symmetric $A$; two non-zero eigenvalues with squares summing to 50 cannot both exceed 5 in magnitude, but both can equal 5.

</details>
