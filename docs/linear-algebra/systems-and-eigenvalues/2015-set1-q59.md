# 2015 CS1 Q59: Finding unknown entries from the eigenvalues of a 2x2 matrix

## Question

Consider the following $2 \times 2$ matrix $A$ where two elements are unknown and are marked by $a$ and $b$. The eigenvalues of this matrix are $-1$ and $7$. What are the values of $a$ and $b$?

$$A = \begin{pmatrix} 1 & 4 \\ b & a \end{pmatrix}$$

- (A) $a = 6,\ b = 4$
- (B) $a = 4,\ b = 6$
- (C) $a = 3,\ b = 5$
- (D) $a = 5,\ b = 3$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For a $2 \times 2$ matrix: the sum of eigenvalues is the trace and the product is the determinant.

- Trace: $1 + a = -1 + 7 = 6 \Rightarrow a = 5$.
- Determinant: $1\cdot a - 4b = (-1)(7) = -7 \Rightarrow 5 - 4b = -7 \Rightarrow b = 3$.

So $a = 5,\ b = 3$: option (D). Checking the others by trace: (A) $1+6 = 7$, (B) $1+4 = 5$, (C) $1+3 = 4$, none equals 6.

**Key idea:** eigenvalues sum to the trace and multiply to the determinant.

</details>
