# GATE CS PYQ Solutions

Previous-year GATE CS questions, solved topic by topic, with diagrams.

- **By subject:** use the navigation menu (Programming & Data Structures first).
- **By year:** see [By year](by-year/index.md).
- Every question shows its **status**: `verified` (matches the official key and any
  code was run), `disputed` (my solution and the key differ) or `unverified`.

Math is written as \(\LaTeX\). Answers are hidden under a collapsible block, so try
the question first.
