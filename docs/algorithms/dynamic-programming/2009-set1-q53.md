# 2009 CS Q53: Recursive definition of the longest common subsequence length

## Question

**Common data for Questions 53 and 54.** A sub-sequence of a given sequence is just the given sequence with some elements (possibly none or all) left out. We are given two sequences `X[m]` and `Y[n]` of lengths $m$ and $n$, respectively, with indexes of `X` and `Y` starting from $0$.

We wish to find the length of the longest common sub-sequence (LCS) of `X[m]` and `Y[n]` as $l(m, n)$, where an incomplete recursive definition for the function $l(i, j)$ to compute the length of the LCS of `X[m]` and `Y[n]` is given below:

```
l(i,j) = 0                 , if either i = 0 or j = 0
       = expr1             , if i,j > 0 and X[i-1] = Y[j-1]
       = expr2             , if i,j > 0 and X[i-1] != Y[j-1]
```

Which one of the following options is correct?

- (A) `expr1` $\equiv l(i-1, j) + 1$
- (B) `expr1` $\equiv l(i, j-1)$
- (C) `expr2` $\equiv \max(l(i-1, j),\ l(i, j-1))$
- (D) `expr2` $\equiv \max(l(i-1, j-1),\ l(i, j))$

*Printed as is: the paper writes `X[i-1]≠Y[j-1]` in the third case; I typed it as `!=`. Note that $l(i, j)$ is the LCS length of the first $i$ characters of `X` and the first $j$ of `Y`.*

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$l(i, j)$ is the LCS length of the prefixes `X[0..i-1]` and `Y[0..j-1]`.

- **Last characters equal** (`X[i-1] = Y[j-1]`): that character can be matched, and the rest is the LCS of the two shorter prefixes: `expr1` $= l(i-1, j-1) + 1$.
- **Last characters differ:** at least one of them is not in the LCS. Drop the last character of `X`, or of `Y`, and keep the better result: `expr2` $= \max(l(i-1, j),\ l(i, j-1))$.

So (C) is correct.

- (A) is wrong: after a match both strings shrink by one, not just `X`. Example: `X = "aa"`, `Y = "a"`. The true LCS is $1$, but (A) gives $l(2,1) = l(1,1) + 1 = 2$.
- (B) is wrong: it drops the matched character without counting it, and shrinks only `Y`. Example: `X = "a"`, `Y = "a"`. The true LCS is $1$, but (B) gives $l(1,1) = l(1,0) = 0$.
- (D) refers to $l(i, j)$ in its own definition, which is circular.

**Code check:** the correct recursion was compared with the versions using (A) and (B). On `X = "aa"`, `Y = "a"` the correct value is $1$ and the (A) version returns $2$. On `X = "a"`, `Y = "a"` the correct value is $1$ and the (B) version returns $0$.

**Key idea:** on a match, shrink both strings; on a mismatch, try dropping the last character of each in turn.

</details>
