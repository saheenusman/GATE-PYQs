# 2016 CS2 Q14: Design paradigm behind the Floyd-Warshall algorithm

## Question

The Floyd-Warshall algorithm for all-pair shortest paths computation is based on

- (A) Greedy paradigm.
- (B) Divide-and-Conquer paradigm.
- (C) Dynamic Programming paradigm.
- (D) neither Greedy nor Divide-and-Conquer nor Dynamic Programming paradigm.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Floyd-Warshall builds $d^{(k)}_{ij}$, the shortest path from $i$ to $j$ using only intermediate vertices $1..k$, from the smaller subproblems

$$d^{(k)}_{ij} = \min\big(d^{(k-1)}_{ij},\ d^{(k-1)}_{ik} + d^{(k-1)}_{kj}\big)$$

The subproblems overlap and the optimal solution is built from optimal sub-solutions, so this is **dynamic programming**, (C). It is not greedy (no locally best choice is committed to) and not divide and conquer (the subproblems are not independent).

**Key idea:** the recurrence $d^{(k)}_{ij}$ over overlapping subproblems is dynamic programming.

</details>
