# 2016 CS2 Q38: Minimum scalar multiplications for a four-matrix chain

## Question

Let $A_1$, $A_2$, $A_3$, and $A_4$ be four matrices of dimensions $10 \times 5$, $5 \times 20$, $20 \times 10$, and $10 \times 5$, respectively. The minimum number of scalar multiplications required to find the product $A_1 A_2 A_3 A_4$ using the basic matrix multiplication method is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1500**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The dimension sequence is $d = (10, 5, 20, 10, 5)$. The best parenthesisation is $A_1\,\big((A_2 A_3)\,A_4\big)$:

| Step | Product | Cost |
|---|---|---|
| $A_2 A_3$ | $(5 \times 20)(20 \times 10)$ | $1000$ |
| $(A_2A_3)\,A_4$ | $(5 \times 10)(10 \times 5)$ | $250$ |
| $A_1\,(A_2A_3A_4)$ | $(10 \times 5)(5 \times 5)$ | $250$ |
| **Total** | | **1500** |

Other orders are worse, e.g. $\big(A_1 (A_2A_3)\big)A_4$ costs $2000$ and $(A_1A_2)(A_3A_4)$ costs $3000$.

**Code check:** the standard matrix-chain DP over $d$ gave $1500$.

**Key idea:** matrix-chain DP gives $A_1((A_2A_3)A_4)$ with cost $1000 + 250 + 250$.

</details>
