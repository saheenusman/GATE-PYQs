# 2008 CS Q80: Recurrence for the subset-sum table

## Question

The subset-sum problem is defined as follows. Given a set of $n$ positive integers $S = \lbrace a_1, a_2, a_3, \ldots, a_n \rbrace$ and a positive integer $W$, is there a subset of $S$ whose elements sum to $W$? A dynamic program for solving this problem uses a two-dimensional Boolean array $X$, with $n$ rows and $W+1$ columns. $X[i,j]$, $1 \le i \le n$, $0 \le j \le W$, is TRUE if and only if there is a subset of $\lbrace a_1, a_2, \ldots, a_i \rbrace$ whose elements sum to $j$.

Which of the following is valid for $2 \le i \le n$ and $a_i \le j \le W$?

- (A) $X[i,j] = X[i-1,j] \lor X[i,j-a_i]$
- (B) $X[i,j] = X[i-1,j] \lor X[i-1,j-a_i]$
- (C) $X[i,j] = X[i-1,j] \land X[i,j-a_i]$
- (D) $X[i,j] = X[i-1,j] \land X[i-1,j-a_i]$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Look at element $a_i$. A subset of $\lbrace a_1..a_i \rbrace$ summing to $j$ either

- **does not use** $a_i$: it is a subset of $\lbrace a_1..a_{i-1} \rbrace$ summing to $j$, i.e. $X[i-1,j]$; or
- **uses** $a_i$ once: the rest is a subset of $\lbrace a_1..a_{i-1} \rbrace$ summing to $j - a_i$, i.e. $X[i-1,j-a_i]$.

The two cases are alternatives, so they are joined by **OR**:

$$X[i,j] = X[i-1,j] \lor X[i-1,j-a_i].$$

- (A) uses $X[i, j-a_i]$, which would let $a_i$ be used several times (unbounded knapsack).
- (C) and (D) use AND, which would require both cases at once.

**Code check:** this recurrence matched a brute-force subset enumeration on 2000 random instances.

**Key idea:** in the 0/1 subset-sum DP each element is either skipped or taken once, so the two cases are combined with OR on the previous row.

</details>
