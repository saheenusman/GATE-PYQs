# 2024 CS2 Q35: Distance of an array from sorted order

## Question

Let $A$ be an array containing integer values. The distance of $A$ is defined as the minimum number of elements in $A$ that must be replaced with another integer so that the resulting array is sorted in non-decreasing order. The distance of the array $[2, 5, 3, 1, 4, 2, 6]$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A replaced element can be given *any* integer, so the elements we keep only need to already be in non-decreasing order. The fewest replacements therefore equal

$$n - (\text{length of the longest non-decreasing subsequence}).$$

**Longest non-decreasing subsequence of $[2, 5, 3, 1, 4, 2, 6]$:** for example $2, 3, 4, 6$, length **4**. No subsequence of length 5 exists (checked by a script).

Distance $= 7 - 4 = 3$. We keep 2, 3, 4, 6 and replace the other three (5, 1, 2) with values that fit between them.

**Key idea:** "minimum changes to sort" is $n$ minus the longest non-decreasing subsequence (LNDS).

</details>
