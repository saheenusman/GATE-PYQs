# 2024 CS2 Q42: Longest subarray with at most two distinct values

## Question

Consider an array `X` that contains $n$ positive integers. A subarray of `X` is defined to be a sequence of array locations with consecutive indices.

The C code snippet given below has been written to compute the length of the longest subarray of `X` that contains at most two distinct integers. The code has two missing expressions labelled (P) and (Q).

```c
int first=0, second=0, len1=0, len2=0, maxlen=0;
for (int i=0; i < n; i++) {
  if (X[i] == first) {
    len2++; len1++;
  } else if (X[i] == second) {
    len2++;
    len1 = (P);
    second = first;
  } else {
    len2 = (Q);
    len1 = 1; second = first;
  }
  if (len2 > maxlen) {
    maxlen = len2;
  }
  first = X[i];
}
```

Which one of the following options gives the CORRECT missing expressions? (Hint: at the end of the $i$-th iteration, the value of `len1` is the length of the longest subarray ending with `X[i]` that contains all equal values, and `len2` is the length of the longest subarray ending with `X[i]` that contains at most two distinct values.)

- (A) (P) `len1+1`, (Q) `len2+1`
- (B) (P) `1`, (Q) `len1+1`
- (C) (P) `1`, (Q) `len2+1`
- (D) (P) `len2+1`, (Q) `len1+1`

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

At the start of each iteration, `first` holds the previous element `X[i-1]` and `second` holds the other value in the current window.

**Case 2: `X[i] == second`.** The new element differs from the previous one, so the run of equal values restarts at length **1**. So **(P) = 1**. (`len2` still grows by 1 because the window keeps the same two values.)

**Case 3: a brand-new value.** The longest valid window ending at `X[i]` is `X[i]` plus the **run of equal values just before it** (that run has one distinct value, plus the new one makes two). That run's length is `len1`, so **(Q) = len1 + 1**. (Keeping `len2 + 1` would wrongly keep a third distinct value.)

**Verified.** I compared the four options with a brute-force search on 20,000 random arrays. Option B matched every time. A and C each failed on 14,348 arrays and D on 8,213.

**Key idea:** the window can only be extended back through the last run of equal values when a third value appears.

</details>
