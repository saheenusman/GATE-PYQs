# 2008 CS Q81: Which table entry answers the subset-sum question

## Question

(Continuing the subset-sum setting of Q.80.) Which entry of the array $X$, if TRUE, implies that there is a subset whose elements sum to $W$?

- (A) $X[1, W]$
- (B) $X[n, 0]$
- (C) $X[n, W]$
- (D) $X[n-1, n]$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

By definition, $X[i,j]$ is TRUE iff some subset of the first $i$ elements sums to $j$. The question asks about the whole set (all $n$ elements) and the target $W$, so the entry is $X[n, W]$.

- (A) $X[1,W]$ only looks at $\lbrace a_1 \rbrace$.
- (B) $X[n,0]$ is TRUE for any input (the empty subset sums to 0), so it says nothing about $W$.
- (D) $X[n-1, n]$ uses the wrong row and the wrong column (the column index is a sum, not an element count).

**Code check:** using $X[n,W]$ agreed with brute force on the same 2000 random instances as Q.80.

**Key idea:** the answer to the full problem sits in the last row ($i = n$) and the target column ($j = W$).

</details>
