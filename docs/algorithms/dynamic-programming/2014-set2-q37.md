# 2014 CS2 Q37: Longest common subsequence and how many there are

## Question

Consider two strings $A$ = "qpqrr" and $B$ = "pqprqrp". Let $x$ be the length of the longest common subsequence (not necessarily contiguous) between $A$ and $B$ and let $y$ be the number of such longest common subsequences between $A$ and $B$. Then $x + 10y$ = ___.

<details class="success" markdown="1">
<summary>Answer</summary>

**34**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The LCS recurrence, with $A_i$, $B_j$ the characters under consideration, is

$$L(i,j) = \begin{cases} L(i-1,j-1) + 1 & A_i = B_j \\ \max(L(i-1,j),\ L(i,j-1)) & \text{otherwise} \end{cases}$$

This gives $x = 4$. The distinct longest common subsequences are

$$\texttt{pqrr},\quad \texttt{qpqr},\quad \texttt{qprr}$$

so $y = 3$.

$$x + 10y = 4 + 30 = 34$$

**Code check:** a DP that collects every distinct LCS string returns length 4 and exactly these three strings.

**Key idea:** count distinct LCS strings by following every maximal branch of the DP table, and do not count the same string twice.

</details>
