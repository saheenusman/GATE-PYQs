# 2016 CS2 Q39: Exponent of the worst case time of a recursive flowchart function

## Question

The given diagram shows the flowchart for a recursive function $A(n)$. Assume that all statements, except for the recursive calls, have $O(1)$ time complexity. If the worst case time complexity of this function is $O(n^{\alpha})$, then the least possible value (accurate up to two decimal positions) of $\alpha$ is ______.

![Flowchart of A(n): Start, then a call A(n/2), then a decision. The left branch makes one call A(n/2) and returns. The right branch makes two calls A(n/2), then a second decision that either returns or makes one call A(n/2) and reaches a third decision that either returns or makes one more call A(n/2) and returns.](../../assets/2016/set2-q39.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**2.32**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count the recursive calls $A(n/2)$ along the **worst path** through the flowchart.

1. The first call $A(n/2)$ always happens (1 call).
2. At the first decision:
   - left: one more call, then return (total 2); or
   - right: two more calls, then another decision.
3. At the second decision: right return (total 3), or down to one more call (total 4) and a third decision.
4. At the third decision: right return (total 4), or left through one more call and return (total **5**).

The longest path makes $5$ calls on subproblems of size $n/2$:

$$T(n) = 5\,T(n/2) + O(1)$$

By the master theorem (case 1), $T(n) = \Theta(n^{\log_2 5})$, and

$$\alpha = \log_2 5 \approx 2.32$$

The key accepts $2.2$ to $2.4$.

**Code check:** $\log_2 5 = 2.3219$.

**Key idea:** worst path has 5 calls on size $n/2$: $T(n) = 5T(n/2) + O(1)$, so $\alpha = \log_2 5$.

</details>
