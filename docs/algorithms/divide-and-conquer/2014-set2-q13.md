# 2014 CS2 Q13: Solution of T(n) = 2T(n/2) + log n

## Question

Which one of the following correctly determines the solution of the recurrence relation with $T(1) = 1$?

$$T(n) = 2T\left(\frac{n}{2}\right) + \log n$$

- (A) $\Theta(n)$
- (B) $\Theta(n \log n)$
- (C) $\Theta(n^2)$
- (D) $\Theta(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Master theorem with $a = 2$, $b = 2$, $f(n) = \log n$. Then $n^{\log_b a} = n$.

$f(n) = \log n = O(n^{1-\epsilon})$ for any $\epsilon \in (0,1)$, so case 1 applies:

$$T(n) = \Theta(n)$$

**Code check:** computing the recurrence for $n = 2^4, 2^8, \ldots, 2^{20}$ gives $T(n)/n$ = 2.63, 2.96, 2.997, 2.9997, 3.0, so $T(n) \to 3n$.

- (B) would need $f(n) = \Theta(n)$.
- (C) is far above the work done at the leaves, $\Theta(n)$.
- (D) $T(n)$ grows at least as fast as the number of leaves, $n$.

**Key idea:** leaves dominate when $f(n)$ is polynomially smaller than $n^{\log_b a}$.

</details>
