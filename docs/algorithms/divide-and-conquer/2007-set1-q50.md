# 2007 CS Q50: Comparisons to find the maximum and minimum together

## Question

An array of $n$ numbers is given, where $n$ is an even number. The maximum as well as the minimum of these $n$ numbers needs to be determined. Which of the following is **TRUE** about the number of comparisons needed?

- (A) At least $2n - c$ comparisons, for some constant $c$, are needed.
- (B) At most $1.5n - 2$ comparisons are needed.
- (C) At least $n\log_2 n$ comparisons are needed.
- (D) None of the above.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Pair up the elements. Compare the two elements of each pair ($n/2$ comparisons). Compare the larger of each pair against the running maximum ($n/2 - 1$ comparisons) and the smaller of each pair against the running minimum ($n/2 - 1$ comparisons). Total:
$$\frac{n}{2} + 2\left(\frac{n}{2} - 1\right) = \frac{3n}{2} - 2 = 1.5n - 2.$$

So at most $1.5n - 2$ comparisons suffice: (B). (This is also optimal: $\lceil 3n/2\rceil - 2$ is a known lower bound.)

- (A) is false: $1.5n - 2 < 2n - c$ for large $n$, so $2n - c$ are not *needed*.
- (C) is false: $n\log_2 n$ is far above $1.5n - 2$.
- (D) is wrong because (B) is true.

**Code check:** Python implementation of the pairing method, checked against `max`/`min`: it used exactly $1, 4, 13, 148, 1498$ comparisons for $n = 2, 4, 10, 100, 1000$, which equals $1.5n - 2$ each time.
