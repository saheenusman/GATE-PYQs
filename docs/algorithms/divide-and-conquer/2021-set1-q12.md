# 2021 CS1 Q12: Lower bound on comparisons to find min and max

## Question

Let P be an array containing $n$ integers. Let $t$ be the lowest upper bound on the number of comparisons of the array elements, required to find the minimum and maximum values in an arbitrary array of $n$ elements. Which one of the following choices is correct?

- (A) $t > 2n-2$
- (B) $t > 3\lceil n/2\rceil$ and $t \le 2n-2$
- (C) $t > n$ and $t \le 3\lceil n/2\rceil$
- (D) $t > \lceil\log_2 n\rceil$ and $t \le n$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The tight bound for finding min and max together is $t=\lceil 3n/2\rceil-2$. The pairing method achieves it: compare elements in pairs, then compare the winners with the current max and the losers with the current min.

For $n=8$: $t=10$, and $n=8$, $3\lceil n/2\rceil=12$. So $n<t\le 3\lceil n/2\rceil$. In general $\lceil 3n/2\rceil-2>n$ once $n\ge 5$, and $\lceil 3n/2\rceil-2\le 3\lceil n/2\rceil$ always.

- (A) $t>2n-2$ is false: the naive method uses $2n-2$ comparisons and $t$ is smaller.
- (B) $t>3\lceil n/2\rceil$ is false.
- (C) $t>n$ and $t\le3\lceil n/2\rceil$. **Correct** (for $n\ge5$).
- (D) $t\le n$ is false, since $t\approx 1.5n$.

The statement holds for large $n$. For tiny $n$ (say $n=2$, $t=1$) the bound $t>n$ fails, so the question implicitly means large $n$.

**Key idea:** min and max together need $\lceil 3n/2\rceil-2$ comparisons, not $2n-2$.

</details>
