# 2015 CS2 Q16: Comparisons to find an element that is neither maximum nor minimum

## Question

An unordered list contains $n$ distinct elements. The number of comparisons to find an element in this list that is neither maximum nor minimum is

- (A) $\Theta(n \log n)$
- (B) $\Theta(n)$
- (C) $\Theta(\log n)$
- (D) $\Theta(1)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Take **any three** elements $a, b, c$ of the list ($n \ge 3$) and find their median with at most 3 comparisons.

The median has one element smaller than it and one larger than it (both in the list), so it can be neither the maximum nor the minimum of the *whole* list. This takes a constant number of comparisons, independent of $n$.

So the answer is $\Theta(1)$: option (D). (A), (B) and (C) correspond to sorting, scanning, or searching, none of which is needed.

**Key idea:** an element with something smaller and something larger is neither max nor min, so three elements suffice.

</details>
