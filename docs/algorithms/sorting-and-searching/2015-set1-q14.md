# 2015 CS1 Q14: Worst-case recurrence of Quicksort

## Question

Which one of the following is the recurrence equation for the worst case time complexity of the Quicksort algorithm for sorting $n\ (\ge 2)$ numbers? In the recurrence equations given in the options below, $c$ is a constant.

- (A) $T(n) = 2T(n/2) + cn$
- (B) $T(n) = T(n-1) + T(1) + cn$
- (C) $T(n) = 2T(n-1) + cn$
- (D) $T(n) = T(n/2) + cn$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In the worst case the pivot is the smallest or largest element. Partitioning costs $cn$ and leaves sub-problems of size $n-1$ and $1$ (or $0$).

$$T(n) = T(n-1) + T(1) + cn \;\Rightarrow\; T(n) = \Theta(n^2)$$

- (A) $2T(n/2) + cn$ is the **best** (balanced) case, giving $\Theta(n\log n)$.
- (C) $2T(n-1)$ would recurse on *two* sub-problems of size $n-1$, which Quicksort never does (and would be exponential).
- (D) $T(n/2) + cn$ recurses on one half only, like binary search with linear work.

**Key idea:** the worst case is a maximally unbalanced split, $n-1$ and $1$.

</details>
