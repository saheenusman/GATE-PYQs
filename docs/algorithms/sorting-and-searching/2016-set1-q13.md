# 2016 CS1 Q13: Worst-case running times of insertion, merge and quick sort

## Question

The worst case running times of Insertion sort, Merge sort and Quick sort, respectively, are:

- (A) $\Theta(n \log n)$, $\Theta(n \log n)$, and $\Theta(n^2)$
- (B) $\Theta(n^2)$, $\Theta(n^2)$, and $\Theta(n \log n)$
- (C) $\Theta(n^2)$, $\Theta(n \log n)$, and $\Theta(n \log n)$
- (D) $\Theta(n^2)$, $\Theta(n \log n)$, and $\Theta(n^2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Algorithm | Worst case | Why |
|---|---|---|
| Insertion sort | $\Theta(n^2)$ | reverse-sorted input: each element moves past all earlier ones |
| Merge sort | $\Theta(n \log n)$ | always splits in half: $T(n) = 2T(n/2) + \Theta(n)$ |
| Quick sort | $\Theta(n^2)$ | worst pivot at every step: $T(n) = T(n-1) + \Theta(n)$ |

That is $\Theta(n^2), \Theta(n \log n), \Theta(n^2)$, which is (D).

**Why the others fail.** (A) makes insertion sort $\Theta(n \log n)$ in the worst case (it is $\Theta(n)$ only in the best case). (B) makes merge sort quadratic and quick sort $n \log n$ in the worst case, both wrong. (C) says quick sort is $\Theta(n \log n)$ in the worst case; that is its average case.

**Key idea:** quick sort is $\Theta(n^2)$ in the worst case; merge sort is $\Theta(n \log n)$ always.

</details>
