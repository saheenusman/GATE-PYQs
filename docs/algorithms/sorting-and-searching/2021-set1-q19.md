# 2021 CS1 Q19: Fewest comparisons to sort an already sorted array

## Question

Consider the following array.

| 23 | 32 | 45 | 69 | 72 | 73 | 89 | 97 |
|---|---|---|---|---|---|---|---|

Which algorithm out of the following options uses the least number of comparisons (among the array elements) to sort the above array in ascending order?

- (A) Selection sort
- (B) Mergesort
- (C) Insertion sort
- (D) Quicksort using the last element as pivot

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The array is already sorted ($n=8$). I counted the comparisons of each algorithm with a script.

| Algorithm | Comparisons |
|---|---|
| Selection sort | 28 ($\binom{8}{2}$, always) |
| Mergesort | 12 |
| Insertion sort | 7 ($n-1$) |
| Quicksort, last pivot | 28 (worst case: sorted input) |

Insertion sort compares each element only with its left neighbour, which is already smaller, so it needs $n-1=7$.

(C) is correct.

**Key idea:** insertion sort is $O(n)$ on sorted input; quicksort with an end pivot is $O(n^2)$ on it.

</details>
