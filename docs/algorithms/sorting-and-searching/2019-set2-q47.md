# 2019 CS2 Q47: Worst-case time to find the median of medians

## Question

There are $n$ unsorted arrays: $A_1, A_2, \dots, A_n$. Assume that $n$ is odd. Each of $A_1, A_2, \dots, A_n$ contains $n$ distinct elements. There are no common elements between any two arrays. The worst-case time complexity of computing the median of the medians of $A_1, A_2, \dots, A_n$ is

- (A) $O(n)$
- (B) $O(n \log n)$
- (C) $O(n^2)$
- (D) $\Omega(n^2 \log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Upper bound.** The median of one unsorted array of $n$ elements can be found in $O(n)$ **worst-case** time (median-of-medians selection). Do it for each of the $n$ arrays: $n \cdot O(n) = O(n^2)$. Then take the median of the $n$ medians in $O(n)$. Total: $O(n^2)$.

**Lower bound.** There are $n^2$ elements in all, and each array's median depends on every element in it. So at least $\Omega(n^2)$ work is needed anyway.

**Why the others fail:**

- (A) and (B) are below $n^2$, but the input alone has $n^2$ elements.
- (D) sorting each array would cost $O(n \log n)$ each and $O(n^2 \log n)$ in total, but selection avoids sorting. $\Omega(n^2 \log n)$ is not a lower bound.

**Key idea:** the median of $n$ elements takes linear time without sorting. Do that $n$ times for $n^2$ total.

</details>
