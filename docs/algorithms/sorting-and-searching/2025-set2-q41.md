# 2025 CS2 Q41: Searching in a bitonic array

## Question

An array $A$ of length $n$ with distinct elements is said to be bitonic if there is an index $1 \le i \le n$ such that $A[1..i]$ is sorted in the non-decreasing order and $A[i+1..n]$ is sorted in the non-increasing order.

Which ONE of the following represents the best possible asymptotic bound for the worst-case number of comparisons by an algorithm that searches for an element in a bitonic array $A$?

- (A) $\Theta(n)$
- (B) $\Theta(1)$
- (C) $\Theta(\log_2 n)$
- (D) $\Theta(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Upper bound, $O(\log n)$.**

1. **Find the peak** by binary search: compare $A[m]$ with $A[m+1]$. If $A[m] < A[m+1]$ the peak is to the right, otherwise it is at $m$ or to the left. This takes $O(\log n)$ comparisons.
2. **Binary search the increasing part** $A[1..i]$ and the decreasing part $A[i+1..n]$, each in $O(\log n)$.

Total: $O(\log n)$.

**Lower bound, $\Omega(\log n)$.** Even if you knew the peak, searching a sorted part of size about $n/2$ needs $\Omega(\log n)$ comparisons (information-theoretic bound).

So the best worst case is $\Theta(\log n)$.

I implemented this three-step search and measured the worst number of comparisons on random bitonic arrays: 29 for $n=2^{10}$, 41 for $n=2^{14}$, and 53 for $n=2^{18}$. These grow by about $3 \cdot 4 = 12$ each time $n$ is multiplied by $2^4$, which is the logarithmic behaviour (about $3\log_2 n$).

| Option | Why wrong |
|---|---|
| A, $\Theta(n)$ | Linear scan is not optimal |
| B, $\Theta(1)$ | Impossible: the position is not known in advance |

**Note on the options.** (C) $\Theta(\log_2 n)$ and (D) $\Theta(\log n)$ describe the **same** growth rate, since logarithm bases differ by a constant factor. The official key lists only (D).

**Key idea:** locate the peak with binary search, then binary search each monotone side: $\Theta(\log n)$.

</details>
