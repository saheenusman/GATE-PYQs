# 2007 CS Q14: Lowest worst-case sorting algorithm

## Question

Which of the following sorting algorithms has the lowest worst-case complexity?

- (A) Merge sort
- (B) Bubble sort
- (C) Quick sort
- (D) Selection sort

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Algorithm | Worst case |
|---|---|
| Merge sort | $\Theta(n \log n)$ |
| Bubble sort | $\Theta(n^2)$ |
| Quick sort | $\Theta(n^2)$ |
| Selection sort | $\Theta(n^2)$ |

Merge sort always splits evenly and merges in linear time, so it stays at $n\log n$: (A).

- (C) Quick sort is $n\log n$ on average but degrades to $n^2$ with consistently bad pivots (for example, an already sorted input with a first-element pivot).
- (B) and (D) are quadratic in every case.
