# 2026 CS2 Q38: Checking a convex-difference condition

## Question

Let $A$ be an integer array of size $n$ with indices $1$ to $n$. An algorithm must check whether $A$ satisfies:

$$\forall\, i, j \in \lbrace 1, \dots, n-1 \rbrace \text{ with } i > j:\quad A[i+1] - A[i] \;>\; A[j+1] - A[j].$$

Which option gives the worst-case time complexity of the fastest algorithm for this problem?

- (A) $\Theta(n)$
- (B) $\Theta(\log n)$
- (C) $\Theta(n \log n)$
- (D) $\Theta(n^2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1: rewrite with differences.** Let $d_k = A[k+1] - A[k]$ for $k = 1, \dots, n-1$. The condition says

$$d_i > d_j \text{ for every } i > j,$$

so the differences must be **strictly increasing**.

**Step 2: only neighbours matter.** If $d_1 < d_2 < \dots < d_{n-1}$, then every pair $i > j$ satisfies $d_i > d_j$ by transitivity. So it is enough to check

$$d_{k+1} > d_k \quad \text{for } k = 1, \dots, n-2.$$

That is a single pass:

```text
for k = 2 to n-1:
    if A[k+1]-A[k] <= A[k]-A[k-1]:
        return false
return true
```

**Step 3: lower bound.** Changing any one element can break the condition, so every element must be read. No algorithm can beat $\Omega(n)$. With the $O(n)$ scan, the answer is $\Theta(n)$.

**Why the others fail:**

- **(B)** $\Theta(\log n)$ would mean not reading most of the array, which is impossible here.
- **(C)** $\Theta(n \log n)$ has no sorting or divide step to justify it.
- **(D)** $\Theta(n^2)$ is the naive check of all pairs $(i, j)$. It is correct but not the fastest.

**Verified** by testing on 20,000 random small arrays: the all-pairs condition and the neighbours-only condition always agreed.

**Key idea:** a condition over all pairs that follows from transitivity can be reduced to a check of neighbouring pairs, turning $O(n^2)$ into $O(n)$.

</details>
