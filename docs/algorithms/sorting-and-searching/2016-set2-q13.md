# 2016 CS2 Q13: Running time of four sorts on an already sorted input

## Question

Assume that the algorithms considered here sort the input sequences in ascending order. If the input is already in ascending order, which of the following are TRUE?

- I. Quicksort runs in $\Theta(n^2)$ time
- II. Bubblesort runs in $\Theta(n^2)$ time
- III. Mergesort runs in $\Theta(n)$ time
- IV. Insertion sort runs in $\Theta(n)$ time

- (A) I and II only
- (B) I and III only
- (C) II and IV only
- (D) I and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**I true.** With the usual first or last element as pivot, a sorted input gives splits of sizes $0$ and $n-1$ every time: $\Theta(n^2)$.

**II false.** Bubble sort that stops when a pass makes no swap finishes after one pass on sorted input: $\Theta(n)$.

**III false.** Mergesort always splits and merges: $\Theta(n \log n)$.

**IV true.** Insertion sort does one comparison per element on sorted input: $\Theta(n)$.

True: I and IV, **(D)**.

**Assumptions the key relies on.**

- Quicksort picks the first or last element as pivot.
- Bubble sort has the early-exit check. Without it, bubble sort is $\Theta(n^2)$ even on sorted input, II would be true, and no option would match.

**Code check:** counting comparisons on sorted input for $n = 100, 200, 400$ gave quicksort (last-element pivot) $4950, 19900, 79800$ (that is $n(n-1)/2$), bubble sort with early exit $99, 199, 399$, insertion sort $99, 199, 399$, and mergesort $316, 732, 1664$ (about $\tfrac12 n \log_2 n$, still $\Theta(n \log n)$).

**Key idea:** naive-pivot quicksort is quadratic on sorted input; insertion sort (and early-exit bubble sort) is linear; mergesort is always $n \log n$.

</details>
