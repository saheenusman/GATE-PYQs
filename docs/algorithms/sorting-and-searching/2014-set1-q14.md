# 2014 CS1 Q14: Quicksort comparisons on two inputs (first-element pivot)

## Question

Let $P$ be a quicksort program to sort numbers in ascending order using the first element as the pivot. Let $t_1$ and $t_2$ be the number of comparisons made by $P$ for the inputs [1 2 3 4 5] and [4 1 5 3 2] respectively. Which one of the following holds?

- (A) $t_1 = 5$
- (B) $t_1 < t_2$
- (C) $t_1 > t_2$
- (D) $t_1 = t_2$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Partitioning $k$ elements takes $k-1$ comparisons against the pivot.

**[1 2 3 4 5]** (already sorted, worst case). The pivot is always the minimum, so the split is $0$ and $k-1$:

$$4 + 3 + 2 + 1 = 10 = t_1$$

**[4 1 5 3 2].**

| Call | Pivot | Comparisons | Parts |
|---|---|---|---|
| [4 1 5 3 2] | 4 | 4 | [1 3 2], [5] |
| [1 3 2] | 1 | 2 | [], [3 2] |
| [3 2] | 3 | 1 | [2], [] |

$t_2 = 4 + 2 + 1 = 7$.

**Code check:** a counting implementation gives $t_1 = 10$, $t_2 = 7$.

So $t_1 > t_2$.

- (A) $t_1 = 10$, not 5.
- (B) and (D) fail since $10 \ne 7$ and $10 > 7$.

**Key idea:** a sorted input is the worst case for a first-element pivot.

</details>
