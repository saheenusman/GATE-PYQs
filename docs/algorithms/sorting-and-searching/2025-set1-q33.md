# 2025 CS1 Q33: Swaps made by bubble sort on a descending array

## Question

The pseudocode of a function `fun()` is given below:

```
fun(int A[0,...,n-1]){
    for i=0 to n-2
        for j=0 to n-i-2
            if (A[j]>A[j+1])
                then swap A[j] and A[j+1]
}
```

Let $A[0,\dots,29]$ be an array storing 30 distinct integers in descending order. The number of swap operations that will be performed, if the function `fun()` is called with $A[0,\dots,29]$ as argument, is __________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**435**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

This is bubble sort. In a **descending** array every adjacent pair is out of order, and passes only ever swap out-of-order neighbours. So **every comparison causes a swap**, and the number of swaps equals the number of comparisons.

Comparisons per pass $i$ (for $i = 0$ to $n-2$): the inner loop runs $j = 0$ to $n-i-2$, which is $n-1-i$ times.

$$\sum_{i=0}^{n-2}(n-1-i) = (n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2}.$$

For $n = 30$: $\dfrac{30 \cdot 29}{2} = 435$.

A simulation of the loops on $30, 29, \dots, 1$ also counts 435 swaps.

(Equivalently: the number of swaps equals the number of inversions, and a descending array has $\binom{30}{2} = 435$ of them.)

**Key idea:** bubble sort does one swap per inversion, and a reverse-sorted array has the maximum $\binom{n}{2}$ inversions.

</details>
