# 2014 CS3 Q42: What does `ProcessArray` do on a sorted array

## Question

Consider the C function given below. Assume that the array `listA` contains `n` ($> 0$) elements, sorted in ascending order.

```c
int ProcessArray(int *listA, int x, int n)
{
  int i, j, k;
  i = 0;
  j = n-1;
  do {
       k = (i+j)/2;
       if (x <= listA[k])
            j = k-1;
       if (listA[k] <= x)
            i = k+1;
     } while (i <= j);

  if (listA[k] == x)
      return(k);
  else
      return -1;
}
```

Which one of the following statements about the function `ProcessArray` is **CORRECT**?

- (A) It will run into an infinite loop when `x` is not in `listA`.
- (B) It is an implementation of binary search.
- (C) It will always find the maximum element in `listA`.
- (D) It will return $-1$ even when `x` is present in `listA`.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each pass examines the middle element `k` of the range `[i, j]`:

- `x < listA[k]`: only the first `if` fires, so `j = k-1` (discard the right half).
- `x > listA[k]`: only the second `if` fires, so `i = k+1` (discard the left half).
- `x == listA[k]`: **both** `if`s fire, so `j = k-1` and `i = k+1`, making $i > j$ and ending the loop with `k` still at the match, so `listA[k] == x` and `k` is returned.

This is **binary search**.

- (A) false: every pass shrinks the range by at least `k`'s position, so the loop ends in at most $\lceil\log_2 (n+1)\rceil$ passes.
- (C) false: it finds `x`, not the maximum (except when `x` is the maximum).
- (D) false: if `x` is present, the range always contains it, so some pass finds it. If `x` is absent, no `k` equals `x`, so $-1$ is correct.

**Code check:** I compiled the function with `gcc -Wall` (no warnings for the function) and tested it on every sorted array of length 1 to 7 with values in $0..4$ (so with duplicates) and every $x \in [-1, 5]$: 5537 cases, 0 wrong results (always correct index when present, $-1$ when absent).

**Key idea:** the two `if`s together implement the three-way comparison of binary search; equality makes both fire and ends the loop.

</details>
