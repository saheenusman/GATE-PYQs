# 2017 CS1 Q48: Worst-case probes to find the first 1 in a 0s-then-1s array of 31 numbers

## Question

Let $A$ be an array of 31 numbers consisting of a sequence of 0's followed by a sequence of 1's. The problem is to find the smallest index $i$ such that $A[i]$ is 1 by probing the minimum number of locations in $A$. The worst case number of probes performed by an *optimal* algorithm is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Algorithm.** Because the array is sorted (0's then 1's), **binary search** works: probe the middle; if it is 1, the first 1 is at or before it, otherwise after it.

**Lower bound.** The answer is one of 31 positions (32 if the array may have no 1 at all). Each probe has two outcomes, so after $k$ probes at most $2^k$ cases can be told apart:

$$2^k \ge 31 \;(\text{or } 32) \;\Rightarrow\; k \ge 5$$

**Upper bound.** Binary search on 31 elements needs $\lceil\log_2(31+1)\rceil = 5$ probes in the worst case.

The optimal worst case is **5**.

**Code check:** a minimax recurrence over the possible positions gave 5 for both 31 and 32 outcomes, and a simulated binary search on all placements of the boundary in a 31-element array used at most 5 probes.

**Key idea:** a yes/no probe halves the candidates, so $n$ candidates need $\lceil\log_2 n\rceil$ probes.

</details>
