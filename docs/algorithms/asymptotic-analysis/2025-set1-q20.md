# 2025 CS1 Q20: Solving T(n) = 2T(n-1) + n 2^n

## Question

Consider the following recurrence relation:

$$T(n) = 2T(n-1) + n2^n \ \text{ for } n > 0,\qquad T(0) = 1.$$

Which ONE of the following options is CORRECT?

- (A) $T(n) = \Theta(n^2 2^n)$
- (B) $T(n) = \Theta(n 2^n)$
- (C) $T(n) = \Theta((\log n)^2\, 2^n)$
- (D) $T(n) = \Theta(4^n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Divide both sides by $2^n$ and let $S(n) = T(n)/2^n$:

$$S(n) = \frac{2T(n-1)}{2^n} + n = S(n-1) + n,\qquad S(0) = 1.$$

Unrolling,

$$S(n) = 1 + (1 + 2 + \dots + n) = 1 + \frac{n(n+1)}{2}.$$

So

$$T(n) = 2^n\left(1 + \frac{n(n+1)}{2}\right) = \Theta(n^2\, 2^n).$$

Numerical check: $T(n)/(n^2 2^n)$ was 0.56 at $n=10$ and 0.51 at $n=60$, settling at $\tfrac12$. The ratios against $n2^n$ and $4^n$ do not settle (they grow or shrink).

| Option | Why wrong |
|---|---|
| B, $n2^n$ | Too small: the sum $\sum k$ gives $n^2$, not $n$ |
| C, $(\log n)^2 2^n$ | Nothing produces logarithms here |
| D, $4^n$ | Too large: the coefficient of $2^n$ grows only polynomially |

**Key idea:** divide by the homogeneous solution $2^n$ to turn the recurrence into a plain sum.

</details>
