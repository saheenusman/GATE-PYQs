# 2011 CS Q37: Increasing order of four growth functions

## Question

Which of the given options provides the increasing order of asymptotic complexity of functions $f_1, f_2, f_3$ and $f_4$ ?

$f_1(n) = 2^n$, $\quad f_2(n) = n^{3/2}$, $\quad f_3(n) = n \log_2 n$, $\quad f_4(n) = n^{\log_2 n}$

- (A) $f_3, f_2, f_4, f_1$
- (B) $f_3, f_2, f_1, f_4$
- (C) $f_2, f_3, f_1, f_4$
- (D) $f_2, f_3, f_4, f_1$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compare in pairs.

- $n \log_2 n$ vs $n^{3/2}$: divide by $n$: $\log_2 n$ vs $\sqrt n$. The square root grows faster, so $f_3 < f_2$.
- $n^{3/2}$ vs $n^{\log_2 n}$: for $\log_2 n > 3/2$ (that is, $n > 3$) the exponent of $f_4$ is larger, so $f_2 < f_4$.
- $n^{\log_2 n} = 2^{(\log_2 n)^2}$ vs $2^n$: $(\log_2 n)^2$ grows slower than $n$, so $f_4 < f_1$.

Order: $f_3 < f_2 < f_4 < f_1$: (A).

Check with $n = 2^{20}$, taking $\log_2$ of each function: $f_3 \approx 24.3$, $f_2 = 30$, $f_4 = 400$, $f_1 = 1048576$.

- (B) puts $f_1$ before $f_4$; (C) puts $f_2$ before $f_3$ and $f_1$ before $f_4$; (D) puts $f_2$ before $f_3$. Each contradicts one of the comparisons above.

**Key idea:** compare growth by taking logs: n log n < n^1.5 < 2^((log n)^2) < 2^n.

</details>
