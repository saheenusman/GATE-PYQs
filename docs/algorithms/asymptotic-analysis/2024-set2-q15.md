# 2024 CS2 Q15: Linear recurrence with initial values 1 and 2

## Question

Let $T(n)$ be the recurrence relation defined as follows:

$T(0) = 1$, $T(1) = 2$, and $T(n) = 5T(n-1) - 6T(n-2)$ for $n \ge 2$.

Which one of the following statements is TRUE?

- (A) $T(n) = \Theta(2^n)$
- (B) $T(n) = \Theta(n 2^n)$
- (C) $T(n) = \Theta(3^n)$
- (D) $T(n) = \Theta(n 3^n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Characteristic equation:** $r^2 - 5r + 6 = 0 \Rightarrow r = 2, 3$. So

$$T(n) = a\cdot 2^n + b\cdot 3^n.$$

**Use the initial values:**

- $T(0) = a + b = 1$
- $T(1) = 2a + 3b = 2$

Subtract twice the first from the second: $b = 0$, so $a = 1$.

$$T(n) = 2^n.$$

Check: $T(2) = 5\cdot 2 - 6\cdot 1 = 4 = 2^2$, $T(3) = 5\cdot 4 - 6 \cdot 2 = 8$. ✓

**Why the others fail:** the $3^n$ term is the faster-growing root, but its coefficient is **zero** here. There is no repeated root, so no $n$ factor.

**Key idea:** always solve for the coefficients. The initial values decide which characteristic roots actually appear.

</details>
