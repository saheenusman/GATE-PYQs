# 2015 CS1 Q64: Return value of a function with nested halving and doubling loops

## Question

Consider the following C function.

```c
int fun1 (int n) {
    int i, j, k, p, q = 0;
    for (i = 1; i < n; ++i) {
        p = 0;
        for (j = n; j > 1; j = j/2)
            ++p;
        for (k = 1; k < p; k = k*2)
            ++q;
    }
    return q;
}
```

Which one of the following most closely approximates the return value of the function `fun1`?

- (A) $n^3$
- (B) $n(\log n)^2$
- (C) $n\log n$
- (D) $n\log(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The outer loop runs $n - 1$ times, and each pass does the same work.

- The $j$ loop halves $j$ from $n$ down to $1$, so $p = \lfloor \log_2 n \rfloor$.
- The $k$ loop doubles $k$ from $1$ while $k < p$, so it runs about $\log_2 p$ times and adds that to $q$.

$$q \approx (n-1)\,\log_2 p = (n-1)\log_2(\log_2 n) \approx n \log(\log n)$$

Option (D). (A), (B) and (C) overcount: $\log n$ appears only inside the logarithm, not as a multiplier.

**Code check:** compiled with `gcc -Wall`. For $n = 2^{16}$ the function returned $262140$, and $q/(n\log_2\log_2 n)$ stayed close to $1$ for $n = 2^4,\dots,2^{20}$, while $q/(n\log_2 n)$ kept shrinking.

**Key idea:** a loop that doubles up to $p$ runs $\log p$ times, and here $p = \log n$.

</details>
