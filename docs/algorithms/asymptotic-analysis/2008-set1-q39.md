# 2008 CS Q39: Ordering the growth of 2^n, n! and n^(log n)

## Question

Consider the following functions:

$$f(n) = 2^n, \qquad g(n) = n!, \qquad h(n) = n^{\log n}$$

Which of the following statements about the asymptotic behaviour of $f(n)$, $g(n)$ and $h(n)$ is true?

- (A) $f(n) = O(g(n));\ g(n) = O(h(n))$
- (B) $f(n) = \Omega(g(n));\ g(n) = O(h(n))$
- (C) $g(n) = O(f(n));\ h(n) = O(f(n))$
- (D) $h(n) = O(f(n));\ g(n) = \Omega(f(n))$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compare the logarithms (base 2):

- $\log f(n) = n$,
- $\log g(n) = \log n! \approx n\log n - 1.44\,n$,
- $\log h(n) = (\log n)^2$.

So, in increasing order of growth: $h \ll f \ll g$.

- $(\log n)^2 \le n$ for large $n$, so $h(n) = O(f(n))$.
- $n \log n \gg n$, so $g(n) = \Omega(f(n))$ (indeed $n! > 2^n$ for $n \ge 4$).

This is (D).

- (A): $f = O(g)$ is true, but $g = O(h)$ is false.
- (B): $f = \Omega(g)$ is false.
- (C): $g = O(f)$ is false.

**Key idea:** compare growth rates by taking logarithms: $(\log n)^2 \ll n \ll n\log n$.

</details>
