# 2007 CS Q15: Number of comparisons in a doubling loop

## Question

Consider the following segment of C-code:

```c
int j, n;
j = 1;
while (j <= n)
    j = j*2;
```

The number of comparisons made in the execution of the loop for any $n > 0$ is:

- (A) $\lceil \log_2 n \rceil + 1$
- (B) $n$
- (C) $\lceil \log_2 n \rceil$
- (D) $\lfloor \log_2 n \rfloor + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**D** (ambiguous question; see the solution)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$j$ takes the values $1, 2, 4, \dots, 2^k$ and the body runs while $2^k \le n$, i.e. for $k = 0, 1, \dots, \lfloor \log_2 n \rfloor$.

- **Loop iterations** (tests that are true): $\lfloor \log_2 n \rfloor + 1$.
- **Every evaluation of `j <= n`**, including the final failing one: $\lfloor \log_2 n \rfloor + 2$.

| $n$ | 1 | 2 | 3 | 4 | 5 | 8 |
|---|---|---|---|---|---|---|
| true tests | 1 | 2 | 2 | 3 | 3 | 4 |
| all tests | 2 | 3 | 3 | 4 | 4 | 5 |

**No option equals $\lfloor\log_2 n\rfloor + 2$ exactly.** Option (A) equals it only when $n$ is *not* a power of 2 (then $\lceil\log_2 n\rceil = \lfloor\log_2 n\rfloor + 1$); at $n = 1, 2, 4, 8, \dots$ it is one too small.

The question says "for any $n > 0$". Reading it as "comparisons that let the loop body run", option (D) is exact for **every** $n$; under the "all evaluations" reading, no option is exact for every $n$. I therefore take (D) as the intended answer.

- (A) fails at every power of 2 under either reading.
- (B) is linear; the loop is logarithmic.
- (C) is too small by at least one for every $n$.

**Code check:** C program (`gcc -Wall -Wextra`), $n = 1..100000$: counting every evaluation gives $\lfloor\log_2 n\rfloor + 2$ for all $n$; option (A) mismatches at the 17 powers of 2 ($1$ to $65536$); option (D) equals the number of true tests for all $n$ and the all-evaluations count minus one.

**Judgement call:** this is the least clear question in the paper. Without an official key I cannot tell which reading the examiners used, so treat (D) as likely rather than certain. If the examiners counted the final failing test, the exact count matches none of the options.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** a loop whose control variable doubles runs $\lfloor\log_2 n\rfloor + 1$ times, and its condition is evaluated once more than that.
