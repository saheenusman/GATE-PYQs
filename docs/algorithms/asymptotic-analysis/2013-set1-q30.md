# 2013 CS Q30: Elements sortable in Θ(log n)

## Question

The number of elements that can be sorted in $\Theta(\log n)$ time using heap sort is

- (A) $\Theta(1)$
- (B) $\Theta\left(\sqrt{\log n}\right)$
- (C) $\Theta\left(\dfrac{\log n}{\log\log n}\right)$
- (D) $\Theta(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Heap sort of $k$ elements takes $\Theta(k \log k)$. We need the largest $k$ with $k\log k = \Theta(\log n)$.

Try $k = \dfrac{\log n}{\log\log n}$:

$$k\log k = \frac{\log n}{\log\log n}\left(\log\log n - \log\log\log n\right) = \Theta(\log n)$$

**Why the others fail:**

- (A), (B) are too small: for $k=\sqrt{\log n}$ the time $k\log k$ is $o(\log n)$.
- (D) $k=\log n$ gives $k\log k = \log n\log\log n$, which exceeds $\Theta(\log n)$ by a $\log\log n$ factor.

**Code check:** with $L=\log n$ from $2^{10}$ to $2^{80}$, the ratio $k\log k / L$ for $k = L/\log L$ rose towards 1 (0.67 to 0.92), while $k=L$ was off by a factor of $L$.

**Flag:** an analysis question about heap sort; filed under `asymptotic-analysis`.

**Key idea:** solve $k\log k = \log n$; the answer is $\Theta(\log n / \log\log n)$.

</details>
