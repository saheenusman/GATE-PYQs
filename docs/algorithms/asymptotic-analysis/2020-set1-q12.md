# 2020 CS Q12: Solving T(n) = T(n^(1/a)) + 1

## Question

For parameters $a$ and $b$, both of which are $\omega(1)$, $T(n) = T(n^{1/a}) + 1$, and $T(b) = 1$.

Then $T(n)$ is

- (A) $\Theta(\log_a \log_b n)$
- (B) $\Theta(\log_{ab} n)$
- (C) $\Theta(\log_b \log_a n)$
- (D) $\Theta(\log_2 \log_2 n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Unroll the recurrence.** Each step takes an $a$-th root and adds 1:

$$T(n) = T(n^{1/a}) + 1 = T(n^{1/a^2}) + 2 = \dots = T(n^{1/a^k}) + k.$$

**Stop at the base case.** The recursion ends when the argument reaches $b$:

$$n^{1/a^k} = b \iff \frac{\log n}{a^k} = \log b \iff a^k = \log_b n \iff k = \log_a \log_b n.$$

So $T(n) = \log_a \log_b n + O(1)$, which is $\Theta(\log_a \log_b n)$.

**Numeric check.** I ran the recurrence for several $(a, b)$ pairs with $n = 10^{60}$. In each case the step count was $\lceil \log_a \log_b n \rceil + 1$: for example $(a,b) = (2,2)$ gave 9 steps against $\log_2\log_2 n \approx 7.64$.

**Why the others fail:**

- **(B)** $\log_{ab} n$ is a single log. The depth of this recurrence is a *double* log.
- **(C)** swaps the bases. The root index $a$ controls how fast the exponent shrinks, so it is the outer log's base.
- **(D)** is correct only for $a = b = 2$. Here $a$ and $b$ are general.

**Key idea:** taking an $a$-th root repeatedly divides $\log n$ by $a$ each time, so the depth is a log of a log.

</details>
