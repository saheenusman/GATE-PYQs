# 2024 CS1 Q42: Recurrence T(n) = √n·T(√n) + n

## Question

Consider the following recurrence relation:

$$T(n) = \begin{cases} \sqrt{n}\,T(\sqrt{n}) + n & \text{for } n \ge 1, \\ 1 & \text{for } n = 1. \end{cases}$$

Which one of the following options is CORRECT?

- (A) $T(n) = \Theta(n \log\log n)$
- (B) $T(n) = \Theta(n \log n)$
- (C) $T(n) = \Theta(n^2 \log n)$
- (D) $T(n) = \Theta(n^2 \log\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Divide by $n$** to remove the $\sqrt{n}$ factor. Let $S(n) = T(n)/n$:

$$\frac{T(n)}{n} = \frac{T(\sqrt{n})}{\sqrt{n}} + 1 \;\Rightarrow\; S(n) = S(\sqrt{n}) + 1.$$

**Count the square-root steps.** The argument goes $n \to n^{1/2} \to n^{1/4} \to \dots$, and reaches a constant after $\log_2 \log_2 n$ steps. Each step adds 1:

$$S(n) = \Theta(\log\log n) \;\Rightarrow\; T(n) = \Theta(n \log\log n).$$

**Check.** Expanding once: $T(n) = n + \sqrt{n}\left(\sqrt{n} + n^{1/4}T(n^{1/4})\right) = 2n + n^{3/4}T(n^{1/4})$. Each level costs about $n$, and there are $\log\log n$ levels.

**Why the others fail:** $n\log n$ would need $\log n$ levels, but squaring-root halves the exponent, so there are only $\log\log n$.

**Key idea:** square-root recurrences have depth $\log\log n$. Substituting $S(n) = T(n)/n$ makes this visible.

</details>
