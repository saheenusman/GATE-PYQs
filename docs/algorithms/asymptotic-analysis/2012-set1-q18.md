# 2012 CS Q18: Average case versus worst case running time

## Question

Let $W(n)$ and $A(n)$ denote respectively, the worst case and average case running time of an algorithm executed on an input of size $n$. Which of the following is **ALWAYS TRUE**?

- (A) $A(n) = \Omega(W(n))$
- (B) $A(n) = \Theta(W(n))$
- (C) $A(n) = O(W(n))$
- (D) $A(n) = o(W(n))$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An average over inputs of size $n$ cannot exceed the maximum over those inputs, so $A(n) \le W(n)$. That means $A(n) = O(W(n))$: (C).

- (A), (B) need $A(n)$ to be at least a constant times $W(n)$. Quicksort has $A(n) = \Theta(n \log n)$ but $W(n) = \Theta(n^2)$, so both fail.
- (D) needs $A(n)$ to be strictly smaller in order. A linear scan that always reads the whole input has $A(n) = W(n)$, so it fails.

**Key idea:** average $\le$ worst always, which gives only the upper bound $O$.

</details>
