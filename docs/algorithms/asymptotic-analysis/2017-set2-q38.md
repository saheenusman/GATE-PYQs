# 2017 CS2 Q38: Time complexity of a loop whose inner step grows with the outer index

## Question

Consider the following C function.

```c
int fun(int n) {
    int i, j;
    for (i = 1; i <= n; i++) {
        for (j = 1; j < n; j += i) {
            printf(" %d %d", i, j);
        }
    }
}
```

Time complexity of `fun` in terms of $\Theta$ notation is

- (A) $\Theta(n\sqrt{n})$
- (B) $\Theta(n^2)$
- (C) $\Theta(n \log n)$
- (D) $\Theta(n^2 \log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Inner loop for a fixed $i$.** $j$ takes the values $1, 1+i, 1+2i, \ldots$ while $j < n$, so it runs about $\dfrac{n-1}{i} \approx \dfrac{n}{i}$ times.

**Total.**

$$\sum_{i=1}^{n} \frac{n}{i} = n \sum_{i=1}^{n} \frac1i = n H_n = \Theta(n \log n).$$

So the answer is **(C)**.

**Why the others fail.** (B) would need the inner loop to run $n$ times for each $i$ (step 1). (D) is even larger. (A) $n\sqrt n$ is bigger than $n\log n$: a harmonic sum, not a $\sqrt n$ sum.

**Code check:** a C program counted the exact iterations (replacing `printf` by a counter):

| $n$ | iterations | iterations / $(n\ln n)$ | iterations / $(n\sqrt n)$ |
|---|---|---|---|
| $10^3$ | 8045 | 1.165 | 0.254 |
| $10^4$ | 103631 | 1.125 | 0.104 |
| $10^5$ | 1266702 | 1.100 | 0.040 |
| $10^6$ | 14969921 | 1.084 | 0.015 |

The ratio to $n\ln n$ settles near a constant (it drifts down towards 1), while the ratio to $n\sqrt n$ goes to 0.

**Key idea:** a step of size $i$ in the inner loop turns the total into a harmonic sum, $n H_n = \Theta(n\log n)$.

</details>
