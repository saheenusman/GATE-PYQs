# 2015 CS3 Q20: Which bounds on the sum of cubes keep the equality correct

## Question

Consider the equality $\displaystyle\sum_{i=0}^{n} i^3 = X$ and the following choices for $X$

- I. $\Theta(n^4)$
- II. $\Theta(n^5)$
- III. $O(n^5)$
- IV. $\Omega(n^3)$

The equality above remains correct if $X$ is replaced by

- (A) Only I
- (B) Only II
- (C) I or III or IV but not II
- (D) II or III or IV but not I

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The sum has a closed form:

$$\sum_{i=0}^{n} i^3 = \frac{n^2(n+1)^2}{4} = \Theta(n^4)$$

- **I. True**, it is exactly $\Theta(n^4)$.
- **II. False.** The sum is much smaller than $n^5$, so it cannot be $\Theta(n^5)$.
- **III. True.** $O(n^5)$ is an upper bound, and $n^4 \le n^5$.
- **IV. True.** $\Omega(n^3)$ is a lower bound, and $n^4 \ge n^3$.

So "I or III or IV but not II": option (C).

**Code check:** $\text{sum}/n^4$ is $0.3025$, $0.2550$, $0.2505$ for $n = 10, 100, 1000$ (heading to $\tfrac14$). $\text{sum}/n^5$ falls to $0.00025$, so it is not $\Theta(n^5)$.

**Key idea:** $\Theta$ is a tight bound. $O$ and $\Omega$ only need to hold on one side, so loose bounds are still correct.

</details>
