# 2026 CS2 Q24: Order functions by growth rate

## Question

Consider the following functions, where $n$ is a positive integer:

$$n^{1/3},\quad \log(n),\quad \log(n!),\quad 2^{\log(n)}$$

Which option lists them in increasing order of asymptotic growth rate? (Base of $\log$ is 2.)

- (A) $\log(n),\ n^{1/3},\ 2^{\log(n)},\ \log(n!)$
- (B) $n^{1/3},\ \log(n),\ \log(n!),\ 2^{\log(n)}$
- (C) $\log(n),\ n^{1/3},\ \log(n!),\ 2^{\log(n)}$
- (D) $2^{\log(n)},\ n^{1/3},\ \log(n),\ \log(n!)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Simplify each function first.

| Function | Simplified | Growth |
|---|---|---|
| $\log n$ | $\log n$ | logarithmic |
| $n^{1/3}$ | $n^{1/3}$ | polynomial, power below 1 |
| $2^{\log_2 n}$ | $n$ | linear |
| $\log(n!)$ | $\Theta(n \log n)$ | linearithmic |

**Why $\log(n!) = \Theta(n \log n)$.** $\log(n!) = \log 1 + \log 2 + \dots + \log n$.

- Upper bound: every term is at most $\log n$, so the sum is at most $n \log n$.
- Lower bound: the top $n/2$ terms are each at least $\log(n/2)$, so the sum is at least $\frac{n}{2}\log\frac{n}{2}$.

**Ordering.**

- Any positive power of $n$ beats any power of $\log n$, so $\log n \ll n^{1/3}$.
- $n^{1/3} \ll n$ because the exponent is smaller.
- $n \ll n \log n$.

So the order is

$$\log n \ \prec\ n^{1/3} \ \prec\ 2^{\log n} \ \prec\ \log(n!).$$

**Numeric check.** At $n = 2^{20}$:

| Function | Value |
|---|---|
| $\log n$ | 20 |
| $n^{1/3}$ | about 102 |
| $2^{\log n}$ | 1,048,576 |
| $\log(n!)$ | about 19,458,756 |

Near $n \approx 1000$ the values of $n^{1/3}$ and $\log n$ are almost equal, but asymptotic order is about large $n$.

**Why the others fail:**

- **(B)** puts $n^{1/3}$ before $\log n$ and $\log(n!)$ before $n$. Both are wrong.
- **(C)** puts $\log(n!)$ before $2^{\log n}$. But $n \log n$ is bigger than $n$.
- **(D)** starts with $2^{\log n} = n$, which is larger than both $n^{1/3}$ and $\log n$.

**Key idea:** simplify $2^{\log n} = n$, remember $\log(n!) = \Theta(n \log n)$, then rank: $\log$ < power < $n$ < $n \log n$.

</details>
