# 2017 CS1 Q4: Ordering functions by asymptotic growth: 10, sqrt n, n, log n, 100/n

## Question

Consider the following functions from positive integers to real numbers:

$$10,\quad \sqrt{n},\quad n,\quad \log_2 n,\quad \frac{100}{n}.$$

The CORRECT arrangement of the above functions in increasing order of asymptotic complexity is:

- (A) $\log_2 n,\ \dfrac{100}{n},\ 10,\ \sqrt{n},\ n$
- (B) $\dfrac{100}{n},\ 10,\ \log_2 n,\ \sqrt{n},\ n$
- (C) $10,\ \dfrac{100}{n},\ \sqrt{n},\ \log_2 n,\ n$
- (D) $\dfrac{100}{n},\ \log_2 n,\ 10,\ \sqrt{n},\ n$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rank by growth.**

| Function | Behaviour as $n\to\infty$ |
|---|---|
| $100/n$ | tends to $0$ (decreasing) |
| $10$ | constant |
| $\log_2 n$ | grows without bound, but slower than any power of $n$ |
| $\sqrt{n}$ | $n^{1/2}$, a polynomial |
| $n$ | $n^{1}$ |

Order: $\dfrac{100}{n} \prec 10 \prec \log_2 n \prec \sqrt{n} \prec n$, which is **(B)**.

**Why the others fail.**

- (A) puts $\log_2 n$ first, but it is unbounded while $100/n \to 0$.
- (C) puts $\sqrt{n}$ before $\log_2 n$; a polynomial beats a logarithm.
- (D) puts $\log_2 n$ before the constant $10$; a function that grows without bound eventually exceeds any constant.

**Key idea:** $1/n \prec \text{constant} \prec \log n \prec n^{c} \prec n$ for $0 < c < 1$.

</details>
