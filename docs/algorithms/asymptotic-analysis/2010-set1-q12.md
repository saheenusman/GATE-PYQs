# 2010 CS Q12: Smallest database size exponent at which an n log n package beats a quadratic one

## Question

Two alternative packages A and B are available for processing a database having $10^k$ records. Package A requires $0.0001\,n^2$ time units and package B requires $10\,n \log_{10} n$ time units to process $n$ records. What is the smallest value of $k$ for which package B will be preferred over A?

- (A) $12$
- (B) $10$
- (C) $6$
- (D) $5$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Put $n = 10^k$, so $\log_{10} n = k$:

- A takes $0.0001 \cdot 10^{2k} = 10^{2k-4}$.
- B takes $10 \cdot 10^k \cdot k = k \cdot 10^{k+1}$.

B is preferred when $k \cdot 10^{k+1} < 10^{2k-4}$, i.e. $k < 10^{k-5}$.

| $k$ | $k$ | $10^{k-5}$ | B preferred? |
|---|---|---|---|
| 5 | 5 | 1 | no |
| 6 | 6 | 10 | **yes** |

For $k \le 5$ the right side is at most $1$ while $k \ge 1$, so B loses; $k = 6$ is the first win: (C).

- (D) $k = 5$: A takes $10^6$, B takes $5 \times 10^6$, so B is slower.
- (A) $12$ and (B) $10$ also favour B but are not the smallest.

**Code check:** scanning $k = 1, 2, \dots$ with exact comparison, the first $k$ where B is cheaper is $6$.

**Key idea:** the $n \log n$ package only wins once $n$ is large enough to overcome its constant factor of $10$ against $n^2/10^4$.

</details>
