# 2023 CS Q54: Counting x = x + 1 in two functions

## Question

Consider functions Function 1 and Function 2 expressed in pseudocode as follows:

```
Function 1              Function 2
while n > 1 do          for i = 1 to 100*n do
  for i = 1 to n do       x = x + 1;
    x = x + 1;          end for
  end for
  n = n/2;
end while
```

Let $f_1(n)$ and $f_2(n)$ denote the number of times the statement "$x = x + 1$" is executed in Function 1 and Function 2, respectively.

Which of the following statements is/are TRUE?

- (A) $f_1(n) \in \Theta(f_2(n))$
- (B) $f_1(n) \in o(f_2(n))$
- (C) $f_1(n) \in \omega(f_2(n))$
- (D) $f_1(n) \in O(n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count Function 2.** The loop runs $100n$ times, so $f_2(n) = 100n \in \Theta(n)$.

**Count Function 1.** The outer loop halves $n$ each round:

$$f_1(n) = n + \frac{n}{2} + \frac{n}{4} + \cdots \approx 2n \in \Theta(n)$$

A run for $n = 2^{10}, 2^{16}, 2^{20}$ gave $f_1 = 2n - 2$ every time, so $f_1 \approx 2n$.

**So both are linear:**
- A: $f_1 \in \Theta(f_2)$. **True.**
- B: $o(\cdot)$ needs $f_1/f_2 \to 0$, but the ratio is about $0.02$. **False.**
- C: $\omega(\cdot)$ needs the ratio to grow. **False.**
- D: $f_1 \in O(n)$. **True.**

**Key idea:** a geometric series of halvings sums to a constant times the first term.

</details>
