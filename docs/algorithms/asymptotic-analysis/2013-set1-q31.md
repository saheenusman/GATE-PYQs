# 2013 CS Q31: Return value of unknown(n)

## Question

Consider the following function:

```c
int unknown(int n) {
    int i, j, k = 0;
    for (i = n/2; i <= n; i++)
        for (j = 2; j <= n; j = j*2)
            k = k + n/2;
    return (k);
}
```

The return value of the function is

- (A) $\Theta(n^2)$
- (B) $\Theta(n^2 \log n)$
- (C) $\Theta(n^3)$
- (D) $\Theta(n^3 \log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count the iterations.**

- Outer loop: $i$ runs from $n/2$ to $n$, so about $n/2 + 1$ times.
- Inner loop: $j = 2, 4, 8, \dots \le n$, so $\lfloor \log_2 n \rfloor$ times.
- Each inner iteration adds $n/2$ to $k$.

$$k = \left(\tfrac n2 + 1\right)\cdot \lfloor\log_2 n\rfloor \cdot \tfrac n2 = \Theta(n^2 \log n)$$

**Why the others fail:**

- (A) forgets the inner $\log n$ factor.
- (C), (D) treat the inner loop as linear, or count the added value $n/2$ twice.

**Code check:** compiled with `gcc -Wall` and run for $n = 16 \dots 2048$. The ratio $k/(n^2\log_2 n)$ settled at $0.25$ (0.2502 at $n=2048$), as the formula predicts. No warnings.

**Key idea:** the return value is (outer count) $\times$ (inner count) $\times$ (increment), not just the iteration count.

</details>
