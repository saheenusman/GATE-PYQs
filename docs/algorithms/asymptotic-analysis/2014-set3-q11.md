# 2014 CS3 Q11: Minimum operations to evaluate X^5 + 4X^3 + 6X + 5 with one temporary

## Question

The minimum number of arithmetic operations required to evaluate the polynomial $P(X) = X^5 + 4X^3 + 6X + 5$ for a given value of $X$, using only one temporary variable is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**7** (official key; I found a 6-operation program, see below)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Disputed.** The key is **7**. I find a program with **6** operations, so the key's minimum looks one too high.

**A 7-operation scheme (the key's answer).** Using $T$ as the only temporary and keeping $X$:

| Step | Statement | $T$ afterwards |
|---|---|---|
| 1 | $T = X \cdot X$ | $X^2$ |
| 2 | $T = T + 4$ | $X^2 + 4$ |
| 3 | $T = T \cdot X$ | $X^3 + 4X$ |
| 4 | $T = T \cdot X$ | $X^4 + 4X^2$ |
| 5 | $T = T + 6$ | $X^4 + 4X^2 + 6$ |
| 6 | $T = T \cdot X$ | $X^5 + 4X^3 + 6X$ |
| 7 | $T = T + 5$ | $P(X)$ |

**A 6-operation scheme.** Complete the square: $X^4 + 4X^2 + 6 = (X^2+2)^2 + 2$, so

$$P(X) = X\big((X^2+2)^2 + 2\big) + 5.$$

| Step | Statement | $T$ afterwards |
|---|---|---|
| 1 | $T = X \cdot X$ | $X^2$ |
| 2 | $T = T + 2$ | $X^2 + 2$ |
| 3 | $T = T \cdot T$ | $X^4 + 4X^2 + 4$ |
| 4 | $T = T + 2$ | $X^4 + 4X^2 + 6$ |
| 5 | $T = T \cdot X$ | $X^5 + 4X^3 + 6X$ |
| 6 | $T = T + 5$ | $P(X)$ |

It uses one temporary, and $X$ stays available. Squaring $T$ is one multiplication.

**Code check:** I searched all programs of the form "start with $T = X$, then apply one operation at a time" for $T \leftarrow T \cdot X,\ T \cdot T,\ T \pm X,\ T \pm c,\ T \cdot c$ (with small integer constants $c$). No program of up to 5 operations reaches $P$, and the first one found has 6 operations, the scheme above. This searches only that family of operations, so it supports "6" but is not a general proof of the minimum.

I have not picked between the two answers. The key's 7 matches the Horner-style scheme; the 6-operation program is valid under the question's own wording.

**Classification flag:** this is an expression-evaluation cost question, with no exact topic. Filed under `asymptotic-analysis` as the nearest algorithms topic.

**Key idea:** the cost of evaluating a polynomial depends on how terms are shared; squaring a partial result can save a multiplication.
