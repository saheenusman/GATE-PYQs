# 2017 CS2 Q3: Matching algorithms with their time complexities

## Question

Match the algorithms with their time complexities:

| Algorithm | Time complexity |
|---|---|
| (P) Towers of Hanoi with $n$ disks | (i) $\Theta(n^2)$ |
| (Q) Binary search given $n$ sorted numbers | (ii) $\Theta(n \log n)$ |
| (R) Heap sort given $n$ numbers at the worst case | (iii) $\Theta(2^{n})$ |
| (S) Addition of two $n \times n$ matrices | (iv) $\Theta(\log n)$ |

- (A) P $\to$ (iii), Q $\to$ (iv), R $\to$ (i), S $\to$ (ii)
- (B) P $\to$ (iv), Q $\to$ (iii), R $\to$ (i), S $\to$ (ii)
- (C) P $\to$ (iii), Q $\to$ (iv), R $\to$ (ii), S $\to$ (i)
- (D) P $\to$ (iv), Q $\to$ (iii), R $\to$ (ii), S $\to$ (i)

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Match each one.**

- **(P) Towers of Hanoi $\to \Theta(2^n)$ (iii).** The move count satisfies $T(n) = 2T(n-1) + 1$, which solves to $2^n - 1$.
- **(Q) Binary search $\to \Theta(\log n)$ (iv).** Each probe halves the range.
- **(R) Heap sort, worst case $\to \Theta(n\log n)$ (ii).** Building the heap is $O(n)$ and $n$ extractions each cost $O(\log n)$.
- **(S) Adding two $n\times n$ matrices $\to \Theta(n^2)$ (i).** There are $n^2$ entries, each added once.

That is P$\to$iii, Q$\to$iv, R$\to$ii, S$\to$i: **(C)**.

**Why the others fail.** (A) calls heap sort quadratic and matrix addition $n\log n$. (B) and (D) swap Hanoi and binary search, giving binary search an exponential cost.

**Code check:** counting Hanoi moves for $n=1..10$ gave $1,3,7,15,31,63,127,255,511,1023 = 2^n - 1$.

**Key idea:** know the standard costs: Hanoi $2^n$, binary search $\log n$, heap sort $n\log n$, matrix addition $n^2$.

</details>
