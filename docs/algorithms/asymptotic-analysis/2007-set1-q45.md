# 2007 CS Q45: Time complexity of T(n) = T(sqrt n) + n

## Question

What is the *time complexity* of the following recursive function:

```c
int DoSomething (int n) {
    if (n <= 2)
        return 1;
    else
        return (DoSomething (floor(sqrt(n))) + n);
}
```

- (A) $\Theta(n^2)$
- (B) $\Theta(n\log_2 n)$
- (C) $\Theta(\log_2 n)$
- (D) $\Theta(\log_2\log_2 n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each call does constant work (a square root, a floor and one addition) plus one recursive call on $\lfloor\sqrt{n}\rfloor$. The `+ n` is added to the returned **value**; it is not extra work proportional to $n$.

So $T(n) = T(\sqrt{n}) + O(1)$. After $k$ calls the argument is about $n^{1/2^k}$; it drops to 2 when $2^k \approx \log_2 n$, i.e. $k = \log_2\log_2 n$. Therefore $T(n) = \Theta(\log\log n)$: (D).

- (A) and (B) treat the `+ n` as $n$ units of work per call.
- (C) $\log n$ would be the depth if the argument were halved ($n/2$), not square-rooted.

**Code check:** C program (`gcc -Wall -Wextra`) counting calls: $n = 4, 16, 256, 65536$ give $2, 3, 4, 5$ calls (one more each time $\log_2\log_2 n$ rises by 1).

**Wording caveat:** this treats `sqrt` and `floor` as constant-time operations, which is the usual convention in such questions.

**Key idea:** repeatedly taking square roots reaches a constant in $\log\log n$ steps.

</details>
