# 2007 CS Q51: Iterations of the primality-test loop

## Question

Consider the following C code segment:

```c
int IsPrime(n)
{
    int i, n;
    for (i = 2; i <= sqrt(n); i++)
        if (n % i == 0)
            { printf("Not Prime\n"); return 0; }
    return 1;
}
```

Let $T(n)$ denote the number of times the `for` loop is executed by the program on input $n$. Which of the following is **TRUE**?

- (A) $T(n) = O(\sqrt{n})$ and $T(n) = \Omega(\sqrt{n})$
- (B) $T(n) = O(\sqrt{n})$ and $T(n) = \Omega(1)$
- (C) $T(n) = O(n)$ and $T(n) = \Omega(\sqrt{n})$
- (D) None of the above

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The loop runs for $i = 2, 3, \dots, \lfloor\sqrt{n}\rfloor$ unless it exits early at a divisor.

- **Upper bound:** at most $\lfloor\sqrt{n}\rfloor - 1$ iterations, so $T(n) = O(\sqrt{n})$.
- **Lower bound:** for any even $n \ge 4$ the loop exits in the first iteration ($i = 2$ divides $n$), so $T(n) = 1$. Hence $T(n) = \Omega(1)$, and no bound larger than a constant holds for *all* $n$.
- For a prime $n$ the loop never exits early and runs $\lfloor\sqrt{n}\rfloor - 1$ times.

So (B) is true.

- (A) is false: $\Omega(\sqrt{n})$ fails for even $n$.
- (C) is false for the same reason (its $O(n)$ part is true but weak).
- (D) is false because (B) is true.

**Code check:** C program (`gcc -Wall -Wextra`) with `n` as the parameter: even $n$ ($4$, $100$, $10^6$) execute the body once; primes $n = 7, 101, 10007, 1000003$ execute it $1, 9, 99, 999$ times (about $\sqrt{n}-1$).

**Wording caveat:** as printed, the function body re-declares `n` (`int i, n;`), which would shadow the parameter and leave it uninitialised. This looks like a typo in the paper; I treated `n` as the function's argument. I also read "number of times the `for` loop is executed" as the number of iterations.

**Key idea:** a bound must hold for every input of size $n$: early exits give a constant lower bound, primes give the $\sqrt{n}$ upper bound.
