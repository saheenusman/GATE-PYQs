# 2021 CS2 Q49: Which statement about T(n) = aT(n/b) + f(n) is correct

## Question

For constants $a\ge1$ and $b>1$, consider the following recurrence defined on the non-negative integers:

$$T(n)=a\cdot T\!\left(\frac nb\right)+f(n)$$

Which one of the following options is correct about the recurrence $T(n)$?

- (A) If $f(n)$ is $n\log_2(n)$, then $T(n)$ is $\Theta(n\log_2(n))$.
- (B) If $f(n)$ is $\dfrac{n}{\log_2(n)}$, then $T(n)$ is $\Theta(\log_2(n))$.
- (C) If $f(n)$ is $O\!\left(n^{\log_b(a)-\epsilon}\right)$ for some $\epsilon>0$, then $T(n)$ is $\Theta\!\left(n^{\log_b(a)}\right)$.
- (D) If $f(n)$ is $\Theta\!\left(n^{\log_b(a)}\right)$, then $T(n)$ is $\Theta\!\left(n^{\log_b(a)}\right)$.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compare $f(n)$ with $n^{\log_b a}$ (master theorem).

**(C) is correct.** This is Case 1: $f(n)=O(n^{\log_b a-\epsilon})$ gives $T(n)=\Theta(n^{\log_b a})$.

- (D) is Case 2. When $f(n)=\Theta(n^{\log_b a})$, the result is $T(n)=\Theta(n^{\log_b a}\log n)$, with an extra $\log n$.
- (A) depends on $a$ and $b$. Take $a=b=2$: then $n^{\log_b a}=n$ and $f(n)=n\log n$, which gives $T(n)=\Theta(n\log^2 n)$. I computed $T$ numerically for $n=2^{10},\dots,2^{22}$: $T/(n\log n)$ keeps growing (5.6 to 11.6), while $T/(n\log^2 n)$ settles near 0.5.
- (B) $T(n)\ge f(n)=n/\log n$ always, and that is not $O(\log n)$. So $T(n)$ cannot be $\Theta(\log n)$.

**Key idea:** only Case 1 of the master theorem, $f$ polynomially smaller than $n^{\log_b a}$, gives $\Theta(n^{\log_b a})$.

</details>
