# 2009 CS Q35: Recurrence T(n) = T(n/3) + cn

## Question

The running time of an algorithm is represented by the following recurrence relation:

$$T(n) = \begin{cases} n & n \le 3 \\ T\!\left(\dfrac{n}{3}\right) + cn & \text{otherwise} \end{cases}$$

Which one of the following represents the time complexity of the algorithm?

- (A) $\Theta(n)$
- (B) $\Theta(n \log n)$
- (C) $\Theta(n^2)$
- (D) $\Theta(n^2 \log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Master theorem.** Here $a = 1$, $b = 3$, $f(n) = cn$, so $n^{\log_b a} = n^{0} = 1$.

$f(n) = cn$ grows polynomially faster than $1$, and the regularity condition holds: $a f(n/b) = c n/3 \le \tfrac13 f(n)$. This is Case 3, so

$$T(n) = \Theta(f(n)) = \Theta(n).$$

**By unrolling.** The work at each level shrinks by a factor of $3$:

$$T(n) = cn + \frac{cn}{3} + \frac{cn}{9} + \cdots \le cn \cdot \frac{1}{1 - 1/3} = 1.5\,cn = \Theta(n).$$

The first term dominates, so the total is a constant multiple of $n$: (A).

- (B) would need $\Theta(n)$ work at each of $\log n$ levels; here the work per level shrinks geometrically.
- (C) and (D) are far too large.

**Code check:** computing $T(3^k)$ with $c = 1$ gave $T(n)/n = 1.4938$ for $n = 3^5$ and $1.5000$ for $n = 3^{10}$ and $3^{15}$, so $T(n) \approx 1.5\,n$.

**Key idea:** a recurrence with a single recursive call on a fraction of the input and linear work per call is dominated by the top-level work: $\Theta(n)$.

</details>
