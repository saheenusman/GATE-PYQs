# 2017 CS2 Q30: Solving T(n) = 2T(sqrt n) + 1

## Question

Consider the recurrence function

$$T(n) = \begin{cases} 2T(\sqrt{n}) + 1, & n > 2 \\ 2, & 0 < n \le 2 \end{cases}$$

Then $T(n)$ in terms of $\Theta$ notation is

- (A) $\Theta(\log \log n)$
- (B) $\Theta(\log n)$
- (C) $\Theta(\sqrt{n})$
- (D) $\Theta(n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Substitute $n = 2^m$.** Then $\sqrt{n} = 2^{m/2}$. Let $S(m) = T(2^m)$:

$$S(m) = 2\,S(m/2) + 1.$$

**Master theorem** ($a = 2$, $b = 2$, $f(m) = 1 = O(m^{1-\varepsilon})$): $S(m) = \Theta(m)$.

Since $m = \log_2 n$:

$$T(n) = \Theta(\log n).$$

That is **(B)**.

**Exact check on $n = 2^{2^k}$.** $T(2)=2$, $T(4)=5$, $T(16)=11$, $T(256)=23$, $T(65536)=47$. In general $T(n) = 3\log_2 n - 1$ on these inputs.

**Why the others fail.**

- (A) $\log\log n$ is the answer for $T(n) = T(\sqrt n) + 1$, with one subproblem, not two.
- (C), (D) are far too large: the recursion tree has only $\log\log n$ levels, with $2^{\text{level}}$ nodes each, and the last level has about $\log n$ nodes.

**Code check:** a program evaluated the recurrence at $n = 2^{1}, 2^{2}, 2^{4}, 2^{8}, 2^{16}, 2^{32}$ and got $2, 5, 11, 23, 47, 95$, which equals $3\log_2 n - 1$ in each case.

**Key idea:** a square-root recurrence becomes a halving recurrence after substituting $n = 2^m$.

</details>
