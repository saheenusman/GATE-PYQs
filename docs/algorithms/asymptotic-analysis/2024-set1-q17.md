# 2024 CS1 Q17: Complexity of a single-pass sortedness check

## Question

Given an integer array of size $N$, we want to check if the array is sorted (in either ascending or descending order). An algorithm solves this problem by making a single pass through the array and comparing each element of the array only with its adjacent elements. The worst-case time complexity of this algorithm is

- (A) both $O(N)$ and $\Omega(N)$
- (B) $O(N)$ but not $\Omega(N)$
- (C) $\Omega(N)$ but not $O(N)$
- (D) neither $O(N)$ nor $\Omega(N)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Upper bound.** One pass with $N - 1$ adjacent comparisons gives $O(N)$.
- **Lower bound.** In the worst case (for example, the array is sorted), the algorithm must look at **every adjacent pair**, because skipping one pair could hide a violation. So the worst-case time is also $\Omega(N)$.

So the worst-case time is $\Theta(N)$, i.e. **both** $O(N)$ and $\Omega(N)$.

**Why the others fail:** it is not larger than linear, since there is only one pass, and it is not smaller than linear in the worst case, since every pair must be checked.

**Key idea:** $\Theta(N)$ means both $O(N)$ and $\Omega(N)$. Asymptotic bounds describe the same worst-case function.

</details>
