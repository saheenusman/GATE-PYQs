# 2026 CS2 Q25: Recurrences giving Theta(n)

## Question

Which of the following can be recurrence relation(s) corresponding to an algorithm with time complexity $\Theta(n)$?

- (A) $T(n) = T(n-1) + 1,\quad T(1) = 1$
- (B) $T(n) = 2T(n/2) + 1,\quad T(1) = 1$
- (C) $T(n) = 2T(n/2) + n,\quad T(1) = 1$
- (D) $T(n) = T(n-1) + n,\quad T(1) = 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Solve each one.

**(A) $T(n) = T(n-1) + 1$.** Unroll: $T(n) = 1 + 1 + \dots + 1$ ($n$ times) $= n$. So $\Theta(n)$. True.

**(B) $T(n) = 2T(n/2) + 1$.** Master theorem: $n^{\log_2 2} = n$, and $f(n) = 1$ is polynomially smaller. Case 1 gives $\Theta(n)$. True.

Tree view: level $i$ has $2^i$ nodes each doing 1 unit, so the total is $1 + 2 + 4 + \dots + n = 2n - 1$.

**(C) $T(n) = 2T(n/2) + n$.** Here $f(n) = n = \Theta(n^{\log_2 2})$, so case 2 gives $\Theta(n \log n)$. False. (This is merge sort.)

**(D) $T(n) = T(n-1) + n$.** Unroll: $T(n) = 1 + 2 + \dots + n = \frac{n(n+1)}{2} = \Theta(n^2)$. False.

**Numeric check.**

| $n$ | A / $n$ | B / $n$ | C / ($n\log n$) | D / $n^2$ |
|---|---|---|---|---|
| 64 | 1.00 | 1.98 | 1.17 | 0.51 |
| 1024 | 1.00 | 2.00 | 1.10 | 0.50 |

A and B stay proportional to $n$. C needs the $\log n$ factor. D is proportional to $n^2$.

**Key idea:** $n$ constant-cost leaves, or a chain of $n$ constant steps, gives $\Theta(n)$. Paying $n$ at every level (C) or $n$ at every step (D) costs more.

</details>
