# 2015 CS3 Q64: Asymptotic comparison of n with n to the power 1 + sin n

## Question

Let $f(n) = n$ and $g(n) = n^{(1 + \sin n)}$, where $n$ is a positive integer. Which of the following statements is/are correct?

- I. $f(n) = O(g(n))$
- II. $f(n) = \Omega(g(n))$

- (A) Only I
- (B) Only II
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The exponent $1 + \sin n$ swings between $0$ and $2$. So $g(n)$ swings between about $n^0 = 1$ and $n^2$. Because $n$ is an integer, $\sin n$ comes close to both $-1$ and $+1$ infinitely often.

**I. $f = O(g)$ fails.** It needs $n \le c\,g(n)$ for all large $n$. When $\sin n$ is near $-1$, $g(n)$ is tiny (near 1), far below $n$.

**II. $f = \Omega(g)$ fails.** It needs $n \ge c\,g(n)$ for all large $n$. When $\sin n$ is near $+1$, $g(n)$ is near $n^2$, far above $n$.

Neither holds: option (D).

**Code check:** for $n$ from $10^6$ to $10^6 + 10^4$, the ratio $g(n)/f(n)$ ranges from about $10^{-6}$ up to about $10^{6}$. So neither $f \le c\,g$ nor $f \ge c\,g$ holds with a fixed $c$.

**Key idea:** if two functions keep swapping which one is larger by unbounded factors, they are not comparable with $O$ or $\Omega$.

</details>
