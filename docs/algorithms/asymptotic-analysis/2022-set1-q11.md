# 2022 CS Q11: f(n²) versus f(n)²

## Question

Which one of the following statements is TRUE for all positive functions $f(n)$?

- (A) $f(n^2) = \Theta(f(n)^2)$, when $f(n)$ is a polynomial
- (B) $f(n^2) = o(f(n)^2)$
- (C) $f(n^2) = O(f(n)^2)$, when $f(n)$ is an exponential function
- (D) $f(n^2) = \Omega(f(n)^2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) True.** If $f$ is a polynomial of degree $k$, then $f(n) = \Theta(n^k)$. So $f(n^2) = \Theta(n^{2k})$ and $f(n)^2 = \Theta(n^{2k})$. The two are $\Theta$ of each other.

**Counterexamples for the rest:**
- (B) $f(n) = n$ gives $f(n^2) = n^2 = f(n)^2$, which is not $o(\cdot)$.
- (C) $f(n) = 2^n$ gives $f(n^2) = 2^{n^2}$ and $f(n)^2 = 2^{2n}$. The ratio $2^{n^2-2n}$ grows without bound, so it is not $O(\cdot)$.
- (D) $f(n) = 2^{-n}$ gives $f(n^2) = 2^{-n^2}$ and $f(n)^2 = 2^{-2n}$. The ratio $2^{2n-n^2} \to 0$, so it is not $\Omega(\cdot)$.

**Key idea:** substituting $n^2$ into a function and squaring it agree only for functions like polynomials, where the exponent just doubles.

</details>
