# 2014 CS3 Q38: Complexity of 2CNFSAT

## Question

Consider the decision problem *2CNFSAT* defined as follows:

$\lbrace \Phi \mid \Phi$ is a satisfiable propositional formula in CNF with at most two literals per clause $\rbrace$

For example, $\Phi = (x_1 \vee x_2) \wedge (x_1 \vee \overline{x_3}) \wedge (x_2 \vee x_4)$ is a Boolean formula and it is in *2CNFSAT*.

The decision problem *2CNFSAT* is

- (A) NP-Complete.
- (B) solvable in polynomial time by reduction to directed graph reachability.
- (C) solvable in constant time since any input instance is satisfiable.
- (D) NP-hard, but not NP-complete.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**2-SAT is in P.** Build the **implication graph**: for each clause $(l_1 \vee l_2)$ add the edges $\bar{l_1} \to l_2$ and $\bar{l_2} \to l_1$. The formula is **unsatisfiable iff some variable $x$ and its negation $\bar{x}$ lie in the same strongly connected component** (each reaches the other). That test is a reachability / SCC computation, which takes polynomial (even linear) time.

- (A) 2-SAT is not NP-complete unless $P = NP$ (it is in P). The NP-complete case is 3-SAT.
- (C) false: not every instance is satisfiable. $(x) \wedge (\bar{x})$, written as $(x \vee x) \wedge (\bar{x} \vee \bar{x})$, is unsatisfiable.
- (D) 2-SAT is not NP-hard unless $P = NP$.

**Key idea:** 2-SAT reduces to reachability in the implication graph, so it is in P (in fact in NL).

</details>
