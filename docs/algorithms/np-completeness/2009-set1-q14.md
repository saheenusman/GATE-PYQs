# 2009 CS Q14: Consequences of a problem being in NP

## Question

Let $\pi_A$ be a problem that belongs to the class NP. Then which one of the following is TRUE?

- (A) There is no polynomial time algorithm for $\pi_A$.
- (B) If $\pi_A$ can be solved deterministically in polynomial time, then P = NP.
- (C) If $\pi_A$ is NP-hard, then it is NP-complete.
- (D) $\pi_A$ may be undecidable.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A problem is **NP-complete** when it is in NP **and** NP-hard. We are told $\pi_A \in \text{NP}$, so adding NP-hardness gives NP-completeness by definition: (C).

- (A) is false: P is inside NP, so many NP problems (sorting-style yes/no questions, for example) have polynomial algorithms.
- (B) is false: a polynomial algorithm for **one** problem in NP only gives P = NP if that problem is NP-complete. $\pi_A$ may already be in P.
- (D) is false: every problem in NP is decidable. Try all certificates of polynomial length and verify each.

**Code check:** none (definition-based, no program to run).

**Key idea:** NP-complete means in NP and NP-hard; a problem already in NP becomes NP-complete as soon as it is NP-hard.

</details>
