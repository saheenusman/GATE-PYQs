# 2012 CS Q4: Consequence of P not equal to NP

## Question

Assuming $P \neq NP$, which of the following is **TRUE**?

- (A) NP-complete $=$ NP
- (B) NP-complete $\cap$ P $= \emptyset$
- (C) NP-hard $=$ NP
- (D) P $=$ NP-complete

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

If some NP-complete problem were in P, every NP problem would reduce to it and so be in P, giving $P = NP$. Under $P \neq NP$ no NP-complete problem is in P, so NP-complete $\cap$ P $= \emptyset$. That is (B).

- (A) false. P is inside NP, and P is non-empty, but none of it is NP-complete.
- (C) false. NP-hard contains problems outside NP, such as the halting problem.
- (D) false. Under $P \neq NP$ the two sets are disjoint.

**Key idea:** NP-complete problems are exactly the ones whose membership in P would collapse $P$ and $NP$.

</details>
