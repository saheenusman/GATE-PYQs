# 2013 CS Q18: P, NP and NP-Complete statements

## Question

Which of the following statements are TRUE?

1. The problem of determining whether there exists a cycle in an undirected graph is in P.
2. The problem of determining whether there exists a cycle in an undirected graph is in NP.
3. If a problem A is NP-Complete, there exists a non-deterministic polynomial time algorithm to solve A.

- (A) 1, 2 and 3
- (B) 1 and 2 only
- (C) 2 and 3 only
- (D) 1 and 3 only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

1. **True.** A DFS finds a cycle in $O(V+E)$ time, so the problem is in P.
2. **True.** $P \subseteq NP$, so anything in P is in NP.
3. **True.** NP-complete means in NP and NP-hard. Being in NP means exactly that a non-deterministic polynomial-time algorithm exists.

All three hold, so (A).

**Why the others fail:** each of (B), (C), (D) rejects one true statement.

**Key idea:** NP-complete problems are in NP by definition, and $P \subseteq NP$.

</details>
