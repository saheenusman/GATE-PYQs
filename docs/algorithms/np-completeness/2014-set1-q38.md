# 2014 CS1 Q38: Venn diagram of P, NP and NPC if clique is solved in polynomial time

## Question

Suppose a polynomial time algorithm is discovered that correctly computes the largest clique in a given graph. In this scenario, which one of the following represents the correct Venn diagram of the complexity classes P, NP and NP Complete (NPC)?

![Four Venn diagrams labelled A to D. (A) One large oval labelled P, with NP written at its upper-right edge and a small NPC circle inside it near the bottom. (B) Two overlapping circles labelled P and NP, with NPC marked by an arrow pointing into the overlap. (C) A large oval labelled P=NP containing a smaller NPC circle. (D) A single oval labelled P=NP=NPC.](../../assets/2014/set1-q38.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Finding the largest clique is NP-hard, and its decision version (CLIQUE) is NP-complete. A polynomial-time algorithm for it solves an NP-complete problem in polynomial time, so

$$P = NP$$

Every problem in NP then reduces to a problem in P, so every (non-trivial) problem in NP is NP-complete. The three classes coincide: **P = NP = NPC**, shown by (D).

- (A) and (B) draw P and NP as different classes, which holds only if $P \ne NP$.
- (C) merges P and NP but draws NPC as a smaller region. That is wrong because every non-trivial language in $P = NP$ is NP-complete.

**Reading note:** strictly, the two trivial languages $\emptyset$ and $\Sigma^*$ are in P but are not NP-complete under many-one reductions. The key ignores this and treats the three as equal; (D) is the intended answer.

**Key idea:** one NP-complete problem in P forces P = NP, and then NPC collapses onto P and NP.

</details>
