# 2015 CS2 Q26: Consequences of polynomial-time reductions around 3-SAT

## Question

Consider two decision problems $Q_1, Q_2$ such that $Q_1$ reduces in polynomial time to 3-SAT and 3-SAT reduces in polynomial time to $Q_2$. Then which one of the following is consistent with the above statement?

- (A) $Q_1$ is in NP, $Q_2$ is NP hard.
- (B) $Q_2$ is in NP, $Q_1$ is NP hard.
- (C) Both $Q_1$ and $Q_2$ are in NP.
- (D) Both $Q_1$ and $Q_2$ are NP hard.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

We are given $Q_1 \le_p \text{3-SAT} \le_p Q_2$.

- $Q_1 \le_p \text{3-SAT}$ and 3-SAT $\in$ NP, so $Q_1 \in$ NP. This is **forced**.
- 3-SAT is NP-hard and 3-SAT $\le_p Q_2$, so $Q_2$ is NP-hard. This is **forced**.

So (A) always holds.

The other options assert more than the chain gives. $Q_2 \in$ NP, $Q_1$ NP-hard, and so on, are true only in the special case where the problem happens to be NP-complete; they do not follow from the reductions.

**Note on the wording.** Read literally, "consistent with" is weaker than "implied": if both problems are NP-complete, every option is true. The key (A) is the one option that must hold in every case, and that is the reading I used. Status is `verified` for that reading.

**Key idea:** reducing *to* an NP problem puts you in NP; reducing *from* an NP-hard problem makes you NP-hard.

</details>
