# 2007 CS Q76: Huffman code for six letters

## Question

**Statement for Linked Answer Questions 76 & 77.** Suppose the letters $a, b, c, d, e, f$ have probabilities $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{16}, \frac{1}{32}, \frac{1}{32}$, respectively.

**Q.76** Which of the following is the Huffman code for the letters $a, b, c, d, e, f$?

- (A) 0, 10, 110, 1110, 11110, 11111
- (B) 11, 10, 011, 010, 001, 000
- (C) 11, 10, 01, 001, 0001, 0000
- (D) 110, 100, 010, 000, 001, 111

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Repeatedly merge the two least probable letters:

| Step | Merge | New weight |
|---|---|---|
| 1 | $e, f$ ($\frac1{32} + \frac1{32}$) | $\frac1{16}$ |
| 2 | $d$, $ef$ ($\frac1{16} + \frac1{16}$) | $\frac18$ |
| 3 | $c$, $def$ | $\frac14$ |
| 4 | $b$, $cdef$ | $\frac12$ |
| 5 | $a$, $bcdef$ | $1$ |

The resulting tree is a chain, so the code lengths are $a:1,\ b:2,\ c:3,\ d:4,\ e:5,\ f:5$, and (up to swapping 0 and 1 at each branch) the code is $0, 10, 110, 1110, 11110, 11111$: (A).

All four options are prefix-free, but only (A) is optimal:

| Option | Kraft sum | Average length |
|---|---|---|
| (A) | 1 | $1.9375$ |
| (B) | 1 | $2.25$ |
| (C) | 1 | $2.1875$ |
| (D) | $0.75$ | $3$ |

- (B), (C) and (D) are valid prefix codes but have a larger average length than the Huffman code, so none can be a Huffman code.

**Code check:** Python (exact fractions): Huffman code lengths $[1,2,3,4,5,5]$, average $31/16 = 1.9375$. Each printed option checked for the prefix property, Kraft sum and average length (table above); only (A) reaches the optimum.

**Key idea:** Huffman code lengths for dyadic probabilities $2^{-k}$ equal $k$; any prefix code with a larger average length is not Huffman.
