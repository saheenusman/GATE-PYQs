# 2017 CS1 Q5: Matching Kruskal, Quicksort and Floyd-Warshall to design paradigms

## Question

Consider the following table:

| Algorithms | Design Paradigms |
|---|---|
| (P) Kruskal | (i) Divide and Conquer |
| (Q) Quicksort | (ii) Greedy |
| (R) Floyd-Warshall | (iii) Dynamic Programming |

Match the algorithms to the design paradigms they are based on.

- (A) (P) $\leftrightarrow$ (ii), (Q) $\leftrightarrow$ (iii), (R) $\leftrightarrow$ (i)
- (B) (P) $\leftrightarrow$ (iii), (Q) $\leftrightarrow$ (i), (R) $\leftrightarrow$ (ii)
- (C) (P) $\leftrightarrow$ (ii), (Q) $\leftrightarrow$ (i), (R) $\leftrightarrow$ (iii)
- (D) (P) $\leftrightarrow$ (i), (Q) $\leftrightarrow$ (ii), (R) $\leftrightarrow$ (iii)

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Match one by one.**

- **Kruskal $\to$ Greedy (ii).** It repeatedly adds the cheapest edge that does not form a cycle, and never undoes a choice.
- **Quicksort $\to$ Divide and Conquer (i).** It partitions around a pivot, then sorts each side recursively.
- **Floyd-Warshall $\to$ Dynamic Programming (iii).** It builds shortest paths using intermediate vertices $\lbrace 1..k\rbrace$ from the table for $k-1$.

This is **(C)**.

**Why the others fail.** (A) calls Quicksort dynamic programming and Floyd-Warshall divide and conquer. (B) calls Kruskal dynamic programming. (D) calls Kruskal divide and conquer and Quicksort greedy.

**Key idea:** greedy commits to a locally best choice; divide and conquer splits into independent subproblems; dynamic programming reuses overlapping subproblem results.

</details>
