# 2015 CS2 Q47: Matching algorithms with their design paradigms or search strategies

## Question

Given below are some algorithms, and some algorithm design paradigms.

| Algorithm | | Paradigm |
|---|---|---|
| 1. Dijkstra's Shortest Path | i. | Divide and Conquer |
| 2. Floyd-Warshall algorithm to compute all pairs shortest path | ii. | Dynamic Programming |
| 3. Binary search on a sorted array | iii. | Greedy design |
| 4. Backtracking search on a graph | iv. | Depth-first search |
| | v. | Breadth-first search |

Match the above algorithms on the left to the corresponding design paradigm they follow.

- (A) 1-i, 2-iii, 3-i, 4-v.
- (B) 1-iii, 2-iii, 3-i, 4-v.
- (C) 1-iii, 2-ii, 3-i, 4-iv.
- (D) 1-iii, 2-ii, 3-i, 4-v.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **1, Dijkstra:** repeatedly picks the closest unsettled vertex. Greedy (iii).
- **2, Floyd-Warshall:** DP over intermediate vertices. Dynamic programming (ii).
- **3, Binary search:** halves the range each step. Divide and conquer (i).
- **4, Backtracking search on a graph:** explores a path as deep as possible and then undoes it. This is depth-first search (iv), not breadth-first.

1-iii, 2-ii, 3-i, 4-iv: option (C). (A) calls Dijkstra divide and conquer. (B) calls Floyd-Warshall greedy. (D) matches backtracking with BFS.

**Key idea:** Dijkstra is greedy, Floyd-Warshall is DP, binary search is divide and conquer, and backtracking is depth-first.

</details>
