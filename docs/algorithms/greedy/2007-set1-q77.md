# 2007 CS Q77: Average length of the Huffman code

## Question

(Linked with Q.76: letters $a, b, c, d, e, f$ with probabilities $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{16}, \frac{1}{32}, \frac{1}{32}$.)

**Q.77** What is the average length of the correct answer to Q.76?

- (A) 3
- (B) 2.1875
- (C) 2.25
- (D) 1.9375

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Using the code $0, 10, 110, 1110, 11110, 11111$ (lengths $1,2,3,4,5,5$):
$$\frac12(1) + \frac14(2) + \frac18(3) + \frac1{16}(4) + \frac1{32}(5) + \frac1{32}(5) = 0.5 + 0.5 + 0.375 + 0.25 + 0.15625 + 0.15625 = 1.9375.$$

(D).

- (A) 3 is the average of the fixed-length code in option (D) of Q.76.
- (B) 2.1875 is the average length of option (C) of Q.76.
- (C) 2.25 is the average length of option (B) of Q.76.

**Code check:** Python: exact average $31/16 = 1.9375$; averages of the other three printed codes are $2.25$, $2.1875$ and $3$.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** average code length $=\sum p_i \ell_i$; for dyadic probabilities it equals the entropy, $1.9375$ bits here.

</details>
