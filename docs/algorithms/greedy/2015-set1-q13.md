# 2015 CS1 Q13: Matching algorithms with their design paradigms

## Question

Match the following:

| | Algorithm | | Paradigm |
|---|---|---|---|
| (P) | Prim's algorithm for minimum spanning tree | (i) | Backtracking |
| (Q) | Floyd-Warshall algorithm for all pairs shortest paths | (ii) | Greedy method |
| (R) | Mergesort | (iii) | Dynamic programming |
| (S) | Hamiltonian circuit | (iv) | Divide and conquer |

- (A) P-iii, Q-ii, R-iv, S-i
- (B) P-i, Q-ii, R-iv, S-iii
- (C) P-ii, Q-iii, R-iv, S-i
- (D) P-ii, Q-i, R-iii, S-iv

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **P, Prim:** repeatedly adds the cheapest edge leaving the tree. Greedy (ii).
- **Q, Floyd-Warshall:** $d^{(k)}_{ij}$ is built from smaller subproblems that overlap. Dynamic programming (iii).
- **R, Mergesort:** splits in half, sorts each, merges. Divide and conquer (iv).
- **S, Hamiltonian circuit:** tries extending a partial path and undoes dead ends. Backtracking (i).

That gives P-ii, Q-iii, R-iv, S-i: option (C). (A) calls Prim dynamic programming. (B) calls Prim backtracking. (D) calls Mergesort dynamic programming.

**Key idea:** Prim is greedy, Floyd-Warshall is DP, Mergesort is divide and conquer, Hamiltonian search is backtracking.

</details>
