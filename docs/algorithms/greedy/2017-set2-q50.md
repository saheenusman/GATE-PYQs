# 2017 CS2 Q50: Expected length of a 100-character message under Huffman coding

## Question

A message is made up entirely of characters from the set $X = \lbrace P, Q, R, S, T\rbrace$. The table of probabilities for each of the characters is shown below:

| Character | Probability |
|---|---|
| $P$ | 0.22 |
| $Q$ | 0.34 |
| $R$ | 0.17 |
| $S$ | 0.19 |
| $T$ | 0.08 |
| Total | 1.00 |

If a message of 100 characters over $X$ is encoded using Huffman coding, then the expected length of the encoded message in bits is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**225**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Build the Huffman tree** by repeatedly merging the two smallest probabilities:

| Step | Merge | New weight |
|---|---|---|
| 1 | $T\,(0.08) + R\,(0.17)$ | 0.25 |
| 2 | $S\,(0.19) + P\,(0.22)$ | 0.41 |
| 3 | $0.25 + Q\,(0.34)$ | 0.59 |
| 4 | $0.41 + 0.59$ | 1.00 |

**Code lengths** (depth in the tree): the root joins the 0.41 node ($S$, $P$ below it) and the 0.59 node ($Q$ and the 0.25 node below it). So $Q = 2$, $P = 2$, $S = 2$, and $R = 3$, $T = 3$ (they sit under the 0.25 node).

**Expected bits per character:**

$$0.34\cdot2 + 0.22\cdot2 + 0.19\cdot2 + 0.17\cdot3 + 0.08\cdot3 = 0.68 + 0.44 + 0.38 + 0.51 + 0.24 = 2.25.$$

**For 100 characters:** $100 \times 2.25 = 225$ bits.

**Code check:** a heap-based Huffman program printed the same four merges, code lengths $Q{:}2,\ P{:}2,\ S{:}2,\ R{:}3,\ T{:}3$ and 225.0 bits. (Ties do not occur here, so the lengths are unique.)

**Key idea:** Huffman repeatedly merges the two lightest nodes; expected length $=\sum p_i \ell_i$.

</details>
