# 2020 CS Q33: Probe 1 address under double hashing for k = 90

## Question

Consider a double hashing scheme in which the primary hash function is $h_1(k) = k \bmod 23$, and the secondary hash function is $h_2(k) = 1 + (k \bmod 19)$. Assume that the table size is 23. Then the address returned by probe 1 in the probe sequence (assume that the probe sequence begins at probe 0) for key value $k = 90$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**13**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Probe sequence.** In double hashing, probe $i$ looks at

$$(h_1(k) + i \cdot h_2(k)) \bmod 23.$$

**Compute for $k = 90$:**

- $h_1(90) = 90 \bmod 23 = 90 - 69 = 21$
- $h_2(90) = 1 + (90 \bmod 19) = 1 + (90 - 76) = 1 + 14 = 15$

| Probe | Address |
|---|---|
| 0 | $21$ |
| 1 | $(21 + 15) \bmod 23 = 36 \bmod 23 = 13$ |

Probe 1 returns **13**. I confirmed these values in code.

**Key idea:** counting starts at probe 0, which is just $h_1(k)$. Probe 1 adds one step of size $h_2(k)$.

</details>
