# 2015 CS3 Q22: Load factor of a hash table with 25 slots and 2000 elements

## Question

Given a hash table $T$ with 25 slots that stores 2000 elements, the load factor $\alpha$ for $T$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**80**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$$\alpha = \frac{n}{m} = \frac{\text{elements}}{\text{slots}} = \frac{2000}{25} = 80$$

**Answer: 80.**

A load factor above 1 is only possible with chaining, where each slot holds a list (here about 80 elements per slot on average).

**Key idea:** load factor $\alpha = n/m$.

</details>
