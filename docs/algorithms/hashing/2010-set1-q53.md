# 2010 CS Q53: Number of insertion orders giving the same hash table

## Question

**Linked Answer Questions 52 and 53** (same hash table as Question 52).

How many different insertion sequences of the key values using the same hash function and linear probing will result in the hash table shown above?

- (A) $10$
- (B) $20$
- (C) $30$
- (D) $40$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

From Question 52, the order must satisfy:

- $52$ after each of $42, 23, 34$;
- $33$ after each of $23, 34, 52, 46$.

Nothing else is constrained ($46$ sits in its home slot $6$, and $42, 23, 34$ sit in their home slots).

Since $33$ must come after $52$, and $52$ after $42, 23, 34$, and $33$ after $46$ too, **$33$ is always last**. Of the other five keys:

- order $42, 23, 34, 52$ with $52$ last of these: $3! = 6$ ways;
- place $46$ anywhere among them: $5$ positions.

Total $6 \times 5 = 30$: (C).

**Code check:** all $6! = 720$ insertion orders were simulated; exactly $30$ produced the table.

**Key idea:** count the linear extensions of the "must come before" constraints.

</details>
