# 2026 CS2 Q30: Longest chain in a chained hash table

## Question

The keys 5, 28, 19, 15, 26, 33, 12, 17, 10 are inserted into a hash table using $h(k) = k \bmod 9$. Collisions are resolved by chaining. After all keys are inserted, the length of the longest chain is _____. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** In chaining, each slot holds a list. All keys with the same hash value go into that slot's list.

**Step 1: compute $k \bmod 9$.**

| Key | $k \bmod 9$ |
|---|---|
| 5 | 5 |
| 28 | 1 |
| 19 | 1 |
| 15 | 6 |
| 26 | 8 |
| 33 | 6 |
| 12 | 3 |
| 17 | 8 |
| 10 | 1 |

**Step 2: group by slot.**

| Slot | Chain | Length |
|---|---|---|
| 1 | 28, 19, 10 | **3** |
| 3 | 12 | 1 |
| 5 | 5 | 1 |
| 6 | 15, 33 | 2 |
| 8 | 26, 17 | 2 |

Slots 0, 2, 4, 7 are empty. The lengths add up to $3+1+1+2+2 = 9$ keys, as expected.

The longest chain is slot 1, with 3 keys.

**Verified** by running the grouping in Python.

**Key idea:** the order of insertion does not change chain lengths in chaining. Count how many keys share each remainder.

</details>
