# 2022 CS Q16: Expected keys per slot with two hash functions

## Question

Suppose we are given $n$ keys, $m$ hash table slots, and two simple uniform hash functions $h_1$ and $h_2$. Further suppose our hashing scheme uses $h_1$ for the odd keys and $h_2$ for the even keys. What is the expected number of keys in a slot?

- (A) $m/n$
- (B) $n/m$
- (C) $2n/m$
- (D) $n/(2m)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B ($n/m$)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Each key lands in a uniformly random slot,** whichever of $h_1$ or $h_2$ is used. Let $n_o$ be the number of odd keys and $n_e$ the number of even keys, with $n_o + n_e = n$.

For a fixed slot, the expected count is

$$\frac{n_o}{m} + \frac{n_e}{m} = \frac{n}{m}$$

**Why the others fail:** (A) inverts the load factor. (C) and (D) multiply or divide by 2, as if the two functions filled two separate tables of $m$ slots each. Both share the same $m$ slots.

**Key idea:** the load factor $\alpha = n/m$ depends only on how many keys share the slots, not on how many hash functions assign them.

</details>
