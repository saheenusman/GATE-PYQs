# 2014 CS3 Q40: Probability that the first 3 slots stay empty after 3 insertions

## Question

Consider a hash table with 100 slots. Collisions are resolved using chaining. Assuming simple uniform hashing, what is the probability that the first 3 slots are unfilled after the first 3 insertions?

- (A) $(97 \times 97 \times 97)/100^3$
- (B) $(99 \times 98 \times 97)/100^3$
- (C) $(97 \times 96 \times 95)/100^3$
- (D) $(97 \times 96 \times 95)/(3! \times 100^3)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Under simple uniform hashing, each key goes to any of the 100 slots with probability $1/100$, **independently** of the other keys.

For one insertion to avoid the first 3 slots, it must land in one of the other 97 slots: probability $97/100$. The three insertions are independent, so

$$P = \left(\frac{97}{100}\right)^3 = \frac{97 \times 97 \times 97}{100^3} \approx 0.9127.$$

- (B), (C) and (D) multiply decreasing factors (99, 98, 97 or 97, 96, 95), as if each key needed a *different* slot. With chaining, several keys may share a slot, so the number of choices does not shrink.

**Code check:** $(97/100)^3 = 0.912673$, the same as $97^3/100^3$.

**Key idea:** with chaining, insertions are independent: each one must avoid the 3 slots.

</details>
