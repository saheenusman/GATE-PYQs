# 2010 CS Q52: Possible insertion order for a linear-probing hash table

## Question

**Linked Answer Questions 52 and 53.**

A hash table of length $10$ uses open addressing with hash function $h(k) = k \bmod 10$, and linear probing. After inserting $6$ values into an empty hash table, the table is as shown below.

| Slot | Key |
|---|---|
| 0 | |
| 1 | |
| 2 | 42 |
| 3 | 23 |
| 4 | 34 |
| 5 | 52 |
| 6 | 46 |
| 7 | 33 |
| 8 | |
| 9 | |

Which one of the following choices gives a possible order in which the key values could have been inserted in the table?

- (A) 46, 42, 34, 52, 23, 33
- (B) 34, 42, 23, 52, 33, 46
- (C) 46, 34, 42, 23, 52, 33
- (D) 42, 46, 33, 23, 34, 52

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Home slots: $42 \to 2$, $23 \to 3$, $34 \to 4$, $52 \to 2$, $46 \to 6$, $33 \to 3$. Two keys are **displaced**:

- $52$ (home $2$) sits in slot $5$, so slots $2, 3, 4$ were already full: **$42, 23, 34$ come before $52$**.
- $33$ (home $3$) sits in slot $7$, so slots $3, 4, 5, 6$ were already full: **$23, 34, 52, 46$ come before $33$**.

Test each option by simulating the insertions:

- (A) $52$ comes before $23$: it would probe $2$ (full), then $3$ (free) and land there. Wrong.
- (B) $33$ comes before $46$: slot $6$ is free, so $33$ would land in $6$. Wrong.
- (C) $46, 34, 42, 23, 52, 33$: $52$ probes $2, 3, 4$ and lands in $5$; $33$ probes $3, 4, 5, 6$ and lands in $7$. **Matches.**
- (D) $33$ comes before $23$: it would take slot $3$. Wrong.

So (C).

**Code check:** each option was inserted into an empty table; only (C) reproduces the table above.

**Key idea:** a key stored away from its home slot tells you which slots were already occupied when it was inserted.

</details>
