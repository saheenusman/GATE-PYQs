# 2020 CS Q41: Is the old MST still an MST after adding one edge

## Question

Let $G = (V, E)$ be a weighted undirected graph and let $T$ be a Minimum Spanning Tree (MST) of $G$ maintained using adjacency lists. Suppose a new weighted edge $(u, v) \in V \times V$ is added to $G$. The worst case time complexity of determining if $T$ is still an MST of the resultant graph is

- (A) $\Theta(|E| + |V|)$
- (B) $\Theta(|E|\,|V|)$
- (C) $\Theta(|E| \log |V|)$
- (D) $\Theta(|V|)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The cycle property.** Adding $(u,v)$ with weight $w$ to the tree $T$ creates exactly one cycle: the tree path from $u$ to $v$ plus the new edge. $T$ is still an MST iff the new edge is **not lighter** than the heaviest edge on that tree path. Otherwise, swapping the new edge for that heaviest edge gives a lighter spanning tree.

**Algorithm.**

1. Search $T$ (a tree stored with adjacency lists) from $u$ until $v$ is found, remembering the path. A tree has $|V|-1$ edges, so a DFS or BFS costs $O(|V|)$.
2. Take the maximum edge weight on that path: $O(|V|)$.
3. Compare it with $w$: $O(1)$.

Total: $O(|V|)$. Only the tree is searched, never the rest of $G$.

**It cannot be faster.** If $T$ is a path, the $u$-$v$ path can have $|V|-1$ edges, and all of them must be examined to know the maximum. So $\Omega(|V|)$ in the worst case, and the bound is $\Theta(|V|)$.

**Why the others fail:**

- **(A)** would be the cost of searching all of $G$. The tree has only $|V|-1$ edges, so $|E|$ never enters.
- **(B) and (C)** are larger than a single tree traversal needs.

**Key idea:** to test one added edge against an MST, check only the tree path between its endpoints. The edge replaces the heaviest edge on that path if it is lighter.

</details>
