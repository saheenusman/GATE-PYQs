# 2024 CS1 Q60: Components from the number of DFS forest edges

## Question

The number of edges present in the forest generated by the DFS traversal of an undirected graph $G$ with 100 vertices is 40. The number of connected components in $G$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**60**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A DFS forest has one tree per connected component. A forest with $n$ vertices and $c$ trees has $n - c$ edges.

$$100 - c = 40 \Rightarrow c = 60.$$

**Key idea:** edges in a spanning forest $= n - c$, so $c = n - (\text{edges})$.

</details>
