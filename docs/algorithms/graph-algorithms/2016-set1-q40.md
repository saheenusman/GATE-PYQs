# 2016 CS1 Q40: MST statements about the lightest and heaviest edge of a cycle

## Question

$G = (V, E)$ is an undirected simple graph in which each edge has a distinct weight, and $e$ is a particular edge of $G$. Which of the following statements about the minimum spanning trees (MSTs) of $G$ is/are TRUE?

- I. If $e$ is the lightest edge of some cycle in $G$, then every MST of $G$ includes $e$
- II. If $e$ is the heaviest edge of some cycle in $G$, then every MST of $G$ excludes $e$

- (A) I only
- (B) II only
- (C) both I and II
- (D) neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**II is true (cycle property).** With distinct weights, the heaviest edge on any cycle belongs to no MST. If a tree contained it, removing it and adding another edge of the cycle would give a lighter spanning tree.

**I is false.** Being the lightest edge of *one* cycle does not protect $e$ if it is the heaviest edge of *another* cycle. Counter-example on vertices $a, b, c, d$ with $e = ab$ of weight $3$:

| Cycle | Edges (weights) | $e$ is |
|---|---|---|
| $a, b, c$ | $ab = 3$, $bc = 4$, $ca = 5$ | lightest |
| $a, b, d$ | $ad = 1$, $bd = 2$, $ab = 3$ | heaviest |

By the cycle property applied to the second cycle, $e$ is in no MST, even though it is the lightest edge of the first cycle.

So only II holds: **(B)**.

**Key idea:** the heaviest edge of any cycle is never in an MST; the lightest edge of a cycle need not be.

</details>
