# 2008 CS Q45: Dijkstra with negative edges

## Question

![A directed graph on eight vertices a to h. Edges: a to b with weight 1; b to c with weight 2; b to e with weight -3; c to d with weight 3; c to h with weight -5; d to a with weight 2; d to g with weight 2; g to h with weight 2; g to e with weight 1; h to e with weight 1; e to f with weight 2; f to g with weight 3.](../../assets/2008/set1-q45.png)

Dijkstra's single source shortest path algorithm when run from vertex $a$ in the above graph, computes the correct shortest path distance to

- (A) only vertex $a$
- (B) only vertices $a, e, f, g, h$
- (C) only vertices $a, b, c, d$
- (D) all the vertices

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The graph has negative edges ($b \to e$ is $-3$, $c \to h$ is $-5$), which usually breaks Dijkstra. It is safe here because **no vertex is extracted before its final distance is known**. Trace:

| Extracted | Distance | Updates |
|---|---|---|
| $a$ | 0 | $b = 1$ |
| $b$ | 1 | $c = 3,\ e = -2$ |
| $e$ | $-2$ | $f = 0$ |
| $f$ | 0 | $g = 3$ |
| $c$ | 3 | $d = 6,\ h = -2$ |
| $h$ | $-2$ | $e$ is already done ($-2 + 1 > -2$) |
| $g$ | 3 | nothing better |
| $d$ | 6 | nothing better |

Final: $a=0,\ b=1,\ c=3,\ d=6,\ e=-2,\ f=0,\ g=3,\ h=-2$. These are the true shortest distances, so all eight are correct: (D).

- (A), (B) and (C) wrongly assume a negative edge must spoil some distances. A negative edge only hurts if it would later shorten a vertex that has already been extracted, which does not happen here.

**Code check:** a heap-based Dijkstra and a Bellman-Ford run give identical distance tables for all eight vertices.

**Key idea:** Dijkstra can survive negative edges on a particular graph, but only when no finalised vertex would be improved later.

</details>
