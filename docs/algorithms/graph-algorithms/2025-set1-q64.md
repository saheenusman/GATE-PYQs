# 2025 CS1 Q64: Largest x for which edge BC is in every MST

## Question

The maximum value of $x$ such that the edge between the nodes B and C is included in every minimum spanning tree of the given graph is _________ . (answer in integer)

![Complete graph on four nodes A, B, C, D, with A top left, B top right, C bottom right, D bottom left. Edge weights: AB = 7, AD = 6, DC = 8, BC = x. The two diagonals are labelled 1 and 3: the label 1 sits on the diagonal through B and D, and the label 3 on the diagonal through A and C.](../../assets/2025/set1-q64.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rule.** Edge $e = BC$ appears in **every** MST exactly when it is *strictly lighter* than the heaviest edge on **every** other $B$-$C$ path. Otherwise some MST can swap it for an edge of equal or smaller weight (cycle property).

So compare $x$ with the **bottleneck** of the best alternative route from B to C: the path whose heaviest edge is smallest.

Edges other than BC: $BD = 1$, $AC = 3$, $AD = 6$, $AB = 7$, $CD = 8$.

| Path from B to C | Heaviest edge |
|---|---|
| B-D-A-C (1, 6, 3) | 6 |
| B-A-C (7, 3) | 7 |
| B-D-C (1, 8) | 8 |

The best alternative has bottleneck 6. So $BC$ is in every MST iff $x < 6$. The largest integer is **5**.

**Check.** I enumerated all spanning trees for $x = 1,\dots,10$: BC is in every MST for exactly $x = 1,\dots,5$. At $x = 6$ there is an MST without BC.

(The labels 1 and 3 on the two diagonals are close together in the printed figure. I tested both assignments, $BD=1, AC=3$ and $BD=3, AC=1$: the answer is 5 either way.)

**Key idea:** an edge is in all MSTs iff it is strictly smaller than the bottleneck of every other path between its endpoints.

</details>
