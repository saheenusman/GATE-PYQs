# 2014 CS2 Q14: What the BFS tree computes in an unweighted graph

## Question

Consider the tree arcs of a BFS traversal from a source node `W` in an unweighted, connected, undirected graph. The tree `T` formed by the tree arcs is a data structure for computing

- (A) the shortest path between every pair of vertices.
- (B) the shortest path from `W` to every vertex in the graph.
- (C) the shortest paths from `W` to only those nodes that are leaves of `T`.
- (D) the longest path in the graph.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

BFS reaches vertices level by level, so the tree path from `W` to any vertex $v$ has the fewest edges among all paths. The tree therefore holds a shortest path from `W` to **every** vertex.

- (A) only paths starting at `W` are guaranteed shortest; paths between other pairs in the tree may not be.
- (C) every vertex, not just leaves, has a shortest path in $T$.
- (D) BFS does not find longest paths.

**Key idea:** in an unweighted graph the BFS tree gives single-source shortest paths.

</details>
