# 2009 CS Q13: What Bellman-Ford can say about negative cycles

## Question

Which of the following statement(s) is/are correct regarding Bellman-Ford shortest path algorithm?

- P. Always finds a negative weighted cycle, if one exists.
- Q. Finds whether any negative weighted cycle is reachable from the source.

Options:

- (A) P only
- (B) Q only
- (C) both P and Q
- (D) neither P nor Q

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key in the supplied PDF is (A) P only. My own analysis gives (B) Q only. Both follow.

**What I get (B).** Bellman-Ford starts from one source $s$ and relaxes edges. A vertex that $s$ cannot reach keeps distance $\infty$, so edges around it never relax. After $|V|-1$ rounds, one more round that still improves some distance proves a negative cycle **reachable from $s$**.

- **P is false.** "Always finds a negative cycle, if one exists" fails when the cycle is not reachable from $s$. Example: edges $s \to a$ (weight $1$) and a separate cycle $b \to c$ (weight $-2$), $c \to b$ (weight $1$). Bellman-Ford from $s$ reports nothing, yet a negative cycle exists.
- **Q is true.** This is exactly what the extra round detects.

So only Q holds: (B).

**What the key says.** (A) P only. That would make P true and Q false, the reverse of how the algorithm behaves. I could not find a reading of the two statements that supports it. I record the key and flag the conflict.

- (C) fails because P is false. (D) fails because Q is true.

**Code check:** Bellman-Ford on the example above (source $s$, unreachable negative cycle) reported no negative cycle; on a graph where the negative cycle is reachable it reported one.

**Key idea:** Bellman-Ford detects only negative cycles reachable from the chosen source.

</details>
