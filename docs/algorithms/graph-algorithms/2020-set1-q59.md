# 2020 CS Q59: MST weight of a graph on v1..v100 with edge weight |i - j|

## Question

Consider a graph $G = (V, E)$, where $V = \lbrace v_1, v_2, \dots, v_{100} \rbrace$, $E = \lbrace (v_i, v_j) \mid 1 \le i < j \le 100 \rbrace$, and weight of the edge $(v_i, v_j)$ is $|i - j|$. The weight of minimum spanning tree of $G$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**99**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Lower bound.** A spanning tree on 100 vertices has exactly 99 edges. Every edge $(v_i, v_j)$ has $i \ne j$, so its weight $|i-j|$ is at least 1. Hence every spanning tree weighs at least $99 \times 1 = 99$.

**It is achieved.** The path

$$v_1 - v_2 - v_3 - \dots - v_{100}$$

uses the 99 edges $(v_i, v_{i+1})$, each of weight $1$. It connects all the vertices and has no cycle, so it is a spanning tree of weight exactly $99$.

So the MST weight is **99**. I also ran Kruskal's algorithm in code on all 4950 edges and got 99.

**Key idea:** when the smallest possible edge weight is 1 and a spanning tree needs $n-1$ edges, the MST weight is at least $n-1$. Here a path of weight-1 edges reaches it.

</details>
