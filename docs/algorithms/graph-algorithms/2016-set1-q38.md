# 2016 CS1 Q38: Largest weight x that can still lie on a shortest path

## Question

Consider the weighted undirected graph with 4 vertices, where the weight of edge $\lbrace i, j \rbrace$ is given by the entry $W_{ij}$ in the matrix $W$.

$$W = \begin{bmatrix} 0 & 2 & 8 & 5 \\ 2 & 0 & 5 & 8 \\ 8 & 5 & 0 & x \\ 5 & 8 & x & 0 \end{bmatrix}$$

The largest possible integer value of $x$, for which at least one shortest path between some pair of vertices will contain the edge with weight $x$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**12**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Number the vertices $1$ to $4$. The unknown edge joins vertices $3$ and $4$. The other edges: $w_{12} = 2$, $w_{13} = 8$, $w_{14} = 5$, $w_{23} = 5$, $w_{24} = 8$.

**The edge $x$ can only help most between its own endpoints.** Compare $x$ with the best alternative route from $3$ to $4$:

| Route | Length |
|---|---|
| $3 \to 2 \to 4$ | $5 + 8 = 13$ |
| $3 \to 1 \to 4$ | $8 + 5 = 13$ |
| $3 \to 2 \to 1 \to 4$ | $5 + 2 + 5 = 12$ |
| $3 \to 1 \to 2 \to 4$ | $8 + 2 + 8 = 18$ |

The best alternative has length $12$. For the direct edge to lie on *a* shortest path, $x \le 12$ (a tie at $12$ still counts as "a shortest path contains it").

**Other pairs need a smaller $x$.** For example $1 \to 3$ via $4$ costs $5 + x$, which beats the best other route ($1 \to 2 \to 3 = 7$) only if $x \le 2$. So the loosest condition is the one for the pair $(3, 4)$, and the largest value is $x = 12$.

**Code check:** for each integer $x$ from $1$ to $39$ the code tested every pair for a shortest path through the $x$-edge; the largest $x$ that worked was $12$.

**Key idea:** $x$ must not exceed the best alternative route $3 \to 2 \to 1 \to 4$ of length 12.

</details>
