# 2014 CS1 Q3: Graph with the same strongly connected components as G

## Question

Let $G=(V,E)$ be a directed graph where $V$ is the set of vertices and $E$ the set of edges. Then which one of the following graphs has the same strongly connected components as $G$ ?

- (A) $G_1 = (V, E_1)$ where $E_1 = \lbrace (u,v) \mid (u,v) \notin E \rbrace$
- (B) $G_2 = (V, E_2)$ where $E_2 = \lbrace (u,v) \mid (v,u) \in E \rbrace$
- (C) $G_3 = (V, E_3)$ where $E_3 = \lbrace (u,v) \mid$ there is a path of length $\le 2$ from $u$ to $v$ in $E \rbrace$
- (D) $G_4 = (V_4, E)$ where $V_4$ is the set of vertices in $G$ which are not isolated

<details class="success" markdown="1">
<summary>Answer</summary>

**B** (official key)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Disputed.** The official key is **B**, but my working shows **C** also preserves the SCCs.

**B (key).** $G_2$ is the reverse graph. $u$ and $v$ reach each other in $G$ exactly when they do in the reverse graph, so the SCCs are the same. Kosaraju's algorithm relies on this.

**C (also valid).** $E_3$ keeps every edge of $E$ (paths of length 1) and adds an edge $(u,w)$ only when $G$ already has a path $u \to v \to w$ (or a trivial path of length 0). Every added edge is already implied by a path in $G$, so reachability is unchanged. So are the SCCs.

**A and D are wrong.**

- (A) The complement of $E$ breaks SCCs. $E=\lbrace (a,b),(b,a) \rbrace$ is one SCC, but the complement has no edges, so two.
- (D) An isolated vertex is an SCC by itself, so deleting it removes a component.

**Code check:** on 3000 random digraphs with up to 6 vertices, $G_2$ and $G_3$ had the same SCCs as $G$ every time. $G_1$ differed in 2098 cases and $G_4$ in 1350.

I have not picked between B and C. The key answer is B; C satisfies the stated condition as well.

**Key idea:** reversing edges, or adding edges implied by existing paths, does not change SCCs.

</details>
