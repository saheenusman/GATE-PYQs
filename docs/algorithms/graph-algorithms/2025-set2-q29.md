# 2025 CS2 Q29: True statements about BFS and DFS

## Question

Which of the following statements regarding Breadth First Search (BFS) and Depth First Search (DFS) on an undirected simple graph $G$ is/are TRUE?

- (A) A DFS tree of $G$ is a Shortest Path tree of $G$.
- (B) Every non-tree edge of $G$ with respect to a DFS tree is a forward/back edge.
- (C) If $(u,v)$ is a non-tree edge of $G$ with respect to a BFS tree, then the distances from the source vertex $s$ to $u$ and $v$ in the BFS tree are within $\pm 1$ of each other.
- (D) Both BFS and DFS can be used to find the connected components of $G$.

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) False.** In a triangle $s, a, b$, DFS from $s$ may go $s \to a \to b$, giving the tree path $s,a,b$. But $b$ is adjacent to $s$ directly, so the tree distance 2 is not the shortest distance 1. Only BFS trees are shortest-path trees (in unweighted graphs).

**(B) True.** In an undirected graph DFS creates only **tree edges and back edges** (to an ancestor, which seen from the ancestor is a forward edge). There are no cross edges, because an edge between two vertices in different branches would have been explored as a tree edge first.

**(C) True.** BFS levels are distances. If $u$ and $v$ are adjacent in $G$ then their true distances from $s$ differ by at most 1, and the BFS tree preserves these distances, so their levels differ by $0$ or $1$.

**(D) True.** Starting a new BFS or DFS from each unvisited vertex gives one traversal per connected component.

**Key idea:** undirected DFS has only tree and back edges. Undirected BFS has non-tree edges only within the same or adjacent levels.

</details>
