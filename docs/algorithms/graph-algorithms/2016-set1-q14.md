# 2016 CS1 Q14: Effect of adding a constant to every edge weight on MST and shortest paths

## Question

Let $G$ be a weighted connected undirected graph with distinct positive edge weights. If every edge weight is increased by the same value, then which of the following statements is/are TRUE?

- P: Minimum spanning tree of $G$ does not change
- Q: Shortest path between any pair of vertices does not change

- (A) P only
- (B) Q only
- (C) Neither P nor Q
- (D) Both P and Q

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let every weight rise by $c > 0$.

**P is true.** Every spanning tree has exactly $n - 1$ edges, so every tree's weight rises by the same amount $(n-1)c$. The cheapest tree stays the cheapest. (Equivalently, Kruskal only looks at the *order* of weights, which is unchanged.)

**Q is false.** A path with more edges gains more than a path with fewer edges. Counter-example on a triangle $u, v, w$:

| Edge | Weight | After $+3$ |
|---|---|---|
| $uv$ | 10 | 13 |
| $uw$ | 4 | 7 |
| $wv$ | 5 | 8 |

Before: $u \to w \to v$ costs $9 < 10$, so the shortest path is via $w$. After: $7 + 8 = 15 > 13$, so the direct edge $uv$ is now shortest. The shortest path changed.

So only P is true: **(A)**.

**Key idea:** all spanning trees have the same number of edges, but paths do not.

</details>
