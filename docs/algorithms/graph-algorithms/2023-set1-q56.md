# 2023 CS Q56: Number of BFS orders from the empty set

## Question

Let $U = \lbrace 1, 2, 3 \rbrace$. Let $2^U$ denote the powerset of $U$. Consider an undirected graph $G$ whose vertex set is $2^U$. For any $A, B \in 2^U$, $(A, B)$ is an edge in $G$ if and only if (i) $A \ne B$, and (ii) either $A \subsetneq B$ or $B \subsetneq A$. For any vertex $A$ in $G$, the set of all possible orderings in which the vertices of $G$ can be visited in a Breadth First Search (BFS) starting from $A$ is denoted by $\mathcal{B}(A)$.

If $\emptyset$ denotes the empty set, then the cardinality of $\mathcal{B}(\emptyset)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5040**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The graph has 8 vertices.** The empty set is a proper subset of every other subset, so $\emptyset$ is adjacent to **all 7** other vertices.

**BFS from $\emptyset$.** It first visits $\emptyset$, then puts all 7 neighbours in the queue in some order. After that, every vertex is already visited, so nothing else is discovered. The BFS order is therefore decided only by the order in which the 7 neighbours are listed:

$$|\mathcal{B}(\emptyset)| = 7! = 5040$$

**Code check:** a script that enumerated all valid BFS orders of this graph from $\emptyset$ found exactly 5040.

**Key idea:** when the start vertex touches every other vertex, any permutation of the others is a valid BFS order.

</details>
