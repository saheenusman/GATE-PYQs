# 2013 CS Q19: Bellman-Ford on a complete graph

## Question

What is the time complexity of Bellman-Ford single-source shortest path algorithm on a complete graph of $n$ vertices?

- (A) $\Theta(n^2)$
- (B) $\Theta(n^2 \log n)$
- (C) $\Theta(n^3)$
- (D) $\Theta(n^3 \log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Bellman-Ford relaxes every edge in each of $|V|-1$ rounds, so it takes $\Theta(|V|\cdot|E|)$.

A complete graph on $n$ vertices has $|E| = n(n-1)/2 = \Theta(n^2)$ edges. So the time is $\Theta(n \cdot n^2) = \Theta(n^3)$.

**Why the others fail:**

- (A) would be the cost of one round, or of Dijkstra with an adjacency matrix.
- (B), (D) have a $\log n$ factor, which comes from heap-based algorithms and not from Bellman-Ford.

**Key idea:** Bellman-Ford is $\Theta(VE)$; dense graphs make that cubic.

</details>
