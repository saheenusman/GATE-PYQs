# 2021 CS1 Q51: Articulation points and the DFS tree

## Question

An *articulation point* in a connected graph is a vertex such that removing the vertex and its incident edges disconnects the graph into two or more connected components.

Let $T$ be a DFS tree obtained by doing DFS in a connected undirected graph $G$.

Which of the following options is/are correct?

- (A) Root of $T$ can never be an articulation point in $G$.
- (B) Root of $T$ is an articulation point in $G$ if and only if it has 2 or more children.
- (C) A leaf of $T$ can be an articulation point in $G$.
- (D) If $u$ is an articulation point in $G$ such that $x$ is an ancestor of $u$ in $T$ and $y$ is a descendant of $u$ in $T$, then all paths from $x$ to $y$ in $G$ must pass through $u$.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In an undirected DFS tree every non-tree edge is a back edge (between a vertex and one of its ancestors). There are no cross edges.

- (A) False. A root with two or more children is an articulation point (see B).
- (B) **True.** If the root has two children, their subtrees have no edge between them (that would be a cross edge). Removing the root splits them. If the root has one child, removing it leaves the rest connected.
- (C) False. Removing a leaf leaves the rest of the tree connected, so a leaf is never an articulation point.
- (D) False. Take edges $0\text{-}1,\ 1\text{-}2,\ 1\text{-}3,\ 3\text{-}0$ and run DFS from 0 through 1 (visiting 2 first, then 3). Vertex 1 is an articulation point (removing it cuts off vertex 2). With $x=0$ (an ancestor of 1) and $y=3$ (a descendant of 1), the edge $0\text{-}3$ is a path that avoids vertex 1.

I checked B on 2000 random connected graphs with random DFS orders: the root was an articulation point exactly when it had two or more children, and no leaf was ever an articulation point.

Answer: **B only**.

**Key idea:** the DFS root is an articulation point iff it has at least two children. For other vertices, check back edges from the subtrees.

</details>
