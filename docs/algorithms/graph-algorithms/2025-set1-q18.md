# 2025 CS1 Q18: MST path lengths versus graph path lengths

## Question

Let $G$ be any undirected graph with positive edge weights, and $T$ be a minimum spanning tree of $G$. For any two vertices, $u$ and $v$, let $d_1(u,v)$ and $d_2(u,v)$ be the shortest distances between $u$ and $v$ in $G$ and $T$, respectively. Which ONE of the options is CORRECT for all possible $G$, $T$, $u$ and $v$?

- (A) $d_1(u,v) = d_2(u,v)$
- (B) $d_1(u,v) \le d_2(u,v)$
- (C) $d_1(u,v) \ge d_2(u,v)$
- (D) $d_1(u,v) \ne d_2(u,v)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$T$ is a subgraph of $G$, so every path in $T$ is also a path in $G$. The shortest path in $G$ is a minimum over **more** paths, so it cannot be longer:

$$d_1(u,v) \le d_2(u,v).$$

**Why it need not be equal.** Take a triangle with $w(uv)=5$, $w(uw)=3$, $w(wv)=4$. The MST is $\lbrace uw, wv\rbrace$ (total 7), which drops the heaviest edge $uv$.

| Pair | $d_1$ | $d_2$ |
|---|---|---|
| $u,v$ | 5 (direct edge) | 7 (via $w$) |
| $u,w$ | 3 | 3 |

| Option | Verdict |
|---|---|
| A: always equal | False for the pair $u,v$ |
| **B: $d_1 \le d_2$** | True always, by the subgraph argument |
| C: $d_1 \ge d_2$ | False for the pair $u,v$ ($5 < 7$) |
| D: always different | False for the pair $u,w$ |

I also checked this on 300 random weighted graphs: $d_1 \le d_2$ never failed, and $d_1 < d_2$ occurred often.

**Key idea:** an MST minimises total weight, not distances: its paths can only be longer than or equal to the graph's shortest paths.

</details>
