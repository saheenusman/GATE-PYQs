# 2021 CS1 Q27: Number of minimum-weight spanning trees

## Question

Consider the following undirected graph with edge weights as shown:

![A 3 by 3 grid of nine vertices. Horizontal edges, top row: 0.1, 0.1. Horizontal edges, middle row: 0.1, 0.9. Horizontal edges, bottom row: 0.9, 0.1. Vertical edges, left column: 0.9 (top), 0.1 (bottom). Vertical edges, middle column: 0.9 (top), 0.1 (bottom). Vertical edges, right column: 0.9 (top), 0.1 (bottom).](../../assets/2021/set1-q27.png)

The number of minimum-weight spanning trees of the graph is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The graph has 9 vertices, so a spanning tree has 8 edges. Of the 12 edges, **seven have weight 0.1** and five have weight 0.9. Rows and columns are named T, M, B and 0, 1, 2 (top, middle, bottom and left, middle, right).

The 0.1 edges are T0-T1, T1-T2, M0-M1, M0-B0, M1-B1, M2-B2, B1-B2. The 0.9 edges are T0-M0, T1-M1, T2-M2, M1-M2, B0-B1.

Do the 0.1 edges alone connect the graph? They form two components:

- $\lbrace T0,T1,T2\rbrace$ (top row, joined by two edges).
- $\lbrace M0,M1,B0,B1,M2,B2\rbrace$ (the rest, joined by the 0.1 edges).

The graph of 0.1 edges has no cycle, so all 7 of them can be used. A spanning tree has 8 edges, so we add **exactly one 0.9 edge** to join the two components. Weight $=7(0.1)+0.9=1.6$.

Count the 0.9 edges that connect the top component to the lower one: T0-M0, T1-M1, T2-M2. That is **3** choices (M1-M2 and B0-B1 join vertices of the same component and would form a cycle).

So there are **3** minimum spanning trees.

Verified by brute force over all $\binom{12}{8}$ edge subsets: the minimum weight is 1.6 and 3 spanning trees reach it.

**Key idea:** take all the light edges that form no cycle, then count the cheapest ways to join the components left.

</details>
