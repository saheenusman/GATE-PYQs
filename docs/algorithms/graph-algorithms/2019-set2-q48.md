# 2019 CS2 Q48: Uniqueness of the minimum spanning tree

## Question

Let $G$ be any connected, weighted, undirected graph.

- I. $G$ has a unique minimum spanning tree, if no two edges of $G$ have the same weight.
- II. $G$ has a unique minimum spanning tree, if, for every cut of $G$, there is a unique minimum-weight edge crossing the cut.

Which of the above two statements is/are TRUE?

- (A) I only
- (B) II only
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Both rely on the **cut property**: the lightest edge crossing any cut belongs to some MST. If that edge is unique, it belongs to **every** MST.

**II is true.** Take any edge $e$ of an MST $T$. Removing $e$ from $T$ splits the vertices into two sides, which defines a cut. The edge $e$ must be a lightest edge across that cut. By assumption that lightest edge is unique, so $e$ is forced. Every MST must contain the same edges, so the MST is unique.

**I is true.** Distinct weights imply that every cut has a unique lightest edge, so I is a special case of II.

**Code check:** I listed every spanning tree of random connected 5-vertex graphs. In the 713 graphs with distinct weights, the MST was unique every time. Each of those graphs also had a unique lightest edge across every cut, and no graph with repeated weights happened to satisfy II, so the same 713 graphs test both statements.

**Why the others fail:** (A), (B) and (D) each deny a true statement.

**Key idea:** a unique lightest edge across a cut is forced into every MST.

</details>
