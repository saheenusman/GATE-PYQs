# 2012 CS Q29: MST after squaring the edge weights

## Question

Let $G$ be a weighted graph with edge weights greater than one and $G'$ be the graph constructed by squaring the weights of edges in $G$. Let $T$ and $T'$ be the minimum spanning trees of $G$ and $G'$, respectively, with total weights $t$ and $t'$. Which of the following statements is **TRUE**?

- (A) $T' = T$ with total weight $t' = t^2$
- (B) $T' = T$ with total weight $t' < t^2$
- (C) $T' \neq T$ but total weight $t' = t^2$
- (D) None of the above

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is MTA. My own working gives a single answer, (D), under the strict reading, so I do not simply accept "no answer". Both readings follow.

**Same tree.** Weights are positive, and squaring is strictly increasing for them, so it keeps the order of the edges. Kruskal's algorithm sorts the edges, so it picks the same edges: $T' = T$. That rules out (C).

**Total weight.** With tree edges $w_1, \dots, w_k$:

$$t' = \sum w_i^2, \qquad t^2 = \Big(\sum w_i\Big)^2 = \sum w_i^2 + 2\sum_{i<j} w_i w_j.$$

- If $T$ has $k \ge 2$ edges, the cross terms are positive, so $t' < t^2$. Then (B) is true and (A) is false.
- If $T$ has exactly one edge (a graph on two vertices), $t' = t^2$. Then (A) is true and (B) is false.

**The two readings.**

- *For every graph $G$:* (A) fails for $k \ge 2$, (B) fails for $k = 1$, (C) always fails, so only (D) holds.
- *For any graph with at least three vertices (what most answer sites assume):* (B).

The question does not state the size of $G$, which is a likely reason the key awards marks to all. I record the key (MTA) and flag that my strict reading is (D).

**Code check:** on 3000 random connected graphs with 2 to 7 vertices and weights from 2 to 9, $T' = T$ every time. $t' < t^2$ in 2503 cases and $t' = t^2$ in 497, all of them two-vertex graphs.

**Key idea:** squaring keeps the edge order so the MST is unchanged, but $\sum w_i^2 < (\sum w_i)^2$ once the tree has two or more edges.
