# 2010 CS Q51: Cheapest path from vertex 1 to 2 using at most 3 edges

## Question

**Common Data Questions 50 and 51** (same graph and matrix $W$ as Question 50).

What is the minimum possible weight of a path $P$ from vertex $1$ to vertex $2$ in this graph such that $P$ contains at most $3$ edges?

- (A) $7$
- (B) $8$
- (C) $9$
- (D) $10$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the weights from the matrix in Question 50. Paths from $1$ to $2$ with at most $3$ edges:

| Edges | Path | Weight |
|---|---|---|
| 1 | $1 \to 2$ | $12$ |
| 2 | $1 \to 0 \to 2$ | $1 + 8 = 9$ |
| 2 | $1 \to 3 \to 2$ | $4 + 7 = 11$ |
| 2 | $1 \to 4 \to 2$ | $9 + 3 = 12$ |
| 3 | $1 \to 0 \to 3 \to 2$ | $1 + 1 + 7 = 9$ |
| 3 | $1 \to 0 \to 4 \to 2$ | $1 + 4 + 3 = \mathbf{8}$ |
| 3 | $1 \to 3 \to 4 \to 2$ | $4 + 2 + 3 = 9$ |

(The other 3-edge paths cost more.) The minimum is $8$: (B).

- (C) $9$ is the best 2-edge path (and some 3-edge paths).
- (A) $7$ and (D) $10$ do not occur as the minimum.

**Code check:** all simple paths $1 \to 2$ with $1$ to $3$ edges were enumerated; the minimum is $8$, via $1,0,4,2$.

**Key idea:** the "at most 3 edges" limit rules out the cheap-looking long detours; check all short paths.

</details>
