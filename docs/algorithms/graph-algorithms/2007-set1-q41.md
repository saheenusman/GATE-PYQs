# 2007 CS Q41: Shortest paths in an unweighted graph

## Question

In an unweighted, undirected connected graph, the shortest path from a node $S$ to every other node is computed most efficiently, in terms of *time complexity*, by

- (A) Dijkstra's algorithm starting from $S$.
- (B) Warshall's algorithm.
- (C) performing a DFS starting from $S$.
- (D) performing a BFS starting from $S$.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

BFS visits vertices in order of increasing distance from $S$, which in an unweighted graph is exactly the shortest-path distance. It runs in $O(V + E)$: (D).

- (A) Dijkstra works but costs $O((V+E)\log V)$ with a heap, more than BFS.
- (B) Warshall's (Floyd-Warshall) computes all-pairs information in $O(V^3)$.
- (C) DFS does not give shortest paths; it can reach a vertex by a long route first.
