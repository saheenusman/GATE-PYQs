# 2016 CS2 Q11: Largest BFS position of a vertex at distance four in a binary tree

## Question

Breadth First Search (BFS) is started on a binary tree beginning from the root vertex. There is a vertex $t$ at a distance four from the root. If $t$ is the $n$-th vertex in this BFS traversal, then the maximum possible value of $n$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**31**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

BFS visits vertices level by level. A vertex at distance $4$ lies on level $4$.

A binary tree has at most $2^i$ vertices on level $i$, so the levels $0$ to $4$ hold at most

$$1 + 2 + 4 + 8 + 16 = 31$$

vertices. In the best (worst-for-us) case all of them are present and $t$ is the last vertex of level $4$, so $n = 31$.

**Key idea:** $t$ can be last on level 4 of a full tree: $2^5 - 1 = 31$.

</details>
