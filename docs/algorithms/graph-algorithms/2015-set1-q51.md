# 2015 CS1 Q51: Impossible distance difference for a non-tree edge in BFS

## Question

Let $G = (V, E)$ be a simple undirected graph, and $s$ be a particular vertex in it called the source. For $x \in V$, let $d(x)$ denote the shortest distance in $G$ from $s$ to $x$. A breadth first search (BFS) is performed starting at $s$. Let $T$ be the resultant BFS tree. If $(u,v)$ is an edge of $G$ that is not in $T$, then which one of the following CANNOT be the value of $d(u) - d(v)$?

- (A) -1
- (B) 0
- (C) 1
- (D) 2

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For **any** edge $(u,v)$ of an undirected graph, $|d(u) - d(v)| \le 1$. If $d(u) \ge d(v) + 2$, the path $s \to v \to u$ (using the edge) would have length $d(v)+1 < d(u)$, contradicting that $d(u)$ is the shortest distance.

So $d(u) - d(v) \in \lbrace -1, 0, 1 \rbrace$ for every edge, tree edge or not.

- $0$: a non-tree edge between two vertices on the same level.
- $\pm 1$: a non-tree edge between consecutive levels (both signs occur by swapping $u$ and $v$).
- $2$: impossible.

Option (D).

**Key idea:** in an undirected graph, BFS levels of adjacent vertices differ by at most 1.

</details>
