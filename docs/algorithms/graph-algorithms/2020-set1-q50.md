# 2020 CS Q50: Shortest paths after reweighting with a potential f

## Question

Let $G = (V, E)$ be a directed, weighted graph with weight function $w: E \to \mathbb{R}$. For some function $f: V \to \mathbb{R}$, for each edge $(u, v) \in E$, define $w'(u, v)$ as $w(u, v) + f(u) - f(v)$.

Which one of the options completes the following sentence so that it is TRUE?

"The shortest paths in $G$ under $w$ are shortest paths under $w'$ too, ______".

- (A) for every $f : V \to \mathbb{R}$
- (B) if and only if $\forall u \in V,\ f(u)$ is positive
- (C) if and only if $\forall u \in V,\ f(u)$ is negative
- (D) if and only if $f(u)$ is the distance from $s$ to $u$ in the graph obtained by adding a new vertex $s$ to $G$ and edges of zero weight from $s$ to every vertex of $G$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Telescoping.** Take any path $P = x_0 \to x_1 \to \dots \to x_k$. Adding up $w'$ along it:

$$w'(P) = \sum_{i=0}^{k-1} \big( w(x_i, x_{i+1}) + f(x_i) - f(x_{i+1}) \big) = w(P) + f(x_0) - f(x_k).$$

All the middle $f$ terms cancel. So the new weight of a path equals its old weight plus a number that depends **only on its two endpoints**.

**Consequence.** All paths between the same pair $(x_0, x_k)$ shift by the same constant $f(x_0) - f(x_k)$. A path that was shortest under $w$ is therefore still shortest under $w'$, whatever $f$ is. No condition on $f$ is needed, so the sentence holds **for every $f$**.

**Why the others fail:**

- **(B) and (C)** restrict the sign of $f$, which is irrelevant because only differences $f(u) - f(v)$ appear and they cancel along a path.
- **(D)** describes the particular $f$ used in Johnson's algorithm (computed with Bellman-Ford). That choice is used to make all new weights *non-negative*, not to preserve shortest paths. Shortest paths are preserved for any $f$.

**Key idea:** reweighting by a potential changes every path between two fixed vertices by the same constant, so the ranking of those paths does not change.

</details>
