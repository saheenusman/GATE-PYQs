# 2021 CS2 Q56: Cycles, back edges and reachability in a 4x4 directed grid

## Question

Consider the following directed graph:

![A 4 by 4 grid of vertices with directed edges. The vertex S is at the bottom-left corner. Each of the three 2 by 2 blocks at the top middle, bottom left and bottom right forms a directed 4-cycle, and the remaining edges join these blocks and the four other vertices in one direction only.](../../assets/2021/set2-q56.png)

Which of the following is/are correct about the graph?

- (A) The graph does not have a topological order.
- (B) A depth-first traversal starting at vertex S classifies three directed edges as back edges.
- (C) The graph does not have a strongly connected component.
- (D) For each pair of vertices $u$ and $v$, there is a directed path from $u$ to $v$.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Number rows from the top (1 to 4) and columns from the left (1 to 4). $S$ is at (4,1).

I read the 24 directed edges from the figure and analysed them with a script. The structure is:

- Three directed **4-cycles** (2×2 blocks): rows 1-2 / columns 2-3 (top middle), rows 3-4 / columns 1-2 (bottom left, contains $S$), and rows 3-4 / columns 3-4 (bottom right). Each is a strongly connected component of size 4.
- The other four vertices, (1,1), (1,4), (2,1), (2,4), are single-vertex components.

So there are 7 strongly connected components.

- (A) **Correct.** A directed cycle exists, so no topological order exists.
- (B) **Correct.** Back edges only occur inside cycles. In each directed 4-cycle, a DFS that enters the cycle uses three of its edges as tree edges, and the fourth edge points back to an ancestor. So the three cycles give exactly three back edges. The DFS from $S$ reaches all 16 vertices. I ran 3000 random neighbour orders: every one gave exactly 3 back edges.
- (C) Wrong. The graph has 7 strongly connected components (every vertex belongs to one).
- (D) Wrong. Vertex (1,4) has no outgoing edge, so nothing is reachable from it.

**Key idea:** a directed cycle rules out a topological order, and each directed cycle forces a back edge in a DFS.

</details>
