# 2024 CS1 Q45: A DFS tree that is also a BFS tree

## Question

Let $G$ be a directed graph and $T$ a depth first search (DFS) spanning tree in $G$ that is rooted at a vertex $v$. Suppose $T$ is also a breadth first search (BFS) tree in $G$, rooted at $v$. Which of the following statements is/are TRUE for every such graph $G$ and tree $T$?

- (A) There are no back-edges in $G$ with respect to the tree $T$
- (B) There are no cross-edges in $G$ with respect to the tree $T$
- (C) There are no forward-edges in $G$ with respect to the tree $T$
- (D) The only edges in $G$ are the edges in $T$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Forward edges are impossible.** A forward edge $u \to w$ goes from $u$ to a *proper descendant* $w$ that is **not** a child. Then $w$ is at depth $\ge \text{depth}(u) + 2$ in $T$. But in a BFS tree, any edge $u \to w$ forces $\text{depth}(w) \le \text{depth}(u) + 1$. Contradiction. So **(C) is true**.

**Back edges and cross edges are possible.** Take $v$ with two children $a$ and $b$ (tree edges $v \to a$, $v \to b$).

- Add $a \to v$: a **back edge**, to an ancestor. Both traversals still produce the same tree. So (A) is false.
- Add $b \to a$: a **cross edge**. If DFS visits $a$ first and finishes it, then $b \to a$ goes to a finished vertex. BFS also gives the same tree. So (B) is false.
- Either extra edge shows (D) is false.

**Key idea:** BFS depth satisfies $\text{depth}(w) \le \text{depth}(u)+1$ along every edge, which rules out forward edges. Back and cross edges do not violate it.

</details>
