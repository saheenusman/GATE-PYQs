# 2007 CS Q49: False statement about a minimum-weight edge and MSTs

## Question

Let $w$ be the minimum weight among all edge weights in an undirected connected graph. Let $e$ be a specific edge of weight $w$. Which of the following is **FALSE**?

- (A) There is a minimum spanning tree containing $e$.
- (B) If $e$ is not in a minimum spanning tree $T$, then in the cycle formed by adding $e$ to $T$, all edges have the same weight.
- (C) Every minimum spanning tree has an edge of weight $w$.
- (D) $e$ is present in every minimum spanning tree.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** Run Kruskal with ties broken in favour of $e$: $e$ is the first edge considered (it has minimum weight) and is accepted.
- **(B) True.** If $e \notin T$, adding $e$ makes a cycle. Every other edge on it has weight $\ge w$ (as $w$ is the minimum). If any had weight $> w$, swapping it for $e$ would give a lighter spanning tree, contradicting that $T$ is minimum. So all edges on the cycle have weight exactly $w$.
- **(C) True.** An MST with no edge of weight $w$ could be improved by adding $e$ and removing a heavier edge from the created cycle.
- **(D) False.** With ties another edge of the same weight can take $e$'s place. Example: a triangle with all three weights $1$; each MST has two of the three edges, so no particular edge is in all of them.

So (D) is false.

**Code check:** Python brute force over 2,280 random connected graphs (3-6 vertices, weights 1-3), enumerating every spanning tree: for every minimum-weight edge $e$ (4,736 cases), (A), (B) and (C) never failed, while (D) failed in 657 cases.

**Key idea:** the minimum-weight edge is in *some* MST but not necessarily in *every* MST when weights tie.
