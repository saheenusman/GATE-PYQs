# 2025 CS1 Q56: Probability a 5-bit message arrives error free

## Question

Suppose a 5-bit message is transmitted from a source to a destination through a noisy channel. The probability that a bit of the message gets flipped during transmission is 0.01. Flipping of each bit is independent of one another. The probability that the message is delivered error-free to the destination is ______ . (rounded off to three decimal places)

<details class="success" markdown="1">
<summary>Answer</summary>

**0.951**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The message is error free iff **none** of the 5 bits flips. Each bit survives with probability $1 - 0.01 = 0.99$, independently:

$$P = 0.99^5 = 0.95099\ldots \approx 0.951.$$

(Equivalently, the number of flipped bits is Binomial$(5, 0.01)$ and we want $P(0)$.)

**Key idea:** for independent events, multiply the probabilities of "no error" on each bit.

</details>
