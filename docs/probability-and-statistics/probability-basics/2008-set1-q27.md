# 2008 CS Q27: Two-day-ahead probability in a two-state Markov chain

## Question

Aishwarya studies either computer science or mathematics everyday. If she studies computer science on a day, then the probability that she studies mathematics the next day is $0.6$. If she studies mathematics on a day, then the probability that she studies computer science the next day is $0.4$. Given that Aishwarya studies computer science on Monday, what is the probability that she studies computer science on Wednesday?

- (A) 0.24
- (B) 0.36
- (C) 0.4
- (D) 0.6

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let C and M stand for computer science and mathematics.

Transition probabilities: C $\to$ M $= 0.6$, so C $\to$ C $= 0.4$; M $\to$ C $= 0.4$.

**Tuesday** (given C on Monday): $P(C) = 0.4$, $P(M) = 0.6$.

**Wednesday** being C can come through either Tuesday state:

$$P(C_{\text{Wed}}) = P(C_{\text{Tue}}) \cdot 0.4 + P(M_{\text{Tue}}) \cdot 0.4 = 0.4 \times 0.4 + 0.6 \times 0.4 = 0.16 + 0.24 = 0.4.$$

This is (C).

- (A) $0.24$ is only the path C $\to$ M $\to$ C, missing C $\to$ C $\to$ C.
- (B) $0.36$ is $0.6 \times 0.6$, which uses the wrong transitions.
- (D) $0.6$ is the one-step probability of C $\to$ M.

**Code check:** squaring the transition matrix gave $P(C \text{ on Wednesday}) = 0.4$.

**Key idea:** add the probabilities of all paths of length two, using the Markov property.

</details>
