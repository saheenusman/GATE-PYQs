# 2014 CS1 Q48: Four dice: number of ways to get sum 22

## Question

Four fair six-sided dice are rolled. The probability that the sum of the results being 22 is $X/1296$. The value of $X$ is _____________.

<details class="success" markdown="1">
<summary>Answer</summary>

**10**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

There are $6^4 = 1296$ equally likely outcomes, so $X$ is the number of outcomes with sum 22.

Replace each die $d$ by $7 - d$ (also uniform on $1..6$). Sum 22 becomes sum $28 - 22 = 6$. Subtract 1 from each: four values $y_i \in [0,5]$ with

$$y_1 + y_2 + y_3 + y_4 = 2$$

The upper bound 5 never binds, so the count is $\binom{2+3}{3} = 10$.

**Code check:** enumerating all 1296 outcomes gives 10 with sum 22.

$$X = 10$$

**Key idea:** reflect the dice ($d \to 7-d$) to turn a high sum into a small one, then use stars and bars.

</details>
