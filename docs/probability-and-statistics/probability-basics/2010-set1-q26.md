# 2010 CS Q26: Probability that a tested computer is declared faulty

## Question

Consider a company that assembles computers. The probability of a faulty assembly of any computer is $p$. The company therefore subjects each computer to a testing process. This testing process gives the correct result for any computer with a probability of $q$. What is the probability of a computer being declared faulty?

- (A) $pq + (1-p)(1-q)$
- (B) $(1-q)p$
- (C) $(1-p)q$
- (D) $pq$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A computer is **declared faulty** in exactly two disjoint ways:

- it **is** faulty (probability $p$) and the test is correct (probability $q$): $pq$;
- it is **not** faulty (probability $1-p$) but the test is wrong (probability $1-q$): $(1-p)(1-q)$.

Total: $pq + (1-p)(1-q)$: (A).

- (B) $(1-q)p$ is "faulty but the test says good".
- (C) $(1-p)q$ is "good and the test says good".
- (D) $pq$ leaves out the false alarms on good computers.

**Key idea:** the test declares "faulty" when it is right about a faulty machine or wrong about a good one.

</details>
