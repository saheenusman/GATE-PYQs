# 2015 CS2 Q59: Probability that a random function from 2 to 20 objects is one-to-one

## Question

Let $X$ and $Y$ denote the sets containing 2 and 20 distinct objects respectively and $F$ denote the set of all possible functions defined from $X$ to $Y$. Let $f$ be randomly chosen from $F$. The probability of $f$ being one-to-one is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**0.95**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each of the 2 elements of $X$ can map to any of the 20 elements of $Y$:

$$|F| = 20^2 = 400$$

A one-to-one function sends the first element anywhere (20 ways) and the second to a different element (19 ways):

$$20 \times 19 = 380$$

$$P = \frac{380}{400} = 0.95$$

**Answer: 0.95.**

**Code check:** counting the pairs $(f(1), f(2))$ with $f(1) \ne f(2)$ gives $380$ of $400$.

**Key idea:** one-to-one functions from an $m$-set to an $n$-set number $n(n-1)\cdots(n-m+1)$, out of $n^m$ functions.

</details>
