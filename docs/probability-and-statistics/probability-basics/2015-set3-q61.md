# 2015 CS3 Q61: Conditional probability for an AND-then-XOR of three bits

## Question

Suppose $X_i$ for $i = 1, 2, 3$ are independent and identically distributed random variables whose probability mass functions are $\Pr[X_i = 0] = \Pr[X_i = 1] = 1/2$ for $i = 1, 2, 3$. Define another random variable $Y = X_1 X_2 \oplus X_3$, where $\oplus$ denotes XOR. Then

$$\Pr[Y = 0 \mid X_3 = 0] = \text{________}$$

<details class="success" markdown="1">
<summary>Answer</summary>

**0.75**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Read $X_1X_2$ as the product (AND) of the two bits.

Given $X_3 = 0$: $Y = X_1X_2 \oplus 0 = X_1X_2$. So

$$\Pr[Y = 0 \mid X_3 = 0] = \Pr[X_1X_2 = 0]$$

$X_1X_2 = 1$ only when both are 1, with probability $\tfrac12 \cdot \tfrac12 = \tfrac14$. So

$$\Pr[X_1X_2 = 0] = 1 - \tfrac14 = \tfrac34 = 0.75$$

Independence of $X_3$ from $X_1, X_2$ means the condition does not change the distribution of $X_1X_2$.

**Answer: 0.75.**

**Code check:** among the 4 equally likely $(X_1, X_2)$ pairs with $X_3 = 0$, 3 give $Y = 0$.

**Key idea:** $a \oplus 0 = a$, and the AND of two fair bits is 1 with probability $1/4$.

</details>
