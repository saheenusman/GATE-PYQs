# 2025 CS1 Q58: Probability from a density proportional to x squared

## Question

Consider a probability distribution given by the density function $P(x)$.

$$P(x) = \begin{cases} Cx^2, & \text{for } 1 \le x \le 4 \\ 0, & \text{for } x < 1 \text{ or } x > 4 \end{cases}$$

The probability that $x$ lies between 2 and 3, i.e., $P(2 \le x \le 3)$ is __________. (rounded off to three decimal places)

<details class="success" markdown="1">
<summary>Answer</summary>

**0.302**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find $C$** from the requirement that the total probability is 1:

$$\int_1^4 Cx^2\,dx = C\cdot\frac{4^3 - 1^3}{3} = C\cdot 21 = 1 \Rightarrow C = \frac{1}{21}.$$

**Probability on $[2,3]$:**

$$P(2 \le x \le 3) = \frac{1}{21}\cdot\frac{3^3 - 2^3}{3} = \frac{1}{21}\cdot\frac{19}{3} = \frac{19}{63} \approx 0.3016.$$

Rounded to three decimals: **0.302** (the key accepts 0.300 to 0.302).

**Key idea:** normalise the density first ($\int P = 1$), then integrate over the interval.

</details>
