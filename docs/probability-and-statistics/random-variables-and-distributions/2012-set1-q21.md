# 2012 CS Q21: CDF of a random variable taking values plus and minus one

## Question

Consider a random variable $X$ that takes values $+1$ and $-1$ with probability $0.5$ each. The values of the cumulative distribution function $F(x)$ at $x = -1$ and $+1$ are

- (A) $0$ and $0.5$
- (B) $0$ and $1$
- (C) $0.5$ and $1$
- (D) $0.25$ and $0.75$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$F(x) = P(X \le x)$, which includes the point $x$ itself.

- $F(-1) = P(X \le -1) = P(X = -1) = 0.5$.
- $F(+1) = P(X \le 1) = 0.5 + 0.5 = 1$.

So $0.5$ and $1$: (C).

- (A), (B) use $P(X < -1) = 0$ for $F(-1)$, which leaves out the mass at $-1$.
- (D) is not a probability that appears in this distribution.

**Key idea:** the CDF uses $\le$, so a jump at a point is already counted at that point.

</details>
