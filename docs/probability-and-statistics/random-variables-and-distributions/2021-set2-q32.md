# 2021 CS2 Q32: Standard deviation of the number of heads in 1000 biased tosses

## Question

For a given biased coin, the probability that the outcome of a toss is a head is 0.4. This coin is tossed 1,000 times. Let $X$ denote the random variable whose value is the number of times that head appeared in these 1,000 tosses. The standard deviation of $X$ (rounded to 2 decimal places) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**15.49**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$X$ is binomial with $n=1000$, $p=0.4$.

$$\operatorname{Var}(X)=np(1-p)=1000\times0.4\times0.6=240,$$

$$\sigma=\sqrt{240}\approx15.49.$$

The official key accepts any value from 15.00 to 16.00, and 15.49 lies in that range.

**Key idea:** binomial variance is $npq$.

</details>
