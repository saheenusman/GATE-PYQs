# 2011 CS Q18: Difference between E[X squared] and the square of E[X]

## Question

If the difference between the expectation of the square of a random variable $\left(E[X^2]\right)$ and the square of the expectation of the random variable $\left(E[X]\right)^2$ is denoted by $R$, then

- (A) $R = 0$
- (B) $R < 0$
- (C) $R \ge 0$
- (D) $R > 0$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$$R = E[X^2] - (E[X])^2 = \text{Var}(X) = E\left[(X - E[X])^2\right]$$

The last expression is the expectation of a square, so it is never negative: $R \ge 0$. It is $0$ exactly when $X$ is constant (with probability $1$).

So (C) is correct.

- (A) holds only for a constant $X$, not in general.
- (B) is impossible because a variance cannot be negative.
- (D) fails for a constant $X$, where $R = 0$.

**Key idea:** E[X^2] - (E[X])^2 is the variance, which is non-negative and zero only for a constant.

</details>
