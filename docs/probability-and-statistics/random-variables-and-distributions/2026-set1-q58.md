# 2026 CS1 Q58: Expected value of a discrete random variable

## Question

Let $X$ be a random variable which takes values in the set $\lbrace 1, 2, 3, 4, 5, 6, 7, 8 \rbrace$. Further,

$$\Pr(X=1) = \Pr(X=2) = \Pr(X=5) = \Pr(X=7) = \tfrac{1}{6}$$
$$\Pr(X=3) = \Pr(X=4) = \Pr(X=6) = \Pr(X=8) = \tfrac{1}{12}$$

The expected value of $X$, denoted $E[X]$, is equal to ________. (rounded off to two decimal places)

<details class="success" markdown="1">
<summary>Answer</summary>

**4.25**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Check it is a distribution:** $4 \times \frac16 + 4 \times \frac1{12} = \frac23 + \frac13 = 1$. 

**Expected value** $E[X] = \sum x \cdot \Pr(X = x)$:

| Group | Values | Sum | Weight | Contribution |
|---|---|---|---|---|
| prob $\frac16$ | 1, 2, 5, 7 | 15 | $\frac16$ | $2.5$ |
| prob $\frac1{12}$ | 3, 4, 6, 8 | 21 | $\frac1{12}$ | $1.75$ |

$$E[X] = 2.5 + 1.75 = \mathbf{4.25}$$

The official key accepts 4.24 to 4.26.

**Key idea:** group values with equal probability, add them, then multiply by that probability.

</details>
