# 2021 CS1 Q45: Covariance versus variance, and absolute deviations

## Question

Consider the two statements.

$S_1$: There exist random variables $X$ and $Y$ such that $\left(\mathbb E\big[(X-\mathbb E(X))\,(Y-\mathbb E(Y))\big]\right)^2 > \text{Var}[X]\,\text{Var}[Y]$.

$S_2$: For all random variables $X$ and $Y$, $\text{Cov}[X,Y]=\mathbb E\Big[\big|X-\mathbb E[X]\big|\,\big|Y-\mathbb E[Y]\big|\Big]$.

Which one of the following choices is correct?

- (A) Both $S_1$ and $S_2$ are true.
- (B) $S_1$ is true, but $S_2$ is false.
- (C) $S_1$ is false, but $S_2$ is true.
- (D) Both $S_1$ and $S_2$ are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$S_1$ is false.** The left side is $\text{Cov}[X,Y]^2$. The Cauchy-Schwarz inequality gives $\text{Cov}[X,Y]^2\le\text{Var}[X]\,\text{Var}[Y]$ for all $X,Y$. So no pair has the strict inequality.

**$S_2$ is false.** The absolute values make the right side non-negative, but covariance can be negative. Counterexample: $X=\pm1$ with probability $\tfrac12$ each, and $Y=-X$. Then $\text{Cov}[X,Y]=-\mathbb E[X^2]=-1$, but $\mathbb E[|X||Y|]=1$.

Both false, so (D).

**Key idea:** $\text{Cov}^2\le\text{Var}\cdot\text{Var}$ (Cauchy-Schwarz), and covariance has a sign, so it is not an expected product of absolute values.

</details>
