# 2011 CS Q33: Incorrect statement about a linearly transformed sequence

## Question

Consider a finite sequence of random values $X = [x_1, x_2, \ldots, x_n]$. Let $\mu_x$ be the mean and $\sigma_x$ be the standard deviation of $X$. Let another finite sequence $Y$ of equal length be derived from this as $y_i = a * x_i + b$, where $a$ and $b$ are positive constants. Let $\mu_y$ be the mean and $\sigma_y$ be the standard deviation of this sequence. Which one of the following statements is **INCORRECT**?

- (A) Index position of mode of $X$ in $X$ is the same as the index position of mode of $Y$ in $Y$.
- (B) Index position of median of $X$ in $X$ is the same as the index position of median of $Y$ in $Y$.
- (C) $\mu_y = a\mu_x + b$
- (D) $\sigma_y = a\sigma_x + b$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

With $a > 0$ the map $x \mapsto a x + b$ is strictly increasing, so it preserves equality and order.

- (A) correct: equal values stay equal, so the most frequent value (mode) sits at the same index.
- (B) correct: the order of the values is unchanged, so the middle element stays the middle element.
- (C) correct: $\mu_y = \frac1n \sum (a x_i + b) = a \mu_x + b$.
- (D) **incorrect:** the constant $b$ shifts every value equally and does not change the spread, while $a$ scales it. So $\sigma_y = a \sigma_x$, not $a\sigma_x + b$.

So the incorrect statement is (D).

**Code check:** a random sample with $a = 3$, $b = 7$ gave $\mu_y = a\mu_x + b$ and $\sigma_y = a\sigma_x$ (and not $a\sigma_x + b$), with the same mode and median positions.

**Key idea:** adding a constant shifts the mean but not the spread; scaling multiplies both mean and standard deviation.

</details>
