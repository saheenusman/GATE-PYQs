# 2017 CS2 Q31: Expectation from a probability generating function

## Question

For any discrete random variable $X$, with probability mass function $P(X = j) = p_j$, $p_j \ge 0$, $j \in \lbrace 0, \ldots, N\rbrace$, and $\sum_{j=0}^{N} p_j = 1$, define the polynomial function $g_X(z) = \sum_{j=0}^{N} p_j z^j$. For a certain discrete random variable $Y$, there exists a scalar $\beta \in [0, 1]$ such that $g_Y(z) = (1 - \beta + \beta z)^N$. The expectation of $Y$ is

- (A) $N\beta(1 - \beta)$
- (B) $N\beta$
- (C) $N(1 - \beta)$
- (D) Not expressible in terms of $N$ and $\beta$ alone

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Expectation from the generating function.** Differentiating $g_X(z) = \sum p_j z^j$ gives $g_X'(1) = \sum j\,p_j = E[X]$.

**Apply to $Y$.**

$$g_Y'(z) = N\beta\,(1 - \beta + \beta z)^{N-1} \;\Rightarrow\; g_Y'(1) = N\beta\,(1)^{N-1} = N\beta.$$

So $E[Y] = N\beta$: **(B)**.

**Another view.** $(1-\beta+\beta z)^N = \sum_j \binom{N}{j}\beta^j(1-\beta)^{N-j} z^j$ is the generating function of Binomial$(N,\beta)$, whose mean is $N\beta$.

**Why the others fail.** (A) $N\beta(1-\beta)$ is the **variance** of a binomial. (C) $N(1-\beta)$ is the expected number of *failures*, $E[N - Y]$. (D) is false: it is expressible.

**Code check:** for $N = 7$, $\beta = 0.3$ the coefficients $p_j$ summed to 1 and $\sum j\,p_j = 2.1 = N\beta$.

**Key idea:** $E[X] = g_X'(1)$ for a probability generating function.

</details>
