# 2017 CS2 Q48: E[(X+2)^2] for a Poisson random variable with mean 5

## Question

If a random variable $X$ has a Poisson distribution with mean 5, then the expectation $E[(X+2)^2]$ equals ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**54**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Expand the square.**

$$E[(X+2)^2] = E[X^2] + 4E[X] + 4.$$

**Poisson facts** (mean $\lambda = 5$): $E[X] = \lambda = 5$ and $\operatorname{Var}(X) = \lambda = 5$, so

$$E[X^2] = \operatorname{Var}(X) + (E[X])^2 = 5 + 25 = 30.$$

**Put together:** $30 + 4\cdot 5 + 4 = 54$.

**Code check:** summing the Poisson pmf numerically (terms up to $k = 119$) gave $E[X^2] = 30.0$ and $E[(X+2)^2] = 54.0$.

**Key idea:** for a Poisson($\lambda$) variable, $E[X] = \operatorname{Var}(X) = \lambda$, so $E[X^2] = \lambda + \lambda^2$.

</details>
