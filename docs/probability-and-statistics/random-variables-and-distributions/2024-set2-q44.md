# 2024 CS2 Q44: Mean of a product of random variables on [0,1]

## Question

Let $x$ and $y$ be random variables, not necessarily independent, that take real values in the interval $[0,1]$. Let $z = xy$ and let the mean values of $x$, $y$, $z$ be $\bar{x}$, $\bar{y}$, $\bar{z}$, respectively. Which one of the following statements is TRUE?

- (A) $\bar{z} = \bar{x}\bar{y}$
- (B) $\bar{z} \le \bar{x}\bar{y}$
- (C) $\bar{z} \ge \bar{x}\bar{y}$
- (D) $\bar{z} \le \bar{x}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(D) is always true.** Since $0 \le y \le 1$ and $x \ge 0$, we have $xy \le x$ for every outcome. Taking expectations, $\bar{z} \le \bar{x}$.

**(A), (B), (C) depend on the correlation**, so none is always true:

- Let $x = y$ be 0 or 1 with probability $\tfrac12$ each. Then $z = x$, $\bar{z} = \tfrac12$ and $\bar{x}\bar{y} = \tfrac14$. So $\bar{z} > \bar{x}\bar{y}$, which kills (A) and (B).
- Let $y = 1 - x$ with $x$ as above. Then $z = 0$, $\bar{z} = 0 < \tfrac14 = \bar{x}\bar{y}$. This kills (C).

**Key idea:** $E[xy] = E[x]E[y]$ only for uncorrelated variables. Without independence, only pointwise bounds like $xy \le x$ carry over.

</details>
