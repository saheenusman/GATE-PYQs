# 2016 CS1 Q4: Lower limit a of a probability density function 1/x^2

## Question

A probability density function on the interval $[a, 1]$ is given by $1/x^2$ and outside this interval the value of the function is zero. The value of $a$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**0.5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A density must integrate to $1$ over its support:

$$\int_a^1 \frac{1}{x^2}\,dx = \Big[-\frac{1}{x}\Big]_a^1 = -1 + \frac{1}{a} = 1$$

So $\dfrac{1}{a} = 2$, giving $a = \dfrac{1}{2}$.

**Check.** $a$ must lie in $(0, 1)$ for the interval to make sense and for $1/x^2$ to be finite on it. $0.5$ qualifies.

**Key idea:** normalise the density: the integral over its support must equal 1.

</details>
