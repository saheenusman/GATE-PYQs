# 2019 CS2 Q57: Probability a quadratic with a random parameter has real roots

## Question

Suppose $Y$ is distributed uniformly in the open interval $(1, 6)$. The probability that the polynomial $3x^2 + 6xY + 3Y + 6$ has only real roots is (rounded off to 1 decimal place) ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**0.8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Real roots need a non-negative discriminant. For $ax^2 + bx + c$ with $a = 3$, $b = 6Y$, $c = 3Y + 6$:

$$b^2 - 4ac = 36Y^2 - 12(3Y+6) = 36Y^2 - 36Y - 72 = 36(Y - 2)(Y + 1).$$

On $(1, 6)$ we have $Y + 1 > 0$, so the condition is $Y \ge 2$.

For $Y$ uniform on $(1,6)$ (length 5):

$$P(2 \le Y < 6) = \frac{6-2}{5} = \frac{4}{5} = 0.8.$$

The single point $Y = 2$ (a repeated root) has probability 0.

**Code check:** the fraction of a fine grid on $(1,6)$ with a non-negative discriminant is 0.8000.

**Key idea:** turn "has real roots" into a condition on $Y$ via the discriminant, then take a length ratio.

</details>
