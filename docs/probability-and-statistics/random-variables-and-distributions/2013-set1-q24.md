# 2013 CS Q24: Expected triangles in a random graph

## Question

Consider an undirected random graph of eight vertices. The probability that there is an edge between a pair of vertices is $1/2$. What is the expected number of unordered cycles of length three?

- (A) $1/8$
- (B) $1$
- (C) $7$
- (D) $8$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use **linearity of expectation** over all possible triangles.

- Number of vertex triples: $\binom{8}{3} = 56$.
- A triple forms a 3-cycle when all 3 of its edges are present: probability $(1/2)^3 = 1/8$.

$$E[\text{triangles}] = 56 \cdot \tfrac18 = 7$$

**Why the others fail:**

- (A) $1/8$ is the probability for a single fixed triple.
- (B) and (D) don't come from $\binom{8}{3}\cdot\tfrac18$ (for example, $8$ would be $\binom{8}{3}/7$).

**Code check:** exact enumeration for $n=4,5,6$ matched $\binom{n}{3}/8$ ($1/2,\ 5/4,\ 5/2$), and the formula gives $7$ for $n=8$.

**Key idea:** expected count = number of candidate structures times probability each is present.

</details>
