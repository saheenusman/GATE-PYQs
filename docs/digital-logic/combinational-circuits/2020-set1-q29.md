# 2020 CS Q29: Select lines of a multiplexer in front of 32 registers

## Question

A multiplexer is placed between a group of 32 registers and an accumulator to regulate data movement such that at any given point in time the content of only one register will move to the accumulator. The minimum number of select lines needed for the multiplexer is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A multiplexer with $s$ select lines can choose among $2^s$ inputs. Here the 32 registers are the inputs, so we need the smallest $s$ with

$$2^s \ge 32 \quad\Rightarrow\quad s = \log_2 32 = 5.$$

With 4 select lines only $2^4 = 16$ registers could be chosen.

**Key idea:** an $N$-to-1 multiplexer needs $\lceil \log_2 N \rceil$ select lines.

</details>
