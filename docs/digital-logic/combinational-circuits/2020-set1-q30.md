# 2020 CS Q30: Input and output lines of a decoder for a 1 KB RAM

## Question

If there are $m$ input lines and $n$ output lines for a decoder that is used to uniquely address a byte addressable 1 KB RAM, then the minimum value of $m + n$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**1034**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Addresses needed.** A byte-addressable 1 KB RAM has $1024 = 2^{10}$ byte locations, so an address has 10 bits.

**The decoder.** An $m$-to-$n$ decoder has $n = 2^m$ outputs, one per input combination. To select each of the 1024 locations uniquely, one output line per location is needed:

$$n \ge 1024 \Rightarrow m \ge 10.$$

The minimum is $m = 10$ and $n = 2^{10} = 1024$:

$$m + n = 10 + 1024 = 1034.$$

**Assumption.** This counts one single decoder driving all 1024 locations, which is what the question means. (Splitting into smaller decoders could reduce the total, but that is not what is asked.)

**Key idea:** an $m$-input decoder has $2^m$ outputs, so a decoder that addresses $N$ locations has $\log_2 N$ inputs and $N$ outputs.

</details>
