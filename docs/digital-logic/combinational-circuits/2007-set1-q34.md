# 2007 CS Q34: Smallest multiplexer for any n-variable function

## Question

Suppose only one multiplexer and one inverter are allowed to be used to implement any Boolean function of $n$ variables. What is the minimum size of the multiplexer needed?

- (A) $2^n$ line to 1 line
- (B) $2^{n+1}$ line to 1 line
- (C) $2^{n-1}$ line to 1 line
- (D) $2^{n-2}$ line to 1 line

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use $n-1$ of the variables as select lines of a $2^{n-1}$-to-1 multiplexer. For each select combination, the output is a function of the last variable $x_n$ alone, which can only be $0$, $1$, $x_n$ or $x_n'$. The first three need no gate and the inverter supplies $x_n'$. So every $n$-variable function can be built: (C).

Why not smaller: with a $2^{n-2}$-to-1 multiplexer, each data input must realise an arbitrary function of the **two** leftover variables $a, b$. Only $0, 1, a, a', b, b'$ are available with just an inverter, so a function such as $a \oplus b$ cannot be formed.

- (A) and (B) work but are larger than necessary.
- (D) is too small, as shown above.

**Code check:** Python, $n = 3$: all 256 functions have each pair $(f(\dots,0), f(\dots,1)) \in \lbrace 00, 11, 01, 10 \rbrace$, i.e. $0, 1, x, x'$ per data input, so a 4-to-1 multiplexer plus one inverter covers all of them.
