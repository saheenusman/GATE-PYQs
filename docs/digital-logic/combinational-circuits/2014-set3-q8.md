# 2014 CS3 Q8: Hardware block that implements an if-else selector

## Question

Consider the following combinational function block involving four Boolean variables $x, y, a, b$ where $x, a, b$ are inputs and $y$ is the output.

```
f (x, y, a, b)
{
    if (x is 1) y = a;
    else y = b;
}
```

Which one of the following digital logic blocks is the most suitable for implementing this function?

- (A) Full adder
- (B) Priority encoder
- (C) Multiplexor
- (D) Flip-flop

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The block outputs $a$ when $x = 1$ and $b$ when $x = 0$:

$$y = x\,a + \bar{x}\,b$$

This is a **2-to-1 multiplexer** with data inputs $a$, $b$ and select line $x$.

- (A) A full adder computes sum and carry of three bits, which is not a selection.
- (B) A priority encoder outputs the index of the highest-priority active input.
- (D) A flip-flop is a sequential element (it stores a bit); this function is purely combinational.

**Key idea:** "if select then A else B" is a multiplexer.

</details>
