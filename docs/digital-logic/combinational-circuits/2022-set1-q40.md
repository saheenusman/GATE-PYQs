# 2022 CS Q40: Select logic of a digital display system

## Question

Consider a digital display system (DDS) shown in the figure that displays the contents of register X. A 16-bit code word is used to load a word in X, either from S or from R. S is a 1024-word memory segment and R is a 32-word register file. Based on the value of mode bit M, T selects an input word to load in X. P and Q interface with the corresponding bits in the code word to choose the addressed word. Which one of the following represents the functionality of P, Q, and T?

![The 16-bit code word is split into the mode bit M, the S-address field and the R-address field. The S-address feeds block P, which selects a word from memory segment S. The R-address feeds block Q, which selects a word from register file R. The outputs of S and R go to block T. The mode bit M also goes directly to T. T feeds register X, which drives the display DDS.](../../assets/2022/set1-q40.png)

- (A) P is 10:1 multiplexer; Q is 5:1 multiplexer; T is 2:1 multiplexer
- (B) P is $10:2^{10}$ decoder; Q is $5:2^5$ decoder; T is 2:1 encoder
- (C) P is $10:2^{10}$ decoder; Q is $5:2^5$ decoder; T is 2:1 multiplexer
- (D) P is 1:10 de-multiplexer; Q is 1:5 de-multiplexer; T is 2:1 multiplexer

<details class="success" markdown="1">
<summary>Answer</summary>

**C (decoders for P and Q, 2:1 multiplexer for T)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Field widths.** The code word has $1 + 10 + 5 = 16$ bits: the mode bit $M$, a 10-bit S-address (1024 words) and a 5-bit R-address (32 words).

- **P** turns a 10-bit address into a one-hot select for one of 1024 words: a $10:2^{10}$ decoder.
- **Q** does the same for 32 words: a $5:2^5$ decoder.
- **T** picks one of two words (from S or from R) using $M$: a 2:1 multiplexer.

That is option C.

**Why the others fail:**
- (A) a 10:1 multiplexer has only 10 data inputs, not 1024.
- (B) an encoder goes the other way (many inputs to a binary code), and it cannot choose between two data words.
- (D) a demultiplexer sends one input to one of many outputs; here the address must select among the words.

**Key idea:** address bits select a word through a decoder; a multiplexer picks between two sources.

</details>
