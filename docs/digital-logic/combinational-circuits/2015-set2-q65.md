# 2015 CS2 Q65: Propagation time of a 4-bit ripple-carry adder

## Question

A half adder is implemented with XOR and AND gates. A full adder is implemented with two half adders and one OR gate. The propagation delay of an XOR gate is twice that of an AND/OR gate. The propagation delay of an AND/OR gate is 1.2 microseconds. A 4-bit ripple-carry binary adder is implemented by using four full adders. The total propagation time of this 4-bit binary adder in microseconds is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**19.2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is 19.2. That number treats each full adder as a block with a fixed delay. A gate-by-gate critical path gives **12.0**. Both follow.

**Gate delays.** AND/OR $= 1.2\ \mu s$, XOR $= 2.4\ \mu s$.

**Reading that gives the key (19.2).** One full adder, input to output:

- Sum: XOR then XOR: $2.4 + 2.4 = 4.8$.
- Carry: XOR, AND, OR: $2.4 + 1.2 + 1.2 = 4.8$.

Four of them in a ripple chain: $4 \times 4.8 = 19.2\ \mu s$.

**Gate-level critical path (12.0).** All $a_i, b_i$ are ready at time 0, and only the carry ripples. Inside a full adder, the carry-in reaches carry-out through just AND then OR, which is $2.4$. The first XOR (on $a_i \oplus b_i$) is already finished by then.

| Stage | Carry-out ready |
|---|---|
| FA0 | $2.4 + 1.2 + 1.2 = 4.8$ |
| FA1 | $4.8 + 2.4 = 7.2$ |
| FA2 | $7.2 + 2.4 = 9.6$ |
| FA3 | $9.6 + 2.4 = 12.0$ |

The last sum bit is also ready at $12.0$. So the real worst case is $4.8 + 3 \times 2.4 = 12.0\ \mu s$.

**Why they differ.** The key adds the full 4.8 for every stage, but the 2.4 for the first XOR is on the critical path only once, in the first stage.

**Code check:** a small timing simulation of the gates gives 12.0 for the circuit and $4 \times 4.8 = 19.2$ for the block model.

A widely used solution ([GeeksforGeeks](https://www.geeksforgeeks.org/gate-gate-cs-2015-set-2-question-58/amp/)) also derives $4 \times 4.8 = 19.2$.

**Conclusion.** I record the official key (19.2). The question asks for the propagation time of the circuit as built, and my gate-level analysis of that circuit gives 12.0, so this is marked `disputed`.

**Key idea:** in a ripple-carry adder the carry chain dominates. Each stage adds only its carry-in to carry-out delay, after the first.
