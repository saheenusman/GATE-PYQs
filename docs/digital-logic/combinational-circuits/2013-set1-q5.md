# 2013 CS Q5: Truth table with valid bit

## Question

In the following truth table, $V = 1$ if and only if the input is valid.

| $D_0$ | $D_1$ | $D_2$ | $D_3$ | $X_0$ | $X_1$ | $V$ |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | x | x | 0 |
| 1 | 0 | 0 | 0 | 0 | 0 | 1 |
| x | 1 | 0 | 0 | 0 | 1 | 1 |
| x | x | 1 | 0 | 1 | 0 | 1 |
| x | x | x | 1 | 1 | 1 | 1 |

What function does the truth table represent?

- (A) Priority encoder
- (B) Decoder
- (C) Multiplexer
- (D) Demultiplexer

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read the table.** There are 4 input lines and a 2-bit binary output $X_1X_0$.

- Output is the index of an asserted input line: $D_0\to 00,\ D_1\to 01,\ D_2\to 10,\ D_3\to 11$.
- Several inputs can be 1 at once (the "x" entries). The highest-numbered asserted line wins, so $D_3$ dominates, then $D_2$, then $D_1$, then $D_0$.
- $V$ is 1 when at least one input is 1, and 0 (output "x") when none is.

That is a 4-to-2 **priority encoder** with a valid output.

**Why the others fail:**

- (B) A decoder has fewer inputs than outputs (n to $2^n$), the reverse of this table.
- (C) A multiplexer needs select lines in addition to data lines.
- (D) A demultiplexer has one data input and several outputs.

**Key idea:** don't-care entries with priority ordering, plus a valid flag, identify a priority encoder.

</details>
