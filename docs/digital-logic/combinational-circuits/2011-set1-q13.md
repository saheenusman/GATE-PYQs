# 2011 CS Q13: Circuit not equivalent to a 2-input XNOR gate

## Question

Which one of the following circuits is **NOT** equivalent to a 2-input XNOR (exclusive NOR) gate?

![Four gate-level circuits, each with two inputs and one output. (A) An XOR gate followed by an inverter. (B) Each input goes through its own inverter into an XOR gate, then an inverter on the output. (C) The top input goes through an inverter, then both inputs enter an XOR gate with no output inverter. (D) The inputs feed an AND gate (one input inverted) followed by an inverter, and an OR gate, whose outputs go to an AND gate followed by an inverter.](../../assets/2011/set1-q13.png)

Options are the four circuits (A) to (D) in the figure.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write the inputs as $a$ and $b$. $\text{XNOR}(a, b) = \overline{a \oplus b}$.

- **(A)** $\overline{a \oplus b}$: XNOR.
- **(B)** $\overline{\bar a \oplus \bar b}$. Inverting both inputs of an XOR does not change it ($\bar a \oplus \bar b = a \oplus b$), so this is $\overline{a \oplus b}$: XNOR.
- **(C)** $\bar a \oplus b = \overline{a \oplus b}$: XNOR (inverting one input of an XOR gives XNOR).
- **(D)** Read the wiring: $b$ is inverted to $\bar b$; $X = \overline{a \cdot \bar b}$ (AND then inverter); $Y = a + \bar b$ (OR). The output is $\overline{X \cdot Y}$.

$$\overline{X Y} = \bar X + \bar Y = a\bar b + \overline{a + \bar b} = a \bar b + \bar a b = a \oplus b$$

This is **XOR**, the complement of XNOR. So (D) is the circuit that is not equivalent.

**Code check:** a truth-table simulation of the four circuits gave outputs $1,0,0,1$ for (A), (B), (C) (XNOR) and $0,1,1,0$ for (D).

**Key idea:** XOR/XNOR identities: inverting one input, or the output, toggles XOR to XNOR; inverting both inputs changes nothing.

</details>
