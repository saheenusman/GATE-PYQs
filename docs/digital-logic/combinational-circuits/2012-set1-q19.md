# 2012 CS Q19: ROM size for a 4-bit multiplier

## Question

The amount of ROM needed to implement a 4 bit multiplier is

- (A) 64 bits
- (B) 128 bits
- (C) 1 Kbits
- (D) 2 Kbits

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A $4 \times 4$ multiplier has two 4-bit inputs, so $8$ address bits and $2^8 = 256$ words. The largest product is $15 \times 15 = 225 < 256$, so each word needs $8$ bits.

$$256 \times 8 = 2048 \text{ bits} = 2 \text{ Kbits}.$$

This is (D).

- (A) $64 = 2^6$ and (B) $128 = 2^7$ are too small to hold all 256 products.
- (C) $1\text{ Kbit}$ would be $256 \times 4$, too few output bits for a product up to $225$.

**Code check:** $2^8 \times 8 = 2048$ bits.

**Key idea:** a ROM-based combinational function has $2^{\text{inputs}}$ words, each as wide as the output.

</details>
