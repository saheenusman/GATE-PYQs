# 2007 CS Q8: Building a 6-to-64 decoder from 3-to-8 decoders

## Question

How many 3-to-8 line decoders with an enable input are needed to construct a 6-to-64 line decoder without using any other logic gates?

- (A) 7
- (B) 8
- (C) 9
- (D) 10

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A 6-to-64 decoder has $64$ outputs. Each 3-to-8 decoder supplies $8$ outputs, so we need $64/8 = 8$ decoders in the output stage.

These eight must be enabled one at a time, according to the **top 3 input bits**. That selection is itself a 3-to-8 decoding, done by one more 3-to-8 decoder whose 8 outputs drive the 8 enable inputs. The low 3 bits go to the data inputs of all eight output decoders.

Total: $8 + 1 = 9$: (C).

- (A) 7 decoders give only 56 outputs.
- (B) 8 decoders give 64 outputs but nothing selects between them without extra gates.
- (D) 10 is more than needed.

**Key idea:** a larger decoder is built as a tree: one decoder on the high bits enabling a bank of decoders on the low bits.
