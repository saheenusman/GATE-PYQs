# 2007 CS Q32: Which expressions are not equivalent to f

## Question

Let $f(w,x,y,z) = \sum (0,4,5,7,8,9,13,15)$. Which of the following expressions are **NOT** equivalent to $f$?

- (P) $x'y'z' + w'xy' + wy'z + xz$
- (Q) $w'y'z' + wx'y' + xz$
- (R) $w'y'z' + wx'y' + xyz + xy'z$
- (S) $x'y'z' + wx'y' + w'y$

Options:

- (A) P only
- (B) Q and S
- (C) R and S
- (D) S only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Expand each expression into minterms ($w$ is the MSB):

| Expression | Minterms | Equal to $f$? |
|---|---|---|
| $f$ | 0, 4, 5, 7, 8, 9, 13, 15 | |
| P | 0, 4, 5, 7, 8, 9, 13, 15 | yes |
| Q | 0, 4, 5, 7, 8, 9, 13, 15 | yes |
| R | 0, 4, 5, 7, 8, 9, 13, 15 | yes |
| S | 0, 2, 3, 6, 7, 8, 9 | **no** |

S has extra minterms $2, 3, 6$ (from $w'y$) and misses $4, 5, 13, 15$. For example, $w=0,x=1,y=0,z=0$ (minterm 4) is in $f$, but S evaluates to $0$ there.

Only S is not equivalent: (D).

- (A) wrongly blames P; P is equivalent.
- (B) wrongly blames Q; Q is equivalent.
- (C) wrongly blames R; R is equivalent.

**Code check:** Python: evaluated each expression over all 16 inputs; P, Q and R give exactly the minterm set of $f$; S does not.

**Key idea:** to compare Boolean expressions, expand each to its minterm set; one mismatch is enough.
