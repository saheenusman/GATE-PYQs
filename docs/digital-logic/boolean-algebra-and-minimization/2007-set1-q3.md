# 2007 CS Q3: Number of Boolean functions of n variables

## Question

What is the maximum number of different Boolean functions involving $n$ Boolean variables?

- (A) $n^2$
- (B) $2^n$
- (C) $2^{2^n}$
- (D) $2^{n^2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A truth table over $n$ variables has $2^n$ rows. Each row's output can independently be $0$ or $1$, so there are
$$2^{(2^n)}$$
distinct functions: (C). (For $n = 2$ this gives $16$ functions.)

- (A) and (B) count rows or variables, not tables.
- (D) $2^{n^2}$ would be right only if the table had $n^2$ rows.

**Key idea:** a function is a choice of output for each of the $2^n$ input rows, giving $2^{2^n}$ functions.
