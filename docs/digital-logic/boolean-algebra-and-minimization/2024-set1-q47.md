# 2024 CS1 Q47: Properties of F = Σ(3,5,6,7)

## Question

Consider a Boolean expression given by $F(X,Y,Z) = \sum(3,5,6,7)$. Which of the following statements is/are CORRECT?

- (A) $F(X,Y,Z) = \prod(0,1,2,4)$
- (B) $F(X,Y,Z) = XY + YZ + XZ$
- (C) $F(X,Y,Z)$ is independent of input $Y$
- (D) $F(X,Y,Z)$ is independent of input $X$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Truth table** (minterm number $= 4X + 2Y + Z$):

| $m$ | $XYZ$ | $F$ |
|---|---|---|
| 0 | 000 | 0 |
| 1 | 001 | 0 |
| 2 | 010 | 0 |
| 3 | 011 | **1** |
| 4 | 100 | 0 |
| 5 | 101 | **1** |
| 6 | 110 | **1** |
| 7 | 111 | **1** |

- **(A) True.** $F$ is 0 exactly at $0,1,2,4$, so $F = \prod(0,1,2,4)$ (a product of maxterms).
- **(B) True.** $F = 1$ when at least two inputs are 1: $XY + YZ + XZ$ is the **majority** function. Its minterms are $011$ ($YZ$), $101$ ($XZ$), $110$ ($XY$), $111$ (all three) = $\sum(3,5,6,7)$ ✓.
- **(C) False.** Changing $Y$ changes $F$: $F(0,0,1) = 0$ but $F(0,1,1) = 1$.
- **(D) False.** Changing $X$ changes $F$: $F(0,1,0) = 0$ but $F(1,1,0) = 1$.

**Key idea:** the sum of minterms lists the 1s of the truth table, and the product of maxterms lists the 0s. The two forms are complements of each other.

</details>
