# 2015 CS1 Q43: Functional completeness of two three-variable functions

## Question

Consider the operations

$$f(X,Y,Z) = X'YZ + XY' + Y'Z' \quad\text{and}\quad g(X,Y,Z) = X'YZ + X'YZ' + XY.$$

Which one of the following is correct?

- (A) Both $\lbrace f \rbrace$ and $\lbrace g \rbrace$ are functionally complete
- (B) Only $\lbrace f \rbrace$ is functionally complete
- (C) Only $\lbrace g \rbrace$ is functionally complete
- (D) Neither $\lbrace f \rbrace$ nor $\lbrace g \rbrace$ is functionally complete

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Simplify $g$.** $g = X'YZ + X'YZ' + XY = X'Y(Z+Z') + XY = X'Y + XY = Y(X'+X) = Y$.

So $g$ just returns $Y$. Any circuit built only from $g$ computes a projection (a variable or constant-free copy of an input), so it can never produce NOT. **$\lbrace g\rbrace$ is not complete.**

**$f$ is complete.** Its truth table ($XYZ = 000, \dots, 111$) is $1,0,0,1,1,1,0,0$.

- NOT: $f(X,X,X)$ is $f(0,0,0)=1$ and $f(1,1,1)=0$, so $f(X,X,X) = X'$.
- Constant 0: $f(X,X,X') = X'XX' + XX' + X'X = 0$.
- Constant 1: $\text{NOT}(0) = 1$.
- AND: $f(X,1,Z) = X'Z$. Feeding $X'$ in place of $X$ gives $f(X',1,Z) = XZ$.

With NOT and AND available, every Boolean function can be built. **$\lbrace f\rbrace$ is complete.**

Only $f$: option (B).

**Code check:** a script testing Post's five criteria (0-preserving, 1-preserving, monotone, self-dual, linear) found $f$ fails all five (so it is complete), while $g$ satisfies all five.

**Key idea:** a single function is complete iff it escapes all five Post classes; $g = Y$ is a projection.

</details>
