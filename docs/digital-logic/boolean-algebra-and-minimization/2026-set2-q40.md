# 2026 CS2 Q40: Minimal SOP of a 4-variable function

## Question

Consider the following 4-variable Boolean function

$$F(A,B,C,D) = \sum m(0, 1, 2, 3, 8, 9, 10, 11)$$

Consider $A$ as MSB, $D$ as LSB. Which one of the following options represents the minimal sum of products form for the above function?

*Note:* $+$ is OR, $\cdot$ is AND, $'$ is NOT.

- (A) $A' + B' + C' + D'$
- (B) $B'$
- (C) $A' \cdot B' + A \cdot B$
- (D) $A'$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Write the minterms in binary** ($ABCD$):

| Minterms | $ABCD$ |
|---|---|
| 0, 1, 2, 3 | `00xx` |
| 8, 9, 10, 11 | `10xx` |

In every one of them $B = 0$. $A$, $C$ and $D$ take all 8 combinations, so $F = B'$.

**K-map:** rows $AB = 00$ and $10$ are all 1s, and they meet across the edge of the map, forming one 8-cell group: $B'$.

**Why the others fail:**

- (A) is true for all but one input combination, so it has too many 1s.
- (C) is true for $AB = 00$ and $11$. The $AB = 11$ rows (12 to 15) are not in $F$.
- (D) $A'$ would include minterms 4 to 7, which are not in $F$.

**Key idea:** a group of $2^k$ cells removes $k$ variables. Eight cells remove three, leaving one literal.

</details>
