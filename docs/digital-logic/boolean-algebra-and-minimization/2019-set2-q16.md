# 2019 CS2 Q16: Which XOR identity is not valid

## Question

Which one of the following is NOT a valid identity?

- (A) $(x \oplus y) \oplus z = x \oplus (y \oplus z)$
- (B) $(x + y) \oplus z = x \oplus (y + z)$
- (C) $x \oplus y = x + y$, if $xy = 0$
- (D) $x \oplus y = (xy + x'y')'$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Here $\oplus$ is XOR and $+$ is OR.

- **(A)** XOR is associative. Valid.
- **(B)** Try $x=0,\ y=1,\ z=1$. Left side: $(0+1)\oplus 1 = 1 \oplus 1 = 0$. Right side: $0 \oplus (1+1) = 0 \oplus 1 = 1$. They differ, so **B is not valid**.
- **(C)** XOR and OR differ only when both inputs are 1. If $xy = 0$ that case is excluded. Valid.
- **(D)** $xy + x'y'$ is XNOR, so its complement is XOR. Valid.

**Code check:** a truth-table run marks only (B) as invalid, with counterexamples $(0,1,1)$ and $(1,1,0)$.

**Key idea:** disprove an identity with one assignment where the two sides differ.

</details>
