# 2016 CS2 Q8: Identity that always holds when four variables XOR to zero

## Question

Let $x_1 \oplus x_2 \oplus x_3 \oplus x_4 = 0$ where $x_1, x_2, x_3, x_4$ are Boolean variables, and $\oplus$ is the XOR operator. Which one of the following must always be TRUE?

- (A) $x_1 x_2 x_3 x_4 = 0$
- (B) $x_1 x_3 + x_2 = 0$
- (C) $\bar{x}_1 \oplus \bar{x}_3 = \bar{x}_2 \oplus \bar{x}_4$
- (D) $x_1 + x_2 + x_3 + x_4 = 0$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

From $x_1 \oplus x_2 \oplus x_3 \oplus x_4 = 0$ we get $x_1 \oplus x_3 = x_2 \oplus x_4$.

Complementing *both* inputs of an XOR leaves it unchanged: $\bar{x}_1 \oplus \bar{x}_3 = x_1 \oplus x_3$ and $\bar{x}_2 \oplus \bar{x}_4 = x_2 \oplus x_4$. So

$$\bar{x}_1 \oplus \bar{x}_3 = \bar{x}_2 \oplus \bar{x}_4$$

always holds: **(C)**.

**Why the others fail** (take $x = 1111$, which has XOR $0$, and $x = 1100$):

- (A) $x_1x_2x_3x_4 = 1$ at $1111$, not $0$.
- (B) at $1100$: $x_1 x_3 + x_2 = 0 + 1 = 1$, not $0$.
- (D) $x_1 + x_2 + x_3 + x_4 = 1$ at $1111$, not $0$.

**Code check:** over all 16 inputs, only (C) held for every input with XOR $= 0$.

**Key idea:** XOR $= 0$ gives $x_1 \oplus x_3 = x_2 \oplus x_4$, and complementing both inputs of XOR changes nothing.

</details>
