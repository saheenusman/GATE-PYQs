# 2025 CS1 Q42: Minimised sum of products for F = sigma(0,2,4,8,10,11,12)

## Question

Consider the following four variable Boolean function in sum-of-product form

$$F(b_3, b_2, b_1, b_0) = \sum(0, 2, 4, 8, 10, 11, 12).$$

where the value of the function is computed by considering $b_3 b_2 b_1 b_0$ as a 4-bit binary number, where $b_3$ denotes the most significant bit and $b_0$ denotes the least significant bit. Note that there are no don't care terms. Which ONE of the following options is the CORRECT minimized Boolean expression for $F$?

- (A) $\bar b_1 \bar b_0 + \bar b_2 \bar b_0 + b_1 \bar b_2 b_3$
- (B) $\bar b_1 \bar b_0 + \bar b_2 \bar b_0$
- (C) $\bar b_2 \bar b_0 + b_1 b_2 b_3$
- (D) $\bar b_0 \bar b_2 + \bar b_3$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Place the minterms on a Karnaugh map (rows $b_3b_2$, columns $b_1b_0$ in Gray order):

| $b_3b_2 \backslash b_1b_0$ | 00 | 01 | 11 | 10 |
|---|---|---|---|---|
| 00 | 1 (m0) | 0 | 0 | 1 (m2) |
| 01 | 1 (m4) | 0 | 0 | 0 |
| 11 | 1 (m12) | 0 | 0 | 0 |
| 10 | 1 (m8) | 0 | 1 (m11) | 1 (m10) |

Groups:

- Column $b_1b_0 = 00$, all four rows (m0, m4, m12, m8): $\bar b_1 \bar b_0$.
- The four corners (m0, m2, m8, m10): $\bar b_2 \bar b_0$.
- m10 and m11: $b_3 \bar b_2 b_1$.

$$F = \bar b_1 \bar b_0 + \bar b_2 \bar b_0 + b_3 \bar b_2 b_1.$$

Every minterm is covered: $\lbrace 0,4,8,12\rbrace \cup \lbrace 0,2,8,10\rbrace \cup \lbrace 10,11\rbrace = \lbrace 0,2,4,8,10,11,12\rbrace$.

| Option | Problem |
|---|---|
| B | Does not cover m11 |
| C | The term $b_1b_2b_3$ covers m14 and m15, which are not in $F$, and m11 is missed |
| D | $\bar b_3$ covers m1, m3, m5 and others that are not in $F$ |

I evaluated all four options on all 16 inputs: only (A) equals $F$.

**Key idea:** cover every 1 with the largest possible groups (4-cell groups here) and add the smallest group needed for the rest (m10, m11).

</details>
