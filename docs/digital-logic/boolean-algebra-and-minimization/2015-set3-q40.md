# 2015 CS3 Q40: Canonical forms of F = P' + QR

## Question

Given the function $F = P' + QR$, where $F$ is a function in three Boolean variables $P$, $Q$ and $R$ and $P' = \,!P$, consider the following statements.

- (S1) $F = \sum(4, 5, 6)$
- (S2) $F = \sum(0, 1, 2, 3, 7)$
- (S3) $F = \prod(4, 5, 6)$
- (S4) $F = \prod(0, 1, 2, 3, 7)$

Which of the following is true?

- (A) (S1) False, (S2) True, (S3) True, (S4) False
- (B) (S1) True, (S2) False, (S3) False, (S4) True
- (C) (S1) False, (S2) False, (S3) True, (S4) True
- (D) (S1) True, (S2) True, (S3) False, (S4) False

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Number the rows by $PQR$ as a 3-bit number ($P$ is the high bit).

- $P' = 1$ for $P = 0$: minterms 0, 1, 2, 3.
- $QR = 1$ for $Q = R = 1$: minterms 3, 7.

$$F = \sum(0, 1, 2, 3, 7)$$

$F = 0$ on the rest, 4, 5, 6. A product-of-maxterms form lists the rows where $F = 0$:

$$F = \prod(4, 5, 6)$$

| Statement | Claim | Truth |
|---|---|---|
| S1 | $\sum(4,5,6)$ | False (these are the zeros) |
| S2 | $\sum(0,1,2,3,7)$ | **True** |
| S3 | $\prod(4,5,6)$ | **True** |
| S4 | $\prod(0,1,2,3,7)$ | False (these are the ones) |

Option (A).

**Code check:** evaluating $F$ on all 8 inputs gives ones at 0, 1, 2, 3, 7 and zeros at 4, 5, 6.

**Key idea:** $\sum$ lists where $F = 1$ (minterms). $\prod$ lists where $F = 0$ (maxterms).

</details>
