# 2025 CS2 Q50: Which Boolean identities are correct

## Question

Which of the following Boolean algebraic equation(s) is/are CORRECT?

- (A) $\bar A B C + A\bar B\bar C + \bar A\bar B\bar C + A\bar B C + ABC = BC + \bar B\bar C + \bar A\bar B$
- (B) $AB + \bar A C + BC = AB + \bar A C$
- (C) $(A + C)(\bar A + B) = AB + \bar A C$
- (D) $\overline{(A + \bar B + \bar D)(C + D)(\bar A + C + D)(A + B + \bar D)} = \bar A D + \bar C\bar D$

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) False.** Left side minterms ($ABC$ as a binary number): $\bar ABC = 3$, $A\bar B\bar C = 4$, $\bar A\bar B\bar C = 0$, $A\bar B C = 5$, $ABC = 7$. So the left side is $\lbrace 0,3,4,5,7\rbrace$. Right side: $BC = \lbrace 3,7\rbrace$, $\bar B\bar C = \lbrace 0,4\rbrace$, $\bar A\bar B = \lbrace 0,1\rbrace$, giving $\lbrace 0,1,3,4,7\rbrace$. They differ (5 versus 1).

**(B) True.** This is the **consensus theorem**: $AB + \bar AC + BC = AB + \bar AC$.

**(C) True.** Expand: $(A + C)(\bar A + B) = A\bar A + AB + \bar AC + BC = AB + \bar AC + BC$, and $BC$ is redundant by consensus, giving $AB + \bar AC$.

**(D) True.** Apply De Morgan to the complement of the product of sums:

$$\overline{(A + \bar B + \bar D)(C + D)(\bar A + C + D)(A + B + \bar D)} = \bar A B D + \bar C\bar D + A\bar C\bar D + \bar A\bar B D.$$

Group: $\bar A D (B + \bar B) + \bar C\bar D(1 + A) = \bar A D + \bar C\bar D$.

I verified all four equations on every input assignment: (B), (C) and (D) hold, (A) fails.

**Key idea:** use the consensus theorem, expand products of sums, and apply De Morgan's law to a complemented product of sums.

</details>
