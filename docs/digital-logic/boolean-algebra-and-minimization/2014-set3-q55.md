# 2014 CS3 Q55: Simplifying a nested XOR expression

## Question

Let $\oplus$ denote the Exclusive OR (XOR) operation. Let '1' and '0' denote the binary constants. Consider the following Boolean expression for $F$ over two variables $P$ and $Q$:

$$F(P,Q) = \big((1 \oplus P) \oplus (P \oplus Q)\big) \oplus \big((P \oplus Q) \oplus (Q \oplus 0)\big)$$

The equivalent expression for $F$ is

- (A) $P + Q$
- (B) $\overline{P + Q}$
- (C) $P \oplus Q$
- (D) $\overline{P \oplus Q}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

XOR is associative and commutative, $x \oplus x = 0$, $x \oplus 0 = x$ and $1 \oplus x = \bar{x}$.

- Left bracket: $(1 \oplus P) \oplus (P \oplus Q) = 1 \oplus (P \oplus P) \oplus Q = 1 \oplus Q = \bar{Q}$.
- Right bracket: $(P \oplus Q) \oplus (Q \oplus 0) = P \oplus (Q \oplus Q) = P$.

$$F = \bar{Q} \oplus P = \overline{P \oplus Q}.$$

That is the XNOR: **D**.

**Code check:** a truth table over all 4 inputs confirms that $F$ equals $1 \oplus (P \oplus Q)$.

**Key idea:** cancel repeated terms in a chain of XORs ($x \oplus x = 0$) and use $1 \oplus x = \bar{x}$.

</details>
