# 2009 CS Q6: Minimum number of 2-input NOR gates for AB + C

## Question

What is the minimum number of gates required to implement the Boolean function $(AB + C)$ if we have to use only 2-input NOR gates?

- (A) 2
- (B) 3
- (C) 4
- (D) 5

<details class="success" markdown="1">
<summary>Answer</summary>

**B** (my answer; the supplied key leaves Q6 blank)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Official key:** the key table in the supplied PDF has no entry for Q6, so I cannot check against it. The answer below is my own derivation.

By the distributive law,

$$AB + C = (A + C)(B + C).$$

A NOR gate gives the complement of an OR, so

- $x = \overline{A + C} = \text{NOR}(A, C)$
- $y = \overline{B + C} = \text{NOR}(B, C)$
- $\text{NOR}(x, y) = \overline{x + y} = (A + C)(B + C) = AB + C.$

That is **3 gates**. No two-gate circuit works, so the minimum is $3$: (B).

- (A) $2$ gates are not enough (checked exhaustively, see below).
- (C) $4$ is not the minimum, since $3$ works.
- (D) $5$ is what the direct translation costs: two inverters for $\bar A$ and $\bar B$, one NOR for $AB$, one NOR with $C$, and one inverter at the end. It is correct but not minimal.

**Status note:** marked `unverified` because the key gives no answer to compare with. Checked by program: an exhaustive search over all networks of $2$-input NOR gates (inputs $A, B, C$ available only in true form) found no circuit for $AB + C$ with $1$ or $2$ gates and found one with $3$. The circuit $\text{NOR}(\text{NOR}(A,C), \text{NOR}(B,C))$ was confirmed to equal $AB + C$ on all $8$ input combinations.

**Key idea:** rewrite the function in product-of-sums form, $(A+C)(B+C)$; NOR-NOR then implements it with no inverters.
