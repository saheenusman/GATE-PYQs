# 2011 CS Q14: Simplified SOP of a product of three sums

## Question

The simplified SOP (Sum of Product) form of the Boolean expression $(P + \bar Q + \bar R) \cdot (P + \bar Q + R) \cdot (P + Q + \bar R)$ is

- (A) $(\bar P \cdot Q + \bar R)$
- (B) $(P + \bar Q \cdot \bar R)$
- (C) $(\bar P \cdot Q + R)$
- (D) $(P \cdot Q + R)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Combine the first two factors, which differ only in $R$:

$$(P + \bar Q + \bar R)(P + \bar Q + R) = P + \bar Q$$

Now multiply by the third factor and use $P + XY = (P + X)(P + Y)$:

$$(P + \bar Q)(P + Q + \bar R) = P + \bar Q (Q + \bar R) = P + \bar Q \bar R$$

So the result is $P + \bar Q \bar R$: (B).

**Check by zeros.** Each factor is $0$ for exactly one input: $(P,Q,R) = 011$, $010$ and $001$. So $f = 0$ only on these three rows and $f = 1$ on $000, 100, 101, 110, 111$. That is $P$ (four rows) plus $000$, i.e. $P + \bar Q \bar R$.

- (A) $\bar P Q + \bar R$ gives $1$ on $010$, where $f = 0$.
- (C) $\bar P Q + R$ gives $0$ on $000$, where $f = 1$.
- (D) $PQ + R$ gives $0$ on $100$, where $f = 1$.

**Code check:** a truth table over all eight inputs matched $P + \bar Q \bar R$ and none of the other three options.

**Key idea:** a product of sums is $0$ only on the rows where some factor is $0$; list those rows and read off the SOP.

</details>
