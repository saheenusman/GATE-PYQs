# 2014 CS2 Q6: Number of self-dual Boolean functions of n variables

## Question

The dual of a Boolean function $F(x_1, x_2, \ldots, x_n, +, \cdot, ')$, written as $F^D$, is the same expression as that of $F$ with $+$ and $\cdot$ swapped. $F$ is said to be self-dual if $F = F^D$. The number of self-dual functions with $n$ Boolean variables is

- (A) $2^n$
- (B) $2^{n-1}$
- (C) $2^{2^n}$
- (D) $2^{2^{n-1}}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$F^D(x_1, \ldots, x_n) = \overline{F(\bar{x}_1, \ldots, \bar{x}_n)}$. So $F$ is self-dual iff

$$F(\bar{x}) = \overline{F(x)} \quad \text{for every input } x.$$

The $2^n$ input combinations pair up as $x$ and its complement $\bar{x}$: $2^{n-1}$ pairs. In each pair the two outputs must be opposite, so choosing $F(x)$ fixes $F(\bar{x})$. Each pair has 2 choices:

$$2^{2^{n-1}}$$

**Code check:** enumerating all functions gives 2, 4, 16 self-dual functions for $n = 1, 2, 3$, equal to $2^{2^{n-1}}$.

- (A), (B) count far too few.
- (C) $2^{2^n}$ is the number of *all* functions.

**Key idea:** a self-dual function is fixed by its values on half the inputs.

</details>
