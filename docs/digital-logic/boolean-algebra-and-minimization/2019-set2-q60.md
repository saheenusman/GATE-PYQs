# 2019 CS2 Q60: Fewest 2-input NOR gates for a 4-variable function

## Question

What is the minimum number of 2-input NOR gates required to implement a 4-variable function expressed in sum-of-minterms form as $f = \Sigma(0, 2, 5, 7, 8, 10, 13, 15)$? Assume that all the inputs and their complements are available. Answer: ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Simplify.** Label the variables $A,B,C,D$ with $D$ as the least significant bit.

| Group | Minterms | Term |
|---|---|---|
| $B'D'$ | 0, 2, 8, 10 | $B'D'$ |
| $BD$ | 5, 7, 13, 15 | $BD$ |

So $f = B'D' + BD$, which is **XNOR of $B$ and $D$**.

**NOR-only form.** Write $f$ as a product of sums:

$$f = (B' + D)(B + D').$$

By De Morgan, $XY = \big(X' + Y'\big)'$. With $X = B' + D$ and $Y = B + D'$:

$$f = \Big( (B'+D)' + (B+D')' \Big)'.$$

| Gate | Inputs | Output |
|---|---|---|
| $g_1$ | $B',\ D$ | $(B' + D)'$ |
| $g_2$ | $B,\ D'$ | $(B + D')'$ |
| $g_3$ | $g_1,\ g_2$ | $f$ |

That is **3 gates**. The complements $B'$ and $D'$ are given as inputs.

**Why not fewer.** The code searched all circuits of 0, 1 and 2 NOR gates built from the 8 available signals ($A,B,C,D$ and complements). None produces $f$. The shortest circuit has 3 gates.

**Key idea:** reduce to the XNOR, then use its product-of-sums form, which is NOR of two NORs.

</details>
