# 2017 CS2 Q27: Which Boolean identity is incorrect

## Question

If $w, x, y, z$ are Boolean variables, then which one of the following is INCORRECT?

- (A) $wx + w(x+y) + x(x+y) = x + wy$
- (B) $\overline{w\bar{x}(y+\bar{z})} + \bar{w}x = \bar{w} + x + \bar{y}z$
- (C) $\big(w\bar{x}(y + x\bar{z}) + \bar{w}\bar{x}\big)\,y = x\bar{y}$
- (D) $(w+y)(wxy + wyz) = wxy + wyz$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) Correct.** $wx + w(x+y) + x(x+y) = wx + wx + wy + x + xy$. Since $x$ absorbs $wx$ and $xy$, this is $x + wy$.

**(B) Correct.** By De Morgan, $\overline{w\bar{x}(y+\bar{z})} = \bar{w} + x + \overline{(y+\bar z)} = \bar{w} + x + \bar{y}z$. Adding $\bar{w}x$ changes nothing because $\bar w$ already covers it.

**(C) INCORRECT.** Inside the bracket, $w\bar{x}\,x\bar{z} = 0$ (since $\bar x x = 0$), so

$$w\bar{x}(y + x\bar{z}) + \bar{w}\bar{x} = \bar{x}(wy + \bar{w}).$$

Multiply by $y$: $\bar{x}\,(wy + \bar{w}y) = \bar{x}\,y\,(w + \bar w) = \bar{x}y$.

So the left side is $\bar{x}y$, not $x\bar{y}$. Counterexample: $x=0$, $y=1$ gives LHS $=1$ but RHS $=0$.

**(D) Correct.** $wxy + wyz = wy(x+z)$, and $(w+y)\cdot wy = wy$ (absorption), so $(w+y)(wxy+wyz) = wy(x+z) = wxy + wyz$.

So the incorrect statement is **(C)**.

**Code check:** a 16-row truth table for each option: (A), (B), (D) hold on all rows; (C) fails, and its left side equals $\bar x y$ on every row.

**Key idea:** simplify with $x\bar{x} = 0$ and absorption before comparing the two sides.

</details>
