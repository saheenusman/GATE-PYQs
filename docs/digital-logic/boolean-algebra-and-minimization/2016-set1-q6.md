# 2016 CS1 Q6: Boolean operator # defined by four properties

## Question

Consider the Boolean operator $\#$ with the following properties: $x \# 0 = x$, $x \# 1 = \bar{x}$, $x \# x = 0$ and $x \# \bar{x} = 1$. Then $x \# y$ is equivalent to

- (A) $x\bar{y} + \bar{x}y$
- (B) $x\bar{y} + \bar{x}\bar{y}$
- (C) $\bar{x}y + xy$
- (D) $xy + \bar{x}\bar{y}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The four properties are exactly the behaviour of XOR: $x \oplus 0 = x$, $x \oplus 1 = \bar{x}$, $x \oplus x = 0$, $x \oplus \bar{x} = 1$. So $x \# y = x\bar{y} + \bar{x}y$.

**Check each option at $y = 0$** (the property $x \# 0 = x$ must hold):

| Option | Expression | At $y=0$ | Equals $x$? |
|---|---|---|---|
| (A) | $x\bar{y} + \bar{x}y$ | $x$ | yes |
| (B) | $x\bar{y} + \bar{x}\bar{y}$ | $x + \bar{x} = 1$ | no |
| (C) | $\bar{x}y + xy$ | $0$ | no |
| (D) | $xy + \bar{x}\bar{y}$ | $\bar{x}$ | no |

(A) also gives $\bar{x}$ at $y = 1$, and $0$ at $y = x$, matching all four properties.

**Code check:** a truth table over all four $(x, y)$ pairs matches (A) with XOR and no other option.

**Key idea:** recognise the identities as XOR and test options at $y = 0$.

</details>
