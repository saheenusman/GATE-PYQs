# 2015 CS3 Q62: Number of prime implicants of a 4-variable function

## Question

The total number of prime implicants of the function $f(w, x, y, z) = \sum(0, 2, 4, 5, 6, 10)$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write the minterms in binary ($wxyz$): $0000,\ 0010,\ 0100,\ 0101,\ 0110,\ 1010$.

**Pair up** cells that differ in one bit:

| Group | Cells | Implicant |
|---|---|---|
| $0, 2, 4, 6$ | $0000, 0010, 0100, 0110$ | $w'z'$ (written `0--0`) |
| $2, 10$ | $0010, 1010$ | $x'yz'$ (`-010`) |
| $4, 5$ | $0100, 0101$ | $w'xy'$ (`010-`) |

None of these three can be merged into a larger group, so each is a **prime implicant**. They are also all essential: minterm 5 is covered only by $w'xy'$, minterm 10 only by $x'yz'$, and minterm 0 only by $w'z'$.

**Answer: 3.**

**Code check:** a Quine–McCluskey run on these six minterms returns exactly `-010`, `0--0` and `010-`.

**Key idea:** a prime implicant is a group that cannot grow any larger. Find them all by combining cells differing in one bit.

</details>
