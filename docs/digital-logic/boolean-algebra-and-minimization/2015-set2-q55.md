# 2015 CS2 Q55: Number of minterms in a complemented expression

## Question

The number of min-terms after minimizing the following Boolean expression is ________

$$[D' + AB' + A'C + AC'D + A'C'D]'$$

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The complement of a sum is the product of the complements (De Morgan):

$$D \cdot (A' + B) \cdot (A + C') \cdot (A' + C + D') \cdot (A + C + D')$$

For this product to be 1:

- $D = 1$, from the first factor.
- Then the last two factors become $(A' + C)$ and $(A + C)$.
- With $(A + C')$: if $A = 0$ we need $C' = 1$ and $C = 1$ together, which is impossible. So $A = 1$.
- $A = 1$ gives $B = 1$ from $(A' + B)$ and $C = 1$ from $(A' + C)$.

The only satisfying input is $A = B = C = D = 1$. The expression minimises to $ABCD$, a single minterm ($m_{15}$).

**Answer: 1.**

**Code check:** evaluating the complement on all 16 inputs gives a 1 only at $(1,1,1,1)$.

**Key idea:** expand the complement with De Morgan and look for the inputs that make every factor 1.

</details>
