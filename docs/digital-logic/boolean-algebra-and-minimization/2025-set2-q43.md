# 2025 CS2 Q43: Expressions equal to a four-variable K-map

## Question

Given the following Karnaugh Map for a Boolean function $F(w,x,y,z)$:

| $wx \backslash yz$ | | | | |
|---|---|---|---|---|
| (row 1) | 1 | 0 | 0 | 1 |
| (row 2) | 0 | 1 | 1 | 0 |
| (row 3) | 0 | 1 | 1 | 0 |
| (row 4) | 1 | 0 | 0 | 1 |

Which one or more of the following Boolean expression(s) represent(s) $F$?

- (A) $\bar w\bar x\bar y\bar z + w\bar x\bar y\bar z + \bar w\bar x y\bar z + w\bar x y\bar z + xz$
- (B) $\bar w\bar x\bar y\bar z + \bar w\bar x y\bar z + w\bar x y z + xz$
- (C) $\bar w\bar x\bar y\bar z + w\bar x\bar y\bar z + w\bar x\bar y z + xz$
- (D) $\bar x\bar z + xz$

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Assumption.** The printed map shows the labels $wx$ and $yz$ but not the bit patterns of the rows and columns. I take the usual Gray-code order, $00, 01, 11, 10$, for both.

Reading the 1s:

| Row $wx$ | Column $yz$ with a 1 | Minterms |
|---|---|---|
| 00 | 00, 10 | 0, 2 |
| 01 | 01, 11 | 5, 7 |
| 11 | 01, 11 | 13, 15 |
| 10 | 00, 10 | 8, 10 |

$$F = \sum(0, 2, 5, 7, 8, 10, 13, 15).$$

- The columns $xz$ pattern: the four cells with $x=1, z=1$ are minterms 5, 7, 13, 15: **$xz$**.
- The four cells with $x=0, z=0$ are 0, 2, 8, 10: **$\bar x \bar z$**.

So $F = \bar x \bar z + xz$ (an XNOR of $x$ and $z$): option **D**.

| Option | Check | Verdict |
|---|---|---|
| **A** | $\bar w\bar x\bar y\bar z = 0$, $w\bar x\bar y\bar z = 8$, $\bar w\bar x y\bar z = 2$, $w\bar x y\bar z = 10$, plus $xz$: all of $\bar x\bar z$ and $xz$ | **Equals $F$** |
| B | $w\bar x y z$ is minterm 11, which is not in $F$, and minterms 8 and 10 are missing | Wrong |
| C | $w\bar x\bar y z$ is minterm 9, which is not in $F$, and minterm 2 is missing | Wrong |
| **D** | $\bar x\bar z + xz$ | **Equals $F$** |

I checked all four expressions against the map for every input: only (A) and (D) match.

**Key idea:** with the map read as minterms, test each expression term by term against the 1s.

</details>
