# 2025 CS1 Q24: Identities with the 3-input majority function

## Question

Let $X$ be a 3-variable Boolean function that produces output as '1' when at least two of the input variables are '1'. Which of the following statement(s) is/are CORRECT, where $a, b, c, d, e$ are Boolean variables?

- (A) $X(a, b, X(c, d, e)) = X(X(a, b, c), d, e)$
- (B) $X(a, b, X(a, b, c)) = X(a, b, c)$
- (C) $X(a, b, X(a, c, d)) = (X(a, b, a)\ \text{AND}\ X(c, d, c))$
- (D) $X(a, b, c) = X(a, X(a, b, c), X(a, c, c))$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$X$ is the **majority** function. Two facts help:

- $X(p, p, q) = p$ (two equal inputs decide the output).
- If $p \ne q$, then $X(p, q, r) = r$ (the third input breaks the tie).

**(B) True.** If $a = b$, both sides equal $a$. If $a \ne b$, then $X(a,b,y) = y$, so the left side is $X(a,b,c)$.

**(D) True.** $X(a,c,c) = c$, so the right side is $X(a, X(a,b,c), c)$. If $a = c$ both sides are $a$. If $a \ne c$, the tie is broken by the middle argument: $X(a,y,c) = y = X(a,b,c)$.

**(A) False.** Take $a=b=c=0$, $d=e=1$. Left: $X(c,d,e) = X(0,1,1) = 1$, then $X(0,0,1) = 0$. Right: $X(a,b,c) = 0$, then $X(0,1,1) = 1$. So $0 \ne 1$.

**(C) False.** Take $a=0$, $b=c=d=1$. Left: $X(a,c,d) = X(0,1,1) = 1$, then $X(0,1,1) = 1$. Right: $X(a,b,a) = X(0,1,0) = 0$, so the AND is $0$. So $1 \ne 0$.

I also tested all 32 input combinations by program: (B) and (D) hold for all, and (A) and (C) fail.

**Key idea:** majority of $(p,p,q)$ is $p$, and the tie-break rule makes many identities easy to check by cases.

</details>
