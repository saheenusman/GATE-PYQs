# 2012 CS Q6: Boolean function from a truth table

## Question

The truth table

| X | Y | f(X, Y) |
|---|---|---|
| 0 | 0 | 0 |
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| 1 | 1 | 1 |

represents the Boolean function

- (A) $X$
- (B) $X + Y$
- (C) $X \oplus Y$
- (D) $Y$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$f$ is $0$ when $X = 0$ and $1$ when $X = 1$, whatever $Y$ is. So $f = X$.

- (B) $X + Y$ would give $1$ at $(0,1)$; the table has $0$.
- (C) $X \oplus Y$ would give $1$ at $(0,1)$ and $0$ at $(1,1)$; both differ from the table.
- (D) $Y$ would give $0$ at $(1,0)$; the table has $1$.

**Key idea:** if the output ignores a variable in every row pair, that variable is absent from the function.

</details>
