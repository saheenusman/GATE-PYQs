# 2007 CS Q9: Which variables does the function depend on

## Question

Consider the following Boolean function of four variables:

$$f(w,x,y,z) = \sum (1,3,4,6,9,11,12,14)$$

The function is

- (A) independent of one variable.
- (B) independent of two variables.
- (C) independent of three variables.
- (D) dependent on all the variables.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write the minterms with $w$ as the MSB and $z$ as the LSB:

| Minterm | $wxyz$ | $x$ | $z$ |
|---|---|---|---|
| 1, 3, 9, 11 | $0001, 0011, 1001, 1011$ | 0 | 1 |
| 4, 6, 12, 14 | $0100, 0110, 1100, 1110$ | 1 | 0 |

Every minterm has $x \ne z$, and all four combinations of $(w, y)$ appear in each group. So
$$f = x'z + xz' = x \oplus z.$$

$f$ does not depend on $w$ or $y$: independent of **two** variables: (B).

- (A) is wrong: both $w$ and $y$ are redundant, not just one.
- (C) is wrong: $x$ and $z$ both matter.
- (D) is wrong: $w$ and $y$ do not matter.

**Code check:** Python: flipping $w$ or $y$ never changes $f$ over all 16 inputs; flipping $x$ or $z$ does. Also $f = x \oplus z$ on all 16 inputs.

**Key idea:** a variable is redundant if flipping it never changes the output; here $f = x \oplus z$.
