# 2018 CS Q14: Which XOR/XNOR identity is not correct

## Question

Let $\oplus$ and $\odot$ denote the Exclusive OR and Exclusive NOR operations, respectively. Which one of the following is NOT CORRECT?

- (A) $\overline{P \oplus Q} = P \odot Q$
- (B) $\bar{P} \oplus Q = P \odot Q$
- (C) $\bar{P} \oplus \bar{Q} = P \oplus Q$
- (D) $(P \oplus \bar{P}) \oplus Q = (P \odot \bar{P}) \odot \bar{Q}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Facts used:** $P\odot Q = \overline{P\oplus Q}$. Complementing one input of XOR complements its output. Complementing both inputs changes nothing.

- **A:** this is the definition of XNOR. Correct.
- **B:** $\bar P\oplus Q = \overline{P\oplus Q} = P\odot Q$. Correct.
- **C:** two complements cancel, so $\bar P\oplus\bar Q = P\oplus Q$. Correct.
- **D:** left side: $P\oplus\bar P = 1$, and $1\oplus Q = \bar Q$. Right side: $P\odot\bar P = 0$ (they always differ), and $0\odot\bar Q = \overline{0\oplus\bar Q} = Q$. So the left side is $\bar Q$ and the right side is $Q$. **Not equal.**

**Code check:** a truth table over all four $(P,Q)$ pairs confirmed A, B, C hold always and D never holds.

**Key idea:** $x \oplus \bar x = 1$ and $x\odot\bar x = 0$, and XNOR is the complement of XOR.

</details>
