# 2015 CS3 Q16: Associativity and commutativity of the # operator

## Question

Let $\#$ be a binary operator defined as

$$X \# Y = X' + Y'$$

where $X$ and $Y$ are Boolean variables. Consider the following two statements.

- (S1) $(P \# Q) \# R = P \# (Q \# R)$
- (S2) $Q \# R = R \# Q$

Which of the following is/are true for the Boolean variables $P$, $Q$ and $R$?

- (A) Only S1 is true
- (B) Only S2 is true
- (C) Both S1 and S2 are true
- (D) Neither S1 nor S2 is true

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$X \# Y = X' + Y'$ is the NAND operation.

**S2 is true.** $Q \# R = Q' + R'$ and $R \# Q = R' + Q'$. OR is commutative, so they are equal.

**S1 is false.** Try $P = 1,\ Q = 0,\ R = 0$:

| | Value |
|---|---|
| $P \# Q = 0 + 1$ | 1 |
| $(P \# Q) \# R = 1 \# 0 = 0 + 1$ | **1** |
| $Q \# R = 1 + 1$ | 1 |
| $P \# (Q \# R) = 1 \# 1 = 0 + 0$ | **0** |

The two sides differ. NAND is not associative.

Only S2 is true: option (B).

**Code check:** a truth table over all 8 inputs finds S1 failing and S2 always holding.

**Key idea:** NAND is commutative but not associative.

</details>
