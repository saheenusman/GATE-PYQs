# 2010 CS Q6: Minterm expansion of PQ + QR' + PR'

## Question

The minterm expansion of $f(P, Q, R) = PQ + Q\overline{R} + P\overline{R}$ is

- (A) $m_2 + m_4 + m_6 + m_7$
- (B) $m_0 + m_1 + m_3 + m_5$
- (C) $m_0 + m_1 + m_6 + m_7$
- (D) $m_2 + m_3 + m_4 + m_5$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Number minterms by the bits $PQR$ with $P$ as the most significant bit. Expand each product term:

- $PQ$ is true for $PQR = 110, 111$, i.e. $m_6, m_7$.
- $Q\overline{R}$ is true for $010, 110$, i.e. $m_2, m_6$.
- $P\overline{R}$ is true for $100, 110$, i.e. $m_4, m_6$.

Union: $m_2 + m_4 + m_6 + m_7$: (A).

- (B), (C): $m_0$ ($PQR = 000$) makes every term $0$, so $m_0$ is not in $f$.
- (B), (D): $m_3$ ($011$) gives $PQ = 0$, $Q\overline{R} = 0$ (as $R = 1$) and $P\overline{R} = 0$, so $m_3$ is not in $f$.

**Code check:** evaluating $f$ on all 8 inputs gave true exactly for $m_2, m_4, m_6, m_7$.

**Key idea:** expand each product term over the missing variables, then take the union of minterms.

</details>
