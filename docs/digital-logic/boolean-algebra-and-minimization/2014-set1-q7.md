# 2014 CS1 Q7: Minimal SOP of a four-variable expression

## Question

Consider the following Boolean expression for $F$:

$$F(P,Q,R,S) = PQ + \bar{P}QR + \bar{P}Q\bar{R}S$$

The minimal sum-of-products form of $F$ is

- (A) $PQ + QR + QS$
- (B) $P + Q + R + S$
- (C) $\bar{P} + \bar{Q} + \bar{R} + \bar{S}$
- (D) $\bar{P}R + \bar{P}\bar{R}S + P$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Factor out $Q$ and use the absorption identity $X + \bar{X}Y = X + Y$ twice:

$$F = Q\,(P + \bar{P}R + \bar{P}\bar{R}S) = Q\,(P + R + \bar{R}S) = Q\,(P + R + S)$$

$$F = PQ + QR + QS$$

**Code check:** `sympy.simplify_logic(F, 'dnf')` returns `(P & Q) | (Q & R) | (Q & S)`.

Every term has $Q$, so $F = 0$ whenever $Q = 0$. That rules out the rest:

- (B) is $1$ at $P=1, Q=0$, but $F = 0$ there.
- (C) is $1$ at $P=Q=R=S=0$, but $F=0$ there.
- (D) is $1$ at $P=1, Q=0$, but $F=0$ there.

**Key idea:** factor the common literal and apply $X + \bar{X}Y = X + Y$.

</details>
