# 2008 CS Q26: Simplifying a product of three Boolean sums

## Question

If $P, Q, R$ are Boolean variables, then

$$(P + \overline{Q})(P\overline{Q} + PR)(\overline{P}\,\overline{R} + \overline{Q})$$

simplifies to

- (A) $P.\overline{Q}$
- (B) $P.\overline{R}$
- (C) $P.\overline{Q} + R$
- (D) $P.\overline{R} + Q$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1.** $P\overline{Q} + PR = P(\overline{Q} + R)$.

**Step 2.** $(P + \overline{Q}) \cdot P(\overline{Q} + R) = P(\overline{Q} + R)$, because $P \cdot P = P$ and the extra $\overline{Q}$ term is already absorbed: $\overline{Q} \cdot P(\overline{Q} + R) = P\overline{Q}$, which is inside $P(\overline{Q} + R)$.

**Step 3.** Multiply by the last factor:

$$P(\overline{Q} + R)(\overline{P}\,\overline{R} + \overline{Q}) = P(\overline{Q} + R)\,\overline{P}\,\overline{R} + P(\overline{Q} + R)\,\overline{Q}.$$

The first part contains $P \cdot \overline{P} = 0$. The second part is $P\,\overline{Q}\,(\overline{Q} + R) = P\overline{Q}$.

So the expression is $P\overline{Q}$: (A).

- (B), (C) and (D) are not equal to it, e.g. (B) at $P = 1, Q = 1, R = 0$ gives 1, while the original expression gives 0.

**Code check:** an 8-row truth table of the original expression equals $P\overline{Q}$ on every row.

**Key idea:** use $P \cdot \overline{P} = 0$ and absorption to collapse a product of sums.

</details>
