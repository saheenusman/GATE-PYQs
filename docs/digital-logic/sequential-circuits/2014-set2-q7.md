# 2014 CS2 Q7: Binary counter feeding an n-to-2^n decoder

## Question

Let $k = 2^n$. A circuit is built by giving the output of an $n$-bit binary counter as input to an $n$-to-$2^n$ bit decoder. This circuit is equivalent to a

- (A) $k$-bit binary up counter.
- (B) $k$-bit binary down counter.
- (C) $k$-bit ring counter.
- (D) $k$-bit Johnson counter.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The $n$-bit counter steps through $0, 1, \ldots, 2^n - 1$. The decoder turns each value into a one-hot code on $2^n = k$ lines. So exactly one output line is 1, and it moves to the next line on every clock, wrapping around. That is a **$k$-bit ring counter**.

- (A), (B) a $k$-bit binary counter would have $2^k$ states in a binary code, but this circuit has only $k$ states.
- (D) a Johnson (twisted ring) counter has $2k$ states and several lines high at once, not one-hot.

**Key idea:** decoder + binary counter gives a one-hot rotating output, a ring counter.

</details>
