# 2021 CS2 Q38: Mealy machine that replaces the first 1 of each run by 0

## Question

Suppose we want to design a synchronous circuit that processes a string of 0's and 1's. Given a string, it produces another string by replacing the first 1 in any subsequence of consecutive 1's by a 0. Consider the following example.

Input sequence: 00100011000011100

Output sequence: 00000001000001100

A *Mealy Machine* is a state machine where both the next state and the output are functions of the present state and the current input.

The above mentioned circuit can be designed as a two-state Mealy machine. The states in the Mealy machine can be represented using Boolean values 0 and 1. We denote the current state, the next state, the next incoming bit, and the output bit of the Mealy machine by the variables $s$, $t$, $b$ and $y$ respectively.

Assume the initial state of the Mealy machine is 0.

What are the Boolean expressions corresponding to $t$ and $y$ in terms of $s$ and $b$?

- (A) $t=s+b$, $y=sb$
- (B) $t=b$, $y=sb$
- (C) $t=b$, $y=s\bar b$
- (D) $t=s+b$, $y=s\bar b$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let the state $s$ remember the **previous input bit**. Then $t=b$.

The output must be 1 only for a 1 that is **not** the first of its run, that is, the current bit is 1 and the previous bit was also 1:

$$y=s\cdot b.$$

Check on the example 00100011000011100: the machine gives 00000001000001100, which equals the required output.

I simulated all four options on this input:

| option | output | matches? |
|---|---|---|
| (A) | 00000011000011100 | no |
| (B) | 00000001000001100 | yes |
| (C) | 00010000100000010 | no |
| (D) | 00011100111100011 | no |

- (A): $t=s+b$ latches the state at 1 after the first 1, so every later 1 comes out as 1, including the second 1 of the run 11 at positions 6 and 7.
- (C) and (D): $y=s\bar b$ is 1 when a run **ends**, not when it continues.

**Key idea:** a one-bit state "previous input" and $y=s\cdot b$ detect the second and later bits of a run of 1s.

</details>
