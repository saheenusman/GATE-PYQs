# 2016 CS1 Q8: Minimum J-K flip-flops for a 0-1-0-2-0-3 counter

## Question

We want to design a synchronous counter that counts the sequence 0-1-0-2-0-3 and then repeats. The minimum number of J-K flip-flops required to implement this counter is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count the distinct states.** The sequence has six positions, and the value $0$ appears three times (positions 1, 3, 5). The counter must know which position it is in to pick the next value, so each position is a different state: **6 states**.

**Flip-flops needed.** $n$ flip-flops give $2^n$ states, so we need $2^n \ge 6$:

- $n = 2$ gives only $4$ states, too few.
- $n = 3$ gives $8$ states, enough.

So the minimum is $3$. Any 6-state sequence can be realised with 3 J-K flip-flops, because a J-K flip-flop can make any required transition (0 to 0, 0 to 1, 1 to 0, 1 to 1).

**About the official key.** The key accepts anything from $3$ to $4$. The minimum is $3$; $4$ is what a less compact design would use.

**Key idea:** count distinct states, not distinct output values: $\lceil \log_2 6 \rceil = 3$.

</details>
