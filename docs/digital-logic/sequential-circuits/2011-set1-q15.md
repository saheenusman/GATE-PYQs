# 2011 CS Q15: Minimum D flip-flops for a mod-258 counter

## Question

The minimum number of D flip-flops needed to design a mod-258 counter is

- (A) 9
- (B) 8
- (C) 512
- (D) 258

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A mod-258 counter has $258$ distinct states. $n$ flip-flops give $2^n$ states, so we need $2^n \ge 258$.

$$2^8 = 256 < 258 \le 512 = 2^9$$

So $n = \lceil \log_2 258 \rceil = 9$: (A).

- (B) $8$ flip-flops give only $256$ states, two short.
- (C) $512$ and (D) $258$ are numbers of states, not numbers of flip-flops.

**Code check:** $\lceil \log_2 258 \rceil$ evaluated to $9$.

**Key idea:** n flip-flops can hold 2^n states, so the count needed is the ceiling of log2 of the number of states.

</details>
