# 2015 CS2 Q17: Minimum JK flip-flops for a repeating count sequence

## Question

The minimum number of JK flip-flops required to construct a synchronous counter with the count sequence $(0,0,1,1,2,2,3,3,0,0,\dots)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each count value appears **twice in a row**, so the counter must remember whether it is on the first or the second occurrence. The distinct states are:

$$(0,a),(0,b),(1,a),(1,b),(2,a),(2,b),(3,a),(3,b)$$

That is $8$ states, and $n$ flip-flops give $2^n$ states, so $2^n \ge 8 \Rightarrow n = 3$.

Two flip-flops would give only 4 states, which is not enough.

**Key idea:** the number of flip-flops is $\lceil \log_2(\text{number of distinct states}) \rceil$.

</details>
