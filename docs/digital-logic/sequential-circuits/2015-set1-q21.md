# 2015 CS1 Q21: Counting sequence of a 4-bit Johnson counter

## Question

Consider a 4-bit Johnson counter with an initial value of 0000. The counting sequence of this counter is

- (A) 0, 1, 3, 7, 15, 14, 12, 8, 0
- (B) 0, 1, 3, 5, 7, 9, 11, 13, 15, 0
- (C) 0, 2, 4, 6, 8, 10, 12, 14, 0
- (D) 0, 8, 12, 14, 15, 7, 3, 1, 0

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A Johnson (twisted-ring) counter feeds the **complement of the last bit** back to the first bit, shifting right each clock.

| Clock | $Q_3Q_2Q_1Q_0$ | Decimal |
|---|---|---|
| 0 | 0000 | 0 |
| 1 | 1000 | 8 |
| 2 | 1100 | 12 |
| 3 | 1110 | 14 |
| 4 | 1111 | 15 |
| 5 | 0111 | 7 |
| 6 | 0011 | 3 |
| 7 | 0001 | 1 |
| 8 | 0000 | 0 |

Sequence: $0, 8, 12, 14, 15, 7, 3, 1, 0$. Option (D).

(A) is the same sequence for a **left**-shifting counter. (B) and (C) are binary counting patterns, which a Johnson counter does not produce. An $n$-bit Johnson counter has only $2n = 8$ states.

**Key idea:** a Johnson counter shifts in $\overline{Q_0}$, giving $2n$ states.

</details>
