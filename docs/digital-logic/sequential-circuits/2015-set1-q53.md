# 2015 CS1 Q53: Output sequence of a D flip-flop feeding a JK flip-flop

## Question

A positive edge-triggered D flip-flop is connected to a positive edge-triggered JK flip-flop as follows. The $Q$ output of the D flip-flop is connected to both the J and K inputs of the JK flip-flop, while the $Q$ output of the JK flip-flop is connected to the input of the D flip-flop. Initially, the output of the D flip-flop is set to logic one and the output of the JK flip-flop is cleared. Which one of the following is the bit sequence (including the initial state) generated at the $Q$ output of the JK flip-flop when the flip-flops are connected to a free-running common clock? Assume that $J = K = 1$ is the toggle mode and $J = K = 0$ is the state-holding mode of the JK flip-flop. Both the flip-flops have non-zero propagation delays.

- (A) 0110110...
- (B) 0100100...
- (C) 011101110...
- (D) 011001100...

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

On each clock edge both flip-flops sample their inputs **at the same time** (old values):

- $D_{\text{next}} = Q_{JK}$ (old)
- $Q_{JK,\text{next}} = \overline{Q_{JK}}$ if $Q_D = 1$ (toggle), else $Q_{JK}$ (hold). Here $J=K=Q_D$.

| Clock | $Q_D$ | $Q_{JK}$ | Next $Q_D$ | Next $Q_{JK}$ |
|---|---|---|---|---|
| 0 (initial) | 1 | 0 | 0 | 1 (toggle) |
| 1 | 0 | 1 | 1 | 1 (hold) |
| 2 | 1 | 1 | 1 | 0 (toggle) |
| 3 | 1 | 0 | 0 | 1 (toggle) |

State at clock 3 is the same as at clock 0, so the pattern repeats every 3 clocks. The $Q_{JK}$ sequence is $0, 1, 1, 0, 1, 1, 0, \dots$ i.e. $0110110\dots$ Option (A).

The circuit only has the 3-state cycle above. (B) has period 3 but the wrong pattern ($010$), while (C) and (D) have period 4, which this circuit cannot produce.

**Code check:** a small simulation printed $011011011$ for nine samples.

**Key idea:** update both flip-flops from the old values at each edge; the pair of states cycles with period 3.

</details>
