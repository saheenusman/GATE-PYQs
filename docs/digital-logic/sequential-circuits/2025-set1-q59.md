# 2025 CS1 Q59: Minimising a state table with eight states

## Question

Consider a finite state machine (FSM) with one input $X$ and one output $f$, represented by the given state transition table. The minimum number of states required to realize this FSM is ________. (Answer in integer)

| Present state | Next state $X=0$ | Next state $X=1$ | Output $f$ $X=0$ | Output $f$ $X=1$ |
|---|---|---|---|---|
| A | F | B | 0 | 0 |
| B | D | C | 0 | 0 |
| C | F | E | 0 | 0 |
| D | G | A | 1 | 0 |
| E | D | C | 0 | 0 |
| F | F | B | 1 | 1 |
| G | G | H | 0 | 1 |
| H | G | A | 1 | 0 |

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Merge **equivalent** states by partition refinement.

**Step 1: group by output pairs $(f|_{X=0}, f|_{X=1})$.**

| Outputs | States |
|---|---|
| (0, 0) | A, B, C, E |
| (1, 0) | D, H |
| (1, 1) | F |
| (0, 1) | G |

**Step 2: refine by next-state classes.** Name the classes $P = \lbrace A,B,C,E\rbrace$, $Q = \lbrace D,H\rbrace$, $F$, $G$.

| State | Next on $X=0$ | Next on $X=1$ | (class, class) |
|---|---|---|---|
| A | F | B | (F, P) |
| B | D | C | (Q, P) |
| C | F | E | (F, P) |
| E | D | C | (Q, P) |

So $P$ splits into $\lbrace A, C\rbrace$ and $\lbrace B, E\rbrace$. In $Q$: D goes to (G, A) and H goes to (G, A): the same, so $\lbrace D,H\rbrace$ stays together.

**Step 3: check stability.** A goes to (F, B) and C goes to (F, E), and B and E are in the same class: consistent. B goes to (D, C) and E goes to (D, C): identical.

Final classes: $\lbrace A, C\rbrace$, $\lbrace B, E\rbrace$, $\lbrace D, H\rbrace$, $\lbrace F\rbrace$, $\lbrace G\rbrace$: **5 states**.

A program doing the same refinement also gave these 5 classes.

**Key idea:** start from the output partition and keep splitting any class whose members go to different classes on some input.

</details>
