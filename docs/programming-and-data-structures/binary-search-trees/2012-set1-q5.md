# 2012 CS Q5: Searching a balanced BST with n times 2 to the n elements

## Question

The worst case running time to search for an element in a balanced binary search tree with $n2^n$ elements is

- (A) $\Theta(n \log n)$
- (B) $\Theta(n2^n)$
- (C) $\Theta(n)$
- (D) $\Theta(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A balanced BST with $N$ nodes has height $\Theta(\log N)$, and a search follows one root-to-leaf path. Here $N = n2^n$, so

$$\log_2 (n 2^n) = n + \log_2 n = \Theta(n).$$

- (A) $n \log n$ is too large for a single path.
- (B) $n2^n$ is $N$ itself, the cost of a linear scan.
- (D) $\log n$ would be the cost if $N = n$.

**Code check:** $\log_2(n2^n)/n$ was $1.33$, $1.07$, $1.01$ for $n = 10, 100, 1000$, tending to $1$.

**Key idea:** search time in a balanced BST is $\Theta(\log N)$, and $\log$ of $2^n$ is $n$.

</details>
