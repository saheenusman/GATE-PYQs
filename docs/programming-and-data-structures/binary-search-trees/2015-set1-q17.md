# 2015 CS1 Q17: Valid inorder traversals of binary search trees

## Question

Which of the following is/are correct inorder traversal sequence(s) of binary search tree(s)?

- I. 3, 5, 7, 8, 15, 19, 25
- II. 5, 8, 9, 12, 10, 15, 25
- III. 2, 7, 10, 8, 14, 16, 20
- IV. 4, 6, 7, 9, 18, 20, 25

- (A) I and IV only
- (B) II and III only
- (C) II and IV only
- (D) II only

*(The paper prints sequence IV as "4, 6, 7, 9 18, 20, 25" with a comma missing; it is read here as 4, 6, 7, 9, 18, 20, 25.)*

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The inorder traversal of a BST visits keys in **strictly increasing order**. So check each sequence for sortedness.

- I: $3<5<7<8<15<19<25$. Sorted.
- II: $12 > 10$. Not sorted.
- III: $10 > 8$. Not sorted.
- IV: $4<6<7<9<18<20<25$. Sorted.

So I and IV: option (A). (B), (C) and (D) each include II or III.

Note the missing comma in the printed IV: read literally, "9 18" would be a single odd token, so I took it as a typo for "9, 18". Either way the key is (A).

**Key idea:** a sequence is a BST inorder iff it is sorted.

</details>
