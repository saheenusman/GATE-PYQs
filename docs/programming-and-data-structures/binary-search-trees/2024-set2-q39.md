# 2024 CS2 Q39: What can be determined from the key set of a BST

## Question

You are given a set $V$ of distinct integers. A binary search tree $T$ is created by inserting all elements of $V$ one by one, starting with an empty tree. The tree $T$ follows the convention that, at each node, all values stored in the left subtree of the node are smaller than the value stored at the node. You are not aware of the sequence in which these values were inserted into $T$, and you do not have access to $T$.

Which one of the following statements is TRUE?

- (A) Inorder traversal of $T$ can be determined from $V$
- (B) Root node of $T$ can be determined from $V$
- (C) Preorder traversal of $T$ can be determined from $V$
- (D) Postorder traversal of $T$ can be determined from $V$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The shape of a BST depends on the insertion order. The set of keys does not fix it.**

For $V = \lbrace 1, 2, 3 \rbrace$:

| Insertion order | Root | Preorder | Postorder |
|---|---|---|---|
| 1, 2, 3 | 1 | 1 2 3 | 3 2 1 |
| 2, 1, 3 | 2 | 2 1 3 | 1 3 2 |
| 3, 2, 1 | 3 | 3 2 1 | 1 2 3 |

- **(A) True.** The inorder traversal of any BST is the keys in **sorted order**, whatever the shape.
- **(B) False.** The root is the first value inserted, which the set does not reveal.
- **(C), (D) False.** Preorder and postorder depend on the shape, as the table shows.

**Key idea:** inorder of a BST is always sorted, so it is the one traversal fixed by the key set alone.

</details>
