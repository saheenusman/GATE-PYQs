# 2021 CS1 Q20: Picking an element smaller than the maximum in a BST

## Question

A binary search tree $T$ contains $n$ distinct elements. What is the time complexity of picking an element in $T$ that is smaller than the maximum element in $T$?

- (A) $\Theta(n\log n)$
- (B) $\Theta(n)$
- (C) $\Theta(\log n)$
- (D) $\Theta(1)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Look only at the root.

- If the root has a right child, the root is smaller than something on its right, so the root is not the maximum. Return the root.
- If the root has no right child, the root is the maximum. Then its left child (which exists when $n\ge2$) is smaller than it. Return that.

Either way, only $O(1)$ nodes are examined.

- (A), (B), (C) assume we must find the maximum (an $O(h)$ walk) or scan the tree. Not needed.

(D) $\Theta(1)$.

**Key idea:** "any element smaller than the max" does not need the max. The root or its left child always works.

</details>
