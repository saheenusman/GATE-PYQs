# 2025 CS2 Q35: Depth of the last key in a BST

## Question

Suppose the values $10, -4, 15, 30, 20, 5, 60, 19$ are inserted in that order into an initially empty binary search tree. Let $T$ be the resulting binary search tree.

The number of edges in the path from the node containing $19$ to the root node of $T$ is ___________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Insert each key by going left if it is smaller than the current node, right if larger.

| Key | Path taken | Placed as |
|---|---|---|
| 10 | | root |
| $-4$ | $-4<10$ → left | left of 10 |
| 15 | $15>10$ → right | right of 10 |
| 30 | right of 10, $30>15$ → right | right of 15 |
| 20 | 10 → 15 → 30, $20<30$ → left | left of 30 |
| 5 | $5<10$ → left, $5>-4$ → right | right of $-4$ |
| 60 | 10 → 15 → 30, $60>30$ → right | right of 30 |
| 19 | 10 → 15 → 30 → 20, $19<20$ → left | left of 20 |

```mermaid
flowchart TD
    n10((10)) --> nm4((-4))
    n10 --> n15((15))
    nm4 --> n5((5))
    n15 --> n30((30))
    n30 --> n20((20))
    n30 --> n60((60))
    n20 --> n19((19))
```
*The final BST. The path from 19 up to the root is 19, 20, 30, 15, 10.*

That path has 5 nodes, so **4 edges**.

Replayed in code: the depth of 19 is 4.

**Key idea:** a key's depth is the number of comparisons made while inserting it, minus the final empty-slot step, so it is the number of ancestors.

</details>
