# 2025 CS1 Q26: True statements about any BST

## Question

Which of the following statement(s) is/are TRUE for any binary search tree (BST) having $n$ distinct integers?

- (A) The maximum length of a path from the root node to any other node is $(n-1)$.
- (B) An inorder traversal will always produce a sorted sequence of elements.
- (C) Finding an element takes $O(\log_2 n)$ time in the worst case.
- (D) Every BST is also a Min-Heap.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) True.** A path of $k$ edges visits $k+1$ distinct nodes, so $k+1 \le n$ and $k \le n-1$. The bound is reached by a chain, for example inserting $1,2,\dots,n$ in order.

**Note on wording:** read (A) as "no path is longer than $n-1$". A balanced BST has shorter paths, so it cannot mean "exactly $n-1$ for every BST". The official key marks (A) true on the "at most" reading.

**(B) True.** Left subtree $<$ node $<$ right subtree at every node, so inorder (left, node, right) visits keys in increasing order.

**(C) False.** The $O(\log_2 n)$ bound needs a *balanced* tree. A plain BST can be a chain, and a search then takes $\Theta(n)$ steps.

```mermaid
flowchart TD
    A((1)) --> B((2))
    B --> C((3))
    C --> D((4))
```
*Keys inserted in sorted order: a chain. Searching for 4 takes 3 edges, and in general $n-1$.*

**(D) False.** A BST orders keys left $<$ node $<$ right, while a min-heap needs parent $\le$ children. In the BST with root 2 and children 1 and 3, the left child 1 is smaller than its parent 2, so it is not a min-heap.

Checked by brute force over all $6! = 720$ insertion orders of 6 keys: inorder was always sorted, the maximum depth reached $n-1 = 5$ (the chain), and some BSTs were not min-heaps. A chain of 1024 keys had depth 1023, against $\log_2 1024 = 10$.

**Key idea:** BST order gives sorted inorder, but search is $O(h)$, which is $O(\log n)$ only for balanced trees. A BST is not a heap.

</details>
