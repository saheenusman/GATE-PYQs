# 2022 CS Q28: Index of the 3rd largest element in a complete BST

## Question

Suppose a binary search tree with 1000 distinct elements is also a complete binary tree. The tree is stored using the array representation of binary heap trees. Assuming that the array indices start with 0, the 3rd largest element of the tree is stored at index ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**509**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Array layout.** With 0-based indices, node $i$ has children $2i+1$ and $2i+2$ (when they are less than 1000), and parent $\lfloor (i-1)/2 \rfloor$.

**The largest element** is the last node of the inorder traversal, which is the end of the rightmost path:

$$0 \to 2 \to 6 \to 14 \to 30 \to 62 \to 126 \to 254 \to 510$$

Node 510 has children 1021 and 1022, both beyond index 999, so it is a leaf. The largest element is at index **510**.

**The 2nd largest** is the inorder predecessor of 510. A leaf's predecessor is the nearest ancestor of which it is in the right subtree: its parent, index **254**.

**The 3rd largest** is the predecessor of 254. That is the maximum of 254's left subtree. The left child is index $2\cdot254+1 = 509$. Its children would be 1019 and 1020, both beyond 999, so 509 is a leaf and the maximum of that subtree. The 3rd largest is at index **509**.

**Code check:** an inorder traversal of the 1000-node complete tree gave the last three indices 509, 254, 510 (3rd, 2nd, 1st largest).

**Key idea:** in a BST the largest keys sit at the end of the inorder traversal; follow right children, then predecessors.

</details>
