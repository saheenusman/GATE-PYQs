# 2016 CS2 Q40: Insertion orders giving a BST of height 6 on seven keys

## Question

The number of ways in which the numbers 1, 2, 3, 4, 5, 6, 7 can be inserted in an empty binary search tree, such that the resulting tree has height 6, is ______.

Note: The height of a tree with a single node is 0.

<details class="success" markdown="1">
<summary>Answer</summary>

**64**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Seven nodes with height $6$ means a **path**: every node has exactly one child.

For a path, each node inserted as root of the remaining range must be the smallest or the largest of the keys not yet used, so at each of the first $6$ insertions there are $2$ choices. The last key is forced.

$$2^{6} = 64$$

**Code check:** building the BST for all $5040$ insertion orders of $1..7$ and counting those with height $6$ gave $64$.

**Key idea:** a height-6 BST on 7 keys is a path: $2^{6}$ insertion orders.

</details>
