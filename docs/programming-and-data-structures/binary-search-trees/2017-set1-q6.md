# 2017 CS1 Q6: Minimum and maximum height of a binary search tree with 15 nodes

## Question

Let $T$ be a binary search tree with 15 nodes. The minimum and maximum possible heights of $T$ are:

*Note: the height of a tree with a single node is 0.*

- (A) 4 and 15 respectively
- (B) 3 and 14 respectively
- (C) 4 and 14 respectively
- (D) 3 and 15 respectively

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Maximum height.** A chain (every node has one child) uses all 15 nodes on a single path of $14$ edges. Height $= 14$.

**Minimum height.** A binary tree of height $h$ holds at most $2^{h+1}-1$ nodes. We need $2^{h+1}-1 \ge 15$:

$$2^{h+1} \ge 16 \;\Rightarrow\; h \ge 3$$

A perfect binary tree of height 3 has exactly $1+2+4+8 = 15$ nodes, so the minimum height is $3$.

So **3 and 14**: **(B)**.

**Why the others fail.** (A), (C) use 4 as the minimum, forgetting that height counts edges (a single node has height 0). (A), (D) use 15 as the maximum, which would be the number of levels, not the height.

**Key idea:** with height counted in edges, $n$ nodes give $\lceil\log_2(n+1)\rceil-1 \le h \le n-1$.

</details>
