# 2009 CS Q37: Maximum height of an AVL tree with 7 nodes

## Question

What is the maximum height of any AVL-tree with 7 nodes? Assume that the height of a tree with a single node is $0$.

- (A) 2
- (B) 3
- (C) 4
- (D) 5

<details class="success" markdown="1">
<summary>Answer</summary>

**B or C** (the official key accepts both)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $N(h)$ be the **fewest** nodes an AVL tree of height $h$ can have. The thinnest such tree has a root, one subtree of height $h-1$ and one of height $h-2$:

$$N(h) = N(h-1) + N(h-2) + 1, \qquad N(0) = 1,\ N(1) = 2.$$

| $h$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $N(h)$ | 1 | 2 | 4 | 7 | 12 | 20 |

A tree of height $3$ needs at least $7$ nodes, and one of height $4$ needs at least $12$. With $7$ nodes the maximum height is $3$: (B). This uses the convention given in the question (a single node has height $0$).

**Why the key also accepts (C).** The key's note uses the bound $h \le 1.44 \log_2 n$, which gives $1.44 \log_2 7 \approx 4$. That is an asymptotic upper bound, not the exact value. The same $4$ also comes out if height is counted in levels (nodes on the longest path) instead of edges. The question fixes the edge convention, so (C) is the weaker reading, but it is on the key, so my answer (B) is not in conflict with it.

- (A) $2$: a height-$2$ AVL tree holds at most $7$ nodes, but $7$ nodes can also be arranged at height $3$, and the question asks for the maximum.
- (D) $5$ needs at least $20$ nodes.

**Code check:** the recurrence above, run for $h = 0$ to $5$, gave $1, 2, 4, 7, 12, 20$; with $7$ nodes the largest $h$ with $N(h) \le 7$ is $3$.

**Key idea:** the sparsest AVL tree of height $h$ follows a Fibonacci-like recurrence, so height grows only logarithmically with $n$.

</details>
