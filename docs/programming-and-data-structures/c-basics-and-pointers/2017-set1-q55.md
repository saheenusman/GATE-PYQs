# 2017 CS1 Q55: Output of a program with static variables and bit counting

## Question

The output of executing the following C program is ______.

```c
#include <stdio.h>

int total(int v) {
    static int count = 0;
    while (v) {
        count += v & 1;
        v >>= 1;
    }
    return count;
}

void main() {
    static int x = 0;
    int i = 5;
    for (; i > 0; i--) {
        x = x + total(i);
    }
    printf("%d\n", x);
}

<details class="success" markdown="1">
<summary>Answer</summary>

**23**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What `total` does.** It adds the number of 1-bits of `v` to the `static` variable `count`. Because `count` is `static`, it keeps its value between calls and is never reset. `total` returns the **running total** so far, not the count for `v` alone.

**Trace.**

| `i` | Binary | 1-bits | `count` after | `total(i)` returns | `x = x + total(i)` |
|---|---|---|---|---|---|
| 5 | 101 | 2 | 2 | 2 | 2 |
| 4 | 100 | 1 | 3 | 3 | 5 |
| 3 | 011 | 2 | 5 | 5 | 10 |
| 2 | 010 | 1 | 6 | 6 | 16 |
| 1 | 001 | 1 | 7 | 7 | 23 |

The program prints **23**.

**Code check:** compiled and run (the original `void main()` gives a `-Wall` warning only), it printed `23`.

**Key idea:** a `static` local persists across calls, so `total` returns a cumulative bit count and `x` sums those cumulative values.

</details>
