# 2016 CS1 Q36: Pseudo-code with pass by reference and dynamic scoping

## Question

What will be the output of the following pseudo-code when parameters are passed by reference and dynamic scoping is assumed?

```
a=3;
void n(x) {x = x * a; print(x);}
void m(y) {a = 1; a = y - a; n(a); print(a);}
void main() {m(a);}
```

- (A) 6, 2
- (B) 6, 6
- (C) 4, 2
- (D) 4, 4

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The official key is (D) $4, 4$. Tracing the code exactly as printed, with the stated rules, gives $0, 0$, which is not an option. Both readings follow.

**Reading 1: the code exactly as printed.** There is only one variable `a`, the global. Under dynamic scoping every use of `a` finds it.

- `main` calls `m(a)`: `y` is a reference to the global `a` (value $3$).
- `a = 1` sets the global (and so `y`) to $1$.
- `a = y - a` gives $1 - 1 = 0$.
- `n(a)`: `x` refers to `a`, so `x = x * a` is $0 \times 0 = 0$. Prints `0`.
- back in `m`, `print(a)` prints `0`.

Output: **0, 0**.

**Reading 2: the key's $4, 4$.** It is reached if `m`'s assignments hit a variable other than the one `y` refers to, for example if `m` has its own local `a`:

- `y` refers to the global $a = 3$.
- local `a = 1`, then local `a = y - a` $= 3 - 1 = 2$.
- `n(a)`: under dynamic scoping `n` sees the most recent `a`, `m`'s local ($=2$). `x` aliases that same cell, so `x = x * a` $= 2 \times 2 = 4$. Prints `4`.
- `print(a)` in `m` prints `4` as well, because `x` aliased it.

Output: **4, 4**, which is (D). With *static* scoping `n` would use the global $a = 3$ and give $6, 6$ (B), which is what the distractors (A), (B) and (C) are built from.

**Conclusion.** I record the official key (D) but the printed code does not contain a local `a`, so I could not derive it from the question as written. That is why this is marked `disputed`.

**Code check:** a small interpreter (cells for by-reference parameters, a scope stack for dynamic scoping) printed `[0, 0]` for the code as printed, `[4, 4]` with a local `a` in `m`, and `[6, 6]` with a local `a` under static scoping.

**Key idea:** dynamic scoping resolves names along the call stack, and by-reference parameters alias the caller's variable.

</details>
