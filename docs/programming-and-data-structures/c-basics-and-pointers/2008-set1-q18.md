# 2008 CS Q18: Nested conditional expression that finds the maximum

## Question

Which combination of the integer variables `x`, `y` and `z` makes the variable `a` get the value 4 in the following expression?

```c
a = (x > y) ? ((x > z) ? x : z) : ((y > z) ? y : z)
```

- (A) $x = 3,\ y = 4,\ z = 2$
- (B) $x = 6,\ y = 5,\ z = 3$
- (C) $x = 6,\ y = 3,\ z = 5$
- (D) $x = 5,\ y = 4,\ z = 5$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The expression returns the **maximum** of `x`, `y`, `z`:

- if `x > y`, it returns the larger of `x` and `z`;
- otherwise it returns the larger of `y` and `z`.

So `a = 4` only when the maximum is $4$.

| Option | Branch taken | `a` |
|---|---|---|
| (A) 3, 4, 2 | $3 > 4$ false, then $4 > 2$ | **4** |
| (B) 6, 5, 3 | $6 > 5$ true, then $6 > 3$ | 6 |
| (C) 6, 3, 5 | $6 > 3$ true, then $6 > 5$ | 6 |
| (D) 5, 4, 5 | $5 > 4$ true, then $5 > 5$ false, so `z` | 5 |

- (B) and (C) have maximum $6$, and (D) has maximum $5$, so none can give $4$.

**Code check:** compiled with `gcc -Wall` and evaluated all four cases: A gives 4, B gives 6, C gives 6, D gives 5.

**Key idea:** a nested conditional that compares every pair computes the maximum of three values.

</details>
