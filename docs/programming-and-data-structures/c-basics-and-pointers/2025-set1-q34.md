# 2025 CS1 Q34: Writing through a pointer argument

## Question

```c
#include <stdio.h>
void foo(int *p, int x){
    *p=x;
}
int main(){
    int *z;
    int a = 20, b = 25;
    z = &a;
    foo(z,b);
    printf("%d",a);
    return 0;
}
```

The output of the given C program is __________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**25**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Step | State |
|---|---|
| `a = 20, b = 25` | `a`=20, `b`=25 |
| `z = &a` | `z` holds the address of `a` |
| `foo(z, b)` | `p` = copy of `z` (points to `a`), `x` = copy of `b` = 25 |
| `*p = x` | writes 25 into the object `p` points to, which is `a` |
| `printf("%d", a)` | `a` is now 25 |

The pointer `p` is a copy, but it holds the **same address**, so writing through it changes the caller's `a`. `b` is passed by value and is unchanged.

Compiled with `gcc -Wall -Wextra -std=c11` (no warnings) and run: prints `25`.

**Key idea:** C passes arguments by value, but a pointer argument lets the callee modify the caller's variable through `*p`.

</details>
