# 2015 CS1 Q65: Postcondition of the repeated-subtraction division loop

## Question

Consider the following pseudo code, where $x$ and $y$ are positive integers.

```
begin
  q := 0
  r := x
  while r >= y do
  begin
     r := r - y
     q := q + 1
  end
end
```

The post condition that needs to be satisfied after the program terminates is

- (A) $\lbrace r = qx + y \wedge r < y \rbrace$
- (B) $\lbrace x = qy + r \wedge r < y \rbrace$
- (C) $\lbrace y = qx + r \wedge 0 < r < y \rbrace$
- (D) $\lbrace q + 1 < r - y \wedge y > 0 \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

This is integer division by repeated subtraction.

**Loop invariant:** $x = qy + r$. Initially $q = 0,\ r = x$, so $x = 0\cdot y + x$ holds. Each pass does $r \leftarrow r - y,\ q \leftarrow q + 1$, which keeps $qy + r$ unchanged.

**On exit:** the loop condition $r \ge y$ is false, so $r < y$.

Post condition: $x = qy + r \wedge r < y$ (and $r \ge 0$ also holds). That is option (B): $q$ is the quotient and $r$ the remainder.

(A) and (C) swap the roles of the variables. (D) is not implied by anything in the program.

**Code check:** for 2000 random positive pairs $(x, y)$ the loop always satisfied (B), and (A), (C), (D) failed every time.

**Key idea:** invariant $\wedge$ negated loop condition gives the postcondition.

</details>
