# 2025 CS2 Q62: Pointer arithmetic and (*ptr)++

## Question

Consider the following C program:

```c
#include <stdio.h>

int main(){
    int a;
    int arr[5] = {30,50,10};
    int *ptr;
    ptr = &arr[0] + 1;
    a = *ptr;
    (*ptr)++;
    ptr++;
    printf("%d", a + (*ptr) + arr[1]);
    return 0;
}
```

The output of the above program is ___________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**111**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`int arr[5] = {30,50,10};` sets $arr = \lbrace 30, 50, 10, 0, 0\rbrace $, since the remaining elements are zero-initialised.

| Statement | Effect | State |
|---|---|---|
| `ptr = &arr[0] + 1` | points to `arr[1]` | `*ptr` = 50 |
| `a = *ptr` | copies the value | `a` = 50 |
| `(*ptr)++` | increments the **pointed-to value** | `arr[1]` = 51 |
| `ptr++` | moves the **pointer** one `int` forward | `ptr` → `arr[2]`, `*ptr` = 10 |

Then the printed value is

`a + *ptr + arr[1]` = $50 + 10 + 51 = 111$.

Note that `a` kept the **old** value 50 because it was copied before the increment, while `arr[1]` is read afterwards and is 51.

Compiled with `gcc -Wall -Wextra -std=c11` (no warnings) and run: prints `111`.

**Key idea:** `(*ptr)++` changes the value pointed to, while `ptr++` changes the pointer. Copied values do not follow later changes.

</details>
