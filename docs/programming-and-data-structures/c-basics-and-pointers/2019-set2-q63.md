# 2019 CS2 Q63: Sum computed with pointer subtraction

## Question

Consider the following C program:

```c
#include <stdio.h>
int main()
{
    int a[] = {2, 4, 6, 8, 10};
    int i, sum = 0, *b = a + 4;
    for (i = 0; i < 5; i++)
        sum = sum + (*b - i) - *(b - i);
    printf ("%d\n", sum);
    return 0;
}
```

The output of the above C program is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**10**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`b = a + 4` points to `a[4]`, which is 10. Two different things appear in each term:

- `*b - i` is the **value** 10 minus $i$.
- `*(b - i)` is the **element** at pointer `b - i`, that is `a[4 - i]`.

Each term is $(10 - i) - a[4-i]$.

| $i$ | $10 - i$ | $a[4-i]$ | Term |
|---|---|---|---|
| 0 | 10 | 10 | 0 |
| 1 | 9 | 8 | 1 |
| 2 | 8 | 6 | 2 |
| 3 | 7 | 4 | 3 |
| 4 | 6 | 2 | 4 |

Sum $= 0 + 1 + 2 + 3 + 4 = $ **10**.

**Code check:** compiled with `gcc -Wall`, no warnings. Output: `10`.

**Key idea:** `*b - i` subtracts from the value. `*(b - i)` moves the pointer first.

</details>
