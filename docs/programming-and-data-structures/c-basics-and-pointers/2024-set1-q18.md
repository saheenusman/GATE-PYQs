# 2024 CS1 Q18: While loop that never reaches 10

## Question

Consider the following C program:

```c
#include <stdio.h>
int main(){
  int a = 6;
  int b = 0;
  while(a < 10) {
    a = a / 12 + 1;
    a += b;
  }
  printf("%d", a);
  return 0;
}
```

Which one of the following statements is CORRECT?

- (A) The program prints 9 as output
- (B) The program prints 10 as output
- (C) The program gets stuck in an infinite loop
- (D) The program prints 6 as output

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Trace.** `a / 12` is integer division. For any $0 \le a < 12$ it is $0$.

| Iteration | `a` before | `a/12 + 1` | `a += b` (b = 0) |
|---|---|---|---|
| 1 | 6 | 1 | 1 |
| 2 | 1 | 1 | 1 |
| 3 | 1 | 1 | 1 |

`a` becomes 1 and stays 1, so `a < 10` is always true.

**Verified.** I ran the loop with a cap of 5 iterations: `a` was 1 after every one, and the condition was still true.

**Why the others fail:** nothing ever raises `a` toward 9, 10 or back to 6, and `printf` is never reached.

**Key idea:** integer division truncates. When the loop body resets the variable to a fixed value below the bound, the loop never ends.

</details>
