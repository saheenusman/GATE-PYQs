# 2016 CS1 Q15: Output of a pointer-swapping function called by value

## Question

Consider the following C program.

```c
#include<stdio.h>
void mystery(int *ptra, int *ptrb) {
    int *temp;
    temp = ptrb;
    ptrb = ptra;
    ptra = temp;
}
int main() {
    int a=2016, b=0, c=4, d=42;
    mystery(&a, &b);
    if (a < c)
        mystery(&c, &a);
    mystery(&a, &d);
    printf("%d\n", a);
}
```

The output of the program is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2016**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`mystery` swaps its two **parameters**, which are local copies of the pointers. The variables `a, b, c, d` in `main` are never written through them, so they keep their values.

| Step | Effect |
|---|---|
| `mystery(&a,&b)` | none |
| `a < c` | $2016 < 4$ is false, so the `if` is skipped |
| `mystery(&a,&d)` | none |
| `printf` | prints `a`, which is still `2016` |

To really swap, the function would have to write through the pointers (`*ptra`, `*ptrb`).

**Code check:** compiled with `gcc -Wall` and run: prints `2016`.

**Key idea:** swapping pointer parameters does not change the caller's variables.

</details>
