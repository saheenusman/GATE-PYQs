# 2015 CS3 Q11: Output of a string with one character overwritten

## Question

Consider the following C program segment.

```c
#include <stdio.h>

int main()
{
    char s1[7] = "1234", *p;
    p = s1 + 2;
    *p = '0';
    printf("%s", s1);
}
```

What will be printed by the program?

- (A) 12
- (B) 120400
- (C) 1204
- (D) 1034

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`s1` holds `'1' '2' '3' '4' '\0'` followed by two more zero bytes (the array has 7 slots).

- `p = s1 + 2` points at `'3'`.
- `*p = '0'` overwrites it with the **character** `'0'` (ASCII 48), not the NUL byte.

So `s1` is now `"1204"`, and `%s` prints it up to the NUL at index 4: **1204**. Option (C).

- (A) `12` is what you would get from `'\0'`, which is not what is written.
- (B) `120400` would need the extra zero bytes to print, but `%s` stops at the first NUL.
- (D) `1034` changes the wrong position.

**Code check:** compiled with `gcc -Wall` with no warnings, prints `1204`.

**Key idea:** `'0'` is a printable character, `'\0'` is the string terminator.

</details>
