# 2019 CS2 Q37: Static variable updated by repeated calls in a for loop

## Question

Consider the following C program:

```c
#include <stdio.h>
int r(){
    static int num=7;
    return num--;
}
int main(){
    for (r();r();r())
        printf("%d",r());
    return 0;
}
```

Which one of the following values will be displayed on execution of the programs?

- (A) 41
- (B) 52
- (C) 63
- (D) 630

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`num` is `static`, so it keeps its value across calls. `num--` returns the **old** value and then decrements. **Every** call to `r()` in the loop header counts too.

| Step | Call | Returns | `num` after | Effect |
|---|---|---|---|---|
| init | `r()` | 7 | 6 | |
| test | `r()` | 6 | 5 | true |
| body | `r()` in `printf` | 5 | 4 | **prints 5** |
| update | `r()` | 4 | 3 | |
| test | `r()` | 3 | 2 | true |
| body | `r()` in `printf` | 2 | 1 | **prints 2** |
| update | `r()` | 1 | 0 | |
| test | `r()` | 0 | −1 | false, stop |

Output: `52`.

**Code check:** compiled with `gcc -Wall`, no warnings. Output: `52`.

**Why the others fail:** (A), (C) and (D) do not match the trace. The body runs exactly twice and prints 5, then 2, so the output is two digits.

**Key idea:** `num--` returns the old value, and the for-loop's init, test and update each call `r()`.

</details>
