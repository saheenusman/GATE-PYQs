# 2019 CS2 Q28: Value printed after two calls to a pass-by-value function

## Question

Consider the following C program:

```c
#include <stdio.h>
int jumble(int x, int y){
    x=2*x+y;
    return x;
}
int main(){
    int x=2, y=5;
    y=jumble(y,x);
    x=jumble(y,x);
    printf("%d \n", x);
    return 0;
}
```

The value printed by the program is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**26**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

C passes arguments by value, so `jumble` changes only its own copies. It returns $2x + y$ using its own parameter names. Mind the swapped call order.

| Step | Call | Computation | Result stored |
|---|---|---|---|
| start | | $x = 2,\ y = 5$ | |
| `y = jumble(y,x)` | `jumble(5, 2)` | $2\cdot5 + 2$ | $y = 12$ |
| `x = jumble(y,x)` | `jumble(12, 2)` | $2\cdot12 + 2$ | $x = 26$ |

`printf` prints **26**.

**Code check:** compiled with `gcc -Wall` with no warnings. Output: `26`.

**Key idea:** read the formal parameters, not the caller's names. The first argument is doubled.

</details>
