# 2025 CS1 Q63: Keeping alternate digits of a number

## Question

Consider the following C program:

```c
#include <stdio.h>
int gate (int n) {
    int d, t, newnum, turn;
    newnum = turn = 0; t=1;
    while (n>=t) t *= 10;
    t /=10;
    while (t>0) {
        d = n/t;
        n = n%t;
        t /= 10;
        if (turn) newnum = 10*newnum + d;
        turn = (turn + 1) % 2;
    }
    return newnum;
}
int main () {
    printf ("%d", gate(14362));
    return 0;
}
```

The value printed by the given C program is _______ . (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**46**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Setup.** The first loop makes `t` the smallest power of 10 above `n` (here 100000). Then `t /= 10` gives `t = 10000`, the place value of the leading digit.

**Main loop.** Each pass peels off the leading digit `d = n/t`, keeps the rest in `n`, and shrinks `t`. `turn` flips 0, 1, 0, 1, ... and the digit is appended to `newnum` only when `turn` is 1.

| Pass | `t` before | `d` | `n` after | `turn` | Append? | `newnum` |
|---|---|---|---|---|---|---|
| 1 | 10000 | 1 | 4362 | 0 | no | 0 |
| 2 | 1000 | 4 | 362 | 1 | yes | 4 |
| 3 | 100 | 3 | 62 | 0 | no | 4 |
| 4 | 10 | 6 | 2 | 1 | yes | 46 |
| 5 | 1 | 2 | 0 | 0 | no | 46 |

The function keeps the 2nd, 4th, ... digits counting from the left. For 14362 these are 4 and 6, giving 46.

Compiled with `gcc -Wall -Wextra -std=c11` (no warnings) and run: prints `46`.

**Key idea:** peel digits from the most significant end with `n/t` and `n%t`, and a 0/1 toggle selects every other digit.

</details>
