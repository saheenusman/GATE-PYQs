# 2024 CS1 Q48: Growth of x in a loop (which return values are larger)

## Question

Consider the following C function definition.

```c
int f(int x, int y) {
  for (int i=0; i<y; i++) {
    x = x + x + y;
  }
  return x;
}
```

Which of the following statements is/are TRUE about the above function?

- (A) If the inputs are x=20, y=10, then the return value is greater than $2^{20}$
- (B) If the inputs are x=20, y=20, then the return value is greater than $2^{20}$
- (C) If the inputs are x=20, y=10, then the return value is less than $2^{10}$
- (D) If the inputs are x=10, y=20, then the return value is greater than $2^{20}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Closed form.** Each iteration does $x \leftarrow 2x + y$. After $y$ iterations:

$$x_{\text{final}} = 2^y x + (2^y - 1)\,y.$$

**Evaluate each call** (and confirmed by running the C function):

| Call | Return value | vs $2^{10} = 1024$ | vs $2^{20} = 1{,}048{,}576$ |
|---|---|---|---|
| f(20, 10) | 30,710 | larger | smaller |
| f(20, 20) | 41,943,020 | larger | **larger** |
| f(10, 20) | 31,457,260 | larger | **larger** |

No call overflows a 32-bit `int` (the largest is about $4.2 \times 10^7$).

- **(A) False.** 30,710 is not greater than $2^{20}$.
- **(B) True.**
- **(C) False.** 30,710 is not less than 1024.
- **(D) True.**

**Key idea:** $x \leftarrow 2x + y$ doubles roughly each step. After $y$ steps the value is about $2^y x$, so long loops dwarf $2^{20}$.

</details>
