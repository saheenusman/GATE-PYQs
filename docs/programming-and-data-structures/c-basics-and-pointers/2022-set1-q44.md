# 2022 CS Q44: Bitwise operators on characters

## Question

What is printed by the following ANSI C program?

```c
#include<stdio.h>

int main(int argc, char *argv[]){
    char a = 'P';
    char b = 'x';
    char c = (a & b) + '*';
    char d = (a | b) - '-';
    char e = (a ^ b) + '+';
    printf("%c %c %c\n", c, d, e);
    return 0;
}
```

ASCII encoding for relevant characters is given below: $A$ to $Z$ are 65 to 90, $a$ to $z$ are 97 to 122, and `*`, `+`, `-` are 42, 43, 45.

- (A) z K S
- (B) 122 75 83
- (C) * - +
- (D) P x +

<details class="success" markdown="1">
<summary>Answer</summary>

**A (z K S)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Codes.** `'P'` $= 65 + 15 = 80 = 0101\,0000_2$ and `'x'` $= 97 + 23 = 120 = 0111\,1000_2$.

| Expression | Binary result | Value | Character |
| --- | --- | --- | --- |
| `a & b` | 0101 0000 | 80 | |
| `c = 80 + 42` | | 122 | `z` |
| `a \| b` | 0111 1000 | 120 | |
| `d = 120 - 45` | | 75 | `K` |
| `a ^ b` | 0010 1000 | 40 | |
| `e = 40 + 43` | | 83 | `S` |

`%c` prints characters, so the output is `z K S`.

**Why the others fail:** (B) is what `%d` would print. (C) and (D) ignore the arithmetic.

**Code check:** compiled with `gcc -Wall`, no warnings. Output `z K S`; printing the values with `%d` gives `122 75 83`.

**Key idea:** `%c` prints the character with that code; apply the bitwise operator first, then add or subtract.

</details>
