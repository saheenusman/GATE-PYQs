# 2016 CS2 Q12: Value printed by a C program mixing pass by value and by pointer

## Question

The value printed by the following program is ______.

```c
void f(int* p, int m){
    m = m + 5;
    *p = *p + m;
    return;
}

void main(){
    int i=5, j=10;

    f(&i, j);
    printf("%d", i+j);
}
```

<details class="success" markdown="1">
<summary>Answer</summary>

**30**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- `j` is passed **by value**: `m` is a copy of $10$.
- `m = m + 5` makes the copy $15$; `j` stays $10$.
- `p` points to `i`, so `*p = *p + m` sets `i` to $5 + 15 = 20$.
- `printf` prints $i + j = 20 + 10 = 30$.

**Code check:** compiled with `gcc -Wall` and run: `30`.

**Key idea:** by-value `m` is lost, the pointer write changes `i` to 20.

</details>
