## Question

Consider the following ANSI-C program.

```c
#include <stdio.h>

int main(){
    int *ptr, a, b, c;
    a=5; b=11; c=20;
    ptr=&a; *ptr=c; ptr=&c;
    a=*(&b); c=*ptr-a;
    printf("%d",c);
    return(0);
}
```

The output of this program is _____. (answer in integer)

Note: Assume that the program compiles and runs successfully.

??? success "Answer"
    **9**

??? info "Solution"
    Trace statement by statement:

    | Statement | Effect | `a` | `b` | `c` | `ptr` points to |
    |---|---|---|---|---|---|
    | `a=5; b=11; c=20;` | init | 5 | 11 | 20 | |
    | `ptr=&a;` | point to `a` | 5 | 11 | 20 | `a` |
    | `*ptr=c;` | `a = c` | **20** | 11 | 20 | `a` |
    | `ptr=&c;` | point to `c` | 20 | 11 | 20 | `c` |
    | `a=*(&b);` | `*(&b)` is just `b`, so `a = 11` | **11** | 11 | 20 | `c` |
    | `c=*ptr-a;` | `*ptr` is `c` (20), so `c = 20 - 11` | 11 | 11 | **9** | `c` |

    Prints **9**. (Compiled with `gcc -Wall` and run: `9`.)

    **Key idea:** `*(&x)` is the same as `x`, and `*ptr` reads whatever variable `ptr` currently points to.
