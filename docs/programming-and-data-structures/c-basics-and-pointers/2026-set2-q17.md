## Question

In C runtime environment, which one of the following is stored in heap?

- (A) A static variable declared inside a function
- (B) An array of integers declared inside a function
- (C) A dynamically allocated array of integers created using `malloc()` function call
- (D) Return address of a function

??? success "Answer"
    **C**

??? info "Solution"
    | Item | Where it lives |
    |---|---|
    | (A) `static` variable inside a function | **Static/data segment** (initialised data or BSS), for the whole program run |
    | (B) local (automatic) array | **Stack** frame of the function |
    | (C) memory from `malloc()` | **Heap** |
    | (D) function return address | **Stack** (saved in the call frame) |

    Only memory obtained through `malloc`, `calloc`, `realloc` (and freed with `free`) comes from the heap.

    **Key idea:** stack = locals and return addresses, data segment = globals and statics, heap = `malloc` memory.
