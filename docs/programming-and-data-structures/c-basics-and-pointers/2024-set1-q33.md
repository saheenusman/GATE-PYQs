# 2024 CS1 Q33: Evaluate an expression with custom precedence

## Question

Consider the operator precedence and associativity rules for the integer arithmetic operators given in the table below.

| Operator | Precedence | Associativity |
|---|---|---|
| $+$ | Highest | Left |
| $-$ | High | Right |
| $*$ | Medium | Right |
| $/$ | Low | Right |

The value of the expression $3 + 1 + 5 * 2 / 7 + 2 - 4 - 7 - 6 / 2$ as per the above rules is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Apply the operators from **highest to lowest** precedence, using each one's associativity.

**1. `+` first (left to right).** The `+` chains are $3+1+5 = 9$ and $7+2 = 9$:

$$9 * 2 / 9 - 4 - 7 - 6 / 2$$

**2. `-` next (right associative).** The chain $9 - 4 - 7 - 6$ groups from the right:

$$9 - (4 - (7 - 6)) = 9 - (4 - 1) = 9 - 3 = 6$$

The expression becomes $9 * 2 / 6 / 2$.

**3. `*` next.** $9 * 2 = 18$, giving $18 / 6 / 2$.

**4. `/` last (right associative).** $18 / (6 / 2) = 18 / 3 = 6$.

**Answer: 6.** I checked this with a small script that applies the four levels in this order.

**Key idea:** precedence decides which operator groups first, and associativity decides the grouping within a chain of equal operators. Here the unusual rules (`-` right associative, `/` below `*`) give a different answer from normal arithmetic.

</details>
