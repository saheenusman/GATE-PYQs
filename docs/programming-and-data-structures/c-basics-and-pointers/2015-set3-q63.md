# 2015 CS3 Q63: Output of a square-and-multiply modular routine

## Question

Suppose $c = \langle c[0], \ldots, c[k-1] \rangle$ is an array of length $k$, where all the entries are from the set $\lbrace 0, 1 \rbrace$. For any positive integers $a$ and $n$, consider the following pseudocode.

```
DOSOMETHING (c, a, n)
    z <- 1
    for i <- 0 to k-1
        do z <- z^2 mod n
        if c[i] = 1
            then z <- (z * a) mod n
    return z
```

If $k = 4$, $c = \langle 1, 0, 1, 1 \rangle$, $a = 2$ and $n = 8$, then the output of DOSOMETHING$(c, a, n)$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Trace the loop, with $a = 2$, $n = 8$ and $c = (1, 0, 1, 1)$:

| $i$ | $c[i]$ | $z \leftarrow z^2 \bmod 8$ | if $c[i] = 1$: $z \leftarrow 2z \bmod 8$ |
|---|---|---|---|
| start | | $z = 1$ | |
| 0 | 1 | $1$ | $2$ |
| 1 | 0 | $4$ | $4$ |
| 2 | 1 | $16 \bmod 8 = 0$ | $0$ |
| 3 | 1 | $0$ | $0$ |

**Answer: 0.**

This is square-and-multiply modular exponentiation, reading the exponent's bits from the most significant end. Here the exponent is $1011_2 = 11$, and $2^{11} = 2048 \equiv 0 \pmod 8$, which agrees.

**Code check:** running the pseudocode in Python gives $z = 2, 4, 0, 0$ in turn and returns 0.

**Key idea:** square at every step, then multiply by $a$ when the bit is 1.

</details>
