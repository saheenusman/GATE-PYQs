# 2014 CS2 Q11: Computing C(n,3) in unsigned int without overflow

## Question

Suppose `n` and `p` are `unsigned int` variables in a C program. We wish to set `p` to ${}^nC_3$. If `n` is large, which one of the following statements is most likely to set `p` correctly?

- (A) `p = n * (n-1) * (n-2) / 6;`
- (B) `p = n * (n-1) / 2 * (n-2) / 3;`
- (C) `p = n * (n-1) / 3 * (n-2) / 2;`
- (D) `p = n * (n-1) * (n-2) / 6.0;`

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Two things matter: every division must be **exact** (integer division truncates), and the **intermediate product** must not overflow a 32-bit `unsigned`.

- (B) $n(n-1)$ is always even, so `/ 2` is exact. Then $\frac{n(n-1)}{2}(n-2)$ equals $3\binom{n}{3}$, which is divisible by 3, so `/ 3` is exact. The largest intermediate is $3\binom{n}{3}$, the smallest of the four.
- (A) `n*(n-1)*(n-2)` is about $n^3$ and overflows much earlier.
- (C) $n(n-1)$ is not always divisible by 3 (for $n = 5$: $20/3 = 6$, then $6 \cdot 3/2 = 9 \ne 10$), so truncation gives wrong answers.
- (D) the product is still computed in `unsigned` and overflows just as in (A) before the floating-point `/ 6.0` happens; the `double` result is then converted back.

**Code check:** a C program compared all four with the true value for every $n$ with $\binom{n}{3} < 2^{32}$ ($n \le 2344$):

| Statement | First wrong $n$ | Wrong values |
|---|---|---|
| (A) | 1627 | 718 |
| (B) | 2050 | 295 |
| (C) | 5 | 780 |
| (D) | 1627 | 718 |

(B) stays correct longest, so it is the most likely to be correct for large $n$. It still overflows eventually.

**Key idea:** order the multiplications and divisions so each division is exact and the intermediates stay small.

</details>
