# 2024 CS2 Q36: Pointer difference versus value difference

## Question

What is the output of the following C program?

```c
#include <stdio.h>
int main() {
  double a[2] = {20.0, 25.0}, *p, *q;
  p = a;
  q = p + 1;
  printf("%d,%d", (int)(q - p), (int)(*q - *p));
  return 0;
}
```

- (A) 4,8
- (B) 1,5
- (C) 8,5
- (D) 1,8

<details class="success" markdown="1">
<summary>Answer</summary>

**B (1,5)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- `p` points to `a[0]` and `q = p + 1` points to `a[1]`.
- **Pointer subtraction** counts elements, not bytes: `q - p` is **1**. (The bytes between them, 8, are divided by `sizeof(double)`.)
- `*q - *p = 25.0 - 20.0 = 5.0`, cast to `int` gives **5**.

Output: **1,5**. Confirmed by compiling and running with `gcc -Wall`.

**Why the others fail:** 4 and 8 would be the byte difference, which C does not report for pointer subtraction. 8 as a value would need different array contents.

**Key idea:** pointer subtraction is scaled by the element size.

</details>
