# 2019 CS2 Q62: Number of lines printed by a float loop

## Question

Consider the following C program:

```c
#include <stdio.h>
int main(){
    float sum = 0.0, j = 1.0, i = 2.0;
    while (i/j > 0.0625){
        j = j + j;
        sum = sum + i/j;
        printf("%f\n", sum);
    }
    return 0;
}
```

The number of times the variable `sum` will be printed, when the above program is executed, is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each pass doubles `j` and adds `i/j` (with $i = 2$) to `sum`. The loop stops when $i/j \le 0.0625 = 1/16$.

| Test `i/j` | `j` after | `sum` printed |
|---|---|---|
| $2/1 = 2$ | 2 | 1.000000 |
| $2/2 = 1$ | 4 | 1.500000 |
| $2/4 = 0.5$ | 8 | 1.750000 |
| $2/8 = 0.25$ | 16 | 1.875000 |
| $2/16 = 0.125$ | 32 | 1.937500 |
| $2/32 = 0.0625$ | | not greater, **stop** |

`sum` is printed **5** times.

**Floating-point note.** All the values are powers of two, so they are exact in floating point. The final test $0.0625 > 0.0625$ is a true tie and is false. There is no rounding trap.

**Code check:** compiled with `gcc -Wall`, no warnings. The program prints exactly 5 lines.

**Key idea:** when the loop condition is a power-of-two boundary, check whether the equality case is included.

</details>
