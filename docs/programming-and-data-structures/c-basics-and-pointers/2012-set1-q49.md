# 2012 CS Q49: Same program with auto and register variables

## Question

**Common data for Questions 48 and 49.** Consider the following C code segment.

```c
int a, b, c = 0;
void prtFun(void);
main( )
{   static int a = 1;      /* Line 1 */
    prtFun( );
    a += 1;
    prtFun( );
    printf(" \n %d %d ", a, b);
}

void prtFun(void)
{   static int a = 2;      /* Line 2 */
    int b = 1;
    a += ++b;
    printf(" \n %d %d ", a, b);
}
```

What output will be generated by the given code segment if:

- Line 1 is replaced by `auto int a = 1;`
- Line 2 is replaced by `register int a = 2;`

| Option | Line 1 | Line 2 | Line 3 |
|---|---|---|---|
| (A) | 3 1 | 4 1 | 4 2 |
| (B) | 4 2 | 6 1 | 6 1 |
| (C) | 4 2 | 6 2 | 2 0 |
| (D) | 4 2 | 4 2 | 2 0 |

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Now neither `a` is static, so each is re-initialised on every entry to its block.

**`prtFun`, every call.** `a = 2`, `b = 1`, `++b` makes `b = 2`, `a += 2` gives $a = 4$. Prints `4 2`. The same happens on the second call, because `a` starts again at $2$: prints `4 2`.

**`main`.** `a` is $1$, then `a += 1` makes it $2$. `b` is the global, $0$. Prints `2 0`.

Output: `4 2`, `4 2`, `2 0`: (D).

- (C) is the answer to Q48; it needs `prtFun`'s `a` to persist, which it no longer does.
- (A), (B) have wrong first lines or a `b` of $1$.

**Code check:** compiled with `gcc -Wall` with the two replaced lines, and run. Output: `4 2`, `4 2`, `2 0`.

**Key idea:** `auto` and `register` locals are re-created on every call; only `static` ones persist.

</details>
