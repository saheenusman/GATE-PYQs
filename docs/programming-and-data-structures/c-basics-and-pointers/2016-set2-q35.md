# 2016 CS2 Q35: Loop invariant of the fast exponentiation function

## Question

The following function computes $X^Y$ for positive integers $X$ and $Y$.

```c
int exp(int X, int Y) {
    int res = 1, a = X, b = Y;

    while ( b != 0 ){
        if ( b%2 == 0) { a = a*a; b = b/2; }
        else           { res = res*a; b = b-1; }
    }
    return res;
}
```

Which one of the following conditions is TRUE before every iteration of the loop?

- (A) $X^Y = a^b$
- (B) $(\text{res} * a)^Y = (\text{res} * X)^b$
- (C) $X^Y = \text{res} * a^b$
- (D) $X^Y = (\text{res} * a)^b$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Claim: $X^Y = \text{res} \cdot a^b$ before every iteration.

- **Start:** $\text{res} = 1$, $a = X$, $b = Y$, so $\text{res} \cdot a^b = X^Y$. ✓
- **Even $b$:** $a \to a^2$, $b \to b/2$, so $(a^2)^{b/2} = a^b$; `res` unchanged. ✓
- **Odd $b$:** $\text{res} \to \text{res} \cdot a$, $b \to b - 1$, so $(\text{res} \cdot a)\, a^{b-1} = \text{res} \cdot a^b$. ✓

**Check the others** with $X = 2$, $Y = 3$. After the first iteration: $\text{res} = 2$, $a = 2$, $b = 2$.

- (A) $X^Y = 8$ but $a^b = 4$. ✗
- (B) $(\text{res} \cdot a)^Y = 64$ but $(\text{res} \cdot X)^b = 16$. ✗
- (D) $X^Y = 8$ but $(\text{res} \cdot a)^b = 16$. ✗

**Code check:** a version of the function with an assertion `X^Y == res * a^b` at the top of the loop ran without failing, and the result matched $X^Y$.

**Key idea:** invariant: $X^Y = \text{res} \cdot a^b$, preserved by both branches.

</details>
