# 2014 CS2 Q10: C function: count the bits of 435

## Question

Consider the function `func` shown below:

```c
int func(int num) {
int count = 0;
    while (num) {
        count++;
        num>>= 1;
    }
return (count);
}
```

The value returned by `func(435)` is __________.

<details class="success" markdown="1">
<summary>Answer</summary>

**9**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The loop shifts `num` right by one each pass and counts the passes until `num` is 0. So `count` is the number of bits in the binary form of `num` (up to its highest set bit).

$$435 = 256 + 128 + 32 + 16 + 2 + 1 = 110110011_2$$

That is 9 bits, so `func(435)` returns **9**.

**Code check:** compiled with `gcc -Wall` and run; it prints `9`.

**Key idea:** repeated right shift counts $\lfloor \log_2 n \rfloor + 1$ bits.

</details>
