# 2017 CS2 Q54: Output of a pre/post increment and decrement sequence

## Question

Consider the following C Program.

```c
#include<stdio.h>
int main() {
    int m = 10;
    int n, n1;
    n = ++m;
    n1 = m++;
    n--;
    --n1;
    n -= n1;
    printf("%d", n);
    return 0;
}
```

The output of the program is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**0**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Trace.**

| Statement | $m$ | $n$ | $n1$ | Note |
|---|---|---|---|---|
| `int m = 10;` | 10 | | | |
| `n = ++m;` | 11 | 11 | | pre-increment: $m$ first, then copy |
| `n1 = m++;` | 12 | 11 | 11 | post-increment: copy 11, then $m$ becomes 12 |
| `n--;` | 12 | 10 | 11 | |
| `--n1;` | 12 | 10 | 10 | |
| `n -= n1;` | 12 | **0** | 10 | $10 - 10$ |

The program prints **0**.

**Code check:** compiled with `gcc -Wall` (no warnings), the program printed `0`. There is no undefined behaviour: each variable is modified once per statement.

**Key idea:** `++m` yields the new value, `m++` yields the old value.

</details>
