# 2023 CS Q35: Static local variable keeps its value

## Question

The integer value printed by the ANSI-C program given below is ______.

```c
#include<stdio.h>
int funcp(){
  static int x = 1;
  x++;
  return x;
}
int main(){
  int x,y;
  x = funcp();
  y = funcp()+x;
  printf("%d\n", (x+y));
  return 0;
}
```

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Two different `x` variables.** The `static int x` inside `funcp` lives for the whole program and is initialised once. The `x` in `main` is a separate local.

**Trace:**

| Step | static x | Returned |
|---|---|---|
| start | 1 | |
| `x = funcp()` | 2 | 2, so main's x = 2 |
| `y = funcp()+x` | 3 | 3, so y = 3 + 2 = 5 |

Printed: $x + y = 2 + 5 = 7$.

**Code check:** compiled with `gcc -Wall` and run, it prints `7`. The order of evaluation inside `funcp()+x` does not matter, because `funcp` never changes main's `x`, so there is no undefined behaviour.

**Key idea:** a `static` local keeps its value between calls and is initialised only once.

</details>
