# 2008 CS Q60: Pass by value and pass by pointer in a C function

## Question

What is printed by the following C program?

```c
int f(int x, int *py, int **ppz)
{
    int y, z;
    **ppz += 1; z = **ppz;
    *py += 2; y = *py;
    x += 3;
    return x + y + z;
}

void main()
{
    int c, *b, **a;
    c = 4; b = &c; a = &b;
    printf("%d", f(c, b, a));
}
```

- (A) 18
- (B) 19
- (C) 21
- (D) 22

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`x` is a copy of `c` (value $4$). `py` points to `c`, and `ppz` points to `b`, so `**ppz` is also `c`.

| Statement | `x` | `c` | `y` | `z` |
|---|---|---|---|---|
| on entry | 4 | 4 | | |
| `**ppz += 1; z = **ppz;` | 4 | 5 | | 5 |
| `*py += 2; y = *py;` | 4 | 7 | 7 | 5 |
| `x += 3;` | 7 | 7 | 7 | 5 |

Return value: $x + y + z = 7 + 7 + 5 = 19$.

- (A) 18 is what you get if `z` is taken as $4$, i.e. read before the `+= 1`.
- (C) 21 would need $z = 7$, i.e. reading `c` after the second update as well.
- (D) 22 does not match any consistent evaluation of the code.

**Code check:** compiled with `gcc` and ran it: it prints `19`.

**Key idea:** a value parameter is a private copy, while a pointer parameter lets the callee change the caller's variable.

</details>
