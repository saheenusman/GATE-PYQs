# 2019 CS2 Q34: Indexing into an array through a pointer

## Question

Consider the following C program:

```c
#include <stdio.h>
int main(){
    int arr[]={1,2,3,4,5,6,7,8,9,0,1,2,5}, *ip=arr+4;
    printf("%d\n", ip[1]);
    return 0;
}
```

The number that will be displayed on execution of the program is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`arr + 4` points to `arr[4]`, which holds 5.

`ip[1]` is `*(ip + 1)`, the element after it: `arr[5]`.

| Index | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| `arr` | 1 | 2 | 3 | 4 | 5 | **6** |

The program prints **6**.

**Code check:** compiled with `gcc -Wall`, no warnings. Output: `6`.

**Key idea:** $p[i]$ means $*(p + i)$, counted from where $p$ points.

</details>
