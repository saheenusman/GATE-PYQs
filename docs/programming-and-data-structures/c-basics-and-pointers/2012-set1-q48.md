# 2012 CS Q48: Output with static locals shadowing a global

## Question

**Common data for Questions 48 and 49.** Consider the following C code segment.

```c
int a, b, c = 0;
void prtFun(void);
main( )
{   static int a = 1;      /* Line 1 */
    prtFun( );
    a += 1;
    prtFun( );
    printf(" \n %d %d ", a, b);
}

void prtFun(void)
{   static int a = 2;      /* Line 2 */
    int b = 1;
    a += ++b;
    printf(" \n %d %d ", a, b);
}
```

What output will be generated by the given code segment?

| Option | Line 1 | Line 2 | Line 3 |
|---|---|---|---|
| (A) | 3 1 | 4 1 | 4 2 |
| (B) | 4 2 | 6 1 | 6 1 |
| (C) | 4 2 | 6 2 | 2 0 |
| (D) | 3 1 | 5 2 | 5 2 |

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Two things matter: `static` locals keep their value between calls, and a local name hides the global one.

**First call of `prtFun`.** The static `a` is initialised once to $2$. Local `b = 1`, then `++b` makes `b = 2`, and `a += 2` gives $a = 4$. Prints `4 2`.

**Back in `main`.** `main`'s own static `a` (initially $1$) becomes $2$.

**Second call.** The static `a` is still $4$. A fresh local `b = 1` becomes $2$, so $a = 4 + 2 = 6$. Prints `6 2`.

**Last `printf` in `main`.** `a` is `main`'s static, $2$. `b` is not declared locally in `main`, so it is the global `b`, which is $0$ (globals start at zero). Prints `2 0`.

Output: `4 2`, `6 2`, `2 0`: (C).

- (A), (D) print `1` or `3` on the first line; `b` is incremented before printing, so it shows $2$.
- (B) prints `6 1` on the second and third lines; `b` is $2$ in `prtFun` and $0$ in `main`.

**Code check:** compiled with `gcc -Wall` and run (I wrote `int main(void)` and added `return 0`). Output, after a leading blank line from the `\n`: `4 2`, `6 2`, `2 0`.

**Key idea:** static locals persist across calls; a local declaration shadows a global of the same name.

</details>
