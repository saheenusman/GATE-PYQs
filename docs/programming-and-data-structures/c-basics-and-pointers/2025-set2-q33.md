# 2025 CS2 Q33: Subtraction-based GCD loop

## Question

```c
int x=126,y=105;
do {
     if(x>y) x=x-y;
     else y=y-x;
} while(x!=y);

printf("%d",x);
```

The output of the given C code segment is ________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**21**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each pass subtracts the smaller value from the larger. This is the subtraction form of Euclid's algorithm, so the loop ends with $x = y = \gcd(126, 105)$.

| Pass | $x$ before | $y$ before | Action | $x$ after | $y$ after |
|---|---|---|---|---|---|
| 1 | 126 | 105 | $x>y$: $x \leftarrow x-y$ | 21 | 105 |
| 2 | 21 | 105 | $y \leftarrow y-x$ | 21 | 84 |
| 3 | 21 | 84 | $y \leftarrow y-x$ | 21 | 63 |
| 4 | 21 | 63 | $y \leftarrow y-x$ | 21 | 42 |
| 5 | 21 | 42 | $y \leftarrow y-x$ | 21 | 21 |

Now $x = y$, so the loop stops and `printf` prints $x = 21$.

Check: $126 = 6\cdot 21$ and $105 = 5\cdot 21$, and 6 and 5 are coprime, so $\gcd = 21$.

Compiled with `gcc -Wall -Wextra -std=c11` (no warnings) and run: prints `21`.

**Key idea:** repeatedly replacing the larger of two numbers by the difference preserves their GCD, so the loop ends at $\gcd(x,y)$.

</details>
