# 2018 CS Q42: Value returned by a double-log loop on 2^40

## Question

Consider the following C code. Assume that `unsigned long int` type length is 64 bits.

```c
unsigned long int fun(unsigned long int n){
    unsigned long int i, j = 0, sum = 0;
    for (i = n; i > 1; i = i/2) j++;
    for ( ; j > 1; j = j/2) sum++;
    return(sum);
}
```

The value returned when we call `fun` with the input $2^{40}$ is

- (A) 4
- (B) 5
- (C) 6
- (D) 40

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**First loop.** `i` starts at $2^{40}$ and is halved while `i > 1`: $2^{40}\to2^{39}\to\cdots\to2^1\to2^0$. That is 40 halvings, so `j = 40`.

**Second loop.** `j` is halved while `j > 1`, and `sum` counts the iterations:

| `j` | `j > 1`? | `sum` after |
|---|---|---|
| 40 | yes | 1 |
| 20 | yes | 2 |
| 10 | yes | 3 |
| 5 | yes | 4 |
| 2 | yes | 5 |
| 1 | no, stop | 5 |

The function returns **5**.

**Why the others fail:** A stops one iteration early (forgets `j = 2`). C and D are not reachable: 40 is the value of `j`, not `sum`.

**Code check:** compiled and run with `1UL<<40` as input, output `5`.

**Key idea:** the loops compute $\lfloor\log_2\lfloor\log_2 n\rfloor\rfloor$; for $n=2^{40}$ that is $\lfloor\log_2 40\rfloor = 5$.

</details>
