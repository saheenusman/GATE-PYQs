## Question

Consider the following three ANSI-C programs, P1, P2, and P3.

```c
/* P1 */                /* P2 */                /* P3 */
#include <stdio.h>      #include <stdio.h>      #include <stdio.h>
int a=5;                int main(){              int main(){
int main(){               int a=5;                 int a=5;
  int a=7;                int a=7;                 float a=7;
  return(0);              return(0);               return(0);
}                       }                        }
```

Which one of the following statements is true?

- (A) Only P1 will compile without any error
- (B) Only P2 will compile without any error
- (C) Only P3 will compile without any error
- (D) All three programs P1, P2, and P3 will compile without any error

??? success "Answer"
    **A**

??? info "Solution"
    The rule: **a name can be declared only once per scope**, but an inner scope may redeclare a name from an outer scope (it shadows it).

    - **P1:** global `a` is at file scope. `int a=7;` is inside `main`'s block, a different scope, so it just shadows. **Compiles.**
    - **P2:** both `int a` are in the *same block*. This is a redefinition. **Error.**
    - **P3:** `int a` and `float a` are in the same block. A different type does not help; this is still a redeclaration. **Error.**

    Checked with `gcc -std=c11`:

    | Program | Result |
    |---|---|
    | P1 | compiles |
    | P2 | `error: redefinition of 'a'` |
    | P3 | `error: conflicting types for 'a'` |

    **Key idea:** shadowing needs an *inner scope*; two declarations in the same block are always an error, whatever their types.
