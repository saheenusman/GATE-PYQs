# 2015 CS1 Q34: Output of a C program mixing pass by value and by pointer

## Question

The output of the following C program is ______.

```c
void f1(int a, int b) {
    int c;
    c=a; a=b; b=c;
}
void f2(int *a, int *b) {
    int c;
    c=*a; *a=*b; *b=c;
}
int main() {
    int a=4, b=5, c=6;
    f1(a,b);
    f2(&b, &c);
    printf("%d", c-a-b);
}
```

<details class="success" markdown="1">
<summary>Answer</summary>

**-5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- `f1(a, b)` passes **copies**, so it swaps its local copies only. `main`'s `a=4, b=5` are unchanged.
- `f2(&b, &c)` passes **addresses**, so it really swaps `b` and `c` in `main`:

| After | `a` | `b` | `c` |
|---|---|---|---|
| start | 4 | 5 | 6 |
| `f1(a,b)` | 4 | 5 | 6 |
| `f2(&b,&c)` | 4 | 6 | 5 |

`c - a - b` $= 5 - 4 - 6 = -5$.

**Code check:** compiled with `gcc -Wall` (no warnings about the code, apart from the missing `#include <stdio.h>` which I added) and the output was `-5`. No undefined behaviour here. Without `<stdio.h>` the call to `printf` is only an implicit declaration; the paper's snippet omits the header.

**Key idea:** pass by value cannot change the caller's variables; pass by pointer can.

</details>
