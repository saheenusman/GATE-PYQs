## Question

Consider the following program in C:

```c
#include <stdio.h>

void func(int i, int j) {
  if(i < j) {
    int i = 0;
    while (i < 10) {
      j += 2;
      i++;
    }
  }
  printf("%d", i);
}

int main() {
  int i = 9, j = 10;
  func(i, j);
  return 0;
}
```

The output of the program is _____. (answer in integer)

Note: Assume that the program compiles and runs successfully.

??? success "Answer"
    **9**

??? info "Solution"
    Inside `if (i < j) { ... }`, the declaration `int i = 0;` creates a **new variable** in the inner block. It *shadows* the parameter `i` only until the closing `}`.

    | Step | Which `i`? | Value |
    |---|---|---|
    | `func(9, 10)` | parameter `i` | 9 |
    | `if (i < j)`, i.e. $9 < 10$ | parameter `i` | true |
    | `int i = 0;` | inner `i` (new) | 0 |
    | loop 10 times: `j += 2; i++` | inner `i`, parameter `j` | inner `i` = 10, `j` = 30 |
    | `}` ends the block | inner `i` is destroyed | |
    | `printf("%d", i)` | parameter `i` | **9** |

    The loop changes the inner `i` and the parameter `j`, never the outer `i`.

    Compiled with `gcc -Wall -std=c11` and run: prints `9`.

    **Key idea:** a variable declared inside a block hides outer variables of the same name only within that block.
