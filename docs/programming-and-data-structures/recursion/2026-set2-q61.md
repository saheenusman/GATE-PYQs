# 2026 CS2 Q61: Maximum return value of a recursive function

## Question

Consider the following ANSI-C function.

```c
int func(int start, int end){
    int length=end+1-start;
    if((length<1)||(start<0)||(end<0)){ return(0); }
    if(length%3==0){
        return(func(start+1, end));
    } else if(length%3==1){
        return(1+func(start, end-1));
    } else {
        return(func(start+2, end));
    }
}
```

The maximum possible value that can be returned from this function is _____. (answer in integer)

Note: Ignore syntax errors (if any) in the function.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Only the **length** $L$ = `end+1-start` matters. Each call moves to a shorter segment; the return value counts the `1+` steps. Let $f(L)$ be the result (for non-negative `start`, `end`):

| $L \bmod 3$ | Call | Next length | Adds 1? |
|---|---|---|---|
| 0 | `func(start+1, end)` | $L-1$ | no |
| 1 | `func(start, end-1)` | $L-1$ | **yes** |
| 2 | `func(start+2, end)` | $L-2$ | no |

The only way to add 1 is when $L \equiv 1 \pmod 3$. After that the length is $L-1 \equiv 0 \pmod 3$. From a length $\equiv 0$, the next is $L-1 \equiv 2$, then $L-3 \equiv 0$ again, and the chain stays in residues $0$ and $2$ until $L$ reaches 0, never meeting residue 1 again.

| $L$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| $f(L)$ | 1 | 0 | 0 | 1 | 0 | 0 | 1 | 0 | 0 |

So $f(L) = 1$ if $L \equiv 1 \pmod 3$, else $0$. The maximum is **1**.

Checked by running the function for every `start` in 0 to 60 and `end` in 0 to 120: the maximum is 1.

**Key idea:** reduce the recursion to a function of the segment length, then look at the pattern mod 3.

</details>
