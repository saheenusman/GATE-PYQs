# 2018 CS Q31: Recursion count of calc(4, 81)

## Question

Consider the following C program:

```c
#include <stdio.h>

int counter = 0;

int calc (int a, int b) {
    int c;

    counter++;
    if (b==3) return (a*a*a);
    else {
        c = calc(a, b/3);
        return (c*c*c);
    }
}

int main (){
    calc(4, 81);
    printf ("%d", counter);
}
```

The output of this program is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Trace the calls.** Each call increments `counter` once, then recurses with `b/3` until `b == 3`:

| Call | `b` | `counter` after | Action |
|---|---|---|---|
| `calc(4, 81)` | 81 | 1 | recurse with 27 |
| `calc(4, 27)` | 27 | 2 | recurse with 9 |
| `calc(4, 9)` | 9 | 3 | recurse with 3 |
| `calc(4, 3)` | 3 | 4 | base case |

The program prints **4**.

**Note on undefined behavior:** the return values grow as $4^3$, $(4^3)^3$, and so on. The value from `calc(4, 27)` is $4^{27}$, which overflows `int` (signed overflow is undefined in C). The result is discarded and `counter` is unaffected, so the printed value is still 4.

**Code check:** compiled with `gcc -Wall -Wextra`, output `4`.

**Key idea:** the depth is $\log_3 b$ levels until the base case $b=3$: $81\to27\to9\to3$.

</details>
