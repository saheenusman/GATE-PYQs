## Question

Consider the recursive functions represented by the following code segment:

```c
int bar(int n){
     if (n == 1) return 0;
     else return 1 + bar(n/2);
}

int foo(int n){
     if (n == 1) return 1;
     else return 1 + foo(bar(n));
}
```

The smallest positive integer $n$ for which `foo(n)` returns 5 is _____. (answer in integer)

Note: Ignore syntax errors (if any) in the function.

??? success "Answer"
    **65536**

??? info "Solution"
    **`bar`:** it halves $n$ until reaching 1 and counts the steps, so `bar(n)` $= \lfloor \log_2 n \rfloor$.

    **`foo`:** `foo(1) = 1` and `foo(n) = 1 + foo(` $\lfloor \log_2 n \rfloor$ `)`. It is non-decreasing in $n$, so the smallest $n$ with `foo(n) = k` comes from the smallest argument that gives `foo = k-1`. Work backwards:

    | `foo(n)` | smallest $n$ | why |
    |---|---|---|
    | 1 | 1 | base case |
    | 2 | 2 | $\lfloor\log_2 2\rfloor = 1$, `foo(1)=1` |
    | 3 | 4 | $\lfloor\log_2 4\rfloor = 2$, `foo(2)=2` |
    | 4 | 16 | $\lfloor\log_2 16\rfloor = 4$, `foo(4)=3` |
    | 5 | $2^{16} = 65536$ | $\lfloor\log_2 65536\rfloor = 16$, `foo(16)=4` |

    Each row is $2^{\text{previous row}}$: $1, 2, 4, 16, 65536$.

    Checked by running the code: `foo(65535) = 4`, `foo(65536) = 5`, and 65536 is the first $n$ with value 5.

    **Key idea:** `bar` computes $\lfloor\log_2 n\rfloor$, so `foo` counts how many times you can take $\lfloor\log_2\rfloor$ before reaching 1 (an iterated-log count).
