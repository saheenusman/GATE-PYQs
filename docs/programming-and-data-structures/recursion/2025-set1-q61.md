# 2025 CS1 Q61: Recursion on a pointer-offset array

## Question

```c
#include <stdio.h>
int foo(int S[],int size){
    if(size == 0) return 0;
    if(size == 1) return 1;
    if(S[0] != S[1]) return 1+foo(S+1,size-1);
    return foo(S+1,size-1);
}
int main(){
    int A[]={0,1,2,2,2,0,0,1,1};
    printf("%d",foo(A,9));
    return 0;
}
```

The value printed by the given C program is _______ . (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`foo(S+1, size-1)` passes the array starting one element later, so each call compares the first two elements of the remaining part. In effect the recursion walks along $A = \lbrace 0,1,2,2,2,0,0,1,1\rbrace $ comparing neighbours.

| Call | Remaining part starts | `S[0]` vs `S[1]` | Contributes |
|---|---|---|---|
| size 9 | 0, 1, ... | 0 ≠ 1 | +1 |
| size 8 | 1, 2, ... | 1 ≠ 2 | +1 |
| size 7 | 2, 2, ... | equal | 0 |
| size 6 | 2, 2, ... | equal | 0 |
| size 5 | 2, 0, ... | 2 ≠ 0 | +1 |
| size 4 | 0, 0, ... | equal | 0 |
| size 3 | 0, 1, ... | 0 ≠ 1 | +1 |
| size 2 | 1, 1 | equal | 0 |
| size 1 | 1 | base case | returns 1 |

Total: $4$ (changes between neighbours) $+ 1$ (base case) $= 5$.

The function counts the **runs** of equal consecutive values. Here the runs are $\lbrace 0\rbrace ,\lbrace 1\rbrace ,\lbrace 2,2,2\rbrace ,\lbrace 0,0\rbrace ,\lbrace 1,1\rbrace $, which is 5. A list with $k$ runs has $k-1$ value changes, plus 1 from the base case, which gives $k$.

Compiled with `gcc -Wall -Wextra -std=c11` (no warnings) and run: prints `5`.

**Key idea:** the function counts runs of equal adjacent elements: each change adds 1, and the base case supplies the final run.

</details>
