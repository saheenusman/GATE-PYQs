# 2011 CS Q49: foo called with 513 and 2

## Question

**Common data for Questions 48 and 49.** Consider the following recursive C function that takes two arguments.

```c
unsigned int foo(unsigned int n, unsigned int r) {
    if (n > 0) return ((n % r) + foo(n / r, r));
    else return 0;
}
```

What is the return value of the function `foo` when it is called as `foo(513, 2)`?

- (A) 9
- (B) 8
- (C) 5
- (D) 2

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

With $r = 2$ the function returns the number of $1$ bits in the binary form of $n$.

$513 = 512 + 1 = 1000000001_2$, which has two $1$ bits.

The remainders along the calls are $1$ (from $513$), then eight $0$s ($256, 128, \ldots, 2$), then $1$ (from $1$):

$$513 \to 256 \to 128 \to 64 \to 32 \to 16 \to 8 \to 4 \to 2 \to 1 \to 0$$

Sum $= 1 + 0 \times 8 + 1 = 2$: (D).

- (A), (B) and (C) are not the digit sum $2$.

**Code check:** compiled with `gcc -Wall -Wextra` and run: `foo(513, 2) = 2`.

**Key idea:** in base 2 the digit sum is the population count (number of 1 bits).

</details>
