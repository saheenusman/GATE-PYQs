# 2014 CS2 Q40: Recursive function: value q with f(q) returning q

## Question

Consider the following function

```c
double f(double x){
   if( abs(x*x - 3) < 0.01) return x;
   else return f(x/2 + 1.5/x);
}
```

Give a value $q$ (to 2 decimals) such that `f(q)` will return $q$: _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**1.73**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`f(q)` returns `q` exactly when the **first** test succeeds, so that no recursion happens:

$$|q^2 - 3| < 0.01 \Rightarrow 2.99 < q^2 < 3.01 \Rightarrow 1.7292 < q < 1.7349$$

The only 2-decimal value in that range is $q = 1.73$ ($1.73^2 = 2.9929$).

(The recursion is Newton's method for $\sqrt{3}$: $x \mapsto x/2 + 1.5/x$. For other starts it converges to about $1.732$, a different value from the start, so `f` does not return the input.)

**Code check:** a C program (compiled with `gcc -Wall`, using `fabs`) tries every $q = 0.01, \ldots, 3.00$. Only `f(1.73)` returns its own argument; `f(1.00)` gives $1.73214$.

**Notes:** `abs` in the question is the integer function in C and would truncate a `double`; the code check uses `fabs`, which is what the question intends. Also, $q = -1.73$ works too, since the test uses $q^2$. The key accepts 1.72 to 1.74.

**Key idea:** the function returns its argument only if the base case holds at once.

</details>
