# 2015 CS3 Q38: Number of calls made by a doubly recursive function

## Question

Consider the following recursive C function.

```c
void get(int n)
{
    if (n<1) return;
    get(n-1);
    get(n-3);
    printf("%d", n);
}
```

If `get(6)` function is being called in `main()` then how many times will the `get()` function be invoked before returning to the `main()`?

- (A) 15
- (B) 25
- (C) 35
- (D) 45

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $C(n)$ be the number of calls (including the first) for `get(n)`:

- $C(n) = 1$ for $n < 1$ (the call returns at once).
- $C(n) = 1 + C(n-1) + C(n-3)$ for $n \ge 1$.

| $n$ | $C(n)$ |
|---|---|
| $\le 0$ | 1 |
| 1 | $1 + 1 + 1 = 3$ |
| 2 | $1 + 3 + 1 = 5$ |
| 3 | $1 + 5 + 1 = 7$ |
| 4 | $1 + 7 + 3 = 11$ |
| 5 | $1 + 11 + 5 = 17$ |
| 6 | $1 + 17 + 7 = \mathbf{25}$ |

Option (B). The other values do not match this count.

**Code check:** adding a counter to the function gives 25 calls for `get(6)`.

**Note.** The count includes the calls with $n < 1$ and the original call from `main`.

**Key idea:** write the call-count recurrence and evaluate it bottom-up.

</details>
