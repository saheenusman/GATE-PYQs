# 2015 CS2 Q21: Output of a recursive function that prints before returning

## Question

Consider the following function written in the C programming language.

```c
void foo (char *a) {
    if ( *a && *a != ' ' ) {
        foo(a+1);
        putchar(*a);
    }
}
```

The output of the above function on input "ABCD EFGH" is

- (A) ABCD EFGH
- (B) ABCD
- (C) HGFE DCBA
- (D) DCBA

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`putchar(*a)` runs **after** the recursive call returns, so characters are printed in reverse order of the descent.

- The recursion goes `A`, `B`, `C`, `D` and stops at the space (`*a != ' '` is false there).
- Unwinding prints `D`, then `C`, then `B`, then `A`.

Output: `DCBA`. Option (D). Nothing after the space is ever visited, so (A) and (C) are wrong, and (B) would need `putchar` *before* the recursive call.

**Code check:** compiled with `gcc -Wall` (with `<stdio.h>` added) and run on `"ABCD EFGH"`; the output was `DCBA`.

**Key idea:** work done after the recursive call happens on the way back, in reverse order.

</details>
