# 2015 CS2 Q24: Return value of a recursive function that sums products of smaller calls

## Question

Consider the following C function.

```c
int fun(int n) {
    int x=1, k;
    if (n==1) return x;
    for (k=1; k<n; ++k)
        x = x + fun(k) * fun(n-k);
    return x;
}
```

The return value of `fun(5)` is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**51**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$\text{fun}(1) = 1$, and for $n > 1$: $\text{fun}(n) = 1 + \sum_{k=1}^{n-1} \text{fun}(k)\,\text{fun}(n-k)$.

| $n$ | Working | fun($n$) |
|---|---|---|
| 1 | base case | 1 |
| 2 | $1 + 1\cdot1$ | 2 |
| 3 | $1 + 1\cdot2 + 2\cdot1$ | 5 |
| 4 | $1 + 1\cdot5 + 2\cdot2 + 5\cdot1$ | 15 |
| 5 | $1 + 1\cdot15 + 2\cdot5 + 5\cdot2 + 15\cdot1$ | 51 |

**Code check:** compiled with `gcc -Wall` and run; it printed `fun(1..5) = 1, 2, 5, 15, 51`.

**Key idea:** expand the recurrence bottom up, reusing the smaller values.

</details>
