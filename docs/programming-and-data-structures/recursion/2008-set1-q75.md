# 2008 CS Q75: Computing a linear recurrence recursively and by arrays

## Question

Consider the following C functions (common data for Q.74 and Q.75):

```c
int f1(int n)
{
    if (n == 0 || n == 1)
        return n;
    else
        return (2 * f1(n-1) + 3 * f1(n-2));
}

int f2(int n)
{
    int i;
    int X[N], Y[N], Z[N];
    X[0] = Y[0] = Z[0] = 0;
    X[1] = 1; Y[1] = 2; Z[1] = 3;
    for (i = 2; i <= n; i++) {
        X[i] = Y[i-1] + Z[i-2];
        Y[i] = 2 * X[i];
        Z[i] = 3 * X[i];
    }
    return X[n];
}
```

`f1(8)` and `f2(8)` return the values

- (A) 1661 and 1640
- (B) 59 and 59
- (C) 1640 and 1640
- (D) 1640 and 1661

<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**`f1`.** $f_1(n) = 2f_1(n-1) + 3f_1(n-2)$ with $f_1(0)=0,\ f_1(1)=1$:

| $n$ | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|
| $f_1(n)$ | 2 | 7 | 20 | 61 | 182 | 547 | 1640 |

**`f2`.** Since $Y[i] = 2X[i]$ and $Z[i] = 3X[i]$:

$$X[i] = Y[i-1] + Z[i-2] = 2X[i-1] + 3X[i-2],$$

the same recurrence with $X[0]=0,\ X[1]=1$. So $f_2(n) = f_1(n)$ and $f_2(8) = 1640$.

- (A) and (D) mix 1661 with 1640. $1661$ is not a term of the sequence.
- (B) $59$ is not a term either.

**Note:** `N` is not defined in the question. Any value $N \ge 9$ works.

**Code check:** compiled with `gcc -Wall` and `N = 16`: `f1(8)=1640`, `f2(8)=1640`; they also agree for every $n$ from 2 to 8.

**Key idea:** two programs that compute the same recurrence, one recursively and one with a loop, return the same values.

</details>
