# 2016 CS2 Q37: Value printed by a recursive maximum-difference function

## Question

Consider the following program:

```c
int f(int *p, int n)
{
   if (n <= 1) return 0;
   else return max(f(p+1,n-1),p[0]-p[1]);
}

int main()
{
   int a[] = {3,5,2,6,4};
   printf("%d", f(a,5));
}
```

Note: `max(x,y)` returns the maximum of $x$ and $y$.

The value printed by this program is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`f` returns the maximum of $p[i] - p[i+1]$ over all adjacent pairs, with a base value of $0$.

For $\lbrace 3, 5, 2, 6, 4 \rbrace$ the differences $p[i] - p[i+1]$ are $-2,\ 3,\ -4,\ 2$.

Unrolling: $f(a,5) = \max(f(a{+}1, 4),\, -2)$ and so on down to $f(\cdot, 1) = 0$, so the result is $\max(0, 2, -4, 3, -2) = 3$.

**Code check:** compiled and run with a `max` helper: prints `3`.

**Key idea:** the function is the maximum of $p[i] - p[i+1]$ (and 0): $\max(-2, 3, -4, 2, 0) = 3$.

</details>
