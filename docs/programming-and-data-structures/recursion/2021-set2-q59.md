# 2021 CS2 Q59: Output of a doubly recursive function foo(15, 15, 10)

## Question

Consider the following ANSI C program.

```c
#include <stdio.h>

int foo(int x, int y, int q)
{
    if ((x <= 0) && (y <= 0))
        return q;
    if (x <= 0)
        return foo(x, y-q, q);
    if (y <= 0)
        return foo(x-q, y, q);
    return foo(x, y-q, q) + foo(x-q, y, q);
}

int main()
{
    int r = foo(15,15,10);
    printf("%d", r);
    return 0;
}
```

The output of the program upon execution is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**60**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Write $g(x,y)=\texttt{foo}(x,y,10)$.

- If $x\le0$ and $y\le0$: $g=10$.
- If only one of $x,y$ is $\le0$, the other keeps being reduced by 10 until it is also $\le0$, so $g=10$.
- If both are positive: $g(x,y)=g(x,y-10)+g(x-10,y)$.

Evaluate:

| call | value |
|---|---|
| $g(5,5)=g(5,-5)+g(-5,5)$ | $10+10=20$ |
| $g(15,5)=g(15,-5)+g(5,5)$ | $10+20=30$ |
| $g(5,15)=g(5,5)+g(-5,15)$ | $20+10=30$ |
| $g(15,15)=g(15,5)+g(5,15)$ | $30+30=60$ |

**Run check:** compiled with `gcc -Wall` (no warnings); it prints `60`.

**Key idea:** trace the recursion tree; the base cases all return $q$, so the answer is $q$ times the number of leaves (6 leaves here).

</details>
