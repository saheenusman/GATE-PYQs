# 2021 CS2 Q33: Value returned by a recursive subtractive GCD function

## Question

Consider the following ANSI C function:

```c
int SomeFunction(int x, int y)
{
  if ((x == 1) || (y == 1)) return 1;
  if (x == y) return x;
  if (x > y) return SomeFunction(x - y, y);
  if (y > x) return SomeFunction(x, y - x);
}
```

The value returned by SomeFunction(15, 255) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**15**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

This is Euclid's algorithm by repeated subtraction, so it returns $\gcd(x,y)$ unless a 1 shows up first (in which case the gcd is 1 anyway).

Trace:

| call | action |
|---|---|
| (15, 255) | $y>x$: (15, 240) |
| (15, 240) | (15, 225) |
| ... | subtract 15 each time |
| (15, 30) | (15, 15) |
| (15, 15) | $x==y$: return 15 |

The recursion is 16 calls deep. The result is $\gcd(15,255)=15$.

**Run check:** compiled and run, it prints `15`. `gcc -Wall` gives one warning, "control reaches end of non-void function", because the compiler cannot see that one of `x==y`, `x>y`, `y>x` always holds. That end is unreachable for ints, so there is no undefined behaviour here.

**Key idea:** repeated subtraction until the two numbers are equal computes the gcd.

</details>
