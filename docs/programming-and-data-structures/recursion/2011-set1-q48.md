# 2011 CS Q48: foo called with 345 and 10

## Question

**Common data for Questions 48 and 49.** Consider the following recursive C function that takes two arguments.

```c
unsigned int foo(unsigned int n, unsigned int r) {
    if (n > 0) return ((n % r) + foo(n / r, r));
    else return 0;
}
```

What is the return value of the function `foo` when it is called as `foo(345, 10)`?

- (A) 345
- (B) 12
- (C) 5
- (D) 3

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`foo(n, r)` adds the last digit of $n$ in base $r$ and recurses on the rest, so it returns the **sum of the base-$r$ digits** of $n$.

| Call | $n \bmod 10$ | next $n / 10$ |
|---|---|---|
| `foo(345, 10)` | $5$ | $34$ |
| `foo(34, 10)` | $4$ | $3$ |
| `foo(3, 10)` | $3$ | $0$ |
| `foo(0, 10)` | returns $0$ | |

Total: $5 + 4 + 3 + 0 = 12$: (B).

- (A) $345$ is the argument itself; (C) $5$ is only the last digit; (D) $3$ is only the first digit.

**Code check:** compiled with `gcc -Wall -Wextra` and run: `foo(345, 10) = 12`.

**Key idea:** the function returns the digit sum of n in base r.

</details>
