# 2010 CS Q35: Alternating sum computed by a recursive function over an array

## Question

What is the value printed by the following C program?

```c
#include <stdio.h>
int f(int *a, int n)
{
    if (n <= 0) return 0;
    else if (*a % 2 == 0) return *a + f(a + 1, n - 1);
    else return *a - f(a + 1, n - 1);
}
int main()
{
    int a[] = {12, 7, 13, 4, 11, 6};
    printf("%d", f(a, 6));
    return 0;
}
```

- (A) $-9$
- (B) $5$
- (C) $15$
- (D) $19$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Even elements are **added** to the rest, odd elements are **subtracted** from it. Evaluate from the end of the array:

| Call (element, remaining $n$) | Rule | Value |
|---|---|---|
| $6$, $n=1$ | even: $6 + f(\cdot,0)$ | $6$ |
| $11$, $n=2$ | odd: $11 - 6$ | $5$ |
| $4$, $n=3$ | even: $4 + 5$ | $9$ |
| $13$, $n=4$ | odd: $13 - 9$ | $4$ |
| $7$, $n=5$ | odd: $7 - 4$ | $3$ |
| $12$, $n=6$ | even: $12 + 3$ | $15$ |

Output $15$: (C).

- (A) $-9$ and (D) $19$ come from flipping the sign rule on some element.
- (B) $5$ is the value of the call at `11`, not the top-level call.

**Code check:** compiled with `gcc -Wall -Wextra` (no warnings); output `15`.

**Key idea:** unwind the recursion from the base case, applying $+$ or $-$ as the element's parity dictates.

</details>
