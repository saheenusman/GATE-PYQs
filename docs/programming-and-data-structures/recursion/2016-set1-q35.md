# 2016 CS1 Q35: Output of a recursive function with a static variable

## Question

What will be the output of the following C program?

```c
void count(int n){
    static int d=1;
    printf("%d ", n);
    printf("%d ", d);
    d++;
    if(n>1) count(n-1);
    printf("%d ", d);
}
void main(){
    count(3);
}
```

- (A) `3 1 2 2 1 3 4 4 4`
- (B) `3 1 2 1 1 1 2 2 2`
- (C) `3 1 2 2 1 3 4`
- (D) `3 1 2 1 1 1 2`

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

`d` is `static`: one shared variable across all calls, initialised once to $1$.

| Call | Prints before | `d` after `d++` | Recurse? | Prints after |
|---|---|---|---|---|
| `count(3)` | `3 1` | 2 | yes | (later) |
| `count(2)` | `2 2` | 3 | yes | (later) |
| `count(1)` | `1 3` | 4 | no | `4` |
| back in `count(2)` | | | | `4` |
| back in `count(3)` | | | | `4` |

By the time any call prints its last value, `d` is $4$ (all increments already happened). Output:

```
3 1 2 2 1 3 4 4 4
```

**Why the others fail.** (B) treats `d` as a fresh local each call; (C) and (D) miss the three final prints.

**Code check:** compiled with `gcc -Wall` (using `int main`) and run: `3 1 2 2 1 3 4 4 4`.

**Key idea:** one shared static counter: the three trailing prints all show its final value 4.

</details>
