# 2009 CS Q18: Value printed by a recursive function that shares one pointer

## Question

Consider the program below:

```c
#include <stdio.h>
int fun(int n, int *f_p) {
    int t, f;
    if (n <= 1) {
        *f_p = 1;
        return 1;
    }
    t = fun(n-1, f_p);
    f = t + *f_p;
    *f_p = t;
    return f;
}
int main() {
    int x = 15;
    printf("%d\n", fun(5, &x));
    return 0;
}
```

The value printed is:

- (A) 6
- (B) 8
- (C) 14
- (D) 15

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Every call receives the **same** pointer `f_p`, the address of `x`. So `*f_p` is one shared variable, and its starting value $15$ is overwritten by `fun(1)` before it is ever read.

Trace from the bottom up. `t` is the value returned by the call below; `*f_p` is what that call left behind.

| Call | `t` | `*f_p` read | `f = t + *f_p` | `*f_p` after (`= t`) | Returns |
|---|---|---|---|---|---|
| `fun(1)` | n/a | n/a | n/a | $1$ (set in base case) | $1$ |
| `fun(2)` | $1$ | $1$ | $2$ | $1$ | $2$ |
| `fun(3)` | $2$ | $1$ | $3$ | $2$ | $3$ |
| `fun(4)` | $3$ | $2$ | $5$ | $3$ | $5$ |
| `fun(5)` | $5$ | $3$ | $8$ | $5$ | $8$ |

The returned values are the Fibonacci numbers $1, 2, 3, 5, 8$, so `fun(5)` prints $8$: (B).

- (A) $6$ and (C) $14$ are not in the sequence $1, 2, 3, 5, 8$.
- (D) $15$ is the original value of `x`, but `fun(1)` overwrites it before any read.

**Code check:** compiled with `gcc -Wall -Wextra`: no warnings. It prints `8`.

**Key idea:** a pointer passed down a recursion lets each level read what the level below wrote; here that carries the previous Fibonacci value.

</details>
