# 2018 CS Q55: Stars printed by a recursive Count procedure

## Question

Consider the following program written in pseudo-code. Assume that `x` and `y` are integers.

```c
Count(x,y) {
    if (y != 1){
        if (x != 1) {
            print("*");
            Count(x/2, y);
        }
        else {
            y = y-1;
            Count(1024, y);
        }
    }
}
```

The number of times that the `print` statement is executed by the call `Count(1024,1024)` is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**10230**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**One pass over $x$.** With `y` fixed, the call prints `*` and halves `x` until `x == 1`:

$$1024\to512\to256\to\cdots\to2\to1$$

That is 10 halvings, so **10 stars** per value of `y`. When `x == 1`, the `else` branch decrements `y` and restarts `x` at 1024.

**How many passes.** The recursion stops when `y == 1`. Starting from `y = 1024`, the passes happen for $y = 1024, 1023, \ldots, 2$, which is $1023$ passes.

$$1023\times10 = 10230$$

**Code check:** a direct C translation counted **10230** prints.

**Key idea:** the outer counter runs $1024\to1$ ($1023$ rounds); each round prints $\log_2 1024 = 10$ stars.

</details>
