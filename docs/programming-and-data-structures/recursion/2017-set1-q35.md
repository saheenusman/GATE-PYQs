# 2017 CS1 Q35: Output of two mutually recursive functions fun1 and fun2

## Question

Consider the following two functions.

```c
void fun1(int n) {
    if (n == 0) return;
    printf("%d", n);
    fun2(n - 2);
    printf("%d", n);
}

void fun2(int n) {
    if (n == 0) return;
    printf("%d", n);
    fun1(++n);
    printf("%d", n);
}
```

The output printed when `fun1(5)` is called is

- (A) `53423122233445`
- (B) `53423120112233`
- (C) `53423122132435`
- (D) `53423120213243`

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Trace.** Note that `++n` inside `fun2` changes `fun2`'s own `n` before the later `printf`.

| Call | Prints before | Calls | Prints after |
|---|---|---|---|
| `fun1(5)` | 5 | `fun2(3)` | 5 |
| `fun2(3)` | 3 | `fun1(4)` (n becomes 4) | 4 |
| `fun1(4)` | 4 | `fun2(2)` | 4 |
| `fun2(2)` | 2 | `fun1(3)` (n becomes 3) | 3 |
| `fun1(3)` | 3 | `fun2(1)` | 3 |
| `fun2(1)` | 1 | `fun1(2)` (n becomes 2) | 2 |
| `fun1(2)` | 2 | `fun2(0)` returns at once | 2 |

**Output in order.** Going down: $5,3,4,2,3,1,2$. At the bottom `fun1(2)` prints $2$ after `fun2(0)` returns. Coming back up: $2$ (`fun2(1)`), $3$ (`fun1(3)`), $3$ (`fun2(2)`), $4$ (`fun1(4)`), $4$ (`fun2(3)`), $5$ (`fun1(5)`):

$$5\,3\,4\,2\,3\,1\,2\;\;2\;\;2\,3\,3\,4\,4\,5 \;=\; 53423122233445$$

This is **(A)**.

**Why the others fail.** (B) and (D) contain a $0$ (nothing prints for $n=0$) and (C) has the wrong order on the way back up, ignoring that `fun2` prints its incremented `n`.

**Code check:** compiling and running the program printed `53423122233445`.

**Key idea:** `++n` changes the local copy, so the *after* print in `fun2` shows the incremented value.

</details>
