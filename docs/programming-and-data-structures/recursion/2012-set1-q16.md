# 2012 CS Q16: Recurrence for the Towers of Hanoi

## Question

The recurrence relation capturing the optimal execution time of the *Towers of Hanoi* problem with $n$ discs is

- (A) $T(n) = 2T(n-2) + 2$
- (B) $T(n) = 2T(n-1) + n$
- (C) $T(n) = 2T(n/2) + 1$
- (D) $T(n) = 2T(n-1) + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

To move $n$ discs: move the top $n-1$ to the spare peg ($T(n-1)$), move the largest disc (1 move), then move the $n-1$ back on top ($T(n-1)$):

$$T(n) = 2T(n-1) + 1,\qquad T(1) = 1.$$

It solves to $T(n) = 2^n - 1$. This is (D).

- (A) skips a disc size; the sub-problem has $n-1$ discs, not $n-2$.
- (B) charges $n$ for the middle step; moving one disc costs $1$.
- (C) halves the problem, which Hanoi does not do.

**Code check:** $2^n - 1$ satisfies $T(n) = 2T(n-1) + 1$ for $n = 1..11$.

**Key idea:** two recursive calls on $n-1$ plus one move gives $2T(n-1) + 1$.

</details>
