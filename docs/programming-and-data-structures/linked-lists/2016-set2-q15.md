# 2016 CS2 Q15: Total cost of deletes, inserts, finds and decrease-keys on a sorted doubly linked list

## Question

$N$ items are stored in a sorted doubly linked list. For a delete operation, a pointer is provided to the record to be deleted. For a decrease-key operation, a pointer is provided to the record on which the operation is to be performed.

An algorithm performs the following operations on the list in this order: $\Theta(N)$ delete, $O(\log N)$ insert, $O(\log N)$ find, and $\Theta(N)$ decrease-key. What is the time complexity of all these operations put together?

- (A) $O(\log^2 N)$
- (B) $O(N)$
- (C) $O(N^2)$
- (D) $\Theta(N^2 \log N)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Cost per operation on a sorted doubly linked list (no random access):

| Operation | Count | Cost each | Total |
|---|---|---|---|
| delete (pointer given) | $\Theta(N)$ | $O(1)$ | $\Theta(N)$ |
| insert | $O(\log N)$ | $O(N)$ (find the place) | $O(N \log N)$ |
| find | $O(\log N)$ | $O(N)$ (linear scan) | $O(N \log N)$ |
| decrease-key | $\Theta(N)$ | $O(N)$ (move the node to keep order) | $\Theta(N^2)$ |

The decrease-key term dominates: $O(N^2)$, **(C)**.

**Why the others fail.** (A) $O(\log^2 N)$ and (B) $O(N)$ are smaller than the decrease-key term. (D) $\Theta(N^2 \log N)$ is larger than anything above.

**Key idea:** $\Theta(N)$ decrease-keys at $O(N)$ each dominate: $O(N^2)$.

</details>
