# 2008 CS Q62: Swapping adjacent elements of a singly linked list

## Question

The following C function takes a singly-linked list of integers as a parameter and rearranges the elements of the list. The function is called with the list containing the integers 1, 2, 3, 4, 5, 6, 7 in the given order. What will be the contents of the list after the function completes execution?

```c
struct node {
    int value;
    struct node *next;
};

void rearrange(struct node *list) {
    struct node *p, *q;
    int temp;
    if (!list || !list->next) return;
    p = list; q = list->next;
    while (q) {
        temp = p->value; p->value = q->value;
        q->value = temp; p = q->next;
        q = p ? p->next : 0;
    }
}
```

- (A) 1, 2, 3, 4, 5, 6, 7
- (B) 2, 1, 4, 3, 6, 5, 7
- (C) 1, 3, 2, 5, 4, 7, 6
- (D) 2, 3, 4, 5, 6, 7, 1

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each loop iteration swaps the **values** of two neighbouring nodes `p` and `q = p->next`, then moves `p` two nodes ahead.

| Iteration | `p` at | `q` at | List after swap |
|---|---|---|---|
| 1 | 1 | 2 | 2 1 3 4 5 6 7 |
| 2 | 3 | 4 | 2 1 4 3 5 6 7 |
| 3 | 5 | 6 | 2 1 4 3 6 5 7 |
| end | 7 | none | `p = 7`, so `q = 0` and the loop stops |

The last node (7) has no partner, so it stays: $2,1,4,3,6,5,7$.

- (A) would mean no swap happened.
- (C) swaps starting from the second pair, not the first.
- (D) is a rotation, but values are only swapped pairwise.

**Code check:** built the list $1..7$, ran `rearrange` and printed `2,1,4,3,6,5,7`.

**Key idea:** the loop swaps adjacent pairs by value, leaving a last unpaired element in place.

</details>
