# 2017 CS2 Q43: Output of a two-direction bubble-sort loop

## Question

Consider the following snippet of a C program. Assume that `swap(&x, &y)` exchanges the contents of `x` and `y`.

```c
int main() {
    int array[] = {3, 5, 1, 4, 6, 2};
    int done = 0;
    int i;

    while (done == 0) {
        done = 1;
        for (i = 0; i <= 4; i++) {
            if (array[i] < array[i+1]) {
                swap(&array[i], &array[i+1]);
                done = 0;
            }
        }
        for (i = 5; i >= 1; i--) {
            if (array[i] > array[i-1]) {
                swap(&array[i], &array[i-1]);
                done = 0;
            }
        }
    }
    printf("%d", array[3]);
}
```

The output of the program is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**3**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What it does.** The first `for` moves smaller values towards the right (swap when `array[i] < array[i+1]`, so larger values go left). The second `for` goes right to left and swaps when `array[i] > array[i-1]`, which also moves larger values left. The loop repeats until a whole round makes no swap. So it sorts the array in **descending** order.

**Round 1.**

- Forward pass: $3,5,1,4,6,2 \to 5,3,1,4,6,2 \to 5,3,4,1,6,2 \to 5,3,4,6,1,2 \to 5,3,4,6,2,1$.
- Backward pass: no swaps at $i=5,4$; then $i=3$: $5,3,6,4,2,1$; $i=2$: $5,6,3,4,2,1$; $i=1$: $6,5,3,4,2,1$.

**Round 2.** Forward pass swaps $3,4$: $6,5,4,3,2,1$. The backward pass makes no swap, but `done` was set to 0 earlier in this round, so another round follows.

**Round 3.** No swaps in either pass, `done` stays 1, and the loop ends.

The final array is $6,5,4,3,2,1$, and `array[3]` $= 3$.

**Code check:** compiled with `gcc -Wall` (no warnings). The program printed the array after each round (`6 5 3 4 2 1`, then `6 5 4 3 2 1`, then unchanged) and output `3`.

**Key idea:** this is a cocktail-shaker style sort in descending order. `array[3]` is the 4th largest of $\lbrace 1..6\rbrace$, i.e. 3.

</details>
