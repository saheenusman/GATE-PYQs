# 2016 CS1 Q34: Missing loop condition in a function that finds the array maximum

## Question

The following function computes the maximum value contained in an integer array `p[]` of size $n$ ($n \ge 1$).

```c
int max(int *p, int n) {
    int a=0, b=n-1;

    while (__________) {
        if (p[a] <= p[b]) { a = a+1; }
        else { b = b-1; }
    }
    return p[a];
}
```

The missing loop condition is

- (A) `a != n`
- (B) `b != 0`
- (C) `b > (a + 1)`
- (D) `b != a`

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Invariant.** The maximum of the array is always inside $p[a..b]$.

- If $p[a] \le p[b]$, then $p[a]$ is not needed (the maximum is at least $p[b]$), so $a$ moves right.
- Otherwise $p[b] < p[a]$, so $p[b]$ is not needed and $b$ moves left.

Each step shrinks the window by one. When the window has **one** element, $a = b$ and that element is the maximum. So the loop must run while `b != a`.

**Why the others fail.**

| Option | Failure |
|---|---|
| (A) `a != n` | keeps going after $a = b$ and reads $p[n]$, out of bounds (e.g. `{5,1}`) |
| (B) `b != 0` | for `{1,5}` $b$ never reaches $0$, so $a$ runs past the array |
| (C) `b > (a+1)` | stops with two elements left and returns `p[a]`, which is wrong for `{1,2}` |

**Code check:** with the condition `b != a`, the function returned the true maximum on $20{,}000$ random arrays of length $1$ to $12$.

**Key idea:** a window-shrinking invariant ends exactly when $a = b$.

</details>
