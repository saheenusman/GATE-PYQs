# 2014 CS1 Q41: What does the triple-loop function MyX return

## Question

Consider the following C function in which `size` is the number of elements in the array `E`:

```c
int MyX(int *E, unsigned int size)
{
  int Y = 0;
  int Z;
  int i, j, k;

  for(i = 0; i < size; i++)
      Y = Y + E[i];

  for(i = 0; i < size; i++)
      for(j = i; j < size; j++)
      {
         Z = 0;
         for(k = i; k <= j; k++)
             Z = Z + E[k];
         if (Z > Y)
             Y = Z;
      }
  return Y;
}
```

The value returned by the function `MyX` is the

- (A) maximum possible sum of elements in any sub-array of array `E`.
- (B) maximum element in any sub-array of array `E`.
- (C) sum of the maximum elements in all possible sub-arrays of array `E`.
- (D) the sum of all the elements in the array `E`.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The first loop sets `Y` to the sum of the whole array. The nest then visits every sub-array $E[i..j]$, computes its sum $Z$, and keeps the larger of `Y` and `Z`. The whole array is itself a sub-array, so `Y` ends as the **maximum sub-array sum**.

**Code check:** compiled with `gcc -Wall -Wextra` (only `-Wsign-compare` warnings from comparing `int` with `unsigned`) and run on three arrays:

| Array | Returned | Best sub-array sum |
|---|---|---|
| `{-2,1,-3,4,-1,2,1,-5,4}` | 6 | 6 |
| `{-3,-1,-2}` | -1 | -1 |
| `{5,-9,6,7,-2}` | 13 | 13 |

- (B) the code adds elements; it never takes a maximum element.
- (C) it keeps only one running maximum, not a sum over sub-arrays.
- (D) `Y` is replaced whenever a sub-array sum is larger, so the answer can exceed the total.

**Key idea:** the triple loop brute-forces the maximum sub-array sum in $O(n^3)$.

</details>
