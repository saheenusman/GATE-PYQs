# 2016 CS1 Q41: Maximum iterations of a queue and stack shuffling loop

## Question

Let $Q$ denote a queue containing sixteen numbers and $S$ be an empty stack. $\text{Head}(Q)$ returns the element at the head of the queue $Q$ without removing it from $Q$. Similarly $\text{Top}(S)$ returns the element at the top of $S$ without removing it from $S$. Consider the algorithm given below.

```
while Q is not Empty do
    if S is Empty OR Top(S) <= Head(Q) then
        x := Dequeue(Q);
        Push(S, x);
    else
        x := Pop(S);
        Enqueue(Q, x);
    end
end
```

The maximum possible number of iterations of the while loop in the algorithm is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**256**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What an iteration does.** Each iteration either *pushes* the head of $Q$ onto $S$, or *pops* the top of $S$ back onto the tail of $Q$. Every element is pushed at least once, so the number of iterations is $n$ plus twice the number of pops, minus whatever is left on $S$ when $Q$ empties.

**Worst case: strictly decreasing input** $16, 15, \dots, 1$. Each new head is smaller than the stack top, so the stack top is popped back to the queue, and the pattern repeats for every pair. The count is $n^2$.

**Evidence.**

- Exhaustively trying every permutation, the maximum number of iterations was exactly $n^2$ for $n = 1, \dots, 9$ ($1, 4, 9, \dots, 81$).
- For $n = 16$ the decreasing input takes $256 = 16^2$ iterations, and $300{,}000$ random permutations of $16$ values never exceeded $256$.

So the maximum is $16^2 = 256$.

**Caveat.** My check for $n = 16$ shows $256$ is reached and (by sampling and the exact small cases) not exceeded; I have not proved the upper bound for $n = 16$ analytically. It agrees with the official key.

**Key idea:** reversed input forces the most pops, giving $n^2 = 256$ iterations.

</details>
