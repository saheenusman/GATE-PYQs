# 2024 CS2 Q48: Reachable outputs with two stacks

## Question

Let S1 and S2 be two stacks. S1 has capacity of 4 elements. S2 has capacity of 2 elements. S1 already has 4 elements: 100, 200, 300, and 400 (400 on top), whereas S2 is empty.

Only the following three operations are available:

- **PushToS2:** pop the top element from S1 and push it on S2.
- **PushToS1:** pop the top element from S2 and push it on S1.
- **GenerateOutput:** pop the top element from S1 and output it to the user.

Note that the pop operation is not allowed on an empty stack and the push operation is not allowed on a full stack.

Which of the following output sequences can be generated by using the above operations?

- (A) 100, 200, 400, 300
- (B) 200, 300, 400, 100
- (C) 400, 200, 100, 300
- (D) 300, 200, 400, 100

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

I searched all reachable states (breadth-first) to confirm each sequence. Operation sequences (T2 = PushToS2, T1 = PushToS1, Out = GenerateOutput):

- **(B) 200, 300, 400, 100:** T2 (400), T2 (300), Out 200, T1 (300), Out 300, T1 (400), Out 400, Out 100. ✓
- **(C) 400, 200, 100, 300:** Out 400, T2 (300), Out 200, Out 100, T1 (300), Out 300. ✓
- **(D) 300, 200, 400, 100:** T2 (400), Out 300, Out 200, T1 (400), Out 400, Out 100. ✓
- **(A) 100, 200, 400, 300:** to output 100 first, the three elements above it (200, 300, 400) must all be parked, but S2 holds only 2 and S1 cannot hold them elsewhere. ✗

**Key idea:** S2 is a 2-slot buffer. An element can be pulled out of order only if the elements above it fit in S2.

</details>
