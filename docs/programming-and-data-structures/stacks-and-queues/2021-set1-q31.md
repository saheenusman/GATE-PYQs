# 2021 CS1 Q31: Stack and queue operation sequence

## Question

Consider the following sequence of operations on an empty stack.

`push(54); push(52); pop(); push(55); push(62); s = pop();`

Consider the following sequence of operations on an empty queue.

`enqueue(21); enqueue(24); dequeue(); enqueue(28); enqueue(32); q = dequeue();`

The value of `s + q` is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**86**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Stack (top on the right).**

| Operation | Stack |
|---|---|
| push(54) | 54 |
| push(52) | 54 52 |
| pop() | 54 |
| push(55) | 54 55 |
| push(62) | 54 55 62 |
| s = pop() | 54 55, **s = 62** |

**Queue (front on the left).**

| Operation | Queue |
|---|---|
| enqueue(21) | 21 |
| enqueue(24) | 21 24 |
| dequeue() | 24 |
| enqueue(28) | 24 28 |
| enqueue(32) | 24 28 32 |
| q = dequeue() | 28 32, **q = 24** |

$s+q=62+24=\mathbf{86}$.

Simulated with Python (list as stack, `deque` as queue): 62, 24, 86.

**Key idea:** a stack is last-in first-out and a queue is first-in first-out.

</details>
