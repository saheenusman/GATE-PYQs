# 2007 CS Q38: Top of stack after the first * in a postfix expression

## Question

The following postfix expression with single digit operands is evaluated using a stack:

```
8 2 3 ^ / 2 3 * + 5 1 * -
```

Note that `^` is the exponentiation operator. The top two elements of the stack after the first `*` is evaluated are:

- (A) 6, 1
- (B) 5, 7
- (C) 3, 2
- (D) 1, 5

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Scan left to right, pushing operands and applying each operator to the top two elements:

| Token | Stack (bottom to top) |
|---|---|
| 8 | 8 |
| 2 | 8 2 |
| 3 | 8 2 3 |
| ^ | 8 8 |
| / | 1 |
| 2 | 1 2 |
| 3 | 1 2 3 |
| * | 1 6 |

After the first `*` the stack holds $1, 6$, so the top two elements are $6$ (top) and $1$: (A).

- (B) $5, 7$ and (D) $1, 5$ are values that occur *later* in the evaluation (after `+` gives 7 and the second `*` gives 5).
- (C) $3, 2$ are the operands consumed by that `*`.

(The full expression evaluates to $7 - 5 = 2$.)

**Code check:** Python stack evaluation: after the first `*` the top is 6 and the element below is 1; final value 2.

**Key idea:** postfix evaluation: operands are pushed, an operator pops two and pushes the result.
