# 2014 CS2 Q41: Queue from a stack with a REVERSE instruction

## Question

Suppose a stack implementation supports an instruction REVERSE, which reverses the order of elements on the stack, in addition to the PUSH and POP instructions. Which one of the following statements is TRUE *with respect to this modified stack*?

- (A) A queue cannot be implemented using this stack.
- (B) A queue can be implemented where ENQUEUE takes a single instruction and DEQUEUE takes a sequence of two instructions.
- (C) A queue can be implemented where ENQUEUE takes a sequence of three instructions and DEQUEUE takes a single instruction.
- (D) A queue can be implemented where both ENQUEUE and DEQUEUE take a single instruction each.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Keep the **front of the queue at the top** of the stack.

- DEQUEUE: `POP`. **1 instruction.**
- ENQUEUE $x$: the new item must go under all others. Do `REVERSE`, `PUSH x`, `REVERSE`. **3 instructions.**

**Code check:** this passes a random test against a real queue.

- (A) false, as above.
- (B) `ENQUEUE = PUSH`, `DEQUEUE = REVERSE, POP` fails. After the `REVERSE` the stack stays reversed, so the next dequeue returns the wrong item. With elements 1, 2, 3 enqueued, the second dequeue returns 3 instead of 2. The test confirms it fails. (`ENQUEUE = PUSH` with `DEQUEUE = REVERSE, POP, REVERSE`, 3 instructions, does work, but that is not the option.)
- (D) one instruction each is impossible: `PUSH` puts the new item on the wrong end for FIFO order, and `POP` takes the newest.

**Key idea:** `REVERSE` lets a stack insert at the bottom; the cost is moved to ENQUEUE or DEQUEUE.

</details>
