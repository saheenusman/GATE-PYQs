# 2016 CS1 Q10: Time of ENQUEUE and DEQUEUE in an array-based queue

## Question

A queue is implemented using an array such that ENQUEUE and DEQUEUE operations are performed efficiently. Which one of the following statements is CORRECT ($n$ refers to the number of items in the queue)?

- (A) Both operations can be performed in $O(1)$ time
- (B) At most one operation can be performed in $O(1)$ time but the worst case time for the other operation will be $\Omega(n)$
- (C) The worst case time complexity for both operations will be $\Omega(n)$
- (D) Worst case time complexity for both operations will be $\Omega(\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use a **circular array** with a `head` index and a `tail` index.

- ENQUEUE writes at `tail` and moves it forward modulo the array size: $O(1)$.
- DEQUEUE reads at `head` and moves it forward modulo the array size: $O(1)$.

No elements are shifted, so both operations take constant time.

**Why the others fail.** (B), (C) and (D) claim that some operation must take $\Omega(n)$ or $\Omega(\log n)$ time in the worst case. That is true only if dequeuing shifts every element left, which is the naive layout and not the efficient one the question describes.

**Key idea:** a circular array gives $O(1)$ ENQUEUE and DEQUEUE.

</details>
