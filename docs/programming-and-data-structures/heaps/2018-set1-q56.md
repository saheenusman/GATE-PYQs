# 2018 CS Q56: Number of min-heaps on seven distinct values

## Question

The number of possible min-heaps containing each value from $\lbrace 1, 2, 3, 4, 5, 6, 7\rbrace$ exactly once is _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**80**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Shape.** A heap with 7 nodes is a perfect binary tree: a root with two subtrees of 3 nodes each.

**Root.** In a min-heap the root is the minimum, so the root is $1$.

**Split the other six values.** Choose which 3 go to the left subtree: $\binom{6}{3} = 20$ ways. The other 3 go right.

**Each 3-node subtree.** Its smallest value must be at its root. The other two values fill the two leaves in either order: 2 ways.

$$20\times2\times2 = 80$$

**Code check:** testing the heap property on all $7! = 5040$ arrangements of the values in the array positions found exactly **80** valid heaps.

**Key idea:** count recursively: root fixed, choose the left subtree's elements, then multiply the heap counts of the two subtrees.

</details>
