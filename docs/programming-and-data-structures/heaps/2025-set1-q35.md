# 2025 CS1 Q35: Height of a min-heap with 32 keys

## Question

The height of any rooted tree is defined as the maximum number of edges in the path from the root node to any leaf node.

Suppose a Min-Heap $T$ stores 32 keys. The height of $T$ is _____________. (Answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A heap is a **complete** binary tree: every level is full except possibly the last, which fills from the left. Level $k$ (root is level 0) holds up to $2^k$ nodes.

| Level | Max nodes | Nodes so far |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 2 | 3 |
| 2 | 4 | 7 |
| 3 | 8 | 15 |
| 4 | 16 | 31 |
| 5 | 32 | 32 (only 1 used) |

Levels 0 to 4 hold exactly 31 nodes. The 32nd key must start a new level 5, as its left-most node. So the deepest leaf is at depth 5.

In general a heap with $n$ nodes has height $\lfloor \log_2 n \rfloor$, and $\lfloor \log_2 32 \rfloor = 5$.

Note the trap: $\log_2 32 = 5$ exactly, but 32 is $2^5$, one node more than a full tree of height 4, so the height is 5 rather than 4.

**Key idea:** height of an $n$-node heap is $\lfloor \log_2 n \rfloor$, and it jumps up whenever $n$ reaches a power of 2.

</details>
