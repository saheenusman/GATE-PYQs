# 2024 CS1 Q41: First three elements after heapifying

## Question

An array $[82, 101, 90, 11, 111, 75, 33, 131, 44, 93]$ is heapified. Which one of the following options represents the first three elements in the heapified array?

- (A) 82, 90, 101
- (B) 82, 11, 93
- (C) 131, 11, 93
- (D) 131, 111, 90

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Build a max-heap** (bottom-up heapify) on 10 elements. Sift down each internal node, from index 5 down to 1 (1-based):

| Step | Sift down (index, value) | Swaps | Array after |
|---|---|---|---|
| start | | | 82, 101, 90, 11, 111, 75, 33, 131, 44, 93 |
| 1 | idx 5, 111 | child 93 smaller: none | unchanged |
| 2 | idx 4, 11 | swap with 131 (idx 8) | 82, 101, 90, **131**, 111, 75, 33, **11**, 44, 93 |
| 3 | idx 3, 90 | children 75, 33 smaller: none | unchanged |
| 4 | idx 2, 101 | swap with 131 (idx 4) | 82, **131**, 90, **101**, 111, 75, 33, 11, 44, 93 |
| 5 | idx 1, 82 | swap with 131, then 111, then 93 | **131, 111, 90, 101, 93, 75, 33, 11, 44, 82** |

Final heap: $[131, 111, 90, 101, 93, 75, 33, 11, 44, 82]$ (confirmed by running the algorithm). First three: **131, 111, 90**.

**Why the others fail:**

- **(A), (B)** start with 82, the original root. After heapifying a max-heap, the root must be the maximum, 131.
- **(C)** puts 11 at position 2. 11 is the smallest value, so in a max-heap it can only be in a leaf, and position 2 is an internal node.

**Key idea:** bottom-up heapify sifts down each internal node from the last parent to the root. The result is a max-heap with the maximum at the root.

</details>
