# 2021 CS2 Q12: Time to find the maximum of a binary min-heap

## Question

Let $H$ be a binary min-heap consisting of $n$ elements implemented as an array. What is the worst case time complexity of an optimal algorithm to find the maximum element in $H$?

- (A) $\Theta(1)$
- (B) $\Theta(\log n)$
- (C) $\Theta(n)$
- (D) $\Theta(n\log n)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a min-heap the root is the smallest. The maximum is **somewhere among the leaves**, but the heap gives no information about which leaf. The leaves are about $\lceil n/2\rceil$ elements.

- Upper bound: scan the $\lceil n/2\rceil$ leaves, which takes $O(n)$.
- Lower bound: any leaf could be the maximum, and a leaf's value is not bounded by any other leaf. An algorithm that skips a leaf cannot rule it out, so it needs $\Omega(n)$ comparisons.

So $\Theta(n)$, (C).

- (A) and (B) would be possible only for the minimum, or for a max-heap.
- (D) is more than a single scan.

**Key idea:** a heap orders a node only against its ancestors and descendants, so the leaves are unordered relative to each other.

</details>
