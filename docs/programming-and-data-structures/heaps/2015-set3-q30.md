# 2015 CS3 Q30: Minimum interchanges to turn an array into a max-heap

## Question

Consider the following array of elements.

$\langle 89, 19, 50, 17, 12, 15, 2, 5, 7, 11, 6, 9, 100 \rangle$

The minimum number of interchanges needed to convert it into a max-heap is

- (A) 4
- (B) 5
- (C) 2
- (D) 3

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Index the array from 1. The parent of $i$ is $\lfloor i/2 \rfloor$. Build the heap bottom-up from the last internal node (index 6):

| Step | Node | Children | Action |
|---|---|---|---|
| 1 | 15 (idx 6) | 9, 100 | swap with 100 |
| 2 | 12 (idx 5) | 11, 6 | none |
| 3 | 17 (idx 4) | 5, 7 | none |
| 4 | 50 (idx 3) | 100, 2 | swap with 100 |
| 5 | 19 (idx 2) | 17, 12 | none |
| 6 | 89 (idx 1) | 19, 100 | swap with 100 |

Three swaps, giving

$\langle 100, 19, 89, 17, 12, 50, 2, 5, 7, 11, 6, 9, 15 \rangle$

**Why not fewer.** 100 starts at the bottom (index 13) under 15, 50 and 89, all smaller than it, so every ancestor on that path is out of order.

**Code check:** I tried every pair of swaps (of any two positions) and none gives a max-heap, so 2 is not enough. Bottom-up build uses exactly 3 swaps and gives a valid heap. Option (D).

**Key idea:** bottom-up heap construction (Floyd) sifts each internal node down. Here only three nodes need to move.

</details>
