# 2014 CS2 Q12: Level-order of a max-heap after inserting 1 and 7

## Question

A priority queue is implemented as a Max-Heap. Initially, it has 5 elements. The level-order traversal of the heap is: 10, 8, 5, 3, 2. Two new elements 1 and 7 are inserted into the heap in that order. The level-order traversal of the heap after the insertion of the elements is:

- (A) 10, 8, 7, 3, 2, 1, 5
- (B) 10, 8, 7, 2, 3, 1, 5
- (C) 10, 8, 7, 1, 2, 3, 5
- (D) 10, 8, 7, 5, 3, 2, 1

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Insert at the next free leaf, then swap upward while the new key is larger than its parent.

| Step | Array (index 1..) | Action |
|---|---|---|
| start | 10, 8, 5, 3, 2 | |
| insert 1 | 10, 8, 5, 3, 2, 1 | parent of index 6 is index 3 (5); $1 < 5$, stop |
| insert 7 | 10, 8, 5, 3, 2, 1, 7 | parent of index 7 is index 3 (5); $7 > 5$, swap |
| | 10, 8, 7, 3, 2, 1, 5 | parent of index 3 is the root (10); $7 < 10$, stop |

Result: 10, 8, 7, 3, 2, 1, 5.

**Code check:** a max-heap insert routine gives `[10, 8, 7, 3, 2, 1, 5]`.

- (B) and (C) change the order of 3 and 2, which insertion never moves.
- (D) is a sorted list, not what heap insertion produces.

**Key idea:** insert at the end, then sift up through the parent chain.

</details>
