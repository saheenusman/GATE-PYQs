# 2023 CS Q12: Which array is a max-heap

## Question

Which one of the following sequences when stored in an array at locations $A[1], \ldots, A[10]$ forms a max-heap?

- (A) 23, 17, 10, 6, 13, 14, 1, 5, 7, 12
- (B) 23, 17, 14, 7, 13, 10, 1, 5, 6, 12
- (C) 23, 17, 14, 6, 13, 10, 1, 5, 7, 15
- (D) 23, 14, 17, 1, 10, 13, 16, 12, 7, 5

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rule.** With 1-based indexing, the children of $A[i]$ are $A[2i]$ and $A[2i+1]$. A max-heap needs every parent $\ge$ its children.

**Check each option for a violation:**

| Option | Violation found |
|---|---|
| A | $A[3]=10$ has child $A[6]=14 > 10$ |
| **B** | none: 23 ≥ 17, 14; 17 ≥ 7, 13; 14 ≥ 10, 1; 7 ≥ 5, 6; 13 ≥ 12 |
| C | $A[5]=13$ has child $A[10]=15 > 13$ |
| D | $A[4]=1$ has child $A[8]=12 > 1$ |

A short script confirmed that only B passes the parent-child test.

**Key idea:** test each parent $A[i]$ against $A[2i]$ and $A[2i+1]$.

</details>
