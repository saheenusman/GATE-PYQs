# 2009 CS Q60: Array after two delete-max operations on the heap of Q59

## Question

**Statement for linked answer questions 59 and 60.** Consider a binary max-heap implemented using an array.

What is the content of the array after two delete operations on the correct answer to the previous question?

- (A) `{ 14, 13, 12, 10, 8 }`
- (B) `{ 14, 12, 13, 8, 10 }`
- (C) `{ 14, 13, 8, 12, 10 }`
- (D) `{ 14, 13, 12, 8, 10 }`

*Linked question: "the previous question" is Q59, whose correct answer is (C), `{ 25, 14, 16, 13, 10, 8, 12 }`. A delete removes the maximum (the root).*

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Start from the heap `25, 14, 16, 13, 10, 8, 12`.

**First delete (removes 25).** Move the last element $12$ to the root, shrink the heap, then sift down. The children of $12$ are $14$ and $16$; swap with the larger, $16$. Now $12$ has child $8$ only (no larger child), so it stops.

$$16,\ 14,\ 12,\ 13,\ 10,\ 8$$

**Second delete (removes 16).** Move the last element $8$ to the root. Its children are $14$ and $12$; swap with $14$. Now $8$ sits at index 1 with children $13$ and $10$; swap with $13$.

$$14,\ 13,\ 12,\ 8,\ 10$$

This is (D).

- (A) `14, 13, 12, 10, 8` and (B) `14, 12, 13, 8, 10` happen to be valid max-heaps too, so the heap rule alone does not rule them out. They are not what delete-max produces: the sift-down sends the moved element $8$ down the path of larger children ($14$, then $13$), which leaves it at index 3 and $10$ at index 4, with $13$ and $12$ as the root's children in that order.
- (C) `14, 13, 8, 12, 10` is not a heap at all: $8$ is the parent of $12$ and $10$.

**Code check:** a delete-max routine run twice on the Q59 array gave `[14, 13, 12, 8, 10]`.

**Key idea:** delete-max moves the last element to the root and sifts it down, always swapping with the larger child.

</details>
