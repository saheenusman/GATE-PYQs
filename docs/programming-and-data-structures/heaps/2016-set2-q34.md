# 2016 CS2 Q34: Maximum depth of integer 9 in a complete binary min-heap of 1 to 1023

## Question

A complete binary min-heap is made by including each integer in $[1, 1023]$ exactly once. The depth of a node in the heap is the length of the path from the root of the heap to that node. Thus, the root is at depth 0. The maximum depth at which integer 9 can appear is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a min-heap every ancestor of a node holds a smaller value. Only the integers $1, \dots, 8$ are smaller than $9$, so $9$ has **at most $8$ ancestors**, and its depth is at most $8$.

**It can be reached.** $1023 = 2^{10} - 1$, so the heap is a full tree with levels $0$ to $9$. Put $1, 2, \dots, 8$ along a root-to-node path (depths $0$ to $7$), put $9$ at depth $8$ below $8$, and fill everything else with larger numbers in heap order.

So the maximum depth is $8$.

**Key idea:** $9$ has at most $8$ smaller ancestors, so depth $\le 8$, and a path $1..8, 9$ achieves it.

</details>
