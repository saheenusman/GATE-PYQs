# 2009 CS Q59: Which array is a binary max-heap

## Question

**Statement for linked answer questions 59 and 60.** Consider a binary max-heap implemented using an array.

Which one of the following arrays represents a binary max-heap?

- (A) `{ 25, 12, 16, 13, 10, 8, 14 }`
- (B) `{ 25, 14, 13, 16, 10, 8, 12 }`
- (C) `{ 25, 14, 16, 13, 10, 8, 12 }`
- (D) `{ 25, 14, 12, 13, 10, 8, 16 }`

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In an array heap with indices from $0$, the children of index $i$ are $2i+1$ and $2i+2$. Max-heap rule: every parent is at least as large as both children.

For (C) `25, 14, 16, 13, 10, 8, 12`:

- $25$ has children $14, 16$: both smaller.
- $14$ (index 1) has children $13, 10$: both smaller.
- $16$ (index 2) has children $8, 12$: both smaller.

So (C) is a max-heap.

- (A) $12$ (index 1) has children $13, 10$, and $13 > 12$.
- (B) $14$ (index 1) has children $16, 10$, and $16 > 14$.
- (D) $12$ (index 2) has children $8, 16$, and $16 > 12$.

**Code check:** a short parent-versus-children test over the four arrays accepted only (C).

**Key idea:** check every parent against its two children; one violation is enough to reject an array.

</details>
