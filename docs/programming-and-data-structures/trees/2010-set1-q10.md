# 2010 CS Q10: Nodes with exactly one child when every node has an odd number of descendants

## Question

In a binary tree with $n$ nodes, every node has an odd number of descendants. Every node is considered to be its own descendant. What is the number of nodes in the tree that have exactly one child?

- (A) $0$
- (B) $1$
- (C) $(n-1)/2$
- (D) $n-1$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $d(v)$ be the number of descendants of $v$, counting $v$ itself. Look at each kind of node:

- **Leaf:** $d = 1$, odd, allowed.
- **Two children $a, b$:** $d = 1 + d(a) + d(b) = 1 + \text{odd} + \text{odd} = \text{odd}$, allowed.
- **Exactly one child $c$:** $d = 1 + d(c) = 1 + \text{odd} = \text{even}$, **not allowed**.

So no node can have exactly one child: the answer is $0$ (A). (Such a tree is a full binary tree, so $n$ is odd.)

- (B) and (D) would require at least one node with a single child, which breaks the parity rule.
- (C) $(n-1)/2$ is the number of internal nodes of a full binary tree on $n$ nodes, not the number of one-child nodes.

**Code check:** all binary tree shapes with up to $11$ nodes were enumerated. In every tree where each node has an odd number of descendants, the count of one-child nodes was $0$.

**Key idea:** a one-child node has $1 + \text{odd}$ descendants, which is even, so it cannot exist.

</details>
