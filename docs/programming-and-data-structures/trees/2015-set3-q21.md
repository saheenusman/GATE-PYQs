# 2015 CS3 Q21: Nodes with two children in a binary tree with 200 leaves

## Question

Consider a binary tree $T$ that has 200 leaf nodes. Then, the number of nodes in $T$ that have exactly two children are ________

<details class="success" markdown="1">
<summary>Answer</summary>

**199**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $n_0, n_1, n_2$ be the numbers of nodes with 0, 1 and 2 children.

- Total nodes: $n = n_0 + n_1 + n_2$.
- A tree with $n$ nodes has $n - 1$ edges, and each edge goes to a child: $n - 1 = n_1 + 2n_2$.

Substitute $n$: $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$, so

$$n_0 = n_2 + 1$$

With $n_0 = 200$: $n_2 = 199$.

**Answer: 199.**

**Code check:** random binary trees (2000 of them, up to 40 nodes) always satisfied $n_2 = n_0 - 1$.

**Key idea:** in any binary tree, leaves $=$ nodes with two children $+ 1$.

</details>
