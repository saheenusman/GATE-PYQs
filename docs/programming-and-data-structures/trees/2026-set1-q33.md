## Question

The height of a binary tree is the number of edges in the longest path from the root to a leaf in the tree. The maximum possible height of a full binary tree with 23 nodes is _____. (answer in integer)

??? success "Answer"
    **11**

??? info "Solution"
    A **full** binary tree has every node with 0 or 2 children.

    **Step 1: count internal nodes.** Let $i$ be the number of internal nodes. Then there are $i+1$ leaves, so

    $$2i + 1 = 23 \Rightarrow i = 11.$$

    **Step 2: bound the height.** A longest root-to-leaf path with $h$ edges has $h+1$ nodes. Every node on it except the last (the leaf) is internal, so $h \le i = 11$.

    **Step 3: achieve it.** Make a "spine": each internal node has one leaf child and one internal child.

    ```mermaid
    flowchart TD
        A((root)) --> L1((leaf))
        A --> B((int))
        B --> L2((leaf))
        B --> C((int))
        C --> L3((leaf))
        C --> L4((leaf))
    ```
    *A 7-node spine has 3 internal nodes and height 3. With 23 nodes the same pattern has 11 internal nodes and height 11.*

    Verified with a small DP over all full-tree shapes: the maximum height for 23 nodes is 11.

    **Key idea:** full binary tree with $n$ nodes has $(n-1)/2$ internal nodes, and its height is at most that number.
