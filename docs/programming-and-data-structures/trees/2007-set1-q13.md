# 2007 CS Q13: Number of binary trees on three unlabeled nodes

## Question

The maximum number of binary trees that can be formed with three unlabeled nodes is:

- (A) 1
- (B) 5
- (C) 4
- (D) 3

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The number of binary tree *shapes* on $n$ unlabeled nodes is the Catalan number $C_n = \frac{1}{n+1}\binom{2n}{n}$. For $n = 3$:
$$C_3 = \frac{1}{4}\binom{6}{3} = 5.$$

The five shapes are: a left chain, a right chain, root with a left child that has a right child, root with a right child that has a left child, and the full tree (root with two children).

- (A), (C) and (D) undercount: they miss the distinction between left and right children, which makes different shapes.

**Code check:** Python recursion $T(n)=\sum_{i} T(i)\,T(n-1-i)$ gives $T(3)=5$.
