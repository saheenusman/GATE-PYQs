# 2014 CS3 Q41: What `DoSomething` returns on a left-child right-sibling tree

## Question

Consider the pseudocode given below. The function `DoSomething()` takes as argument a pointer to the root of an arbitrary tree represented by the *leftMostChild-rightSibling* representation. Each node of the tree is of type `treeNode`.

```c
typedef struct treeNode* treeptr;

struct treeNode
{
    treeptr leftMostChild, rightSibling;
};

int DoSomething (treeptr tree)
{
   int value=0;
   if (tree != NULL) {
     if (tree->leftMostChild == NULL)
         value = 1;
     else
         value = DoSomething(tree->leftMostChild);
     value = value + DoSomething(tree->rightSibling);
   }
   return(value);
}
```

When the pointer to the root of a tree is passed as the argument to `DoSomething`, the value returned by the function corresponds to the

- (A) number of internal nodes in the tree.
- (B) height of the tree.
- (C) number of nodes without a right sibling in the tree.
- (D) number of leaf nodes in the tree.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In this representation, `leftMostChild` points to a node's first child and `rightSibling` points to the next child of the same parent.

`DoSomething(t)` returns the number of leaves in the subtree of `t` **plus all of `t`'s right siblings' subtrees**:

- if `t` has no child, it contributes **1** (a leaf);
- otherwise it contributes the leaf count of its children's list, `DoSomething(leftMostChild)`;
- then it adds the count of its right siblings, `DoSomething(rightSibling)`.

Called on the root (which has no sibling), the result is the number of leaves in the whole tree: **D**.

- (A) internal nodes are never counted: they add 0 of their own.
- (B) height would use a `max`, not a sum.
- (C) nodes without a right sibling are not what the base case tests.

**Code check:** I compiled the function (`gcc -Wall` gives no warning for the function itself) with a test harness that builds 2000 random general trees. `DoSomething` equals the number of leaves in every one of them (0 mismatches).

**Key idea:** `leftMostChild == NULL` identifies a leaf; the sum over children and siblings counts all leaves.

</details>
