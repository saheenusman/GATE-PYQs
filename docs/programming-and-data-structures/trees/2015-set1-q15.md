# 2015 CS1 Q15: Maximum and minimum nodes in a binary tree of height 5

## Question

The height of a tree is the length of the longest root-to-leaf path in it. The maximum and minimum number of nodes in a binary tree of height 5 are

- (A) 63 and 6, respectively
- (B) 64 and 5, respectively
- (C) 32 and 6, respectively
- (D) 31 and 5, respectively

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Height is counted in **edges**, so a tree of height $h$ has $h+1$ levels.

- Maximum: every level is full, $2^0 + 2^1 + \dots + 2^5 = 2^6 - 1 = 63$.
- Minimum: a single path of 6 nodes (one node per level), so $h + 1 = 6$.

Option (A). (B) 64 exceeds the maximum. (C) 32 is the number of leaves in a full tree, not the node count. (D) $31$ and $5$ is the answer if height were counted in *nodes* (5 levels).

**Key idea:** with height in edges, nodes range from $h+1$ to $2^{h+1}-1$.

</details>
