# 2007 CS Q39: Postorder from inorder and preorder

## Question

The inorder and preorder traversal of a binary tree are

```
d b e a f c g   and   a b d e c f g,
```

respectively. The postorder traversal of the binary tree is

- (A) d e b f g c a
- (B) e d b g f c a
- (C) e d b f g c a
- (D) d e f g b c a

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The first preorder symbol is the root: $a$. In the inorder sequence, $a$ splits the tree:

- left subtree inorder $d\,b\,e$, preorder $b\,d\,e$: root $b$, left child $d$, right child $e$.
- right subtree inorder $f\,c\,g$, preorder $c\,f\,g$: root $c$, left child $f$, right child $g$.

Postorder (left, right, root): left subtree $d\,e\,b$, right subtree $f\,g\,c$, then $a$:

$$d\ e\ b\ f\ g\ c\ a$$

(A).

- (B) and (C) put $e$ before $d$, which would need $e$ to be the left child of $b$.
- (D) lists $f\,g$ before $b$, i.e. it places the right subtree's leaves before the left subtree's root.

**Code check:** Python: rebuilt the tree from the two traversals and printed the postorder: `debfgca`.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** preorder gives the root, inorder splits left and right; recurse, then output left, right, root.

</details>
