# 2007 CS Q12: Maximum nodes in a binary tree of height h

## Question

The height of a binary tree is the maximum number of edges in any root to leaf path. The maximum number of nodes in a binary tree of height $h$ is:

- (A) $2^h - 1$
- (B) $2^{h-1} - 1$
- (C) $2^{h+1} - 1$
- (D) $2^{h+1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

With height counted in **edges**, level $i$ ($i = 0..h$) holds at most $2^i$ nodes. So
$$\sum_{i=0}^{h} 2^i = 2^{h+1} - 1.$$

Check: $h = 0$ gives $1$ node (a lone root); $h = 1$ gives $3$; $h = 2$ gives $7$. So (C).

- (A) $2^h - 1$ is the count when height is measured in *levels* (a tree with $h$ levels).
- (B) is even smaller.
- (D) $2^{h+1}$ is one too many (it equals the sum plus 1).

**Code check:** Python recursion $N(h) = 1 + 2N(h-1)$ gives $1, 3, 7, 15, 31$ for $h = 0..4$, equal to $2^{h+1}-1$.

**Key idea:** read the definition of height: edges (root alone has height 0) gives $2^{h+1}-1$, levels gives $2^h-1$.
