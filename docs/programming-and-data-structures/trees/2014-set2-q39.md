# 2014 CS2 Q39: Maximum value of an expression tree with 0/1 leaves

## Question

Consider the expression tree shown. Each leaf represents a numerical value, which can either be 0 or 1. Over all possible choices of the values at the leaves, the maximum possible value of the expression represented by the tree is ___.

![Expression tree with eight leaves, each marked 0/1. The root is +. Its left child is a minus node, whose children are a plus node (leaves 1 and 2) and a minus node (leaves 3 and 4). Its right child is a plus node, whose children are a minus node (leaves 5 and 6) and a plus node (leaves 7 and 8).](../../assets/2014/set2-q39.png)

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Name the leaves $a, b, c, d, e, f, g, h$ from left to right. Reading the tree:

$$\big((a + b) - (c - d)\big) + \big((e - f) + (g + h)\big)$$

Maximise each part separately, since the leaves are independent:

- $a + b \le 2$ (both 1).
- $-(c - d)$ is largest when $c = 0, d = 1$: it is $+1$.
- $e - f \le 1$ ($e=1, f=0$).
- $g + h \le 2$.

$$2 + 1 + 1 + 2 = 6$$

**Code check:** trying all $2^8 = 256$ leaf assignments gives a maximum of 6.

**Key idea:** push each leaf to the value that helps its sign in the expression.

</details>
