## Question

The set T represents various traversals over a binary tree. The set S represents the order of visiting nodes during a traversal.

| T | S |
|---|---|
| I: Inorder | L: left subtree, node, right subtree |
| II: Preorder | M: node, left subtree, right subtree |
| III: Postorder | N: left subtree, right subtree, node |

Which one of the following is the correct match from T to S?

- (A) I – L, II – M, III – N
- (B) I – M, II – L, III – N
- (C) I – N, II – M, III – L
- (D) I – L, II – N, III – M

??? success "Answer"
    **A**

??? info "Solution"
    The name says *when the node itself is visited*:

    - **Pre**order: node **before** its subtrees, which is M (node, left, right).
    - **In**order: node **between** its subtrees, which is L (left, node, right).
    - **Post**order: node **after** its subtrees, which is N (left, right, node).

    Example tree with root 1 and children 2 (left) and 3 (right):

    ```mermaid
    flowchart TD
        A((1)) --> B((2))
        A --> C((3))
    ```

    | Traversal | Output |
    |---|---|
    | Inorder | 2 1 3 |
    | Preorder | 1 2 3 |
    | Postorder | 2 3 1 |

    Options B, C, D each swap at least one pair of traversals.

    **Key idea:** pre / in / post tells you where the node goes relative to its two subtrees; the left subtree is always visited before the right.
