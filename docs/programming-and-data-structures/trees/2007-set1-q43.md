# 2007 CS Q43: Leaves and internal nodes of a complete n-ary tree

## Question

A complete $n$-ary tree is a tree in which each node has $n$ children or no children. Let $I$ be the number of internal nodes and $L$ be the number of leaves in a complete $n$-ary tree. If $L = 41$, and $I = 10$, what is the value of $n$?

- (A) 3
- (B) 4
- (C) 5
- (D) 6

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count edges two ways. Each internal node has $n$ children, so the number of non-root nodes is $nI$. The total number of nodes is $I + L$, so
$$I + L - 1 = nI \quad\Longrightarrow\quad L = (n-1)I + 1.$$

Substitute $L = 41$, $I = 10$: $41 = 10(n-1) + 1$, so $n - 1 = 4$ and $n = 5$: (C).

Check: $10$ internal nodes with $5$ children each give $1 + 50 = 51$ nodes, of which $51 - 10 = 41$ are leaves.

- (A), (B) and (D) give $L = 21, 31, 51$ for $I = 10$.

**Code check:** arithmetic check above ($1 + 5\cdot 10 = 51$ nodes, $41$ leaves).

**Key idea:** in a full $n$-ary tree, $L = (n-1)I + 1$.
