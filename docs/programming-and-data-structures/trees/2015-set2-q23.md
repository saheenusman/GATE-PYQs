# 2015 CS2 Q23: Nodes with two children in a binary tree with 20 leaves

## Question

A binary tree $T$ has 20 leaves. The number of nodes in $T$ having two children is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**19**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $n_0, n_1, n_2$ be the numbers of nodes with 0, 1 and 2 children.

- Edges $= n_1 + 2n_2$, and also edges $=$ nodes $- 1 = n_0 + n_1 + n_2 - 1$.
- Equating: $n_1 + 2n_2 = n_0 + n_1 + n_2 - 1 \Rightarrow n_2 = n_0 - 1$.

With $n_0 = 20$: $n_2 = 19$.

**Key idea:** in any binary tree, (nodes with two children) $=$ (leaves) $-$ 1.

</details>
