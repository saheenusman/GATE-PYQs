# 2014 CS1 Q12: Counting subtrees with exactly 4 nodes: value of a + 10b

## Question

Consider a rooted $n$ node binary tree represented using pointers. The best upper bound on the time required to determine the number of subtrees having exactly 4 nodes is $O(n^a \log^b n)$. Then the value of $a + 10b$ is __________.

<details class="success" markdown="1">
<summary>Answer</summary>

**1**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Do one post-order traversal. At each node compute

$$size(v) = 1 + size(left) + size(right)$$

and add 1 to a counter whenever $size(v) = 4$. Each node is visited once with $O(1)$ work, so the time is $O(n)$.

That is $O(n^1 \log^0 n)$, so $a = 1$, $b = 0$ and

$$a + 10b = 1$$

No algorithm can do better than $\Omega(n)$ because it must read every node, so $O(n)$ is the best bound.

**Code check:** a single post-order pass matched a brute-force count on 500 random trees.

**Key idea:** compute subtree sizes bottom-up in one traversal.

</details>
