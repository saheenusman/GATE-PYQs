# 2007 CS Q85: Paths avoiding a forbidden segment

## Question

(Linked with Q.84: the same robot.)

**Q.85** Suppose that the robot is not allowed to traverse the line segment from $(4,4)$ to $(5,4)$. With this constraint, how many distinct paths are there for the robot to reach $(10,10)$ starting from $(0,0)$?

- (A) $2^9$
- (B) $2^{19}$
- (C) $\dbinom{8}{4} \times \dbinom{11}{5}$
- (D) $\dbinom{20}{10} - \dbinom{8}{4} \times \dbinom{11}{5}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count all paths and subtract those that use the forbidden step $(4,4) \to (5,4)$.

A path using that step has three parts:

- $(0,0) \to (4,4)$: $\binom{8}{4}$ ways,
- the step itself: 1 way,
- $(5,4) \to (10,10)$: $5$ rights and $6$ ups, so $\binom{11}{5}$ ways.

Paths using the step: $\binom{8}{4}\binom{11}{5} = 70 \times 462 = 32340$. So the allowed paths number
$$\binom{20}{10} - \binom{8}{4}\binom{11}{5} = 184756 - 32340 = 152416.$$

(D).

- (C) is the number of paths that **do** use the segment, the opposite of what is asked.
- (A) $2^9$ and (B) $2^{19}$ are unrelated powers of two.

**Code check:** Python grid dynamic programme with the edge $(4,4)\to(5,4)$ removed gives $152416$, equal to $\binom{20}{10} - \binom{8}{4}\binom{11}{5}$.

**Key idea:** count the complement: total paths minus paths through the forbidden edge (paths to its start $\times$ paths from its end).

</details>
