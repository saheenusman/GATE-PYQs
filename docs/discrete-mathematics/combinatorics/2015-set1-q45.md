# 2015 CS1 Q45: Recurrence for bit strings that contain two consecutive 1s

## Question

Let $a_n$ represent the number of bit strings of length $n$ containing two consecutive 1s. What is the recurrence relation for $a_n$?

- (A) $a_{n-2} + a_{n-1} + 2^{n-2}$
- (B) $a_{n-2} + 2a_{n-1} + 2^{n-2}$
- (C) $2a_{n-2} + a_{n-1} + 2^{n-2}$
- (D) $2a_{n-2} + 2a_{n-1} + 2^{n-2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Split by how the string starts.

- Starts with $0$: the rest is any length-$(n-1)$ string containing $11$. That gives $a_{n-1}$.
- Starts with $10$: the rest is a length-$(n-2)$ string containing $11$. That gives $a_{n-2}$.
- Starts with $11$: already contains $11$, and the other $n-2$ bits are free. That gives $2^{n-2}$.

$$a_n = a_{n-1} + a_{n-2} + 2^{n-2}$$

Option (A). Check: $a_1 = 0$, $a_2 = 1$, so $a_3 = 1 + 0 + 2 = 3$ (the strings 011, 110, 111). Options (B), (C), (D) have an extra factor of 2 on a term and give $4$, $4$ and $5$ for $a_3$.

**Code check:** brute-force counts for $n = 1..8$ are $0, 1, 3, 8, 19, 43, 94, 201$, and $a_n = a_{n-1} + a_{n-2} + 2^{n-2}$ held for every $n$ from 3 to 11 (the other options failed).

**Key idea:** condition on the first one or two bits to get a recurrence.

</details>
