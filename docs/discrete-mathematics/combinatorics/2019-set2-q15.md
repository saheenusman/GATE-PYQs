# 2019 CS2 Q15: Counting pairs (x, X) with x in X

## Question

Let $U = \lbrace 1, 2, \dots, n \rbrace$. Let $A = \lbrace (x, X) \mid x \in X,\ X \subseteq U \rbrace$. Consider the following two statements on $\lvert A \rvert$.

- I. $\lvert A \rvert = n\,2^{n-1}$
- II. $\lvert A \rvert = \sum_{k=1}^{n} k \binom{n}{k}$

Which of the above statements is/are TRUE?

- (A) Only I
- (B) Only II
- (C) Both I and II
- (D) Neither I nor II

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count the pairs in two ways. Both ways count the same set $A$.

**Fix the element $x$ first.** Each of the $n$ elements lies in exactly $2^{n-1}$ subsets (the other $n-1$ elements are free). So $\lvert A\rvert = n\,2^{n-1}$. **I is true.**

**Fix the size of $X$ first.** There are $\binom{n}{k}$ subsets of size $k$, and each gives $k$ pairs (one per member). So $\lvert A\rvert = \sum_{k=1}^{n} k\binom{n}{k}$. **II is true.**

**Check, $n = 2$:** the pairs are $(1,\lbrace 1\rbrace)$, $(2,\lbrace 2\rbrace)$, $(1,\lbrace 1,2\rbrace)$, $(2,\lbrace 1,2\rbrace)$. That is 4, and $2 \cdot 2^1 = 4$, $1\cdot 2 + 2 \cdot 1 = 4$.

**Code check:** brute force for $n = 1$ to $8$ confirms both formulas.

**Key idea:** double counting. The same identity $\sum k\binom nk = n2^{n-1}$ appears from the two directions.

</details>
