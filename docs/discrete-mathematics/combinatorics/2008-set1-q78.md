# 2008 CS Q78: Recurrence for binary strings with no consecutive 0s

## Question

Let $X_n$ denote the number of binary strings of length $n$ that contain no consecutive 0s. (Common statement for Q.78 and Q.79.)

Which of the following recurrences does $X_n$ satisfy?

- (A) $X_n = 2X_{n-1}$
- (B) $X_n = X_{\lfloor n/2 \rfloor} + 1$
- (C) $X_n = X_{\lfloor n/2 \rfloor} + n$
- (D) $X_n = X_{n-1} + X_{n-2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Split the valid strings of length $n$ by their last symbol:

- ending in **1**: the first $n - 1$ symbols are any valid string, so there are $X_{n-1}$ of them;
- ending in **0**: the symbol before it must be $1$, and the first $n - 2$ symbols are any valid string: $X_{n-2}$ of them.

So $X_n = X_{n-1} + X_{n-2}$: (D), a Fibonacci-type recurrence.

- (A) $2X_{n-1}$ would count every extension, including the ones that create "00".
- (B) and (C) have a divide-by-two structure and grow far too slowly.

**Code check:** counting all binary strings of length $n$ without "00" by brute force gave $X_n = 2, 3, 5, 8, 13, 21, 34, 55$ for $n = 1..8$, and the recurrence $X_n = X_{n-1} + X_{n-2}$ held for $n = 3..12$.

**Key idea:** condition on the last symbol to get a recurrence for strings with a forbidden pattern.

</details>
