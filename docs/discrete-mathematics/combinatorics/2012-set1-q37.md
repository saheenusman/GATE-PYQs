# 2012 CS Q37: Onto functions from an n-element set to a 2-element set

## Question

How many onto (or surjective) functions are there from an $n$-element ($n \ge 2$) set to a $2$-element set?

- (A) $2^n$
- (B) $2^n - 1$
- (C) $2^n - 2$
- (D) $2(2^n - 2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each of the $n$ elements has $2$ choices of image, so there are $2^n$ functions in all. A function fails to be onto only if it misses one of the two targets, which means it is constant. There are exactly $2$ constant functions.

$$2^n - 2.$$

This is (C).

- (A) counts all functions, constant ones included.
- (B) removes only one constant function.
- (D) doubles the right count.

**Code check:** brute force for $n = 2..6$ gave $2, 6, 14, 30, 62$, which equals $2^n - 2$.

**Key idea:** onto to a 2-set means "not constant", so subtract the 2 constant functions from $2^n$.

</details>
