# 2008 CS Q79: The value of X5 for strings with no consecutive 0s

## Question

(Continuing Q.78.) The value of $X_5$ is

- (A) 5
- (B) 7
- (C) 8
- (D) 16

<details class="success" markdown="1">
<summary>Answer</summary>

none (key derives 13, which is not an option)

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Status: disputed.** The supplied key works out the value as 13 but gives no letter, and 13 is not among the options. Both views follow.

**My derivation.** With $X_1 = 2$ (the strings 0 and 1) and $X_2 = 3$ (01, 10, 11), the recurrence $X_n = X_{n-1} + X_{n-2}$ from Q.78 gives

$$X_3 = 5,\quad X_4 = 8,\quad X_5 = 13.$$

**Key's view.** The key's explanation reaches the same value, $X_5 = 13$ (its text writes $X_1 = 2,\ X_2 = 3,\ X_3 = 2 + 3,\ X_4 = 5 + 3,\ X_5 = 8 + 5 = 13$).

**The problem.** None of (A) 5, (B) 7, (C) 8, (D) 16 is 13. The nearest is (C) 8, which is $X_4$, so the printed question seems to be off by one index or to have wrong options. I do not pick an option; I record that the question has no correct answer among its options.

**Code check:** enumerating all $2^5 = 32$ binary strings of length 5 and removing those with "00" leaves 13 strings.

**Key idea:** $X_n$ is a Fibonacci-type sequence: $2, 3, 5, 8, 13, \ldots$.

</details>
