# 2007 CS Q84: Number of monotone lattice paths from (0,0) to (10,10)

## Question

**Statement for Linked Answer Questions 84 & 85.** Suppose that a robot is placed on the Cartesian plane. At each step it is allowed to move either one unit up or one unit right, i.e., if it is at $(i, j)$ then it can move to either $(i+1, j)$ or $(i, j+1)$.

**Q.84** How many distinct paths are there for the robot to reach the point $(10, 10)$ starting from the initial position $(0, 0)$?

- (A) $\dbinom{20}{10}$
- (B) $2^{20}$
- (C) $2^{10}$
- (D) None of the above

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Every path is a sequence of $20$ moves, exactly $10$ rights and $10$ ups. Choosing which $10$ of the $20$ positions are the right moves determines the path:
$$\binom{20}{10} = 184756.$$

(A).

- (B) $2^{20}$ counts all sequences of 20 moves, including those that do not end at $(10,10)$.
- (C) $2^{10}$ is much too small.
- (D) is wrong since (A) is correct.

**Code check:** Python: $\binom{20}{10} = 184756$, and a path-count dynamic programme over the grid gives the same number.

**Status note:** `unverified`. GATE 2007 had no official answer key, so there is nothing to compare against. This is my own answer.

**Key idea:** a lattice path to $(m, n)$ is a choice of which $m$ of the $m + n$ steps go right: $\binom{m+n}{m}$.

</details>
