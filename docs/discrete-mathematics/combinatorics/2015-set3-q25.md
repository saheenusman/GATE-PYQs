# 2015 CS3 Q25: Four-digit numbers with non-decreasing digits from {1, 2, 3}

## Question

The number of 4 digit numbers having their digits in non-decreasing order (from left to right) constructed by using the digits belonging to the set $\lbrace 1, 2, 3 \rbrace$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**15**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A non-decreasing number is fixed by **how many times** each digit appears. Let the counts of 1, 2 and 3 be $a, b, c$:

$$a + b + c = 4,\qquad a, b, c \ge 0$$

By stars and bars:

$$\binom{4 + 3 - 1}{3 - 1} = \binom{6}{2} = 15$$

**Answer: 15.**

**Code check:** listing all $3^4 = 81$ four-digit strings and keeping the sorted ones gives 15.

**Key idea:** sorted arrangements of a multiset are determined by counts, so use stars and bars.

</details>
