# 2015 CS2 Q58: Number of onto functions from a 4-set to a 3-set

## Question

The number of onto functions (surjective functions) from set $X = \lbrace 1, 2, 3, 4 \rbrace$ to set $Y = \lbrace a, b, c \rbrace$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**36**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Inclusion–exclusion.** All functions: $3^4 = 81$. Subtract the ones that miss at least one element of $Y$:

$$81 - \binom{3}{1}2^4 + \binom{3}{2}1^4 = 81 - 48 + 3 = 36$$

**Direct count.** Onto means every element of $Y$ is used, so exactly one element of $Y$ gets two pre-images:

- Choose which two elements of $X$ share an image: $\binom{4}{2} = 6$.
- Match the three groups (one pair and two singles) to $a, b, c$: $3! = 6$.

$6 \times 6 = 36$. This is also $3!\,S(4,3) = 6 \times 6$, with $S(4,3)$ a Stirling number of the second kind.

**Answer: 36.**

**Code check:** enumerating all $81$ functions and keeping the ones that hit $a$, $b$ and $c$ gives $36$.

**Key idea:** onto count $= \sum_{j} (-1)^j \binom{m}{j}(m-j)^n$.

</details>
