# 2017 CS2 Q47: a3 - a0 from an ordinary generating function (1+z)/(1-z)^3

## Question

If the ordinary generating function of a sequence $\lbrace a_n\rbrace_{n=0}^{\infty}$ is $\dfrac{1+z}{(1-z)^3}$, then $a_3 - a_0$ is equal to ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**15**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Expand $\dfrac{1}{(1-z)^3}$.** It is $\sum_{n\ge 0}\binom{n+2}{2} z^n$ (coefficients $1, 3, 6, 10, \ldots$).

**Multiply by $(1+z)$.** The coefficient of $z^n$ is

$$a_n = \binom{n+2}{2} + \binom{n+1}{2} = \frac{(n+2)(n+1) + (n+1)n}{2} = (n+1)^2.$$

So $a_0 = 1$ and $a_3 = 16$:

$$a_3 - a_0 = 16 - 1 = 15.$$

**Code check:** multiplying the series $1/(1-z)$ three times and then by $(1+z)$ gave the coefficients $1, 4, 9, 16, 25, \ldots$, so $a_3 - a_0 = 15$.

**Key idea:** $\dfrac{1}{(1-z)^k} = \sum \binom{n+k-1}{k-1} z^n$.

</details>
