# 2016 CS1 Q2: Recurrence for n-bit strings with no two consecutive 1s

## Question

Let $a_n$ be the number of $n$-bit strings that do NOT contain two consecutive 1s. Which one of the following is the recurrence relation for $a_n$?

- (A) $a_n = a_{n-1} + 2a_{n-2}$
- (B) $a_n = a_{n-1} + a_{n-2}$
- (C) $a_n = 2a_{n-1} + a_{n-2}$
- (D) $a_n = 2a_{n-1} + 2a_{n-2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Condition on the last bit.**

- Last bit $0$: the first $n-1$ bits can be any valid string, so $a_{n-1}$ ways.
- Last bit $1$: the bit before it must be $0$, and the first $n-2$ bits can be any valid string, so $a_{n-2}$ ways.

$$a_n = a_{n-1} + a_{n-2}, \qquad a_1 = 2,\; a_2 = 3$$

This gives $2, 3, 5, 8, 13, \dots$ (Fibonacci).

**Why the others fail.** Test $a_3$, which is $5$ (the valid strings are 000, 001, 010, 100, 101).

| Option | $a_3$ from the formula |
|---|---|
| (A) $a_{n-1} + 2a_{n-2}$ | $3 + 2\cdot 2 = 7$ |
| (C) $2a_{n-1} + a_{n-2}$ | $2\cdot 3 + 2 = 8$ |
| (D) $2a_{n-1} + 2a_{n-2}$ | $2\cdot 3 + 2\cdot 2 = 10$ |

**Code check:** counting valid strings for $n = 1..8$ gave $2, 3, 5, 8, 13, 21, 34, 55$, and $a_n = a_{n-1} + a_{n-2}$ held for every $n \ge 3$ tested.

**Key idea:** forbidding 11 forces a 0 before any final 1, which splits the count into $a_{n-1} + a_{n-2}$.

</details>
