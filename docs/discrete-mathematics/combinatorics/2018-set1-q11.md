# 2018 CS Q11: Generating function of a_n = 2n + 3

## Question

Which one of the following is a closed form expression for the generating function of the sequence $\lbrace a_n \rbrace$, where $a_n = 2n + 3$ for all $n = 0, 1, 2, \ldots$ ?

- (A) $\dfrac{3}{(1-x)^2}$
- (B) $\dfrac{3x}{(1-x)^2}$
- (C) $\dfrac{2-x}{(1-x)^2}$
- (D) $\dfrac{3-x}{(1-x)^2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split the sequence:**

$$G(x) = \sum_{n\ge0}(2n+3)x^n = 2\sum_{n\ge0} n x^n + 3\sum_{n\ge0} x^n$$

**Use the standard sums:** $\sum x^n = \dfrac{1}{1-x}$ and $\sum n x^n = \dfrac{x}{(1-x)^2}$.

$$G(x) = \frac{2x}{(1-x)^2} + \frac{3}{1-x} = \frac{2x + 3(1-x)}{(1-x)^2} = \frac{3-x}{(1-x)^2}$$

**Check the first coefficients of D:** $(3-x)(1+2x+3x^2+\cdots)$ gives $3,\ 6-1 = 5,\ 9-2 = 7$, which are $a_0, a_1, a_2$.

**Why the others fail:** A gives $3(n+1)$. B gives $3n$. C starts with $a_0 = 2$, not 3.

**Key idea:** write the sequence as a combination of $\frac{1}{1-x}$ and its derivative form $\frac{x}{(1-x)^2}$.

</details>
