# 2015 CS1 Q41: Telescoping sum of 1 over x(x+1)

## Question

$$\sum_{x=1}^{99} \frac{1}{x(x+1)} = \text{______}.$$

<details class="success" markdown="1">
<summary>Answer</summary>

**0.99**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Split each term with partial fractions:

$$\frac{1}{x(x+1)} = \frac{1}{x} - \frac{1}{x+1}$$

The sum telescopes (all middle terms cancel):

$$\sum_{x=1}^{99}\left(\frac1x - \frac1{x+1}\right) = 1 - \frac{1}{100} = 0.99$$

**Key idea:** $\frac{1}{x(x+1)} = \frac1x - \frac1{x+1}$, so $\sum_{x=1}^{n} = 1 - \frac{1}{n+1}$.

</details>
