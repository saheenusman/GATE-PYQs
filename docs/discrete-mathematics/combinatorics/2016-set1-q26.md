# 2016 CS1 Q26: Coefficient of x^12 in (x^3 + x^4 + x^5 + ...)^3

## Question

The coefficient of $x^{12}$ in $(x^3 + x^4 + x^5 + x^6 + \cdots)^3$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**10**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Factor out the smallest power.**

$$x^3 + x^4 + \cdots = x^3\,(1 + x + x^2 + \cdots) = \frac{x^3}{1 - x}$$

So

$$\left(\frac{x^3}{1-x}\right)^3 = x^9\,(1-x)^{-3}$$

We need $x^{12}$, i.e. the coefficient of $x^{3}$ in $(1-x)^{-3}$.

**Use the series** $(1-x)^{-3} = \sum_{k \ge 0} \binom{k+2}{2} x^k$. For $k = 3$:

$$\binom{5}{2} = 10$$

**Counting view.** The number of solutions of $a + b + c = 12$ with each of $a, b, c \ge 3$. Setting $a' = a - 3$, etc., gives $a' + b' + c' = 3$ with $a', b', c' \ge 0$, which has $\binom{5}{2} = 10$ solutions.

**Code check:** enumerating all triples in $[3, 12]$ with sum $12$ gave $10$.

**Key idea:** shift out $x^9$, then the coefficient is a stars-and-bars count $\binom{5}{2}$.

</details>
