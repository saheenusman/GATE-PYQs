# 2023 CS Q15: Closed form of the Lucas sequence

## Question

The Lucas sequence $L_n$ is defined by the recurrence relation:

$$L_n = L_{n-1} + L_{n-2}, \quad n \ge 3,$$

with $L_1 = 1$ and $L_2 = 3$.

Which one of the options given is TRUE?

- (A) $L_n = \left(\frac{1+\sqrt5}{2}\right)^n + \left(\frac{1-\sqrt5}{2}\right)^n$
- (B) $L_n = \left(\frac{1+\sqrt5}{2}\right)^n - \left(\frac{1-\sqrt5}{2}\right)^{3}$
- (C) $L_n = \left(\frac{1+\sqrt5}{2}\right)^n + \left(\frac{1-\sqrt5}{2}\right)^{3}$
- (D) $L_n = \left(\frac{1+\sqrt5}{2}\right)^n - \left(\frac{1-\sqrt5}{2}\right)^n$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Why a sum of powers works.** Let $\varphi = \frac{1+\sqrt5}{2}$ and $\psi = \frac{1-\sqrt5}{2}$. Both satisfy $x^2 = x + 1$, so $\varphi^n = \varphi^{n-1} + \varphi^{n-2}$ and the same for $\psi$. Any combination $a\varphi^n + b\psi^n$ obeys the recurrence.

**Fit the starting values** with $a = b = 1$:

- $n = 1$: $\varphi + \psi = 1$ ✓
- $n = 2$: $\varphi^2 + \psi^2 = (\varphi+\psi)^2 - 2\varphi\psi = 1 + 2 = 3$ ✓

So **A** is correct.

**Code check:** the formula rounded to integers gave $1, 3, 4, 7, 11, 18, 29, \ldots$, the same as the recurrence.

**Why the others fail:** B and C have an exponent 3 on the second term instead of $n$, which breaks the recurrence. D uses a difference: $\varphi - \psi = \sqrt5$ at $n = 1$, which is not 1.

**Key idea:** solve the characteristic equation $x^2 = x + 1$, then fit constants to the first two terms.

</details>
