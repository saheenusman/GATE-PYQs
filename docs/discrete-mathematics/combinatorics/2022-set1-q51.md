# 2022 CS Q51: A recurrence with halving

## Question

Consider the following recurrence:

$$f(1) = 1;\quad f(2n) = 2f(n) - 1 \text{ for } n \ge 1;\quad f(2n+1) = 2f(n) + 1 \text{ for } n \ge 1.$$

Then, which of the following statements is/are TRUE?

- (A) $f(2^n - 1) = 2^n - 1$
- (B) $f(2^n) = 1$
- (C) $f(5 \cdot 2^n) = 2^{n+1} + 1$
- (D) $f(2^n + 1) = 2^n + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find a closed form.** The first values are $f(1..8) = 1, 1, 3, 1, 3, 5, 7, 1$. Write $m = 2^k + \ell$ with $0 \le \ell < 2^k$. This is the Josephus function, so

$$f(m) = 2\ell + 1$$

Check by induction. For $m = 2n$, $\ell$ is even and $n = 2^{k-1} + \ell/2$, so $f(m) = 2(2 \cdot \tfrac{\ell}{2} + 1) - 1 = 2\ell + 1$. For $m = 2n + 1$, $\ell$ is odd and $n = 2^{k-1} + \tfrac{\ell - 1}{2}$, so $f(m) = 2(\ell - 1 + 1) + 1 = 2\ell + 1$. The base case $f(1) = 1$ has $\ell = 0$.

- **(A) True.** $2^n - 1 = 2^{n-1} + (2^{n-1} - 1)$, so $\ell = 2^{n-1} - 1$ and $f = 2^n - 1$.
- **(B) True.** $2^n = 2^n + 0$, so $\ell = 0$ and $f = 1$.
- **(C) True.** $5 \cdot 2^n = 2^{n+2} + 2^n$, so $\ell = 2^n$ and $f = 2^{n+1} + 1$.
- **(D) False.** $2^n + 1$ has $\ell = 1$, so $f = 3$. This equals $2^n + 1$ only for $n = 1$, not in general.

**Code check:** the recurrence was evaluated for $n = 1$ to $7$. (A), (B), (C) held every time. (D) failed for all $n \ge 2$.

**Key idea:** identify the recurrence as the Josephus function $f(m) = 2\ell + 1$, where $m = 2^k + \ell$.

</details>
