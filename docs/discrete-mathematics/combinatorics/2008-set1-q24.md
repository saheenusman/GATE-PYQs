# 2008 CS Q24: Difference of the sums of even and odd integers

## Question

Let $P = \displaystyle\sum_{\substack{1 \le i \le 2k \\ i\ \text{odd}}} i$ and $Q = \displaystyle\sum_{\substack{1 \le i \le 2k \\ i\ \text{even}}} i$, where $k$ is a positive integer. Then

- (A) $P = Q - k$
- (B) $P = Q + k$
- (C) $P = Q$
- (D) $P = Q + 2k$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Pair each even number with the odd number just below it:

$$Q - P = (2 - 1) + (4 - 3) + \cdots + (2k - (2k-1)) = \underbrace{1 + 1 + \cdots + 1}_{k\ \text{terms}} = k.$$

So $P = Q - k$: (A).

- (B) has the sign reversed, (C) says they are equal, and (D) is off by a factor of $2$.

**Code check:** for $k = 1, 2, 3, 7$: $P = 1, 4, 9, 49$ and $Q = 2, 6, 12, 56$, so $Q - k = P$ in every case.

**Classification note:** this is a summation identity, so I filed it under `combinatorics`.

**Key idea:** pair consecutive terms; each pair differs by $1$.

</details>
