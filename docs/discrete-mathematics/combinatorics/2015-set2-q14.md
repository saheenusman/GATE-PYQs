# 2015 CS2 Q14: Number of divisors of 2100

## Question

The number of divisors of 2100 is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**36**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Factorise: $2100 = 2^2 \times 3^1 \times 5^2 \times 7^1$.

For $\prod p_i^{a_i}$, the number of divisors is $\prod (a_i + 1)$:

$$(2+1)(1+1)(2+1)(1+1) = 3 \times 2 \times 3 \times 2 = 36$$

**Key idea:** number of divisors $= \prod (a_i + 1)$ over the prime factorisation.

</details>
