# 2022 CS Q36: Generating function of a sequence

## Question

Which one of the following is the closed form for the generating function of the sequence $\lbrace a_n \rbrace_{n \ge 0}$ defined below?

$$a_n = \begin{cases} n + 1, & n \text{ is odd} \\ 1, & \text{otherwise} \end{cases}$$

- (A) $\dfrac{x(1 + x^2)}{(1 - x^2)^2} + \dfrac{1}{1 - x}$
- (B) $\dfrac{x(3 - x^2)}{(1 - x^2)^2} + \dfrac{1}{1 - x}$
- (C) $\dfrac{2x}{(1 - x^2)^2} + \dfrac{1}{1 - x}$
- (D) $\dfrac{x}{(1 - x^2)^2} + \dfrac{1}{1 - x}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Split the sequence.** $a_n = 1 + n\cdot[n \text{ odd}]$. The constant 1 gives $\sum x^n = \dfrac{1}{1-x}$.

**The odd part.** Start from $\sum_{n \text{ odd}} x^n = \dfrac{x}{1 - x^2}$. Multiplying each coefficient by $n$ is the operator $x\frac{d}{dx}$:

$$x\frac{d}{dx}\left(\frac{x}{1-x^2}\right) = x \cdot \frac{(1-x^2) + 2x^2}{(1-x^2)^2} = \frac{x(1 + x^2)}{(1 - x^2)^2}$$

So $G(x) = \dfrac{x(1+x^2)}{(1-x^2)^2} + \dfrac{1}{1-x}$, which is option A.

**Check the first terms.** $\dfrac{x(1+x^2)}{(1-x^2)^2} = x + 3x^3 + 5x^5 + \cdots$, so $a_1 = 1 + 1 = 2$ and $a_3 = 1 + 3 = 4$, as the definition says.

**Why the others fail.** Compare the coefficients of the first fraction with the needed $a_n - 1$ (which is $1$ at $x^1$ and $3$ at $x^3$):
- (B) has coefficient 3 at $x^1$, so $a_1 = 4$ instead of 2.
- (C) has coefficient 2 at $x^1$, so $a_1 = 3$ instead of 2.
- (D) has coefficient 1 at $x^1$ (correct) but 2 at $x^3$, so $a_3 = 3$ instead of 4.

**Key idea:** split off the constant part, then use $x\,d/dx$ to attach the factor $n$.

</details>
