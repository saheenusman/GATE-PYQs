# 2026 CS1 Q12: 0-1 matrices with even rows and columns

## Question

Consider $4 \times 4$ matrices with entries from $\lbrace 0, 1 \rbrace$. The number of such matrices with an **even number of 1s in every row and every column** is

- (A) 512
- (B) 1025
- (C) 1023
- (D) 255

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Idea.** Choose the top-left $3 \times 3$ block freely. The rest is then forced.

1. Each of the first 3 rows needs an even number of 1s. Its last entry (column 4) is forced: put a 1 if the first three entries have an odd count, else 0.
2. Each of the first 3 columns needs an even number of 1s. Its last entry (row 4) is forced the same way.
3. The corner cell (row 4, column 4) must fix the parity of row 4.

Now check that column 4 is also even. The total number of 1s in the matrix is even whether counted by rows or by columns, so when every other line is even, the last one must be even as well. So the corner is consistent, with no extra choice and no contradiction.

```text
free free free | forced
free free free | forced
free free free | forced
------------------------
forced forced forced | forced
```

The number of matrices is therefore

$$2^{3 \times 3} = 2^9 = 512.$$

**Another way to see it.** There are $2^{16}$ matrices. The 8 parity conditions (4 rows, 4 columns) are not independent: the sum of the row parities equals the sum of the column parities. That leaves 7 independent conditions, giving $2^{16-7} = 2^9$.

**Why the others fail:** the valid matrices form a solution set of linear equations mod 2, so their count must be a power of 2. The values 1025, 1023 and 255 are not powers of 2 ($1025 = 2^{10}+1$, $1023 = 2^{10}-1$, $255 = 2^8-1$).

**Verified** by checking all $2^{16}$ matrices in Python: exactly 512 qualify.

**Key idea:** count free choices, then show the rest is forced. For parity constraints on an $r \times c$ matrix the answer is $2^{(r-1)(c-1)}$.

</details>
