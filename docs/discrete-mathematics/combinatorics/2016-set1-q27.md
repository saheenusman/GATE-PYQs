# 2016 CS1 Q27: Value of K in a99 = K x 10^4 for a quadratic-forcing recurrence

## Question

Consider the recurrence relation $a_1 = 8$, $a_n = 6n^2 + 2n + a_{n-1}$. Let $a_{99} = K \times 10^4$. The value of $K$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**198**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Unroll the recurrence.** Note $6\cdot 1^2 + 2\cdot 1 = 8 = a_1$, so with $a_0 = 0$ the formula holds from $n = 1$:

$$a_n = \sum_{k=1}^{n} (6k^2 + 2k) = 6\cdot\frac{n(n+1)(2n+1)}{6} + 2\cdot\frac{n(n+1)}{2}$$

$$= n(n+1)(2n+1) + n(n+1) = n(n+1)(2n+2) = 2n(n+1)^2$$

**Evaluate at $n = 99$.**

$$a_{99} = 2 \cdot 99 \cdot 100^2 = 1{,}980{,}000 = 198 \times 10^4$$

So $K = 198$.

**Code check:** iterating the recurrence from $a_1 = 8$ up to $n = 99$ gave $a_{99} = 1{,}980{,}000$.

**Key idea:** unroll to $\sum (6k^2 + 2k) = 2n(n+1)^2$ and evaluate at $n = 99$.

</details>
