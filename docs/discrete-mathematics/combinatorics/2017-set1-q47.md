# 2017 CS1 Q47: Integers from 1 to 500 divisible by 3 or 5 or 7

## Question

The number of integers between 1 and 500 (both inclusive) that are divisible by 3 or 5 or 7 is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**271**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Inclusion-exclusion.** Let $A_k$ be the multiples of $k$ in $1..500$.

| Set | Count |
|---|---|
| $\lvert A_3\rvert$ | $\lfloor 500/3\rfloor = 166$ |
| $\lvert A_5\rvert$ | $\lfloor 500/5\rfloor = 100$ |
| $\lvert A_7\rvert$ | $\lfloor 500/7\rfloor = 71$ |
| $\lvert A_3\cap A_5\rvert$ | $\lfloor 500/15\rfloor = 33$ |
| $\lvert A_3\cap A_7\rvert$ | $\lfloor 500/21\rfloor = 23$ |
| $\lvert A_5\cap A_7\rvert$ | $\lfloor 500/35\rfloor = 14$ |
| $\lvert A_3\cap A_5\cap A_7\rvert$ | $\lfloor 500/105\rfloor = 4$ |

$$\lvert A_3\cup A_5\cup A_7\rvert = (166+100+71) - (33+23+14) + 4 = 337 - 70 + 4 = 271$$

The answer is **271**.

**Code check:** counting by brute force over $1..500$ gave $271$.

**Key idea:** add singles, subtract pairs, add the triple.

</details>
