# 2014 CS3 Q49: Functions satisfying f(f(i)) = i on 0..2014

## Question

Consider the set of all functions $f: \lbrace 0, 1, \ldots, 2014 \rbrace \to \lbrace 0, 1, \ldots, 2014 \rbrace$ such that $f(f(i)) = i$, for all $0 \le i \le 2014$. Consider the following statements:

- $P$. For each such function it must be the case that for every $i$, $f(i) = i$.
- $Q$. For each such function it must be the case that for some $i$, $f(i) = i$.
- $R$. Each such function must be onto.

Which one of the following is CORRECT?

- (A) $P$, $Q$ and $R$ are true
- (B) Only $Q$ and $R$ are true
- (C) Only $P$ and $Q$ are true
- (D) Only $R$ is true

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$f(f(i)) = i$ means $f \circ f$ is the identity, so $f$ is its own inverse: $f$ is a **bijection** (an involution). It consists of fixed points and 2-cycles (swaps $i \leftrightarrow j$).

- **$R$ true.** Every $i$ equals $f(f(i))$, which is in the image of $f$, so $f$ is onto.
- **$P$ false.** Swapping $f(0) = 1$, $f(1) = 0$ and fixing all other points is allowed.
- **$Q$ true.** The set has $2015$ elements, an **odd** number. Elements not fixed come in swapped pairs, so there is an even number of them. At least one element is therefore a fixed point.

So only $Q$ and $R$: **B**.

**Code check:** for sets of size 3 to 7, I listed all involutions. Every one has at least one fixed point when the size is odd (minimum 1 fixed point) while for even sizes (4, 6) some have none. For sizes up to 5, I also checked all functions with $f(f(i)) = i$ and each was a bijection.

**Key idea:** an involution pairs up its non-fixed points; an odd-sized set must keep at least one fixed point.

</details>
