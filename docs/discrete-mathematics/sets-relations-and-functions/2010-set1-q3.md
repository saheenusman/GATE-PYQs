# 2010 CS Q3: Number of reflexive relations on a 5-element set

## Question

What is the possible number of reflexive relations on a set of 5 elements?

- (A) $2^{10}$
- (B) $2^{15}$
- (C) $2^{20}$
- (D) $2^{25}$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A relation on a set of $n=5$ elements is a subset of the $n^2 = 25$ ordered pairs.

A reflexive relation must contain all $n = 5$ pairs $(a, a)$. The other $n^2 - n = 20$ pairs can each be in or out freely, so the count is $2^{20}$: (C).

- (A) $2^{10} = 2^{n(n-1)/2}$ counts reflexive **and symmetric** relations (one free choice per unordered pair).
- (B) $2^{15} = 2^{n(n+1)/2}$ counts **symmetric** relations.
- (D) $2^{25}$ counts **all** relations on the set.

**Code check:** $2^{(5 \cdot 5) - 5} = 1048576 = 2^{20}$.

**Key idea:** reflexive means the diagonal is forced; only the off-diagonal $n^2 - n$ pairs are free.

</details>
