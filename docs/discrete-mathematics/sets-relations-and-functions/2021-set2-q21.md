# 2021 CS2 Q21: Functions between two sets of equal size

## Question

Consider the following sets, where $n\ge2$:

$S_1$: Set of all $n\times n$ matrices with entries from the set $\lbrace a,b,c\rbrace$

$S_2$: Set of all functions from the set $\lbrace0,1,2,\ldots,n^2-1\rbrace$ to the set $\lbrace0,1,2\rbrace$

Which of the following choice(s) is/are correct?

- (A) There does not exist a bijection from $S_1$ to $S_2$.
- (B) There exists a surjection from $S_1$ to $S_2$.
- (C) There exists a bijection from $S_1$ to $S_2$.
- (D) There does not exist an injection from $S_1$ to $S_2$.

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Counting.**

- $|S_1|=3^{n^2}$: each of the $n^2$ entries has 3 choices.
- $|S_2|=3^{n^2}$: each of the $n^2$ inputs maps to one of 3 outputs.

Both sets have the same finite size, so a bijection exists. (Matrix entry $(i,j)$ corresponds to input $ni+j$.)

- (A) False. A bijection exists.
- (B) **True.** A bijection is a surjection.
- (C) **True.**
- (D) False. A bijection is an injection.

Answer: **B and C**.

**Key idea:** two finite sets of equal size always admit a bijection.

</details>
