# 2016 CS1 Q28: Maximum size of the range of a function with two recursive rules

## Question

A function $f : \mathbb{N}^+ \rightarrow \mathbb{N}^+$, defined on the set of positive integers $\mathbb{N}^+$, satisfies the following properties:

- $f(n) = f(n/2)$ if $n$ is even
- $f(n) = f(n+5)$ if $n$ is odd

Let $R = \lbrace i \mid \exists j : f(j) = i \rbrace$ be the set of distinct values that $f$ takes. The maximum possible size of $R$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each rule says $f$ at one number equals $f$ at another number. Follow the rule from any $n$ and $f$ keeps the same value all along the way.

**Where the chains end.** Even $n$ halves, and odd $n$ becomes $n+5$ (even), then halves, so values shrink until they fall into a small cycle:

- $1 \to 6 \to 3 \to 8 \to 4 \to 2 \to 1$: the cycle $\lbrace 1, 2, 3, 4, 6, 8 \rbrace$
- $5 \to 10 \to 5$: the cycle $\lbrace 5, 10 \rbrace$

Numbers such as $7 \to 12 \to 6$ and $9 \to 14 \to 7 \to 12 \to 6$ flow into the first cycle.

**Consequence.** All numbers in a cycle must share one value (following the cycle returns to the start), so $f$ takes **at most one value per cycle**. There are two cycles, and giving them different values is consistent, so the maximum is $|R| = 2$.

**Code check:** following the two rules from every $n \le 400$ found exactly these two cycles and no others.

**Key idea:** $f$ is constant on each terminal cycle of the rule graph, and there are exactly two cycles.

</details>
