# 2014 CS3 Q2: True statement about functions, images and preimages

## Question

Let $X$ and $Y$ be finite sets and $f: X \to Y$ be a function. Which one of the following statements is TRUE?

- (A) For any subsets $A$ and $B$ of $X$, $|f(A \cup B)| = |f(A)| + |f(B)|$
- (B) For any subsets $A$ and $B$ of $X$, $f(A \cap B) = f(A) \cap f(B)$
- (C) For any subsets $A$ and $B$ of $X$, $|f(A \cap B)| = \min \lbrace |f(A)|, |f(B)| \rbrace$
- (D) For any subsets $S$ and $T$ of $Y$, $f^{-1}(S \cap T) = f^{-1}(S) \cap f^{-1}(T)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Counter-example for (A), (B), (C): $X = \lbrace 1,2,3 \rbrace$, $Y = \lbrace a,b \rbrace$, $f(1) = f(2) = a$, $f(3) = b$, with $A = \lbrace 1 \rbrace$, $B = \lbrace 2 \rbrace$.

- (A) false: $|f(A \cup B)| = |\lbrace a \rbrace| = 1$, but $|f(A)| + |f(B)| = 2$. The images overlap.
- (B) false: $f(A \cap B) = f(\emptyset) = \emptyset$, but $f(A) \cap f(B) = \lbrace a \rbrace$. It holds only if $f$ is injective.
- (C) false: $|f(A \cap B)| = 0$, but $\min = 1$.
- (D) **true for every function:** $x \in f^{-1}(S \cap T) \iff f(x) \in S \text{ and } f(x) \in T \iff x \in f^{-1}(S) \cap f^{-1}(T)$.

**Code check:** the counter-example above gives $1$ vs $2$ for (A) and $\emptyset$ vs $\lbrace a \rbrace$ for (B), and (D) holds for all 16 pairs of subsets of $Y$.

**Key idea:** preimages preserve unions and intersections, but images preserve only unions (not intersections).

</details>
