# 2015 CS2 Q12: Cardinality of a power set

## Question

The cardinality of the power set of $\lbrace 0, 1, 2, \dots, 10 \rbrace$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2048**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The set has $11$ elements ($0$ through $10$). A set with $n$ elements has $2^n$ subsets.

$$2^{11} = 2048$$

**Key idea:** $|2^A| = 2^{|A|}$.

</details>
