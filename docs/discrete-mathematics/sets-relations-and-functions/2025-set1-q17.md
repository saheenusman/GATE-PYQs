# 2025 CS1 Q17: What composition of onto functions says about g

## Question

$g(.)$ is a function from $A$ to $B$, $f(.)$ is a function from $B$ to $C$, and their composition defined as $f(g(.))$ is a mapping from $A$ to $C$.

If $f(.)$ and $f(g(.))$ are onto (surjective) functions, which ONE of the following is TRUE about the function $g(.)$?

- (A) $g(.)$ must be an onto (surjective) function.
- (B) $g(.)$ must be a one-to-one (injective) function.
- (C) $g(.)$ must be a bijective function, that is, both one-to-one and onto.
- (D) $g(.)$ is not required to be a one-to-one or onto function.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Give counter-examples for "onto" and for "one-to-one".

**$g$ need not be onto.** Let $A = \lbrace 1\rbrace$, $B = \lbrace 1, 2\rbrace$, $C = \lbrace 1\rbrace$, $g(1) = 1$, and $f(1) = f(2) = 1$.

- $f$ is onto $C$, and $f \circ g: 1 \mapsto 1$ is onto $C$.
- But $g$ misses $2 \in B$, so $g$ is **not onto**.

**$g$ need not be one-to-one.** Let $A = \lbrace 1, 2\rbrace$, $B = \lbrace 1\rbrace$, $C = \lbrace 1\rbrace$, $g(1) = g(2) = 1$, and $f(1) = 1$.

- $f$ is onto, and $f \circ g$ is onto.
- But $g(1) = g(2)$, so $g$ is **not one-to-one**.

(I found both examples by enumerating all small functions with a program.)

| Option | Verdict |
|---|---|
| A, B, C | Each says $g$ must have a property that the examples above violate |
| **D** | Correct |

What *is* forced: $f$ must be onto on the part of $B$ that $g$ reaches. Nothing more is guaranteed about $g$.

**Key idea:** $f\circ g$ onto only needs $f$ to cover $C$ using values $g$ reaches. It says nothing about the rest of $B$ or about repeated values of $g$.

</details>
