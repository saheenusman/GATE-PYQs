# 2020 CS Q27: Probability that a random relation on {1,2,3} is reflexive

## Question

Let $\mathcal{R}$ be the set of all binary relations on the set $\lbrace 1,2,3 \rbrace$. Suppose a relation is chosen from $\mathcal{R}$ at random. The probability that the chosen relation is reflexive (round off to 3 decimal places) is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**0.125**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Count all relations.** A binary relation on a 3-element set is any subset of the $3 \times 3 = 9$ ordered pairs:

$$|\mathcal{R}| = 2^9 = 512.$$

**Count reflexive ones.** A reflexive relation must contain the three pairs $(1,1), (2,2), (3,3)$. The other $9 - 3 = 6$ pairs are free:

$$2^6 = 64.$$

**Probability:**

$$\frac{64}{512} = \frac{1}{8} = 0.125.$$

I confirmed this by enumerating all 512 relations in code: 64 are reflexive.

**Key idea:** for a relation on $n$ elements, fix the $n$ diagonal pairs and choose the rest freely, which gives $2^{n^2-n}$ reflexive relations out of $2^{n^2}$.

</details>
