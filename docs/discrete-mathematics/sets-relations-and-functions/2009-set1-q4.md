# 2009 CS Q4: Symmetry and antisymmetry of a relation on {x, y, z}

## Question

Consider the binary relation $R = \lbrace (x, y), (x, z), (z, x), (z, y) \rbrace$ on the set $\lbrace x, y, z \rbrace$. Which one of the following is TRUE?

- (A) $R$ is symmetric but NOT antisymmetric.
- (B) $R$ is NOT symmetric but antisymmetric.
- (C) $R$ is both symmetric and antisymmetric.
- (D) $R$ is neither symmetric nor antisymmetric.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Not symmetric:** $(x, y) \in R$ but $(y, x) \notin R$.
- **Not antisymmetric:** both $(x, z)$ and $(z, x)$ are in $R$ with $x \ne z$.

So $R$ is neither: (D).

- (A) claims symmetric, which fails at $(x, y)$.
- (B) claims antisymmetric, which fails at the pair $(x, z), (z, x)$.
- (C) claims both, and both fail.

**Code check:** a program testing both definitions on $R$ returned symmetric = False and antisymmetric = False.

**Key idea:** one missing reverse pair breaks symmetry; one pair of distinct elements related both ways breaks antisymmetry.

</details>
