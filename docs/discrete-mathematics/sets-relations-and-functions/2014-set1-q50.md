# 2014 CS1 Q50: log2 log2 N for functions from 4-bit inputs to one bit

## Question

Let $S$ denote the set of all functions $f: \lbrace 0,1 \rbrace^4 \to \lbrace 0,1 \rbrace$. Denote by $N$ the number of functions from $S$ to the set $\lbrace 0,1 \rbrace$. The value of $\log_2 \log_2 N$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**16**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The domain $\lbrace 0,1 \rbrace^4$ has $2^4 = 16$ elements. A function to $\lbrace 0,1 \rbrace$ picks one of 2 values for each, so

$$|S| = 2^{16} = 65536$$

Functions from $S$ to $\lbrace 0,1 \rbrace$:

$$N = 2^{|S|} = 2^{65536}$$

$$\log_2 N = 65536 = 2^{16} \Rightarrow \log_2\log_2 N = 16$$

**Code check:** `math.log2(2**16)` gives `16.0`.

**Key idea:** the number of functions from a set of size $m$ to a 2-element set is $2^m$.

</details>
