# 2016 CS2 Q26: Reflexivity and transitivity of a relation on N x N

## Question

A binary relation $R$ on $\mathbb{N} \times \mathbb{N}$ is defined as follows: $(a, b) R (c, d)$ if $a \le c$ or $b \le d$. Consider the following propositions:

- P: $R$ is reflexive
- Q: $R$ is transitive

Which one of the following statements is TRUE?

- (A) Both P and Q are true.
- (B) P is true and Q is false.
- (C) P is false and Q is true.
- (D) Both P and Q are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**P is true.** $(a, b) R (a, b)$ because $a \le a$.

**Q is false.** Take $(1,1)$, $(0,1)$, $(0,0)$:

- $(1,1) R (0,1)$: $1 \le 0$ is false, but $1 \le 1$ is true, so yes.
- $(0,1) R (0,0)$: $0 \le 0$ is true, so yes.
- $(1,1) R (0,0)$: $1 \le 0$ false and $1 \le 0$ false, so **no**.

Transitivity fails. P true, Q false: **(B)**.

**Code check:** a search over $\lbrace 0..4 \rbrace^2$ confirmed reflexivity and found the same witness for the failure of transitivity.

**Key idea:** reflexive since $a \le a$; $(1,1), (0,1), (0,0)$ breaks transitivity.

</details>
