# 2015 CS3 Q60: Reflexivity and symmetry of a relation on pairs

## Question

Let $R$ be a relation on the set of ordered pairs of positive integers such that $((p, q), (r, s)) \in R$ if and only if $p - s = q - r$. Which one of the following is true about $R$?

- (A) Both reflexive and symmetric
- (B) Reflexive but not symmetric
- (C) Not reflexive but symmetric
- (D) Neither reflexive nor symmetric

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Rewrite the condition: $p - s = q - r \iff p + r = q + s$.

**Reflexive?** $((p,q),(p,q)) \in R$ needs $p + p = q + q$, so $p = q$. It fails for $(1, 2)$: $1 + 1 \ne 2 + 2$. **Not reflexive.**

**Symmetric?** If $((p,q),(r,s)) \in R$ then $p + r = q + s$. For the reversed pair $((r,s),(p,q))$ the condition is $r + p = s + q$, which is the same equation. **Symmetric.**

Not reflexive but symmetric: option (C).

- (A) and (B) say reflexive, which fails at $(1, 2)$.
- (D) says not symmetric, which fails by the argument above.

**Code check:** over all pairs with entries 1 to 4, the relation is not reflexive and is symmetric.

**Key idea:** simplify the defining equation first. Then reflexivity means putting the same pair on both sides, and symmetry means swapping the two pairs.

</details>
