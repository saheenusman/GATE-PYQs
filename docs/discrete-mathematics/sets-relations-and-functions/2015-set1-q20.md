# 2015 CS1 Q20: True statements about the power set of a set of sets

## Question

For a set $A$, the power set of $A$ is denoted by $2^A$. If $A = \lbrace 5, \lbrace 6 \rbrace, \lbrace 7 \rbrace \rbrace$, which of the following options are TRUE?

- I. $\emptyset \in 2^A$
- II. $\emptyset \subseteq 2^A$
- III. $\lbrace 5, \lbrace 6 \rbrace \rbrace \in 2^A$
- IV. $\lbrace 5, \lbrace 6 \rbrace \rbrace \subseteq 2^A$

- (A) I and III only
- (B) II and III only
- (C) I, II and III only
- (D) I, II and IV only

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$A$ has three elements: $5$, $\lbrace 6 \rbrace$ and $\lbrace 7 \rbrace$. $2^A$ is the set of all subsets of $A$.

- I: $\emptyset$ is a subset of $A$, so $\emptyset \in 2^A$. **True.**
- II: the empty set is a subset of every set. **True.**
- III: $5 \in A$ and $\lbrace 6\rbrace \in A$, so $\lbrace 5,\lbrace 6\rbrace\rbrace \subseteq A$, hence it is a member of $2^A$. **True.**
- IV: for $\subseteq$, the elements $5$ and $\lbrace 6\rbrace$ would have to be members of $2^A$. But $5$ is not a subset of $A$, and $\lbrace 6 \rbrace \subseteq A$ would need $6 \in A$, which is false. **False.**

So I, II and III: option (C).

**Key idea:** keep $\in$ (member) and $\subseteq$ (subset) apart; $x \in 2^A$ iff $x \subseteq A$.

</details>
