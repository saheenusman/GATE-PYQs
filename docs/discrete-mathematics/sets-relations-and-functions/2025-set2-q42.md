# 2025 CS2 Q42: Partial order and lattice of 0-1 functions

## Question

Let $\mathcal{F}$ be the set of all functions from $\lbrace 1, \dots, n\rbrace$ to $\lbrace 0, 1\rbrace$. Define the binary relation $\preccurlyeq$ on $\mathcal{F}$ as follows:

$\forall f, g \in \mathcal{F},\ f \preccurlyeq g$ if and only if $\forall x \in \lbrace 1, \dots, n\rbrace,\ f(x) \le g(x)$, where $0 \le 1$.

Which of the following statement(s) is/are TRUE?

- (A) $\preccurlyeq$ is a symmetric relation
- (B) $(\mathcal{F}, \preccurlyeq)$ is a partial order
- (C) $(\mathcal{F}, \preccurlyeq)$ is a lattice
- (D) $\preccurlyeq$ is an equivalence relation

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Think of each function as an $n$-bit string, with $f \preccurlyeq g$ when $g$ has a 1 wherever $f$ does. This is the subset order on $\lbrace 1..n\rbrace$.

| Property | Holds? | Reason |
|---|---|---|
| Reflexive | Yes | $f(x) \le f(x)$ |
| Antisymmetric | Yes | $f \preccurlyeq g$ and $g \preccurlyeq f$ give $f(x) = g(x)$ for all $x$ |
| Transitive | Yes | $\le$ is transitive pointwise |
| Symmetric | **No** | the all-zero function $\preccurlyeq$ the all-one function, but not the reverse |

| Option | Verdict |
|---|---|
| A: symmetric | False, by the example above |
| **B: partial order** | **True**: reflexive, antisymmetric, transitive |
| **C: lattice** | **True**: any two functions have a least upper bound (pointwise max) and a greatest lower bound (pointwise min), both in $\mathcal F$ |
| D: equivalence relation | False: it is not symmetric |

I checked these properties by program for $n=3$ (8 functions).

**Key idea:** the pointwise order on bit-vectors is the subset order of a power set, a partial order that is a lattice.

</details>
