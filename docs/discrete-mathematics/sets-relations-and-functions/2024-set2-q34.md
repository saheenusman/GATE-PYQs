# 2024 CS2 Q34: Total orders extending a partial order

## Question

Let $P$ be the partial order defined on the set $\lbrace 1,2,3,4 \rbrace$ as follows:

$$P = \lbrace (x,x) \mid x \in \lbrace 1,2,3,4 \rbrace \rbrace \cup \lbrace (1,2), (3,2), (3,4) \rbrace$$

The number of total orders on $\lbrace 1,2,3,4 \rbrace$ that contain $P$ is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A total order that contains $P$ is a **linear extension**: a listing of 1, 2, 3, 4 in which 1 comes before 2, 3 comes before 2, and 3 comes before 4.

**Enumerate** (smallest first):

| # | Order |
|---|---|
| 1 | 1, 3, 2, 4 |
| 2 | 1, 3, 4, 2 |
| 3 | 3, 1, 2, 4 |
| 4 | 3, 1, 4, 2 |
| 5 | 3, 4, 1, 2 |

Any other order breaks a rule. 3 must come before both 2 and 4, and 1 before 2, so 2 always comes after 1 and 3, and 4 always comes after 3.

Checking all $4! = 24$ permutations by script gives the same 5.

**Key idea:** count permutations that respect every given relation.

</details>
