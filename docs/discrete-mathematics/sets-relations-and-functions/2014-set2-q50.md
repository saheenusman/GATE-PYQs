# 2014 CS2 Q50: Lexicographic order on subsets: largest and smallest subset

## Question

Consider the following relation on subsets of the set $S$ of integers between 1 and 2014. For two distinct subsets $U$ and $V$ of $S$ we say $U < V$ if the minimum element in the symmetric difference of the two sets is in $U$.

Consider the following two statements:

- $S1$: There is a subset of $S$ that is larger than every other subset.
- $S2$: There is a subset of $S$ that is smaller than every other subset.

Which one of the following is CORRECT?

- (A) Both $S1$ and $S2$ are true
- (B) $S1$ is true and $S2$ is false
- (C) $S2$ is true and $S1$ is false
- (D) Neither $S1$ nor $S2$ is true

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

For distinct $U, V$ the symmetric difference is non-empty, and its minimum lies in exactly one of them. So exactly one of $U < V$ or $V < U$ holds: this is a **total order** (it compares subsets like lexicographic order on 0/1 strings, with 1 coming first).

- **Smallest:** $S$ itself. For any $V \ne S$, the symmetric difference is $S \setminus V$, whose minimum is in $S$, so $S < V$.
- **Largest:** the empty set. For any $V \ne \emptyset$ the symmetric difference is $V$, whose minimum is in $V$, so $V < \emptyset$.

So both $S1$ and $S2$ are true: **A**.

**Code check:** for $n = 4$, I enumerated all 16 subsets: the only one larger than all others is $\emptyset$, and the only one smaller than all others is $\lbrace 1,2,3,4 \rbrace$. The argument does not depend on $n$.

**Key idea:** the relation is a total order, and a finite total order has a least and a greatest element.

</details>
