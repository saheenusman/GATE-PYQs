# 2023 CS Q49: Quotient of a surjective function

## Question

Let $f : A \to B$ be an onto (or surjective) function, where $A$ and $B$ are nonempty sets. Define an equivalence relation $\sim$ on the set $A$ as

$$a_1 \sim a_2 \text{ if } f(a_1) = f(a_2),$$

where $a_1, a_2 \in A$. Let $E = \lbrace [x] : x \in A \rbrace$ be the set of all the equivalence classes under $\sim$. Define a new mapping $F : E \to B$ as $F([x]) = f(x)$, for all the equivalence classes $[x]$ in $E$.

Which of the following statements is/are TRUE?

- (A) $F$ is NOT well-defined.
- (B) $F$ is an onto (or surjective) function.
- (C) $F$ is a one-to-one (or injective) function.
- (D) $F$ is a bijective function.

<details class="success" markdown="1">
<summary>Answer</summary>

**B, C and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Well-defined.** If $[x] = [y]$ then $x \sim y$, so $f(x) = f(y)$. The value $F([x])$ does not depend on the representative chosen, so **A is false**.

**Onto.** Any $b \in B$ equals $f(a)$ for some $a$ (since $f$ is onto), and $F([a]) = b$. **B is true.**

**One-to-one.** If $F([x]) = F([y])$ then $f(x) = f(y)$, so $x \sim y$ and $[x] = [y]$. **C is true.**

**Bijective.** Onto and one-to-one together make $F$ bijective. **D is true.**

**Key idea:** collapsing the domain by "same image" turns any surjection into a bijection (the first isomorphism idea).

</details>
