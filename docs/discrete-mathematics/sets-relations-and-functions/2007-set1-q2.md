# 2007 CS Q2: Largest and smallest equivalence relations

## Question

Let $S$ be a set of $n$ elements. The number of ordered pairs in the largest and the smallest equivalence relations on $S$ are

- (A) $n$ and $n$
- (B) $n^2$ and $n$
- (C) $n^2$ and $0$
- (D) $n$ and $1$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Largest:** $S \times S$ (every element related to every element) is an equivalence relation with $n^2$ ordered pairs. No relation on $S$ can have more.
- **Smallest:** an equivalence relation must be reflexive, so it contains all $(x, x)$. The identity relation already works, so the minimum is $n$ pairs.

So $n^2$ and $n$: (B).

- (A) the largest is not $n$.
- (C) the smallest cannot be $0$: the empty relation is not reflexive (for $n \ge 1$).
- (D) both values are wrong.
