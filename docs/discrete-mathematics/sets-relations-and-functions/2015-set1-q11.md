# 2015 CS1 Q11: Ratio of compositions of two functions

## Question

If $g(x) = 1 - x$ and $h(x) = \dfrac{x}{x-1}$, then $\dfrac{g(h(x))}{h(g(x))}$ is:

- (A) $\dfrac{h(x)}{g(x)}$
- (B) $\dfrac{-1}{x}$
- (C) $\dfrac{g(x)}{h(x)}$
- (D) $\dfrac{x}{(1-x)^2}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Compute each composition.

$$g(h(x)) = 1 - \frac{x}{x-1} = \frac{(x-1) - x}{x-1} = \frac{-1}{x-1}$$

$$h(g(x)) = \frac{1-x}{(1-x)-1} = \frac{1-x}{-x} = \frac{x-1}{x}$$

$$\frac{g(h(x))}{h(g(x))} = \frac{-1}{x-1}\cdot\frac{x}{x-1} = \frac{-x}{(x-1)^2}$$

Now test the options.

- (A) $\dfrac{h(x)}{g(x)} = \dfrac{x}{(x-1)(1-x)} = \dfrac{-x}{(x-1)^2}$. Matches.
- (B) $-1/x$ is not equal to it (try $x=2$: ours is $-2$, (B) is $-0.5$).
- (C) $\dfrac{g(x)}{h(x)} = \dfrac{(1-x)(x-1)}{x} = \dfrac{-(x-1)^2}{x}$, which is the reciprocal.
- (D) $\dfrac{x}{(1-x)^2}$ has the wrong sign (at $x=2$ it is $+2$).

**Key idea:** substitute carefully in both orders and compare; at $x=2$ the ratio is $-2$.

</details>
