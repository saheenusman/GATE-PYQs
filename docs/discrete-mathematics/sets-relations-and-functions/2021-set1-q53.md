# 2021 CS1 Q53: Circular relations and equivalence relations

## Question

A relation $R$ is said to be *circular* if $aRb$ and $bRc$ together imply $cRa$. Which of the following options is/are correct?

- (A) If a relation $S$ is reflexive and symmetric, then $S$ is an equivalence relation.
- (B) If a relation $S$ is circular and symmetric, then $S$ is an equivalence relation.
- (C) If a relation $S$ is reflexive and circular, then $S$ is an equivalence relation.
- (D) If a relation $S$ is transitive and circular, then $S$ is an equivalence relation.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An equivalence relation is reflexive, symmetric and transitive.

- (A) False. Take $S=\lbrace(1,1),(2,2),(3,3),(1,2),(2,1),(2,3),(3,2)\rbrace$. It is reflexive and symmetric, but $1S2$ and $2S3$ without $1S3$, so it is not transitive.
- (B) False. The empty relation is circular and symmetric (vacuously) but not reflexive.
- (C) **True.** Let $S$ be reflexive and circular.
  - Symmetric: if $aSb$, then $bSb$ (reflexive), so $aSb$ and $bSb$ give $bSa$.
  - Transitive: if $aSb$ and $bSc$, circularity gives $cSa$, then symmetry (just shown) gives $aSc$.
- (D) False. The empty relation is transitive and circular but not reflexive.

I enumerated all $2^9$ relations on a 3-element set. (A), (B) and (D) each have counterexamples. For (C), no relation that is reflexive and circular fails to be an equivalence relation.

Answer: **C**.

**Key idea:** reflexive + circular $\Rightarrow$ symmetric $\Rightarrow$ transitive. Without reflexivity you can always fall back on the empty relation.

</details>
