# 2018 CS Q37: Which of four sets are countable

## Question

Let $N$ be the set of natural numbers. Consider the following sets.

- P: Set of Rational numbers (positive and negative)
- Q: Set of functions from $\lbrace 0, 1\rbrace$ to $N$
- R: Set of functions from $N$ to $\lbrace 0, 1\rbrace$
- S: Set of finite subsets of $N$.

Which of the sets above are countable?

- (A) Q and S only
- (B) P and S only
- (C) P and R only
- (D) P, Q and S only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **P (rationals):** countable. Each rational is a pair of integers $p/q$, and $\mathbb{Z}\times\mathbb{Z}$ is countable.
- **Q (functions $\lbrace0,1\rbrace\to N$):** a function is determined by the pair $(f(0), f(1))\in N\times N$, which is countable.
- **R (functions $N\to\lbrace0,1\rbrace$):** these are infinite binary sequences. **Uncountable** by Cantor's diagonal argument.
- **S (finite subsets of $N$):** countable. Each finite subset can be encoded as a finite binary string, and there are countably many of those.

Countable: P, Q and S, so **D**.

**Why the others fail:** A and B leave out a countable set; C includes R, which is uncountable.

**Key idea:** finite objects built from countable pieces are countable; infinite sequences over $\lbrace0,1\rbrace$ are not.

</details>
