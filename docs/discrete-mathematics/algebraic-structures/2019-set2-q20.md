# 2019 CS2 Q20: Which relation on a group is an equivalence relation

## Question

Let $G$ be an arbitrary group. Consider the following relations on $G$:

- $R_1$: $\forall a, b \in G,\ a\,R_1\,b$ if and only if $\exists g \in G$ such that $a = g^{-1} b g$
- $R_2$: $\forall a, b \in G,\ a\,R_2\,b$ if and only if $a = b^{-1}$

Which of the above is/are equivalence relation/relations?

- (A) $R_1$ and $R_2$
- (B) $R_1$ only
- (C) $R_2$ only
- (D) Neither $R_1$ nor $R_2$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$R_1$ (conjugacy) is an equivalence relation.**

- Reflexive: take $g = e$, so $a = e^{-1} a e$.
- Symmetric: if $a = g^{-1} b g$ then $b = g a g^{-1} = (g^{-1})^{-1} a\,(g^{-1})$, so $b\,R_1\,a$.
- Transitive: if $a = g^{-1} b g$ and $b = h^{-1} c h$ then $a = (hg)^{-1} c\,(hg)$.

**$R_2$ is not.** Reflexivity needs $a = a^{-1}$ for every $a$, which fails in any group with an element of order above 2 (in $\mathbb{Z}_3$, $1 \ne 1^{-1} = 2$). It is symmetric but not transitive in general.

**Code check:** on the group $S_3$ the program reports $R_1$ as reflexive, symmetric and transitive, and $R_2$ as not reflexive and not transitive.

**Key idea:** conjugacy is an equivalence relation. "Equals the inverse" is not.

</details>
