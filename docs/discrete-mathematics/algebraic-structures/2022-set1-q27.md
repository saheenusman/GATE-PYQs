# 2022 CS Q27: Group theory statements

## Question

Which of the following statements is/are TRUE for a group $G$?

- (A) If for all $x, y \in G$, $(xy)^2 = x^2 y^2$, then $G$ is commutative.
- (B) If for all $x \in G$, $x^2 = 1$, then $G$ is commutative. Here, 1 is the identity element of $G$.
- (C) If the order of $G$ is 2, then $G$ is commutative.
- (D) If $G$ is commutative, then a subgroup of $G$ need not be commutative.

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** $xyxy = xxyy$. Cancel $x$ on the left and $y$ on the right: $yx = xy$.
- **(B) True.** If $x^2 = 1$ for all $x$, every element is its own inverse. Then $xy = (xy)^{-1} = y^{-1}x^{-1} = yx$.
- **(C) True.** A group of order 2 is $\lbrace 1, a \rbrace$. The only products are $1\cdot a = a\cdot 1$ and $a \cdot a$, so the group is commutative.
- **(D) False.** Any two elements of a subgroup are elements of $G$, so they commute. A subgroup of a commutative group is commutative.

**Key idea:** use cancellation and inverses; subgroups inherit commutativity.

</details>
