# 2009 CS Q1: Property that is not necessarily true for a group

## Question

Which one of the following is NOT necessarily a property of a Group?

- (A) Commutativity
- (B) Associativity
- (C) Existence of inverse for every element
- (D) Existence of identity

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A group is a set with a binary operation that is closed, **associative**, has an **identity**, and gives every element an **inverse**. Commutativity is not required: a group that has it is called an abelian group.

So (A) is the property a group need not have.

Example: the permutations of $\lbrace 1, 2, 3 \rbrace$ under composition (the group $S_3$). Applying two particular swaps in different orders gives different results, so it is a group that is not commutative.

- (B), (C), (D) are part of the definition, so they always hold.

**Code check:** a program over the $6$ permutations of $\lbrace 0, 1, 2 \rbrace$ found a pair $p, q$ with $pq \ne qp$.

**Key idea:** the group axioms are closure, associativity, identity and inverses; commutativity is an extra condition (abelian groups).

</details>
