# 2009 CS Q22: Generators of a cyclic group from its composition table

## Question

For the composition table of a cyclic group shown below:

| * | a | b | c | d |
|---|---|---|---|---|
| a | a | b | c | d |
| b | b | a | d | c |
| c | c | d | b | a |
| d | d | c | a | b |

Which one of the following choices is correct?

- (A) $a, b$ are generators
- (B) $b, c$ are generators
- (C) $c, d$ are generators
- (D) $d, a$ are generators

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The identity is $a$ (its row and column repeat the headings). An element is a **generator** if its powers produce all four elements, i.e. its order is $4$.

| Element | Powers | Order |
|---|---|---|
| $a$ | $a$ | 1 |
| $b$ | $b, a$ | 2 |
| $c$ | $c, b, d, a$ | 4 |
| $d$ | $d, b, c, a$ | 4 |

(For example $c \cdot c = b$, then $b \cdot c = d$, then $d \cdot c = a$.)

So the generators are $c$ and $d$: (C).

- (A) $a$ is the identity and $b$ has order $2$.
- (B) $b$ has order $2$.
- (D) $a$ is the identity.

**Code check:** a program computed the order of each element from the table: $a:1$, $b:2$, $c:4$, $d:4$. It also confirmed the table is associative, so it is a group.

**Key idea:** in a cyclic group of order $n$, the generators are the elements of order $n$.

</details>
