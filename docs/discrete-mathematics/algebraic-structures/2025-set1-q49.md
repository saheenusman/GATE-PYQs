# 2025 CS1 Q49: Structure of functions under pointwise addition

## Question

$A = \lbrace 0, 1, 2, 3, \dots\rbrace$ is the set of non-negative integers. Let $\digamma$ be the set of functions from $A$ to itself. For any two functions, $f_1, f_2 \in \digamma$, we define

$$(f_1 \odot f_2)(n) = f_1(n) + f_2(n)$$

for every number $n$ in $A$. Which of the following is/are CORRECT about the mathematical structure $(\digamma, \odot)$?

- (A) $(\digamma, \odot)$ is an Abelian group.
- (B) $(\digamma, \odot)$ is an Abelian monoid.
- (C) $(\digamma, \odot)$ is a non-Abelian group.
- (D) $(\digamma, \odot)$ is a non-Abelian monoid.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Check the axioms.

| Property | Holds? | Reason |
|---|---|---|
| Closure | Yes | The pointwise sum of two functions into the non-negative integers is again such a function |
| Associativity | Yes | $(f_1 + f_2) + f_3 = f_1 + (f_2 + f_3)$ pointwise |
| Identity | Yes | The zero function $e(n) = 0$ (and $0 \in A$) |
| Commutativity | Yes | $f_1(n) + f_2(n) = f_2(n) + f_1(n)$ |
| Inverses | **No** | For $f(n) = 1$ we would need $g(n)$ with $1 + g(n) = 0$, so $g(n) = -1 \notin A$ |

So $(\digamma, \odot)$ is a commutative monoid, but **not a group** (not every element has an inverse).

| Option | Verdict |
|---|---|
| A: Abelian group | False: no inverses |
| **B: Abelian monoid** | **True** |
| C: non-Abelian group | False: not a group, and the operation is commutative |
| D: non-Abelian monoid | False: the operation is commutative |

**Key idea:** non-negative values have no additive inverses, so pointwise addition gives a commutative monoid and not a group.

</details>
