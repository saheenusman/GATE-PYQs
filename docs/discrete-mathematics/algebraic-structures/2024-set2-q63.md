# 2024 CS2 Q63: Self-inverse elements in a product group

## Question

Let $Z_n$ be the group of integers $\lbrace 0, 1, 2, \dots, n-1 \rbrace$ with addition modulo $n$ as the group operation. The number of elements in the group $Z_2 \times Z_3 \times Z_4$ that are their own inverses is ________

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An element $(a,b,c)$ is its own inverse when $2(a,b,c) = (0,0,0)$, i.e. each coordinate satisfies $2x \equiv 0$ in its own group.

| Group | Solutions of $2x \equiv 0$ | Count |
|---|---|---|
| $Z_2$ | 0, 1 | 2 |
| $Z_3$ | 0 only ($2x \equiv 0 \pmod 3$ forces $x = 0$) | 1 |
| $Z_4$ | 0, 2 | 2 |

Total $= 2 \times 1 \times 2 = 4$.

**Key idea:** in a direct product the self-inverse test is done coordinate by coordinate, and the counts multiply.

</details>
