# 2013 CS Q1: x ⊕ y = x² + y²

## Question

A binary operation $\oplus$ on a set of integers is defined as $x \oplus y = x^2 + y^2$.
Which one of the following statements is TRUE about $\oplus$?

- (A) Commutative but not associative
- (B) Both commutative and associative
- (C) Associative but not commutative
- (D) Neither commutative nor associative

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Commutative:** $x \oplus y = x^2+y^2 = y^2+x^2 = y \oplus x$.

**Associative?** Compare both groupings:

- $(x\oplus y)\oplus z = (x^2+y^2)^2 + z^2$
- $x\oplus(y\oplus z) = x^2 + (y^2+z^2)^2$

Counter-example $x=1,\ y=2,\ z=3$:

| Grouping | Value |
|---|---|
| $(1\oplus 2)\oplus 3$ | $5^2+9 = 34$ |
| $1\oplus(2\oplus 3)$ | $1+13^2 = 170$ |

Different, so $\oplus$ is not associative.

**Why the others fail:**

- (B), (C): they claim associativity, which the counter-example refutes.
- (D): it denies commutativity, but the definition is symmetric in $x$ and $y$.

**Code check:** a short Python run gave $34$ and $170$ for this example.

**Key idea:** to disprove associativity, one numeric counter-example is enough.

</details>
