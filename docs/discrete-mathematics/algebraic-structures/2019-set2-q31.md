# 2019 CS2 Q31: Remainder of 3 to the power 51 modulo 5

## Question

The value of $3^{51} \bmod 5$ is ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Powers of 3 repeat modulo 5 with period 4, because $3^4 = 81 \equiv 1 \pmod 5$ (Fermat: $\varphi(5) = 4$).

$$51 = 4 \cdot 12 + 3 \;\Rightarrow\; 3^{51} \equiv (3^4)^{12} \cdot 3^3 \equiv 27 \equiv 2 \pmod 5.$$

**Code check:** `pow(3, 51, 5)` returns 2.

**Key idea:** reduce the exponent by the cycle length, here 4.

</details>
