# 2023 CS Q51: Symmetric difference on a power set

## Question

Let $X$ be a set and $2^X$ denote the powerset of $X$. Define a binary operation $\Delta$ on $2^X$ as follows:

$$A \,\Delta\, B = (A - B) \cup (B - A).$$

Let $H = (2^X, \Delta)$. Which of the following statements about $H$ is/are correct?

- (A) $H$ is a group.
- (B) Every element in $H$ has an inverse, but $H$ is NOT a group.
- (C) For every $A \in 2^X$, the inverse of $A$ is the complement of $A$.
- (D) For every $A \in 2^X$, the inverse of $A$ is $A$.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Check the group axioms.**

- **Closure:** $A \Delta B$ is again a subset of $X$.
- **Associativity:** symmetric difference is associative (an element is in the result exactly when it is in an odd number of the sets).
- **Identity:** $A \Delta \emptyset = A$, so $\emptyset$ is the identity.
- **Inverse:** $A \Delta A = \emptyset$, so every element is its **own inverse**.

So $H$ is a group (**A true**) and the inverse of $A$ is $A$ (**D true**).

**Why the others fail:**
- **B**: every element has an inverse, and the other axioms hold, so $H$ *is* a group.
- **C**: $A \Delta A^c = X$, not $\emptyset$, so the complement is not the inverse (unless $X = \emptyset$).

**Key idea:** the identity here is $\emptyset$, so the inverse must combine with $A$ to give $\emptyset$.

</details>
