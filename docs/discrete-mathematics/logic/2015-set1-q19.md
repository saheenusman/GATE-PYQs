# 2015 CS1 Q19: The statement not equivalent to p if and only if q

## Question

Which one of the following is NOT equivalent to $p \leftrightarrow q$?

- (A) $(\neg p \vee q) \wedge (p \vee \neg q)$
- (B) $(\neg p \vee q) \wedge (q \rightarrow p)$
- (C) $(\neg p \wedge q) \vee (p \wedge \neg q)$
- (D) $(\neg p \wedge \neg q) \vee (p \wedge q)$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$p \leftrightarrow q$ is true exactly when $p$ and $q$ have the same truth value.

- (A) $(p \to q) \wedge (q \to p)$ written with disjunctions. Equivalent.
- (B) $q \to p$ is $\neg q \vee p$, so this is the same as (A). Equivalent.
- (C) true when $p$ and $q$ **differ**, which is $p \oplus q$ (XOR). **Not equivalent**, it is the negation.
- (D) true when both false or both true. Equivalent.

Check with $p = T,\ q = F$: $p\leftrightarrow q$ is false but (C) is true.

**Key idea:** $p \leftrightarrow q$ is "same value"; $(\neg p\wedge q)\vee(p\wedge\neg q)$ is "different value".

</details>
