# 2007 CS Q48: Satisfying at least half of the clauses of a CNF formula

## Question

Which of the following is **TRUE** about formulae in Conjunctive Normal Form?

- (A) For any formula, there is a truth assignment for which at least half the clauses evaluate to true.
- (B) For any formula, there is a truth assignment for which all the clauses evaluate to true.
- (C) There is a formula such that for each truth assignment, at most one-fourth of the clauses evaluate to true.
- (D) None of the above.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(A) is true.** Pick each variable true or false by a fair coin. A clause with $k \ge 1$ literals is false only if all $k$ literals are false, which has probability $2^{-k} \le 1/2$. So each clause is satisfied with probability at least $1/2$, and the expected number of satisfied clauses is at least half of them. Some assignment must do at least as well as the average, so some assignment satisfies at least half.

- (B) is false: $(x)(\neg x)$ is unsatisfiable.
- (C) contradicts (A): (A) says some assignment satisfies at least half, so it cannot be that every assignment satisfies at most a quarter.
- (D) is wrong because (A) is true.

**Code check:** Python brute force over 20,000 random CNF formulas (1-5 variables, 1-12 clauses of 1-3 literals): the best assignment always satisfied at least half the clauses (minimum fraction exactly 0.5); 9,386 of the formulas were not fully satisfiable, which rules out (B).

**Assumption:** the formulas are not allowed to contain an empty clause.

**Key idea:** a random assignment satisfies each clause with probability $\ge 1/2$, so some assignment satisfies at least half the clauses (the idea behind the simple MAX-SAT approximation).
