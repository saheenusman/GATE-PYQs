# 2016 CS2 Q27: Predicate calculus formula that is not valid

## Question

Which one of the following well-formed formulae in predicate calculus is NOT valid?

- (A) $(\forall x\, p(x) \Rightarrow \forall x\, q(x)) \Rightarrow (\exists x\, \lnot p(x) \lor \forall x\, q(x))$
- (B) $(\exists x\, p(x) \lor \exists x\, q(x)) \Rightarrow \exists x\, (p(x) \lor q(x))$
- (C) $\exists x\, (p(x) \land q(x)) \Rightarrow (\exists x\, p(x) \land \exists x\, q(x))$
- (D) $\forall x\, (p(x) \lor q(x)) \Rightarrow (\forall x\, p(x) \lor \forall x\, q(x))$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(D) is not valid.** Take the domain $\lbrace 1, 2 \rbrace$ with $p(1) = \text{T}$, $p(2) = \text{F}$, $q(1) = \text{F}$, $q(2) = \text{T}$.

- $\forall x\,(p(x) \lor q(x))$ is true (each element satisfies one of them).
- $\forall x\, p(x)$ is false and $\forall x\, q(x)$ is false, so $\forall x\, p(x) \lor \forall x\, q(x)$ is false.

True $\Rightarrow$ false is false, so (D) fails.

**The others are valid.**

- (A) $(\forall x\, p \Rightarrow \forall x\, q)$ is equivalent to $\exists x\, \lnot p(x) \lor \forall x\, q(x)$, so the whole formula is "$A \Rightarrow A$".
- (B) If some $x$ satisfies $p$, or some $x$ satisfies $q$, then some $x$ satisfies $p \lor q$.
- (C) A single $x$ with $p(x) \land q(x)$ witnesses both $\exists x\, p$ and $\exists x\, q$.

**Key idea:** $\forall$ does not distribute over $\lor$; a two-element counter-model refutes (D).

</details>
