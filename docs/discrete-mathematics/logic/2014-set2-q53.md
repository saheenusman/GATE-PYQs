# 2014 CS2 Q53: Which expression is not a tautology

## Question

Which one of the following Boolean expressions is NOT a tautology?

- (A) $((a \to b) \wedge (b \to c)) \to (a \to c)$
- (B) $(a \leftrightarrow c) \to (\sim b \to (a \wedge c))$
- (C) $(a \wedge b \wedge c) \to (c \vee a)$
- (D) $a \to (b \to a)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Find an assignment that makes (B) false. Take $a = b = c = 0$:

- $a \leftrightarrow c$ is true,
- $\sim b$ is true,
- $a \wedge c$ is false.

So the inner implication $\sim b \to (a \wedge c)$ is $T \to F = F$, and the whole expression is $T \to F = F$. Hence (B) is not a tautology.

The others are tautologies:

- (A) hypothetical syllogism.
- (C) if $a \wedge b \wedge c$ holds then $a$ holds, so $c \vee a$ holds.
- (D) if $a$ is true then $b \to a$ is true.

**Code check:** a truth table over all 8 assignments shows (A), (C), (D) are tautologies and (B) fails only at $(0,0,0)$.

**Key idea:** one falsifying assignment shows a formula is not a tautology.

</details>
