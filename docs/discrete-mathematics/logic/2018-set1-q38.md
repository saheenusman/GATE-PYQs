# 2018 CS Q38: Models of a first-order sentence with three existentials

## Question

Consider the first-order logic sentence

$$\varphi \equiv \exists s\,\exists t\,\exists u\,\forall v\,\forall w\,\forall x\,\forall y\ \psi(s,t,u,v,w,x,y)$$

where $\psi(s,t,u,v,w,x,y)$ is a quantifier-free first-order logic formula using only predicate symbols, and possibly equality, but no function symbols. Suppose $\varphi$ has a model with a universe containing 7 elements.

Which one of the following statements is necessarily true?

- (A) There exists at least one model of $\varphi$ with universe of size less than or equal to 3.
- (B) There exists no model of $\varphi$ with universe of size less than or equal to 3.
- (C) There exists no model of $\varphi$ with universe of size greater than 7.
- (D) Every model of $\varphi$ has a universe of size equal to 7.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Shrink the model to the witnesses.** Take the 7-element model and let $s, t, u$ be the elements that witness the $\exists$ quantifiers. They are at most **3 distinct elements**.

Restrict the model to this set $W$ of witnesses (keep the same predicate interpretations on $W$). The remaining part of the sentence is $\forall v\forall w\forall x\forall y\,\psi$, with $\psi$ quantifier-free and with no function symbols. A purely universal statement stays true when you throw elements away, because every tuple in $W$ was already a tuple in the big model. The witnesses $s,t,u$ are still in $W$.

So the restricted structure is a model of $\varphi$ with at most 3 elements: **A is necessarily true**.

**Why the others fail:**
- **B** contradicts A.
- **C:** nothing stops larger models from existing; only the reverse (shrinking) is guaranteed.
- **D:** by A, a model of size at most 3 exists, so not every model has size 7.

**Key idea:** this is the Bernays-Schonfinkel class: with no function symbols, an $\exists^*\forall^*$ sentence that has a model has one of size at most the number of existential variables.

</details>
