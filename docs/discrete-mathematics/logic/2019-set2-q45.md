# 2019 CS2 Q45: Which sets satisfy a first-order divisibility formula

## Question

Consider the first order predicate formula $\varphi$:

$$\forall x\,\big[(\forall z\;\, z \mid x \Rightarrow ((z = x) \vee (z = 1))) \Rightarrow \exists w\,\big((w > x) \wedge (\forall z\;\, z \mid w \Rightarrow ((w = z) \vee (z = 1)))\big)\big]$$

Here '$a \mid b$' denotes that '$a$ divides $b$', where $a$ and $b$ are integers. Consider the following sets:

- S1. $\lbrace 1, 2, 3, \dots, 100 \rbrace$
- S2. Set of all positive integers
- S3. Set of all integers

Which of the above sets satisfy $\varphi$?

- (A) S1 and S2
- (B) S1 and S3
- (C) S2 and S3
- (D) S1, S2 and S3

<details class="success" markdown="1">
<summary>Answer</summary>

**C (official key). My analysis agrees on S1 and S2, but finds S3 fails under a strict reading: see the solution**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What $\varphi$ says.** Call $n$ *prime-like* if its only divisors are $n$ and $1$. Then $\varphi$ says: for every prime-like $x$ there is a larger prime-like $w$. In words, there is no largest prime in the set.

**S1 = $\lbrace 1..100\rbrace$ fails.** Take $x = 97$. It is prime-like, but $98, 99, 100$ are all composite, so no larger prime-like $w$ exists in the set.

**S2 = positive integers satisfies it.** There are infinitely many primes (Euclid). For $x = 1$ take $w = 2$.

**S3 = all integers: this is where the key and I differ.**

- *Official key (C):* treat divisors as ordinary positive divisors. Then negative $x < -1$ are not prime-like, $x = 0$ is not prime-like (every $z$ divides 0), and $x = -1$ or any non-negative prime-like $x$ has a larger prime $w$. So S3 satisfies $\varphi$, same as S2.
- *Strict reading:* the formula quantifies $z$ over the set itself. In S3 that includes negative $z$. For every $w \ge 1$, $z = -w$ divides $w$ but is neither $w$ nor $1$, so **no** $w > -1$ is prime-like. But $x = -1$ is prime-like (its divisors are $1$ and $-1 = x$). Then the formula needs a prime-like $w > -1$, and there is none. So S3 would **fail**, leaving only S2, which is not an option.

**Verdict.** The key (C) is reached only under the positive-divisor reading. I am recording the official key and flagging that the question is ambiguous about negative divisors.

**Code check:** brute force on $\lbrace 1..100\rbrace$ finds the single violator $x = 97$. On $\lbrace 1..1000\rbrace$ no $x \le 500$ violates. With $z$ over $\lbrace -200..200\rbrace$ (strict S3), the only $x$ with a true premise is $-1$, and the only prime-like $w$ is $-1$ itself, which is not $> -1$.

**Key idea:** the formula states "no largest prime". The domain decides whether it holds.

</details>
