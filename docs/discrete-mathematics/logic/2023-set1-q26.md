# 2023 CS Q26: Which statements imply a conjecture

## Question

Geetha has a conjecture about integers, which is of the form

$$\forall x \bigl( P(x) \implies \exists y\, Q(x, y) \bigr),$$

where $P$ is a statement about integers, and $Q$ is a statement about pairs of integers. Which of the following (one or more) option(s) would *imply* Geetha's conjecture?

- (A) $\exists x \bigl( P(x) \wedge \forall y\, Q(x, y) \bigr)$
- (B) $\forall x\, \forall y\, Q(x, y)$
- (C) $\exists y\, \forall x \bigl( P(x) \implies Q(x, y) \bigr)$
- (D) $\exists x \bigl( P(x) \wedge \exists y\, Q(x, y) \bigr)$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What we must show.** For *every* $x$ with $P(x)$, some $y$ gives $Q(x,y)$.

- **A (does not imply).** It talks about *one* $x$ only. Other $x$ with $P(x)$ may have no witness.
- **B (implies).** $Q(x,y)$ holds for all pairs, so for any $x$ any $y$ works.
- **C (implies).** Fix the $y$ promised by $\exists y$. For any $x$, $P(x) \implies Q(x, y)$, so $P(x)$ gives $Q(x,y)$ for that $y$, and hence $\exists y\, Q(x,y)$.
- **D (does not imply).** Again only one $x$ is covered.

**Key idea:** an "exists $x$" statement can never imply a "for all $x$" statement. Check the quantifier order.

</details>
