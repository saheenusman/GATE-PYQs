# 2012 CS Q1: Valid inferences: modus tollens versus denying the antecedent

## Question

Consider the following logical inferences.

**I1:** If it rains then the cricket match will not be played. The cricket match was played. *Inference:* There was no rain.

**I2:** If it rains then the cricket match will not be played. It did not rain. *Inference:* The cricket match was played.

Which of the following is **TRUE**?

- (A) Both I1 and I2 are correct inferences
- (B) I1 is correct but I2 is not a correct inference
- (C) I1 is not correct but I2 is a correct inference
- (D) Both I1 and I2 are not correct inferences

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $R$ = "it rains" and $M$ = "the match is played". The rule is $R \to \neg M$.

**I1** has premises $R \to \neg M$ and $M$, and concludes $\neg R$. This is modus tollens (the contrapositive $M \to \neg R$ applied to $M$). **Valid.**

**I2** has premises $R \to \neg M$ and $\neg R$, and concludes $M$. This *denies the antecedent*, which is not valid. With no rain the match may still not be played (bad light, say): $R = 0, M = 0$ makes both premises true and the conclusion false.

- (A) I2 is invalid.
- (C) reverses the verdicts.
- (D) I1 is valid.

**Code check:** a truth-table run over all four $(R, M)$ pairs showed I1 valid and I2 invalid.

**Key idea:** from $P \to Q$ you may infer $\neg Q \to \neg P$, never $\neg P \to \neg Q$.

</details>
