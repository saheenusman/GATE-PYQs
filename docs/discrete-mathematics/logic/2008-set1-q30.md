# 2008 CS Q30: Translating a statement about automata into first order logic

## Question

Let $fsa$ and $pda$ be two predicates such that $fsa(x)$ means $x$ is a finite state automaton, and $pda(y)$ means that $y$ is a pushdown automaton. Let $equivalent$ be another predicate such that $equivalent(a, b)$ means $a$ and $b$ are equivalent. Which of the following first order logic statements represents the following:

*Each finite state automaton has an equivalent pushdown automaton.*

- (A) $(\forall x\ fsa(x)) \Rightarrow (\exists y\ pda(y) \wedge equivalent(x, y))$
- (B) $\neg \forall y\ (\exists x\ fsa(x) \Rightarrow pda(y) \wedge equivalent(x, y))$
- (C) $\forall x\ \exists y\ (fsa(x) \wedge pda(y) \wedge equivalent(x, y))$
- (D) $\forall x\ \exists y\ (fsa(y) \wedge pda(x) \wedge equivalent(x, y))$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The intended meaning is "for every $x$ that is an FSA, there exists a $y$ that is a PDA and is equivalent to $x$", i.e. $\forall x\,\big(fsa(x) \Rightarrow \exists y\,(pda(y) \wedge equivalent(x,y))\big)$. Compare the options with this shape:

- (A) The quantifier $\forall x$ covers only $fsa(x)$, so the $x$ in the second half is a free variable. It says "if everything is an FSA, then...". Wrong.
- (B) $\neg \forall y\,(\ldots)$ asserts that *not* every $y$ has a property, which is a different claim altogether.
- (D) The roles are swapped: $x$ is the PDA and $y$ the FSA ("each PDA has an equivalent FSA"), which is false and not what was asked.
- (C) has the right quantifiers ($\forall x \exists y$) and the right roles ($fsa(x)$, $pda(y)$, $equivalent(x,y)$). It is the closest to the intended sentence, and the key's answer.

**Caveat on the wording.** Read literally, (C) uses "$\wedge$" where the natural form uses "$\Rightarrow$" after $fsa(x)$, so it would say that *every* $x$ is an FSA. None of the options has the exact implication form, so (C) is the best match.

**Key idea:** "every $A$ has a $B$" is $\forall x\,(A(x) \Rightarrow \exists y\,B(x,y))$, with the guard attached to $x$ only.

</details>
