# 2014 CS3 Q53: First-order formula for 'not all rainy days are cold'

## Question

The CORRECT formula for the sentence, "not all rainy days are cold" is

- (A) $\forall d\ (\text{Rainy}(d) \wedge \sim\text{Cold}(d))$
- (B) $\forall d\ (\sim\text{Rainy}(d) \to \text{Cold}(d))$
- (C) $\exists d\ (\sim\text{Rainy}(d) \to \text{Cold}(d))$
- (D) $\exists d\ (\text{Rainy}(d) \wedge \sim\text{Cold}(d))$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

"All rainy days are cold" is $\forall d\,(\text{Rainy}(d) \to \text{Cold}(d))$. Negate it:

$$\sim\forall d\,(\text{Rainy}(d) \to \text{Cold}(d)) \equiv \exists d\,\sim(\text{Rainy}(d) \to \text{Cold}(d)) \equiv \exists d\,(\text{Rainy}(d) \wedge \sim\text{Cold}(d)).$$

That is (D): there is a rainy day that is not cold.

- (A) says *every* day is rainy and not cold.
- (B) says every non-rainy day is cold. It is about the wrong set of days.
- (C) is true whenever some day is *not* rainy (the implication is then vacuously true), so it does not express the sentence.

**Key idea:** $\sim\forall x\,(P \to Q) \equiv \exists x\,(P \wedge \sim Q)$.

</details>
