# 2009 CS Q24: Binary operation defined by a truth table, equivalent to P or Q

## Question

The binary operation $\square$ is defined as follows:

| P | Q | P $\square$ Q |
|---|---|---|
| T | T | T |
| T | F | T |
| F | T | F |
| F | F | T |

Which one of the following is equivalent to $P \vee Q$ ?

- (A) $\neg Q \,\square\, \neg P$
- (B) $P \,\square\, \neg Q$
- (C) $\neg P \,\square\, Q$
- (D) $\neg P \,\square\, \neg Q$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

From the table, $P \square Q$ is false only when $P = F$ and $Q = T$. That is the truth table of

$$P \square Q = P \vee \neg Q.$$

Substitute into each option:

- (A) $\neg Q \square \neg P = \neg Q \vee P$
- (B) $P \square \neg Q = P \vee \neg(\neg Q) = P \vee Q$
- (C) $\neg P \square Q = \neg P \vee \neg Q$
- (D) $\neg P \square \neg Q = \neg P \vee Q$

Truth values (1 = true) in the order $(P,Q) = (1,1), (1,0), (0,1), (0,0)$:

| Expression | Values |
|---|---|
| $P \vee Q$ | 1, 1, 1, 0 |
| (A) | 1, 1, 0, 1 |
| (B) | 1, 1, 1, 0 |
| (C) | 0, 1, 1, 1 |
| (D) | 1, 0, 1, 1 |

Only (B) matches $P \vee Q$: (B).

**Code check:** a program confirmed $P \square Q = P \vee \neg Q$ matches the table and that only option (B) equals $P \vee Q$ on all four input pairs.

**Key idea:** read the operation's definition off the truth table first ($P \vee \neg Q$), then substitute.

</details>
