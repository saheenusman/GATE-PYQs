# 2020 CS Q49: Which predicate equivalence is NOT valid

## Question

Which one of the following predicate formulae is NOT logically valid?

Note that $W$ is a predicate formula without any free occurrence of $x$.

- (A) $\forall x\,(p(x) \lor W) \equiv \forall x\, p(x) \lor W$
- (B) $\exists x\,(p(x) \land W) \equiv \exists x\, p(x) \land W$
- (C) $\forall x\,(p(x) \to W) \equiv \forall x\, p(x) \to W$
- (D) $\exists x\,(p(x) \to W) \equiv \forall x\, p(x) \to W$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Since $x$ does not occur free in $W$, $W$ behaves like a constant when quantified over $x$.

**(A) Valid.**
- If $W$ is true, both sides are true.
- If $W$ is false, both sides reduce to $\forall x\, p(x)$.

**(B) Valid.**
- If $W$ is false, both sides are false.
- If $W$ is true, both sides reduce to $\exists x\, p(x)$.

**(D) Valid.** Rewrite the implication:

$$\exists x\,(\lnot p(x) \lor W) \equiv \exists x\,\lnot p(x) \lor W \equiv \lnot\forall x\, p(x) \lor W \equiv \forall x\, p(x) \to W.$$

**(C) NOT valid.** The same rewriting gives

$$\forall x\,(\lnot p(x) \lor W) \equiv \forall x\,\lnot p(x) \lor W \equiv \lnot\exists x\, p(x) \lor W \equiv \exists x\, p(x) \to W.$$

So the left side of (C) is $\exists x\, p(x) \to W$, not $\forall x\, p(x) \to W$. These differ.

**Counterexample.** Domain $\lbrace 1, 2 \rbrace$, $p(1)$ true, $p(2)$ false, $W$ false.

| Side | Value |
|---|---|
| $\forall x\,(p(x) \to W)$ | $p(1) \to W$ is $T \to F = F$, so **false** |
| $\forall x\, p(x) \to W$ | $\forall x\, p(x)$ is false, so **true** |

The two sides disagree, so (C) is not valid.

I also checked all four by brute force over every predicate on a 3-element domain, with $W$ true and false. (A), (B) and (D) held every time and (C) failed.

**Key idea:** a quantifier moving past an implication flips on the antecedent: $\forall x\,(p \to W) \equiv \exists x\, p \to W$, and $\exists x\,(p \to W) \equiv \forall x\, p \to W$.

</details>
