# 2014 CS1 Q1: Logic form of 'Not all that glitters is gold'

## Question

Consider the statement

"Not all that glitters is gold"

Predicate $glitters(x)$ is true if $x$ glitters and predicate $gold(x)$ is true if $x$ is gold. Which one of the following logical formulae represents the above statement?

- (A) $\forall x: glitters(x) \Rightarrow \neg gold(x)$
- (B) $\forall x: gold(x) \Rightarrow glitters(x)$
- (C) $\exists x: gold(x) \wedge \neg glitters(x)$
- (D) $\exists x: glitters(x) \wedge \neg gold(x)$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

"All that glitters is gold" is $\forall x: glitters(x) \Rightarrow gold(x)$. Negate it:

$$\neg\forall x\,(glitters(x) \Rightarrow gold(x)) \equiv \exists x\,(glitters(x) \wedge \neg gold(x))$$

So some glittering thing is not gold: **D**.

- (A) says nothing that glitters is gold, which is far stronger.
- (B) says all gold glitters, which has the implication reversed.
- (C) says some gold does not glitter, which is a different claim.

**Key idea:** $\neg\forall x\,(P \Rightarrow Q) \equiv \exists x\,(P \wedge \neg Q)$.

</details>
