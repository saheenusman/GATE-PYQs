# 2017 CS1 Q29: Truth of (r implies p) implies q when (p implies q) implies r is false

## Question

Let $p$, $q$, and $r$ be propositions and the expression $(p \to q) \to r$ be a contradiction. Then, the expression $(r \to p) \to q$ is

- (A) a tautology.
- (B) a contradiction.
- (C) always TRUE when $p$ is FALSE.
- (D) always TRUE when $q$ is TRUE.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**What the premise forces.** An implication $X \to r$ is false only when $X$ is true and $r$ is false. So the premise "$(p\to q)\to r$ is false" means

$$r = \text{F} \quad\text{and}\quad (p \to q) = \text{T}$$

Allowed $(p,q,r)$: $(0,0,0)$, $(0,1,0)$, $(1,1,0)$.

**Evaluate the second expression.** With $r$ false, $r \to p$ is true, so

$$(r\to p)\to q \;\equiv\; \text{T}\to q \;\equiv\; q$$

| $(p,q,r)$ | $(r\to p)\to q$ |
|---|---|
| $(0,0,0)$ | F |
| $(0,1,0)$ | T |
| $(1,1,0)$ | T |

**Check the options.**

- (A) Not a tautology: it is false at $(0,0,0)$.
- (B) Not a contradiction: it is true at $(0,1,0)$ and $(1,1,0)$.
- (C) "True when $p$ is false" fails at $(0,0,0)$.
- (D) It equals $q$, so it is **true whenever $q$ is true**. Correct: **(D)**.

**Code check:** a truth table found the three assignments above. On them, $(r\to p)\to q$ was true exactly when $q$ was true.

**Note on the wording.** Taken literally, $(p\to q)\to r$ is *not* a contradiction as a formula: with $r$ true it is true. The question means "assume the expression is false", which is how I read it. The official key (D) is consistent with that reading.

**Key idea:** a false implication fixes its parts (antecedent true, consequent false); substitute those values into the second expression.

</details>
