# 2016 CS2 Q1: Expressions logically implied by P and (P implies Q)

## Question

Consider the following expressions:

- (i) false
- (ii) $Q$
- (iii) true
- (iv) $P \lor Q$
- (v) $\lnot Q \lor P$

The number of expressions given above that are logically implied by $P \land (P \Rightarrow Q)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$P \land (P \Rightarrow Q) \equiv P \land Q$ (modus ponens). An expression is implied if it is true whenever $P \land Q$ is true, i.e. when $P = Q = \text{T}$.

| Expression | Value at $P = Q = \text{T}$ | Implied? |
|---|---|---|
| (i) false | F | no |
| (ii) $Q$ | T | yes |
| (iii) true | T | yes |
| (iv) $P \lor Q$ | T | yes |
| (v) $\lnot Q \lor P$ | T | yes |

Four expressions are implied.

**Code check:** a truth-table check over all four $(P, Q)$ rows counted $4$.

**Key idea:** $P \land (P \Rightarrow Q) \equiv P \land Q$; test each expression at $P = Q = $ T.

</details>
