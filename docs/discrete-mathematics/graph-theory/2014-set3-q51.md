# 2014 CS3 Q51: Number of edges in a forest

## Question

If $G$ is a forest with $n$ vertices and $k$ connected components, how many edges does $G$ have?

- (A) $\lfloor n/k \rfloor$
- (B) $\lceil n/k \rceil$
- (C) $n - k$
- (D) $n - k + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each connected component of a forest is a tree. A tree on $n_i$ vertices has $n_i - 1$ edges. Summing over the $k$ components:

$$\sum_{i=1}^{k} (n_i - 1) = n - k.$$

Check: a single tree ($k = 1$) has $n - 1$ edges, which (D) would break ($n$), and $n$ isolated vertices ($k = n$) have $0$ edges, which (A) and (B) would break ($1$).

**Key idea:** a forest with $n$ vertices and $k$ trees has $n - k$ edges.

</details>
