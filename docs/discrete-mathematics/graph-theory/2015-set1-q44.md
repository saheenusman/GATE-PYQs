# 2015 CS1 Q44: Edges of a planar graph whose faces are all triangles

## Question

Let $G$ be a connected planar graph with 10 vertices. If the number of edges on each face is three, then the number of edges in $G$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**24**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each face is bounded by 3 edges, and each edge borders two faces, so $3F = 2E$, i.e. $F = \frac{2E}{3}$.

Euler's formula for a connected planar graph: $V - E + F = 2$.

$$10 - E + \frac{2E}{3} = 2 \;\Rightarrow\; \frac{E}{3} = 8 \;\Rightarrow\; E = 24$$

This is the maximum for a planar graph: $3V - 6 = 24$.

**Key idea:** all faces triangles gives $E = 3V - 6$.

</details>
