# 2014 CS1 Q51: Number of edges in the 12x12 king-move graph

## Question

Consider an undirected graph $G$ where self-loops are not allowed. The vertex set of $G$ is $\lbrace (i,j) : 1 \le i \le 12,\ 1 \le j \le 12 \rbrace$. There is an edge between $(a,b)$ and $(c,d)$ if $|a - c| \le 1$ and $|b - d| \le 1$. The number of edges in this graph is __________.

<details class="success" markdown="1">
<summary>Answer</summary>

**506**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each vertex is joined to its neighbours in the $12 \times 12$ grid, including diagonals (king moves). Count edge directions separately:

| Type | Count |
|---|---|
| Horizontal (same row) | $12 \times 11 = 132$ |
| Vertical (same column) | $11 \times 12 = 132$ |
| Diagonal `\` | $11 \times 11 = 121$ |
| Diagonal `/` | $11 \times 11 = 121$ |

$$132 + 132 + 121 + 121 = 506$$

**Code check:** counting unordered pairs of the 144 vertices that satisfy the condition gives 506.

**Key idea:** count each edge direction once; each cell pair is counted once.

</details>
