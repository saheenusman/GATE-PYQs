# 2014 CS2 Q51: Self-complementary cycle

## Question

A cycle on $n$ vertices is isomorphic to its complement. The value of $n$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Isomorphic graphs have the same number of edges. The cycle $C_n$ has $n$ edges, and its complement has $\binom{n}{2} - n$ edges. So

$$n = \frac{n(n-1)}{2} - n \;\Rightarrow\; \frac{n-1}{2} = 2 \;\Rightarrow\; n = 5.$$

For $n = 5$, the complement of $C_5$ (vertices $0..4$) joins $i$ to $i \pm 2$, which is again a 5-cycle ($0\text{-}2\text{-}4\text{-}1\text{-}3\text{-}0$). So the isomorphism exists.

**Code check:** NetworkX isomorphism tests for $C_n$ against its complement, for $n = 3, \ldots, 11$, succeed only for $n = 5$.

**Key idea:** a self-complementary graph has exactly half of the $\binom{n}{2}$ edges.

</details>
