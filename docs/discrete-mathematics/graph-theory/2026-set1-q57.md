# 2026 CS1 Q57: Matchings in a path on 8 vertices

## Question

Let $G$ be an undirected graph which is a path on 8 vertices. The number of matchings in $G$ is _____. (answer in integer)

<details class="success" markdown="1">
<summary>Answer</summary>

**34**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A *matching* is a set of edges with no shared vertex. The empty set of edges counts as a matching, and the official key counts it.

Let $m(n)$ be the number of matchings of a path on $n$ vertices. Look at the last vertex $v_n$.

- **$v_n$ is not matched.** Remove it: what remains is a path on $n-1$ vertices, so $m(n-1)$ ways.
- **$v_n$ is matched** with $v_{n-1}$ (its only neighbour). Remove both: a path on $n-2$ vertices remains, so $m(n-2)$ ways.

$$m(n) = m(n-1) + m(n-2), \qquad m(1) = 1,\ m(2) = 2.$$

This is the Fibonacci sequence.

| $n$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| $m(n)$ | 1 | 2 | 3 | 5 | 8 | 13 | 21 | **34** |

**Check by size for $n = 8$** (7 edges in a row, choose $j$ pairwise non-adjacent ones):

| $j$ edges | Ways |
|---|---|
| 0 | 1 |
| 1 | 7 |
| 2 | 15 |
| 3 | 10 |
| 4 | 1 |
| Total | 34 |

The count for $j$ edges is $\binom{8-j}{j}$.

**Verified** by listing all edge subsets of the path in Python: the counts for $n = 1..8$ are 1, 2, 3, 5, 8, 13, 21, 34. (If you left out the empty matching you would get 33, which does not match the key.)

**Key idea:** for a path, "last vertex unmatched or matched with its neighbour" gives a Fibonacci recurrence.

</details>
