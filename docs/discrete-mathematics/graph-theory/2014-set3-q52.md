# 2014 CS3 Q52: Number of faces of a planar graph with minimum degree 3

## Question

Let $\delta$ denote the minimum degree of a vertex in a graph. For all planar graphs on $n$ vertices with $\delta \ge 3$, which one of the following is **TRUE**?

- (A) In any planar embedding, the number of faces is at least $\dfrac{n}{2} + 2$
- (B) In any planar embedding, the number of faces is less than $\dfrac{n}{2} + 2$
- (C) There is a planar embedding in which the number of faces is less than $\dfrac{n}{2} + 2$
- (D) There is a planar embedding in which the number of faces is at most $\dfrac{n}{\delta + 1}$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Let $e$ be the number of edges and $f$ the number of faces.

- Every vertex has degree $\ge 3$, so the degree sum is $2e \ge 3n$, which gives $e \ge 3n/2$.
- **Euler's formula** for a connected planar graph: $n - e + f = 2$, so $f = 2 - n + e$.

$$f \ge 2 - n + \frac{3n}{2} = \frac{n}{2} + 2.$$

This holds in every planar embedding, so (A) is true, and (B) and (C) are false.

(D) claims a number of faces as small as $n/(\delta+1)$, which is at most $n/4$. That is below the lower bound $n/2 + 2$, so it is impossible.

**Code check:** for $K_4$, the cube, the octahedron, the icosahedron and the dodecahedron (all planar with $\delta \ge 3$), $f = e - n + 2$ satisfies $f \ge n/2 + 2$, with equality for $K_4$, the cube and the dodecahedron (3-regular graphs).

**Key idea:** $\delta \ge 3 \Rightarrow e \ge 3n/2$, and Euler's formula turns that into $f \ge n/2 + 2$.

</details>
