# 2013 CS Q26: Line graph properties

## Question

The line graph $L(G)$ of a simple graph $G$ is defined as follows:

- There is exactly one vertex $v(e)$ in $L(G)$ for each edge $e$ in $G$.
- For any two edges $e$ and $e'$ in $G$, $L(G)$ has an edge between $v(e)$ and $v(e')$, if and only if $e$ and $e'$ are incident with the same vertex in $G$.

Which of the following statements is/are TRUE?

- (P) The line graph of a cycle is a cycle.
- (Q) The line graph of a clique is a clique.
- (R) The line graph of a planar graph is planar.
- (S) The line graph of a tree is a tree.

- (A) P only
- (B) P and R only
- (C) R only
- (D) P, Q and S only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(P) True.** In a cycle $C_n$ each edge touches exactly two others, forming a cycle of the same length: $L(C_n) = C_n$.
- **(Q) False.** $K_4$ has 6 edges, so $L(K_4)$ has 6 vertices and 12 edges (each edge meets 4 others). A clique on 6 vertices needs 15 edges.
- **(R) False.** The star $K_{1,5}$ is planar, but all 5 edges share the centre, so $L(K_{1,5}) = K_5$, which is not planar.
- **(S) False.** The star $K_{1,3}$ is a tree, but $L(K_{1,3}) = K_3$, a triangle, which has a cycle.

Only P is true: (A).

**Why the others fail:** (B), (C), (D) each include at least one of Q, R, S, refuted above.

**Code check:** $L(C_n)$ is a cycle for $n=3$ to $9$; the $K_4$ count (6 vertices, 12 edges), $L(K_{1,5})=K_5$ nonplanar and $L(K_{1,3})=K_3$ were all confirmed with networkx.

**Key idea:** edges sharing a vertex become adjacent in $L(G)$; a high-degree vertex turns into a clique.

</details>
