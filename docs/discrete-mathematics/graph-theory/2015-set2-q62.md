# 2015 CS2 Q62: True statement about bridges in a connected graph

## Question

In a connected graph, a bridge is an edge whose removal disconnects a graph. Which one of the following statements is true?

- (A) A tree has no bridges
- (B) A bridge cannot be part of a simple cycle
- (C) Every edge of a clique with size $\ge 3$ is a bridge (A clique is any complete subgraph of a graph)
- (D) A graph with bridges cannot have a cycle

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**(B) is true.** Suppose edge $uv$ lies on a simple cycle. Removing $uv$ leaves the rest of the cycle as a $u$–$v$ path, so $u$ and $v$ are still connected and the graph stays connected. So $uv$ is not a bridge.

**Counter-examples for the rest:**

- (A) A tree with at least 2 vertices, such as a single edge $K_2$: *every* edge of a tree is a bridge.
- (C) The triangle $K_3$: each edge lies on the cycle, so none is a bridge.
- (D) A triangle with a pendant edge attached: the pendant edge is a bridge, yet the graph has a cycle.

**Code check:** over all 995 connected graphs on 2 to 7 vertices, no bridge ever lies on a cycle, and each counter-example above was found.

**Key idea:** an edge is a bridge exactly when it lies on no cycle.

</details>
