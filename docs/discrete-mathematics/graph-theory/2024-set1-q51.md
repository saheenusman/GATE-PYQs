# 2024 CS1 Q51: Always-true facts about chromatic number k

## Question

The chromatic number of a graph is the minimum number of colours used in a proper colouring of the graph. Let $G$ be any graph with $n$ vertices and chromatic number $k$. Which of the following statements is/are always TRUE?

- (A) $G$ contains a complete subgraph with $k$ vertices
- (B) $G$ contains an independent set of size at least $n/k$
- (C) $G$ contains at least $k(k-1)/2$ edges
- (D) $G$ contains a vertex of degree at least $k$

<details class="success" markdown="1">
<summary>Answer</summary>

**B and C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) False.** A 5-cycle has chromatic number 3 but contains no triangle ($K_3$). Chromatic number can exceed the largest clique.
- **(B) True.** A proper $k$-colouring splits the $n$ vertices into $k$ colour classes, each an independent set. By pigeonhole, some class has at least $n/k$ vertices.
- **(C) True.** Between any two colour classes there must be at least one edge. Otherwise the two classes could be merged into one colour, giving a colouring with fewer than $k$ colours. There are $\binom{k}{2} = k(k-1)/2$ pairs of classes, so at least that many edges.
- **(D) False.** $K_k$ has chromatic number $k$ but every vertex has degree $k - 1$. (So does the 5-cycle: $k = 3$, degree 2.)

**Key idea:** colour classes are independent sets, and distinct classes must be joined by at least one edge each.

</details>
