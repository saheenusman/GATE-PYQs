# 2024 CS2 Q51: Spanning trees all of even weight

## Question

Let $G$ be an undirected connected graph in which every edge has a positive integer weight. Suppose that every spanning tree in $G$ has even weight. Which of the following statements is/are TRUE for every such graph $G$?

- (A) All edges in $G$ have even weight
- (B) All edges in $G$ have even weight OR all edges in $G$ have odd weight
- (C) In each cycle $C$ in $G$, all edges in $C$ have even weight
- (D) In each cycle $C$ in $G$, either all edges in $C$ have even weight OR all edges in $C$ have odd weight

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Edge exchange.** Let $e$ and $f$ be two edges on a cycle $C$. The path $C - f$ is a tree fragment, so extend it to a spanning tree $T$ that contains $e$ but not $f$. In $T$ the path between the ends of $f$ is $C - f$, which uses $e$. So $T - e + f$ is also a spanning tree. Both trees have even weight, so

$$w(f) - w(e) \text{ is even} \;\Rightarrow\; w(e) \equiv w(f) \pmod 2.$$

Any two edges on a common cycle can be swapped this way, so **all edges of a cycle have the same parity**. That is exactly **(D)**.

**Counterexamples to the rest:**

- **(A), (B)** Take a path with edge weights $1, 1, 2$ (a tree, so its only spanning tree has weight 4, even). Edges are not all even and not all odd.
- **(C)** Take a triangle with all weights 1. Every spanning tree has 2 edges, weight 2 (even), but the cycle's edges are odd.

(I also confirmed this by brute force over all connected graphs on 4 vertices with weights 1 or 2: only (D) held in all 98 cases that satisfy the hypothesis.)

**Key idea:** swapping one edge of a spanning tree along a cycle preserves parity, so edges in one cycle share parity.

</details>
