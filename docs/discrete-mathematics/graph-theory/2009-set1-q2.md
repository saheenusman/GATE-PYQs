# 2009 CS Q2: Chromatic number of a connected graph with no odd cycle

## Question

What is the chromatic number of an $n$-vertex simple connected graph which does not contain any odd length cycle? Assume $n \ge 2$.

- (A) 2
- (B) 3
- (C) $n - 1$
- (D) $n$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A graph with no odd-length cycle is **bipartite**, so it can be coloured with $2$ colours. A connected graph with $n \ge 2$ vertices has at least one edge, so one colour is not enough. Hence the chromatic number is exactly $2$: (A).

- (B) $3$ colours are needed only when there is an odd cycle (for example a triangle).
- (C) and (D) $n - 1$ and $n$ do not fit in general. A path on $n$ vertices has no odd cycle but needs only $2$ colours; $n$ colours are needed only for the complete graph $K_n$, which contains triangles once $n \ge 3$.

**Code check:** all labelled connected graphs on $3$ to $6$ vertices were generated. Of these, $3248$ have no odd cycle, and every one of them has chromatic number $2$.

**Key idea:** no odd cycle means bipartite, which means chromatic number $2$ (for a graph with at least one edge).

</details>
