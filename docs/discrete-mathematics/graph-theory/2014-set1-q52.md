# 2014 CS1 Q52: Which 6-tuple is not a graphic degree sequence

## Question

An ordered $n$-tuple $(d_1, d_2, \ldots, d_n)$ with $d_1 \ge d_2 \ge \cdots \ge d_n$ is called *graphic* if there exists a simple undirected graph with $n$ vertices having degrees $d_1, d_2, \ldots, d_n$ respectively. Which of the following 6-tuples is NOT graphic?

- (A) (1, 1, 1, 1, 1, 1)
- (B) (2, 2, 2, 2, 2, 2)
- (C) (3, 3, 3, 1, 0, 0)
- (D) (3, 2, 1, 1, 1, 0)

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Use the Havel-Hakimi test: remove the largest degree $d$ and subtract 1 from the next $d$ largest degrees. Repeat. The sequence is graphic iff it ends at all zeros with no negative entry.

**(C)** $(3,3,3,1,0,0)$: remove 3, subtract from the next three: $(2,2,0,0,0)$. Remove 2: $(1,-1,0,0)$. A negative degree appears, so **not graphic**.

Another view: three vertices of degree 3 among only four non-isolated vertices would need to be adjacent to all other non-isolated ones, so the one vertex of degree 1 would get degree 3.

The others are graphic:

- (A) three disjoint edges.
- (B) a 6-cycle.
- (D) vertex $a$ of degree 3 joined to $b$ (2), $c$ and $d$ (1 each); then $b$ also joins $e$. Degrees: $a=3$, $b=2$, $c=d=e=1$, $f=0$.

**Code check:** a Havel-Hakimi program returns false only for (C).

**Key idea:** Havel-Hakimi decides whether a degree sequence is graphic.

</details>
