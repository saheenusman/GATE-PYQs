# 2008 CS Q23: A property true for every planar graph

## Question

Which of the following statements is true for every planar graph on $n$ vertices?

- (A) The graph is connected
- (B) The graph is Eulerian
- (C) The graph has a vertex-cover of size at most $3n/4$
- (D) The graph has an independent set of size at least $n/3$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) False. A planar graph can be disconnected (for example two isolated vertices).
- (B) False. A single edge (or any path) is planar but not Eulerian.
- (C) **True.** By the **Four Colour Theorem** every planar graph can be coloured with 4 colours. The vertices split into 4 independent sets, so the largest has at least $n/4$ vertices. The complement of an independent set is a vertex cover, so there is a vertex cover of size at most $n - n/4 = 3n/4$.
- (D) False. $K_4$ is planar with $n = 4$, but its largest independent set has size $1 < 4/3 = n/3$.

So (C).

**Code check:** a brute force on $K_4$ gave a maximum independent set of size $1$ (less than $n/3 = 1.33$) and a minimum vertex cover of size $3 = 3n/4$.

**Key idea:** a planar graph is 4-colourable, so it has an independent set of size at least $n/4$, which gives a vertex cover of size at most $3n/4$.

</details>
