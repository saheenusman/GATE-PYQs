# 2017 CS2 Q23: Maximum vertices for 25 edges with minimum degree 3

## Question

$G$ is an undirected graph with $n$ vertices and 25 edges such that each vertex of $G$ has degree at least 3. Then the maximum possible value of $n$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**16**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Handshake lemma.** The sum of all degrees is twice the number of edges:

$$\sum_v \deg(v) = 2 \times 25 = 50.$$

Each vertex has degree at least 3, so

$$3n \le 50 \;\Rightarrow\; n \le \frac{50}{3} = 16.67 \;\Rightarrow\; n \le 16.$$

**Is 16 achievable?** For $n = 16$ the degrees must add up to 50. Take 14 vertices of degree 3 and 2 of degree 4: $14\cdot 3 + 2\cdot 4 = 50$. Such a degree sequence is realisable by a simple graph.

So the maximum is $n = 16$.

**Code check:** the Havel–Hakimi algorithm built a simple graph on 16 vertices with 25 edges and minimum degree 3 from the degree sequence $(4,4,3,\ldots,3)$.

**Key idea:** use $\sum \deg = 2|E|$ for an upper bound, then show a graph reaching it.

</details>
