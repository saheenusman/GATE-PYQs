# 2013 CS Q25: Handshake lemma statements

## Question

Which of the following statements is/are TRUE for undirected graphs?

- P: Number of odd degree vertices is even.
- Q: Sum of degrees of all vertices is even.

- (A) P only
- (B) Q only
- (C) Both P and Q
- (D) Neither P nor Q

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Q.** Each edge adds 1 to the degree of each of its two endpoints, so $\sum \deg(v) = 2|E|$, which is even. **True.**

**P.** Split the sum into even-degree and odd-degree vertices. The even-degree part is even, and the total is even, so the odd-degree part is even. A sum of odd numbers is even only when there is an even number of terms. **True.**

Both are true: (C).

**Why the others fail:** (A), (B) accept only one; (D) rejects both. Both follow from the handshake lemma.

**Code check:** the lemma held on all graphs with up to 6 vertices.

**Key idea:** handshake lemma: $\sum \deg = 2|E|$, so the number of odd-degree vertices is even.

</details>
