# 2018 CS Q53: Degree and components of the adjacent-swap permutation graph

## Question

Let $G$ be a graph with $100!$ vertices, with each vertex labelled by a distinct permutation of the numbers $1, 2, \ldots, 100$. There is an edge between vertices $u$ and $v$ if and only if the label of $u$ can be obtained by swapping two adjacent numbers in the label of $v$. Let $y$ denote the degree of a vertex in $G$, and $z$ denote the number of connected components in $G$.

Then, $y + 10z = $ _____.

<details class="success" markdown="1">
<summary>Answer</summary>

**109**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Degree $y$.** A permutation of length 100 has 99 adjacent pairs. Swapping each pair gives a different permutation, so every vertex has exactly **99** neighbours: $y = 99$.

**Components $z$.** Adjacent swaps (bubble-sort moves) can reach any permutation from any other: every permutation can be sorted by adjacent swaps, so all vertices are mutually reachable. The graph is connected: $z = 1$.

$$y + 10z = 99 + 10(1) = 109$$

**Code check:** for $n = 3,4,5,6$, building the graph on all $n!$ permutations gave degree $n-1$ everywhere and a single component; the pattern gives $99$ and $1$ for $n=100$.

**Key idea:** adjacent transpositions generate the whole symmetric group, so the graph is connected; each vertex has $n-1$ such swaps.

</details>
