# 2010 CS Q1: Two trees with equal sum of degrees

## Question

Let $G=(V,E)$ be a graph. Define $\xi(G)=\sum_d i_d \times d$, where $i_d$ is the number of vertices of degree $d$ in $G$. If $S$ and $T$ are two different trees with $\xi(S)=\xi(T)$, then

- (A) $|S| = 2|T|$
- (B) $|S| = |T| - 1$
- (C) $|S| = |T|$
- (D) $|S| = |T| + 1$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Grouping vertices by degree, $\sum_d i_d \times d$ is just the **sum of all vertex degrees**, so $\xi(G) = 2|E|$ by the handshake lemma.

A tree on $n$ vertices has $n-1$ edges, so $\xi(T) = 2(n-1)$. This is strictly increasing in $n$, so $\xi(S) = \xi(T)$ forces $|S| = |T|$: (C).

- (A), (B), (D) would give $\xi(S)$ and $\xi(T)$ that differ by $2$ or more, because $\xi$ changes by $2$ for every extra vertex.

**Code check:** for every non-isomorphic tree with $n = 2$ to $10$ vertices, the sum of degrees was exactly $2(n-1)$.

**Key idea:** $\sum_d i_d \cdot d$ is the degree sum, which is $2|E|$; for a tree, that fixes the number of vertices.

</details>
