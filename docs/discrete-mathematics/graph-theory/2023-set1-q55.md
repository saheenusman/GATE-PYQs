# 2023 CS Q55: Greedy vertex colouring

## Question

Let $G$ be a simple, finite, undirected graph with vertex set $\lbrace v_1, \ldots, v_n \rbrace$. Let $\Delta(G)$ denote the maximum degree of $G$ and let $N = \lbrace 1, 2, \ldots \rbrace$ denote the set of all possible colors. Color the vertices of $G$ using the following greedy strategy:

```
for i = 1, ..., n
  color(v_i) <- min{ j in N :
      no neighbour of v_i is colored j }
```

Which of the following statements is/are TRUE?

- (A) This procedure results in a proper vertex coloring of $G$.
- (B) The number of colors used is at most $\Delta(G) + 1$.
- (C) The number of colors used is at most $\Delta(G)$.
- (D) The number of colors used is equal to the chromatic number of $G$.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**A (true).** Each vertex picks a colour that none of its already coloured neighbours has, so no edge ever gets equal colours.

**B (true).** A vertex has at most $\Delta$ neighbours, which block at most $\Delta$ colours. So some colour in $\lbrace 1, \ldots, \Delta+1 \rbrace$ is free.

**C (false).** For the complete graph $K_n$, $\Delta = n - 1$ but all $n$ vertices need different colours: $\Delta + 1$ colours.

**D (false).** The result depends on the vertex order. On the path $v_1 - v_2 - v_3 - v_4$, taking the vertices in the order $v_1, v_4, v_2, v_3$ gives $v_1 = 1,\ v_4 = 1,\ v_2 = 2,\ v_3 = 3$. That uses 3 colours, but the chromatic number is 2. A small script reproduced this.

**Key idea:** greedy colouring is always proper and never needs more than $\Delta + 1$ colours, but it is not always optimal.

</details>
