# 2016 CS2 Q3: Colours sufficient for any planar graph

## Question

The minimum number of colours that is sufficient to vertex-colour any planar graph is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**4**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

By the **Four Colour Theorem**, every planar graph can be vertex-coloured with $4$ colours. So $4$ colours are sufficient.

Fewer will not do for all planar graphs: $K_4$ is planar and needs $4$ colours. So the minimum number that is sufficient for *every* planar graph is $4$.

**Key idea:** Four Colour Theorem; $K_4$ is planar and needs 4.

</details>
