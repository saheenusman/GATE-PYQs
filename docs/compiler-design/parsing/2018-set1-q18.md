# 2018 CS Q18: The false statement about compiler phases

## Question

Which one of the following statements is FALSE?

- (A) Context-free grammar can be used to specify both lexical and syntax rules.
- (B) Type checking is done before parsing.
- (C) High-level language programs can be translated to different Intermediate Representations.
- (D) Arguments to a function can be passed using the program stack.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Check each option.**

- **A:** true. Lexical rules are regular, and every regular language is context-free, so a CFG can describe both.
- **B:** **false.** Parsing builds the syntax tree first. Type checking is part of semantic analysis and works on that tree, so it comes *after* parsing.
- **C:** true. A compiler can use different IRs, such as three-address code, bytecode, or an AST.
- **D:** true. Many calling conventions push arguments on the program stack.

**Key idea:** phase order is lexical analysis, parsing, semantic analysis (type checking), then intermediate code and optimization.

</details>
