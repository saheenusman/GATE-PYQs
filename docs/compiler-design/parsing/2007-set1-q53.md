# 2007 CS Q53: Regular grammars, LL(1) and LR(1)

## Question

Consider the following two statements:

- P: Every regular grammar is LL(1)
- Q: Every regular set has a LR(1) grammar

Which of the following is **TRUE**?

- (A) Both P and Q are true.
- (B) P is true and Q is false.
- (C) P is false and Q is true.
- (D) Both P and Q are false.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**P is false.** A regular grammar can have two productions for the same non-terminal that start with the same terminal, for example $S \to aS \mid a$. Both start with $a$, so one symbol of look-ahead cannot choose. (A regular grammar can also be ambiguous.) It generates a regular set but the grammar is not LL(1).

**Q is true.** Every regular language is accepted by a DFA, hence by a deterministic PDA that ignores its stack, so it is a deterministic CFL. Every deterministic CFL has an LR(1) grammar.

So P false, Q true: (C).

- (A) and (B) wrongly claim P is true.
- (D) wrongly claims Q is false.
