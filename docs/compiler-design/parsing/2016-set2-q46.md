# 2016 CS2 Q46: Which grammars correctly generate a C-like array declaration

## Question

A student wrote two context-free grammars $G_1$ and $G_2$ for generating a single C-like array declaration. The dimension of the array is at least one. For example,

```
int a[10][3];
```

The grammars use $D$ as the start symbol, and use six terminal symbols `int ; id [ ] num`.

| Grammar $G_1$ | Grammar $G_2$ |
|---|---|
| $D \to \text{int } L;$ | $D \to \text{int } L;$ |
| $L \to \text{id } [E$ | $L \to \text{id } E$ |
| $E \to \text{num}]$ | $E \to E[\text{num}]$ |
| $E \to \text{num}]\ [E$ | $E \to [\text{num}]$ |

Which of the grammars correctly generate the declaration mentioned above?

- (A) Both G1 and G2
- (B) Only G1
- (C) Only G2
- (D) Neither G1 nor G2

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The target language is `int id` followed by one or more `[num]` groups, then `;`.

**$G_1$.** $L \to \text{id}\,[E$, and $E$ is either `num ]` (the last dimension) or `num ] [ E` (one more dimension to come). So $E$ derives $\text{num}]\,[\text{num}]\,[\ldots\text{num}]$ and $L$ derives `id [num] [num] ... [num]` with at least one group. ✓

**$G_2$.** $E \to [\text{num}]$ is one group and $E \to E[\text{num}]$ appends another, so $E$ derives one or more `[num]` groups. $L \to \text{id}\,E$ gives `id [num] [num] ...`. ✓

Both generate exactly the declarations with at least one dimension: **(A)**.

**Derivation of `int a[10][3];` in $G_2$:** $D \Rightarrow \text{int } L; \Rightarrow \text{int id } E; \Rightarrow \text{int id } E[\text{num}]; \Rightarrow \text{int id } [\text{num}][\text{num}];$.

**Key idea:** both grammars generate `id` followed by one or more `[num]` groups.

</details>
