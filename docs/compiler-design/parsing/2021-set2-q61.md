# 2021 CS2 Q61: Number of LR(0) items in GOTO(GOTO(I0, <), <)

## Question

Consider the following augmented grammar with $\lbrace\#,@,<,>,a,b,c\rbrace$ as the set of terminals.

$$S'\to S$$
$$S\to S\#cS$$
$$S\to SS$$
$$S\to S@$$
$$S\to\ <S>$$
$$S\to a$$
$$S\to b$$
$$S\to c$$

Let $I_0=\text{CLOSURE}(\lbrace S'\to\bullet S\rbrace)$. The number of items in the set $\text{GOTO}(\text{GOTO}(I_0,<),<)$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**GOTO($I_0$, <).** Move the dot over `<` in every item of $I_0$ that has `<` after the dot. Only $S\to\bullet{<}S{>}$ qualifies, giving the kernel $S\to{<}\bullet S{>}$. The dot is now before $S$, so add all $S$-productions with the dot at the start:

$$S\to\bullet S\#cS,\ S\to\bullet SS,\ S\to\bullet S@,\ S\to\bullet{<}S{>},\ S\to\bullet a,\ S\to\bullet b,\ S\to\bullet c$$

Total: 1 kernel + 7 closure items = **8** items. Call this $I_1$.

**GOTO($I_1$, <).** In $I_1$ again only $S\to\bullet{<}S{>}$ has `<` after the dot, so the kernel is again $S\to{<}\bullet S{>}$ and the closure is the same 7 items. This is exactly $I_1$, so it again has **8** items.

I computed both sets with a small LR(0) closure/goto script: each has 8 items and the two sets are equal.

**Key idea:** GOTO moves the dot over a symbol and takes the closure; here the second `<` leads back to the same state.

</details>
