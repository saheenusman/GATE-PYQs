# 2017 CS2 Q6: Power of Canonical LR, SLR and LALR parsers

## Question

Which of the following statements about parser is/are CORRECT?

- I. Canonical LR is more powerful than SLR.
- II. SLR is more powerful than LALR.
- III. SLR is more powerful than Canonical LR.

Options:

- (A) I only
- (B) II only
- (C) III only
- (D) II and III only

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The hierarchy of grammars each parser accepts.**

$$\text{SLR}(1) \subset \text{LALR}(1) \subset \text{CLR}(1)=\text{LR}(1)$$

- **I is true.** Canonical LR(1) accepts every SLR grammar and more. CLR uses full lookaheads, while SLR uses the coarse FOLLOW sets, so SLR can show conflicts that CLR avoids.
- **II is false.** LALR is *more* powerful than SLR. LALR uses the same state count as SLR but precise lookaheads.
- **III is false.** SLR is the *least* powerful of the three.

So I only: **(A)**.

**Why the others fail.** (B), (C), (D) each include II or III, which reverse the hierarchy.

**Status note:** theory question (no program applies); the answer matches the official key.

**Key idea:** power order: SLR $<$ LALR $<$ CLR; state count: SLR $=$ LALR $<$ CLR.

</details>
