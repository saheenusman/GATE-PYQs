# 2022 CS Q29: Items in goto(closure(I0), +)

## Question

Consider the augmented grammar with $\lbrace +, *, (, ), id \rbrace$ as the set of terminals.

$$S' \to S$$
$$S \to S + R \mid R$$
$$R \to R * P \mid P$$
$$P \to (S) \mid id$$

If $I_0$ is the set of two LR(0) items $\lbrace [S' \to S\bullet],\ [S \to S\bullet + R] \rbrace$, then $goto(closure(I_0), +)$ contains exactly ______ items.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Closure of $I_0$.** The dot in both items is before $+$ or at the end, so no non-terminal follows the dot and the closure adds nothing: $closure(I_0) = I_0$.

**Goto on $+$.** Only $[S \to S\bullet + R]$ has $+$ after the dot. Moving the dot gives the kernel item

$$[S \to S + \bullet R]$$

**Closure of that kernel.** The dot is before $R$, so add the $R$ productions. The dot is then before $R$ (again) and before $P$, so add the $P$ productions:

1. $S \to S + \bullet R$
2. $R \to \bullet R * P$
3. $R \to \bullet P$
4. $P \to \bullet (S)$
5. $P \to \bullet id$

That is **5** items.

**Code check:** an LR(0) closure/goto script gave 5 items.

**Key idea:** goto moves the dot over the symbol and then takes the closure of the result.

</details>
