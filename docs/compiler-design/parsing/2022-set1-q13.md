# 2022 CS Q13: True statement about parsers and compilers

## Question

Which one of the following statements is TRUE?

- (A) The LALR(1) parser for a grammar $G$ cannot have reduce-reduce conflict if the LR(1) parser for $G$ does not have reduce-reduce conflict.
- (B) Symbol table is accessed only during the lexical analysis phase.
- (C) Data flow analysis is necessary for run-time memory management.
- (D) LR(1) parsing is sufficient for deterministic context-free languages.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(D) True.** Every deterministic context-free language has an LR(1) grammar, so LR(1) parsing is enough for all DCFLs.
- (A) False. Merging LR(1) states with the same core into LALR(1) states can create reduce-reduce conflicts that the canonical LR(1) parser did not have. (It cannot create new shift-reduce conflicts.)
- (B) False. The symbol table is used in later phases too, such as semantic analysis and code generation.
- (C) False. Data flow analysis is a compile-time optimization technique, not something run-time memory management needs.

**Key idea:** LALR merging can add reduce-reduce conflicts; LR(1) captures exactly the deterministic context-free languages.

</details>
