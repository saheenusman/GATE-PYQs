# 2024 CS2 Q40: Filling cells of an LL(1) parsing table

## Question

Consider the following context-free grammar where the start symbol is $S$ and the set of terminals is $\lbrace a,b,c,d \rbrace$.

$$S \to AaAb \mid BbBa, \qquad A \to cS \mid \epsilon, \qquad B \to dS \mid \epsilon$$

The following is a partially-filled LL(1) parsing table.

| | $a$ | $b$ | $c$ | $d$ | $\$$ |
|---|---|---|---|---|---|
| $S$ | $S \to AaAb$ | $S \to BbBa$ | (1) | (2) | |
| $A$ | $A \to \epsilon$ | (3) | $A \to cS$ | | |
| $B$ | (4) | $B \to \epsilon$ | | $B \to dS$ | |

Which one of the following options represents the CORRECT combination for the numbered cells in the parsing table? ("blank" denotes that the corresponding cell is empty.)

- (A) (1) $S \to AaAb$, (2) $S \to BbBa$, (3) $A \to \epsilon$, (4) $B \to \epsilon$
- (B) (1) $S \to BbBa$, (2) $S \to AaAb$, (3) $A \to \epsilon$, (4) $B \to \epsilon$
- (C) (1) $S \to AaAb$, (2) $S \to BbBa$, (3) blank, (4) blank
- (D) (1) $S \to BbBa$, (2) $S \to AaAb$, (3) blank, (4) blank

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**FIRST sets.**

- $FIRST(AaAb)$: $A$ is nullable, so it contains $c$ (from $A \to cS$) and $a$. So $\lbrace a, c \rbrace$.
- $FIRST(BbBa)$: similarly $\lbrace b, d \rbrace$.

**Cells (1) and (2).** $S \to AaAb$ goes in column $c$ (and $a$). $S \to BbBa$ goes in column $d$ (and $b$). So (1) = $S \to AaAb$ and (2) = $S \to BbBa$.

**FOLLOW sets for the $\epsilon$-rules.**

- $FOLLOW(A) = \lbrace a, b \rbrace$ (from $AaAb$: $A$ is followed by $a$, and the second $A$ by $b$).
- $FOLLOW(B) = \lbrace a, b \rbrace$ (similarly).

Put $A \to \epsilon$ in columns $a$ and $b$, so (3) = $A \to \epsilon$. Put $B \to \epsilon$ in columns $a$ and $b$, so (4) = $B \to \epsilon$.

**Why the others fail:** (B) swaps the $S$ rules (a $B$-rule starts with $d$ or $b$, not $c$). (C) and (D) leave cells empty that the $\epsilon$-productions must fill.

**Key idea:** in an LL(1) table, $A \to \alpha$ goes under $FIRST(\alpha)$, and if $\alpha$ is nullable also under $FOLLOW(A)$.

</details>
