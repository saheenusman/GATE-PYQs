# 2019 CS2 Q53: Number of items in GOTO(I0, open parenthesis)

## Question

Consider the augmented grammar given below:

```
S' -> S
S  -> <L> | id
L  -> L,S | S
```

Let $I_0 = \mathrm{CLOSURE}(\lbrace [S' \to \bullet S] \rbrace)$. The number of items in the set $\mathrm{GOTO}(I_0, \langle)$ is: ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**5**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

(The paper uses angle brackets as the parentheses. I write `<` for the opening bracket below.)

**$I_0$.** Closure of $S' \to \bullet S$ adds the $S$ rules:

$$S' \to \bullet S,\quad S \to \bullet\langle L\rangle,\quad S \to \bullet\mathrm{id}.$$

**GOTO($I_0$, `<`).** Only $S \to \bullet\langle L\rangle$ has `<` after the dot. Move the dot: $S \to \langle \bullet L\rangle$. Then close it. The dot is before $L$, so add the $L$ rules. The dot in $L \to \bullet S$ is before $S$, so add the $S$ rules.

| # | Item | Why |
|---|---|---|
| 1 | $S \to \langle \bullet L\rangle$ | the kernel |
| 2 | $L \to \bullet L,S$ | dot before $L$ |
| 3 | $L \to \bullet S$ | dot before $L$ |
| 4 | $S \to \bullet\langle L\rangle$ | dot before $S$ (from item 3) |
| 5 | $S \to \bullet\mathrm{id}$ | dot before $S$ (from item 3) |

**5 items.**

**Code check:** an LR(0) closure and GOTO program prints exactly these five items.

**Key idea:** GOTO moves the dot over the symbol, then closes: every non-terminal right after a dot pulls in its productions.

</details>
