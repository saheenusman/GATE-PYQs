# 2016 CS2 Q45: Grammar free from left recursion

## Question

Which one of the following grammars is free from left recursion?

- (A) `S -> AB`, `A -> Aa | b`, `B -> c`
- (B) `S -> Ab | Bb | c`, `A -> Bd | ε`, `B -> e`
- (C) `S -> Aa | B`, `A -> Bb | Sc | ε`, `B -> d`
- (D) `S -> Aa | Bb | c`, `A -> Bd | ε`, `B -> Ae | ε`

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A grammar is left recursive if some nonterminal can derive a string starting with itself, directly or through others.

- (A) $A \to Aa$ is **directly** left recursive.
- (B) $S$ starts with $A$, $B$ or $c$; $A$ starts with $B$ (or is empty); $B$ starts with the terminal $e$. The relation "starts with" has no cycle, so there is **no left recursion**.
- (C) $S \Rightarrow Aa \Rightarrow Sca$ (using $A \to Sc$): **indirect** left recursion.
- (D) $A \Rightarrow Bd \Rightarrow Aed$ (using $B \to Ae$): **indirect** left recursion.

Only (B) is free from left recursion.

**Key idea:** (B) has no cycle among 'can start with' relations; the others have direct or indirect cycles.

</details>
