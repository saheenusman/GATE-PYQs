# 2021 CS1 Q41: Filling cells of an LL(1) table

## Question

Consider the following context-free grammar where the set of terminals is $\lbrace a,b,c,d,f\rbrace$.

```
S -> d a T | R f
T -> a S | b a T | eps
R -> c a T R | eps
```

The following is a partially-filled LL(1) parsing table.

| | $a$ | $b$ | $c$ | $d$ | $f$ | $\$$ |
|---|---|---|---|---|---|---|
| S | | | (1) | S -> d a T | (2) | |
| T | T -> a S | T -> b a T | (3) | | T -> eps | (4) |
| R | | | R -> c a T R | | R -> eps | |

Which one of the following choices represents the correct combination for the numbered cells in the parsing table ("blank" denotes that the corresponding cell is empty)?

- (A) (1) S -> Rf, (2) S -> Rf, (3) T -> eps, (4) T -> eps
- (B) (1) blank, (2) S -> Rf, (3) T -> eps, (4) T -> eps
- (C) (1) S -> Rf, (2) blank, (3) blank, (4) T -> eps
- (D) (1) blank, (2) S -> Rf, (3) blank, (4) blank

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**FIRST sets.** $R$ can be empty, so $\text{FIRST}(Rf)=\lbrace c,f\rbrace$ ($R$ gives $c$, and if $R$ is empty we reach $f$).

- Cell (1), $S$ on $c$: $c\in\text{FIRST}(Rf)$, so $S\to Rf$.
- Cell (2), $S$ on $f$: $f\in\text{FIRST}(Rf)$ through the empty $R$, so $S\to Rf$.

**FOLLOW(T).** $T$ appears at the end of $S\to daT$ and $T\to aS$ (so it inherits FOLLOW(S), and $\$\in$ FOLLOW(S)). It also appears in $R\to caTR$ before $R$, so FOLLOW(T) contains FIRST(R) $=\lbrace c\rbrace$ and, as $R$ can be empty, FOLLOW(R) $=\lbrace f\rbrace$. And FOLLOW(S) gets FOLLOW(T) through $T\to aS$. So $\text{FOLLOW}(T)=\lbrace c,f,\$\rbrace$.

- Cell (3), $T$ on $c$: $T\to\varepsilon$, since $c\in$ FOLLOW(T).
- Cell (4), $T$ on $\$$: $T\to\varepsilon$, since $\$\in$ FOLLOW(T).

So (A). The other choices leave one of these cells blank, though each of them has an entry.

A script computed FIRST, FOLLOW and the whole table and found exactly these four entries, with no conflicts, so the grammar is LL(1).

**Key idea:** put $A\to\alpha$ under FIRST($\alpha$), and under FOLLOW($A$) too when $\alpha$ can be empty.

</details>
