# 2014 CS1 Q34: Canonical item set: conflict on a terminal symbol

## Question

A canonical set of items is given below

$$S \to L . > R$$

$$Q \to R .$$

On input symbol $<$ the set has

- (A) a shift-reduce conflict and a reduce-reduce conflict.
- (B) a shift-reduce conflict but not a reduce-reduce conflict.
- (C) a reduce-reduce conflict but not a shift-reduce conflict.
- (D) neither a shift-reduce nor a reduce-reduce conflict.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The set has two items:

- $S \to L \,.\, > R$ is a **shift** item. It can shift only the symbol $>$.
- $Q \to R \,.$ is a **reduce** item.

A **shift-reduce conflict** on a symbol $a$ needs a shift item with $a$ right after the dot *and* a reduce possible on $a$. The only shift symbol here is $>$, not $<$, so on $<$ there is nothing to shift.

A **reduce-reduce conflict** needs two reduce items. There is only one.

So on $<$ there is no conflict of either kind: **D**.

- (A), (B) need a shift on $<$, which does not exist.
- (C) needs a second reduce item.

(A conflict would exist on input $>$, if $>$ were in the lookahead set of $Q \to R .$.)

**Key idea:** a conflict on symbol $a$ needs both actions to be possible on $a$.

</details>
