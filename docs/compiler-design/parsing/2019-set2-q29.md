# 2019 CS2 Q29: FOLLOW set of a non-terminal with nullable symbols

## Question

Consider the grammar given below:

```
S -> Aa
A -> BD
B -> b | ε
D -> d | ε
```

Let a, b, d, and \$ be indexed as follows:

| a | b | d | \$ |
|---|---|---|---|
| 3 | 2 | 1 | 0 |

Compute the FOLLOW set of the non-terminal B and write the index values for the symbols in the FOLLOW set in the descending order. (For example, if the FOLLOW set is {a, b, d, \$}, then the answer should be 3210.)

Answer: ________.

<details class="success" markdown="1">
<summary>Answer</summary>

**31**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Where B appears:** only in $A \to BD$.

1. $D$ follows $B$, and $\mathrm{FIRST}(D) = \lbrace d, \varepsilon \rbrace$. So $d \in \mathrm{FOLLOW}(B)$.
2. $D$ can be $\varepsilon$, so whatever follows $A$ also follows $B$: $\mathrm{FOLLOW}(A) \subseteq \mathrm{FOLLOW}(B)$.
3. From $S \to Aa$: $\mathrm{FOLLOW}(A) = \lbrace a \rbrace$.

$$\mathrm{FOLLOW}(B) = \lbrace a, d \rbrace.$$

**Left out:** $b$ never follows $B$. And \$ is not there: $S \to Aa$ always puts $a$ after $A$, so nothing can end the string right after $B$.

**Indices in descending order:** $a = 3$, $d = 1$, giving **31**.

**Code check:** a FIRST/FOLLOW fixed-point program on this grammar returns $\lbrace a, d \rbrace$ and the string `31`.

**Key idea:** a nullable symbol after $B$ passes the FOLLOW of the left-hand side through to $B$.

</details>
