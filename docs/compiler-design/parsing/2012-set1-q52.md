# 2012 CS Q52: FIRST and FOLLOW sets of A and B in a grammar

## Question

**Statement for Linked Answer Questions 52 and 53.** For the grammar below, a partial LL(1) parsing table is also presented along with the grammar. Entries that need to be filled are indicated as E1, E2, and E3. $\varepsilon$ is the empty string, $\$$ indicates end of input, and $\mid$ separates alternate right hand sides of productions.

$$S \to aAbB \mid bAaB \mid \varepsilon \qquad A \to S \qquad B \to S$$

| | a | b | \$ |
|---|---|---|---|
| **S** | E1 | E2 | S → ε |
| **A** | A → S | A → S | error |
| **B** | B → S | B → S | E3 |

The FIRST and FOLLOW sets for the non-terminals A and B are

- (A) FIRST(A) $= \lbrace a, b, \varepsilon \rbrace =$ FIRST(B); FOLLOW(A) $= \lbrace a, b \rbrace$; FOLLOW(B) $= \lbrace a, b, \$ \rbrace$
- (B) FIRST(A) $= \lbrace a, b, \$ \rbrace$; FIRST(B) $= \lbrace a, b, \varepsilon \rbrace$; FOLLOW(A) $= \lbrace a, b \rbrace$; FOLLOW(B) $= \lbrace \$ \rbrace$
- (C) FIRST(A) $= \lbrace a, b, \varepsilon \rbrace =$ FIRST(B); FOLLOW(A) $= \lbrace a, b \rbrace$; FOLLOW(B) $= \emptyset$
- (D) FIRST(A) $= \lbrace a, b \rbrace =$ FIRST(B); FOLLOW(A) $= \lbrace a, b \rbrace$; FOLLOW(B) $= \lbrace a, b \rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**FIRST.** $S \to \varepsilon$, $S \to aAbB$, $S \to bAaB$ give $\text{FIRST}(S) = \lbrace a, b, \varepsilon \rbrace$. Since $A \to S$ and $B \to S$:

$$\text{FIRST}(A) = \text{FIRST}(B) = \lbrace a, b, \varepsilon \rbrace.$$

**FOLLOW.**

- $A$ appears in $aAbB$ (followed by $b$) and in $bAaB$ (followed by $a$): $\text{FOLLOW}(A) = \lbrace a, b \rbrace$.
- $B$ appears at the end of $aAbB$ and $bAaB$, so $\text{FOLLOW}(B) \supseteq \text{FOLLOW}(S)$.
- $\text{FOLLOW}(S)$ contains $\$$ (start symbol), plus $\text{FOLLOW}(A)$ (from $A \to S$) and $\text{FOLLOW}(B)$ (from $B \to S$). So $\text{FOLLOW}(S) = \lbrace a, b, \$ \rbrace$, and $\text{FOLLOW}(B) = \lbrace a, b, \$ \rbrace$.

This is (A).

- (B) puts $\$$ in a FIRST set, which can never happen, and gives $\text{FOLLOW}(B)$ only $\$$.
- (C) says $\text{FOLLOW}(B)$ is empty; but $B$ ends productions of $S$, which is followed by $\$$.
- (D) leaves $\varepsilon$ out of FIRST and $\$$ out of $\text{FOLLOW}(B)$.

**Code check:** a fixed-point computation of FIRST and FOLLOW gave $\text{FIRST}(S) = \text{FIRST}(A) = \text{FIRST}(B) = \lbrace a, b, \varepsilon \rbrace$, $\text{FOLLOW}(S) = \text{FOLLOW}(B) = \lbrace a, b, \$ \rbrace$ and $\text{FOLLOW}(A) = \lbrace a, b \rbrace$.

**Key idea:** if a non-terminal ends a production, it inherits the FOLLOW set of the left-hand side.

</details>
