# 2021 CS1 Q15: SLR(1) grammars and CFG parsing time

## Question

Consider the following statements.

$S_1$: Every SLR(1) grammar is unambiguous but there are certain unambiguous grammars that are not SLR(1).

$S_2$: For any context-free grammar, there is a parser that takes at most $O(n^3)$ time to parse a string of length $n$.

Which one of the following options is correct?

- (A) $S_1$ is true and $S_2$ is false
- (B) $S_1$ is false and $S_2$ is true
- (C) $S_1$ is true and $S_2$ is true
- (D) $S_1$ is false and $S_2$ is false

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**$S_1$ is true.** An SLR(1) parsing table has no conflicts, so each string has one parse tree and the grammar is unambiguous. The converse fails: some unambiguous grammars (for example, ones that are LR(1) but not SLR(1)) give conflicts in an SLR(1) table.

**$S_2$ is true.** Any CFG can be converted to Chomsky normal form, and CYK parses a string of length $n$ in $O(n^3)$ time (Earley also gives $O(n^3)$).

Both true, so (C).

**Key idea:** SLR(1) is a strict subset of unambiguous grammars, and general CFG parsing is cubic (CYK).

</details>
