# 2026 CS1 Q28: True statements about LL(1) parsers

## Question

Which of the following statements is/are true?

- (A) LL(1) parser uses backtracking
- (B) For a grammar to be LL(1), it must be left-recursive
- (C) For a grammar to be LL(1), it must be left-factored
- (D) The LL(1) parsers are more powerful than the SLR parsers

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** An LL(1) parser reads Left to right, builds a Leftmost derivation, and looks ahead **1** token to choose a production. It uses a parsing table, so the choice must be unique.

- **(A) False.** LL(1) is predictive: the table decides, and there is no backtracking.
- **(B) False.** A left-recursive grammar (for example $E \to E + T$) makes the predictive parser loop forever. LL(1) grammars **cannot** be left-recursive.
- **(C) True.** If two productions of a non-terminal share a common prefix (for example $A \to ab \mid ac$), the one-token lookahead cannot choose between them. So the grammar must be left-factored.
- **(D) False.** SLR (a bottom-up LR parser) handles all LL(1) languages and more, including left-recursive grammars. So the LR family is the more powerful one.

**Key idea:** LL(1) needs no left recursion, no common prefixes (left-factored), and no ambiguity.

</details>
