# 2019 CS2 Q13: Derivation used by LR parsers

## Question

Which one of the following kinds of derivation is used by LR parsers?

- (A) Leftmost
- (B) Leftmost in reverse
- (C) Rightmost
- (D) Rightmost in reverse

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An LR parser reads the input **L**eft to right and builds a **R**ightmost derivation, but **in reverse**. It works bottom-up: it shifts tokens, then reduces a handle to a non-terminal. The sequence of reductions, read backwards, is a rightmost derivation.

**Why the others fail:**

- (A) *Leftmost* is what top-down LL parsers follow.
- (B) *Leftmost in reverse* is not used by a standard parser.
- (C) *Rightmost* is the right derivation, but the parser produces it in the reverse order, not forward.

**Key idea:** LR = left-to-right scan, rightmost derivation traced backwards by reductions.

</details>
