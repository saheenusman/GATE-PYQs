# 2024 CS1 Q26: Bottom-up parsers

## Question

Which of the following is/are Bottom-Up Parser(s)?

- (A) Shift-reduce Parser
- (B) Predictive Parser
- (C) LL(1) Parser
- (D) LR Parser

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **Shift-reduce** and **LR** parsers build the parse tree from the leaves up by shifting tokens onto a stack and reducing handles. Both are bottom-up. (LR parsers are one kind of shift-reduce parser.)
- **Predictive** parsers (including **LL(1)**) start from the start symbol and expand non-terminals using the lookahead. They are top-down.

**Key idea:** LL = top-down (leftmost derivation). LR = bottom-up (reverse rightmost derivation).

</details>
