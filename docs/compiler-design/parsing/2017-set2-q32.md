# 2017 CS2 Q32: A non-left-recursive grammar equivalent to the given expression grammar

## Question

Consider the following expression grammar G:

```text
E -> E - T | T
T -> T + F | F
F -> (E) | id
```

Which of the following grammars is not left recursive, but is equivalent to G?

(A)
```text
E -> E - T | T
T -> T + F | F
F -> (E) | id
```

(B)
```text
E  -> TE'
E' -> -TE' | ε
T  -> T + F | F
F  -> (E) | id
```

(C)
```text
E -> TX
X -> -TX | ε
T -> FY
Y -> +FY | ε
F -> (E) | id
```

(D)
```text
E -> TX | (TX)
X -> -TX | +TX | ε
T -> id
```

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Two conditions:** no left recursion, and the same language as $G$.

**(A)** is $G$ itself. $E \to E - T$ and $T \to T + F$ are left recursive. Rejected.

**(B)** removes the left recursion for $E$ only. $T \to T + F$ is still left recursive. Rejected.

**(C)** is the standard elimination applied to both:

- $E \to E - T \mid T$ becomes $E \to TX$, $X \to -TX \mid \epsilon$.
- $T \to T + F \mid F$ becomes $T \to FY$, $Y \to +FY \mid \epsilon$.

No rule starts with its own head, and the language is unchanged. **(C)**.

**(D)** is not left recursive, but it is **not equivalent**: its $T$ only derives `id`, so parenthesised sub-expressions can appear only as a whole expression, never inside, e.g., $\text{id} + (\text{id})$ or $((\text{id}))$. It also allows $+$ at the $E$-level (with a different grouping).

**Code check:** an Earley parser enumerated all token strings up to length 7 over $\lbrace \text{id}, +, -, (, )\rbrace$ (60 strings in $L(G)$). (B) and (C) generate exactly those, but (D) misses 38 of them, for example `( ( id ) )`. A scan for direct left recursion found it in (A) (rules $E$, $T$) and (B) (rule $T$), and in neither (C) nor (D).

**Key idea:** $A \to A\alpha \mid \beta$ becomes $A \to \beta A',\ A' \to \alpha A' \mid \epsilon$, and it must be done for every left-recursive nonterminal.

</details>
