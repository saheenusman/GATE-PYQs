# 2017 CS1 Q17: FOLLOW set of the nonterminal Q in a small grammar

## Question

Consider the following grammar:

$$P \to xQRS$$
$$Q \to yz \mid z$$
$$R \to w \mid \varepsilon$$
$$S \to y$$

What is FOLLOW($Q$)?

- (A) $\lbrace R\rbrace$
- (B) $\lbrace w\rbrace$
- (C) $\lbrace w, y\rbrace$
- (D) $\lbrace w, \$\rbrace$

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Where $Q$ appears.** Only in $P \to xQRS$, followed by $RS$. So FOLLOW($Q$) $\supseteq$ FIRST($RS$).

- FIRST($R$) $= \lbrace w, \varepsilon\rbrace$, so add $w$.
- $R$ can derive $\varepsilon$, so look past it: FIRST($S$) $= \lbrace y\rbrace$, so add $y$.
- $S$ cannot derive $\varepsilon$, so we stop there. FOLLOW($P$) is not added, so $\$$ is not included.

$$\text{FOLLOW}(Q) = \lbrace w, y\rbrace$$

This is **(C)**.

**Why the others fail.**

- (A) $R$ is a nonterminal; FOLLOW sets contain only terminals (and $\$$).
- (B) forgets that $R$ may vanish, which lets $y$ (from $S$) follow $Q$.
- (D) $\$$ follows only symbols that can end a sentence. $S$ always follows, so $Q$ is never last.

**Code check:** computing FIRST and FOLLOW by fixed-point iteration gave FOLLOW($Q$) $=\lbrace w,y\rbrace$ (and FOLLOW($R$) $=\lbrace y\rbrace$).

**Key idea:** FOLLOW($X$) takes FIRST of what comes after $X$, and continues past any nullable symbols.

</details>
