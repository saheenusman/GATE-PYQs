# 2020 CS Q34: Reduction steps of a bottom-up parser for aaadbbb

## Question

Consider the following grammar.

$S \to aSB \mid d$

$B \to b$

The number of reduction steps taken by a bottom-up parser while accepting the string $aaadbbb$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**7**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A bottom-up parser traces a rightmost derivation backwards. The rightmost derivation of $aaadbbb$ is

$$S \Rightarrow aSB \Rightarrow aSb \Rightarrow aaSBb \Rightarrow aaSbb \Rightarrow aaaSBbb \Rightarrow aaaSbbb \Rightarrow aaadbbb.$$

It has 7 steps, so the parser makes 7 reductions.

**Shift-reduce trace:**

| Stack | Action | Reductions so far |
|---|---|---|
| `aaad` | shifted `a a a d` | 0 |
| `aaaS` | reduce $d \to S$ | 1 |
| `aaaSb` | shift `b` | 1 |
| `aaaSB` | reduce $b \to B$ | 2 |
| `aaS` | reduce $aSB \to S$ | 3 |
| `aaSb` | shift `b` | 3 |
| `aaSB` | reduce $b \to B$ | 4 |
| `aS` | reduce $aSB \to S$ | 5 |
| `aSb` | shift `b` | 5 |
| `aSB` | reduce $b \to B$ | 6 |
| `S` | reduce $aSB \to S$ | 7 |

The stack ends as the start symbol $S$ with the input used up, so the string is accepted.

**Count by rule:** one use of $S \to d$, three uses of $B \to b$ (one per `b`), and three uses of $S \to aSB$ (one per `a`): $1 + 3 + 3 = 7$. I also simulated a shift-reduce parser in code and got 7 reductions.

**Key idea:** the number of reductions equals the number of steps in the rightmost derivation, which is the number of rule applications in the parse tree.

</details>
