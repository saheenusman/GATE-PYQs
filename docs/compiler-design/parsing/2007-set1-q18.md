# 2007 CS Q18: Which parser is top-down

## Question

Which one of the following is a top-down parser?

- (A) Recursive descent parser.
- (B) Operator precedence parser.
- (C) An LR($k$) parser.
- (D) An LALR($k$) parser.

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A top-down parser builds the parse tree from the start symbol downward, expanding non-terminals. Recursive descent does exactly this, with one procedure per non-terminal: (A).

- (B) Operator precedence, (C) LR($k$) and (D) LALR($k$) are all **bottom-up** (shift-reduce) parsers.
