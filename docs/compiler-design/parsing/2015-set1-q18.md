# 2015 CS1 Q18: What a shift-reduce parser stack contains

## Question

Which one of the following is TRUE at any valid state in shift-reduce parsing?

- (A) Viable prefixes appear only at the bottom of the stack and not inside
- (B) Viable prefixes appear only at the top of the stack and not inside
- (C) The stack contains only a set of viable prefixes
- (D) The stack never contains viable prefixes

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In a shift-reduce parser the stack content (grammar symbols) is always a **viable prefix** of some right-sentential form: a prefix that does not extend beyond the right end of the handle.

- (C) The stack contains only a set of viable prefixes. Correct.
- (A), (B) The whole stack is the viable prefix, so it is not confined to the bottom or the top.
- (D) The opposite of the true statement.

**Key idea:** the stack of a correct shift-reduce parse is always a viable prefix.

</details>
