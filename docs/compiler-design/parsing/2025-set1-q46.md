# 2025 CS1 Q46: True statements about First and Follow

## Question

Which of the following statement(s) is/are TRUE while computing First and Follow during top down parsing by a compiler?

- (A) For a production $A \to \epsilon$, $\epsilon$ will be added to $First(A)$.
- (B) If there is any input right end marker, it will be added to $First(S)$, where $S$ is the start symbol.
- (C) For a production $A \to \epsilon$, $\epsilon$ will be added to $Follow(A)$.
- (D) If there is any input right end marker, it will be added to $Follow(S)$, where $S$ is the start symbol.

<details class="success" markdown="1">
<summary>Answer</summary>

**A and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Option | Verdict | Reason |
|---|---|---|
| **A** | True | If $A \to \epsilon$ is a production then $A$ can derive the empty string, so $\epsilon \in First(A)$ |
| B | False | The end marker \$ can appear after the whole input, so it goes into $Follow(S)$, never into a First set (First sets hold the first symbols of derived strings) |
| C | False | $Follow$ sets contain terminals and \$, but never $\epsilon$ |
| **D** | True | Rule: put the end marker \$ into $Follow(S)$ for the start symbol $S$ |

**Key idea:** $\epsilon$ belongs only in First sets, and \$ belongs only in Follow sets.

</details>
