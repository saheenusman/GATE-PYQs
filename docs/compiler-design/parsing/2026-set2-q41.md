# 2026 CS2 Q41: Shift-reduce conflicts in an LR(0) table

## Question

Consider canonical $LR(0)$ parsing of the grammar below, with terminals $\lbrace a, b, c \rbrace$, non-terminals $\lbrace A, B, C, S \rbrace$ and start symbol $S$.

$$S \to ACB \qquad A \to aA \mid \epsilon \qquad C \to cC \mid \epsilon \qquad B \to bB \mid b$$

How many shift-reduce conflicts occur in the $LR(0)$ ACTION table?

- (A) 2
- (B) 3
- (C) 4
- (D) 5

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** In an LR(0) table, a state that contains a *complete item* ($X \to \alpha\,\cdot$) reduces on **every** terminal. If that state also has an item that can **shift** a terminal $t$, the cell for $t$ holds both a shift and a reduce: a shift-reduce conflict.

Build the LR(0) states (augmenting with $S' \to S$). The states with both a reduce item and a shift item:

| State (after reading) | Reduce item | Shift on | Conflict cell |
|---|---|---|---|
| start | $A \to \cdot$ | $a$ (from $A \to \cdot aA$) | on $a$ |
| after $A$ | $C \to \cdot$ | $c$ (from $C \to \cdot cC$) | on $c$ |
| after $a$ (inside $A \to a \cdot A$) | $A \to \cdot$ | $a$ | on $a$ |
| after $C$'s $c$ (inside $C \to c \cdot C$) | $C \to \cdot$ | $c$ | on $c$ |
| after $b$ (items $B \to b \cdot B$ and $B \to b \cdot$) | $B \to b \cdot$ | $b$ | on $b$ |

That is **5** conflict cells: 2 on $a$, 2 on $c$, and 1 on $b$.

(Each state has exactly one terminal that can be shifted, so each state contributes one conflict. The grammar's empty productions and the $B \to bB \mid b$ overlap cause every one of them.)

**Verified.** I built the full LR(0) automaton (11 states) in Python and counted the cells holding both a shift and a reduce: 5.

**Key idea:** in LR(0) there is no lookahead, so a state with a reduce item and a shiftable terminal always conflicts. Empty productions and common prefixes create these states.

</details>
