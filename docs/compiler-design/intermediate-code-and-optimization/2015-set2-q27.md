# 2015 CS2 Q27: Matching compiler topics with the techniques they use

## Question

Match the following:

| | Topic | | Technique |
|---|---|---|---|
| P | Lexical analysis | 1 | Graph coloring |
| Q | Parsing | 2 | DFA minimization |
| R | Register allocation | 3 | Post-order traversal |
| S | Expression evaluation | 4 | Production tree |

- (A) P-2, Q-3, R-1, S-4
- (B) P-2, Q-1, R-4, S-3
- (C) P-2, Q-4, R-1, S-3
- (D) P-2, Q-3, R-4, S-1

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **P, lexical analysis:** the scanner is a DFA, and minimising it is a standard step. So P-2.
- **Q, parsing:** a parse builds a derivation, shown as a production (parse) tree. So Q-4.
- **R, register allocation:** variables that are live together cannot share a register, which is a graph-colouring problem. So R-1.
- **S, expression evaluation:** a post-order traversal of the expression tree evaluates operands before the operator. So S-3.

P-2, Q-4, R-1, S-3: option (C). Each other option moves at least two items.

**Key idea:** scanner $\to$ DFA, parser $\to$ parse tree, register allocation $\to$ graph colouring, evaluation $\to$ post-order.

</details>
