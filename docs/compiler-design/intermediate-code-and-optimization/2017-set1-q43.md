# 2017 CS1 Q43: Number of control flow paths in a program with ten if statements

## Question

Consider the following grammar:

```
stmt   -> if expr then expr else expr; stmt | ò
expr   -> term relop term | term
term   -> id | number
id     -> a | b | c
number -> [0-9]
```

where `relop` is a relational operator (e.g., `<`, `>`, ...), `ò` refers to the empty statement, and `if`, `then`, `else` are terminals.

Consider a program $P$ following the above grammar containing ten `if` terminals. The number of control flow paths in $P$ is ______. For example, the program

```
if e1 then e2 else e3
```

has 2 control flow paths, $e_1 \to e_2$ and $e_1 \to e_3$.

<details class="success" markdown="1">
<summary>Answer</summary>

**1024**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Shape of the programs.** In `stmt -> if expr then expr else expr; stmt | ò`, the `then` and `else` parts are `expr`, not `stmt`. So there is **no nesting**: a program is a straight sequence of `if-then-else` statements, ended by the empty statement. An `expr` has no `&&`/`||`, so it is a single block with no branching.

**Paths.** Each `if` has exactly two routes ($e_1\to e_2$ or $e_1 \to e_3$), and after either route control continues to the next statement. Choices in different statements are independent, so the counts multiply:

$$2 \times 2 \times \cdots \times 2 \;(10\text{ times}) = 2^{10} = 1024$$

The answer is **1024**.

**Code check:** counting paths from start to end of the control flow graph for $n$ sequential `if` statements gave $2,4,8,\ldots,512,1024$ for $n=1\ldots10$.

**Key idea:** sequential two-way branches multiply the number of paths ($2^n$); only nesting would change the pattern.

</details>
