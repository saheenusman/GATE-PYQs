# 2021 CS2 Q23: Which of these is not an intermediate representation

## Question

In the context of compilers, which of the following is/are NOT an intermediate representation of the source program?

- (A) Three address code
- (B) Abstract Syntax Tree (AST)
- (C) Control Flow Graph (CFG)
- (D) Symbol table

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An intermediate representation (IR) is a form of the program that the compiler produces and transforms between source and target.

- (A) Three-address code is a standard linear IR.
- (B) An AST is a tree IR, produced by the parser.
- (C) A control flow graph is a graph IR built from basic blocks, used for optimization.
- (D) A symbol table is a **data structure holding information about names** (types, scopes, addresses). It is not a representation of the program's code. **Not an IR.**

Answer: **D**.

**Key idea:** IRs represent the program's code (tree, linear code, graph). The symbol table stores information about identifiers.

</details>
