# 2024 CS1 Q39: Basic blocks in three-address code

## Question

Consider the following pseudo-code.

```
L1:  t1 = -1
L2:  t2 = 0
L3:  t3 = 0
L4:  t4 = 4 * t3
L5:  t5 = 4 * t2
L6:  t6 = t5 * M
L7:  t7 = t4 + t6
L8:  t8 = a[t7]
L9:  if t8 <= max goto L11
L10: t1 = t8
L11: t3 = t3 + 1
L12: if t3 < M goto L4
L13: t2 = t2 + 1
L14: if t2 < N goto L3
L15: max = t1
```

Which one of the following options CORRECTLY specifies the number of basic blocks and the number of instructions in the largest basic block, respectively?

- (A) 6 and 6
- (B) 6 and 7
- (C) 7 and 7
- (D) 7 and 6

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find the leaders** (first instruction of each basic block):

1. The first instruction: **L1**.
2. Every jump **target**: L11 (from L9), L4 (from L12), L3 (from L14).
3. Every instruction **right after** a jump: L10 (after L9), L13 (after L12), L15 (after L14).

Leaders: L1, L3, L4, L10, L11, L13, L15. Each block runs from a leader to just before the next.

| Block | Instructions | Count |
|---|---|---|
| B1 | L1 to L2 | 2 |
| B2 | L3 | 1 |
| B3 | L4 to L9 | **6** |
| B4 | L10 | 1 |
| B5 | L11 to L12 | 2 |
| B6 | L13 to L14 | 2 |
| B7 | L15 | 1 |

**7 basic blocks**, the largest with **6 instructions** (L4 to L9).

**Key idea:** leaders = first instruction, jump targets, and instructions following jumps.

</details>
