# 2015 CS2 Q44: Nodes and edges in the control flow graph of intermediate code

## Question

Consider the intermediate code given below.

```
(1)  i = 1
(2)  j = 1
(3)  t1 = 5 * i
(4)  t2 = t1 + j
(5)  t3 = 4 * t2
(6)  t4 = t3
(7)  a[t4] = -1
(8)  j = j + 1
(9)  if j<=5 goto (3)
(10) i=i+1
(11) if i<5 goto (2)
```

The number of nodes and edges in the control-flow-graph constructed for the above code, respectively, are

- (A) 5 and 7
- (B) 6 and 7
- (C) 5 and 5
- (D) 7 and 8

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Find the leaders** (first statements of basic blocks):

- statement (1): the first statement,
- statements (2) and (3): targets of the jumps in (11) and (9),
- statement (10): it follows the conditional jump in (9).

**Basic blocks:**

| Block | Statements |
|---|---|
| B1 | (1) |
| B2 | (2) |
| B3 | (3) to (9) |
| B4 | (10) to (11) |

**Edges:** B1 $\to$ B2, B2 $\to$ B3, B3 $\to$ B3 (jump to (3)), B3 $\to$ B4 (fall through), B4 $\to$ B2 (jump to (2)).

With explicit **Entry** and **Exit** nodes added, there are $4 + 2 = 6$ nodes and the edges Entry $\to$ B1 and B4 $\to$ Exit give $5 + 2 = 7$ edges.

6 nodes and 7 edges: option (B).

**Assumption.** The key only works if Entry and Exit nodes are counted. Counting the four basic blocks alone gives 4 nodes and 5 edges, which is not among the options.

**Key idea:** find leaders, form basic blocks, then add edges for jumps and fall-through (and Entry/Exit nodes).

</details>
