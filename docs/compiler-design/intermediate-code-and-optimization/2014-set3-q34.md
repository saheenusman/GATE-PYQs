# 2014 CS3 Q34: Nodes and edges in the DAG of a basic block

## Question

Consider the basic block given below.

```
a = b + c
c = a + d
d = b + c
e = d - b
a = e + b
```

The minimum number of nodes and edges present in the DAG representation of the above basic block respectively are

- (A) 6 and 6
- (B) 8 and 10
- (C) 9 and 12
- (D) 4 and 4

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Build the DAG, reusing a node when the same value is computed again. The initial values $b, c, d$ are leaves.

| Statement | Node | Meaning |
|---|---|---|
| `a = b + c` | $n_1$ | $b + c_0$ |
| `c = a + d` | $n_2$ | $n_1 + d_0$ |
| `d = b + c` | $n_3$ | $b + n_2$ (this `c` is the *new* one, so it does not reuse $n_1$) |
| `e = d - b` | | $(b + n_2) - b = n_2$ |
| `a = e + b` | | $n_2 + b = b + n_2 = n_3$ |

For the last two statements the minimum DAG uses the identity $(b + x) - b = x$ and the commutativity of $+$. They add **no new node**: `e` is the node $n_2$, and `a` is the node $n_3$.

**Nodes:** 3 leaves ($b, c, d$) $+$ 3 operator nodes ($n_1, n_2, n_3$) $= 6$. **Edges:** 2 per operator node $= 6$. So **A**.

**Code check:** a DAG builder with plain value numbering (no algebra) gives 8 nodes and 10 edges, which is option (B). With the simplification $(x+y)-y = x$ it gives 6 and 6.

**Note:** the key's 6 and 6 relies on that algebraic simplification, which goes beyond the standard DAG construction (value numbering). I read "minimum" as allowing it, which matches the key. Under the standard construction alone, the answer would be (B).

**Key idea:** reusing nodes for repeated values shrinks the DAG; algebraic identities can shrink it more.

</details>
