# 2021 CS2 Q48: Liveness: OUT of one statement and IN of the next

## Question

For a statement $S$ in a program, in the context of liveness analysis, the following sets are defined:

$USE(S)$ : the set of variables used in $S$

$IN(S)$ : the set of variables that are live at the entry of $S$

$OUT(S)$ : the set of variables that are live at the exit of $S$

Consider a basic block that consists of two statements, $S_1$ followed by $S_2$. Which one of the following statements is correct?

- (A) $OUT(S_1)=IN(S_2)$
- (B) $OUT(S_1)=IN(S_1)\cup USE(S_1)$
- (C) $OUT(S_1)=IN(S_2)\cup OUT(S_2)$
- (D) $OUT(S_1)=USE(S_1)\cup IN(S_2)$

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Liveness is a backward data-flow analysis. A variable is live at the exit of a statement if it is live at the entry of **some successor**.

In a basic block, $S_1$ has exactly one successor, $S_2$. So

$$OUT(S_1)=IN(S_2).$$

- (B) $IN(S_1)=USE(S_1)\cup(OUT(S_1)-DEF(S_1))$, so $IN(S_1)\cup USE(S_1)=IN(S_1)$. That is the entry of $S_1$, not its exit.
- (C) $OUT(S_2)$ can contain a variable that $S_2$ redefines. Take $S_2$: `x = 5` with `x` used later. Then `x` is in $OUT(S_2)$ but dead at the exit of $S_1$.
- (D) $USE(S_1)$ is live **before** $S_1$. Take $S_1$: `t = a`. Then `a` is in $USE(S_1)$ but need not be live after $S_1$.

**Key idea:** liveness flows backward: the live-out set of a statement is the live-in set of its successor (union over successors).

</details>
