# 2025 CS1 Q13: Which optimisation uses live variable analysis

## Question

Which ONE of the following techniques used in compiler code optimization uses live variable analysis?

- (A) Run-time function call management
- (B) Register assignment to variables
- (C) Strength reduction
- (D) Constant folding

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

A variable is **live** at a point if its current value may still be used later. Two variables that are never live at the same time can **share one register**. Deciding which variables can share a register, and which must be spilled, is exactly what **register assignment (allocation)** uses liveness for.

| Option | Why |
|---|---|
| A, function call management | Deals with activation records and the call stack, not liveness |
| **B, register assignment** | Uses live ranges (interference between live variables) |
| C, strength reduction | Replaces costly operations with cheaper ones (for example $x*2$ by $x+x$), using induction-variable analysis |
| D, constant folding | Evaluates constant expressions at compile time |

**Key idea:** live variable analysis feeds register allocation, and also dead-code elimination.

</details>
