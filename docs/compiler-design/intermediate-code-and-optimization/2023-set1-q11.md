# 2023 CS Q11: Front-end and back-end of a compiler

## Question

Consider the following statements regarding the front-end and back-end of a compiler.

S1: The front-end includes phases that are independent of the target hardware.

S2: The back-end includes phases that are specific to the target hardware.

S3: The back-end includes phases that are specific to the programming language used in the source code.

Identify the CORRECT option.

- (A) Only S1 is TRUE.
- (B) Only S1 and S2 are TRUE.
- (C) S1, S2, and S3 are all TRUE.
- (D) Only S1 and S3 are TRUE.

<details class="success" markdown="1">
<summary>Answer</summary>

**B (only S1 and S2 are TRUE)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Front end:** lexical, syntax and semantic analysis, then intermediate code generation. It depends on the **source language** but not on the target machine. **S1 is true.**

**Back end:** code optimisation for the target and code generation. It depends on the **target hardware** but not on the source language. **S2 is true.**

**S3 is false:** the back end works on intermediate code, so it does not care which language produced it. This split is why one back end can serve many languages, and one front end many machines.

**Key idea:** front end = source-language specific, back end = target-machine specific.

</details>
