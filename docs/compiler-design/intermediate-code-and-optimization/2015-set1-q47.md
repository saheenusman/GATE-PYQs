# 2015 CS1 Q47: Temporaries needed for a three-address SSA code of an expression

## Question

The least number of temporary variables required to create a three-address code in static single assignment form for the expression $q + r/3 + s - t * 5 + u * v/w$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**8**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Apply operator precedence ($*$ and $/$ before $+$ and $-$) and left-to-right associativity:

$$((((q + (r/3)) + s) - (t*5)) + ((u*v)/w))$$

In SSA every variable is assigned **exactly once**, so each operation needs a fresh temporary:

| Temp | Operation |
|---|---|
| $t_1$ | $r / 3$ |
| $t_2$ | $q + t_1$ |
| $t_3$ | $t_2 + s$ |
| $t_4$ | $t * 5$ |
| $t_5$ | $t_3 - t_4$ |
| $t_6$ | $u * v$ |
| $t_7$ | $t_6 / w$ |
| $t_8$ | $t_5 + t_7$ |

There are 8 operators, so 8 temporaries.

**Key idea:** in SSA no temporary is reused, so the number needed equals the number of operators.

</details>
