# 2013 CS Q49: Registers needed without spilling

## Question

**Common data for Questions 48 and 49.** The following code segment is executed on a processor which allows only register operands in its instructions. Each instruction can have at most two source operands and one destination operand. Assume that all variables are dead after this code segment.

```c
c = a + b;
d = c * a;
e = c + a;
x = c * c;
if (x > a) {
    y = a * a;
}
else {
    d = d * d;
    e = e * e;
}
```

What is the minimum number of registers needed in the instruction set architecture of the processor to compile this code segment without any spill to memory? Do not apply any optimization other than optimizing register allocation.

- (A) 3
- (B) 4
- (C) 5
- (D) 6

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Without code motion, statements stay in order. Count live values just after each statement.

| After statement | Live values | Count |
|---|---|---|
| `c = a + b` | $a, c$ ($b$ is dead) | 2 |
| `d = c * a` | $a, c, d$ | 3 |
| `e = c + a` | $a, c, d, e$ | **4** |
| `x = c * c` | $a, x, d, e$ ($c$ now dead) | 4 |
| `if (x > a)` | $a, x, d, e$ | 4 |

After `e = c + a`, the value $c$ is still needed by `x = c*c`, while $a$, $d$ and $e$ are needed later. The peak is 4, and a register allocator can always use $c$'s register for $x$, so **4 registers** suffice.

**Why the others fail:** (A) 3 is too few at the peak. (C), (D) are more than needed.

**Code check:** a liveness count per statement gave a maximum of 4.

**Key idea:** the minimum number of registers is the maximum number of simultaneously live values.

</details>
