# 2014 CS2 Q18: Which activity is NOT performed during compilation

## Question

Which one of the following is **NOT** performed during compilation?

- (A) Dynamic memory allocation
- (B) Type checking
- (C) Symbol table management
- (D) Inline expansion

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Dynamic memory allocation** (`malloc`, `new`) happens when the program **runs**, because the sizes and lifetimes are known only then. A compiler can only emit the calls.

- (B) type checking is done in semantic analysis (static typing).
- (C) the symbol table is built and used by the compiler throughout.
- (D) inline expansion replaces a call with the function body, an optimisation done at compile time.

**Classification flag:** this is a runtime-environment question. It is filed under `intermediate-code-and-optimization`, with `syntax-directed-translation` as the second topic, since there is no runtime-environment topic.

**Key idea:** static work (types, symbols, inlining) is compile time; heap allocation is run time.

</details>
