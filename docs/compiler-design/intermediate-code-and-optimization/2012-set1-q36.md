# 2012 CS Q36: Activation records and access links with nested procedures

## Question

Consider the program given below, in a block-structured pseudo-language with lexical scoping and nesting of procedures permitted.

```
Program main;
   Var ...

   Procedure A1;
      Var ...
      Call A2;
   End A1

   Procedure A2;
      Var ...

      Procedure A21;
         Var ...
         Call A1;
      End A21

      Call A21;
   End A2

   Call A1;
End main.
```

Consider the calling chain: Main $\to$ A1 $\to$ A2 $\to$ A21 $\to$ A1

The correct set of activation records along with their access links is given by

![Four diagrams, A to D, each a vertical stack of activation records with curved access-link arrows and a frame pointer. A: five records Main, A1, A2, A21, A1, each linked to the record above it. B: five records; A2 links to Main, A21 links to A2, the last A1 links to A21, and the first A1 has no link. C: only four records, Main, A1, A2, A21; A1 and A2 link to Main and A21 links to A2. D: five records Main, A1, A2, A21, A1; both A1 records and A2 link to Main, and A21 links to A2.](../../assets/2012/set1-q36.png)

- (A) the first diagram
- (B) the second diagram
- (C) the third diagram
- (D) the fourth diagram

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

An **access link** (static link) points to the activation record of the *lexically enclosing* procedure, not to the caller.

**Nesting:**

- `A1` and `A2` are declared directly inside `main`. Their access links point to `main`'s record.
- `A21` is declared inside `A2`. Its access link points to the most recent `A2` record.

**For the chain** Main $\to$ A1 $\to$ A2 $\to$ A21 $\to$ A1:

| Record | Access link points to |
|---|---|
| A1 (first) | Main |
| A2 | Main |
| A21 | A2 |
| A1 (second) | Main |

That is the fourth diagram, (D).

- (A) links each record to the one above it, which is the dynamic (caller) chain, not the static one.
- (B) links the last `A1` to `A21` and gives the first `A1` no link.
- (C) shows only four records; the chain has five.

**Code check:** a small table of lexical parents (`A1`, `A2` inside `main`; `A21` inside `A2`) gave the links in the table above.

**Classification note:** this is a runtime-environments question. The topic list has no runtime-environment topic, so it is filed under `intermediate-code-and-optimization` (the same choice as for the earlier runtime-environment questions).

**Key idea:** the access link follows lexical nesting, so a procedure always links to its definer, whoever called it.

</details>
