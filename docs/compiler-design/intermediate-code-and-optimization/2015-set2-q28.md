# 2015 CS2 Q28: True statement about an abstract syntax tree and a control flow graph

## Question

In the context of abstract-syntax-tree (AST) and control-flow-graph (CFG), which one of the following is TRUE?

- (A) In both AST and CFG, let node $N_2$ be the successor of node $N_1$. In the input program, the code corresponding to $N_2$ is present after the code corresponding to $N_1$
- (B) For any input program, neither AST nor CFG will contain a cycle
- (C) The maximum number of successors of a node in an AST and a CFG depends on the input program
- (D) Each node in AST and CFG corresponds to at most one statement in the input program

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- (A) False. A loop's back edge in a CFG makes a successor appear *earlier* in the code, and an AST child need not come later in the text either (e.g. the loop body of a `for`).
- (B) False. A **CFG** has cycles whenever the program has a loop. (An AST is a tree, so it has none.)
- (C) **True.** An AST node can have any number of children (a call with many arguments, a block with many statements), and a CFG node can have many successors (a `switch`). The maximum depends on the program.
- (D) False. A CFG node is typically a basic block holding several statements.

Option (C).

**Key idea:** AST fan-out and CFG fan-out are not bounded by a constant, and CFGs may have cycles.

</details>
