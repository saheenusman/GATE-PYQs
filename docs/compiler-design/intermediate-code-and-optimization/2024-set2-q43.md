# 2024 CS2 Q43: Triples for an array expression

## Question

Consider the following expression: $x[i] = (p + r) * -s[i] + u / w$. The following sequence shows the list of triples representing the given expression, with entries missing for triples (1), (3), and (6).

| # | op | arg1 | arg2 |
|---|---|---|---|
| (0) | $+$ | $p$ | $r$ |
| (1) | | | |
| (2) | uminus | (1) | |
| (3) | | | |
| (4) | $/$ | $u$ | $w$ |
| (5) | $+$ | (3) | (4) |
| (6) | | | |
| (7) | $=$ | (6) | (5) |

Which one of the following options fills in the missing entries CORRECTLY?

- (A) (1) `=[]  s  i`, (3) `*  (0)  (2)`, (6) `[]=  x  i`
- (B) (1) `[]=  s  i`, (3) `-  (0)  (2)`, (6) `=[]  x  (5)`
- (C) (1) `=[]  s  i`, (3) `*  (0)  (2)`, (6) `[]=  x  (5)`
- (D) (1) `[]=  s  i`, (3) `-  (0)  (2)`, (6) `=[]  x  i`

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Triple notation for arrays** (as in the Dragon book):

- `=[] s i` means *read* `s[i]` (the value).
- `[]= x i` means *address of the target* `x[i]`, which a later `=` triple assigns into.

**Fill in:**

- **(1)** is the operand of unary minus, `s[i]`, so it is a read: `=[] s i`.
- **(2)** `uminus (1)` is given.
- **(3)** multiplies $(p+r)$ by $-s[i]$: `* (0) (2)`. (It is a multiplication, not a subtraction.)
- **(5)** adds $(3)$ and $u/w$.
- **(6)** is the left side $x[i]$, used as an assignment target: `[]= x i`.
- **(7)** `= (6) (5)` stores (5) into that element.

That matches option (A).

**Why the others fail:** (B) and (D) use `-` for the product and `[]=` for the read of `s[i]`. (C) writes `[]= x (5)`, which puts the value in the index slot instead of `i`.

**Key idea:** in triples, `=[]` reads an array element and `[]=` names an element to assign into.

</details>
