# 2021 CS1 Q60: Number of DAG nodes for a code segment

## Question

Consider the following C code segment:

```c
a = b + c;
e = a + 1;
d = b + c;
f = d + 1;
g = e + f;
```

In a compiler, this code segment is represented internally as a directed acyclic graph (DAG). The number of nodes in the DAG is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Build the DAG with value numbering, so equal sub-expressions share a node.

| Statement | Node |
|---|---|
| leaves | $b$, $c$, and the constant $1$ (3 nodes) |
| `a = b + c` | $+(b,c)$ (new node, call it $n_1$) |
| `e = a + 1` | $+(n_1,1)$ (new node $n_2$) |
| `d = b + c` | same as $n_1$ (reused) |
| `f = d + 1` | $+(n_1,1)=n_2$ (reused) |
| `g = e + f` | $+(n_2,n_2)$ (new node $n_3$) |

Total: 3 leaves + $n_1$ + $n_2$ + $n_3$ $=\mathbf{6}$ nodes. Here $a$ and $d$ label $n_1$, and $e$ and $f$ label $n_2$.

A value-numbering script also gave 6 nodes.

**Key idea:** a DAG shares common sub-expressions, so repeated expressions add no new node.

</details>
