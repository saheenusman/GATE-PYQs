# 2024 CS2 Q21: Matching compiler phases with their products

## Question

Consider the following two sets:

| Set X | Set Y |
|---|---|
| P. Lexical Analyzer | 1. Abstract Syntax Tree |
| Q. Syntax Analyzer | 2. Token |
| R. Intermediate Code Generator | 3. Parse Tree |
| S. Code Optimizer | 4. Constant Folding |

Which one of the following options is the CORRECT match from Set X to Set Y?

- (A) P – 4; Q – 1; R – 3; S – 2
- (B) P – 2; Q – 3; R – 1; S – 4
- (C) P – 2; Q – 1; R – 3; S – 4
- (D) P – 4; Q – 3; R – 2; S – 1

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **P, lexical analyzer → 2, Token.** It turns characters into tokens.
- **Q, syntax analyzer → 3, Parse Tree.** It checks tokens against the grammar and builds the parse tree.
- **R, intermediate code generator → 1, Abstract Syntax Tree.** It works from the syntax tree (the abstract form of the parse tree) to emit intermediate code.
- **S, code optimizer → 4, Constant Folding.** Folding constants (for example `2*3` to `6`) is a classic optimization.

Match: P–2, Q–3, R–1, S–4.

**Why the others fail:** each of them pairs the lexer with something other than tokens, or the optimizer with a tree.

**Key idea:** know the artifact each compiler phase consumes or produces: tokens, parse tree, AST/IR, optimized code.

</details>
