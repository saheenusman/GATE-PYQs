# 2014 CS1 Q17: Which statement about code optimization is FALSE

## Question

Which one of the following is **FALSE**?

- (A) A basic block is a sequence of instructions where control enters the sequence at the beginning and exits at the end.
- (B) Available expression analysis can be used for common subexpression elimination.
- (C) Live variable analysis can be used for dead code elimination.
- (D) $x = 4 * 5 \Rightarrow x = 20$ is an example of common subexpression elimination.

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

$x = 4 * 5 \Rightarrow x = 20$ evaluates a constant expression at compile time. That is **constant folding**, not common subexpression elimination (CSE). CSE reuses a value already computed by an identical expression, such as $a = b + c;\ d = b + c$.

- (A) is the definition of a basic block.
- (B) an expression that is *available* at a point has been computed on every path and not changed since, so it can be reused: CSE.
- (C) an assignment to a variable that is not live afterwards is dead code.

**Key idea:** constant folding is not CSE; CSE needs a repeated expression.

</details>
