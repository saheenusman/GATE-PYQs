# 2017 CS1 Q12: Static single assignment form of a four-line three-address program

## Question

Consider the following intermediate program in three address code

```
p = a - b
q = p * c
p = u * v
q = p + q
```

Which one of the following corresponds to a *static single assignment* form of the above code?

- (A)
  ```
  p1 = a - b
  q1 = p1 * c
  p1 = u * v
  q1 = p1 + q1
  ```
- (B)
  ```
  p3 = a - b
  q4 = p3 * c
  p4 = u * v
  q5 = p4 + q4
  ```
- (C)
  ```
  p1 = a - b
  q1 = p2 * c
  p3 = u * v
  q2 = p4 + q3
  ```
- (D)
  ```
  p1 = a - b
  q1 = p * c
  p2 = u * v
  q2 = p + q
  ```

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**SSA rules.** (1) Every variable is assigned **exactly once**. (2) Every use refers to the version that is current at that point in the original program.

**Expected result.** Version each assignment, then rewrite uses:

| Original | SSA (one valid numbering) |
|---|---|
| `p = a - b` | `p1 = a - b` |
| `q = p * c` | `q1 = p1 * c` |
| `p = u * v` | `p2 = u * v` |
| `q = p + q` | `q2 = p2 + q1` |

Version numbers only need to be distinct per variable; they need not be consecutive. Option (B) follows the same structure: `p3`, then `q4` uses `p3`, then `p4`, then `q5 = p4 + q4`. Each name is defined once and every use matches the latest definition. So **(B)**.

**Why the others fail.**

- (A): `p1` and `q1` are each assigned twice, which breaks the single-assignment rule.
- (C): uses `p2`, `p4`, `q3`, which are never defined, so the uses do not match the definitions.
- (D): the right-hand sides use plain `p` and `q`, the old non-SSA names, so uses are not renamed.

**Key idea:** in SSA each name has one definition; every use must name the definition that reaches it.

</details>
