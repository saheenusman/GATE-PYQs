# 2025 CS2 Q21: Backpatching in one pass

## Question

Consider the following statements about the use of backpatching in a compiler for intermediate code generation:

- (I) Backpatching can be used to generate code for Boolean expression in one pass.
- (II) Backpatching can be used to generate code for flow-of-control statements in one pass.

Which ONE of the following options is CORRECT?

- (A) Only (I) is correct.
- (B) Only (II) is correct.
- (C) Both (I) and (II) are correct.
- (D) Neither (I) nor (II) is correct.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The problem.** For a jump such as `if a < b goto ?`, the target label is not known yet when the code is generated, because the code for the later part has not been seen. Generating code in **one pass** therefore needs a way to fill the targets in later.

**Backpatching** solves it. The generator keeps *lists* of incomplete jumps (the `truelist` and `falselist`) and fills in the target addresses as soon as they become known.

- **(I) True.** Short-circuit code for `&&`, `||`, `!` leaves jumps whose targets are decided later. Backpatching lists resolve them in one pass.
- **(II) True.** `if`, `if-else` and `while` have jumps over the body or back to the start. The `nextlist` and the same patching technique handle them in one pass.

Both statements are correct.

**Key idea:** backpatching records unresolved jumps in lists and patches them once the target is known, which allows one-pass code generation for both Boolean expressions and control flow.

</details>
