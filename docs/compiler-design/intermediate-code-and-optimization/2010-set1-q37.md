# 2010 CS Q37: Minimum registers needed to run a straight-line program without spilling

## Question

The program below uses six temporary variables $a, b, c, d, e, f$.

```
a = 1
b = 10
c = 20
d = a + b
e = c + d
f = c + e
b = c + e
e = b + f
d = 5 + e
return d + f
```

Assuming that all operations take their operands from registers, what is the minimum number of registers needed to execute this program without spilling?

- (A) $2$
- (B) $3$
- (C) $4$
- (D) $6$

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Count how many variables are **live** (will still be read later) after each statement. The minimum registers equal the largest such count.

| After statement | Live variables | Count |
|---|---|---|
| `a = 1` | $a$ | 1 |
| `b = 10` | $a, b$ | 2 |
| `c = 20` | $a, b, c$ | 3 |
| `d = a + b` | $c, d$ | 2 |
| `e = c + d` | $c, e$ | 2 |
| `f = c + e` | $c, e, f$ | 3 |
| `b = c + e` | $b, e, f$ | 3 |
| `e = b + f` | $e, f$ | 2 |
| `d = 5 + e` | $d, f$ | 2 |

$a$ and $b$ are dead right after `d = a + b`, and $c$ is dead after `b = c + e`. At most $3$ values are ever live together, and $3$ are needed (for example $c, e, f$ after `f = c + e`). A destination register can reuse a source register that dies in that statement. So $3$ registers suffice: (B).

- (A) $2$ fails at `f = c + e`, where $c, e, f$ are all live.
- (C) and (D) are more than needed.

**Code check:** a liveness analysis in Python gave a maximum of $3$ simultaneously live variables, with live-in sizes $0, 1, 2, 3, 2, 2, 3, 2, 2, 2$ for the ten statements.

**Key idea:** the register need of straight-line code is the maximum number of simultaneously live values.

</details>
