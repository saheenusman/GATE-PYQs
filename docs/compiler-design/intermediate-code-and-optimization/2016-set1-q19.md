# 2016 CS1 Q19: Number of variables after converting a code segment to SSA form

## Question

Consider the following code segment.

```
x = u - t;
y = x * v;
x = y + w;
y = t - z;
y = x * y;
```

The minimum number of total variables required to convert the above code segment to static single assignment form is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**10**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

In SSA every variable is assigned exactly once, so each assignment creates a new version.

```
x1 = u - t
y1 = x1 * v
x2 = y1 + w
y2 = t - z
y3 = x2 * y2
```

**Count the variables.**

- Never assigned, only read: $u, t, v, w, z$ (5 variables).
- Assigned once each: $x_1, y_1, x_2, y_2, y_3$ (5 variables).

Total $= 5 + 5 = 10$. The original names `x` and `y` no longer appear as variables, only their versions do.

**Key idea:** one fresh variable per assignment plus the unassigned inputs.

</details>
