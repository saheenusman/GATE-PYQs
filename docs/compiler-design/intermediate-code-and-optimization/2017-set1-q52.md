# 2017 CS1 Q52: Minimum registers to evaluate an expression on a load/store architecture

## Question

Consider the expression $(a-1)*(((b+c)/3)+d)$. Let X be the minimum number of registers required by an *optimal* code generation (without any register spill) algorithm for a load/store architecture, in which *(i) only load and store instructions can have memory operands* and *(ii) arithmetic instructions can have only register or immediate operands*. The value of X is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**2**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Rules.** Operands $a, b, c, d$ live in memory, so each must be loaded into a register first. Constants $1$ and $3$ are immediates and need no register.

**An order that uses 2 registers.** Evaluate the right operand of `*` first, then the left:

| Step | Instruction | Registers in use |
|---|---|---|
| 1 | `R1 = load b` | R1 |
| 2 | `R2 = load c` | R1, R2 |
| 3 | `R1 = R1 + R2` | R1 |
| 4 | `R1 = R1 / 3` (immediate) | R1 |
| 5 | `R2 = load d` | R1, R2 |
| 6 | `R1 = R1 + R2` | R1 |
| 7 | `R2 = load a` | R1, R2 |
| 8 | `R2 = R2 - 1` (immediate) | R1, R2 |
| 9 | `R1 = R2 * R1` | R1 |

At most 2 registers are live at once.

**Lower bound.** `b + c` combines two memory values. Both must be in registers at the same time (an arithmetic instruction has no memory operand), so at least 2 registers are needed.

**Order matters.** Doing $a-1$ first and keeping it live while computing $(b+c)/3 + d$ would need 3 registers ($a-1$, $b$, $c$). Evaluating the more demanding subtree first (Sethi-Ullman) avoids that.

So $X = $ **2**.

**Code check:** a Sethi-Ullman labelling of the expression gave 2. I also ran the 9-instruction two-register program above on 1000 random values of $a,b,c,d$, and it matched $(a-1)\times(((b+c)/3)+d)$ every time.

**Key idea:** evaluate the subtree that needs more registers first; immediates don't need a register, so only loaded variables count.

</details>
