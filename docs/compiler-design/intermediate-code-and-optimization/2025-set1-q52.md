# 2025 CS1 Q52: Counting basic blocks in 3-address code

## Question

Refer to the given 3-address code sequence. This code sequence is split into basic blocks. The number of basic blocks is ________. (Answer in integer)

```
1001: i = 1
1002: j = 1
1003: t1 = 10*i
1004: t2 = t1+j
1005: t3 = 8*t2
1006: t4 = t3-88
1007: a[t4] = 0.0
1008: j = j+1
1009: if j <= 10 goto 1003
1010: i = i+1
1011: if i <= 10 goto 1002
1012: i = 1
1013: t5 = i-1
1014: t6 = 88*t5
1015: a[t6] = 1.0
1016: i = i+1
1017: if i <= 10 goto 1013
```

<details class="success" markdown="1">
<summary>Answer</summary>

**6**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Find the **leaders** (first instructions of basic blocks):

1. The first instruction: **1001**.
2. Every instruction that is the **target** of a jump: 1003 (from 1009), 1002 (from 1011), 1013 (from 1017).
3. Every instruction that **immediately follows** a jump: 1010 (after 1009), 1012 (after 1011). After 1017 there is no next instruction.

Leaders: $\lbrace 1001, 1002, 1003, 1010, 1012, 1013\rbrace$. Each block runs from a leader up to just before the next one:

| Block | Instructions |
|---|---|
| B1 | 1001 |
| B2 | 1002 |
| B3 | 1003 to 1009 |
| B4 | 1010 to 1011 |
| B5 | 1012 |
| B6 | 1013 to 1017 |

That is **6** basic blocks. I confirmed the leader set with a short script.

**Key idea:** leaders are the first instruction, every jump target, and every instruction after a jump. The block count equals the leader count.

</details>
