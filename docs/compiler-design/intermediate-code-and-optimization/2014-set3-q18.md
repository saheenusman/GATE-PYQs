# 2014 CS3 Q18: Statements about recursion and storage allocation

## Question

Which of the following statements are CORRECT?

1. Static allocation of all data areas by a compiler makes it impossible to implement recursion.
2. Automatic garbage collection is essential to implement recursion.
3. Dynamic allocation of activation records is essential to implement recursion.
4. Both heap and stack are essential to implement recursion.

- (A) 1 and 2 only
- (B) 2 and 3 only
- (C) 3 and 4 only
- (D) 1 and 3 only

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Each recursive call needs its own copy of local variables, parameters and the return address. These live in an **activation record**, and several can be alive at once.

- **1 true.** If every data area is allocated statically, there is one fixed copy per procedure, so nested activations of the same procedure would overwrite each other.
- **2 false.** Garbage collection reclaims heap objects. Recursion with stack-allocated activation records needs no GC.
- **3 true.** Activation records must be created dynamically, one per call.
- **4 false.** A stack alone suffices. The heap is not essential (languages such as Pascal and C implement recursion with only a stack for local data).

So 1 and 3: **D**.

**Classification flag:** this is a runtime-environment question. It is filed under `intermediate-code-and-optimization` since there is no runtime-environment topic (the same choice as for the 2014 CS2 runtime-environment question).

**Key idea:** recursion needs dynamically allocated activation records, typically on a stack; it needs neither GC nor a heap.

</details>
