# 2018 CS Q47: Tokens produced by a longest-prefix lexical analyzer

## Question

A lexical analyzer uses the following patterns to recognize three tokens $T_1$, $T_2$, and $T_3$ over the alphabet $\lbrace a,b,c\rbrace$.

- $T_1$: `a?(b|c)*a`
- $T_2$: `b?(a|c)*b`
- $T_3$: `c?(b|a)*c`

Note that '`x?`' means 0 or 1 occurrence of the symbol $x$. Note also that the analyzer outputs the token that matches the longest possible prefix.

If the string `bbaacabc` is processed by the analyzer, which one of the following is the sequence of tokens it outputs?

- (A) $T_1T_2T_3$
- (B) $T_1T_1T_3$
- (C) $T_2T_1T_3$
- (D) $T_3T_3$

<details class="success" markdown="1">
<summary>Answer</summary>

**D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Step 1: from the start of `bbaacabc`.**

| Token | Longest prefix matched | Length |
|---|---|---|
| $T_1$ | `bba` | 3 |
| $T_2$ | `bb` | 2 |
| $T_3$ | `bbaac` ($c?$ empty, `bbaa`, then `c`) | 5 |

$T_3$ wins and consumes `bbaac`.

**Step 2: from the rest, `abc`.**

| Token | Longest prefix matched | Length |
|---|---|---|
| $T_1$ | `a` | 1 |
| $T_2$ | `ab` | 2 |
| $T_3$ | `abc` ($c?$ empty, `ab`, then `c`) | 3 |

$T_3$ wins again and consumes `abc`.

The output is $T_3T_3$: **D**.

**Why the others fail:** A, B and C start with $T_1$ or $T_2$, but those match fewer than 5 characters at the start. Longest prefix beats listing order.

**Code check:** a Python script using `re.fullmatch` on every prefix reproduced the table and the output $T_3T_3$.

**Key idea:** the lexer takes the longest match across *all* patterns at each position (maximal munch).

</details>
