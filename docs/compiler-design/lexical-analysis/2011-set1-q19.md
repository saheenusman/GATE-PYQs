# 2011 CS Q19: Machine model needed for lexical analysis

## Question

The lexical analysis for a modern computer language such as Java needs the power of which one of the following machine models in a necessary and sufficient sense?

- (A) Finite state automata
- (B) Deterministic pushdown automata
- (C) Non-deterministic pushdown automata
- (D) Turing machine

<details class="success" markdown="1">
<summary>Answer</summary>

**A**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

Tokens (identifiers, keywords, literals, operators, comments) are described by **regular expressions**. Regular expressions are exactly as powerful as finite automata, so a finite automaton is both necessary and sufficient for the scanner: (A).

Nesting and matching (balanced brackets, block structure) need a stack, but that is the parser's job, not the scanner's.

- (B), (C) pushdown automata are more powerful than needed, so they are sufficient but not necessary.
- (D) a Turing machine is even more powerful than needed.

**Key idea:** lexical analysis needs only regular-language power, so a finite automaton suffices.

</details>
