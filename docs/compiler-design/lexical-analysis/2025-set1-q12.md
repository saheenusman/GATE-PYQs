# 2025 CS1 Q12: The false statement about the symbol table

## Question

Which ONE of the following statements is FALSE regarding the symbol table?

- (A) Symbol table is responsible for keeping track of the scope of variables.
- (B) Symbol table can be implemented using a binary search tree.
- (C) Symbol table is not required after the parsing phase.
- (D) Symbol table is created during the lexical analysis phase.

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

| Option | Verdict | Reason |
|---|---|---|
| A | True | Scope information (which declaration a name refers to) is kept in the symbol table, usually as a stack of tables or scope numbers |
| B | True | Any dictionary structure works: hash table, binary search tree, linked list |
| **C** | **False** | The table is needed **after** parsing too: semantic analysis (type checking), code generation (addresses, offsets) and optimisation all look names up in it |
| D | True | The lexical analyser creates the entries when it recognises identifiers (later phases fill in types and attributes) |

The question asks for the false statement, which is (C).

**Key idea:** the symbol table is created early (lexical analysis) but used through the whole compiler, up to code generation.

</details>
