# 2010 CS Q13: Compiler data structure that holds information about variables and their attributes

## Question

Which data structure in a compiler is used for managing information about variables and their attributes?

- (A) Abstract syntax tree
- (B) Symbol table
- (C) Semantic stack
- (D) Parse table

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

The **symbol table** maps each identifier to its attributes: type, scope, storage location, and so on. The lexical analyser creates entries, and later phases look them up and fill in the attributes. (B).

- (A) An abstract syntax tree represents the structure of the program, not a table of names.
- (C) A semantic stack holds attribute values during syntax-directed translation, then discards them.
- (D) A parse table drives the parser (for example the LL or LR action table); it has nothing to do with variables.

**Classification note:** a symbol table is used by several phases, with no better home in the fixed topic list, so I filed this under `lexical-analysis`, the phase that creates its entries.

**Key idea:** the symbol table is the compiler's record of every name and its attributes.

</details>
