# 2017 CS2 Q5: Matching compiler inputs to the phase that processes them

## Question

Match the following according to input (from the left column) to the compiler phase (in the right column) that processes it:

| Input | Compiler phase |
|---|---|
| (P) Syntax tree | (i) Code generator |
| (Q) Character stream | (ii) Syntax analyzer |
| (R) Intermediate representation | (iii) Semantic analyzer |
| (S) Token stream | (iv) Lexical analyzer |

- (A) P $\to$ (ii), Q $\to$ (iii), R $\to$ (iv), S $\to$ (i)
- (B) P $\to$ (ii), Q $\to$ (i), R $\to$ (iii), S $\to$ (iv)
- (C) P $\to$ (iii), Q $\to$ (iv), R $\to$ (i), S $\to$ (ii)
- (D) P $\to$ (i), Q $\to$ (iv), R $\to$ (ii), S $\to$ (iii)

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The pipeline.**

$$\text{characters} \xrightarrow{\text{lexical}} \text{tokens} \xrightarrow{\text{syntax}} \text{syntax tree} \xrightarrow{\text{semantic}} \text{intermediate code} \xrightarrow{\text{code gen.}} \text{target code}$$

Each phase takes the previous phase's output as its input:

- **(Q) Character stream** is read by the **lexical analyzer (iv)**.
- **(S) Token stream** is read by the **syntax analyzer (ii)**.
- **(P) Syntax tree** is checked by the **semantic analyzer (iii)**.
- **(R) Intermediate representation** is translated by the **code generator (i)**.

That is P$\to$iii, Q$\to$iv, R$\to$i, S$\to$ii: **(C)**.

**Why the others fail.** Each of (A), (B), (D) pairs at least one input with a phase out of order, for example the character stream with the code generator or the token stream with the semantic analyzer.

**Status note:** no program applies; the answer matches the official key.

**Key idea:** the output of one compiler phase is the input to the next: characters, tokens, tree, intermediate code, target code.

</details>
