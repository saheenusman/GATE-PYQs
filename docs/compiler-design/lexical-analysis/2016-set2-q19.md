# 2016 CS2 Q19: Matching compiler phases with the concepts they use

## Question

Match the following:

| | Phase | | Concept |
|---|---|---|---|
| (P) | Lexical analysis | (i) | Leftmost derivation |
| (Q) | Top down parsing | (ii) | Type checking |
| (R) | Semantic analysis | (iii) | Regular expressions |
| (S) | Runtime environments | (iv) | Activation records |

- (A) P ↔ i, Q ↔ ii, R ↔ iv, S ↔ iii
- (B) P ↔ iii, Q ↔ i, R ↔ ii, S ↔ iv
- (C) P ↔ ii, Q ↔ iii, R ↔ i, S ↔ iv
- (D) P ↔ iv, Q ↔ i, R ↔ ii, S ↔ iii

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- P Lexical analysis $\leftrightarrow$ (iii) regular expressions: tokens are specified by regular expressions.
- Q Top-down parsing $\leftrightarrow$ (i) leftmost derivation: a top-down parser builds a leftmost derivation.
- R Semantic analysis $\leftrightarrow$ (ii) type checking.
- S Runtime environments $\leftrightarrow$ (iv) activation records (stack frames).

That is P-iii, Q-i, R-ii, S-iv: **(B)**.

**Key idea:** lexing - regular expressions; top-down - leftmost derivation; semantics - types; runtime - activation records.

</details>
