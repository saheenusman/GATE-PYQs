# 2024 CS2 Q29: False statements about attribute grammars

## Question

Which of the following statements is/are **FALSE**?

- (A) An attribute grammar is a syntax-directed definition (SDD) in which the functions in the semantic rules have no side effects
- (B) The attributes in a L-attributed definition cannot always be evaluated in a depth-first order
- (C) Synthesized attributes can be evaluated by a bottom-up parser as the input is parsed
- (D) All L-attributed definitions based on LR(1) grammar can be evaluated using a bottom-up parsing strategy

<details class="success" markdown="1">
<summary>Answer</summary>

**B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

- **(A) True.** That is the definition of an attribute grammar: an SDD with side-effect-free semantic rules.
- **(B) False.** In an L-attributed definition each inherited attribute depends only on the parent's attributes and on siblings to the **left**. So the attributes can always be evaluated in a single left-to-right depth-first traversal. The statement says "cannot always", which is wrong.
- **(C) True.** A synthesized attribute depends only on children, so it can be computed at each reduction by an LR parser.
- **(D) False per the key.** Evaluating L-attributed definitions bottom-up needs **marker non-terminals** (extra $\epsilon$ productions) to place inherited-attribute computations. These can destroy the LR(1) property, so the claim that **all** L-attributed definitions on LR(1) grammars can be handled this way does not hold.

**Why this is flagged:** (D) is the subtle one. I am following the official key, and the reasoning above is my reading of why it is false, not a derivation from the paper.

**Key idea:** L-attributed definitions are exactly those evaluable in one depth-first left-to-right pass. S-attributed ones are the ones that fit bottom-up parsing directly.

</details>
