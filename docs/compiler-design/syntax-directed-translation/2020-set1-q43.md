# 2020 CS Q43: Which attribute rules are L-attributed

## Question

Consider the productions A → PQ and A → XY. Each of the five non-terminals A, P, Q, X, and Y has two attributes: $s$ is a synthesized attribute, and $i$ is an inherited attribute. Consider the following rules.

Rule 1: P.$i$ = A.$i$ + 2, Q.$i$ = P.$i$ + A.$i$, and A.$s$ = P.$s$ + Q.$s$

Rule 2: X.$i$ = A.$i$ + Y.$s$ and Y.$i$ = X.$s$ + A.$i$

Which one of the following is TRUE?

- (A) Both Rule 1 and Rule 2 are L-attributed.
- (B) Only Rule 1 is L-attributed.
- (C) Only Rule 2 is L-attributed.
- (D) Neither Rule 1 nor Rule 2 is L-attributed.

<details class="success" markdown="1">
<summary>Answer</summary>

**B**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**The L-attributed condition.** In a production $A \to X_1 X_2 \dots X_n$, an **inherited** attribute of $X_j$ may depend only on:

- inherited attributes of the head $A$, and
- attributes (inherited or synthesized) of the symbols **to the left** of $X_j$, namely $X_1, \dots, X_{j-1}$.

It must **not** depend on symbols to its right, or on its own synthesized attributes. Synthesized attributes have no such restriction.

**Rule 1** for $A \to PQ$:

| Rule | Depends on | Allowed? |
|---|---|---|
| P.$i$ = A.$i$ + 2 | head's inherited A.$i$ | yes |
| Q.$i$ = P.$i$ + A.$i$ | P (left sibling), A.$i$ (head, inherited) | yes |
| A.$s$ = P.$s$ + Q.$s$ | children's synthesized attributes | yes (synthesized) |

All allowed, so Rule 1 is L-attributed.

**Rule 2** for $A \to XY$:

| Rule | Depends on | Allowed? |
|---|---|---|
| X.$i$ = A.$i$ + Y.$s$ | Y.$s$, where Y is to the **right** of X | **no** |
| Y.$i$ = X.$s$ + A.$i$ | X (left sibling), A.$i$ | yes |

The first rule makes X's inherited attribute depend on a right sibling, so Rule 2 is **not** L-attributed.

Only Rule 1 is L-attributed.

**Why the other options fail:** (A) and (C) claim Rule 2 is L-attributed. (D) claims Rule 1 is not.

**Key idea:** an inherited attribute can look up to the parent or sideways to the left, never to the right. This is what lets a single left-to-right pass evaluate everything.

</details>
