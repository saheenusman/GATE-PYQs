# 2026 CS1 Q53: Comparing two syntax-directed definitions

## Question

Consider the following two syntax-directed definitions SDD1 and SDD2 for type declarations.

![SDD1 on grammar G1: D to T V with D.type = T.type, V.type = T.type; T to int, T to float; V to V1 id with V1.type = V.type and put(id.entry, V.type); V to id with put(id.entry, V.type). SDD2 on grammar G2: D to D1 id with D.type = D1.type and put(id.entry, D1.type); D to T id with D.type = T.type and put(id.entry, T.type); T to int; T to float](../../assets/2026/set1-q53.png)

$D$ is the start symbol, and $int$, $float$ and $id$ are the three terminals. $V_1$ is the same as $V$ and $D_1$ is the same as $D$. The function $put$ updates the symbol table with the type of an identifier.

Let $P$ and $Q$ be the languages specified by grammars G1 and G2. Which of the following statements is/are true?

- (A) The languages $P$ and $Q$ are the same
- (B) SDD2 is S-attributed and contains only synthesized attributes
- (C) SDD1 is L-attributed and contains only inherited attributes
- (D) The specifications of SDD1 and SDD2 are such that the same entries get added to the symbol table

<details class="success" markdown="1">
<summary>Answer</summary>

**A, B and D**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Refresher.** A *synthesized* attribute is computed from the node's children. An *inherited* attribute comes from the parent or a left sibling. An SDD is *S-attributed* if it has only synthesized attributes.

**(A) True.** G1 generates $(int \mid float)\ id^+$: a type followed by one or more ids ($D \to TV$, $V \to V_1\,id \mid id$). G2 generates the same: $D \to T\,id$ first, then $D \to D_1\,id$ any number of times. Same language.

**(B) True.** In SDD2 every attribute is read from the children: $D.type = D_1.type$ and $D.type = T.type$ are computed bottom-up. The calls to $put$ use $D_1.type$ and $T.type$, which are also from children. So it is S-attributed.

**(C) False.** SDD1 does have inherited attributes ($V.type = T.type$ and $V_1.type = V.type$ flow downward), and it is L-attributed. But it also has synthesized ones ($T.type$ is set from the terminal, $D.type$ from $T.type$). So it does **not** contain *only* inherited attributes.

**(D) True.** Both SDDs record the declared type of every identifier: SDD1 passes the type down from $T$ to each $id$, and SDD2 passes the type up from $T$ through $D$ and uses it at every $id$. Every identifier ends up with the same type in both.

**Key idea:** read direction off the rule. Child to parent means synthesized; parent to child means inherited. S-attributed means no inherited attributes at all.

</details>
