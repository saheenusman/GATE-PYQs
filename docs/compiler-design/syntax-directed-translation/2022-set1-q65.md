# 2022 CS Q65: Evaluating an attribute grammar

## Question

Consider the following grammar along with translation rules.

| Production | Rule |
| --- | --- |
| $S \to S_1 \# T$ | $S.val = S_1.val * T.val$ |
| $S \to T$ | $S.val = T.val$ |
| $T \to T_1 \% R$ | $T.val = T_1.val \div R.val$ |
| $T \to R$ | $T.val = R.val$ |
| $R \to id$ | $R.val = id.val$ |

Here $\#$ and $\%$ are operators and $id$ is a token that represents an integer and $id.val$ represents the corresponding integer value. The set of non-terminals is $\lbrace S, T, R, P \rbrace$ and a subscripted non-terminal indicates an instance of the non-terminal.

Using this translation scheme, the computed value of $S.val$ for root of the parse tree for the expression $20\ \#\ 10\ \%\ 5\ \#\ 8\ \%\ 2\ \%\ 2$ is ______.

<details class="success" markdown="1">
<summary>Answer</summary>

**80**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Read the grammar.** Both rules are left recursive, so $\#$ and $\%$ associate to the left. Also, $\%$ lives inside $T$ and $\#$ at the level of $S$, so $\%$ binds tighter than $\#$.

**Group the expression.**

$$20\ \#\ (10\ \%\ 5)\ \#\ (8\ \%\ 2\ \%\ 2)$$

**Evaluate the $T$ parts** (here $\%$ means $\div$):
- $20 \to 20$
- $10\ \%\ 5 = 10 \div 5 = 2$
- $8\ \%\ 2\ \%\ 2 = (8 \div 2) \div 2 = 2$

**Evaluate $S$** (here $\#$ means $*$), left to right:

$$S.val = (20 * 2) * 2 = 80$$

**Code check:** evaluating the grouped expression gave 80.

**Key idea:** the grammar shape fixes precedence and associativity; compute the values bottom-up over the parse tree.

</details>
