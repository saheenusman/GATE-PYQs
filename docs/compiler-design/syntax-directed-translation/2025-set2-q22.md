# 2025 CS2 Q22: S-attributed and L-attributed rules

## Question

Given the following syntax directed translation rules:

- Rule 1: $R \to AB\ \lbrace B.i = R.i - 1;\ A.i = B.i;\ R.i = A.i + 1;\rbrace$
- Rule 2: $P \to CD\ \lbrace P.i = C.i + D.i;\ D.i = C.i + 2;\rbrace$
- Rule 3: $Q \to EF\ \lbrace Q.i = E.i + F.i;\rbrace$

Which ONE is the CORRECT option among the following?

- (A) Rule 1 is S-attributed and L-attributed; Rule 2 is S-attributed and not L-attributed; Rule 3 is neither S-attributed nor L-attributed
- (B) Rule 1 is neither S-attributed nor L-attributed; Rule 2 is S-attributed and L-attributed; Rule 3 is S-attributed and L-attributed
- (C) Rule 1 is neither S-attributed nor L-attributed; Rule 2 is not S-attributed and is L-attributed; Rule 3 is S-attributed and L-attributed
- (D) Rule 1 is S-attributed and not L-attributed; Rule 2 is not S-attributed and is L-attributed; Rule 3 is S-attributed and L-attributed

<details class="success" markdown="1">
<summary>Answer</summary>

**C**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Definitions.**

- **S-attributed:** only **synthesized** attributes (each depends on children).
- **L-attributed:** every **inherited** attribute of a right-hand-side symbol depends only on the parent's inherited attributes and on symbols to its **left**. (S-attributed is a special case of L-attributed.)

| Rule | Analysis | S-attr? | L-attr? |
|---|---|---|---|
| 1: $R \to AB$ | $A.i = B.i$ is an inherited attribute of $A$ that depends on $B$, which is to its **right**. Also $B.i$ and $A.i$ are inherited, so the rule is not S-attributed | No | **No** |
| 2: $P \to CD$ | $D.i = C.i + 2$ is inherited, so **not S-attributed**. But $D$ depends only on $C$, to its left, so it is **L-attributed**. ($P.i$ is synthesized and fine) | No | Yes |
| 3: $Q \to EF$ | Only the synthesized $Q.i = E.i + F.i$ | Yes | Yes |

This matches option C.

| Option | Why wrong |
|---|---|
| A, B | Rule 2 contains an inherited attribute, so it cannot be S-attributed |
| D | Rule 1 contains inherited attributes, so it cannot be S-attributed |

**Key idea:** an inherited attribute that reads a right sibling breaks L-attribution, and any inherited attribute breaks S-attribution.

</details>
