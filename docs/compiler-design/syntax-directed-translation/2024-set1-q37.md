# 2024 CS1 Q37: Evaluate a syntax-directed definition on MMLK

## Question

Consider the following syntax-directed definition (SDD).

| Production | Semantic rule |
|---|---|
| $S \to D\,H\,T\,U$ | $S.val = D.val + H.val + T.val + U.val$ |
| $D \to \text{"M"}\,D_1$ | $D.val = 5 + D_1.val$ |
| $D \to \epsilon$ | $D.val = -5$ |
| $H \to \text{"L"}\,H_1$ | $H.val = 5 * 10 + H_1.val$ |
| $H \to \epsilon$ | $H.val = -10$ |
| $T \to \text{"C"}\,T_1$ | $T.val = 5 * 100 + T_1.val$ |
| $T \to \epsilon$ | $T.val = -5$ |
| $U \to \text{"K"}$ | $U.val = 5$ |

Given "MMLK" as the input, which one of the following options is the CORRECT value computed by the SDD (in the attribute $S.val$)?

- (A) 45
- (B) 50
- (C) 55
- (D) 65

<details class="success" markdown="1">
<summary>Answer</summary>

**A (45)**

</details>

<details class="info" markdown="1">
<summary>Solution</summary>

**Parse "MMLK" as $D\,H\,T\,U$:** $D$ = "MM", $H$ = "L", $T$ = empty, $U$ = "K".

All attributes are synthesized, so evaluate bottom-up:

| Part | Derivation | Value |
|---|---|---|
| $D$ | $M\,M\,\epsilon$: $5 + (5 + (-5))$ | **5** |
| $H$ | $L\,\epsilon$: $50 + (-10)$ | **40** |
| $T$ | $\epsilon$ | **−5** |
| $U$ | K | **5** |

$$S.val = 5 + 40 + (-5) + 5 = 45.$$

**Why the others fail:** 50, 55 and 65 come from forgetting an $\epsilon$ rule's negative value (−5 for $D$ or $T$, −10 for $H$).

**Key idea:** the $\epsilon$-productions contribute their own constants. Do not skip them.

</details>
