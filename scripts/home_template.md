# GATE CS PYQ Solutions

Previous-year GATE CS questions, solved topic by topic, with diagrams and answers checked against the official answer keys.

{{SUMMARY}}

!!! tip "On a phone"
    Tap **☰** (top left) for the topic menu, and the magnifier (top right) to search.

## How to use

1. Pick a topic below, or browse [By year](by-year/index.md).
2. Read the question and try it yourself first.
3. Tap **Answer** to check, then **Solution** for the working.

Each question has a status:

- **verified**: matches the official answer key, and any code was compiled and run
- **disputed**: the working and the official key disagree (both are explained)
- **unverified**: not yet checked against the key
